# edit-modes bash 判定测试用例

用于验证 `edit-modes/index.ts` 中的两个策略（均基于 tree-sitter-bash AST）。命令以 JSON 字符串列出，便于直接复制。

- **只读策略** `analyzeBashCommand()`：用于 `ask-to-edit` / `auto-edit`。期望放行 = 只读；期望弹确认 = 非只读。
- **auto-all 策略** `classifyDangerousBash()`：期望自动放行（无危险效果）/ 弹确认（命中危险策略）。
- `git commit` 由 `isGitCommitCommand()` 在所有模式强制确认，不在此列。

统计：只读策略 109 放行 + 62 弹确认；auto-all 策略 33 放行 + 40 弹确认。合计 244 条。

> 复现方式（开发机）：从 `index.ts` 抽出 `const SAFE_REDIRECT_TARGETS` 到 `// git commit guard` 之前的分类器代码，用 esbuild 转成 ESM 后 `import { analyzeBashCommand, classifyDangerousBash }`，对下面四组逐一断言。
