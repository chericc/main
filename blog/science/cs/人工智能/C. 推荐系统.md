# 附录 C 推荐系统

**本章导读**：推荐系统的本质是**从稀疏反馈中估计偏好**，并在**长期收益**与**即时点击**之间做权衡。它把第 19 章的监督学习、第 17 章的 bandit、第 13 章的图模型与第 18 章的机制设计揉在一起。本附录按"经典 → 深度 → 图 → 序列/强化 → 评估 → 在线"的顺序展开。

**学习目标**：完成本附录学习后，你应当能够：

- 写出协同过滤的两种形式与矩阵分解的目标；
- 说明隐式反馈建模（BPR、ALS）与显式评分的差异；
- 比较 NCF、Wide&Deep、DeepFM、DIN 的结构创新；
- 说明 LightGCN/PinSage 如何把图结构用于推荐；
- 解释序列推荐与强化学习推荐的问题设定；
- 设计离线与在线评估方案，识别"离线好、线上差"的原因。

**预备知识**：第 19 章的矩阵分解与深度学习；第 17 章的 bandit；基本的线性代数与优化。

---

## C.1 协同过滤与矩阵分解

**用户-物品矩阵** $R \in \mathbb{R}^{m\times n}$ 高度稀疏（通常 < 5% 有观测）。

**（1）基于用户的协同过滤（UserCF）**：找相似用户，推荐他们喜欢的物品。

$$\hat r_{ui} = \frac{\sum_{v \in N(u)} \text{sim}(u,v)\, r_{vi}}{\sum_{v} |\text{sim}(u,v)|}$$

相似度：余弦、皮尔逊、Jaccard。

**（2）基于物品的协同过滤（ItemCF）**：$r_{ui}$ 用用户评过分的相似物品加权。工业界更常用（物品数相对稳定、可离线预计算）。

**（3）矩阵分解（MF）**：把 $R$ 分解为 $P \in \mathbb{R}^{m\times k}$、$Q \in \mathbb{R}^{n\times k}$：

$$\min_{P,Q} \sum_{(u,i)\in\Omega} \big(r_{ui} - p_u^\top q_i\big)^2 + \lambda(\|p_u\|^2 + \|q_i\|^2)$$

用 **SGD** 或 **ALS**（交替最小二乘，可并行）求解。

**（4）隐式反馈**：只有点击/购买，没有负样本。两种处理：

- **BPR（贝叶斯个性化排序）**：对每个用户构造正负对 $(u, i^+, i^-)$，最大化

$$\sum \ln\sigma\big(\hat r_{ui^+} - \hat r_{ui^-}\big) - \lambda\|\Theta\|^2$$

- **ALS with confidence**：$c_{ui} = 1 + \alpha r_{ui}$，置信度加权的最小二乘。

**（5）偏差项**：$\hat r_{ui} = \mu + b_u + b_i + p_u^\top q_i$，吸收用户/物品的整体倾向。

**冷启动**：新用户/新物品无交互，需用**内容特征**（Side info）或**探索**（bandit）。第 17.3 节的 Thompson 采样是标准工具。

## C.2 深度学习推荐

**（1）Neural CF（NCF）**：用 MLP 替代内积，学习用户-物品的任意交互函数：

$$\hat r_{ui} = f_\theta\big(\text{concat}(p_u, q_i)\big)$$

**（2）Wide & Deep**：宽线性部分记忆（特征交叉），深部分泛化（嵌入 + MLP），联合训练。

**（3）DeepFM**：FM（因子分解机）建模二阶交叉 + DNN 建模高阶交叉，共享嵌入。

**（4）DCN（Deep & Cross Network）**：显式的高阶特征交叉层：

$$x_{l+1} = x_0 x_l^\top w_l + b_l + x_l$$

**（5）DIN（Deep Interest Network）**：用**注意力**根据候选物品动态聚合用户历史行为——"用户对什么感兴趣取决于要推荐什么"。

**（6）特征与工程**：

| 特征类型 | 例子 |
| --- | --- |
| 用户画像 | 年龄、性别、地域 |
| 行为序列 | 点击、购买、停留时长 |
| 物品属性 | 类目、品牌、价格 |
| 上下文 | 时间、位置、设备、网络 |
| 交叉特征 | 用户×类目偏好、物品共现 |

**（7）多任务学习**：CTR + 转化率（CVR）+ 停留时长联合建模（MMOE、PLE），利用任务间的相关性提升样本效率。

**（8）损失与校准**：CTR 预估常用**交叉熵**；负采样比例会导致概率偏差，需**校准**（如使用真实负样本比例校正）。

## C.3 图神经网络推荐

**为什么用图**：用户-物品交互天然是二分图；高阶关系（用户-物品-用户）提供协同信号。

**（1）GCN 式传播**（LightGCN）：去掉特征变换与非线性，只保留邻域聚合：

$$e_u^{(k+1)} = \sum_{i \in N(u)} \frac{1}{\sqrt{|N(u)||N(i)|}} e_i^{(k)}$$

最终嵌入取各层平均。LightGCN 的简洁性说明：**在推荐中，传播结构比非线性更重要**。

**（2）PinSage**：工业级 GraphSAGE 变体，用随机游走采样邻居，支持十亿级图。

**（3）异构图**：用户-物品-品牌-类目多类型节点，用元路径（meta-path）或关系感知聚合。

**（4）知识图谱增强**：把物品属性、外部知识作为边，缓解冷启动与稀疏。

**（5）问题**：**过度平滑**（层数多时节点表示趋同）、**流行度偏差**（高度节点主导）、** scalability**（邻居爆炸）。

## C.4 序列推荐与强化学习推荐

**（1）序列推荐**：用户行为是有序的，下一物品预测可建模为序列任务。

| 模型 | 思路 |
| --- | --- |
| FPMC / GRU4Rec | 马尔可夫 / RNN 建模转移 |
| Caser | 卷积捕捉局部序列模式 |
| SASRec | 自注意力（类似 GPT）建模长序列 |
| BERT4Rec | 双向掩码建模（类似 BERT） |
| 生成式推荐 | 把物品离散为 token，用 LLM 生成 |

**（2）强化学习推荐**：把推荐看作序贯决策，优化**长期留存**而非单次点击。

- 状态：用户画像 + 历史；
- 动作：推荐列表；
- 奖励：点击、停留、留存、负反馈（退款/卸载）；
- 挑战：**离线评估难**（反事实）、**探索成本高**、**奖励延迟**。

实践常用：**bandit**（LinUCB、Thompson）做冷启动与探索；**离线 RL**（CQL、IQL）用日志数据训练；**模拟器**做策略预演。

**（3）生成式推荐**：把推荐转化为"序列生成"（如 TIGER），用语义 ID 表示物品，借 LLM 的序列建模能力；优点是可统一召回与排序，缺点是训练与推理成本。

## C.5 冷启动与评价指标

**冷启动的三种情形**：

| 情形 | 可用信息 | 方法 |
| --- | --- | --- |
| 新用户 | 注册信息、少量行为 | 内容/人口统计、快速问卷、bandit 探索 |
| 新物品 | 属性、文本/图像 | 内容嵌入、跨域迁移、知识图谱 |
| 新系统 | 无数据 | 专家规则、迁移学习、主动学习 |

**离线指标**：

| 指标 | 含义 |
| --- | --- |
| HR@K | 命中率（Top-K 中是否有正样本） |
| NDCG@K | 考虑位置折扣的排序质量 |
| MRR | 首个正确项位置的倒数 |
| AUC / GAUC | 排序能力（GAUC 按用户加权） |
| Recall@K / Precision@K | 覆盖率与准确率 |
| 覆盖率 / 多样性 / 新颖性 | 生态健康度 |

**离线评估的陷阱**：

1. **数据偏差**：日志只包含"被曝光过"的物品（**曝光偏差**）；
2. **位置偏差**：用户更可能点击靠前位置；
3. **反馈回路**：模型只推荐它喜欢的，评估数据也被它塑造；
4. **评估协议不一致**：负样本采样方式不同导致指标不可比。

**对策**：**反事实评估**（IPS、Doubly Robust）、**无偏学习**（unbiased LTR）、**模拟器**、**在线 A/B**。

**在线指标**：CTR、CVR、人均时长、留存、GMV、多样性、投诉率。**长期指标**（留存）比短期指标（点击）更重要，但反馈更慢。

## C.6 信息流推荐与在线学习

**信息流（feed）推荐**的特点：

- **强实时**：新内容秒级涌入，需快速冷启动；
- **强上下文**：位置、时间、网络、设备影响巨大；
- **多目标**：点击、停留、互动、负反馈、生态；
- **审核与安全**：内容合规是硬约束。

**系统架构**（典型四段）：

```
召回（多路：协同/向量/热度/社交）→ 粗排（轻量模型）→ 精排（重模型）→ 重排（多样性/打散/规则）
```

**在线学习**：

| 方式 | 说明 |
| --- | --- |
| 流式训练 | 实时更新参数（FTRL、在线 SGD） |
| 增量索引 | 新物品立即可召回 |
| 近线训练 | 分钟级更新（参数服务器） |
| 模型热切换 | 无停机上线 |

**EE（探索-利用）**：用 bandit 分配少量流量探索新内容，兼顾生态与收益。

**多样性与打散**：MMR（最大边际相关性）、DPP（行列式点过程）、规则打散（同作者/同类目限流）。

**生态与公平**：新创作者曝光、长尾内容扶持、避免"强者愈强"的马太效应；这与第 18 章的公平分配、第 27 章的算法伦理直接相关。

**评估的终极标准**：不是离线 AUC，而是**用户长期价值**与**生态健康**。这要求把短期指标与长期指标结合，并用**因果方法**（附录 D）评估干预效果。

## 本附录小结

**核心要点**

1. 协同过滤分 UserCF/ItemCF；**矩阵分解**用隐向量刻画偏好，隐式反馈用 BPR/置信度 ALS。
2. 深度推荐的四类创新：**交互函数（NCF）、特征交叉（Wide&Deep/DeepFM/DCN）、动态兴趣（DIN）、多任务（MMOE/PLE）**。
3. 图推荐用邻域传播（LightGCN）或采样聚合（PinSage），需处理过度平滑与流行度偏差。
4. 序列推荐从 GRU4Rec 演进到 SASRec/BERT4Rec 与生成式推荐；RL 推荐优化长期价值但评估困难。
5. 冷启动靠内容特征 + 迁移 + 探索；离线评估必须警惕**曝光/位置偏差与反馈回路**。
6. 信息流系统是"召回 → 粗排 → 精排 → 重排"的流水线，在线学习与 EE 是核心竞争力；最终标准是长期价值与生态健康。
