# 第 13 章 概率推理（Probabilistic Reasoning）

**本章导读**：全联合分布能回答一切问题，却装不下真实问题。贝叶斯网络用**局部条件独立**把联合分布拆成若干小因子的乘积，从而既保住表达力又控制参数规模。本章讲三件事：如何用网络表示不确定知识（13.1–13.3）、如何在网络上做精确推断（13.4，变量消元）与近似推断（13.5，采样与变分）、以及如何区分"相关"与"因果"（13.6）。

**学习目标**：完成本章学习后，你应当能够：

- 用贝叶斯网络表示联合分布，写出链式分解并计算参数数；
- 判断给定网络中的条件独立关系（d-分离）；
- 用 CPT、确定性节点、逻辑节点与连续分布刻画条件分布；
- 手工执行变量消元，说明消元顺序对复杂度的影响；
- 描述直接采样、拒绝采样、似然加权、Gibbs 采样的偏差与效率；
- 说明因果网络与贝叶斯网络的差别，识别混杂与对撞偏差。

**预备知识**：第 12 章的概率与条件独立；图论中的有向无环图（DAG）与路径。

## 13.1 不确定领域中的知识表示

**贝叶斯网络（Bayesian network, BN）** 是一个有向无环图，节点是随机变量，边表示**直接影响**，每个节点附带**条件概率表（CPT）**：

$$P(X_1, \dots, X_n) = \prod_{i=1}^{n} P\big(X_i \mid \text{Parents}(X_i)\big)$$

**经典例子：防盗报警网络**（Pearl 的原始例子）：

```
Burglary ──→ Alarm ←── Earthquake
                │
                ├──→ JohnCalls
                └──→ MaryCalls
```

- 节点：`Burglary`（入室盗窃）、`Earthquake`（地震）、`Alarm`（报警）、`JohnCalls`、`MaryCalls`；
- 参数：$P(B)$、$P(E)$、$P(A \mid B, E)$（4 个）、$P(J \mid A)$（2 个）、$P(M \mid A)$（2 个），共 10 个；
- 全联合分布：$2^5 = 32$ 个条目。

**参数节省的一般公式**：若每个节点最多 $k$ 个父节点、取值数 $d$，则参数数 $O(n d^{k+1})$，而非 $O(d^n)$。这一差距是贝叶斯网络可行的根本原因。

**语义的两种读法**：

1. **分解（因子化）**：$P$ 等于各节点"给定父节点的条件概率"之积；
2. **局部机制（causal / generative）**：每个节点描述"其父节点如何生成它"——这是建模者更常用的直觉。

**建造网络的三个步骤**：

1. 确定变量集与取值；
2. 确定依赖结构（边），并保证无环；
3. 填写 CPT（可由专家知识、数据统计或两者结合）。

**边方向的实用规则**：**从原因指向结果**。这不是数学要求（同一分布可由不同方向的网络表示），但因果方向通常更稀疏、更易填表、更易解释——这也是 §13.6 的伏笔。

## 13.2 贝叶斯网络的语义

**d-分离（d-separation）** 给出了从图结构直接读出条件独立的判定规则。给定证据集 $E$，一条路径被**阻断**当且仅当路径上存在：

- **链或分叉**中的中间节点**在 $E$ 中**（被观测）；
- **对撞**中的中间节点**不在 $E$ 中，且其后代都不在 $E$ 中**。

若所有路径都被阻断，则两端变量在给定 $E$ 下**条件独立**。

**d-分离的三种基本形态**（与 §12.4 对应）：

| 形态 | 结构 | 阻断条件 |
| --- | --- | --- |
| 链 | $X \to Z \to Y$ | $Z$ 被观测 |
| 分叉 | $X \leftarrow Z \to Y$ | $Z$ 被观测 |
| 对撞 | $X \to Z \leftarrow Y$ | $Z$ **未**被观测（且后代未被观测） |

**应用示例（报警网络）**：

- `JohnCalls ⟂ MaryCalls | Alarm`：给定报警时，两人独立；
- `Burglary ⟂ Earthquake`：无共同父节点，独立；
- `Burglary ⟂ JohnCalls | Alarm`：给定报警后，盗窃与 John 打电话独立（路径被阻断）；
- 但若**不**观测 `Alarm`：`JohnCalls` 与 `MaryCalls` 通过 `Alarm` 相关（都暗示报警）。

**马尔可夫毯（Markov blanket）**。节点 $X$ 的马尔可夫毯是它的**父节点 + 子节点 + 子节点的其他父节点**。给定马尔可夫毯，$X$ 与网络中其余所有节点条件独立。这一性质是吉布斯采样与特征选择的理论基础。

**等价的马尔可夫随机场**。任何 BN 都有唯一的**最小 I-map**（保持所有条件独立的稀疏图），但反过来，把有向图转为无向图（moralization：连父节点、去方向）会**丢失**部分条件独立。这就是为什么同一分布用 MRF 表示时通常需要更多参数（附录 F.1）。

## 13.3 条件分布的高效表示

CPT 是最朴素的表示：$k$ 个父节点、每个 $d$ 值时需 $d^k$ 个数字。当父节点多或取值连续时，需要更紧凑的形式。

**（1）确定性节点（deterministic node）**。子节点由父节点唯一决定，无需完整 CPT：

$$P(\text{Out} \mid A, B) = 1 \text{ 当且仅当 } \text{Out} = A \land B$$

**（2）逻辑节点**：`AND`、`OR`、`NOT`、`XOR` 等，等价于确定性节点，可用规则声明。

**（3）噪声或（noisy-OR）**。$n$ 个原因独立地"可能引发"结果：

$$P(\text{Effect} \mid \text{Parents}) = 1 - \prod_{i \in \text{true parents}} (1 - q_i)$$

其中 $q_i = P(\text{Effect} \mid \text{只有原因 } i)$。参数从 $2^n$ 降到 $n$，且天然解释"多个原因叠加提高概率"。医学诊断网络大量使用它。

**（4）上下文特定独立（context-specific independence, CSI）**。某些父节点取值确定后，其余父节点无关。例如：

```
if 天气 = 晴: 带伞概率 = 0.05（与季节无关）
if 天气 = 雨: 带伞概率 = 0.9
```

用**树/规则（decision tree or rule）** 表示 CPT 可显著压缩。

**（5）连续变量**：

| 形式 | 表达 | 用途 |
| --- | --- | --- |
| 线性高斯 | $X \sim \mathcal{N}(w_0 + \sum w_i u_i,\ \sigma^2)$ | 卡尔曼滤波、结构方程模型 |
| 高斯混合 | 多个高斯的加权和 | 多模态连续分布 |
| 非参数（核密度、样条） | 由数据决定形状 | 小样本、灵活建模 |

**线性高斯网络的特殊地位**：所有边缘与条件分布仍是高斯，精确推断可用矩阵运算闭式求解——这是 §14.4 卡尔曼滤波的基础。

## 13.4 贝叶斯网络中的精确推断

**推断任务**：

- **后验分布**：$P(Q \mid E=e)$；
- **最大后验（MAP）**：$\arg\max_q P(Q=q \mid E=e)$；
- **边际似然**：$P(E=e)$（用于模型比较）。

**变量消元（variable elimination, VE）**。核心思想：把求和移到因子内部，避免重复枚举。

1. 把每个 CPT 写成**因子**（factor，一张关于若干变量的表）；
2. 按某个**消元顺序**逐个消去隐变量：把含该变量的所有因子相乘，再对该变量求和，得到新因子；
3. 最后把所有因子相乘并归一化。

**示例**：查询 $P(B \mid j, m)$，按 $M, A, E$ 的顺序消去隐变量（$J$、$M$ 都是证据，$J$ 只出现在一个因子里）：

$$P(B \mid j,m) = \alpha \sum_e P(e) \sum_a P(a \mid B,e)\,P(j \mid a)\underbrace{\sum_m P(m \mid a)}_{=\,1}$$

关键观察：$M$ 只以 $P(m \mid a)$ 的形式出现，且对 $m$ 求和为 $1$——所以在本例中，一旦知道 $A$，$M$ 的证据就不再提供额外信息，可以直接消去。这就是变量消元相对于"枚举全部隐变量"的加速方式。

**复杂度**：

- 时间与空间由**诱导宽度（induced width）** 决定，即消元过程中产生的最大因子规模；
- 对树状网络，VE 是线性的；
- 对一般网络，最坏指数——精确推断是 **NP 难**的，且计数问题（配分函数）是 **#P 难**的；
- 消元顺序对复杂度影响巨大，求最优顺序是 NP 难，实践中用**最小度/最小填入**启发式。

**其他精确算法**：

| 算法 | 思路 | 适用 |
| --- | --- | --- |
| 变量消元 | 逐个消元，复用因子 | 单查询、中等宽度 |
| 桶消元（bucket elimination） | VE 的表格化组织 | 教学与实现参考 |
| 联结树（junction tree） | 把网络化为团树，消息传递 | 多查询、可复用 |
| 信念传播（belief propagation） | 树上精确、一般图上近似 | 树、稀疏图 |
| 递归条件化（recursive conditioning） | 按变量分裂 + 缓存 | 高宽度但可分解 |

**联结树算法**值得单独理解：它把 BN 转化为一棵"团（clique）树"，满足**运行交集性质**，然后在树上做两遍消息传递（收集 + 分发），一次编译后可回答任意查询。它就是 §14.2 前向-后向算法在图模型上的推广。

## 13.5 贝叶斯网络中的近似推断

当网络宽度大、精确推断不可行时，用采样或变分近似。

**（1）直接采样（direct sampling / ancestral sampling）**。按拓扑序采样每个节点：先采父节点，再按 CPT 采子节点。得到的是联合分布的样本，但**不接受证据**——需要用拒绝采样。

**（2）拒绝采样（rejection sampling）**。采样后丢弃与证据不符的样本，用剩余样本估计后验。

- 正确但**极低效**：接受率 = $P(E=e)$，证据罕见时几乎全部丢弃；
- 复杂度随证据变量数指数恶化。

**（3）似然加权（likelihood weighting）**。按证据固定证据变量的值，只在非证据变量上采样，并用**权重** $w = \prod_{e \in E} P(e \mid \text{parents}(e))$ 修正偏差。

- 估计量无偏，效率远高于拒绝采样；
- 缺点：当证据变量的父节点很多时，权重方差大（**权重退化**）。

**（4）吉布斯采样（Gibbs sampling / MCMC）**。从任意与证据一致的初始赋值出发，反复：

1. 随机选一个非证据变量 $X_i$；
2. 按 $P(X_i \mid \text{马尔可夫毯}(X_i))$ 重新采样它的值。

- 只需计算局部条件概率（马尔可夫毯），无需全联合分布；
- 收敛后样本近似后验；
- 缺点：**混合慢**（多模态、强相关时），难以判断收敛；对确定性关系敏感。

**（5）其他 MCMC**：Metropolis–Hastings、哈密顿蒙特卡洛（HMC/NUTS）——后者利用梯度，是现代概率编程系统的默认（§15.5）。

**（6）变分推断（variational inference）**。把推断变成优化：选一个简单分布族 $q_\phi$，最小化

$$\mathrm{KL}\big(q_\phi(Z) \,\|\, P(Z \mid E)\big) = \log P(E) - \underbrace{\mathbb{E}_q[\log P(Z,E) - \log q_\phi(Z)]}_{\text{ELBO}}$$

最大化 **ELBO** 等价于最小化 KL。优点是**快、可扩展、可批量**；缺点是有**近似偏差**（$q$ 族不够灵活时低估后验方差），且不保证一致性。

**（7）信念传播与环状图**。树上精确；一般图上做 loopy BP，经验上常好但无保证（可用于解码、近似边际）。

**方法选择**：

| 场景 | 推荐 |
| --- | --- |
| 网络窄、需精确 | 变量消元 / 联结树 |
| 证据多、网络大 | 似然加权 / Gibbs |
| 需可扩展、可微 | 变分推断 / HMC |
| 实时、精度要求低 | loopy BP / 采样少量样本 |

## 13.6 因果网络

贝叶斯网络描述**观测分布**，不直接回答"如果我做 $X$，$Y$ 会怎样"。这两类问题需要不同的算子。

**干预 vs 观测**：

- 观测：$P(Y \mid X = x)$——看到 $X=x$ 的人中 $Y$ 的分布；
- 干预：$P(Y \mid do(X = x))$——强制设定 $X=x$ 后 $Y$ 的分布。

二者常不等，因为存在**混杂（confounder）**：同时影响 $X$ 与 $Y$ 的变量。经典例子：冰淇淋销量与溺水人数正相关，但干预"多吃冰淇淋"不会增加溺水——混杂是"气温"。

**因果图（causal graph）** 与贝叶斯网络结构相同，但语义不同：边表示**直接因果作用**，且假设**无未观测混杂**（因果充分性）与**无反馈**。

**后门准则（back-door criterion）**：若变量集 $Z$ 阻断了 $X$ 与 $Y$ 之间所有"含指向 $X$ 的边"的路径，且 $Z$ 不含 $X$ 的后代，则

$$P(Y \mid do(X=x)) = \sum_z P(Y \mid X=x, Z=z)\, P(z)$$

即"分层后加权平均"。**前门准则**处理 $X$ 与 $Y$ 之间有未观测混杂、但存在中介 $M$ 的情形（详见附录 D.4）。

**三个必须区分的偏差**：

| 偏差 | 结构 | 错误做法 |
| --- | --- | --- |
| 混杂偏差 | $X \leftarrow Z \to Y$ | 不控制 $Z$，把相关当因果 |
| 对撞偏差 | $X \to Z \leftarrow Y$ | **控制** $Z$，人为制造相关（Berkson 悖论） |
| 中介偏差 | $X \to M \to Y$ | 控制 $M$，把总效应误当直接效应 |

**因果发现**：从数据推断图结构，方法包括约束-based（PC 算法：条件独立检验）、评分-based（BDeu/BIC + 搜索）、函数因果模型（LiNGAM：利用非高斯性定向）。它们都依赖强假设，实际应用需领域知识校验。

**因果与机器学习的关系**：

- 预测模型只需 $P(Y \mid X)$，因果模型需要 $P(Y \mid do(X))$——后者才支持**决策与政策评估**；
- 因果不变性（invariant causal prediction）是**分布外泛化**的一条原则：因果机制跨环境稳定，相关性则不稳定；
- 因果推断是**可解释性**的强形式："因为 $X$ 变了，所以 $Y$ 变了"比"特征重要度"更接近人类解释。

完整的 do-演算、反事实与因果发现算法见**附录 D**；本章只需记住：**贝叶斯网络是"看"，因果网络是"做"**。

## 本章小结

**核心要点**

1. 贝叶斯网络用 $\prod_i P(X_i \mid \text{Pa}(X_i))$ 因子化联合分布，参数从 $O(d^n)$ 降到 $O(n d^{k+1})$。
2. **d-分离**从图结构读出条件独立；对撞节点"被观测后打开路径"是关键反直觉点。
3. CPT 可用确定性节点、**噪声或**、CSI 与线性高斯压缩；线性高斯网络有闭式推断。
4. **变量消元**把求和推入因子内部，复杂度由**诱导宽度**决定；精确推断 NP 难、计数 #P 难。
5. 近似推断四条路线：拒绝采样（正确但低效）、**似然加权**（无偏）、**Gibbs**（局部更新）、**变分**（快但有偏）。
6. **因果网络**回答 $do(\cdot)$ 问题；混杂、对撞、中介三类偏差决定了"该控制什么、不该控制什么"。
