# 第 14 章 随时间变化的概率推理（Probabilistic Reasoning over Time）

**本章导读**：静态贝叶斯网络把世界看作一张快照，但感知流、股价、语音、机器人位姿都是**随时间演化**的。本章引入时间切片与马尔可夫假设，把"信念更新"写成递推：**滤波**（现在）、**预测**（未来）、**平滑**（过去）、**最可能序列**（整条轨迹）。四类模型按状态空间与分布形状区分：HMM（离散）、卡尔曼滤波（线性高斯连续）、粒子滤波（任意连续）、动态贝叶斯网络（结构化多变量）。

**学习目标**：完成本章学习后，你应当能够：

- 写出时序模型的两个假设（马尔可夫、平稳）与转移模型/传感器模型；
- 推导滤波、预测、平滑、Viterbi 的递推公式；
- 在 HMM 上执行前向-后向算法与 Viterbi 解码；
- 写出卡尔曼滤波的预测与更新方程，说明其最优性条件；
- 描述粒子滤波的重要性采样与重采样，诊断样本退化；
- 用动态贝叶斯网络表达多变量时序依赖，说明其推断方法。

**预备知识**：第 12–13 章的概率与贝叶斯网络；矩阵运算与高斯分布；动态规划（Viterbi 的基础）。

---

## 14.1 时间与不确定性

**时序模型的基本设定**：世界由离散时间步 $t = 0,1,2,\dots$ 上的状态序列 $X_t$ 与观测序列 $E_t$ 描述。

**两个关键假设**：

1. **马尔可夫假设（一阶）**：未来只依赖当前状态，
$$P(X_{t+1} \mid X_{0:t}) = P(X_{t+1} \mid X_t)$$
2. **平稳假设（stationary）**：转移与观测机制不随时间变化，
$$P(X_{t+1} \mid X_t) = P(X_1 \mid X_0),\qquad P(E_t \mid X_t) = P(E_1 \mid X_1)$$

由此得到**转移模型** $P(X' \mid X)$ 与**传感器模型** $P(E \mid X)$，它们合起来定义了整个时序过程（一个无限长的贝叶斯网络，形如"拉链"）。

**四个基本推断任务**：

| 任务 | 查询 | 直觉 |
| --- | --- | --- |
| **滤波（filtering）** | $P(X_t \mid e_{1:t})$ | 我现在在哪 |
| **预测（prediction）** | $P(X_{t+k} \mid e_{1:t})$ | 我将来会在哪 |
| **平滑（smoothing）** | $P(X_k \mid e_{1:t})$，$k < t$ | 我当时在哪（事后回看） |
| **最可能解释（MAP）** | $\arg\max_{x_{1:t}} P(x_{1:t} \mid e_{1:t})$ | 我走过的整条轨迹 |

**为什么滤波要递推**：直接对 $t$ 步联合分布求和需要 $O(|X|^t)$；利用马尔可夫性可做到每步 $O(|X|^2)$，与 $t$ 线性。

## 14.2 时序模型中的推断

**滤波递推**（前向）：

$$P(X_{t+1} \mid e_{1:t+1}) = \alpha\, P(e_{t+1} \mid X_{t+1}) \sum_{x_t} P(X_{t+1} \mid x_t)\, P(x_t \mid e_{1:t})$$

两部分：

- **预测步**（时间更新）：$\hat P(X_{t+1}) = \sum_{x_t} P(X_{t+1} \mid x_t) P(x_t \mid e_{1:t})$；
- **更新步**（观测更新）：乘以似然 $P(e_{t+1} \mid X_{t+1})$ 并归一化。

**预测递推**：不断应用转移模型做 $k$ 步展开：

$$P(X_{t+k} \mid e_{1:t}) = \sum_{x_{t+k-1}} P(X_{t+k} \mid x_{t+k-1}) P(x_{t+k-1} \mid e_{1:t})$$

$k$ 越大，分布越平滑（趋于**先验平稳分布**），这是"长期预测必然发散"的数学表现。

**平滑**（前向-后向）：

$$P(X_k \mid e_{1:t}) = \alpha\, \underbrace{P(X_k \mid e_{1:k})}_{\text{前向 } f_{1:k}} \cdot \underbrace{P(e_{k+1:t} \mid X_k)}_{\text{后向 } b_{k+1:t}}$$

后向递推：

$$b_{k+1:t} = P(e_{k+1:t} \mid X_k) = \sum_{x_{k+1}} P(e_{k+1} \mid x_{k+1})\, P(x_{k+1} \mid X_k)\, b_{k+2:t}$$

**直觉**：滤波只看"过去到现在的证据"，平滑同时用"未来的证据"，因此**平滑总是比滤波更准确**。离线的语音识别、地图构建、故障复盘都用平滑。

**Viterbi（最可能序列）**：把"求和"换成"取最大"：

$$\mathbf{m}_{1:t+1} = \max_{x_t} \Big[ P(e_{t+1} \mid X_{t+1}) \cdot P(X_{t+1} \mid x_t) \cdot \mathbf{m}_{1:t} \Big]$$

并保留**回溯指针** $\arg\max$，最后反向恢复路径。复杂度 $O(t \cdot |X|^2)$，与滤波同阶。

**关键区别**：$P(X_t \mid e_{1:t})$ 的逐点最大序列 ≠ Viterbi 路径。前者允许"每步各自最可能"的组合在时间上不连贯，后者是全局最优的连贯轨迹。语音识别必须用 Viterbi。

## 14.3 隐马尔可夫模型

**HMM（hidden Markov model）** 是状态离散、状态数有限的时序模型，由三元组参数化：

$$\pi = P(X_0),\qquad A_{ij} = P(X_t = j \mid X_{t-1} = i),\qquad B_{ik} = P(E_t = k \mid X_t = i)$$

**三个经典问题**：

| 问题 | 算法 | 复杂度 |
| --- | --- | --- |
| 评估 $P(e_{1:t})$ | 前向算法 | $O(t\,\lvert X\rvert^2)$ |
| 解码 $\arg\max x_{1:t}$ | Viterbi | $O(t\,\lvert X\rvert^2)$ |
| 学习参数 | Baum–Welch（EM 的 HMM 版本） | 每轮 $O(t\,\lvert X\rvert^2)$ |

**Baum–Welch** 的 E 步用前向-后向算**期望占用**（$\gamma_t(i)$）与**期望转移**（$\xi_t(i,j)$），M 步按期望计数重估 $\pi, A, B$。这是第 20 章 EM 的特例。

**HMM 的数值稳定**：前向概率随 $t$ 指数衰减，须每步归一化（得到 $\alpha$ 常数）或在对数域计算。

**典型应用与失效**：

| 应用 | 状态 | 观测 |
| --- | --- | --- |
| 语音识别（早期） | 音素 | MFCC 帧 |
| 词性标注 | 词性 | 词 |
| 基因序列 | 外显子/内含子 | 碱基 |
| 手势识别 | 手势阶段 | 传感器读数 |

失效场景：

- **状态数需人工设定**，且真实过程可能有无穷状态；
- **观测独立假设**过强（给定状态时观测之间常相关）；
- **一阶马尔可夫**无法表达长程依赖（如语法结构）；
- 离散观测空间需要量化，损失信息。

这些局限推动了线性高斯模型（14.4）、粒子滤波（14.5）与结构化模型（14.6）的发展。

## 14.4 卡尔曼滤波

**线性高斯模型**：

$$X_{t+1} = F X_t + w_t, \qquad w_t \sim \mathcal{N}(0, Q)$$
$$E_t = H X_t + v_t, \qquad v_t \sim \mathcal{N}(0, R)$$

- $F$：状态转移矩阵；$H$：观测矩阵；
- $Q, R$：过程噪声与观测噪声协方差；
- 初始状态 $X_0 \sim \mathcal{N}(\mu_0, \Sigma_0)$。

**卡尔曼滤波（Kalman filter）** 是这一模型下的**精确**滤波，因为高斯分布在线性变换与条件化下封闭。

**预测步**：

$$\hat\mu_{t+1} = F \mu_t, \qquad \hat\Sigma_{t+1} = F \Sigma_t F^\top + Q$$

**更新步**（观测 $e_{t+1}$）：

$$K_{t+1} = \hat\Sigma_{t+1} H^\top (H \hat\Sigma_{t+1} H^\top + R)^{-1} \quad \text{(卡尔曼增益)}$$
$$\mu_{t+1} = \hat\mu_{t+1} + K_{t+1}(e_{t+1} - H \hat\mu_{t+1})$$
$$\Sigma_{t+1} = (I - K_{t+1} H)\hat\Sigma_{t+1}$$

**卡尔曼增益的直觉**：$K$ 在"信模型"与"信观测"之间加权：

- 观测噪声大（$R$ 大）→ $K$ 小 → 更相信预测；
- 预测不确定大（$\hat\Sigma$ 大）→ $K$ 大 → 更相信观测。

**最优性**：在线性 + 高斯 + 已知参数的假设下，卡尔曼滤波是**最小均方误差**最优估计。放宽线性的标准工具是**扩展卡尔曼滤波（EKF）**（局部线性化）与**无迹卡尔曼滤波（UKF）**（sigma 点采样），二者都是近似。

**应用**：GPS/IMU 融合、目标跟踪、火箭导航、经济状态估计、机器人 SLAM。工程要点：

- 参数 $Q, R$ 的调节决定滤波器"性格"，常用最大似然或交叉验证；
- 模型非线性强时 EKF 会发散，需 UKF 或粒子滤波；
- 数值上要用 Joseph 形式或平方根滤波保证协方差正定。

## 14.5 粒子滤波

当状态空间高维、非线性、非高斯时，用**粒子滤波（particle filter）** 近似后验：用 $N$ 个加权样本 $\{(x_t^{(i)}, w_t^{(i)})\}$ 表示分布。

**SIR（sequential importance resampling）**：

1. **采样**：从转移模型 $x_t^{(i)} \sim P(X_t \mid x_{t-1}^{(i)})$ 生成新粒子；
2. **加权**：$w_t^{(i)} \propto P(e_t \mid x_t^{(i)})$；
3. **重采样**：按权重有放回地抽 $N$ 个粒子，权重重置为 $1/N$；
4. 估计：$\hat P(X_t \mid e_{1:t}) \approx \sum_i w_t^{(i)} \delta(x_t - x_t^{(i)})$。

**为什么必须重采样**：不重采样时，权重方差随 $t$ 指数增长，几乎所有粒子权重趋于零——**权重退化（weight degeneracy）**。

**重采样的问题**：**样本贫化（sample impoverishment）**——少数高权重粒子被反复复制，多样性丧失。缓解方法：

| 方法 | 思路 |
| --- | --- |
| 系统重采样 | 低方差、$O(N)$ |
| 自适应重采样 | 仅在有效样本数 $N_\text{eff} = 1/\sum w_i^2$ 低于阈值时重采样 |
| 正则化粒子滤波 | 重采样后加小扰动，恢复多样性 |
| 辅助粒子滤波（APF） | 采样时考虑观测，提前筛选 |
| MCMC 步 | 重采样后做若干 Gibbs/MH 步 |

**优点**：非参数、可处理任意非线性/多模态、易并行；
**缺点**：高维需指数多粒子（**维度灾难**）、无法很好处理罕见事件、随机性导致结果不稳定。

**应用**：机器人定位（Monte Carlo localization）、视觉跟踪、金融状态空间模型、粒子滤波 SLAM。

## 14.6 动态贝叶斯网络

**动态贝叶斯网络（DBN）** 是时序模型的"结构化"版本：每个时间切片内部是一个贝叶斯网络，相邻切片之间用转移边连接。

**形式**：$(P(X_0), P(X_t \mid X_{t-1}))$，其中 $X_t$ 是若干变量的向量。典型例子：车辆跟踪中的 $(x, y, v_x, v_y)$，或病人监护中的多指标。

**表达能力对比**：

| 模型 | 状态空间 | 分布 | 推断 |
| --- | --- | --- | --- |
| HMM | 离散、单变量 | 任意离散 | 精确（前向-后向） |
| 卡尔曼 | 连续、线性高斯 | 高斯 | 精确（矩阵递推） |
| 粒子滤波 | 连续、任意 | 任意 | 近似（采样） |
| DBN | 多变量、结构化 | 取决于局部模型 | 精确（若树状）或近似 |

**推断方法**：

- **展开（unrolling）**：把 DBN 展开成 $t$ 层静态网络，再用第 13 章的变量消元；
- **前向-后向在团树上**：若每个切片的接口变量少（树宽小），可做精确的接口算法（interface algorithm）；
- **近似**：粒子滤波、loopy BP、变分。

**结构学习与切换模型**：

- **切换线性动态系统（switching LDS）**：用离散模式变量切换不同的线性动态，能表达"运动模式突变"（如行人突然转向）；
- **结构 EM**：同时学转移结构与参数；
- **非参数 DBN**：用狄利克雷过程决定状态数（第 20 章）。

**工程要点**：

1. **接口变量（interface）** 的选择决定推断复杂度——只保留"跨切片有边"的变量；
2. **时间粒度**要与过程的时间常数匹配，过细会引入冗余、过粗会丢失动态；
3. **参数共享**（平稳假设）能大幅减少数据需求，但会牺牲对"机制变化"的适应能力；
4. 长序列推断优先用**平滑**而非滤波，但需离线或固定延迟。

## 本章小结

**核心要点**

1. 时序模型依赖**马尔可夫 + 平稳**假设，由转移模型与传感器模型定义；"拉链"结构使递推可行。
2. 四个推断任务：**滤波**（现在）、**预测**（未来）、**平滑**（过去）、**Viterbi**（整条路径）；平滑比滤波更准。
3. **HMM** 用前向-后向与 Viterbi 解决评估、解码、学习三问题；离散状态与观测独立是其局限。
4. **卡尔曼滤波**在线性高斯下是最优估计，增益权衡"信模型"与"信观测"；非线性时用 EKF/UKF。
5. **粒子滤波**以采样近似任意分布，核心是重要性加权与重采样；权重退化与样本贫化是主要风险。
6. **DBN** 用结构化切片表达多变量动态，接口变量的规模决定推断难度。
