# 第 19 章 从样例中学习（Learning from Examples）

**本章导读**：前 18 章讨论"给定知识如何推理"，本章转向"知识从哪来"——从数据中归纳。这是机器学习的核心，也是现代 AI 的主战场。本章依次处理：学习任务的形式化、监督学习的通用框架、决策树、模型选择与偏差-方差、学习理论、线性模型、非参数方法、支持向量机与集成方法，最后给出"开发一个机器学习系统"的工程流程。

**学习目标**：完成本章学习后，你应当能够：

- 区分监督、无监督、半监督、自监督与强化学习；
- 用 ERM 框架描述学习问题，说明归纳偏置的必要性；
- 构造决策树（ID3/C4.5/CART），解释分裂准则与剪枝；
- 用交叉验证选模型，用偏差-方差分解诊断过拟合与欠拟合；
- 推导线性回归/逻辑回归的损失与梯度，说明正则化的作用；
- 区分参数与非参数方法，说明核技巧为何能避免显式高维映射；
- 解释 Bagging、Boosting、Stacking 的原理与差异；
- 按"数据 → 特征 → 模型 → 评估 → 部署"流程开发系统，并识别数据泄漏等陷阱。

**预备知识**：线性代数（矩阵、特征值）、概率统计（期望、方差、最大似然）、微积分（梯度、凸优化）、第 12 章的贝叶斯法则。

## 19.1 学习的形式

**Mitchell 的定义**：对任务 $T$、性能度量 $P$ 与经验 $E$，若程序在 $T$ 上以 $P$ 衡量的性能随 $E$ 提升，则称其从 $E$ 中**学习**。

**学习范式的划分**：

| 范式 | 数据 | 目标 | 代表 |
| --- | --- | --- | --- |
| 监督学习 | $(x_i, y_i)$ | 学 $f: X \to Y$ | 分类、回归 |
| 无监督学习 | $\{x_i\}$ | 发现结构 | 聚类、降维（附录 G） |
| 半监督学习 | 少量标注 + 大量无标注 | 利用未标注数据 | 自训练、图方法（附录 G.3） |
| 自监督学习 | 自动构造的标签 | 表征学习 | 对比学习、掩码建模（附录 E.3） |
| 强化学习 | 奖励信号 | 序贯决策 | Q-learning（第 22 章） |

**经验风险最小化（ERM）**：真实风险 $R(f) = \mathbb{E}_{(x,y)\sim P}[L(f(x), y)]$ 不可知，用训练集上的**经验风险**替代：

$$\hat R(f) = \frac{1}{N}\sum_{i=1}^{N} L\big(f(x_i), y_i\big)$$

**归纳偏置（inductive bias）**：没有偏置就无法从有限样本泛化（"没有免费的午餐"定理）。偏置的形式包括：

- **假设空间限制**：只考虑线性函数、深度网络、决策树；
- **正则化**：偏好"简单"模型（参数小、树浅、稀疏）；
- **先验**：贝叶斯视角下的 $P(\theta)$。

**学习 = 在"拟合数据"与"保持简单"之间权衡**。这是贯穿全章的主线。

## 19.2 监督学习

**任务类型**：

| 任务 | 输出 | 损失 |
| --- | --- | --- |
| 二分类 | $y \in \{0,1\}$ | 交叉熵、Hinge |
| 多分类 | $y \in \{1,\dots,K\}$ | 交叉熵 |
| 回归 | $y \in \mathbb{R}$ | 均方误差、绝对误差 |
| 排序 | 序列 | pairwise ranking loss |
| 结构化预测 | 序列/图 | 结构化 hinge、CRF 似然 |

**评估指标**（分类，正类为关注类）：

$$\text{Precision} = \frac{TP}{TP+FP},\quad \text{Recall} = \frac{TP}{TP+FN},\quad F_1 = \frac{2PR}{P+R}$$

- **AUC-ROC**：阈值无关的排序质量；
- **PR 曲线**：类别极不平衡时更敏感；
- **校准（calibration）**：预测概率是否与实际频率一致（可靠性图、Brier 分数）。

**回归指标**：MSE、MAE、$R^2$、MAPE（注意 MAPE 对小值敏感）。

**关键概念**：

- **泛化（generalization）**：在未见数据上的表现；
- **过拟合**：训练误差低、泛化误差高；
- **欠拟合**：两者都高；
- **分布偏移**：训练与部署分布不同（协变量偏移、标签偏移、概念漂移）。

## 19.3 决策树学习

**决策树**用一系列"属性测试"把输入空间划分成矩形区域，每个叶节点给出预测。

**构造算法**（递归）：

1. 若所有样本同类 → 叶节点；
2. 若无属性可用 → 叶节点（多数类）；
3. 选**最佳分裂属性**，按取值划分数据，递归。

**分裂准则**：

| 准则 | 公式 | 说明 |
| --- | --- | --- |
| 信息增益（ID3） | $IG = H(Y) - \sum_v \frac{\lvert D_v\rvert}{\lvert D\rvert}H(Y \mid v)$ | 偏好多值属性 |
| 增益率（C4.5） | $IG / \text{SplitInfo}$ | 惩罚多值属性 |
| 基尼不纯度（CART） | $1 - \sum_k p_k^2$ | 计算快，等价于方差不纯度 |

**剪枝**：

- **预剪枝**：限制深度、叶最小样本数、最小增益；
- **后剪枝**：先长满树，再自底向上用验证集判断是否剪枝（**代价复杂度剪枝**，CART 的 `ccp_alpha`）。

**决策树的优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 可解释、可可视化 | 单树方差大、易过拟合 |
| 不需特征缩放 | 对轴对齐分裂敏感（斜边界需很多步） |
| 能处理混合类型与缺失 | 不稳定（数据小扰动改变结构） |

**从树到森林**：单树的高方差正是集成方法（§19.9）的动机。

**回归树**：叶节点取均值，分裂准则用**方差减少**（MSE 减少）。CART 同时支持分类与回归。

## 19.4 模型选择与优化

**偏差-方差分解**（对平方损失）：

$$\mathbb{E}\big[(y - \hat f(x))^2\big] = \underbrace{\text{Bias}^2}_{\text{系统性误差}} + \underbrace{\text{Variance}}_{\text{对数据的敏感}} + \underbrace{\sigma^2}_{\text{不可约噪声}}$$

| 现象 | 偏差 | 方差 | 对策 |
| --- | --- | --- | --- |
| 欠拟合 | 高 | 低 | 更复杂模型、更多特征 |
| 过拟合 | 低 | 高 | 正则化、更多数据、集成、早停 |

**模型选择**：

- **留出法**：训练/验证/测试三分（大数据）；
- **$k$ 折交叉验证**：数据少时的标准做法；时间序列要用**前向滚动**验证，不能随机打乱；
- **嵌套交叉验证**：调参与评估分离，避免乐观偏差；
- **信息准则**：AIC、BIC（偏好拟合好且参数少）。

**超参数优化**：网格、随机搜索、贝叶斯优化（用代理模型 + 采集函数）、Hyperband（bandit 思想，§17.3）。

**正则化**：

| 形式 | 公式 | 效果 |
| --- | --- | --- |
| $L_2$（岭） | $\lambda\|\theta\|_2^2$ | 参数收缩，平滑 |
| $L_1$（Lasso） | $\lambda\|\theta\|_1$ | 稀疏，特征选择 |
| 弹性网 | 两者组合 | 相关特征组选择 |
| 早停 | 验证误差回升即停 | 隐式正则 |
| Dropout | 随机失活 | 集成近似（§21.5） |

**数据泄漏（data leakage）**是模型选择中最常见的错误：在划分前做标准化、用未来数据做特征、用测试集调参。它会让离线指标虚高，上线后暴跌。

## 19.5 学习理论

**PAC 学习（probably approximately correct）**：一个假设类是可 PAC 学习的，若对任意 $\varepsilon, \delta$，用足够多的样本能以概率 $1-\delta$ 学到误差 $\le \varepsilon$ 的假设。

**样本复杂度**（有限假设空间 $|\mathcal{H}|$）：

$$N \ge \frac{1}{2\varepsilon^2}\Big(\ln|\mathcal{H}| + \ln\frac{1}{\delta}\Big)$$

**VC 维（Vapnik–Chervonenkis dimension）**：假设类能"打散（shatter）"的最大点集大小。

- 线性分类器在 $\mathbb{R}^d$ 中的 VC 维是 $d+1$；
- 区间分类器的 VC 维是 2；
- 神经网络的 VC 维与参数量同阶（但实践中泛化常优于理论界）。

**泛化界**（大致形式）：

$$R(f) \le \hat R(f) + O\left(\sqrt{\frac{\mathrm{VC}(\mathcal{H}) + \ln(1/\delta)}{N}}\right)$$

**理论的三条实践启示**：

1. **样本量与容量要匹配**：参数越多，需要越多数据；
2. **界是悲观的**：深度网络的实际泛化远好于 VC 界，说明"容量"不是唯一因素（隐式正则、数据分布、优化动力学都在起作用）；
3. **PAC 不告诉你"哪个模型好"**，只告诉你"需要多少数据才能可靠地比较"。

## 19.6 线性模型与回归

**线性回归**：$y = \theta^\top x + \epsilon$，最小化

$$J(\theta) = \frac{1}{2N}\sum_i (y_i - \theta^\top x_i)^2$$

闭式解（正规方程）：$\hat\theta = (X^\top X)^{-1} X^\top y$，复杂度 $O(d^3)$；$d$ 大时用梯度下降或 SGD。

**岭回归**：加 $L_2$ 正则，解为 $\hat\theta = (X^\top X + \lambda I)^{-1}X^\top y$，同时改善数值稳定性（$X^\top X$ 病态时）。

**逻辑回归**：$P(y=1 \mid x) = \sigma(\theta^\top x)$，$\sigma(z) = 1/(1+e^{-z})$，损失为**交叉熵**：

$$J(\theta) = -\frac{1}{N}\sum_i \big[y_i \log \hat y_i + (1-y_i)\log(1-\hat y_i)\big]$$

梯度形式极简洁：$\nabla J = \frac{1}{N}\sum_i (\hat y_i - y_i)x_i$。**它是凸的**，可用牛顿法/IRLS 或 SGD 求解。

**多分类**：softmax 回归

$$P(y=k \mid x) = \frac{e^{\theta_k^\top x}}{\sum_j e^{\theta_j^\top x}}$$

**广义线性模型（GLM）**：把线性预测子通过链接函数映射到输出分布（泊松回归、Gamma 回归），统一了回归与分类。

**线性模型的边界**：只能表达线性决策边界。解决途径有三：特征工程（多项式、交互项）、核方法（§19.8）、神经网络（第 21 章）。

## 19.7 非参数模型

非参数方法不假设固定的参数形式，模型复杂度随数据增长。

**$k$ 近邻（kNN）**：

$$\hat y(x) = \text{majority}\big(y_{i} : x_i \in \text{kNN}(x)\big)$$

- 无训练阶段（懒惰学习），预测 $O(Nd)$；
- $k$ 小 → 低偏差高方差；$k$ 大 → 平滑但偏差大；
- 需要距离度量与特征缩放；高维下距离失效（**维度灾难**）。

**核回归 / Nadaraya–Watson**：

$$\hat f(x) = \frac{\sum_i K\!\big(\frac{x-x_i}{h}\big) y_i}{\sum_i K\!\big(\frac{x-x_i}{h}\big)}$$

带宽 $h$ 控制平滑度。**局部加权回归（LOESS）** 在每个查询点拟合一个局部线性模型。

**核密度估计（KDE）**：$\hat p(x) = \frac{1}{Nh}\sum_i K\big(\frac{x-x_i}{h}\big)$，用于密度估计与异常检测。

**高斯过程（GP）**：把函数看作无穷维高斯分布，$f \sim \mathcal{GP}(m, k)$，预测给出均值与不确定度：

$$\mu(x_*) = k_*^\top (K + \sigma^2 I)^{-1} y,\qquad \sigma^2(x_*) = k_{**} - k_*^\top (K+\sigma^2I)^{-1}k_*$$

优点是**自带不确定性**（贝叶斯优化、主动学习的核心），缺点是 $O(N^3)$ 复杂度。

**非参数方法的共同特点**：

| 优点 | 缺点 |
| --- | --- |
| 灵活、假设少 | 需要保留训练数据 |
| 天然处理非线性 | 高维与大数据下慢 |
| GP 提供不确定度 | 需选核/带宽 |

## 19.8 支持向量机

**最大间隔思想**：在可分数据中，选择使两类间隔最大的超平面。

$$\min_{w,b}\ \frac{1}{2}\|w\|^2 \quad \text{s.t.}\ y_i(w^\top x_i + b) \ge 1,\ \forall i$$

**对偶形式**（拉格朗日）：

$$\max_{\alpha}\ \sum_i \alpha_i - \frac{1}{2}\sum_{i,j}\alpha_i\alpha_j y_i y_j x_i^\top x_j \quad \text{s.t.}\ \alpha_i \ge 0,\ \sum_i \alpha_i y_i = 0$$

**关键洞察**：对偶只涉及**内积** $x_i^\top x_j$，因此把内积换成核函数 $K(x_i,x_j)$ 就能在隐式高维空间中做线性分类——**核技巧**。

**常用核**：

| 核 | 形式 | 适用 |
| --- | --- | --- |
| 线性 | $x^\top z$ | 高维稀疏（文本） |
| 多项式 | $(x^\top z + c)^d$ | 特征交互 |
| RBF/高斯 | $\exp(-\gamma\|x-z\|^2)$ | 通用，需调 $\gamma$ |
| Sigmoid | $\tanh(\alpha x^\top z + c)$ | 少用（非正定） |

**软间隔（C-SVM）**：允许违反间隔，引入松弛变量 $\xi_i$：

$$\min\ \frac{1}{2}\|w\|^2 + C\sum_i \xi_i \quad \text{s.t.}\ y_i(w^\top x_i+b) \ge 1 - \xi_i,\ \xi_i \ge 0$$

$C$ 控制"间隔最大化"与"训练误差"的权衡。**Hinge 损失**视角：$\max(0, 1 - y f(x))$。

**求解**：SMO（序列最小优化）每次优化两个 $\alpha_i$，解析更新；大规模用线性 SVM（LIBLINEAR）或核近似（Nyström、随机特征）。

**SVM 的地位**：在深度学习的 RBF 核 SVM 曾是通用强基线；如今在**小样本、高维稀疏、需要凸性保证**的场景仍常用。

## 19.9 集成学习

**为什么集成有效**：多个模型的误差若不完全相关，平均后方差下降。

**（1）Bagging（bootstrap aggregating）**：对数据有放回采样训练多个模型，投票/平均。主要降低**方差**。

**随机森林（random forest）**：Bagging + 每次分裂随机选特征子集，进一步**去相关**。OOB（out-of-bag）样本可做无偏误差估计。

**（2）Boosting**：串行训练，每个新模型关注前一个模型的错误。

- **AdaBoost**：提高误分类样本权重，最终加权投票；
- **梯度提升（GBM）**：把新模型拟合到**负梯度**（残差），目标是最小化任意可微损失：

$$F_m(x) = F_{m-1}(x) + \nu\, h_m(x),\qquad h_m \approx -\nabla_F L$$

- **XGBoost / LightGBM / CatBoost**：GBM 的工程优化（二阶泰勒、直方图分裂、leaf-wise 生长、类别特征处理），是表格数据的**默认最强基线**。

Boosting 主要降低**偏差**，但噪声大时容易过拟合，需要学习率 $\nu$、树深、子采样共同调节。

**（3）Stacking**：用元学习器组合多个基模型的输出（用交叉验证生成元特征，避免泄漏）。

**（4）其他**：

| 方法 | 思路 |
| --- | --- |
| 投票/平均 | 简单组合 |
| 快照集成 | 同一次训练的不同检查点 |
| 混合专家（MoE） | 门控网络按输入选择专家 |
| Dropout | 训练时随机失活 ≈ 指数多个子网络的集成 |

**集成方法的取舍**：Bagging/RF 稳、易并行、少调参；Boosting 精度高但需调参、对噪声敏感；Stacking 提升有限但成本高。

## 19.10 开发机器学习系统

**完整流程**：

1. **定义问题与指标**：业务目标 → 可测指标（离线 + 线上）；先问"标签从哪来、延迟多久、错误的代价是否对称"；
2. **数据**：采集、清洗、标注、去重、划分（时间/用户维度防泄漏）；
3. **特征**：领域特征、统计特征、嵌入特征；做**特征版本管理**；
4. **建模**：先跑简单基线（逻辑回归/GBM），再考虑复杂模型；
5. **评估**：交叉验证 + 分层分析（按人群/场景拆开看），检查公平性与鲁棒性；
6. **部署**：离线批、在线服务、边缘；考虑延迟、吞吐、成本；
7. **监控与迭代**：数据漂移、指标下降、反馈闭环、A/B 实验。

**五个高频陷阱**：

| 陷阱 | 表现 | 对策 |
| --- | --- | --- |
| 数据泄漏 | 离线 AUC 0.99，线上 0.6 | 严格按时间/实体划分，特征只用"预测时刻可得"的信息 |
| 指标与业务脱节 | 准确率高但亏钱 | 用成本敏感指标、因果评估（附录 D） |
| 类别不平衡 | 全预测多数类 | 重采样、阈值调整、PR 曲线 |
| 分布漂移 | 上线后逐渐失效 | 监控输入分布，定期重训 |
| 反馈回路 | 模型只看到自己推荐的内容 | 保留探索流量、反事实评估 |

**工程建议**：

- **简单模型 + 好特征** 常胜过复杂模型；
- 先建立**可复现的流水线**（数据版本、实验记录、随机种子）；
- 把**评估**当成一等公民：没有可信评估，就没有迭代方向；
- 表格数据优先 GBM，图像/文本/语音优先预训练模型（第 21、24 章）。

## 本章小结

**核心要点**

1. 学习 = **ERM + 归纳偏置**；没有偏置就没有泛化（没有免费的午餐）。
2. 决策树用信息增益/基尼选分裂，需剪枝控制方差；单树不稳定，是集成的动机。
3. **偏差-方差分解**是诊断过拟合/欠拟合的核心工具；正则化、交叉验证与早停是主要对策。
4. **VC 维与 PAC** 给出样本复杂度的量级；实际泛化常优于理论界，说明容量之外还有隐式正则。
5. 线性模型凸、可解释、梯度简洁；**核技巧**让线性方法获得非线性能力。
6. 非参数方法灵活、GP 提供不确定度；SVM 以最大间隔 + 核函数著称。
7. **Bagging/RF 降方差，Boosting 降偏差**；XGBoost/LightGBM 是表格数据的强基线。
8. 工程上最大的风险是**数据泄漏、指标错位与分布漂移**，而非模型不够复杂。

**关键术语**

| 中文 | 英文 |
| --- | --- |
| 经验风险最小化 | empirical risk minimization |
| 归纳偏置 | inductive bias |
| 过拟合 / 欠拟合 | overfitting / underfitting |
| 偏差-方差分解 | bias-variance decomposition |
| 交叉验证 | cross-validation |
