# 第 18 章 多智能体决策（Multiagent Decision Making）

**本章导读**：当环境里还有其他会"算计"的智能体时，单智能体的 MDP 框架不够用——你的收益取决于别人的选择，而别人也在预测你。本章从多智能体环境的性质出发，讨论非零和博弈中的均衡、联盟形成中的分配问题（Shapley 值、核）、集体决策中的偏好聚合（投票与社会选择），最后落到机制设计与拍卖——这些是从"分析博弈"走向"设计规则"的桥梁。

**学习目标**：完成本章学习后，你应当能够：

- 按可观察性、目标关系、通信与学习方式刻画多智能体环境；
- 区分零和、常和、非零和博弈，求解一般和博弈的纳什均衡；
- 用特征函数描述联盟博弈，计算 Shapley 值并检验核的稳定性；
- 说明投票规则的公理性质，解释 Condorcet 悖论与 Arrow 不可能定理；
- 用机制设计视角设计拍卖，说明 VCG 的激励相容性与预算平衡的冲突；
- 说明多智能体系统中"均衡选择"与"学习收敛"的困难。

**预备知识**：第 5 章的博弈树与均衡概念；第 16 章的效用；第 17 章的 MDP；线性规划基础（求均衡用）。

---

## 18.1 多智能体环境的性质

第 2 章已给出"单/多智能体"的划分，但多智能体系统还需要更细的维度。

| 维度 | 取值 | 影响 |
| --- | --- | --- |
| 目标关系 | 完全一致 / 完全对立 / 混合动机 | 决定用协作、对抗还是博弈论工具 |
| 可观察性 | 完全 / 部分（含私有信息） | 决定是否需要信念与信息集 |
| 通信 | 无 / 可观察动作 / 显式消息 | 决定协调的可能性 |
| 集中 vs 分布 | 统一决策 / 各自决策 | 决定是否需要协调机制 |
| 学习 | 无学习 / 同步学习 / 异步学习 | 决定系统是否收敛 |
| 规模 | 2 人 / 少数 / 大规模 | 决定算法（精确解 vs 近似） |

**四类典型场景**：

1. **协作（cooperative）**：团队共享同一奖励（如多机器人搬运），可建模为**集中式 MDP** 或 **Dec-POMDP**；
2. **对抗（adversarial）**：零和博弈（棋类、竞价对手），用极小极大/CFR；
3. **混合动机（mixed-motive）**：如交通、谈判——合作能创造价值，分配又存在冲突；
4. **大规模自利**：每个个体独立优化，宏观行为由均衡或学习动态决定（如金融市场、路由）。

**协调问题（coordination problem）**：即使目标一致，若没有沟通，智能体可能选到"都次优"的组合。典型例子是"两个人都想见面但忘了约地点"：$(A,A)$ 与 $(B,B)$ 都是均衡，但选了 $(A,B)$ 就都受损。**均衡选择（equilibrium selection）** 是协作系统的核心难题。

## 18.2 非零和博弈

**一般和（general-sum）博弈**用收益矩阵描述。以**囚徒困境**为例：

| | 合作 | 背叛 |
|:---|:---:|:---:|
| **合作** | (−1, −1) | (−10, 0) |
| **背叛** | (0, −10) | (−5, −5) |

- 每个玩家的**占优策略**都是背叛；
- 唯一纳什均衡是（背叛，背叛），但（合作，合作）是**帕累托更优**的；
- 结论：**个体理性 ≠ 集体理性**。

**纳什均衡的求法**：

- **纯策略**：逐一检查每个格子是否为"双方都不愿单方面偏离"（最佳反应）；
- **混合策略**：让对手在各纯策略间无差异，解线性方程组。例如"监听 vs 反监听"的零和博弈，混合均衡使对手的期望收益相等；
- **支撑枚举**：对每个可能的支撑集（support，被赋予正概率的策略集合）解 LP，检查可行性——适合小规模；
- **Lemke–Howson**：互补枢轴算法，可求一个均衡，但不能保证选到"好的"均衡。

**零和博弈是特例**：$u_1 + u_2 = 0$ 时，纳什均衡等价于**鞍点**，可用线性规划求解（von Neumann 极小极大定理）：

$$\max_{\sigma_1} \min_{\sigma_2} \sigma_1^\top M \sigma_2 = \min_{\sigma_2} \max_{\sigma_1} \sigma_1^\top M \sigma_2 = v$$

$v$ 是博弈值。这就是"石头剪刀布"的混合策略解。

**均衡的三个问题**：

| 问题 | 说明 |
| --- | --- |
| **不唯一** | 多个均衡，选哪个需要额外准则（帕累托、风险占优、焦点） |
| **不唯一性导致不可预测** | 对手可能选任意均衡，策略需鲁棒 |
| **计算困难** | 一般和博弈求纳什均衡是 **PPAD 完全**的（非零和比零和难得多） |

**重复博弈与合作**：有限次重复的囚徒困境仍由逆向归纳得到"一直背叛"；无限次（或未知终止概率 $\delta$）时，"以牙还牙"可维持合作，条件是 $\delta$ 足够大（**民间定理**，folk theorem）。这解释了长期关系为何能产生信任。

## 18.3 联盟形成

**联盟博弈（coalitional game）**：玩家集合 $N$，**特征函数** $v: 2^N \to \mathbb{R}$ 给出每个联盟 $S$ 能获得的总价值，$v(\emptyset) = 0$。

**核心问题**：如何把 $v(N)$ 分配给各玩家，使联盟稳定？

**（1）Shapley 值**。衡量每个玩家的"平均边际贡献"：

$$\phi_i(v) = \sum_{S \subseteq N \setminus \{i\}} \frac{|S|!\,(n-|S|-1)!}{n!}\big[v(S \cup \{i\}) - v(S)\big]$$

**四条公理**唯一确定它：

| 公理 | 含义 |
| --- | --- |
| 有效性 | $\sum_i \phi_i = v(N)$（全部分完） |
| 对称性 | 贡献相同者得相同份额 |
| 零玩家 | 无贡献者得 0 |
| 可加性 | 两个博弈之和的分配等于分配之和 |

**计算**：精确计算是指数级，但可用采样近似（**蒙特卡洛 Shapley**）。Shapley 值也是**可解释机器学习**中"特征贡献"的标准度量（SHAP）。

**（2）核（core）**。分配 $x$ 属于核，若没有任何联盟能通过脱离获得更多：

$$\sum_{i \in S} x_i \ge v(S), \quad \forall S \subseteq N$$

核可能为空（不存在稳定分配），此时需要更弱的解概念（**稳定集、核仁 nucleolus、Shapley 值**）。

**（3）联盟形成的动态**。实际问题中，联盟不是给定的，而是由智能体协商形成：

- **分裂-合并（split-merge）**：智能体反复分裂与合并联盟；
- **匹配（matching）**：两人联盟用稳定匹配（Gale–Shapley）；
- **重叠联盟**：一个智能体可同时属于多个联盟（如任务分配）；
- **计算复杂度**：找最优联盟划分通常是 NP 难（集合划分），用启发式或约束优化。

**应用**：电网中的发电商联合报价、货运中的拼单、联邦学习中的参与方激励、多人游戏中的临时同盟。

## 18.4 集体决策

**社会选择（social choice）** 研究"如何把个体偏好聚合为集体决策"。

**投票规则**：

| 规则 | 说明 | 问题 |
| --- | --- | --- |
| 多数决（plurality） | 得票最多者胜 | 忽视偏好强度，易被"搅局者"影响 |
| 排序复选（ranked pairs） | 按两两对决排序 | 计算复杂，仍有策略性 |
| Borda 计数 | 按排名赋分 | 易受" burying"策略影响 |
| 认可投票（approval） | 只标记可接受者 | 简化但信息损失 |
| 比例代表 | 按得票比例分配席位 | 需要阈值与舍入规则 |

**Condorcet 悖论**：多数偏好可以**非传递**：

- 1/3 选民：$A \succ B \succ C$；
- 1/3 选民：$B \succ C \succ A$；
- 1/3 选民：$C \succ A \succ B$。

两两对决：$A$ 胜 $B$，$B$ 胜 $C$，$C$ 胜 $A$——没有 Condorcet 赢家。这说明"多数规则"无法保证一致的集体偏好。

**Arrow 不可能定理**：不存在同时满足以下公理的社会福利函数（对三个以上备选）：

1. **无限制域**：任何偏好组合都允许；
2. **帕累托原则**：全体一致偏好必须被尊重；
3. **无关备选独立性（IIA）**：两备选的相对排序只依赖个体对二者的排序；
4. **非独裁**：不存在一个人决定所有结果。

结论：**任何满足 1–3 的规则必然是独裁的**。这不是"设计得不好"，而是逻辑上的不可能。

**Gibbard–Satterthwaite 定理**：任何非独裁、对三个以上备选有效的投票规则都**可被策略性操纵**。因此"诚实投票"无法由规则保证，只能靠机制设计（§18.5）或激励相容的支付。

**实践中的应对**：

- 接受"没有完美规则"，按场景选规则（如选举要防策略、评审要表达能力）；
- 用**参与式预算**、**审议民主**等流程补充投票；
- 在多智能体系统中，用**拍卖**替代投票（能表达强度且有激励保证）。

## 18.5 机制设计与拍卖

**机制设计（mechanism design）** 是"逆向博弈论"：给定想要的结果，设计规则使自利参与者的均衡行为导致该结果。

**三个核心性质**：

| 性质 | 含义 |
| --- | --- |
| **激励相容（IC）** | 诚实报告是占优策略 |
| **个体理性（IR）** | 参与不会比不参与更差 |
| **社会福利最大** | 分配使总效用最大 |

**显示原理（revelation principle）**：任何机制能达到的均衡结果，都可以由一个**直接显示机制**（参与者直接报告类型）达到。因此设计时可只在"直接机制"中搜索。

**VCG 机制（Vickrey–Clarke–Groves）**：

- 每个参与者报告对物品的估值 $v_i$；
- 分配使 $\sum_i v_i$ 最大的组合；
- 支付 = 由于你的参与而给他人造成的损失（**外部性**）：
$$p_i = \sum_{j \ne i} v_j(\text{不含 } i \text{ 的最优}) - \sum_{j \ne i} v_j(\text{含 } i \text{ 的最优})$$

**性质**：VCG 是激励相容的（说真话最优），且社会福利最大；但**不一定预算平衡**（可能需要外部补贴），且对合谋与虚假身份（Sybil）脆弱。

**四类拍卖**：

| 类型 | 规则 | 等价性 |
| --- | --- | --- |
| 英式（升价） | 公开加价 | 与二价拍卖策略等价 |
| 荷式（降价） | 价格下降直到有人接受 | 与一价拍卖策略等价 |
| 一价密封 | 最高价者付自己的报价 | 需"报价折扣"（均衡中报价低于估值） |
| 二价密封（Vickrey） | 最高价者付第二高价 | 诚实报价是占优策略 |

**收益等价定理**：在风险中性、独立私有估值、对称的设定下，四类标准拍卖的**期望收益相同**。这解释了为什么拍卖形式的选择更多取决于**参与成本、合谋风险、多物品组合**等现实因素。

**组合拍卖（combinatorial auction）**：同时拍卖多个物品，允许对组合出价（如频谱拍卖）。VCG 适用但计算是 NP 难的（winner determination），实践中用整数规划 + 近似机制。

**应用**：广告竞价（GSP、VCG 变体）、频谱分配、云资源调度、供应链采购、碳排放交易。

**多智能体系统设计的建议**：

1. 先判断是**协作、对抗还是混合动机**，再选工具；
2. 协作系统优先解决**协调与均衡选择**，而非只优化单体策略；
3. 自利系统要设计**激励相容**的规则，并防范合谋与身份攻击；
4. 学习型多智能体（MARL）要警惕**非平稳性**（对手在学）与**均衡不收敛**（如石头剪刀布的循环）。

## 本章小结

**核心要点**

1. 多智能体环境按**目标关系、可观察性、通信、集中度、学习方式**刻画；协调问题即使在完全合作下也存在。
2. 一般和博弈的核心是**纳什均衡**；囚徒困境说明个体理性可能背离集体最优，重复博弈可用触发策略维持合作。
3. 联盟博弈用**特征函数**描述价值，**Shapley 值**满足四条公理、**核**刻画稳定性；两者都可能计算困难或为空。
4. **Condorcet 悖论**与 **Arrow 不可能定理**说明完美投票规则不存在；Gibbard–Satterthwaite 进一步说明策略操纵不可避免。
5. **机制设计**用"逆向博弈论"设计规则；**VCG** 激励相容且社会福利最大，但不保证预算平衡。
6. 多智能体学习面临非平稳性与均衡收敛问题，需要"规则设计 + 学习算法"协同。
