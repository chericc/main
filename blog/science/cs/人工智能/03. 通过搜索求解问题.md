# 第 3 章 通过搜索求解问题（Solving Problems by Searching）

**本章导读**：搜索是 AI 最基础的求解范式：把问题抽象成状态空间，在图上寻找从初始状态到目标的路径。本章先给出问题与解的形式化定义，再系统比较无信息搜索（BFS、UCS、DFS、IDS）与有信息搜索（贪心、A*、IDA*），最后讨论启发式函数的设计与评估。读完后你应能针对具体问题选出策略，并说清其完备性、最优性与复杂度边界。

**学习目标**：完成本章学习后，你应当能够：

- 用五要素形式化一个问题，区分状态空间图与搜索树；
- 写出 BFS、UCS、DFS、DLS、IDS、双向搜索的复杂度并判断其适用场景；
- 证明 A* 在可纳（admissible）启发式下的最优性，说明一致性（consistent）的作用；
- 区分树搜索与图搜索，解释重复状态检测为何必要；
- 设计可纳且一致的启发式，用"松弛问题"与模式数据库系统化地构造；
- 用有效分支因子与支配关系比较启发式质量。

**预备知识**：图论基础（节点、边、路径、树）、大 $O$ 记号、优先队列（堆）的操作与复杂度。第 2 章关于"基于目标的智能体"与"原子状态表示"的讨论是本章的直接背景。

---

## 3.1 问题求解智能体

**问题求解智能体**是第 2 章"基于目标的智能体"的具体形态：它把环境抽象为**状态**，以**搜索**代替逐步反射，找到动作序列后依次执行。

**良定义问题（well-defined problem）** 由五要素确定：

| 要素 | 含义 | 记号 |
| --- | --- | --- |
| 初始状态 | 智能体出发的状态 | $s_0$ |
| 动作 | 每个状态下可执行的动作集 | $\text{ACTIONS}(s)$ |
| 转移模型 | 执行动作后的结果（后继函数） | $\text{RESULT}(s,a) = s'$ |
| 目标测试 | 判断是否达成目标 | $\text{GOAL-TEST}(s)$ |
| 路径代价 | 路径的数值代价，通常逐步累加 | $g(\text{path}) = \sum_i \text{COST}(s_i,a_i,s_{i+1})$ |

问题的**解**是从 $s_0$ 到目标状态的动作序列；**最优解**是路径代价最小的解。

**抽象（abstraction）** 是形式化的核心：删去与求解无关的细节，只保留影响决策的要素。好的抽象满足两条：被删的细节不影响解的合法性；抽象后的动作易于"细化"回真实动作。八数码把"棋盘摆法"抽象为状态，把"移动空格"抽象为动作，就是把连续的物理现实压成离散搜索问题。

**状态空间图 vs 搜索树**：

- **状态空间图**是问题固有的结构：节点是状态，有向边是动作，搜索前就已（隐式）存在。
- **搜索树**是算法运行时动态展开的树：根是 $s_0$，边是扩展，形态取决于策略与重复状态处理。

二者的关键差别是：同一个状态可能在搜索树中**多次出现**（经不同路径）。因此树搜索可能陷入循环，图搜索必须维护**已扩展集合（explored / closed set）**。

**性能度量**四个指标：

- **完备性（completeness）**：有解时是否保证找到；
- **最优性（optimality）**：找到的解是否代价最小；
- **时间复杂度**：通常以生成的节点数计；
- **空间复杂度**：运行所需的最大内存。

记 $b$ 为分支因子、$d$ 为最浅目标深度、$m$ 为状态空间最大深度、$\ell$ 为深度限制、$C^*$ 为最优解代价、$\varepsilon$ 为最小步代价。

## 3.2 示例问题

**（1）Romania 路线规划**。状态是城市，动作是沿道路移动，代价是里程，目标是到达 Bucharest。它的价值在于**可视化搜索过程**：不同策略展开的节点顺序差异一目了然。

**（2）八数码（8-puzzle）**。3×3 棋盘上 8 个数字块与 1 个空格，动作是空格上下左右移动。

- 状态数：$9!/2 = 181\,440$（可达状态）；
- 平均分支因子约 3，平均解长 22；
- 结论：无信息搜索勉强可解，**15 数码（16!/2 ≈ 1.05×10¹³）必须用启发式或更强方法**。

**（3）八皇后**。8×8 棋盘放 8 个互不攻击的皇后。

- 完整状态形式化：状态含 $k$ 个皇后，动作是放置下一个，共 $8!$ 种排列，搜索树 $2057$ 个节点；
- 增量形式化：每步任选一列放置，搜索树约 $8^8 = 1.7\times10^7$；
- 局部搜索形式化：状态是完整布局，动作是移动一个皇后（见 §4.1）——**形式化的选择直接决定算法类别**。

**（4）真空吸尘器世界**。两个格子 A、B，每格可能脏，动作是 `Left`、`Right`、`Suck`。它可以做得很小（完全可观察、确定性），也可以逐步加难度（部分可观察、随机污渍、动态环境），是检验算法假设的"实验台"。

**（5）真实世界问题**。路径规划（地图导航）、旅行商（TSP）、超大规模集成电路布线、蛋白质折叠、自动定理证明，都能映射到搜索框架，区别在于状态空间的大小与代价结构。

## 3.3 搜索算法

**搜索算法的骨架**（图搜索版本）：

```
frontier ← {初始状态}
explored ← {}
loop:
    if frontier 为空: return failure
    node ← frontier 中按策略选出的节点
    if GOAL-TEST(node.state): return 解
    explored ← explored ∪ {node.state}
    for each action in ACTIONS(node.state):
        child ← 生成子节点（含路径代价 g、深度 d）
        if child.state ∉ explored ∪ frontier:
            frontier ← frontier ∪ {child}
```

两个关键设计点：

1. **边界（frontier）的数据结构**决定策略：队列 → BFS，栈 → DFS，优先队列 → UCS/A*。
2. **重复状态检测**用哈希集合实现，代价是内存；不做检测的树搜索在某些问题上会无限循环。

**节点与状态的区别**：节点是搜索树中的记账对象，含状态、父节点、动作、代价 $g$、深度 $d$；状态是世界的一种配置。忘记这一点是复杂度分析出错的常见原因。

## 3.4 无信息搜索策略

无信息（盲）搜索只用问题定义本身的信息。

**广度优先搜索（BFS）**。总是扩展最浅的未扩展节点，边界用 FIFO 队列。

- 完备性：是（分支因子有限时）；
- 最优性：**仅当**所有步代价相等时为是；
- 复杂度：时间与空间均为 $O(b^d)$——**空间是 BFS 的致命弱点**。

**一致代价搜索（UCS）**。按路径代价 $g(n)$ 出队，等价于"以代价为深度"的 BFS；当步代价全为 1 时退化为 BFS。

- 完备性：是（步代价 $\ge \varepsilon > 0$）；
- 最优性：是，第一个出队的目标节点即为最优；
- 复杂度：$O(b^{1+\lfloor C^*/\varepsilon \rfloor})$；
- 关键细节：**目标测试必须在出队时做**，而非生成时做，否则可能返回次优解。

**深度优先搜索（DFS）**。总是扩展最深的节点，边界用 LIFO 栈。

- 完备性：否（无限深度或存在环时）；
- 最优性：否；
- 复杂度：空间仅 $O(bm)$（这是 DFS 唯一的优势），时间 $O(b^m)$。

**深度受限搜索（DLS）**。给 DFS 加深度上限 $\ell$，把无限深度问题变成有限问题；完备性依赖 $\ell \ge d$。

**迭代加深搜索（IDS）**。依次令 $\ell = 0,1,2,\dots$ 做 DLS，重复展开浅层节点。

- 完备性：是；最优性：步代价相等时是；
- 时间：$O(b^d)$（重复代价被几何级数吸收，仅常数因子约 $\frac{b}{b-1}$）；
- 空间：$O(bd)$——**兼具 BFS 的最优性与 DFS 的空间优势**，是未知深度时的默认选择。

**双向搜索（bidirectional search）**。从起点与目标同时搜索，两棵搜索树相遇即得解。

- 时间与空间均为 $O(b^{d/2})$（若每次扩展一层）；
- 前提：目标可反向展开、有唯一明确目标、边可逆（或需反向代价）；
- 工程要点：用哈希表检查相遇，或用"前沿相遇"条件保证最优性。

**复杂度汇总**（$b$ 分支因子，$d$ 最浅解深度，$m$ 最大深度）：

| 算法 | 完备 | 最优 | 时间 | 空间 |
| --- |:---:|:---:| --- | --- |
| BFS | 是 | 仅等代价 | $O(b^d)$ | $O(b^d)$ |
| UCS | 是 | 是 | $O(b^{1+\lfloor C^*/\varepsilon\rfloor})$ | 同时间 |
| DFS | 否 | 否 | $O(b^m)$ | $O(bm)$ |
| DLS | 是（$\ell\ge d$） | 否 | $O(b^\ell)$ | $O(b\ell)$ |
| IDS | 是 | 仅等代价 | $O(b^d)$ | $O(bd)$ |
| 双向 | 是 | 是 | $O(b^{d/2})$ | $O(b^{d/2})$ |

一句话选型：**内存够、要最优 → UCS；内存紧、深度未知 → IDS；有明确目标且可反向 → 双向。**

## 3.5 有信息（启发式）搜索策略

有信息搜索用**启发式函数** $h(n)$ 估计"从节点 $n$ 到目标的代价"，从而优先扩展更有希望的节点。

**贪心最优搜索（greedy best-first）**。按 $h(n)$ 出队，只看向目标"有多近"。

- 优点：通常极快，常能直达目标；
- 缺点：不完备、不最优，$h$ 有误导时会走进死胡同（如"从 Arad 到 Bucharest 的直线距离"在山区会严重低估）。

**A\* 搜索**。按 $f(n) = g(n) + h(n)$ 出队：$g$ 是已付代价，$h$ 是估计的剩余代价，$f$ 是**经过 $n$ 的整条路径的代价估计**。

- **可纳性（admissibility）**：$h(n) \le h^*(n)$（真实剩余代价），即从不高估。可纳 + 图搜索（或树搜索）⇒ **A\* 最优**。
- **一致性（consistency / monotonicity）**：$h(n) \le c(n,a,n') + h(n')$，即三角不等式。一致性 ⇒ 可纳，且保证**节点第一次被扩展时已是最优**，无需重新打开。
- 复杂度：指数级最坏情形，但好的 $h$ 可把有效分支因子压到接近 1。

A\* 最优性的证明骨架：设最优解代价 $C^*$，若 A\* 返回次优解 $G_2$（$g(G_2) > C^*$），则存在最优路径上的节点 $n$ 仍在边界中，且 $f(n) = g(n) + h(n) \le C^*$（可纳性），故 $f(n) < g(G_2) = f(G_2)$，$n$ 应先于 $G_2$ 被扩展，矛盾。

**迭代加深 A\*（IDA\*）**。把 IDS 的深度限制换成 $f$ 值阈值：每次只搜 $f \le$ 阈值 的节点，超限就裁剪并记录最小超限值作为下一轮阈值。

- 空间：$O(bd)$（DFS 式）；
- 适合**状态空间大、内存受限、解代价为整数**的场景；
- 缺点：可能重复扩展大量节点，尤其在 $f$ 值密集时。

**递归最佳优先搜索（RBFS）**。用递归 + 局部 $f$ 上界模拟 A\*，空间线性，允许回溯时"记住"次优分支。

**SMA\***（简化内存受限 A\*）。边界只保留 $k$ 个节点，淘汰 $f$ 最差的节点但记住其最优被遗忘后代的值，可在有限内存下逼近 A\* 的最优性。

**加权 A\*（$f = g + w h$，$w > 1$）**。牺牲最优性换速度，$w$ 越大越接近贪心；这是实际系统（如游戏寻路）最常用的折中。

## 3.6 启发式函数

启发式的质量决定 A\* 的实用价值。评价与构造有两套工具。

**有效分支因子（effective branching factor, $b^*$）**。若一次搜索生成 $N$ 个节点、解深 $d$，解方程

$$N + 1 = 1 + b^* + (b^*)^2 + \cdots + (b^*)^d$$

得到的 $b^*$ 就是"等效分支因子"。$b^*$ 越接近 1，启发式越好。它比原始 $h$ 值更能跨问题比较。

**支配（dominance）**。若对任意 $n$ 有 $h_2(n) \ge h_1(n)$，且二者均可纳，则 $h_2$ **支配** $h_1$：用 $h_2$ 扩展的节点集是 $h_1$ 的子集。因此在**可纳前提下，$h$ 越大越好**。

**松弛问题法（relaxed problem）**。把原问题的约束去掉一部分，松弛问题的最优代价就是原问题的一个可纳启发式：

| 原问题 | 松弛 | 启发式 |
| --- | --- | --- |
| 八数码（块只能移到相邻空格） | 块可移到任意位置 | 错位块数（misplaced tiles） |
| 八数码 | 块可自由移动，不考虑阻挡 | 曼哈顿距离 |
| 八数码 | 块可重叠 | 线性冲突（linear conflict）修正的曼哈顿距离 |
| Romania（受道路限制） | 任意直线可达 | 直线距离 |

曼哈顿距离支配错位块数——后者是前者的弱化版本。

**模式数据库（pattern database）**。把状态投影到少数几个对象上（如"1,2,3,4 的位置"），预计算该投影从每个配置到目标的精确代价并存表。多个模式数据库取最大值即为可纳启发式，是 15 数码与 Rubik's Cube 的经典加速手段。

**从经验中学习启发式**。用特征线性组合 $h(n) = \sum_i w_i f_i(n)$，以实际解代价为标签做回归（第 19 章），或用神经网络直接拟合 $h$（第 21 章）。注意：学到的 $h$ 不保证可纳，需要时可用 $h'(n) = \min(h(n), h^*(n))$ 或加权校正。

## 本章小结

**核心要点**

1. 问题由 $s_0$、动作、转移模型、目标测试、路径代价五要素定义；**抽象质量决定搜索难度**。
2. 状态空间图是问题固有结构，搜索树是运行时结构；重复状态检测是图搜索与树搜索的分界。
3. BFS 空间爆炸、DFS 不完备、**IDS 兼顾最优与线性空间**、UCS 在一般代价下最优。
4. A\* 以 $f=g+h$ 排序；**可纳性保证最优，一致性免去重新打开节点**。
5. 内存受限时用 IDA\*、RBFS、SMA\*；实际系统常用加权 A\* 换速度。
6. 启发式可用**松弛问题**系统构造，用**有效分支因子**评估，用**支配关系**比较；模式数据库是强启发式的工程范式。
