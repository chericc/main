# 第 17 章 复杂决策（Making Complex Decisions）

**本章导读**：第 16 章只做一次决策，但真实智能体的每个动作都影响未来。序贯决策把"现在"与"未来"用一个递推式（Bellman 方程）连起来。本章依次讨论：MDP 的定义与最优性方程（17.1）、值迭代与策略迭代（17.2）、探索-利用权衡与多臂老虎机（17.3）、部分可观测下的 POMDP（17.4）及其求解（17.5）。这套框架是强化学习（第 22 章）的"已知模型"版本。

**学习目标**：完成本章学习后，你应当能够：

- 写出 MDP 五元组、折扣回报、策略与 Bellman 最优方程；
- 手算值迭代与策略迭代，说明二者的收敛条件与复杂度差异；
- 解释折扣因子的作用，以及为什么无限折扣总和不发散；
- 区分 bandit 的 regret、UCB 与 Thompson 采样，说明探索-利用的取舍；
- 把 POMDP 化为信念 MDP，说明其复杂度来源；
- 描述 POMDP 的精确与近似求解（point-based、QMDP、POMCP）。

**预备知识**：第 12–13 章的概率与马尔可夫性；第 16 章的 MEU；动态规划基础。

## 17.1 序贯决策问题

**MDP（马尔可夫决策过程）** 由五元组定义：

$$\mathcal{M} = (S, A, T, R, \gamma)$$

| 要素 | 含义 |
| --- | --- |
| $S$ | 状态集合 |
| $A$ | 动作集合 |
| $T(s' \mid s, a)$ | 转移概率 |
| $R(s, a, s')$ | 奖励函数 |
| $\gamma \in [0,1)$ | 折扣因子 |

**马尔可夫性质**：$P(s_{t+1} \mid s_t, a_t, \text{历史}) = T(s_{t+1} \mid s_t, a_t)$——未来只依赖当前状态。

**回报（return）**：

$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}$$

**为什么折扣**：$\gamma < 1$ 保证无限和收敛（$|G_t| \le R_\text{max}/(1-\gamma)$），同时编码"越远越不确定/越不重要"。$\gamma = 0$ 是短视，$\gamma \to 1$ 是长期规划。工程上 $\gamma$ 也是**有效视野** $1/(1-\gamma)$ 的度量：$\gamma=0.99$ 约看 100 步。

**策略** $\pi: S \to A$（确定性）或 $\pi(a \mid s)$（随机）。**状态价值**与**动作价值**：

$$V^\pi(s) = \mathbb{E}_\pi\Big[\sum_{k\ge0}\gamma^k R_{t+k+1} \,\Big|\, s_t = s\Big]$$
$$Q^\pi(s,a) = \mathbb{E}\big[R_{t+1} + \gamma V^\pi(s_{t+1}) \mid s_t = s, a_t = a\big]$$

**Bellman 期望方程**（给定策略）：

$$V^\pi(s) = \sum_a \pi(a \mid s) \sum_{s'} T(s' \mid s,a)\big[R(s,a,s') + \gamma V^\pi(s')\big]$$

**Bellman 最优方程**：

$$V^*(s) = \max_a \sum_{s'} T(s' \mid s,a)\big[R(s,a,s') + \gamma V^*(s')\big]$$
$$Q^*(s,a) = \sum_{s'} T(s' \mid s,a)\big[R(s,a,s') + \gamma \max_{a'} Q^*(s',a')\big]$$

**关键性质**：

- Bellman 算子是**压缩映射**（$\gamma$-contraction，在 sup 范数下），因此不动点存在且唯一，值迭代必然收敛；
- 最优策略是**确定性**的（存在至少一个最优确定性策略）；
- 给定 $Q^*$，$\pi^*(s) = \arg\max_a Q^*(s,a)$，无需模型——这是 Q-learning 的理论基础（§22.3）。

## 17.2 MDP 算法

**（1）值迭代（value iteration）**。直接迭代 Bellman 最优算子：

$$V_{k+1}(s) \leftarrow \max_a \sum_{s'} T(s' \mid s,a)\big[R(s,a,s') + \gamma V_k(s')\big]$$

- 每轮 $O(|S|^2 |A|)$（稠密转移）；
- 保证收敛，收敛速度由 $\gamma$ 决定（$\gamma$ 接近 1 时慢）；
- 终止条件：$\|V_{k+1} - V_k\|_\infty < \varepsilon(1-\gamma)/(2\gamma)$ 可保证策略 $\varepsilon$-最优。

**（2）策略迭代（policy iteration）**。交替两步：

- **策略评估**：解线性方程组 $V^\pi = R^\pi + \gamma T^\pi V^\pi$，或迭代到收敛；
- **策略改进**：$\pi'(s) = \arg\max_a \sum_{s'} T(s'|s,a)[R + \gamma V^\pi(s')]$。

若策略不再变化则最优。**通常比值迭代更快**（迭代次数少），但每次迭代代价高。**修正策略迭代（modified PI）** 只做少量评估步，是二者的折中。

**（3）线性规划**。$V^*$ 是如下 LP 的唯一最优解：

$$\min \sum_s V(s) \quad \text{s.t.}\ V(s) \ge \sum_{s'} T(s'|s,a)\big[R + \gamma V(s')\big],\ \forall s,a$$

理论上优雅（多项式时间），实际规模上不如迭代法。

**（4）部分可观察之外的其他变体**：

| 变体 | 差异 |
| --- | --- |
| 平均奖励 MDP | 优化长期平均而非折扣和 |
| 带约束 MDP（CMDP） | 增加"安全约束"（如 $E[\text{cost}] \le c$） |
| 连续状态/动作 | 用函数近似、离散化或策略梯度（§22.5） |
| 多目标 MDP | 返回 Pareto 前沿 |

**复杂度**：MDP 的精确求解是 **P 完全**（多项式时间可解，但难以并行化）；POMDP 则是 **PSPACE 完全**。

## 17.3 多臂老虎机问题

**bandit 设定**：有 $K$ 台老虎机，每台的平均奖励未知，每次只能拉一台，目标是在 $T$ 次拉动中最大化总收益。它是"无状态 MDP"（或单状态 MDP），也是探索-利用问题的最纯粹形式。

**Regret（后悔）**：

$$\text{Regret}(T) = T \mu^* - \sum_{t=1}^{T} \mathbb{E}[\mu_{a_t}]$$

其中 $\mu^*$ 是最优臂的均值。目标是最小化 regret 的增长阶。

**下界**：Lai–Robbins 定理给出 $\Omega(\log T)$ 的下界（对非退化分布）。因此最优算法的 regret 是 $O(\log T)$。

**UCB1（上置信界）**：

$$a_t = \arg\max_i \Big[ \hat\mu_i + \sqrt{\frac{2\ln t}{n_i}} \Big]$$

- 第一项是利用（当前估计），第二项是探索（不确定性）；
- 每个臂被拉次数 $n_i$ 越少，置信宽度越大；
- UCB 的 regret 为 $O(\log T)$，且不需知道分布。

**Thompson 采样（后验采样）**：为每个臂维护奖励分布的**后验**，每步从后验采样一个均值，选最大的臂。它天然平衡探索与利用（不确定性大的臂采样值波动大，容易被选中），实践中常优于 UCB。

$$
\tilde\mu_i \sim P(\mu_i \mid \text{历史}),\qquad a_t = \arg\max_i \tilde\mu_i
$$

**其他策略**：

| 策略 | 思路 | 特点 |
| --- | --- | --- |
| $\varepsilon$-贪心 | 以 $\varepsilon$ 概率随机 | 简单但 regret 线性（固定 $\varepsilon$） |
| 衰减 $\varepsilon$ | $\varepsilon_t \propto 1/t$ | 可接近对数 regret |
| 乐观初始化 | 初始值设高 | 迫使每个臂被试一次 |
| 梯度 bandit | 用 softmax 参数做梯度上升 | 适合非平稳 |
| 上下文 bandit | 奖励依赖上下文特征 | 推荐系统的标准模型（附录 C） |

**非平稳 bandit**：用滑动窗口或指数加权估计，把"旧数据的权重"衰减，UCB 的窗口版本可跟踪变化的最优臂。

**应用**：临床试验（多治疗方案分配）、A/B 测试（减少损失）、推荐系统冷启动、广告竞价、超参数搜索（Hyperband 的成功源于 bandit 思想）。

## 17.4 部分可观测马尔可夫决策过程

**POMDP** 在 MDP 上增加观测：

$$\mathcal{P} = (S, A, T, R, \Omega, O, \gamma)$$

- $\Omega$：观测集合；
- $O(o \mid s', a)$：在状态 $s'$ 执行 $a$ 后得到观测 $o$ 的概率。

**信念状态**：

$$b'(s') = \alpha\, O(o \mid s', a) \sum_s T(s' \mid s,a)\, b(s)$$

**信念 MDP**：以**信念**为状态的 MDP，其转移由 $T$、$O$ 与贝叶斯更新导出，奖励为 $\rho(b,a) = \sum_s b(s) R(s,a)$。

$$V^*(b) = \max_a \Big[\rho(b,a) + \gamma \sum_o P(o \mid b,a) V^*(b')\Big]$$

**关键结论**：

- 信念空间是**单纯形**（连续、无穷维），因此 POMDP 的精确求解极其困难；
- $V^*$ 是信念空间上的**分段线性凸函数**（PWLC）；
- POMDP 是 **PSPACE 完全**的；
- 有限视野 POMDP 的 $V^*$ 由有限个 $\alpha$-向量组成，可用**枚举 + 剪枝**求解。

**为什么必须用信念**：动作会影响**未来的信息**（主动感知）。只看当前最可能状态（MLS）会忽略"为了确认而采取的行动"，导致次优。

## 17.5 POMDP 求解算法

**（1）精确值迭代（alpha-vector）**。有限视野下，$t$ 步的价值函数是 $\alpha$-向量的上包络：

$$V_t(b) = \max_{\alpha \in \Gamma_t} \alpha^\top b$$

每步通过"条件计划树"生成新向量集合并做**剪枝**（去掉被支配的向量）。视野加深时向量数指数增长（可达 $|A|^{t}|O|^t$），仅适合玩具问题。

**（2）QMDP**。假设"执行一步后状态完全可观察"，用 $V_\text{MDP}(s)$ 近似：

$$Q_\text{QMDP}(b,a) = \sum_s b(s) \Big[R(s,a) + \gamma \sum_{s'} T(s'|s,a) V^*_\text{MDP}(s')\Big]$$

- 优点：只需解一次 MDP，极快；
- 缺点：忽略信息价值，在"需要主动感知"的问题上严重次优。

**（3）point-based 方法（PBVI、POMCP、SARSOP）**。只在**可达的信念点集合**上算值，而非整个单纯形：

- **PBVI**：维护一组代表性信念点，做 Bellman 备份；
- **SARSOP**：用"成功概率"引导采样，聚焦高价值区域；
- **POMCP**：MCTS 在信念空间上的扩展，用粒子表示信念，rollout 采样观测，适用于大规模问题（如机器人导航、对话）。

**（4）近似与其他**：

| 方法 | 思路 |
| --- | --- |
| 有限状态控制器 | 把策略限制为若干个内部记忆状态 |
| 基于 RNN 的策略 | 用循环网络隐含地表示信念（§22.5） |
| 信念抽象 | 把相似信念聚类后求解 |
| 分层 POMDP | 宏动作 + 子策略 |

**工程选型**：

1. 状态数小、需要精确 → alpha-vector；
2. 只需粗略策略、信息价值低 → QMDP；
3. 大规模、需在线决策 → POMCP；
4. 有仿真器、可用深度学习 → RNN 策略 + 策略梯度（End-to-End）。

## 本章小结

**核心要点**

1. MDP = 状态 + 动作 + 转移 + 奖励 + 折扣；**Bellman 最优方程**是不动点方程，其算子 $\gamma$-压缩。
2. **值迭代**每轮一个 Bellman 备份，**策略迭代**交替评估与改进；二者都收敛到 $V^*$，实践中常组合使用。
3. 折扣因子 $\gamma$ 决定有效视野 $1/(1-\gamma)$，也决定收敛速度。
4. **bandit** 是探索-利用的最简形式；regret 下界 $\Omega(\log T)$，**UCB** 与 **Thompson 采样**可达 $O(\log T)$。
5. POMDP 用**信念状态**把部分可观测转为连续状态 MDP，复杂度为 PSPACE 完全。
6. POMDP 求解从精确 $\alpha$-向量到 **QMDP**（快但忽略信息价值）与 **point-based/POMCP**（可扩展）。
