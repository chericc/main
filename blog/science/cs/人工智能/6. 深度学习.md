## 6.1 神经网络基础

**从生物神经元到人工神经元。** 生物神经元通过树突 (Dendrites) 接收电化学信号，在胞体 (Soma) 中整合，当膜电位超过阈值时经轴突 (Axon) 发放动作电位，再通过突触 (Synapse) 传递给下游神经元。人工神经元是这一过程的数学抽象：输入信号 `x₁, x₂, ..., xₙ` 类比树突接收的信号，乘以各自权重 (Weight) `w₁, w₂, ..., wₙ`（类比突触连接强度）后求和，再加上偏置 (Bias) `b`（类比静息电位），得到净输入 `z = w·x + b`；最后经激活函数 (Activation Function) `f(·)` 做非线性变换，产生输出 `y = f(z)`，类比动作电位的发放与否。

**感知机 (Perceptron)。** Rosenblatt 于 1958 年提出的感知机是最简单的神经元模型，其形式为 `y = f(w·x + b)`，其中 `f` 最初取阶跃函数 (Step Function)，输出二值 0 或 1，实现线性二分类。它的学习规则十分直观：对每个误分类样本，按

```
w ← w + η · (y_true − y_pred) · x
b ← b + η · (y_true − y_pred)
```

更新权重与偏置，其中 `η` 为学习率 (Learning Rate)。从几何上看，感知机在特征空间中寻找一个分离超平面 (Separating Hyperplane) `w·x + b = 0` 将正负样本分开；当数据线性可分 (Linearly Separable) 时，感知机收敛定理保证算法在有限步内收敛。

**XOR 问题与第一次寒冬。** 感知机的致命局限是无法处理 XOR（异或）这类非线性可分问题——在二维平面上，无论怎样画一条直线，都无法把 (0,0)、(1,1) 与 (0,1)、(1,0) 分开。Minsky 与 Papert 在 1969 年的《Perceptrons》中严格证明了单层感知机不能解决 XOR，这直接导致连接主义研究陷入低谷，成为第一次 AI 寒冬 (First AI Winter) 的主要推手之一。他们同时指出多层感知机可能具备解决能力，但当时缺乏有效的多层训练算法。

**多层感知机 (Multi-Layer Perceptron, MLP)。** MLP 由输入层 (Input Layer)、一个或多个隐藏层 (Hidden Layers) 与输出层 (Output Layer) 构成，相邻层之间全连接 (Fully Connected, FC)，同层神经元之间无连接，整体形成有向无环图 (DAG)。前向传播 (Forward Pass) 中，信息从输入逐层向后传递，第 `l` 层的计算为

$$a^{(l)} = f\left(W^{(l)} a^{(l-1)} + b^{(l)}\right)$$

其中 `a^(l-1)` 是上一层的激活输出，`W^(l)` 与 `b^(l)` 是该层权重与偏置。**万能近似定理 (Universal Approximation Theorem)** 指出：只要存在一个隐藏层且使用非线性激活函数，具有足够多神经元的 MLP 就能以任意精度逼近任意连续函数（Cybenko、Hornik 等人于 1989 年分别独立证明）。这奠定了神经网络的表达力基础，但定理只保证存在性，既未告诉我们需要多少神经元，也未提供学习算法。深度与宽度的对比进一步说明问题：多个隐藏层的深层网络能以指数级更少的参数表达同一函数，并能学习输入特征的层次化抽象表示 (Hierarchical Representation)，这正是深度学习成功的核心原因之一。

**激活函数。** 激活函数为网络引入非线性 (Non-linearity)。若没有激活函数或全部使用线性激活，多层线性变换的复合仍是线性变换，无论堆叠多少层都退化为单层线性模型，深度便失去意义。下表汇总了主流激活函数的关键性质。

| 激活函数 | 公式 | 值域 | 优点 | 缺点 | 典型场景 |
|:---|:---|:---|:---|:---|:---|
| Sigmoid | `σ(x) = 1/(1+e^{-x})` | (0, 1) | 平滑、可解释为概率 | 梯度消失、非零中心、指数开销 | 二分类输出层 |
| Tanh | `tanh(x) = (e^x−e^{-x})/(e^x+e^{-x})` | (−1, 1) | 零中心、梯度比 Sigmoid 大 | 梯度消失、指数开销 | 历史 RNN 隐藏层 |
| ReLU | `max(0, x)` | [0, +∞) | 非饱和、计算快、稀疏激活 | 死亡 ReLU、非零中心 | CNN/MLP 隐藏层 |
| Leaky ReLU | `max(αx, x)`, α≈0.01 | (−∞, +∞) | 缓解死亡 ReLU、计算快 | 非零中心、α 为超参 | CNN 隐藏层 |
| ELU | `x`(x>0), `α(e^x−1)`(x≤0) | (−α, +∞) | 近零均值、平滑可导 | 指数开销略高 | CNN 隐藏层 |
| GELU | `x·Φ(x) ≈ x·σ(1.702x)` | ≈(−0.17, +∞) | 概率门控、正则化效果 | 计算比 ReLU 复杂 | Transformer |
| Swish/SiLU | `x·σ(x)` | ≈(−0.28, +∞) | 平滑非单调、NAS 发现 | 计算比 ReLU 复杂 | EfficientNet |
| Softmax | `e^{z_i}/Σ_j e^{z_j}` | (0,1)、和为 1 | 概率化输出 | 仅用于最后一层 | 多分类输出层 |

Sigmoid 将实数压缩到 (0, 1)，处处可导且可解释为概率，但在 `|x|` 较大时导数 `σ'(x) = σ(x)(1−σ(x))` 趋近于 0，深层反向传播时梯度指数衰减，且输出恒正导致下一层梯度更新方向一致，收敛呈之字形 (zig-zag)。Tanh 是零中心的，缓解了之字形问题，但仍存在饱和区梯度消失。ReLU 是深度学习的转折点：正半轴导数恒为 1，计算只需一次 `max`，负半轴输出为零带来稀疏激活，这使 AlexNet 等深层网络的训练成为可能；其代价是负半轴梯度为零，学习率过高时神经元可能进入"死亡 ReLU"状态而永久不再更新，实践中常配合较小学习率与 He 初始化。Leaky ReLU 与 PReLU 在负区间保留小斜率，ELU 则在负区间平滑过渡并趋向零均值。GELU 以标准正态累积分布函数 `Φ(x)` 对输入做概率门控，是 BERT、GPT、ViT 等 Transformer 的标配；Swish/SiLU 由神经架构搜索发现，在 EfficientNet 等深度残差网络上常略优于 ReLU。Softmax 用于输出层，将 logits 映射为概率分布，与交叉熵损失配合时梯度形式极简：`∂L/∂z_i = ŷ_i − y_i`。

实践中，隐藏层默认首选 ReLU；若出现大量死亡神经元，改用 Leaky ReLU 或 ELU 并调低学习率、检查初始化；Transformer 与 NLP 任务使用 GELU；分类输出层二分类用 Sigmoid、多分类用 Softmax；回归任务通常不加激活。隐藏层应避免 Sigmoid/Tanh，除非是 LSTM/GRU 门控等依赖其特定性质的场合。

## 6.2 反向传播与自动微分

**反向传播的目的。** 反向传播 (Backpropagation, BP) 的核心任务是高效计算损失 $L$ 对网络中所有参数 $\mathbf{W}^{(l)}, \mathbf{b}^{(l)}$ 的梯度。它的关键思想是链式法则 (Chain Rule) 与动态规划 (Dynamic Programming) 的结合：前向传播时逐层缓存中间量，反向传播时复用已经算出的中间梯度，把原本指数级的重复计算降为线性级。前向传播 (Forward Pass) 逐层计算激活 $a^{(l)}$ 并缓存线性输出 $z^{(l)}$；反向传播 (Backward Pass) 则从输出层向输入层逐层传播误差信号 $\boldsymbol{\delta}^{(l)} = \frac{\partial L}{\partial \mathbf{z}^{(l)}}$。单层梯度公式为

$$\frac{\partial L}{\partial \mathbf{W}^{(l)}} = \boldsymbol{\delta}^{(l)} \left(\mathbf{a}^{(l-1)}\right)^\mathsf{T},$$

而误差信号本身按下式逐层回传：

$$\boldsymbol{\delta}^{(l)} = \left({\mathbf{W}^{(l+1)}}^\mathsf{T} \boldsymbol{\delta}^{(l+1)}\right) \odot f'\left(\mathbf{z}^{(l)}\right),$$

其中 $\odot$ 为逐元素乘积 (Hadamard Product)。

**计算图视角。** 把网络表示成计算图 (Computational Graph)，节点是运算、边是数据流，反向传播本质上就是在这个有向无环图上做反向模式自动微分 (Reverse-Mode Automatic Differentiation)。以两层网络加 MSE 损失为例，输入 $x \in \mathbb{R}^d$、隐层含 $h$ 个神经元、输出 $\hat{y} \in \mathbb{R}$，完整算法可拆为下表步骤。

| 步骤 | 操作 | 公式 |
|:---:|:---|:---|
| F1 | 线性变换 1 | $\mathbf{z}^{(1)} = \mathbf{W}^{(1)}\mathbf{x} + \mathbf{b}^{(1)}$ |
| F2 | 激活 | $\mathbf{a}^{(1)} = \sigma(\mathbf{z}^{(1)})$ |
| F3 | 线性变换 2 | $z^{(2)} = \mathbf{W}^{(2)}\mathbf{a}^{(1)} + b^{(2)}$ |
| F4 | 输出与损失 | $\hat{y} = z^{(2)},\; L = \tfrac{1}{2}(\hat{y} - y)^2$ |
| B1 | 输出层误差 | $\delta^{(2)} = \partial L/\partial z^{(2)} = \hat{y} - y$ |
| B2 | 隐层误差 | $\boldsymbol{\delta}^{(1)} = ({\mathbf{W}^{(2)}}^\mathsf{T}\delta^{(2)}) \odot \sigma'(\mathbf{z}^{(1)})$ |
| B3 | $\mathbf{W}^{(2)}$ 梯度 | $\partial L/\partial \mathbf{W}^{(2)} = \delta^{(2)} (\mathbf{a}^{(1)})^\mathsf{T}$ |
| B4 | $\mathbf{W}^{(1)}$ 梯度 | $\partial L/\partial \mathbf{W}^{(1)} = \boldsymbol{\delta}^{(1)} \mathbf{x}^\mathsf{T}$ |

**梯度消失与梯度爆炸。** 深层网络的训练困难大多源于梯度的病态传播。梯度消失 (Vanishing Gradient) 指梯度经过多层 Sigmoid/Tanh 向浅层传播时呈指数衰减：对 Sigmoid 有 $|\sigma'(x)| \le 0.25$，多层导数相乘使 $\prod |f'| \ll 1$，浅层梯度趋近于 0，训练陷入平台期。梯度爆炸 (Exploding Gradient) 则相反，梯度随层数指数增长，常见于深层 RNN 或不当初始化，导致参数更新步幅过大、损失震荡甚至溢出为 NaN。应对手段各有针对性，如下表所示。

| 问题 | 方法 | 原理 |
|:---|:---|:---|
| 梯度消失 | ReLU 类激活 | 正区间导数恒为 1，避免连乘衰减 |
| 梯度消失 | 批归一化 | 将每层输入归一化，避免落入饱和区 |
| 梯度消失 | 残差连接 | $y = F(x) + x$，梯度经恒等映射直接回传 |
| 梯度消失 | Xavier/He 初始化 | 维持各层激活方差一致 |
| 梯度爆炸 | 梯度裁剪 | 按值截断 $g \leftarrow \mathrm{clip}(g,-v,v)$ 或按范数缩放 $g \leftarrow g \cdot v/\|g\|$ |

**权重初始化。** 糟糕的初始化会让训练一开始就陷入梯度消失或爆炸，核心原则是维持前向与反向传播中各层激活方差一致。Xavier/Glorot 初始化从 $U[-\sqrt{6/(n_\text{in}+n_\text{out})}, \sqrt{6/(n_\text{in}+n_\text{out})}]$ 采样，适合 Tanh 等近似线性区间的激活；He/Kaiming 初始化服从 $\mathcal{N}(0, 2/n_\text{in})$，补偿 ReLU 将一半神经元置零造成的方差减半，是 ReLU 网络的推荐选择。

**自动微分。** 深度学习中求导有三种主流方式。符号微分 (Symbolic Differentiation) 由人或计算机代数系统推导解析式，结果精确但易出现表达式爆炸 (Expression Swell)；数值微分 (Numerical Differentiation) 用差分 $f'(x) \approx (f(x+h)-f(x))/h$ 近似，实现简单但受截断误差与舍入误差双重影响，且需 $O(n)$ 次函数求值；自动微分 (Automatic Differentiation) 把程序分解为基本运算后按链式法则精确求导，兼顾精度与效率，代价是需构建计算图。自动微分又分前向模式 (Forward-mode) 与反向模式 (Reverse-mode)：前者与函数求值同步，一次前向传播计算"一个输入对所有输出的敏感度"，对应 Jacobian-向量积 (JVP)，适合输入少输出多的函数；后者先正向建图再逆向遍历，一次传播计算"一个输出对所有输入的梯度"，对应向量-Jacobian 积 (VJP)，适合输入多输出少的标量损失——这正是反向传播。其累积公式为

$$\bar{v}_k = \sum_{j \in \text{children}(k)} \bar{v}_j \frac{\partial v_j}{\partial v_k},$$

其中 $\bar{v}_i = \partial L/\partial v_i$ 称为伴随值 (Adjoint Value)，$v_i$ 为前向计算的原值 (Primal Value)。

**现代框架。** PyTorch 的 autograd 采用动态计算图 (define-by-run)，每次前向传播实时构建图并追踪 `requires_grad=True` 的张量；TensorFlow 的 `GradientTape` 在上下文内记录操作，退出后调用 `tape.gradient()` 完成反向传播。动态图的优势在于灵活支持控制流、图结构可随输入变化、调试直观，且与 NumPy 风格一致，因而成为研究与工程的主流。

## 6.3 优化算法

**深度学习优化的特点。** 与凸优化不同，深度网络的损失函数高度非凸 (non-convex)，参数空间高维，且梯度只能基于 mini-batch 做随机估计。批量大小的选择直接影响优化质量：全量批梯度 (Batch GD) 无噪声但每步代价极大、内存受限；单样本随机梯度 (Stochastic GD) 噪声极高、难以向量化；mini-batch 梯度（如 32/64/128）介于两者之间，兼顾收敛速度与 GPU 利用率，是实际训练的标准做法。

**从 SGD 到动量。** 最朴素的随机梯度下降 (Stochastic Gradient Descent, SGD) 更新为 `θ_{t+1} = θ_t − η ∇L(θ_t; mini-batch)`，简单且理论扎实，但在沟壑 (ravine) 地形中震荡严重、对学习率极其敏感、收敛慢。动量法 (Momentum) 累积历史梯度作为"速度"，在一致方向上加速、在震荡方向上相互抵消，典型形式为 `v_{t+1} = β v_t + η ∇L(θ_t)`、`θ_{t+1} = θ_t − v_{t+1}`，其中 `β ≈ 0.9`；其直觉类比小球滚下山坡时的惯性，可越过浅局部极小。Nesterov 加速梯度 (NAG) 进一步改进，先在动量方向"向前看一步"再计算梯度：`v_{t+1} = β v_t + η ∇L(θ_t − β v_t)`，从而纠正过冲 (overshooting)。

**自适应学习率方法。** AdaGrad 为每个参数分配独立学习率，稀疏特征用大学习率、频繁特征用小学习率，但累积平方梯度 `G_t = G_{t−1} + (∇L)²` 单调递增会使学习率逐渐趋零，训练提前终止。RMSprop 用指数移动平均替代单调累积，`G_t = β G_{t−1} + (1−β)(∇L)²`，解决了 dying LR 问题。Adam (Adaptive Moment Estimation) 综合动量（一阶矩）、RMSprop（二阶矩）与偏差修正：

$$m_t = \beta_1 m_{t-1} + (1-\beta_1)\nabla L,\quad v_t = \beta_2 v_{t-1} + (1-\beta_2)(\nabla L)^2,$$
$$\hat{m}_t = \frac{m_t}{1-\beta_1^t},\quad \hat{v}_t = \frac{v_t}{1-\beta_2^t},\quad \theta_{t+1} = \theta_t - \eta \frac{\hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon},$$

默认超参为 `η = 0.001, β₁ = 0.9, β₂ = 0.999, ε = 1e-8`，是使用最广泛的基准优化器。AdamW 则修正了 Adam 中 L2 正则与权重衰减不等价的问题，把权重衰减从梯度更新中解耦：`θ_{t+1} = θ_t − η( m̂_t/(√v̂_t+ε) + λ θ_t )`，成为现代 Transformer/GPT/ViT 训练的标配（PyTorch ≥ 1.2、HuggingFace 默认）。

下表汇总各优化器的核心特征，便于横向比较。

| 优化器 | 核心公式（简化） | 优点 | 缺点 |
|:---|:---|:---|:---|
| SGD | `θ −= η∇L` | 简单稳定、泛化好 | 收敛慢、对 LR 敏感 |
| Momentum | `v = βv + η∇L; θ −= v` | 加速收敛、抑制震荡 | 可能过冲 |
| NAG | `v = βv + η∇L(θ−βv)` | 更快更稳、纠正过冲 | 计算略增 |
| AdaGrad | `θ −= η∇L/√(Σ∇L²)` | 适合稀疏特征 | LR 单调衰减至 0 |
| RMSprop | `θ −= η∇L/√(EMA(∇L²))` | 解决 dying LR | 无动量、收敛偏慢 |
| Adam | `m,v` 双矩 + 偏差修正 | 收敛快、鲁棒、默认首选 | 泛化有时略逊 SGD |
| AdamW | Adam + 解耦 `λθ` | 正确实现权重衰减 | 多一个超参 λ |

**学习率调度与梯度裁剪。** 学习率是深度学习中最重要的超参数之一，常用调度策略包括：阶梯衰减 (Step Decay) 每若干 epoch 乘以因子 γ；指数衰减 (Exponential Decay) `η_t = η₀ γ^t`；余弦退火 (Cosine Annealing) `η_t = η_min + 0.5(η₀−η_min)(1+cos(tπ/T))`，平滑下降并可在周期末重启；线性预热加余弦衰减 (Linear Warmup + Cosine Decay) 先在前约 10% 步线性升高再余弦下降，是 Transformer 训练默认方案；平台衰减 (Reduce on Plateau) 在验证损失连续若干 epoch 不下降时自动降学习率；循环学习率 (Cyclic LR) 与 1cycle 策略则让学习率在区间内波动，有助于跳出鞍点。梯度裁剪 (Gradient Clipping) 用于防止梯度爆炸，按值裁剪逐元素硬截断，按范数裁剪 `g ← c·g/‖g‖` 在缩放时保持方向；Transformer 训练中按全局范数裁剪是标准操作。实践中，CV 任务（CNN/ViT）常用 SGD+Momentum 加余弦退火或 AdamW+余弦，NLP 任务（Transformer/GPT）用 AdamW 加预热余弦；调参顺序通常先定学习率（Adam 约 3e-4，SGD 约 0.1），再调批大小，最后微调 β 与权重衰减。

## 6.4 训练技巧

**内部协变量偏移。** 训练过程中前面层的参数不断更新，使每一层的输入分布持续变化，这种现象称为内部协变量偏移 (Internal Covariate Shift)。它迫使后续层不断适应新分布，收敛缓慢，并要求谨慎的初始化与较小的学习率。归一化与跳跃连接是应对这一问题的核心技术。

**批归一化 (Batch Normalization, BN)。** BN 对 mini-batch 内每个特征维度做标准化

$$\hat{x}^{(k)} = \frac{x^{(k)} - \mu_B^{(k)}}{\sqrt{\sigma_B^{2(k)} + \varepsilon}},$$

再引入可学习的缩放与平移参数 `y^(k) = γ^(k) x̂^(k) + β^(k)` 以恢复表达能力。推理阶段使用训练期间累积的滑动平均 `μ_running`、`σ²_running`，而非当前 batch 的统计量。BN 允许更大学习率、降低对初始化的敏感性、自带由 batch 统计噪声带来的正则化效果，并使 Sigmoid 等饱和激活的深层网络可训练。但它的局限也明显：依赖 batch 大小，小 batch 时统计量噪声大；不适配各时间步输入分布不同的 RNN；不兼容在线/流式学习。典型放置位置是卷积层之后、激活函数之前，即 Conv → BN → ReLU。

**层归一化与其它归一化。** 层归一化 (Layer Normalization, LN) 沿特征维度而非 batch 维度计算均值与方差，对每个样本独立归一化，因而完全与 batch 大小无关，适用于小 batch 甚至 batch size 为 1，也天然适配 RNN、Transformer 等序列模型。在 Transformer 中，早期标准做法是残差相加后做 LN（Post-LN），现代则多用 Pre-LN。实例归一化 (Instance Normalization, IN) 逐样本逐通道归一化，主要用于风格迁移；组归一化 (Group Normalization, GN) 将通道分组后在组内归一化，兼顾 LN 的不依赖 batch 与 BN 的利用通道相关性，在 batch size 较小时显著优于 BN。各类归一化的归一化轴与适用场景如下表。

| 方法 | 归一化轴（张量 N×C×H×W） | 依赖 batch | 典型应用 |
|:---|:---|:---:|:---|
| Batch Norm | N, H, W | 是 | CNN 图像分类 |
| Layer Norm | C, H, W | 否 | Transformer、RNN |
| Instance Norm | H, W | 否 | 风格迁移 |
| Group Norm | C/G, H, W | 否 | 检测/分割的小 batch 训练 |

**Dropout。** Dropout 在训练阶段以概率 p 随机将神经元输出置零，并将保留的输出缩放 `1/(1−p)`（即 Inverted Dropout，推理时无需额外缩放）：

$$r_j \sim \mathrm{Bernoulli}(1-p),\quad \tilde{h} = r \odot h \cdot \frac{1}{1-p}.$$

它的直觉有两点：一是打破神经元之间的协同适应 (Co-adaptation)，迫使每个神经元学习更鲁棒的特征；二是每次训练相当于采样一个不同的稀疏子网络，测试时隐式集成了指数数量级的子网络。隐藏层常用 p=0.5、输入层常用 p=0.2。其变体包括：丢整个特征图的 Spatial Dropout、丢权重而非激活的 DropConnect、随机丢弃整个残差层的 Stochastic Depth，以及丢弃连续方块区域、在 CNN 中效果更好的 DropBlock。现代 SOTA 模型中 Dropout 使用有所减少（部分被 BN 与数据增强取代），但在 ViT 的注意力等结构中仍然保留。

**残差连接。** 残差连接 (Residual Connection) 让网络学习残差映射 `H(x) = F(x) + x`，而非直接学习 `H(x)`：

$$\mathbf{y} = \mathcal{F}(\mathbf{x}, \{W_i\}) + \mathbf{x}.$$

若恒等映射是最优解，网络只需把 `F(x)` 学成 0，远比学成恒等映射容易；这解决了更深网络反而不如浅网络的退化问题 (Degradation)。更重要的是，梯度可经跳跃连接 (Skip Connection) 直接回传：

$$\frac{\partial \mathcal{L}}{\partial \mathbf{x}} = \frac{\partial \mathcal{L}}{\partial \mathbf{y}}\left(1 + \frac{\partial \mathcal{F}}{\partial \mathbf{x}}\right),$$

其中恒等项 1 保证了梯度的"高速公路"。常见变体包括将 BN 与 ReLU 前置的 Pre-activation、用 1×1→3×3→1×1 卷积先降维再升维的 Bottleneck，以及用拼接替代加法的 DenseNet。综合来看，ResNet 类 CNN 以 BN、残差连接为主；ViT/GPT 类模型以 LN、残差连接为主，Dropout 按需使用。

## 6.5 卷积神经网络

**动机。** 图像、视频等网格结构数据若用全连接网络处理，参数量会随像素数爆炸。卷积神经网络 (Convolutional Neural Network, CNN) 通过参数共享 (Parameter Sharing) 与局部连接 (Local Connectivity)，大幅降低参数量，并天然具备平移等变性 (Translation Equivariance)。这是 CNN 处理视觉任务的根本优势。

**卷积层。** 二维离散卷积 (Discrete Convolution) 定义为

$$(I * K)[i,j] = \sum_m \sum_n I[i+m, j+n] \cdot K[m,n],$$

其中 I 为输入特征图 (Input Feature Map)，K 为卷积核 (Kernel/Filter)。步幅 (Stride) s 控制滑动步长，填充 (Padding) p 控制边界处理：Valid Padding 取 p=0、输出缩小；Same Padding 取 p=⌊(k−1)/2⌋（当 s=1 时）使输出与输入同尺寸；Full Padding 取 p=k−1、输出扩大。输出尺寸为

$$o = \left\lfloor \frac{i + 2p - k}{s} \right\rfloor + 1.$$

参数共享使同一卷积核在整张输入上滑动复用权重，赋予平移等变性；每层使用多个卷积核则输出多通道特征图，各通道学习边缘、纹理、颜色等不同模式。1×1 卷积实现通道方向的线性组合，不改变空间尺寸，常用于瓶颈结构降维/升维；空洞卷积 (Dilated/Atrous Convolution) 在核元素间插入空洞，以膨胀率 d 扩大感受野而不增加参数量，常用于语义分割与时序建模。

**池化层。** 池化 (Pooling) 用于降采样、扩大感受野并降低计算量。最大池化 (Max Pooling) 取窗口最大值，提供局部平移不变性 (Translation Invariance) 并保留最显著特征；平均池化 (Average Pooling) 取均值，输出更平滑、对噪声更鲁棒；全局平均池化 (Global Average Pooling, GAP) 将整个空间维度池化为 1×1，替代全连接层作为分类器前层，大幅减少参数量并防止过拟合。

**架构演进。** CNN 的发展大致经历从小规模骨架到深层残差、再到现代化设计的过程。下表汇总各经典架构的关键信息。

| 架构 | 年份 | 参数量 | ImageNet Top-1 | 核心创新 |
|:---|:---|:---|:---|:---|
| LeNet-5 | 1998 | ~60K | — | Conv-Pool-FC 骨架 |
| AlexNet | 2012 | ~60M | ~63.3% | ReLU、Dropout、GPU 训练 |
| VGG-16 | 2014 | ~138M | ~74.4% | 3×3 小卷积核堆叠 |
| GoogLeNet | 2014 | ~6.8M | ~74.8% | Inception 模块、1×1 降维 |
| ResNet-50 | 2015 | ~25.6M | ~80.4% | 残差连接、Bottleneck |
| DenseNet-121 | 2017 | ~8.0M | ~75.6% | 密集连接、特征复用 |
| SENet-154 | 2017 | ~115M | ~82.7% | SE 通道注意力 |
| EfficientNet-B7 | 2019 | ~66.3M | ~84.3% | 复合缩放 |
| ConvNeXt-XL | 2022 | ~350M | ~86.3% | 现代化 CNN 设计 |

LeNet-5 用 Conv-Pool-Conv-Pool-FC 的七层结构完成 MNIST 手写数字识别，开创了 CNN 范式。AlexNet 以 5 个卷积层加 3 个全连接层、约 60M 参数夺得 ImageNet 2012 冠军，top-5 错误率 15.3%，其 ReLU、Dropout、数据增强与双 GPU 训练成为后世标配，直接引爆深度学习革命。VGG 全部使用 3×3 小卷积核堆叠，证明两个 3×3 卷积可获得一个 5×5 的感受野而参数更少、非线性更强，确立了"深度至关重要"的思想。GoogLeNet 提出 Inception 模块，用并行的 1×1、3×3、5×5 卷积分支加池化分支拼接输出，并以 1×1 卷积降维控制计算量，用 GAP 替代全连接层。

**现代架构。** ResNet 引入残差学习与 Bottleneck 块，使 100 层以上网络的训练成为可能，ResNet-152 将 top-5 错误率降到 3.57%，首次超越人类约 5.1% 的水平，成为现代视觉任务的通用骨干。ResNeXt 引入基数 (Cardinality) 概念，用分组卷积将残差块拆为多分支，在相同 FLOPs 下比单纯增加深度或宽度收益更高。DenseNet 让每一层与前面所有层直接连接，通过特征复用强化梯度传播，在同等性能下参数量更少。SENet 提出 Squeeze-and-Excitation 模块，用全局平均池化加两个全连接层生成通道重要性权重，再逐通道重标定，是通道注意力的先驱且即插即用。EfficientNet 提出复合缩放，同时均匀缩放深度 `d=α^φ`、宽度 `w=β^φ` 与分辨率 `r=γ^φ`，并约束 `α·β²·γ²≈2`，以极小参数量达到当时 SOTA。ConvNeXt 把 Transformer 的设计理念（大卷积核、LayerNorm、GELU、阶段比例 3:3:9:3）融入纯 CNN，性能匹敌甚至超越 Swin Transformer。总体趋势是：深度持续增加并由残差突破瓶颈，宽度与基数走向系统化缩放，归一化从 LRN→BN→LN 演进，激活从 Sigmoid/Tanh→ReLU→Swish→GELU，注意力从无到 SE 再到多头自注意力，设计方式则从人工设计走向 NAS 与 CNN-Transformer 融合。

## 6.6 序列模型

**动机。** 文本、语音、时间序列等序列数据具有可变长度与时序依赖 (Temporal Dependencies)，传统前馈网络无法直接建模。循环神经网络 (Recurrent Neural Network, RNN) 与前馈网络的本质区别在于参数跨时间步共享 (Parameter Sharing Across Time Steps)，并引入隐藏状态 $h_t$ 作为记忆。循环连接使当前输出依赖先前状态，形成沿时间轴展开的计算图。RNN 的基本递推为

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h),\qquad y_t = W_{hy} h_t + b_y.$$

训练时把网络沿时间展开，再应用标准反向传播，即沿时间反向传播 (Backpropagation Through Time, BPTT)，每步梯度需乘以 Jacobian 矩阵 $\partial h_t/\partial h_{t-1}$。

**RNN 的核心问题。** 当 Jacobian 特征值 `|λ| < 1` 时，梯度随时间指数衰减 `∂L/∂h₀ ∝ ∏ λ_t → 0`，网络无法学习长距离依赖；当 `|λ| > 1` 时梯度指数增长趋于无穷，训练不稳定。前者为梯度消失，后者为梯度爆炸，后者可用梯度裁剪 `g ← min(1, τ/‖g‖)·g` 缓解。为从根本上解决长距离依赖，研究者提出了门控机制。

**LSTM。** 长短期记忆网络 (Long Short-Term Memory, LSTM) 由 Hochreiter 与 Schmidhuber 于 1997 年提出，核心是引入门控单元状态 $C_t$ 作为记忆高速公路。遗忘门 $f_t = \sigma(W_f[h_{t-1}, x_t] + b_f)$ 决定丢弃哪些旧信息；输入门 $i_t = \sigma(W_i[h_{t-1}, x_t] + b_i)$ 决定写入哪些新信息；候选值 $\tilde{C}_t = \tanh(W_C[h_{t-1}, x_t] + b_C)$ 给出新候选；单元状态按 `C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t` 更新；输出门 $o_t = \sigma(W_o[h_{t-1}, x_t] + b_o)$ 决定输出多少记忆；最终 `h_t = o_t ⊙ tanh(C_t)`。LSTM 之所以缓解梯度消失，关键在于单元状态更新是加法形式，反向传播时梯度不经历连续矩阵乘法，且门可以学到 `f_t → 1` 来长期保留信息。常见变体包括让门也能看到细胞状态的窥孔连接 (Peephole Connections)，以及令 `f_t = 1 − i_t` 以减少参数的耦合遗忘-输入门。

**GRU。** 门控循环单元 (Gated Recurrent Unit, GRU) 由 Cho 等人于 2014 年提出，简化 LSTM 为两个门且不设独立细胞状态，隐藏状态直接充当记忆。重置门 $r_t = \sigma(W_r[h_{t-1}, x_t] + b_r)$ 控制忽略多少历史，更新门 $z_t = \sigma(W_z[h_{t-1}, x_t] + b_z)$ 控制新旧信息的插值比例，候选状态 $\tilde{h}_t = \tanh(W[r_t \odot h_{t-1}, x_t] + b)$，最终 `h_t = (1 − z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t`：$z_t \to 1$ 用新信息，$z_t \to 0$ 保留历史。相比 LSTM，GRU 无需独立 $C_t$，把遗忘门与输入门合并为 $z_t$，参数量更少、训练更快，经验上二者相当，小数据下 GRU 可能更优。三种模型的对比如下。

| 特性 | RNN | LSTM | GRU |
|:---|:---|:---|:---|
| 门数量 | 0 | 3 | 2 |
| 独立细胞状态 | 无 | 有 | 无 |
| 权重矩阵组数 | 3 | 4 | 3 |
| 梯度消失抵抗 | 差 | 强 | 较强 |
| 长序列建模 | 差 | 优 | 优 |
| 提出年份 | 1986/1990 | 1997 | 2014 |

**双向与深层 RNN。** 双向 RNN (Bidirectional RNN) 用两个独立 RNN 分别正向（$t=1\to T$）与反向（$t=T\to1$）处理序列，再把两个隐藏状态拼接 `h_t^bi = [h_t^forward; h_t^backward]`，使每个时间步同时包含过去与未来上下文。它适用于序列整体已知的命名实体识别、机器翻译、语音识别，但不适用于生成时未来不可见的自回归语言模型。深层 RNN (Deep RNN) 把多个 RNN 层垂直堆叠，第 l 层隐藏状态作为第 l+1 层输入，浅层捕获局部时序模式、深层捕获层次化时序抽象，实践中 2–4 层足够，层间可加 Dropout 与残差连接。

**训练技巧。** 序列模型训练常用几种工程手段。Teacher Forcing 在训练时始终输入真实上一步标签而非模型预测，加速收敛但可能造成训练与推理分布不一致的曝光偏差 (Exposure Bias)；Scheduled Sampling 以随训练递增的概率逐步改用模型自身预测，缓解该偏差；截断 BPTT (Truncated BPTT) 对极长序列只回传最近 k 步梯度，降低显存与计算量；梯度裁剪是所有 RNN 训练的必要条件，典型阈值 τ∈[1,5]；Dropout 施加于非循环连接，循环连接内部需用变分 Dropout 等特殊方案。

## 6.7 Seq2Seq 与注意力

**Seq2Seq 架构。** 机器翻译、文本摘要、对话生成等任务的输入与输出长度不同，需要可变长的序列映射范式。Seq2Seq 由编码器与解码器组成：编码器逐时间步读取输入 $x_{1:T}$，把整个输入压缩为固定维度的上下文向量 $c$（通常取 RNN 最后隐藏状态）；解码器以 $c$ 为条件自回归生成目标序列，

$$P(y_1,\dots,y_{T'}\mid x_1,\dots,x_T) = \prod_{t=1}^{T'} P(y_t \mid c, y_1,\dots,y_{t-1}).$$

训练时用 Teacher Forcing 每步喂入真实标签，推理时喂入上一步预测并配合集束搜索。Seq2Seq 的核心瓶颈在于无论输入多长，编码器都把全部信息压进单一固定向量，长序列（尤其早期 token）信息丢失严重。

**注意力机制。** 注意力 (Attention) 让解码器在每个输出步动态聚焦输入的相关部分：根据当前解码状态为所有编码器隐藏状态分配权重，再加权求和得到动态上下文向量。计算分三步：先算对齐分数 `e_{t,i} = score(s_{t-1}, h_i^enc)`，再经 Softmax 得权重 `α_{t,i} = exp(e_{t,i}) / Σ_j exp(e_{t,j})`，最后加权求和 `c_t = Σ_i α_{t,i} h_i^enc`。Bahdanau 与 Luong 是两种经典实现，其差异如下表。

| 属性 | Bahdanau（加法，2014） | Luong（乘法，2015） |
|:---|:---|:---|
| Score 函数 | $v^\top \tanh(W_a h_i^enc + U_a s_{t-1})$ | dot / general / concat |
| 计算时机 | 解码 RNN 之前 | 解码 RNN 之后 |
| 信息流 | $s_{t-1} \to c_t \to s_t$ | $s_{t-1} \to s_t \to c_t$ |
| 对齐学习 | 对齐模型与整体端到端联合训练 | 同样联合训练，score 更简洁 |

Bahdanau 注意力用前馈对齐模型计算未归一化分数，softmax 后加权求和，再把 `[y_{t-1}, c_t]` 送入 RNN 更新状态，其对齐权重可可视化为二维对齐矩阵。Luong 注意力先由解码 RNN 输出 $s_t$，再用它与所有编码器状态计算 score，三种变体为点积 dot、引入可学习矩阵的 general（最流行）以及类似加法的 concat；它还区分全局注意力（对所有状态计算）与局部注意力（仅在预测窗口内计算，用于长序列加速）。注意力的意义在于突破单向量瓶颈、显著提升长句翻译质量、提供可解释的对齐可视化，并直接启发了 Transformer 的全注意力架构。

**集束搜索与复制机制。** 贪婪解码每步取 argmax，容易陷入局部最优；集束搜索 (Beam Search) 每步保留概率最高的 top-k 个部分假设，k 条路径同时扩展，最终选择累积对数概率最大的完整序列，并常用长度归一化 `score(Y) = (1/|Y|^α) Σ_t log P(y_t|…)` 避免偏向短序列。k 越大质量越好但越慢，典型取 5–10。复制机制 (Copy Mechanism) 则让解码器可直接复制源端 token，对罕见词、命名实体与摘要任务至关重要：每步计算 copy gate `p_gen ∈ [0,1]`，以 $p_{gen}$ 概率从词表生成、以 $1-p_{gen}$ 概率从注意力分布复制；Pointer-Generator Network 在此基础上加入覆盖向量与复制开关，在 CNN/Daily Mail 摘要任务上显著提升 ROUGE。

## 6.8 Transformer

**动机。** RNN 必须按时间步顺序计算，无法并行，且难以捕捉超长距离依赖。Transformer（Vaswani 等，2017）用自注意力 (Self-Attention) 取代循环结构，实现全并行计算，彻底抛弃了循环。

**缩放点积注意力。** 自注意力的输入是查询 Q (Queries)、键 K (Keys)、值 V (Values)，在自注意力中三者均来自同一输入序列的线性投影。核心公式为

$$\mathrm{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \mathrm{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d_k}}\right)\mathbf{V}.$$

除以 $\sqrt{d_k}$ 是为防止点积随维度平方级膨胀使 softmax 落入饱和区；其直觉是每个位置的输出等于所有位置 value 的加权和，权重由当前 query 与各 key 的相似度决定。自注意力复杂度为 $O(n^2 d)$，对序列长度呈平方级，是处理长文本的核心瓶颈。

**多头注意力。** 单头注意力只能关注一种关系模式，多头注意力 (Multi-Head Attention, MHA) 让多个头并行计算、各自学习不同的表示子空间。第 i 个头为 `head_i = Attention(Q W_i^Q, K W_i^K, V W_i^V)`，每个头降维为原来的 1/h，总计算量与单头相当，最后拼接并经输出投影：

$$\mathrm{MultiHead}(\mathbf{Q},\mathbf{K},\mathbf{V}) = \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)\mathbf{W}^O.$$

不同头可分别关注语法结构、语义关联与位置关系。base Transformer 的典型配置是 h=8、d_k=d_v=64、d=512。

**整体架构。** 编码器由 N 个相同层堆叠，每层为多头自注意力加 Add & Norm，再经前馈网络 (FFN) 与 Add & Norm；解码器每层则依次为带掩码的多头自注意力、交叉注意力、前馈网络，均配 Add & Norm。残差连接把每个子层输入直接加回输出，缓解深层梯度消失；层归一化沿特征维度归一化使训练稳定（现代多用 Pre-LN）；前馈网络是两层 MLP，`FFN(x) = max(0, xW₁+b₁)W₂+b₂`（原始用 ReLU，现代用 GELU/SwiGLU），中间维度约为 4d。解码器中的带掩码自注意力 (Masked Self-Attention) 在 softmax 前把得分矩阵上三角设为 −∞，使自回归生成时不"看到"未来 token；交叉注意力 (Cross-Attention) 的 Q 来自解码器、K 与 V 来自编码器输出，用于融合源端信息。

**位置编码。** 自注意力具有排列不变性，"A 爱 B"与"B 爱 A"会得到相同分布，因此必须注入位置信息。正弦位置编码 (Sinusoidal) 用不同频率的 sin/cos 函数

$$\mathrm{PE}(pos, 2i) = \sin\!\left(\frac{pos}{10000^{2i/d}}\right),\quad \mathrm{PE}(pos, 2i+1) = \cos\!\left(\frac{pos}{10000^{2i/d}}\right)$$

编码绝对位置；可学习位置编码把位置视为可训练向量，灵活但无法外推到训练时未见的长度；相对位置编码则在注意力中注入位置间相对距离，代表方案有 Transformer-XL、T5 的分桶相对偏置、ALiBi 的线性偏置以及 RoPE 旋转位置编码，其中 RoPE 通过旋转矩阵把位置融入 Q 与 K 的内积、仅取决于相对距离且与 FlashAttention 兼容。各方案对比如下。

| 编码方式 | 外推长度 | 额外参数 | 代表模型 |
|:---|:---|:---:|:---|
| Sinusoidal | 可（效果有限） | 无 | 原始 Transformer |
| 可学习 | 不可（需固定 max_len） | 有 | BERT、GPT |
| Relative Bucketed | 可 | 有 | T5 |
| ALiBi | 可 | 无 | BLOOM |
| RoPE | 可（配合 NTK 缩放等） | 无 | LLaMA、Qwen、DeepSeek |

**成功原因与演化。** Transformer 强大的根源在于：任意两个 token 之间只需 O(1) 步注意力，路径长度恒定，长距离依赖建模能力强；编码器所有 token 同时计算，高度并行；多头提供多样表示子空间；残差加层归一化使数十上百层稳定训练。按结构可分为编码器专用（BERT，双向注意力，适合理解任务）、解码器专用（GPT 系列，因果注意力，适合生成）与编解码器（原始 Transformer、T5、BART，适合条件生成）。关键后续改进包括 Pre-LN（消除 Post-LN 对预热的依赖）、RoPE（成为主流位置编码）与 FlashAttention（利用 GPU SRAM 分级 IO 与在线 softmax，把显存从 O(n²) 降到 O(n) 并保持精确计算，是现代长上下文训练的基础）。

## 6.9 自编码器与变分自编码器

**判别模型与生成模型。** 判别模型 (Discriminative Model) 直接对条件概率 P(Y|X) 建模，学习决策边界，关注"给定 X 时 Y 是什么"，如逻辑回归、SVM、标准分类网络；生成模型 (Generative Model) 对联合概率 P(X,Y) 建模，学习数据底层分布并能从中采样生成新数据，如朴素贝叶斯、GMM、VAE、GAN、扩散模型。二者的对比如下。

| 维度 | 判别模型 | 生成模型 |
|:---|:---|:---|
| 建模目标 | P(Y\|X) 条件分布 | P(X,Y) 联合分布 |
| 关注点 | 类别决策边界 | 数据的分布形态 |
| 能否生成 | 否 | 是 |
| 典型任务 | 分类、回归 | 图像生成、密度估计 |
| 代表模型 | Logistic、SVM、CNN | Naive Bayes、VAE、GAN |

**自编码器 (Autoencoder, AE)。** AE 通过编码器-解码器 (Encoder-Decoder) 架构，让网络把输入压缩为低维潜在表示，再从中重建输入，本质是无监督的恒等映射学习。以 784 维 MNIST 输入为例，编码器逐层降维 `784→256→64` 得到瓶颈层潜在编码 `z ∈ R^k`，解码器再升维 `k→64→256→784` 重建。优化目标是最小化重建误差

$$\mathcal{L}(\phi,\theta) = \mathbb{E}_x\left[\|x - D_\theta(E_\phi(x))\|^2\right],$$

对二值输入也可用二元交叉熵。若瓶颈维数不小于输入维数（overcomplete），网络可能直接学到恒等映射而失去意义。AE 的常见变体见下表。

| 类型 | 约束方式 | 核心原理 |
|:---|:---|:---|
| Undercomplete | `dim(z) < dim(x)` | 瓶颈强制学习显著特征 |
| Overcomplete | `dim(z) ≥ dim(x)` | 需额外正则化防止恒等映射 |
| Sparse AE | 隐层激活加稀疏惩罚 | 鼓励多数神经元被抑制 |
| Denoising AE | 输入加噪、重建干净输入 | 迫使学习稳健特征 |
| Contractive AE | 惩罚 Encoder Jacobian | 使潜在表示对扰动不敏感 |

Denoising AE 的训练流程是：对干净输入加噪得到 $\tilde{x}$，编码为 `z = E_φ(x̃)`，解码重建 `x̂ = D_θ(z)`，以干净输入 x 为目标计算损失，再反向传播更新参数；关键点在于监督目标是干净 x 而非含噪 $\tilde{x}$。Contractive AE 惩罚编码器 Jacobian 的 Frobenius 范数，等价于学习流形的切平面 (Tangent Plane)，使潜在表示对噪声具有局部不变性。AE 的根本局限是不能生成新样本：潜在空间没有概率结构，随机采样 z 解码出的结果无意义；潜在空间不连续，相近的 z 可能解码出完全不同的 x；它本质上是确定性映射，缺乏生成所需的随机性与覆盖性。

**变分自编码器 (Variational Autoencoder, VAE)。** VAE（Kingma & Welling, 2014）把 AE 改造为概率生成模型，在潜在空间施加显式概率先验，使从先验采样 $z \sim P(z)$ 再经解码器即可生成有意义的样本。其概率框架为：先验 `P(z) ~ N(0,I)`，似然 `P(x|z) ~ N(μ_θ(z), σ²I)`（连续数据）或 Bernoulli（二值数据），目标是最大化边缘似然 `log P(x) = log ∫ P(x|z)P(z)dz`，但该积分不可计算 (Intractable)。

**变分推断与 ELBO。** VAE 引入近似后验 $Q_\phi(z|x)$ 逼近真实后验，编码器不再输出确定性编码，而是输出高斯分布参数 `(μ_φ(x), σ²_φ(x))`。从 `log P(x)` 出发可分解为

$$\log P(x) = \underbrace{\mathbb{E}_{Q_\phi}\left[\log \frac{P(x,z)}{Q_\phi(z|x)}\right]}_{\mathrm{ELBO}} + D_{\mathrm{KL}}\big(Q_\phi(z|x) \parallel P(z|x)\big),$$

其中 KL 散度恒非负，故 `log P(x) ≥ ELBO`，最大化 ELBO 即最大化对数似然的下界（Evidence Lower Bound 名称由此而来）：

$$\mathcal{L}_{\mathrm{ELBO}} = \underbrace{\mathbb{E}_{Q_\phi(z|x)}[\log P_\theta(x|z)]}_{\text{重建项}} - \underbrace{D_{\mathrm{KL}}(Q_\phi(z|x)\parallel P(z))}_{\text{KL 正则项}}.$$

重建项确保从 z 能准确重建 x，KL 项迫使近似后验接近标准高斯先验。当 `P(z) = N(0,I)`、`Q_φ(z|x) = N(μ,σ²)` 时，KL 有闭式解 `D_KL = −½ Σ_j (1 + log σ_j² − μ_j² − σ_j²)`，推动 μ→0、σ→1。

**重参数化技巧。** 直接对 `z ~ N(μ_φ(x), σ²_φ(x))` 采样是随机操作，梯度无法穿过随机节点反向传播。重参数化 (Reparameterization) 把采样改写为确定性变换

$$z = \mu + \sigma \odot \varepsilon,\qquad \varepsilon \sim \mathcal{N}(0, I),$$

其中噪声 ε 独立于参数，随机性被外移到输入噪声上，梯度便可沿 μ_φ 与 σ_φ 回传，实现端到端可微训练。VAE 的完整损失为

$$\mathcal{L}_{\mathrm{VAE}} = \frac{1}{N}\sum_i\left[\|x_i - \hat{x}_i\|^2 + \lambda \cdot \frac{1}{2}\sum_j\left(\sigma_{i,j}^2 + \mu_{i,j}^2 - 1 - \log\sigma_{i,j}^2\right)\right],$$

其中 λ 平衡重建质量与潜在空间正则强度。

**VAE 的性质与扩展。** KL 正则使潜在空间连续平滑，相近的采样点解码出语义相似的结果，因而支持插值 `z_interp = α z_A + (1−α) z_B` 与语义向量运算，并可直接从先验采样生成新样本。β-VAE 在 KL 项前乘以 `β > 1`，更强的 KL 压力迫使潜在维度彼此独立，实现解耦 (Disentanglement)，每个潜变量对应一个可解释生成因子；β 过大重建质量下降，过小退化为普通 VAE，典型取 2–10。VAE 的局限主要是生成样本偏模糊（高斯似然与像素独立性假设使解码器趋向均值）、后验坍塌 (Posterior Collapse)（解码器过强时 KL 被优化为 0，潜变量被忽略，可用 KL annealing、Free Bits 缓解）以及高斯先验表达力有限（可用 VampPrior、NVAE、VQ-VAE 扩展）。综合来看，AE 是确定性压缩-重建网络、潜在空间无约束、损失为重建误差、不能生成；VAE 是概率生成模型、编码器输出分布参数、潜在空间被约束为 N(0,I)、损失为重建项加 KL、能从先验采样并平滑插值。

## 6.10 生成对抗网络

**核心思想。** Goodfellow 等人在 2014 年提出的生成对抗网络 (Generative Adversarial Network, GAN) 让生成器 G 与判别器 D 进行极小极大博弈 (Minimax Game)：G 从噪声 $z \sim p_z$ 生成假样本欺骗 D，D 判别输入来自真实数据 $p_{data}$ 还是 G。目标函数为

$$\min_G \max_D V(D,G) = \mathbb{E}_{x\sim p_{data}}[\log D(x)] + \mathbb{E}_{z\sim p_z}[\log(1 - D(G(z)))].$$

当 G 学到 `p_g = p_{data}` 时达到均衡，D 无法区分、输出 0.5，最优判别器为 `D*(x) = p_data(x)/(p_data(x)+p_g(x))`；在最优 D 下，G 的优化等价于最小化 JS 散度 `JS(p_data ‖ p_g)`。GAN 的原始训练存在三大不稳定问题：模式坍塌 (Mode Collapse) 使 G 只产生少数几种样本；判别器过强时 `log(1−D(G(z)))` 饱和导致梯度消失；两者交替训练的震荡使过程难以收敛。

**DCGAN。** DCGAN（Radford 等，2015）是第一套使 GAN 训练趋于稳定的架构指南：判别器用步幅卷积替代池化，生成器用转置卷积上采样；在 G 与 D 中均使用批归一化以避免模式坍塌；去掉全连接隐藏层，改用全卷积架构并以全局平均池化接分类层；激活方面生成器除输出层用 tanh 外均用 ReLU，判别器全部用 LeakyReLU（0.2）。它首次生成相对逼真的人脸与卧室图像，极大推动了 GAN 研究。

**WGAN 与 WGAN-GP。** WGAN（Arjovsky 等，2017）从数学根源上解决训练困难：原始 GAN 最小化 JS 散度，当真实分布与生成分布是低维流形且支撑集不相交时 JS 恒为 log 2、梯度为零，G 无法学习。WGAN 改用 Wasserstein-1 距离（Earth Mover's Distance），其 Kantorovich-Rubinstein 对偶形式为

$$W(p_r, p_g) = \sup_{\|f\|_L \le 1}\left(\mathbb{E}_{x\sim p_r}[f(x)] - \mathbb{E}_{x\sim p_g}[f(x)]\right).$$

即使两分布支撑集无交集，W 仍光滑且提供有意义的梯度。WGAN 去掉判别器输出层的 Sigmoid，改称评论家 (Critic) 并输出实数值，通过权重裁剪把参数限制在 [−c,c] 以强制满足 1-Lipschitz，损失为 `E[D(G(z))] − E[D(x)]`。WGAN 的损失曲线与样本质量正相关、可作收敛指示，并显著减少模式坍塌。WGAN-GP 进一步用梯度惩罚 `λ E[(‖∇_x̂ D(x̂)‖₂ − 1)²]`（x̂ 为真伪样本连线上的随机插值点）替代粗暴的权重裁剪，更稳定、收敛更快，成为事实标准实现。

**条件 GAN。** 条件 GAN (cGAN) 让 G 与 D 同时接收额外条件 y，`G(z|y)` 根据噪声与条件生成、`D(x|y)` 评估给定条件下的真实性，条件通常与 z 拼接或以投影方式注入。其重要派生模型包括：pix2pix 处理配对图像翻译，G 用 U-Net、D 用 PatchGAN 并配合 L1 损失；CycleGAN 面向非配对图像集合，引入循环一致性损失实现马↔斑马等风格迁移；StackGAN/AttnGAN 做文本到图像生成，用多阶段堆叠逐步提高分辨率并以注意力对齐文本与图像区域。

**ProGAN 与 StyleGAN。** ProGAN（Karras 等，2017）从 4×4 分辨率开始训练，逐步平滑添加新层直到 1024×1024，并引入像素归一化、均衡学习率与小批次标准差等稳定化技术，新层加入时用权重 α 从旧层插值过渡。StyleGAN（2019/2020）灵感来自风格迁移的 AdaIN：映射网络 `f: Z → W` 用 8 层 MLP 把噪声映射到中间潜在空间 W，合成网络从常数张量出发逐层通过 AdaIN 注入风格 `AdaIN(x,y) = σ(y_s)·(x−μ(x))/σ(x) + μ(y_b)`，并额外注入高斯噪声提供细节。风格混合让低分辨率层用 $w_1$、高分辨率层用 $w_2$，发现低层控制姿态脸型等粗粒度特征、高层控制发色肤色等细粒度特征；截断技巧 `w' = w̄ + ψ(w−w̄)` 以多样性换取保真度。StyleGAN2 去除 AdaIN 的均值归一化、改用调制-解调消除水滴伪影，并引入路径长度正则使潜在空间更平滑。

**评估指标。** Inception Score (IS) 用预训练 Inception v3 分类，`IS = exp(E_x[KL(p(y|x)‖p(y))])`，高 IS 意味着样本被自信分类且整体类分布均匀，但它对模式坍塌不敏感、不适用于 ImageNet 以外数据集。Fréchet Inception Distance (FID) 计算 Inception 特征空间中真实与生成分布的距离

$$\mathrm{FID} = \|\mu_r - \mu_g\|_2^2 + \mathrm{Tr}\left(\Sigma_r + \Sigma_g - 2(\Sigma_r\Sigma_g)^{1/2}\right),$$

假设特征服从高斯分布，更与人类判断一致、对模式坍塌敏感，是当前事实标准，但需要足够样本量（建议 ≥10k）。GAN 的应用覆盖无条件图像生成（StyleGAN2、BigGAN）、图像超分辨率（SRGAN、ESGAN）、图像到图像翻译（pix2pix、CycleGAN、SPADE）、文本到图像（StackGAN、AttnGAN）、视频生成与 3D 生成等。这些指标与架构改进共同支撑了 GAN 在图像生成领域的广泛应用。

## 6.11 扩散模型

**核心思想。** 扩散模型 (Diffusion Model) 包含两个过程：前向过程逐步向数据添加噪声，将其破坏为纯噪声；逆向过程学习逆转扩散，从纯噪声逐步去噪生成新数据。训练与采样的对称性使其兼具稳定训练与高质量生成。

**前向与逆向过程。** 前向扩散是固定马尔可夫链，在 T 个时间步上逐步添加高斯噪声，单步转移分布为

$$q(x_t \mid x_{t-1}) = \mathcal{N}\left(x_t;\ \sqrt{1-\beta_t}\, x_{t-1},\ \beta_t \mathbf{I}\right),$$

其中噪声调度 $\beta_t$ 随 t 递增（如从 $10^{-4}$ 到 0.02），T 通常取 1000。借助重参数化可一步从 $x_0$ 算出任意 $x_t$：

$$x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1 - \bar{\alpha}_t}\, \varepsilon,\qquad \varepsilon \sim \mathcal{N}(0, \mathbf{I}),$$

其中 `α_t = 1−β_t`、`ᾱ_t = ∏_{s=1}^t α_s`。当 T 足够大时 `ᾱ_T → 0`，$x_T$ 近似标准高斯。逆向过程学习 `p_θ(x_{t-1}|x_t) = N(x_{t-1}; μ_θ(x_t,t), σ_t²I)`，其关键洞察是不直接预测 $x_{t-1}$，而是预测该步添加的噪声 ε，因为由 $x_t$ 与噪声可解析反推 $x_{t-1}$。

**DDPM。** 去噪扩散概率模型 (Denoising Diffusion Probabilistic Model, DDPM) 由 Ho 等人于 2020 年提出，训练一个网络 $\varepsilon_\theta(x_t,t)$ 预测 $x_t$ 中的噪声，损失极简：

$$L_{\text{simple}} = \mathbb{E}_{t, x_0, \varepsilon}\left[\left\|\varepsilon - \varepsilon_\theta(x_t, t)\right\|^2\right].$$

采样时从 $x_T \sim N(0,I)$ 出发迭代去噪：

$$x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar{\alpha}_t}}\varepsilon_\theta(x_t,t)\right) + \sigma_t z,\qquad z \sim \mathcal{N}(0,\mathbf{I}).$$

其骨干网络是 U-Net，通过正弦时间嵌入 (Time Embedding) 把时间步注入各层，在多个分辨率层级插入自注意力块，并广泛使用残差连接与组归一化。DDPM 之所以有效且稳定，是因为每个时间步都有训练信号（不像 GAN 依赖单一对抗信号），小步加噪使逆向分布近似高斯易于拟合，且概率密度全覆盖、不易模式崩溃。

**DDIM 与采样加速。** DDIM（Song 等，2021）推广了 DDPM 的马尔可夫假设，采用非马尔可夫前向过程并允许确定性采样（取 `σ_t=0`），但仍沿用相同的 DDPM 训练目标，从而可用约 50 步而非 1000 步生成高质量图像。进一步加速手段包括基于常微分方程高阶求解器的 DPM-Solver（10–20 步）、把多步模型蒸馏为少步模型的渐进蒸馏 (Progressive Distillation)，以及学习点到点单步映射、实现 1 步生成的一致性模型 (Consistency Models)。

**无分类器引导。** 无分类器引导 (Classifier-Free Guidance, CFG) 在不额外训练分类器的前提下增强条件控制，其公式为

$$\hat{\varepsilon}_\theta(x_t,t,c) = \varepsilon_\theta(x_t,t,\varnothing) + w\left(\varepsilon_\theta(x_t,t,c) - \varepsilon_\theta(x_t,t,\varnothing)\right),$$

其中 c 为条件、∅ 为空条件、w 为引导强度。训练时以一定概率随机丢弃条件，使模型同时学会条件与无条件生成。w=1 为标准条件生成；w 通常取 7–9 可放大条件信号、改善文本对齐，但会降低多样性；w 过大会导致图像过饱和失真。

**Stable Diffusion。** Stable Diffusion（Rombach 等，2022）的核心创新是把扩散从像素空间迁移到潜在空间，构成潜在扩散模型 (Latent Diffusion Model, LDM)。VAE 编码器把 `512×512×3` 图像压缩为 `64×64×4` 的潜在表示（压缩约 8 倍），U-Net 在潜在空间中做前向加噪与逆向去噪，VAE 解码器再把结果还原为图像，CLIP 文本编码器则把提示词编码后经交叉注意力注入 U-Net 各层。交叉注意力中 Q 来自 U-Net 中间特征图（空间信息），K、V 来自 CLIP 文本嵌入（语义信息），从而实现文本到图像。计算优势显著：潜在空间约 16K 维，而像素空间约 786K 维，计算量缩减约 48 倍，使消费级 GPU 也能生成高分辨率图像。综合训练稳定性、生成质量与采样速度，GAN 训练不稳定、质量锐利、单次前向采样快但无显式潜在空间；VAE 训练稳定、样本偏模糊、潜在空间可插值；扩散模型训练极稳定、质量最高但采样慢（已大幅改善），已成为当前生成模型的主流范式。

## 6.12 自回归模型与流模型

**自回归模型。** 自回归 (Autoregressive) 模型利用链式法则将联合分布分解为条件分布的乘积：

$$P(\mathbf{x}) = \prod_{t=1}^{n} P(x_t \mid x_{1:t-1}),$$

生成时先采样 $x_1$，再依次采样 $x_2 \sim P(x_2|x_1)$ 直到 $x_n$，每一步都依赖前面所有已生成元素，天然适配序列数据。在图像生成中它按光栅扫描顺序逐像素生成：PixelCNN 用掩码卷积 (Masked Convolutions) 遮蔽未来像素，以 mask A（仅当前层）与 mask B（跨层通道）实现因果约束；Gated PixelCNN 引入门控激活 `y = tanh(W_f * x) ⊙ σ(W_g * x)`，改善深层信号传播并消除盲点；PixelCNN++ 用离散化逻辑混合似然替代 256 路 softmax，并引入下采样/上采样结构与跳连接；WaveNet 用扩张因果卷积 (Dilated Causal Convolutions) 指数级扩大感受野，逐采样点预测 16kHz 原始音频，经 μ-law 量化到 256 个值以 softmax 预测，曾用于 Google Assistant 的语音合成。自回归模型的优点是显式似然、可直接优化 log P(x)、训练稳定无对抗博弈；缺点是顺序采样不可并行，生成 n 个元素需 O(n) 步，高维数据极慢，缓解手段有蒸馏、投机解码与非自回归并行解码。

**流模型。** 归一化流 (Normalizing Flows) 通过一系列可逆变换 (Invertible Transformations) 把简单基分布映射为复杂数据分布。设 `z_0 ~ p_0(z_0)` 为标准高斯，经 K 个可逆变换 `x = z_K = f_K ∘ … ∘ f_1(z_0)`，由变量替换公式得

$$\log p(\mathbf{x}) = \log p_0(\mathbf{z}_0) - \sum_{k=1}^{K} \log\left|\det \frac{\partial f_k}{\partial \mathbf{z}_{k-1}}\right|,$$

训练目标即最大化数据的对数似然。流模型要求变换可逆、Jacobian 行列式易计算、输入输出同维。NICE（2014）提出加法耦合层：把输入沿通道切分为两半，前半恒等传递，后半加上对前半的任意变换 `y_{d+1:n} = z_{d+1:n} + m(z_{1:d})`，其 Jacobian 为下三角、行列式为 1，是保体积变换。RealNVP（2016）升级为仿射耦合层 `y_{d+1:n} = z_{d+1:n} ⊙ exp(s(z_{1:d})) + t(z_{1:d})`，行列式为 `exp(Σ_i s_i)`，计算高效且非保体积、表达力更强；其多尺度架构逐段把部分变量因式分解出去，形成类似小波分解的层次表示。Glow（2018）用三个组件替代固定排列：ActNorm 做基于数据初始化的通道仿射归一化，1×1 可逆卷积学习通道间线性排列（用 LU 分解高效计算行列式），以及仿射耦合层，交替堆叠后在高分辨率人脸生成上表现逼真并支持平滑潜在插值。流模型的优点是精确似然、稳定训练、潜在空间可逆可编辑；缺点是架构约束强、计算与参数开销大。它在生成质量上已被扩散模型超越，但其耦合层被广泛用于记忆高效梯度计算与变分推断等场景。

**生成模型统一对比。** 各类生成模型在似然、稳定性、采样速度与模式覆盖上各有取舍，选择时应以任务需求为准。

| 维度 | 自回归 | 流模型 | VAE | GAN | 扩散 |
|:---|:---|:---|:---|:---|:---|
| 似然 | 精确 log p(x) | 精确 log p(x) | ELBO 下界 | 隐式 | ELBO/Score |
| 训练稳定性 | 很稳定 | 很稳定 | 较稳定 | 易不稳定 | 极稳定 |
| 采样速度 | 慢（串行） | 中等 | 快 | 很快 | 慢（多步） |
| 生成质量 | 良好 | 良好 | 有时模糊 | 很高 | 目前最佳 |
| 模式覆盖 | 较好 | 较好 | 好 | 差 | 极好 |
| 代表模型 | PixelCNN、WaveNet | NICE、Glow | VAE、VQ-VAE | StyleGAN | DDPM、SD |

选型时，需要精确概率密度评估（异常检测、压缩）可选自回归或流模型；需要快速且高质量图像生成可选 GAN 或蒸馏加速的扩散模型；文本生成用自回归（GPT 系列，见 §6.15）；潜在空间插值与编辑用流模型或 StyleGAN 的 W 空间；当前通用生成（图像/音频/视频）与条件可控生成则首选扩散模型（如 ControlNet）。

## 6.13 预训练与迁移

**迁移学习。** 从头训练大模型需要海量数据与算力，从相关任务或数据中迁移知识可大幅降低成本。传统做法是在 ImageNet 等大规模数据上预训练 (Pre-training)，再在目标任务上微调 (Fine-tuning)，这是 Transformer 出现前 CV 领域的主导范式。其有效性源于低层特征（边缘、纹理）是任务无关的，高层特征才是任务特定的。

**预训练-微调范式。** 该范式分为两阶段。预训练阶段在海量无标签或半标签数据上用自监督目标训练大模型：NLP 中常用语言模型（GPT）与掩码语言模型 (MLM, BERT)；CV 中常用有监督 ImageNet（ViT 之前）、对比学习 (Contrastive Learning, SimCLR、MoCo) 与掩码图像建模 (MIM, MAE)。微调阶段在标注的下游数据上适配预训练模型，通常添加任务特定头部 (Task-specific Head)（分类层、NER 的 CRF、QA 的 Span Predictor 等），并全参数微调 (Full Fine-tuning)。此外还派生领域适配（通用域预训练后到生物医学、法律等特定域微调，如 BioBERT、LegalBERT）与多任务微调。

**提示学习与参数高效微调。** 提示学习 (Prompt-based Learning) 弥合预训练目标与下游任务格式之间的鸿沟，把下游任务重新表述为语言建模问题，例如把情感分类写成 `"This movie is great. It was [MASK]."` 并预测 `[MASK]` 位置。提示工程可由人工设计模板、自动搜索离散 token 或连续向量，也可采用 GPT-3 风格的上下文学习 (In-Context Learning)，即在提示中提供少量示例而无需梯度更新。当全参数微调成本过高时，参数高效微调 (Parameter-Efficient Fine-Tuning, PEFT) 只训练极少参数，常见方法如下表（详见第 9 章 §9.17）。

| 方法 | 可训练参数 | 是否改结构 | 推理开销 | 代表 |
|:---|:---|:---|:---|:---|
| Full Fine-tuning | 100% | 仅加任务头 | 无额外 | BERT/GPT 全量微调 |
| Adapter | 3–5% | 插入瓶颈层 | 轻微增加 | Houlsby Adapter |
| Prefix-Tuning | <1% | 追加 Prefix 向量 | 无额外 | Prefix-Tuning |
| Prompt Tuning | <0.1% | 追加软提示 | 无额外 | Lester 等 |
| LoRA | 0.1–1% | 注入低秩矩阵 | 可合并、无开销 | LoRA、QLoRA |
| In-Context Learning | 0% | 无修改 | 无额外 | GPT-3/4 |

从适配机制看，预训练-微调需要梯度更新与中等规模标注数据，模型规模要求低，推理成本低但灵活性差（任务绑定）；PEFT 也需梯度更新但参数极少；上下文学习不需要梯度与标注，但要求模型规模极大（通常 >10B）且推理成本高（长提示），换来零样本任务切换能力。

**规模与涌现。** 模型规模增大时，少样本 (Few-shot) 与零样本 (Zero-shot) 性能显著提升；当规模超过某个阈值，会突然出现小模型完全不具备的涌现能力 (Emergent Abilities)，如算术推理、多步推理与指令遵循。这些现象大致遵循缩放定律 (Scaling Laws)：损失 L 与参数量 N、数据量 D、计算量 C 呈幂律关系 `L(N,D,C) ∝ N^{−α} + D^{−β} + C^{−γ}`，我们将在 §6.15 进一步讨论具体形式。

## 6.14 BERT 系列

**BERT。** 双向编码器表示 (Bidirectional Encoder Representations from Transformers, BERT)（Devlin 等，2018）使用纯 Transformer 编码器，base 版为 L=12、H=768、A=12 头、约 110M 参数，large 版为 L=24、H=1024、A=16 头、约 340M 参数。其核心洞察是双向上下文比 GPT 的单向自回归能捕捉更深层语义，但双向性意味着无法使用标准自回归语言建模，因而必须引入掩码语言模型 (Masked Language Model, MLM)。

**预训练目标。** MLM 随机遮蔽 15% 的 token，其中 80% 替换为 `[MASK]`、10% 替换为随机 token、10% 保持不变，目标是基于双向上下文预测原始 token；随机替换与保持不变的比例缓解了 `[MASK]` 在预训练出现而微调时不存在的预训练-微调不匹配 (Pretrain-Finetune Mismatch)。下一个句子预测 (Next Sentence Prediction, NSP) 输入句子对 (A,B)，其中 50% 为真实下一句、50% 为随机句，做二分类以学习句子级关系，对问答与自然语言推理至关重要。BERT 的输入表示为 `[CLS] + A + [SEP] + B + [SEP]`，叠加 token 嵌入、区分 A/B 的 segment 嵌入与 position 嵌入。微调时只需在 `[CLS]` 上加分类头做句子级任务，或用每个 token 的输出做 NER、QA 等 token 级任务。下表给出 BERT 在 GLUE 基准上的表现。

| 模型 | 参数量 | MNLI-m | QQP | SST-2 | CoLA | GLUE 平均 |
|:---|:---|:---|:---|:---|:---|:---|
| BERT_base | 110M | 84.6 | 71.2 | 93.5 | 52.1 | 79.6 |
| BERT_large | 340M | 86.7 | 72.1 | 94.9 | 60.5 | 82.1 |

BERT 的预训练流程可概括为：对 BooksCorpus 与 Wikipedia（约 16GB）做 WordPiece 分词得到 30K 词表，构造 `[CLS]+A+[SEP]+B+[SEP]` 输入并叠加三类嵌入，随机遮蔽 15% token，送入多层双向 Transformer 编码器，最后由 MLM 头与 NSP 头联合优化 `L = L_MLM + L_NSP`。

**RoBERTa。** RoBERTa（Liu 等，2019）的核心发现是 BERT 严重训练不足，通过优化训练配方即可大幅提升性能。其改动包括：移除 NSP（发现其无益甚至有害）；改用跨文档边界的完整句子而非句子对；从静态 mask 改为动态 mask，每个 epoch 生成不同遮蔽；把训练数据从 16GB 扩到 160GB（增加 CC-News、OpenWebText、Stories）；把批大小从 256/1024 提高到 8K，训练步数从 1M 减到 500K；分词从字符级 BPE（30K 词表）改为字节级 BPE（50K 词表）。改进后 RoBERTa 在所有基准上匹配或超越 BERT，尤其在生成式任务和大数据场景下表现突出。

**ALBERT。** ALBERT（Lan 等，2019）针对 BERT 参数量过大提出两项削减技术：因式分解嵌入参数化 (Factorized Embedding Parameterization) 把 `V×H` 嵌入矩阵分解为 `V×E` 与 `E×H`（E≪H），例如把 V=30000、H=768 的 23M 嵌入参数在 E=128 时降到约 4M；跨层参数共享 (Cross-Layer Parameter Sharing) 让所有 Transformer 层共享同一组 Attention 与 FFN 参数。此外它用句子顺序预测 (Sentence Order Prediction, SOP) 替代 NSP，要求判断两个连续段落顺序是否正确，比主题判断式的 NSP 更具话语级推理难度。ALBERT-xxlarge（235M、12 层）以比 BERT-large（340M、24 层）少约 30% 的参数取得更好成绩，但跨层共享不减少 FLOPs，推理计算量并未降低。BERT 系列还有多个领域/语言特化变体：BioBERT（生物医学文献）、SciBERT（科学文本）、ClinicalBERT（临床病历）、mBERT（104 种语言共享词表、支持跨语言迁移）以及用知识蒸馏得到的 DistilBERT（小 40%、快 60%、保留 97% 性能）。

## 6.15 GPT 系列

**核心哲学。** GPT 系列从 GPT-1/2 的"生成式预训练加任务特定微调"演进到 GPT-3 的"语言模型即少样本学习器"，再到 GPT-4 的"多模态通才"。其本质驱动是更大的模型、更多数据与更多算力共同催生越来越强的涌现能力。

**GPT-1 与 GPT-2。** GPT-1（Radford 等，2018）用 12 层 Transformer 解码器（约 117M 参数），在 BooksCorpus（约 5GB）上做标准自回归语言建模 `L_pre = −Σ_i log P(x_i|x_{<i})`，微调时在顶部加任务特定线性分类层并端到端更新全部参数，首次系统建立了 NLP"大规模无监督预训练加有监督微调"的标准范式。GPT-2（2019）把规模扩大到 48 层、1.5B 参数，训练数据为约 40GB 的 WebText（从 Reddit 高赞外链抓取、刻意不含维基百科以便测试），主张语言模型可在零样本条件下完成下游任务、无需微调，只需通过 prompt 指引；当模型足够大且数据足够多样时，多任务学习会隐式发生在语言建模目标中。它以 `"Translate to French: [text] =>"` 之类格式做零样本迁移，在阅读理解、翻译、摘要、问答上展现竞争力。OpenAI 最初因担心被滥用仅发布较小版本，后全部发布。

**GPT-3 与上下文学习。** GPT-3（Brown 等，2020）采用 96 层 Transformer 解码器、175B 参数（`d_model=12288`、96 个头，激活为 GELU 的 Swish 变体），从 125M 到 175B 共 8 个规模变体用于研究缩放行为。训练语料经过滤后约 570GB，混合比例为 Common Crawl 60%、WebText2 22%、Books1+Books2 16%、Wikipedia 3%。其核心创新是上下文学习 (In-Context Learning)：不更新任何模型参数，仅通过 prompt 中的示例指导行为，分零样本（仅任务描述）、单样本（1 个示例）与少样本（K 个示例，通常 10–100 个，受上下文窗口限制）三种模式，性能随示例数提升。在 175B 规模下，GPT-3 展示出算术推理、未专门训练的翻译、代码生成与常识推理等涌现能力。其局限包括幻觉 (Hallucination)、知识时效性受限、上下文窗口仅 2048 token、意图对齐差以及可能生成有害内容。

**InstructGPT 与 ChatGPT。** GPT-3 虽强却不遵循用户意图。InstructGPT（Ouyang 等，2022）用基于人类反馈的强化学习 (Reinforcement Learning from Human Feedback, RLHF) 对齐（见第 7 章 §7.10），三阶段流程为：先用标注员撰写的高质量对话演示做监督微调 (SFT)；再对同一 prompt 的多个回答按质量排序训练奖励模型 (RM)；最后用奖励模型打分作为信号，通过近端策略优化 (PPO) 优化策略模型。效果上，1.3B 的 InstructGPT 在遵循指令方面显著优于 175B 的 GPT-3，且"对齐税"极小。ChatGPT（2022.11）基于 GPT-3.5 系列并用对话格式做 RLHF 训练，引爆全球大模型热潮。

**GPT-4。** GPT-4（2023）技术细节未公开，标志前沿大模型研发走向闭源。它支持文本加图像的多模态输入，推理能力显著提升，事实准确性与可控性安全性改进，上下文窗口扩展到 8K/32K。其在统一律师资格考试进入前 10%、SAT 数学与阅读写作接近满分、竞赛编程超越多数人类选手、医疗执照考试高分通过。业界普遍推测其采用混合专家 (Mixture of Experts, MoE) 架构。

**缩放定律。** 缩放定律刻画了模型性能与规模之间的定量关系。Kaplan 等（OpenAI, 2020）发现交叉熵损失 L 与参数量 N、数据量 D 之间呈幂律 `L(N) = (N_c/N)^{α_N}`、`L(D) = (D_c/D)^{α_D}`（α_N≈0.076、α_D≈0.095），并结论：固定计算预算下应大幅增加模型规模、数据量增长较慢，最优训练时 tokens 与 parameters 约呈 1:1，且 `N_opt ∝ C^{0.73}`、`D_opt ∝ C^{0.27}`。Chinchilla（DeepMind, 2022）修正了这一结论，认为应同等增加模型规模与数据量，最优配比约为 `tokens ≈ 20 × parameters`，即 `N_opt ∝ C^{0.50}`、`D_opt ∝ C^{0.50}`。实验上，70B 参数、训练 1.4T token 的 Chinchilla 在几乎所有下游任务上超越 280B 参数、仅训练 300B token 的 Gopher，且推理成本更低。这揭示当时多数大模型（包括 GPT-3）其实训练不足，应平衡模型缩放与数据缩放，后续 Llama、Falcon 等开源模型均遵循 Chinchilla 法则。GPT 系列的整体脉络可概括为：从"更大的模型"（GPT-1→2→3）到"更聪明的训练"（RLHF），再到"多模态通才"（GPT-4），并伴随开源到闭源的转变。

## 6.16 视觉预训练

**背景。** 在 Transformer 进入视觉领域之前，CNN 主导 CV，ImageNet 监督预训练是标准范式。Transformer 在 NLP 的成功引发"能否用 Transformer 处理视觉"的思考，由此催生了一批视觉预训练模型。

**ViT。** 视觉 Transformer (Vision Transformer, ViT)（Dosovitskiy 等，2020）的核心思想是把图像 patch 视作 token，直接套用标准 Transformer 编码器。处理流程为：把 `224×224` 图像切成 `16×16` 的 patch，得到 `14×14=196` 个 token，每个经线性投影映射为 768 维向量；添加 `[CLS]` token 与可学习位置编码后送入 Transformer 编码器，取 `[CLS]` 输出做分类。关键发现是数据量足够大时（ImageNet-21K、JFT-300M）ViT 达到甚至超越 CNN，但在中小规模数据上落后，因为缺少归纳偏置 (Inductive Bias)：相比 CNN 它没有平移等变性与局部性，却拥有更灵活的全局注意力。Hybrid ViT 用 CNN 特征图代替原始 patch 作为 token，兼顾 CNN 的局部性与 Transformer 的全局性。重要变体中，DeiT 用 CNN 教师网络做知识蒸馏，无需大规模预训练数据即可训练 ViT；Swin Transformer 采用层次化结构与移位窗口注意力，复杂度线性、类似 CNN 金字塔，适合密集预测。

**MAE。** 掩码自编码器 (Masked Autoencoder, MAE)（He 等，2021）是视觉版的 BERT，采用非对称编码器-解码器：编码器只处理可见 patch（约 25%），极大提升效率；轻量解码器输入可见 patch 编码与掩码 token，重建完整图像。其掩码比例高达 75%（远超 BERT 的 15%，因为图像有大量空间冗余），预训练目标是在掩码区域做像素级重建，损失为

$$\mathcal{L}_{\text{MAE}} = \frac{1}{|M|}\sum_{i\in M}\|\mathbf{x}_i - \hat{\mathbf{x}}_i\|^2,$$

其中 M 为被掩码的 patch 集合。非对称设计使预训练非常高效，下游微调性能强劲。

**DINO。** DINO（Caron 等，2021）通过教师-学生知识蒸馏做自监督学习，两者架构相同（均为 ViT），教师不做梯度反传而用指数移动平均更新 `θ_t ← λθ_t + (1−λ)θ_s`，学生学习匹配教师的输出分布。避免坍塌的关键技巧是 Multi-crop（同时使用大尺寸全局视图与小尺寸局部视图）以及 Centering 加 Sharpening（对教师输出中心化防止维度坍塌，对学生输出锐化防止均匀分布坍塌）。DINO 训练的 ViT 会出现惊人特性：注意力图自动涌现语义分割能力，`[CLS]` token 的注意力无需任何监督即可勾勒物体边界。DINOv2 规模化后产出通用视觉特征，匹敌甚至超越弱监督特征。

**其它范式与趋势。** 视觉自监督还包括：MoCo v3 用动量编码器加动态队列适配 ViT 做对比学习；BEiT 先用离散 VAE 把图像 token 化再做掩码 token 级预测；SimMIM 以随机掩码加轻量线性预测头直接回归像素值；CLIP 用图文对比学习引入文本监督（见第 10 章 §10.9）。下表对各范式做横向比较。

| 维度 | 监督预训练 | 对比学习 | 掩码图像建模 | 自蒸馏 |
|:---|:---|:---|:---|:---|
| 监督信号 | 类别标签 | 样本自身增强 | 像素重建 | 教师输出分布 |
| 数据需求 | 需标注 | 无需标注 | 无需标注 | 无需标注 |
| 代表工作 | ViT-JFT | MoCo v3 | MAE、BEiT | DINO、DINOv2 |
| 典型下游 | 分类 | 分类/检测 | 分类/检测/分割 | 分类/语义分割 |
| 计算效率 | 中 | 需大 batch/队列 | 高（MAE 仅 25% patch） | 中（需 multi-crop） |

总体趋势是 NLP 与 CV 在 Transformer 架构上加速融合：ViT 把 BERT 的 token 化思想引入视觉，MAE 直接借鉴 BERT 的掩码建模范式，DINO 体现自蒸馏的独特价值，视觉预训练正从"有监督 ImageNet"走向"自监督加大数据加 Transformer"。

## 6.17 模型压缩

**动机。** 现代大模型参数量可达数百亿乃至万亿级，推理时占用大量显存、算力与功耗，难以直接部署到边缘设备或移动终端。压缩目标是在尽量保持精度的前提下降低模型体积、推理延迟与能耗，典型效果是从 GB 级压到 MB 级、推理速度提升 2–10 倍。

**量化。** 量化 (Quantization) 把权重或激活从 32 位浮点 (FP32) 降到 INT8、INT4 甚至二值等低位宽表示，其收益包括约 4 倍内存缩减、整数运算加速（INT8 GEMM 吞吐可达 FP32 的 2–4 倍）以及更低的功耗（整数运算能耗约为浮点的十分之一）。量化的三要素是缩放因子 (Scale) `s = (r_max−r_min)/(q_max−q_min)`、零点 (Zero Point) `z = q_min − round(r_min/s)` 以及量化/反量化 `q = round(r/s)+z`、`r̂ = s(q−z)`。按训练时机可分为后训练量化 (Post-Training Quantization, PTQ) 与量化感知训练 (Quantization-Aware Training, QAT)：

- PTQ 无需重训，仅用少量校准数据（100–1000 样本）统计量化参数，范围校准可选 Min-Max（对异常值敏感）、Percentile（截断尾部）或基于 MSE/KL 的搜索；
- QAT 在训练中插入伪量化节点模拟误差，反向用直通估计器 (Straight-Through Estimator, STE) 把 `round` 的梯度视为恒等映射，精度更高但需完整训练管线。

量化粒度上，Per-Tensor 粒度最粗、实现最简单，Per-Channel 每个输出通道独立参数、精度更高且主流硬件广泛支持，Group-wise 进一步分组量化、精度更高但更复杂。量化对象可分仅量化权重与权重激活都量化。极端量化包括 INT4/NF4、二值网络（权重取 ±1，把乘法简化为位运算）与三值网络（权重取 −1/0/+1，引入稀疏性）。下表汇总 LLM 量化实战方法。

| 方法 | 技术特点 | 典型场景 |
|:---|:---|:---|
| GPTQ | 逐列量化 + 按 Hessian 补偿误差 | 4-bit 权重、GPU 推理 |
| AWQ | 识别显著激活对应通道并保留高位精度 | 4-bit 推理、TinyChat |
| GGUF/GGML | 2–8 bit 混合精度格式 | llama.cpp/Ollama，CPU/Mac |
| bitsandbytes | NF4 加双重量化 | QLoRA 微调 |
| LLM.int8() | 混合精度，异常值用 FP16 | HuggingFace INT8 推理 |

**剪枝。** 剪枝 (Pruning) 移除不重要的权重或神经元以获得稀疏模型，核心是如何度量重要性。幅度剪枝 (Magnitude Pruning) 假设小权重贡献可忽略，训练收敛后按剪枝率确定阈值、将小于阈值的权重置零得到掩码，再可选微调恢复精度。按粒度分为非结构化剪枝（独立裁剪每个权重，压缩率高但需专用稀疏硬件）与结构化剪枝（裁剪整个神经元、卷积核、通道或注意力头，硬件直接兼容、缩小矩阵维度）。NVIDIA Ampere/Ada 支持的 2:4 结构化稀疏属于二者的折中。按策略分为一次性（剪枝后微调，高剪枝率易永久损失）、迭代式（剪枝与微调交替）与渐进式幅度剪枝（训练中按 schedule 逐步提高稀疏度，效果最好）。彩票假设 (Lottery Ticket Hypothesis)（Frankle & Carbin, 2019）指出，随机初始化稠密网络中潜藏稀疏子网络（中奖彩票），若以原始初始权重恢复并独立训练可达到原网络性能，说明过度参数化并非必需、大网络的价值在于包含更多潜在中奖彩票；结合权重倒回 (Rewinding) 可在训练早期 checkpoint 恢复权重、提高命中率。

**知识蒸馏。** 知识蒸馏 (Knowledge Distillation) 训练小模型（学生）模仿大模型（教师）的预测。教师提供的软标签 (Soft Labels) 是各类别概率分布，比 one-hot 硬标签携带更丰富信息。温度软化 Softmax `p_i^T = exp(z_i/T)/Σ_j exp(z_j/T)` 在 T>1 时平滑分布、揭示类间相似性，例如告诉学生"3 与 8 比 3 与 2 更相似"。蒸馏损失为

$$L = \alpha \mathcal{L}_{\mathrm{CE}}(y_s, y_{\text{true}}) + (1-\alpha) T^2 D_{\mathrm{KL}}\left(p_t^T \parallel p_s^T\right),$$

其中第一项保持真实标签约束，第二项对齐软分布，α 平衡二者，`T²` 补偿温度升高导致的梯度缩小。按教师来源可分为离线（教师先训好再蒸，最常见）、在线（师生同时从零训练，如互学习）与自蒸馏（网络用自身历史预测或深层指导浅层）。特征蒸馏以 FitNets 为代表，学生不仅学输出还学教师中间层特征表示，常用两步法先初始化浅层再整体蒸馏；关系蒸馏则要求学生保持教师样本间的关系结构，如 RKD 保留距离或角度关系、CRD 用对比学习最大化师生表示互信息，对检测与分割等结构化输出任务效果突出。

**其它压缩技术。** 低秩分解把权重矩阵 `W ≈ U_{m×k} V_{k×n}`（k≪min(m,n)）使参数量从 mn 降到 k(m+n)，常用 SVD 截断最小奇异值。参数共享包括 ALBERT 的跨层共享与输入输出 embedding 权值绑定 (Weight Tying)。面向效率的神经架构搜索 (NAS) 自动寻找精度-效率最优结构，代表有使用深度可分离卷积的 MobileNet、复合缩放的 EfficientNet 以及以移动端延迟为奖励的 MnasNet。下表给出压缩方法的综合对比。

| 方法 | 压缩原理 | 压缩比 | 精度损失 | 训练成本 | 硬件要求 |
|:---|:---|:---:|:---:|:---|:---|
| PTQ(INT8) | 降低数值精度 | 4× | 极低 | 零（仅校准） | 标准 INT8 |
| QAT(INT8) | 训练中模拟量化 | 4× | 几乎无损 | 完整训练 | 标准 INT8 |
| AWQ/GPTQ(INT4) | 4-bit 权重量化 | 8× | 低 | 校准加重建 | GPU/CPU |
| 非结构化剪枝 | 独立权重置零 | 2–10× | 低 | 微调可选 | 需稀疏硬件 |
| 结构化剪枝 | 移除通道/头 | 1.5–3× | 中等 | 多次迭代微调 | 标准硬件 |
| 知识蒸馏 | 大模型教小模型 | 10–100× | 中高 | 需教师加学生 | 标准硬件 |
| 低秩分解 | 矩阵分解 | 2–3× | 中等 | 微调 | 标准硬件 |

选型上，最小成本方案是 PTQ(INT8)，几乎是"免费午餐"且主流推理框架均支持；LLM 本地部署用 AWQ(GPU) 或 GGUF(CPU/Mac) 的 4-bit 量化；跨架构压缩用知识蒸馏；追求通用部署则用结构化剪枝加微调。现代实践中常叠加多种技术——先用 QAT 训出高精度模型，再结构化剪枝并微调，最后 PTQ 量化到 INT8——以逼近精度-效率的帕累托最优。

## 6.18 推理优化

**动机。** 面向用户的推理延迟至关重要，图级与算子级优化与 §6.17 的模型级压缩互补，共同提升部署吞吐与响应速度。

**计算图优化。** 计算图优化是在保持语义不变的前提下改善执行效率的 IR 级变换，主要包括：常量折叠 (Constant Folding) 预先计算输入全为编译期常量的子图，例如把 BatchNorm 参数在推理时折叠进前一层卷积 `y = w(x−μ)/σ + b → y = w'x + b'`；死代码消除 (DCE) 删除输出从未被消费的运算；代数化简消除 `x+0`、`x×1`、连续转置/重塑、成对 squeeze/unsqueeze 等冗余；公共子表达式消除 (CSE) 识别并去重多分支中的相同计算；内存布局优化为硬件选择最优张量布局（NCHW 与 NHWC），并在消费者不匹配处插入 `layout_transform`。

**算子融合。** 算子融合 (Operator Fusion) 的动机是内存带宽常常是主瓶颈，把多个算子合并为单个 GPU kernel 可使中间张量不出片上内存，从而减少读写与 kernel 启动开销。典型模式见下表。

| 融合模式 | 原始算子 | 收益 |
|:---|:---|:---|
| Conv-BN-ReLU | Conv→BN→ReLU | BN 折进卷积权重，ReLU 作原位后处理 |
| 注意力融合 | Q·Kᵀ→Softmax→×V | 单 kernel（FlashAttention），显存 O(N²)→O(N) |
| MatMul-Bias-Act | MatMul→Add→GELU | 偏置在 epilogue 加、激活在寄存器算 |
| 逐元素链 | Add→Mul→Tanh→… | 单次遍历数据、无中间缓冲 |
| LayerNorm+Dropout | LayerNorm→Dropout | kernel 启动从 2 降到 1 |

TensorRT、XLA、TVM、ONNX Runtime 等框架都能自动完成不同程度的融合。

**内存优化。** 内存优化手段包括：激活重计算 (Activation Checkpointing) 只保存部分中间激活、反向时重算其余部分，以约 20–30% 额外计算换取显著显存节省，从而支持更大批或更长序列；内存规划 (Memory Planning) 预分配全局内存池并复用生命周期已结束的缓冲，降低碎片与分配开销；原位操作 (In-place Operations) 在张量原值不再使用时直接原地修改，激活函数、Dropout 掩码与逐元素运算都是天然候选。

**低精度推理。** 降低数值精度可在几乎不损精度的前提下提升吞吐。FP16（5 位指数、10 位尾数）相比 FP32 约有 2 倍吞吐与一半显存，但数值范围窄、大激活可能溢出；BF16（8 位指数、7 位尾数）与 FP32 同指数范围、无溢出之虞，尾数精度较低但多数负载可接受，广泛用于 TPU 与 A100/H100；INT8 在 Tensor Core 上可达 FP32 的约 4 倍吞吐，需配合缩放与零点；FP8 的 E4M3（精度高，适合权重激活）与 E5M2（动态范围宽，适合梯度）在 H100 上约为 FP16 的 2 倍。混合精度 (Mixed Precision) 对不同算子选用不同精度，例如注意力分数用 FP16、LayerNorm/Softmax 用 FP32 以保证数值稳定，主权重保持 FP32。各精度对比如下。

| 精度 | 位宽 | 指数 | 尾数 | 相对 FP32 吞吐 | 硬件 |
|:---|:---:|:---:|:---:|:---:|:---|
| FP32 | 32 | 8 | 23 | 1× | 所有 GPU |
| FP16 | 16 | 5 | 10 | ~2× | Volta+ Tensor Core |
| BF16 | 16 | 8 | 7 | ~2× | A100/H100/TPU |
| INT8 | 8 | — | — | ~4× | Turing+ Tensor Core |
| FP8(E4M3) | 8 | 4 | 3 | ~4× vs FP16 | H100 |

**推理引擎与 LLM 优化。** 专用推理引擎封装了上述优化：NVIDIA TensorRT 提供图优化、kernel 自动调优、INT8/FP8 校准与插件系统；ONNX Runtime 跨平台并通过 Execution Provider 适配多种后端；OpenVINO 针对 Intel CPU/VPU；CoreML 面向 Apple Neural Engine；TFLite/MediaPipe 面向移动端；vLLM 用 PagedAttention 管理 KV Cache 并支持连续批处理；TensorFlow Serving/Triton 面向生产服务。针对 LLM 还有专门优化：KV Cache 缓存所有已生成 token 的 Key/Value 投影避免重复计算，其显存随序列长度线性增长，是长上下文的主要瓶颈；连续批处理 (Continuous Batching) 让请求在 token 生成边界动态加入与退出，显著提升 GPU 利用率；推测解码 (Speculative Decoding) 用小的草稿模型预测 K 个候选、由大模型并行验证，接受匹配 token、丢弃分歧 token，可得 2–3 倍加速且输出分布不变；量化 KV Cache 用 INT8/FP8 存储减少 2–4 倍显存，支持更长上下文。

## 6.19 分布式训练

**动机。** 现代大模型参数量超 100B，单卡显存远不够用；训练数据达 TB 级，单卡训练耗时不可接受。算力与显存需求双双远超单卡，分布式训练成为必由之路。

**数据并行。** 数据并行 (Data Parallelism, DP) 让每个 GPU 持有完整模型副本，把 mini-batch 切分到各卡：各卡独立前向与反向得到本地梯度 `∇L_k`，通过 all-reduce 汇总 `∇L = (1/N)Σ_k ∇L_k`，再用相同梯度同步更新参数。All-reduce 常用 Ring 算法（GPU 组成逻辑环、2(N−1) 步完成、带宽最优）或 Tree 算法（适合层次化拓扑）。梯度累积 (Gradient Accumulation) 在 K 个 micro-batch 上累积梯度后再 all-reduce，等效放大批大小 K 倍。数据并行的局限是每卡必须存完整模型与优化器状态（Adam 约需约 2 倍参数量的状态），不减少单卡显存压力。PyTorch 的 DistributedDataParallel (DDP) 在反向阶段异步启动梯度 all-reduce，把通信与下一层计算重叠，效率远高于单机 DataParallel。

**模型并行。** 模型并行把模型层或单层参数矩阵切分到不同 GPU。朴素纵向并行让不同 GPU 持有不同层，激活依次流过，但任一时刻只有一张卡在工作、利用率极低。张量并行 (Tensor Parallelism, TP) 对矩阵乘 `Y = XW` 把 W 按列（或按行）切分；按列切分时各卡计算部分输出后拼接，按行切分时需先对 X 做列切分再 all-reduce 汇总。自注意力层可按头切分，把 h 个头分到 N 张卡各算 h/N 个，最后 all-reduce 合并。Megatron-LM 是专为 Transformer 设计的张量并行方案，在 MLP 与自注意力两处插入同步点以最小化通信。

**流水线并行。** 流水线并行 (Pipeline Parallelism, PP) 把模型按层切成连续 P 个 stage 分到 P 张卡，再把 mini-batch 切成 M 个 micro-batch 形成流水线。流水线的启动与排空阶段会造成 GPU 空闲，即气泡 (Bubble)，约占总时间的 `(P−1)/(P+M−1)`。GPipe 让所有 micro-batch 先完成前向再统一反向，气泡随 M 增大而减小，但需缓存所有中间激活（可用激活重计算缓解）；PipeDream 的 1F1B 调度让前向与反向交替进行（做完 1 个前向立即做 1 个反向），气泡更小且激活缓存更少，但调度复杂；交错流水线让每张卡持有多个不连续的 stage，进一步打散气泡。

**三维混合并行与 ZeRO。** 三维混合并行同时使用 DP、TP 与 PP：以 Megatron-Turing NLG 530B 为例，节点内 8 张 GPU 用 NVLink 做张量并行（通信频繁、带宽要求高），跨节点用流水线并行（层间通信量小），再把整组复制到多个数据分片组做数据并行（组间 all-reduce 梯度）。ZeRO (Zero Redundancy Optimizer) 则从另一个角度消除冗余：标准数据并行中每卡都存有相同的优化器状态、梯度与参数，三者都冗余。ZeRO-1 只分片优化器状态，节省约 4 倍内存；ZeRO-2 连梯度也分片，节省约 8 倍；ZeRO-3 连参数也分片，使显存随 GPU 数量线性扩展，前向计算某层时 all-gather 该层完整参数、算完立即释放，反向时再次 all-gather。ZeRO-Offload 把优化器状态与计算卸载到 CPU 内存，ZeRO-Infinity 进一步卸载到 NVMe SSD，使理论上可训练万亿参数模型。FSDP (Fully Sharded Data Parallel) 是 PyTorch 原生的 ZeRO-3 实现，把参数展平分片，按需 all-gather 并在反向结束后 reduce-scatter 梯度，其 sharding strategy 可选 FULL_SHARD、HYBRID_SHARD、SHARD_GRAD_OP。

**通信原语与收敛性。** 分布式训练依赖若干集合通信原语，见下表。

| 通信原语 | 含义 | 示例 |
|:---|:---|:---|
| All-Reduce | 所有卡求和/求均值后广播回所有卡 | 梯度聚合 |
| All-Gather | 各卡数据拼接后广播给所有人 | ZeRO-3 收集参数 |
| Reduce-Scatter | 先求和再按卡分发不同分片 | ZeRO-2/3 梯度分片 |
| Broadcast | 一张卡的数据复制到所有卡 | 参数初始化分发 |
| Point-to-Point | 两张卡之间直接传输 | 流水线层间传输 |

常用通信后端中，NCCL 面向 NVIDIA GPU 集群并针对 NVLink、InfiniBand 优化，是 DP/TP/PP 的首选；Gloo 适用于 CPU 或跨平台；MPI 用于超算与传统 HPC。大规模训练的收敛性方面，大批量训练会降低梯度随机性，常配合线性缩放规则 `lr = η₀ B_new/B_base`（批大小增大 k 倍则学习率近似乘 k）、逐层自适应的 LARS/LAMB 以及预热加衰减。同步 SGD 等待所有卡梯度到齐再更新，数学上等价于大批量 SGD、收敛稳定但受慢节点 (Straggler) 拖累；异步 SGD 基于参数服务器，worker 直接 push 梯度、pull 最新参数，无需同步屏障、速度快，但各 worker 拿到的是陈旧梯度 (Stale Gradients)，可能不稳定，需限制 staleness 或做梯度补偿。综合对比如下。

| 并行策略 | 显存效率 | 通信开销 | 扩展性 | 典型框架 |
|:---|:---|:---|:---|:---|
| 数据并行 | 每卡完整模型 | 低 | 中等 | DDP、Horovod |
| 张量并行 | 单层切分 | 极高 | 低（通常 ≤8 卡） | Megatron-LM |
| 流水线并行 | 按层切分 | 低 | 中等 | GPipe、PipeDream |
| ZeRO-3/FSDP | 线性扩展 | 中等 | 高 | DeepSpeed、FSDP |
| 三维混合 | 最优 | 综合 | 最高 | Megatron+DeepSpeed |

实践建议是：小模型（<1B）多卡直接用 DDP；中等模型（1B–10B）用 FSDP 或 ZeRO-2 加梯度累积；大模型（10B–100B）用 ZeRO-3 加节点内张量并行；超大规模（>100B）用三维混合并行。
