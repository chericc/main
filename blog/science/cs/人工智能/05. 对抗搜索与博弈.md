# 第 5 章 对抗搜索与博弈（Adversarial Search and Games）

**本章导读**：当环境里还有别的智能体，而且它们的目标与你相反时，搜索就从"找路径"变成"算策略"。本章先给出博弈的形式化与均衡概念，再依次讨论极小极大、α-β 剪枝、蒙特卡洛树搜索、随机博弈与不完全信息博弈，最后说明博弈搜索的边界。这里的算法是 AlphaGo/AlphaZero 一类系统的骨架。

**学习目标**：完成本章学习后，你应当能够：

- 用形式化七元组描述一个博弈，区分零和与非零和、完全与不完全信息；
- 写出极小极大算法并证明其在零和完全信息博弈中的最优性；
- 推导 α-β 剪枝的最优与最坏复杂度，说明走法排序的作用；
- 说明 MCTS 的四个阶段与 UCB1 公式，解释它为何不依赖评估函数；
- 把随机博弈写成期望极小极大（expectiminimax）；
- 说明地平线效应、评估函数依赖与不完全信息带来的根本困难。

**预备知识**：第 3 章的树搜索与复杂度；纳什均衡的基本概念（§18.2 会展开）；概率期望。

## 5.1 博弈论

**博弈的形式化**。一个（扩展式）博弈可由以下要素刻画：

| 要素 | 含义 |
| --- | --- |
| 玩家 $N = \{1,\dots,n\}$ | 参与者集合 |
| 状态 $S$ | 局面集合，含初始状态 $s_0$ |
| 行动 $A(s)$ | 轮到行动的玩家可选的走法 |
| 转移 $s' = f(s,a)$ | 确定性博弈中的结果 |
| 终局与收益 $u(s)$ | 终局时各玩家的效用向量 |
| 轮到谁 $\text{Player}(s)$ | 行动权归属 |
| 信息 | 玩家能观察到多少历史 |

**零和博弈**：对所有终局 $s$，$\sum_i u_i(s) = 0$，即一方所得即另一方所失。棋类、球类、拍卖中的"分配"多数可建模为零和或常和博弈。零和时只需优化单个数值（自己的效用），这是极小极大可行的前提。

**策略与均衡**。**纯策略**是"每个信息集选一个动作"的完整计划；**混合策略**是纯策略上的概率分布。**纳什均衡**是一组策略，任何玩家单独偏离都不能获益：

$$\forall i,\ \forall s_i': \ u_i(\sigma_i^*, \sigma_{-i}^*) \ge u_i(s_i', \sigma_{-i}^*)$$

**占优策略（dominant strategy）**：无论对手怎么做都是最优的策略。存在占优策略时均衡易求；否则需迭代消除劣策略或解线性规划。

经典模型是**囚徒困境**：双方都有占优策略（背叛），但（合作，合作）对双方都更好。它说明**个体理性不等于集体最优**，也是第 18 章集体决策的起点。重复博弈中，"以牙还牙"（tit-for-tat）可通过触发式策略维持合作。

**博弈的复杂度**。国际象棋的状态数约 $10^{47}$，围棋约 $10^{170}$，而可观测宇宙的原子数约 $10^{80}$。**穷举在原理上不可能**，因此所有实用算法都必须做三件事之一：剪枝（忽略不影响结果的分支）、近似（用评估函数估计非终局）、采样（只探索部分分支）。

## 5.2 博弈中的最优决策

**极小极大值（minimax value）**。对玩家 MAX 而言，状态 $s$ 的价值是：

$$\text{MINIMAX}(s) = \begin{cases} \text{UTILITY}(s), & s \text{ 为终局} \\ \max_{a} \text{MINIMAX}(\text{RESULT}(s,a)), & \text{MAX 行动} \\ \min_{a} \text{MINIMAX}(\text{RESULT}(s,a)), & \text{MIN 行动} \end{cases}$$

**最优策略**：对每个状态选使极小极大值最大的动作。注意这是**针对完美对手**的策略——它最大化最坏情况下的收益（maximin），因此是稳健的，但可能比针对弱对手的最优策略保守。

**算法**是对博弈树的后序遍历，时间 $O(b^m)$、空间 $O(bm)$（深度优先）。$b=35$、$m=100$ 的国际象棋需要 $10^{154}$ 个节点，因此必须截断。

**截断与评估函数**。在深度 $d$ 处停止，用**评估函数** $\text{EVAL}(s)$ 估计非终局的价值：

$$\text{H-MINIMAX}(s,d) = \begin{cases} \text{EVAL}(s), & d = 0 \\ \text{UTILITY}(s), & s \text{ 终局} \\ \max_a \text{H-MINIMAX}(\text{RESULT}(s,a), d-1), & \text{MAX} \\ \min_a \cdots, & \text{MIN} \end{cases}$$

评估函数的设计原则：

1. **与胜率单调相关**：如国际象棋的子力价值（兵 1、马 3、车 5、后 9）；
2. **特征加权**：$\text{EVAL}(s) = \sum_i w_i f_i(s)$，权重可由人类经验、自我对弈回归（第 19 章）或神经网络学习（§21.8）；
3. **计算要快**：评估被调用数百万次，常数因子比理论精度更重要。

**地平线效应（horizon effect）**：截断深度处恰好掩盖了对手的致命反击，导致评估严重失真。对策包括：静态搜索（quiescence search，只扩展"吃子/将军"等激烈走法）、延展（extension）、以及用 MCTS 替代固定深度。

## 5.3 启发式 α-β 树搜索

α-β 剪枝的核心思想：**一旦某个分支已经差到不可能被选中，就不必再算它**。

**两个边界**：

- $\alpha$：MAX 在路径上已确保的最小值（下界）；
- $\beta$：MIN 在路径上已确保的最大值（上界）。

遍历中若 $\alpha \ge \beta$，则该节点剩余分支可剪去。

```
function ALPHA-BETA(s, α, β, maximizing):
    if 终局(s): return UTILITY(s)
    if maximizing:
        v ← -∞
        for a in ACTIONS(s):
            v ← max(v, ALPHA-BETA(RESULT(s,a), α, β, false))
            if v ≥ β: return v            # β 剪枝
            α ← max(α, v)
        return v
    else:
        v ← +∞
        for a in ACTIONS(s):
            v ← min(v, ALPHA-BETA(RESULT(s,a), α, β, true))
            if v ≤ α: return v            # α 剪枝
            β ← min(β, v)
        return v
```

**复杂度**：

| 情形 | 时间复杂度 | 有效深度倍数 |
| --- | --- | --- |
| 最坏（走法排序最差） | $O(b^m)$，与极小极大相同 | 1× |
| 最好（走法排序最优） | $O(b^{m/2})$ | 2× |

$O(b^{m/2})$ 意味着**同等时间可以搜两倍深**——这是 α-β 的全部价值。因此**走法排序**（先试最可能好的走法）是工程核心：历史启发、杀手走法（killer moves）、置换表（transposition table）都是为此服务。

**置换表**：不同走法序列可能到达同一局面（换位），用哈希表缓存已算过的局面值可大幅节省。这是现代棋类引擎的标准组件。

**其他增强**：空着裁剪（null-move pruning）、后期着法裁剪（late move reduction）、迭代加深（先浅搜得到走法排序）。这些技巧使国际象棋引擎的实际有效分支因子降到 2 左右。

## 5.4 蒙特卡洛树搜索

当分支因子巨大、评估函数难以设计（围棋）时，**蒙特卡洛树搜索（MCTS）** 用随机模拟代替深度评估。

**四个阶段**（每次迭代）：

1. **选择（selection）**：从根沿"已被证明有希望"的路径下行，用 **UCB1** 平衡利用与探索；
2. **扩展（expansion）**：在叶节点新增一个未试过的子节点；
3. **模拟（simulation / rollout）**：从该节点随机走到底，得到胜负；
4. **回溯（backpropagation）**：把结果沿路径回传，更新访问次数 $N$ 与胜率 $Q$。

**UCB1 选择公式**：

$$\text{UCB1}(i) = \underbrace{\frac{Q_i}{N_i}}_{\text{利用}} + c\sqrt{\underbrace{\frac{\ln N}{N_i}}_{\text{探索}}}, \qquad c \approx \sqrt{2}$$

其理论依据是**多臂老虎机**的上置信界（§17.3）：$c$ 控制探索强度，$N_i \to 0$ 时探索项趋于无穷，保证每个动作至少被访问一次。

**为什么 MCTS 有效**：

- **无需评估函数**：随机模拟的结果是有偏但无偏见的"真值样本"；
- **非对称扩展**：只在有希望的分支上加深，天然聚焦；
- **随时可停**：迭代次数决定精度，便于时间控制。

**改进方向**：

| 改进 | 做法 |
| --- | --- |
| 启发式 rollout | 用简单策略代替随机走子（如围棋的"吃子优先"） |
| 树内价值网络 | 用网络估计叶子价值，替代 rollout（AlphaGo） |
| PUCT | 用先验概率 $P(s,a)$ 加权：$U = c P(s,a)\frac{\sqrt{N(s)}}{1+N(s,a)}$ |
| 策略网络 | 网络输出走法分布，剪掉低概率分支（AlphaZero） |

**AlphaZero 范式**：策略网络 + 价值网络 + MCTS 自我对弈，不使用任何人类棋谱。它的成功说明"搜索 + 学习"的互补性：搜索提供高质量标签，学习把搜索的结果**蒸馏**回网络，从而在下次搜索中更快。

## 5.5 随机博弈

当环境含随机性（骰子、洗牌），博弈树中出现**机会节点（chance node）**，其值为子节点的**期望**：

$$\text{EXPECTIMINIMAX}(s) = \begin{cases} \text{UTILITY}(s), & \text{终局} \\ \max_a \cdots, & \text{MAX} \\ \min_a \cdots, & \text{MIN} \\ \sum_r P(r)\,\text{EXPECTIMINIMAX}(\text{RESULT}(s,r)), & \text{机会节点} \end{cases}$$

**与极小极大的三点差异**：

1. **期望会"抹平"差异**：极小极大只看最坏分支，期望则考虑所有分支的概率加权，因此评估函数的**单调性不保留**——$f$ 严格单调不代表 $\sum P f$ 保持相同排序（只保留线性变换下的等价性）。
2. **剪枝更弱**：机会节点的值范围受概率约束，α-β 剪枝的界要按概率缩放才能使用（star1/star2 界）。
3. **复杂度**：$O(b^m n^m)$，其中 $n$ 是机会节点平均分支数。

**典型例子**：西洋双陆棋（dice）、扑克（牌）、21 点。实践中常用**期望 rollout** 的 MCTS 变体，而非完整的期望极小极大。

## 5.6 部分可观测博弈

**不完全信息博弈**（玩家看不到对手的手牌）与**部分可观测博弈**（看不到环境状态）在数学上相通：都可建模为**信息集（information set）**——玩家无法区分的状态集合。

难点：

- **策略必须定义在信息集上**，而非状态上；
- 极小极大失效，因为对手的"私有信息"无法直接观测，需要**信念**（对手手牌的概率分布）；
- 均衡可能是混合策略，需要解线性规划或迭代求解。

**反事实遗憾最小化（CFR）** 是求解不完全信息博弈的主流方法：

- 维护每个信息集上每个动作的**遗憾值**（未选动作比已选动作多得的收益）；
- 按遗憾比例更新策略（regret matching）；
- 在两人零和博弈中，平均策略收敛到**纳什均衡**；
- 变体：CFR+（遗憾截断）、Monte Carlo CFR（采样）、Deep CFR（用网络近似）。

**Libratus/Pluribus** 在无限注德州扑克上击败职业选手，核心正是 CFR 及其抽象化（把相似牌力归并成桶）与自我对弈。

## 5.7 博弈搜索算法的局限

1. **依赖评估函数**：极小极大 + 评估函数的强度上限由评估函数决定；MCTS 缓解了这一点，但仍受 rollout 策略与先验影响。
2. **地平线效应**：固定深度截断必然存在，只是严重程度不同。
3. **组合爆炸的指数墙**：围棋类博弈的状态空间使任何"全树"方法失效，只能采样。
4. **博弈规则必须完全已知**：规则可由代码精确执行是博弈搜索的前提；现实任务（谈判、竞价）的规则常是模糊的。
5. **对手模型假设**：极小极大假设完美对手，MCTS 假设对手按最优策略混合；面对人类失误时，可以利用对手模型获得更高收益（**对手建模**）。
6. **泛化到新博弈**：AlphaZero 需要针对每个博弈重新训练；跨博弈的通用搜索仍是开放问题（附录 E.4 的世界模型是相关方向）。

## 本章小结

**核心要点**

1. 博弈由玩家、状态、行动、转移、终局收益与信息结构定义；**零和 + 完全信息**是极小极大可行的前提。
2. 极小极大求的是**对完美对手的最优**（maximin），截断后用评估函数近似；**地平线效应**是其固有缺陷。
3. **α-β 剪枝**把最优情形的时间从 $O(b^m)$ 降到 $O(b^{m/2})$，走法排序与置换表是工程关键。
4. **MCTS** 用 UCB1 平衡探索与利用，以采样代替穷举，是围棋类问题的转折点；AlphaZero = 策略/价值网络 + MCTS + 自我对弈。
5. 随机博弈用**期望极小极大**；不完全信息博弈需要**信息集**与 CFR，收敛到纳什均衡。
6. 博弈搜索的边界在于评估函数、组合爆炸与对手模型假设。
