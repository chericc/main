# 人工智能 · 目录

本系列是一套面向系统学习的人工智能学习材料，共 16 章，覆盖从基础搜索、逻辑推理、机器学习、深度学习，到自然语言处理、计算机视觉、强化学习与前沿专题的完整脉络。

- **学习材料结构**：第 1–9 章已按统一体例整理，每章开头含「本章导读 / 学习目标 / 预备知识」，结尾含「本章小结（核心要点回顾 + 关键术语中英对照）」，便于建立章节地图与复习回顾。
- **第 10–16 章**：目前为章节目录（大纲）形态，正文待补充。
