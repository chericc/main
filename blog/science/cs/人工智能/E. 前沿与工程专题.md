## E.1 图神经网络（GNN）

**问题**：图数据（社交网络、分子、知识图谱、代码依赖）没有固定的邻域顺序，卷积无法直接套用。

**消息传递（message passing）** 是统一框架：

$$m_v^{(k)} = \bigoplus_{u \in N(v)} \phi\big(h_v^{(k-1)}, h_u^{(k-1)}, e_{uv}\big),\qquad h_v^{(k)} = \psi\big(h_v^{(k-1)}, m_v^{(k)}\big)$$

其中 $\oplus$ 是置换不变的聚合（求和/均值/最大值）。

**代表模型**：

| 模型 | 聚合方式 | 特点 |
| --- | --- | --- |
| GCN | 归一化邻域求和 + 线性变换 | 简洁、谱方法解释 |
| GraphSAGE | 采样邻居 + 拼接 | 归纳式、可扩展 |
| GAT | 多头注意力加权 | 自适应邻居权重 |
| GIN | 求和 + MLP | 表达力接近 WL 测试 |
| MPNN | 通用消息传递 | 统一框架 |

**关键问题**：

| 问题 | 说明 | 缓解 |
| --- | --- | --- |
| 过平滑（over-smoothing） | 层数多时节点表示趋同 | 残差、跳跃连接、限制层数 |
| 过挤压（over-squashing） | 长程信息被压缩到固定维度 | 图重连、虚拟节点 |
| 表达力上限 | 不超过 1-WL 测试 | 位置编码、子图方法 |
| 大规模 | 邻居爆炸 | 采样（GraphSAGE、Cluster-GCN） |
| 异质图 | 多类型节点/边 | 关系感知聚合、元路径 |

**应用**：分子性质预测、药物发现、社交推荐（附录 C.3）、知识图谱补全、代码理解、物理仿真。

## E.2 元学习

**元学习（meta-learning）** = 学会学习：从多个任务中学习"如何快速适应新任务"。

**三种范式**：

| 范式 | 思路 | 代表 |
| --- | --- | --- |
| 基于度量 | 学一个度量空间，近邻分类 | 孪生网络、原型网络、匹配网络 |
| 基于优化 | 学一个好的初始化/更新规则 | **MAML**、Reptile |
| 基于模型 | 用记忆/注意力快速吸收新样本 | MANN、Transformer 上下文学习 |

**MAML 的双层优化**：

$$\min_\theta \sum_{\mathcal{T}_i} \mathcal{L}_{\mathcal{T}_i}\Big(\theta - \alpha \nabla_\theta \mathcal{L}_{\mathcal{T}_i}(\theta)\Big)$$

内层是任务内的几步梯度下降，外层优化"下降后"的损失。它学的是**易于微调的初始化**。

**Reptile** 更简单：多步 SGD 后把参数往任务解的方向拉，不需要二阶梯度。

**少样本学习**：$N$-way $K$-shot 设定；原型网络用类均值做原型，按距离分类。

**上下文学学习（in-context learning）**：大模型无需更新参数，仅凭提示中的示例就能"学会"任务——可视为一种**隐式元学习**。

**应用**：少样本分类、快速适应新用户/新设备、超参数迁移、强化学习的快速适应（Meta-RL）。

## E.3 自监督学习

**核心思想**：从数据本身构造监督信号，避免人工标注。

**（1）对比学习**：拉近正样本、推远负样本。

- **SimCLR**：同一样本的两个增强为正对，batch 内其他为负对；
- **MoCo**：用动量编码器 + 队列提供大量负样本；
- **BYOL / SimSiam**：不用负样本，靠预测器 + 停止梯度防止坍塌；
- **CLIP**：图文配对为正，跨模态对齐。

**InfoNCE 目标**：

$$\mathcal{L} = -\log \frac{\exp(\text{sim}(q,k_+)/\tau)}{\sum_{j}\exp(\text{sim}(q,k_j)/\tau)}$$

**（2）掩码建模**：遮住一部分输入，让模型预测。

- **BERT**：掩码 token 预测（§24.6）；
- **MAE**：遮住图像 patch，重建像素；
- **Span Corruption（T5）**：遮住连续片段。

**（3）自回归**：预测下一项（GPT、PixelCNN）。

**（4）其他前置任务**：旋转预测、拼图、时间顺序、去噪自编码。

**为什么有效**：好的表示应能"预测未观测部分"或"区分不同实例"，这迫使模型学习语义结构而非表面统计。

**风险**：**捷径解**（利用低层统计如颜色、压缩伪影）可能导致表示退化；需要仔细设计增强与负样本。

## E.4 世界模型

**世界模型（world model）** 是对环境动态的可预测表示：给定状态与动作，预测下一状态（或观测）。

**三类用法**：

| 用法 | 说明 | 代表 |
| --- | --- | --- |
| 规划 | 在模型中搜索/优化动作序列 | Dreamer、MuZero、MPC |
| 想象训练 | 用模型生成的数据训练策略 | Dyna、MBPO |
| 评估与预测 | 预测干预后果、做反事实分析 | 因果世界模型 |

**关键技术**：

- **潜在动力学**：在低维隐空间预测（Dreamer 的 RSSM）；
- **离散潜变量**：避免模糊，适合多模态未来（VQ-VAE、离散扩散）；
- **长视野稳定性**：误差累积是核心难题，需多步一致性训练；
- **视频生成世界模型**：Sora 类模型用大规模视频学习"物理直觉"，但**是否真懂物理**仍有争议。

**与模型预测控制的关系**：MPC 假设模型已知且精确；学习型世界模型把"模型"换成网络，需处理不确定性与分布外误差。

**评估**：预测误差、下游任务表现、物理一致性（守恒律、碰撞）、反事实合理性。

## E.5 神经符号系统

**动机**：神经网络擅长感知与泛化，符号系统擅长推理与验证。

**三种耦合方式**：

| 方式 | 做法 | 例子 |
| --- | --- | --- |
| 神经 → 符号 | 网络输出结构化表示，交给符号推理 | 语义解析、场景图 → 逻辑 |
| 符号 → 神经 | 用符号约束引导/校验网络输出 | 约束解码、逻辑约束损失、SHAP |
| 联合训练 | 端到端可微的逻辑层 | 逻辑张量网络、DeepProbLog |

**典型架构**：

- **检索 + 推理**：LLM 生成候选，定理证明器/SMT 校验（数学、代码）；
- **知识图谱 + 嵌入**：符号约束 + 向量泛化（§10.7）；
- **程序合成**：网络生成程序，执行器提供反馈（DreamCoder、AlphaCode）。

**价值**：

1. **可验证**：符号约束使输出可检查（类型、单位、逻辑一致性）；
2. **数据效率**：规则提供先验，减少样本需求；
3. **可解释**：推理链可追溯。

**难点**：符号层不可微导致训练困难；知识获取仍需人工；两层的接口设计（离散化、对齐）是工程核心。

## E.6 AI for Science

**角色演进**：从"加速计算"到"提出假设"。

| 层次 | 例子 |
| --- | --- |
| 代理模型 | 用网络替代昂贵仿真（气候、流体） |
| 预测 | AlphaFold（蛋白结构）、天气预报（GraphCast） |
| 生成 | 分子/材料生成（GNoME）、蛋白质设计 |
| 发现 | 数学猜想辅助（FunSearch）、符号回归 |
| 实验闭环 | 自动实验室、主动学习选实验 |

**AlphaFold 的意义**：把"结构预测"从数月降到分钟级，改变了结构生物学的工作流；但它预测的是**静态结构**，动力学、复合物、突变效应仍需其他方法。

**方法论要点**：

1. **等变与对称性**：分子/晶体需要 SE(3) 等变网络；
2. **数据与仿真**：科学数据稀缺，常用物理仿真生成训练集；
3. **不确定性**：科学结论需要置信区间与误差传播；
4. **可验证性**：预测必须能被实验检验——这是与互联网应用的根本差别。

**风险**：错误预测可能误导实验方向；需与领域专家协作，并公开不确定度。

## E.7 Agent 与大模型协作

**Agent = 目标 + 规划 + 记忆 + 工具 + 反思**。

**最小闭环**：

```
观察 → 思考（ReAct）→ 选择工具 → 执行 → 观察 → … → 交付
```

**组件设计**：

| 组件 | 关键技术 |
| --- | --- |
| 规划 | ReAct、Plan-and-Execute、树搜索（ToT）、任务分解 |
| 记忆 | 上下文窗口、向量检索、结构化状态、摘要压缩 |
| 工具 | 函数调用（JSON schema）、代码执行、浏览器、数据库、API |
| 验证 | 单元测试、类型检查、规则校验、模型裁判 |
| 反思 | 自我批评、重试、回滚、人类反馈 |

**多 Agent 协作**：

| 模式 | 说明 |
| --- | --- |
| 流水线 | 角色分工（规划者/执行者/审查者） |
| 辩论 | 多个 Agent 互相质疑，提升事实性 |
| 投票 | 多样本集成 |
| 层级 | 管理者分解任务，工作者执行 |

**工程风险**：

| 风险 | 表现 | 对策 |
| --- | --- | --- |
| 长程漂移 | 多步后偏离目标 | 检查点、子目标验证、重规划 |
| 工具误用 | 参数错误、越权调用 | schema 校验、权限最小化、人工确认 |
| 提示注入 | 外部内容劫持指令 | 内容隔离、指令/数据分离 |
| 成本失控 | 循环调用、超长上下文 | 预算上限、提前终止、缓存 |
| 评估困难 | 无标准答案 | 任务级评测集、过程日志审计 |

**评估**：任务成功率、步骤数、成本、人工干预率；对开放任务需**过程评估**而非只看最终答案。

## E.8 工程实践：模型压缩、推理优化与分布式训练

**（1）量化（quantization）**：用低精度表示权重/激活。

| 类型 | 说明 |
| --- | --- |
| 训练后量化（PTQ） | 校准数据确定缩放因子，简单 |
| 量化感知训练（QAT） | 训练时模拟量化误差，精度更高 |
| 权重量化 vs 全量化 | 只量化权重（W4A16）省显存；全量化（W8A8）省算力 |
| 异常值处理 | LLM 的激活有离群值，用分组量化/AWQ/SmoothQuant |

**（2）剪枝（pruning）**：去掉冗余连接/通道/层。

- **非结构化**：稀疏权重，需稀疏计算库支持；
- **结构化**：去掉整个通道/头，直接加速；
- **彩票假说**：稀疏子网络可从零训练复现性能（理论意义大于工程）。

**（3）知识蒸馏（distillation）**：小学生模仿教师的软标签（logits），或模仿中间特征/注意力。

**（4）推理优化**：

| 技术 | 作用 |
| --- | --- |
| KV 缓存 | 避免自回归重复计算 |
| 连续批处理（continuous batching） | 提高 GPU 利用率 |
| PagedAttention | 高效管理 KV 显存（vLLM） |
| 投机采样（speculative decoding） | 小模型草稿 + 大模型验证 |
| 算子融合 / FlashAttention | 减少显存读写 |
| 结构化输出约束 | 保证 JSON/SQL 合法 |

**（5）分布式训练**：

| 并行方式 | 切分对象 | 适用 |
| --- | --- | --- |
| 数据并行（DP） | batch | 模型能放进单卡 |
| 张量并行（TP） | 层内矩阵 | 单层过大 |
| 流水线并行（PP） | 层 | 深模型跨节点 |
| 专家并行（EP） | MoE 专家 | 稀疏大模型 |
| ZeRO / FSDP | 优化器状态/梯度/参数分片 | 降低显存冗余 |
| 重计算（activation checkpointing） | 时间换显存 | 长序列/大模型 |

**通信是瓶颈**：TP 需高带宽（NVLink），PP 需低延迟，DP 需高吞吐；拓扑与并行策略必须匹配硬件。

**工程建议**：

1. 先做**性能剖析**（计算/内存/通信各占多少），再选优化手段；
2. 量化优先于剪枝（工具成熟、收益直接）；
3. 推理成本由**显存带宽**与**批大小**主导，而非 FLOPs；
4. 建立**端到端基准**（延迟 P50/P99、吞吐、成本/请求）。

## 本附录小结

**核心要点**

1. **GNN** 用消息传递统一图学习；GCN/GraphSAGE/GAT 各有侧重，需处理过平滑、过挤压与可扩展性。
2. **元学习**三范式：度量、优化（MAML）、模型；目标是"少样本快速适应"。
3. **自监督**靠对比、掩码、自回归构造信号；CLIP 把图文对齐变成通用表示。
4. **世界模型**用于规划、想象训练与干预预测；长视野误差累积是核心难题。
5. **神经符号**三条耦合路径：神经→符号、符号→神经、端到端可微；价值在可验证与可解释。
6. **AI for Science** 从代理模型走向假设生成与实验闭环，可验证性是底线。
7. **Agent** 的关键是规划-记忆-工具-验证闭环；风险在长程漂移、工具误用与提示注入。
8. 工程侧：**量化最划算、剪枝需硬件支持、蒸馏换架构、并行看瓶颈**。
