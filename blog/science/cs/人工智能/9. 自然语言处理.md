# 第 9 章 自然语言处理

**本章导读**：自然语言处理（Natural Language Processing, NLP）研究如何让计算机理解与生成人类语言。本章按"基础表示—结构分析—任务应用—大模型"的脉络展开：先从文本预处理、语言模型与词向量讲起，说明如何把离散文本转化为可计算的表示；再介绍序列标注、句法分析、语义角色标注与信息抽取等结构化理解方法；随后讨论文本分类、机器翻译、摘要、问答与对话等经典应用；最后进入大语言模型时代，涵盖预训练架构、提示工程、检索增强生成、参数高效微调、对齐技术以及评测与应用。各节既相对独立又层层递进，建议结合具体任务理解每一步技术演进的动机。

## 9.1 文本预处理

文本预处理（Text Preprocessing）是 NLP 流水线中最基础也最关键的环节，目标是把非结构化、含噪声的原始文本转换为结构化、可供计算的形式，同时保留语义并控制特征空间规模。原始语料常存在编码不一致、格式混乱、词形变化与功能词冗余等问题；若不处理，既会造成特征空间膨胀（维度灾难），也会干扰后续的语义分析。本节依次讨论字符编码与归一化、分词、词干提取与词形还原、停用词处理，最后给出完整流水线。

### 9.1.1 字符编码与文本归一化

计算机只能处理数字，因此需要字符编码（Character Encoding）把字符映射为码位。ASCII（1963）用 7 位定义 128 个字符，无法表示中文；此后出现 GB2312（1980，收录 6,763 个汉字）、GBK（1995，21,003 个）与 GB18030（2000，7 万以上）等中国国家标准。Unicode 为世界上每个字符分配唯一码点（Code Point），写作 `U+XXXX`（如"中"为 `U+4E2D`），目前收录超过 14.9 万个字符。UTF-8 是最常用的 Unicode 编码方案，采用 1–4 字节变长编码，与 ASCII 完全兼容，并具有自同步性与字节序无关性。其编码规则如下。

| 码点范围 | 字节数 | 首字节格式 | 后续字节格式 |
|:---|:---|:---|:---|
| U+0000 – U+007F | 1 | `0xxxxxxx` | — |
| U+0080 – U+07FF | 2 | `110xxxxx` | `10xxxxxx` |
| U+0800 – U+FFFF | 3 | `1110xxxx` | `10xxxxxx` × 2 |
| U+10000 – U+10FFFF | 4 | `11110xxx` | `10xxxxxx` × 3 |

以"中"（U+4E2D）为例，它落在三字节区间，按模板填入后得到 `11100100 10111000 10101101`，即 `E4 B8 AD`。文本归一化（Text Normalization）则把文本转换为标准统一形式，包括大小写转换、全角/半角统一、Unicode NFC 归一化、数字与标点处理等。例如 `é` 既可能是单码点 `U+00E9`，也可能是组合形式 `U+0065 + U+0301`；NFC 归一化保证同一字符只有一种规范表示。

### 9.1.2 分词

分词（Tokenization）把连续文本切分为独立语义单元（token），是几乎所有 NLP 任务的第一步，其质量直接影响后续所有环节。词级分词以空格和标点切分，适用于英语等印欧语言，但面临缩写（`don't`）、连字符词（`state-of-the-art`）、命名实体（`New York`）等边界歧义，而且无法直接用于中文。中文分词（Chinese Word Segmentation）常用三类方法：基于词典的最大匹配法（正向或逆向）、基于统计的序列标注方法（HMM、CRF），以及基于深度学习的 BiLSTM-CRF 或 BERT 端到端方法。

字符级分词把文本切为单个字符，词汇表极小且不存在未登录词（Out-of-Vocabulary, OOV）问题，但序列长度约增加数倍，每个 token 携带的语义信息极少，会加重下游建模负担。子词分词（Subword Tokenization）是介于词级与字符级之间的折中：常见词保持完整，罕见词拆分为有意义的子词片段。它兼顾语义信息与词汇表规模，是当前大语言模型（Large Language Model, LLM）的标准方案。三种主流算法对比如下。

| 特性 | BPE | WordPiece | SentencePiece |
|:---|:---|:---|:---|
| 合并准则 | 频率最高 | 互信息最高 | BPE 或 Unigram |
| 语言依赖 | 依赖空格分词 | 依赖空格分词 | 语言无关 |
| 子词前缀 | 无 | `##` | `▁` |
| 代表模型 | GPT-2、RoBERTa | BERT、DistilBERT | T5、ALBERT |

BPE（Byte Pair Encoding）由 Gage 于 1994 年提出、Sennrich 等（2016）引入 NLP，步骤为：把词拆为字符并添加结束符 `</w>`；统计相邻 token 对频率；合并频率最高的一对；重复直到达到预设词表大小。WordPiece 用于 BERT，选择使语言模型似然增益最大（等价于点互信息最高）的 token 对合并，并用 `##` 标记非词首子词。SentencePiece（Kudo & Richardson, 2018）直接在原始文本上训练，把空格视为普通字符（用 `▁` 表示），语言无关且可逆。

### 9.1.3 词干提取与词形还原

词干提取（Stemming）是基于规则的后缀剥离，把语义相关的词形映射到同一词干，以降低特征维度；但它不保证结果是有效词。Porter Stemmer（1980）定义约 60 条规则并按顺序应用，其核心概念 measure 指词干中"辅音—元音"序列的数量。Lancaster Stemmer（Paice, 1990）规则更多、更激进，词干更短但过度词干提取风险更高；Snowball Stemmer（Porter, 2001）是 Porter 的多语言改进版，也是 NLTK 中推荐的实现。

词形还原（Lemmatization）依据词典与词性（Part-of-Speech, POS）把词还原为词典形式（lemma），输出一定是有效词，但需要词性标注且速度较慢。二者核心区别如下。

| 特性 | 词干提取 | 词形还原 |
|:---|:---|:---|
| 方法 | 规则后缀剥离 | 词典形态学分析 |
| 输出 | 词干（可能无效） | 词元（一定有效） |
| 需要词性标注 | 否 | 是 |
| 速度与准确性 | 快、中等 | 慢、高 |
| `better` | `better` | `good` |
| `ran` | `ran` | `run` |

常用工具包括 NLTK 的 WordNet Lemmatizer、spaCy 与 Stanza。词干提取适用于对精度要求不高的召回场景，词形还原适用于需要语言学正确性的分析任务。

### 9.1.4 停用词与预处理流水线

停用词（Stop Words）是在处理中被过滤掉的高频低信息量词，如英语的 the、is、and，中文的"的""了""在"。停用词表可由频率法（取词频最高的 $k$ 个词）、文档频率法（出现于超过 $p\%$ 的文档）或人工编制得到；NLTK 英语表含 179 词，哈工大中文表约 767 词。去除停用词能降低特征维度与噪声，但在情感分析（"not good"中的 not 被删会丢失否定）和机器翻译（语法信息丢失）中可能有害。当代 Transformer 模型通常不去停用词，而由注意力机制自动学习哪些词重要。TF-IDF 可作为停用词的替代方案：停用词出现在几乎所有文档中，其逆文档频率接近零，权重被自然压低。

一个典型的中文分类预处理流水线为：编码检测 → 文本清洗 → 中文分词 → 去除停用词 → 向量化。以"这家餐厅的菜品非常好吃，服务也很周到"为例，先清洗多余标点，再分词，去停用词后保留"餐厅、菜品、非常、好吃、服务、周到"等实词，最后用 TF-IDF 或词向量转为数值特征。英文流水线还需小写转换，并可在词干提取与词形还原之间选择——前者可能产生 `extens` 这类无效词干，后者依赖正确的词性标注。

## 9.2 语言模型

### 9.2.1 语言模型与 n-gram

语言模型（Language Model, LM）为一段词序列分配概率。给定 $W=w_1,w_2,\dots,w_n$，由概率链式法则可分解为前缀条件概率的连乘：

$$P(W)=\prod_{i=1}^{n}P(w_i\mid w_1,w_2,\dots,w_{i-1})$$

若词表大小为 $|V|$，长度为 $i-1$ 的历史就有 $|V|^{i-1}$ 种，直接估计会指数爆炸。n-gram 模型引入马尔可夫假设（Markov Assumption），只依赖前 $n-1$ 个词：

$$P(w_i\mid w_1,\dots,w_{i-1})\approx P(w_i\mid w_{i-n+1},\dots,w_{i-1})$$

unigram（$n=1$）、bigram（$n=2$）、trigram（$n=3$）分别对应 0、1、2 个上下文词。参数由最大似然估计（Maximum Likelihood Estimation, MLE）从语料中统计：

$$P_{\text{MLE}}(w_i\mid w_{i-n+1},\dots,w_{i-1})=\frac{\text{Count}(w_{i-n+1},\dots,w_i)}{\text{Count}(w_{i-n+1},\dots,w_{i-1})}$$

例如语料中 `Count(喜欢, 吃)=3`、`Count(喜欢)=4`，则 $P(\text{吃}\mid\text{喜欢})=0.75$。

### 9.2.2 数据稀疏与平滑

n-gram 面临的最大挑战是数据稀疏（Data Sparsity）：大量合理组合从未在语料中出现，其 MLE 概率为零，而序列概率是连乘，任何一项为零都会使整体为零，模型因此丧失泛化能力。平滑（Smoothing）的核心思想是从已观测 n-gram 中"借"出概率质量，分配给未观测 n-gram。常用方法如下。

| 方法 | 核心思想 | 优势 | 劣势 |
|:---|:---|:---|:---|
| 拉普拉斯（Add-k） | 每个计数加常数 $k$ | 简单直观 | 过度平滑 |
| Good-Turing | 用 $N_{r+1}$ 调整 $r$ 的计数 | 理论基础好 | 高频不稳定 |
| Jelinek-Mercer | 不同阶 n-gram 线性插值 | 实现简单 | 权重需调优 |
| Katz Backoff | 高阶不足则回退到低阶 | 效果较好 | 回退逻辑复杂 |
| Kneser-Ney | 折扣 + 续接概率回退 | 实践效果最优 | 实现较复杂 |

拉普拉斯平滑（Laplace/Add-k）为每个计数加常数 $k$：$P(w_i\mid w_{i-1})=\frac{\text{Count}(w_{i-1},w_i)+k}{\text{Count}(w_{i-1})+k|V|}$，$k=1$ 即加一平滑；它把所有未见事件都赋予概率，导致高频 n-gram 被严重低估。Good-Turing 利用恰好出现 $r+1$ 次的 n-gram 数量 $N_{r+1}$ 来调整 $r$ 次事件的计数 $r^*=(r+1)N_{r+1}/N_r$，使零频事件获得非零概率，但高频区不连续时不稳定，需配合回退。Kneser-Ney 的关键创新是用续接概率（continuation probability）代替低阶 MLE 作为回退分布，衡量一个词能接续多少种不同上下文；例如"Francisco"几乎只跟在"San"之后，其续接概率很低，从而避免被高估。

### 9.2.3 困惑度

困惑度（Perplexity, PP）是评估语言模型的标准指标，衡量模型预测下一个词时的不确定度：

$$PP(W)=\left(\prod_{i=1}^{N}P(w_i\mid w_1,\dots,w_{i-1})\right)^{-1/N}=2^{H(P,Q)}$$

其中 $H(P,Q)$ 是模型在测试集上的交叉熵。困惑度可理解为模型每步预测面临的"等价候选数"：完美模型 PP=1，均匀模型 PP=$|V|$，越低越好。以"我喜欢吃苹果"为例，若各条件概率为 0.3、0.4、0.5、0.2，则 $PP=(0.3\times0.4\times0.5\times0.2)^{-1/4}\approx3.03$。英语的熵率估计约为 1.0–1.5 bits/word，对应理想困惑度约 2–2.8，远低于当前最好的模型，说明仍有改进空间。困惑度越低表示模型越好，且可在同一测试集上直接比较不同模型。

### 9.2.4 神经语言模型

n-gram 的本质局限在于：离散符号之间完全独立、无法共享语义；上下文窗口固定；参数随阶数按 $|V|^n$ 增长。神经语言模型（Neural Language Model, NLM）通过连续空间的分布式表示（Distributed Representation）解决这些问题。

Bengio 等（2003）的前馈神经语言模型（NNLM）把前 $n-1$ 个词经共享嵌入矩阵映射为稠密向量，拼接后送入隐藏层，再经 softmax 输出词表概率分布。其关键创新是词嵌入（Word Embedding）由所有上下文位置共享，语义相近的词在嵌入空间中靠近，从而实现跨上下文泛化，参数量由 $|V|^n$ 降为 $|V|\cdot m$ 量级；局限是输入窗口仍然固定。

Mikolov 等（2010）的循环神经网络语言模型（RNN-LM）用隐状态递归编码全部历史：$h_t=\sigma(W_h h_{t-1}+W_x x_t+b_h)$，理论上可捕捉任意长度依赖，但实践中受梯度消失与爆炸困扰；LSTM（Hochreiter & Schmidhuber, 1997）与 GRU（Cho 等, 2014）通过门控机制缓解这一问题，成为 RNN-LM 的标准变体。

Transformer（Vaswani 等, 2017；其结构详见第 6 章）以自注意力机制彻底取代循环结构：

$$\text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

自回归语言模型使用因果掩码，使位置 $t$ 只能关注 $\le t$ 的位置。多头注意力（Multi-Head Attention）在不同投影子空间中并行计算，前馈网络、残差连接与层归一化构成每个 Transformer 层，位置信息由正弦编码或现代的可学习相对位置编码、旋转位置编码（RoPE）注入。相比 RNN，Transformer 支持全序列并行计算、能直接连接任意距离的位置；配合 KV Cache、FlashAttention 与分组查询注意力（GQA），上下文可扩展到数千乃至数十万 token，模型规模可达数十亿至数万亿参数。Kaplan 等（2020）的缩放定律（Scaling Laws）进一步揭示损失随参数量、数据量与计算量呈幂律下降。语言模型由此经历了从离散计数到连续表示、再到并行自注意力的三代范式，成为通向通用人工智能的核心基础设施（详见 §9.14）。

## 9.3 词向量

### 9.3.1 从离散符号到分布式表示

早期词表示采用 one-hot 编码：长度为 $|V|$ 的二值向量，仅在对应索引处为 1。它有两个根本缺陷：任意两个不同词的向量正交，因而无法表达语义相似性；维度等于词表大小，极为稀疏，且无法在训练中未见组合上泛化。例如模型见过"cat sat on the mat"却无法泛化到"dog sat on the rug"，因为 cat/dog、mat/rug 的向量间没有结构化关联。

分布式表示（Distributed Representation）的理论基础是 Harris 的分布假说（Distributional Hypothesis, 1954）："出现在相似上下文中的词倾向于具有相似语义。"Firth（1957）将其精炼为"You shall know a word by the company it keeps."。其核心是把每个词映射为低维稠密实值向量 $\mathbf{w}\in\mathbb{R}^d$（$d$ 通常取 50–300），语义信息分布在所有维度上，每个维度不单独对应某个语义特征。

### 9.3.2 Word2Vec

Word2Vec（Mikolov 等, 2013）是把分布假说工程化的里程碑工作，包含两种互补架构。CBOW（Continuous Bag-of-Words）由上下文预测中心词，对上下文词向量取平均后经 softmax 输出；Skip-gram 恰好相反，由中心词预测上下文窗口内每个词，每个中心词可产生 $2m$ 个训练样本，因此对低频词建模更充分。二者对比如下。

| 特性 | CBOW | Skip-gram |
|:---|:---|:---|
| 训练目标 | 从上下文预测中心词 | 从中心词预测上下文 |
| 训练速度 | 较快 | 较慢 |
| 低频词处理 | 较差 | 较好 |
| 适合场景 | 大规模语料、重效率 | 小语料、重语义质量 |

直接计算全词表 softmax 的代价为 $O(V)$，因此提出两种高效近似。负采样（Negative Sampling, NEG）把多分类转为二分类，对每个正样本随机采样 $K$ 个噪声词作为负样本，噪声分布取词频的 3/4 次方 $P_n(w)\propto f(w)^{3/4}$，以平滑分布、提高低频词被采样的概率，复杂度降为 $O(K+1)$，典型 $K=5\sim20$。层次化 Softmax（Hierarchical Softmax）把词表组织为哈夫曼树，每个内部节点是一个二分类器，从根到词的路径概率连乘即得该词概率，复杂度为 $O(\log V)$。实践中负采样实现简单且效果通常更优，层次化 Softmax 更稳定但略逊。

### 9.3.3 GloVe

GloVe（Global Vectors for Word Representation, Pennington 等, 2014）与 Word2Vec 不同，它从全局词—词共现矩阵出发。设 $X_{ij}$ 为词 $j$ 出现在词 $i$ 上下文窗口中的加权次数，$X_i=\sum_k X_{ik}$，条件概率 $P_{ij}=X_{ij}/X_i$。其关键洞察来自共现概率的比值：以 ice 与 steam 为例，探测词 solid 的比值远大于 1（与 ice 相关），gas 的比值远小于 1（与 steam 相关），而 water、fashion 的比值接近 1（与两者都相关或都不相关）。于是 GloVe 让词向量点积拟合这一比值，最终导出

$$\mathbf{w}_i^\top\tilde{\mathbf{w}}_j+b_i+\tilde{b}_j=\log X_{ij}$$

损失函数为加权最小二乘 $\mathcal{L}=\sum_{i,j}f(X_{ij})\big(\mathbf{w}_i^\top\tilde{\mathbf{w}}_j+b_i+\tilde{b}_j-\log X_{ij}\big)^2$，权重 $f(x)=\min\big((x/x_{\max})^\alpha,1\big)$（$x_{\max}=100,\alpha=0.75$）使不共现的词对不贡献损失，同时抑制 the 等超高频词对主导训练。最终词向量取两个嵌入矩阵之和。Word2Vec 是预测式、利用局部窗口、支持在线学习；GloVe 是计数式、利用全局统计、中小语料下更稳定。

### 9.3.4 FastText、评估与局限

FastText（Bojanowski 等, 2017）把词表示为其字符 n-gram 向量之和。以"where"为例，会提取 `<wh`、`whe`、`her` 等长度 3–6 的片段以及完整词本身。这一设计带来三项优势：共享子词的词自然获得相似向量（如 unhappy 与 unlucky 共享 un）、未登录词只要字符片段出现过就能得到合理向量、对德语等形态丰富语言尤为适用。三种词向量方法对比如下。

| 特性 | Word2Vec | GloVe | FastText |
|:---|:---|:---|:---|
| 基本单元 | 词 | 词 | 词 + 字符 n-gram |
| OOV 处理 | 不支持 | 不支持 | 支持子词推断 |
| 形态学感知 | 无 | 无 | 强 |
| 训练方式 | 预测式 | 计数式 | 预测式 |
| 全局信息 | 局部窗口 | 全局共现 | 局部窗口 |

词向量的经典定性评估是词类比任务：$\mathbf{w}_a-\mathbf{w}_b+\mathbf{w}_c\approx\mathbf{w}_d$，如 king−man+woman=queen（性别关系）、Paris−France+Italy=Rome（首都关系）；定量评估包括在 SimLex-999、WordSim-353 等数据集上计算与人工评分的相关性、下游任务表现与探针任务。静态词向量存在根本局限：一词一义（bank 在"河岸"与"银行"中共享同一向量）、训练后固定不变、只能处理词级语义、以及会放大语料中的社会偏见。这些局限直接引出了下一节的上下文词表示。

## 9.4 上下文词表示

### 9.4.1 静态表示的局限

静态词向量为每个词分配固定的、与上下文无关的向量，无法处理一词多义（Polysemy）。形式化地，若静态嵌入为 $f:V\to\mathbb{R}^d$，则任何句子中词 $w_i$ 的表示都相同：$\mathbf{e}_{w_i}^{(s_1)}=\mathbf{e}_{w_i}^{(s_2)}=\cdots=f(w_i)$。上下文词表示（Contextualized Word Representation）打破这一限制，令表示随所在句子变化：$\mathbf{e}_{w_i}^{(s)}=g(w_i,s)$。以 bank 为例，"去银行存钱"与"河岸开满鲜花"两句话中该词的向量方向差异显著，分别更接近 money/account 与 shore/river。静态表示与上下文表示的核心差异在于：前者查表即得、开销 $O(1)$，后者需前向传播整个网络、开销 $O(n)$，但能区分多义、捕捉句法与语义角色信息。

### 9.4.2 ELMo

ELMo（Embeddings from Language Models, Peters 等, 2018）是首个产生广泛影响的上下文化词表示方法，用双向 LSTM 语言模型（Bidirectional LM, BiLM）产生表示。前向 LM 基于上文、后向 LM 基于下文分别预测当前词，联合训练最大化双向对数似然。对每个词，ELMo 取各层隐状态并做任务特定加权：

$$\text{ELMo}_k=\gamma\sum_{j=0}^{L}s_j\mathbf{h}_{k,j}^{\text{LM}}$$

其中 $s_j$ 是 softmax 归一化的层权重，$\gamma$ 是任务特定的缩放因子。经验发现，低层更多捕捉词形与句法信息，高层更多捕捉语义信息，因此句法任务（如 POS、CCG）偏重低层，语义任务（如 SRL、NER）偏重高层。使用时把 ELMo 向量与原始词嵌入拼接作为下游模型的输入；它在 SQuAD、SNLI、SRL、NER、SST-5、共指消解等六个任务上均带来提升，数据量较小的任务提升尤为明显，因为上下文化预训练注入了大量先验知识。

### 9.4.3 CoVe 与范式转变

CoVe（Contextualized Word Vectors, McCann 等, 2017）比 ELMo 更早探索该思路：利用机器翻译任务训练编码器，再取编码器隐状态作为上下文表示。其出发点是翻译天然要求理解上下文——一个词如何翻译必须依赖语境。CoVe 以 GloVe 为输入、双层双向 LSTM 为编码器，取第二层双向隐状态拼接得到 600 维向量，再与 GloVe 拼接用于下游任务。

ELMo 与 CoVe 代表了两种预训练范式：语言模型目标与翻译任务目标。ELMo 只需单语数据、支持层级加权，适用范围更广；CoVe 需要平行语料、仅使用最后一层，在多数任务上略逊于 ELMo。这一阶段标志着 NLP 从静态嵌入走向上下文化嵌入的关键转变。与随后出现、采用端到端微调的 BERT 与 GPT 相比，ELMo/CoVe 通常作为冻结的特征提取器、基于 LSTM，且是"伪双向"（前向与后向 LM 独立训练后拼接）；BERT 的掩码语言模型能同时利用左右上下文，在需要深度双向推理的任务上表现更优。ELMo 的历史意义在于首次系统证明上下文化预训练能显著提升下游性能，开启了预训练革命（详见 §9.14）。

## 9.5 序列标注

### 9.5.1 序列标注问题概述

序列标注（Sequence Labeling）为输入序列中的每个元素分配标签，同时考虑标签之间的依赖关系，是自然语言处理中最基础的结构化预测（Structured Prediction）任务。与普通分类不同，它把变长输入序列 $\mathbf{x}=(x_1,\dots,x_n)$ 映射为等长标签序列 $\mathbf{y}=(y_1,\dots,y_n)$，需要考虑全局最优路径，通常用 Viterbi 算法解码：

$$\mathbf{y}^*=\arg\max_{\mathbf{y}\in\mathcal{Y}^n}P(\mathbf{y}\mid\mathbf{x})$$

典型任务包括词性标注、命名实体识别、中文分词、语义角色标注与语音识别音素标注。不同模型对该序列概率有不同的分解方式：生成式模型（如 HMM）建模 $\prod_i P(x_i\mid y_i)P(y_i\mid y_{i-1})$，判别式模型（如 CRF）直接建模条件概率并可用任意特征。

### 9.5.2 词性标注

词性标注（Part-of-Speech Tagging, POS）为句子中每个词分配语法类别，是句法分析与许多下游任务的基础。Penn Treebank（PTB）标签集包含 36 个词性标签，核心标签如下表。

| 标签 | 含义 | 示例 | 标签 | 含义 | 示例 |
|:---|:---|:---|:---|:---|:---|
| NN | 单数名词 | dog | VB | 动词原形 | run |
| NNS | 复数名词 | dogs | VBD | 动词过去式 | ran |
| NNP | 专有名词 | London | VBG | 现在分词 | running |
| JJ | 形容词 | big | VBN | 过去分词 | eaten |
| RB | 副词 | quickly | VBZ | 第三人称单数 | runs |
| DT | 限定词 | the | IN | 介词/从属连词 | in, that |

标准标注形如 `The/DT big/JJ cat/NNS sat/VBD on/IN the/DT mat/NN ./.`。核心难点是兼类词，例如 run 既可作动词也可作名词；据 PTB 统计约 55% 的英语词存在词性兼类，因此上下文建模至关重要。

HMM 是经典统计方法：词性为隐状态、词为观测值，包含初始概率、转移概率与发射概率三要素，用 Viterbi 解码，参数由 MLE 估计。它在 PTB 上准确率约 96.0%–96.5%，受限于一阶马尔可夫假设——只考虑前一个标签，无法捕捉长距离依赖。未登录词会导致发射概率为零，可用平滑与词形特征（前缀、后缀、大小写、是否含数字）缓解。神经网络方法用分布式词向量替代离散特征，并用 BiLSTM 或 Transformer 编码上下文，在 PTB 上准确率可达 97.5% 以上，且无需人工设计特征。

### 9.5.3 命名实体识别

命名实体识别（Named Entity Recognition, NER）从非结构化文本中识别具有特定意义的实体并分类，是信息抽取（Information Extraction）的核心子任务，也是关系抽取、事件抽取与知识图谱构建的基础。以 CoNLL-2003 为例，常见实体类型有人名（PER）、地名（LOC）、机构名（ORG）与杂项（MISC）。

标注方案中，BIO 最常用：`B-X` 表示实体 X 的开始，`I-X` 表示内部，`O` 表示非实体；BIOES 额外增加 `E-X`（结束）与 `S-X`（单字实体），显式标注边界，通常比 BIO 提升 0.5%–1.0% 的 F1。例如"John lives in New York City"标注为 `B-PER O O B-LOC I-LOC I-LOC`。经典方法包括基于规则与地名词典的方法（无需标注但覆盖率低）以及判别式条件随机场（Conditional Random Field, CRF，可用任意特征且不需独立性假设）。

BiLSTM-CRF（Huang 等, 2015；Lample 等, 2016）结合双向 LSTM 的上下文编码与 CRF 的全局标签约束，成为 NER 的经典架构。其流程分三步：嵌入层融合预训练词向量与字符级 BiLSTM/CNN 表示；BiLSTM 层拼接前向与后向隐状态 $\mathbf{h}_i$；CRF 层用发射得分与可学习转移矩阵定义序列总得分

$$\text{Score}(\mathbf{x},\mathbf{y})=\sum_{i=1}^{n}\mathbf{P}_{i,y_i}+\sum_{i=1}^{n-1}\mathbf{T}_{y_i,y_{i+1}}$$

条件概率为 $\exp(\text{Score})/Z(\mathbf{x})$，训练最大化正确序列对数似然，配分函数用前向算法在 $O(n|\mathcal{Y}|^2)$ 内计算，解码用 Viterbi。CRF 转移矩阵会自动学到 `B-PER→I-PER` 合法、`B-PER→I-LOC` 与 `O→I-PER` 非法等约束。BERT+CRF 以 BERT 替换 BiLSTM，将 CoNLL-2003 英语 F1 提升至 93% 以上。此外还有多任务学习、跨度提取（直接预测实体首尾）与少样本 NER 等方向。

### 9.5.4 评估与本节小结

NER 评估区分实体级与令牌级两种粒度。实体级要求边界与类型完全一致，$TP$ 为完全正确的实体、$FP$ 为预测错误、$FN$ 为漏检，精确率、召回率与 F1 为

$$P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN},\quad F_1=\frac{2PR}{P+R}$$

例如真实实体为 `[Barack Obama]_PER` 而预测为 `[Barack]_PER [Obama]_PER`，则 TP=1、FP=2、FN=1。令牌级对每个标签独立计算，可用 micro-average（汇总 TP/FP/FN，受高频标签如 `O` 主导）或 macro-average（各类分别计算后平均，对所有标签一视同仁）。NER 领域通常报告实体级 micro-F1。严格匹配要求边界与类型完全一致，宽松匹配允许边界重叠或仅类型正确。方法演进可概括为下表。

| 方法 | 特点 | 优势 | 局限 |
|:---|:---|:---|:---|
| HMM | 生成式、bigram 转移 | 训练简单、可解释 | 仅捕捉局部依赖 |
| CRF | 判别式、特征模板 | 灵活用特征、全局最优 | 需人工设计特征 |
| BiLSTM | 神经网络、端到端 | 自动学习特征 | 不保证标签一致性 |
| BiLSTM-CRF | 神经网络 + CRF 解码 | 上下文编码 + 全局约束 | 训练开销较大 |
| BERT-CRF | 预训练 + CRF 解码 | 最强上下文表示 | 推理成本高 |

序列标注是 NLP 从规则到统计、从浅层到深层演进的典型范例，其主线是用更强大的表示学习替代人工特征，同时保留对结构化输出的约束建模。

## 9.6 句法分析

句法分析（Syntactic Parsing）把线性词序列转化为层次化句法结构，回答"谁修饰谁、谁是谓语的论元、短语边界在哪里"。两大范式是成分句法分析（Constituency Parsing）与依存句法分析（Dependency Parsing），前者从短语结构出发、后者从词间支配关系出发，为同一语言现象提供互补视角。句法分析的核心挑战包括：歧义（一个句子的合法句法树数量可随长度按卡塔兰数增长，如"I saw the man with a telescope"有两种解释）、长距离依赖、口语与噪声的鲁棒性以及领域适应。

### 9.6.1 成分句法分析

成分句法分析源自结构主义语言学，认为句子由短语递归构成，目标是找出短语结构树。上下文无关文法（Context-Free Grammar, CFG）是最基础的形式化工具，为四元组 $G=\langle N,\Sigma,R,S\rangle$，其中 $N$ 是非终结符（句法范畴）、$\Sigma$ 是终结符（词）、$R$ 是形如 $A\to\beta$ 的产生式、$S$ 是起始符号。简化英语子集的规则如 $S\to NP\;VP$、$NP\to Det\;N$、$VP\to V\;NP$、$PP\to P\;NP$ 等。

CKY 算法（Cocke-Kasami-Younger）是基于动态规划的 CFG 分析算法，要求文法为乔姆斯基范式（Chomsky Normal Form, CNF），即规则形如 $A\to B\;C$ 或 $A\to w$。它维护二维表 $\pi[i,j]$ 存储能推导子串 $w_i\cdots w_j$ 的非终结符，枚举分割点 $k$ 组合左右两半，时间复杂度 $O(n^3|G|)$、空间复杂度 $O(n^2|N|)$。图句法分析（Chart Parsing）用活动边（部分匹配的产生式）与非活动边（已完成的推导）缓存中间结果，避免重复计算；自底向上从词归约，自顶向下从 $S$ 预测，实际系统常用 Earley 或左角解析等混合策略。

Penn Treebank（PTB, Marcus 等, 1993）用括号标记法标注约 100 万词的华尔街日报句法树，极大推动了统计句法分析。概率上下文无关文法（PCFG）为每条规则附加概率 $P(A\to\beta)=\text{Count}(A\to\beta)/\text{Count}(A)$，把 CKY 扩展为最优句法树搜索。但 PCFG 有强烈的独立性假设，导致结果常不准确；后续用词汇化（如 Collins parser, 1997）、子范畴化与潜伏变量（Klein & Manning, 2003）等方法缓解。

### 9.6.2 依存句法分析

依存句法分析源自 Tesnière 的依存语法，用有向边直接表示词与词之间的支配关系。依存树 $D=(V,A)$ 中，0 是人工添加的根节点（ROOT），1 到 $n$ 对应句中的词，弧 $(h,m)$ 表示词 $h$ 支配词 $m$。依存树必须满足单根性、连通性、无环性与单头性（每个非根词恰有一条入弧）。其优势是：依存关系直接对应语义—句法联系、适应自由词序语言、表示紧凑（$n$ 个词恰有 $n-1$ 条边）、标注成本低于成分标注。Universal Dependencies（UD, Nivre 等, 2014）提供跨语言标签体系，含 `nsubj`（名词性主语）、`obj`（直接宾语）、`amod`（形容词修饰语）、`det`（限定词）、`nmod`、`case`、`root` 等。

基于转移（Transition-based）的方法把分析建模为状态机上的动作序列预测。配置 $c=(\sigma,\beta,A)$ 由栈、缓冲区与已建弧集合构成。Arc-Standard 系统含三种动作：`SHIFT` 把缓冲区首词移入栈，`LEFT-ARC` 令栈顶支配次栈顶，`RIGHT-ARC` 令次栈顶支配栈顶；$n$ 个词恰好需要 $2n$ 步。Arc-Eager 系统增加 `REDUCE` 动作，具有增量性——已添加的弧在后续不会被撤销。早期基于转移的解析用人工特征加分类器（Yamada & Matsumoto, 2003；Nivre, 2003），现多由神经网络端到端预测动作。

基于图（Graph-based）的方法把依存分析视为在完全有向图上寻找最大生成树：

$$T^*=\arg\max_{T\in\mathcal{T}(G)}\sum_{(h,m)\in T}s(h,m)$$

一阶（arc-factored）模型假设弧得分可加，可用 Eisner 算法（限投射树，$O(n^3)$）或 Chu-Liu/Edmonds 算法（允许非投射，$O(n^2)$）求解；高阶模型进一步考虑相邻兄弟或祖父—父—孙三元组。Dozat & Manning（2017）的 Biaffine Parser 将图方法与深度学习结合：BiLSTM 编码后经两个 MLP 分别得到头表示与依存词表示（打破对称性），用双仿射变换为弧打分

$$s_{\text{arc}}(i,j)=\mathbf{r}_j^{\text{dep}\top}\mathbf{U}\mathbf{r}_i^{\text{head}}+\mathbf{w}^\top[\mathbf{r}_i^{\text{head}};\mathbf{r}_j^{\text{dep}}]+b$$

再以另一双仿射层预测依存关系标签，联合优化弧与标签的交叉熵损失。该方法简洁优雅，显著优于传统特征工程。

### 9.6.3 评估与两种范式对比

依存分析的标准指标是 UAS（无标签依存正确率，即中心词预测正确的词占比）与 LAS（有标签依存正确率，中心词与关系标签都正确的占比），另有整句完全匹配的 UEM、LEM。成分分析用 PARSEVAL 的精确率、召回率、F1（均基于短语匹配）与 Crossing Brackets。现代 Biaffine Parser 在 PTB 上 LAS 约 94%，结合 BERT 可达 95%。两种范式对比如下。

| 维度 | 成分句法分析 | 依存句法分析 |
|:---|:---|:---|
| 理论基础 | 结构主义、Chomsky 形式语法 | Tesnière 依存语法 |
| 输出结构 | 短语结构树（含短语节点） | 有向依存树（仅词节点） |
| 核心算法 | CKY、Earley、Chart Parsing | Eisner、Chu-Liu/Edmonds、转移系统 |
| 跨语言适用性 | 对 SVO 语言较自然 | 对自由词序语言更灵活 |
| 语义接口 | 需额外组合语义规则 | 依存关系直接对应语义角色 |
| 典型树库 | Penn Treebank | Universal Dependencies |

基于转移的方法在线性时间内增量解析但可能因早期错误级联（误差传播）；基于图的方法能求全局最优、天然支持非投射，但计算更昂贵。两者在神经时代逐渐融合，共享上下文编码器。

## 9.7 语义角色标注与语义解析

### 9.7.1 语义角色标注概述

语义角色标注（Semantic Role Labeling, SRL）识别句子中的谓词—论元结构（predicate-argument structure），回答"谁对谁做了什么"。与句法分析关注词间语法依存不同，SRL 关注语义参与者：句法结构不同的"John broke the window"与"The window was broken by John"应得到相同的语义角色——施事者（Agent）都是 John，受事者（Patient）都是 window。SRL 为问答、信息抽取、机器翻译、摘要等任务提供了与表层句法无关的语义表示层，是连接句法与深层语义的桥梁。它与依存句法分析（输出依存弧）、语义解析（输出逻辑式）、关系抽取（输出三元组）的区别如下表。

| 任务 | 分析对象 | 输出形式 | 示例 |
|:---|:---|:---|:---|
| SRL | 谓词—论元结构 | 论元角色标签 | `[John]_A0 broke [the window]_A1` |
| 依存句法分析 | 词间依存关系 | 依存弧 | $broke → John (nsubj)$ |
| 语义解析 | 自然语言到形式语义 | 逻辑表达式 | `break(John, window)` |
| 关系抽取 | 实体间关系 | 三元组 | `(John, broke, window)` |

### 9.7.2 语义角色体系

PropBank（Proposition Bank, Palmer 等, 2005）是最广泛使用的 SRL 语料库，其核心思想是为每个动词义项定义一组编号论元。核心论元 $ARG0\sim ARG5$ 中，ARG0 通常对应施事者或经验者，ARG1 对应受事者或主题，ARG2 及以后依动词而异（受益者、工具、起点、终点等）。修饰性论元以 `ARGM-` 前缀表示，包括时间（TMP）、地点（LOC）、方式（MNR）、原因（CAU）、目的（PRP）、否定（NEG）、情态（MOD）、副词性（ADV）与话语连接（DIS）等。同一动词的不同义项有独立框架，例如 run.01（奔跑）中 ARG0 是跑步者，run.02（经营）中 ARG0 是经营者。以 `[Mary] broke [the window] [with a rock] [yesterday]` 为例，ARG0=Mary、ARG1=the window、ARGM-MNR=with a rock、ARGM-TMP=yesterday。

NomBank（Meyers 等, 2004）把框架扩展到名词化谓词（如 destruction、arrival），其论元常通过介词短语或所有格实现，识别难度更高。其他框架中，FrameNet 基于框架语义学、角色名称语义透明，VerbNet 结合 Levin 动词分类并带选择限制，Universal Propositions 提供跨语言统一编号论元。

### 9.7.3 SRL 方法

最早的 SRL 把论元识别建模为序列标注，用 BIO 方案为每个词标 `B-ARGX`、`I-ARGX` 或 `O`。但它无法处理嵌套论元（如"the destruction of the city"中 the city 同时是内部论元）、不连续论元以及多谓词句。改进方案包括 BIOES（增加结束与单词论元标签）与在输入中加入谓词指示特征。

基于片段（Span-based）的方法枚举所有连续片段 $w_{i:j}$，为每个片段—谓词对评分，用首尾词表示、逐元素乘积与宽度特征构成片段表示，再经前馈网络分类。它能显式建模边界、支持嵌套论元，但复杂度为 $O(n^2)$。基于依存（Dependency-based）的方法把论元表示为依存树中谓词的依存子树，由依存路径确定边界，天然支持不连续论元，但强依赖依存分析质量。

神经 SRL 模型中，注意力机制用于建模谓词与候选论元的关联，CRF 层用于保证标签序列合法。BERT-based SRL 利用深层上下文表示：将谓词标记插入输入（如 `[CLS] The boy [PRED] kicked [/PRED] the ball [SEP]`），再把谓词表示与各词表示交互后解码。多谓词共享同一遍 BERT 编码以提高效率。在 CoNLL-2005 英语测试集上，传统特征工程 + SVM 约 75.9% F1，BiLSTM+CRF 约 81.0%，BERT-large+CRF 达 86.9%。

### 9.7.4 语义解析

语义解析（Semantic Parsing）把自然语言转换为形式化语义表示，使语义可由计算机执行或推理。其核心挑战包括：歧义（"Every student read a book"存在宽域/窄域歧义）、组合性（Frege 原则：句子意义由组成部分按句法结构组合）、词汇与形式谓词的非一一对应以及高昂的标注成本。

Lambda 演算（$\lambda$-calculus）是最经典的形式语义框架。基本类型包括实体类型 $e$、真值类型 $t$，以及函数类型 $\langle e,t\rangle$（一元谓词）、$\langle e,\langle e,t\rangle\rangle$（二元谓词）。组合规则有函数应用与 $\lambda$ 抽象；量词类型为 $\langle\langle e,t\rangle,t\rangle$。例如"Every student likes some teacher"可自底向上组合为 $\forall x.[\text{student}(x)\supset\exists y.[\text{teacher}(y)\land\text{like}(x,y)]]$。

组合范畴语法（Combinatory Categorial Grammar, CCG, Steedman, 2000）是高度词汇化的形式语法，把句法与语义统一在同一推导中。每个词被赋予范畴（基本范畴如 $S$、$NP$、$N$，复合范畴用斜线表示函数类型），通过前向/后向应用、组合与提升等有限规则把相邻成分组合，推导同时产出句法树与语义表达式。例如 likes 的范畴为 $(S\backslash NP)/NP$，语义为 $\lambda y.\lambda x.\text{like}(x,y)$。

抽象语义表示（Abstract Meaning Representation, AMR, Banarescu 等, 2013）是句子级语义图，把句子抽象为有根有向无环图。概念节点用 PropBank 义项、命名实体或抽象概念表示，边用 `:arg0`、`:arg1`、`:mod`、`:location` 等关系。AMR 剥离时态、语态、冠词等句法信息，并把不同介词统一为语义关系；变量复用支持共指。例如"The boy wants to go"表示为

```text
(w / want-01
    :arg0 (b / boy)
    :arg1 (g / go-02
        :arg0 b))
```

AMR 解析方法分三类：基于图（先预测概念节点再预测关系边）、基于序列（把图线性化为字符串用 Seq2Seq 生成）与基于转移（通过 SHIFT、REDUCE、ARC 等动作逐步建图）。SRL、$\lambda$ 演算、CCG、AMR 的表示粒度、形式化程度与可执行性各不相同，其中 $\lambda$ 演算与 CCG 语义可执行、可推理，AMR 更接近自然语言语义、应用偏文本生成与机器翻译。

SRL 与语义解析在问答（定位问题中 who 对应的 ARG0；把问题转为 SPARQL 查询）、信息抽取（为事件抽取提供谓词—论元基础）、机器翻译（检验译前译后论元角色一致）、摘要与语义相似度计算中均有应用。

## 9.8 文本分类与情感分析

### 9.8.1 文本分类概述

文本分类（Text Classification）把一段文本映射到一个或多个预定义类别，是应用最广泛的任务之一。主要子任务包括：主题分类（如 20 Newsgroups、AG News）、垃圾邮件检测（朴素贝叶斯早在 2002 年就被 Graham 用于反垃圾邮件）、情感分析、对话中的意图识别与语言检测。在深度学习兴起前，文本分类依赖手工设计的稀疏特征。

### 9.8.2 传统特征与分类器

词袋模型（Bag-of-Words, BoW）忽略词序与语法，仅统计词频，把文档表示为 $|V|$ 维向量。它实现简单、可解释性强，但完全丢失词序（"狗咬人"与"人咬狗"表示相同），维度极高且无法捕捉语义相似性。TF-IDF 通过同时考虑词频（TF）与逆文档频率（IDF）解决高频常见词区分力弱的问题：

$$\text{TF}(t,d)=\frac{c(t,d)}{\sum_{t'\in d}c(t',d)},\quad \text{IDF}(t)=\log\frac{N}{\text{df}(t)},\quad \text{TF-IDF}=\text{TF}\times\text{IDF}$$

一个词若在当前文档频繁、在语料中稀有，则区分力强；"的"虽 TF 高但 IDF 极低，权重被抑制。为避免除零，IDF 常写为 $\log\frac{N}{\text{df}(t)+1}+1$。为弥补词序丢失，可引入 N-gram 特征（如 unigram+bigram），但特征空间会指数增长，需配合特征选择或正则化。

在特征向量之上可用多种经典分类器。朴素贝叶斯（Naive Bayes, NB）假设特征在给定类别下条件独立，取对数避免下溢，其中多项式 NB 最适合词频特征；虽然独立性假设几乎不成立，但其低方差特性使其在高维稀疏文本上极具竞争力。支持向量机（Support Vector Machine, SVM）寻找最大间隔超平面，在高维稀疏 TF-IDF 特征上表现优异，线性核通常优于核 SVM。逻辑回归（Logistic Regression, LR）用 sigmoid 把线性组合映射到概率，支持 L1/L2 正则、训练高效，是工业界的常用基线。三者对比如下。

| 分类器 | 训练速度 | 对稀疏高维数据 | 可解释性 | 多分类支持 |
|:---|:---|:---|:---|:---|
| 朴素贝叶斯 | 极快 | 良好 | 高 | 原生支持 |
| SVM | 较慢 | 优秀 | 中 | 需 One-vs-Rest |
| 逻辑回归 | 快 | 良好 | 高 | softmax 原生支持 |
| 随机森林 | 中 | 一般 | 中 | 原生支持 |

### 9.8.3 深度学习方法

深度学习自动学习特征表示，无需手工设计 TF-IDF 或 N-gram。TextCNN（Kim, 2014）把一维卷积用于词嵌入序列，用不同窗口大小（如 3、4、5）的卷积核捕捉局部 N-gram 模式，经 max-over-time pooling 得到固定长度表示，再经 Dropout 与全连接层分类。关键设计是卷积核大小、每种大小的核数量、激活函数（ReLU）与 Dropout 率。

LSTM 与 GRU 通过门控机制建模序列依赖，可取最后隐状态或所有隐状态平均池化作为文档表示；双向 LSTM（BiLSTM）拼接两个方向的隐状态以获得更全面上下文；BiLSTM + Attention 对隐状态加权聚合，自适应聚焦关键位置。BERT 微调则取最后一层 `[CLS]` 的隐状态接线性分类层，端到端微调整个模型，学习率通常为 $2\times10^{-5}\sim5\times10^{-5}$，并采用线性预热加衰减、2–4 个 epoch，必要时使用层次学习率衰减。各方法在 SST-2 上的典型准确率如下。

| 方法 | 长距离依赖 | 并行化 | 预训练需求 | SST-2 准确率 |
|:---|:---|:---|:---|:---|
| TextCNN | 弱（局部 N-gram） | 完全并行 | 可选 | ~87% |
| BiLSTM | 强 | 顺序计算 | 可选 | ~88% |
| BiLSTM + Attention | 强 | 顺序计算 | 可选 | ~89% |
| BERT-base | 极强 | 完全并行 | 大规模语料 | ~93% |
| RoBERTa-large | 极强 | 完全并行 | 更大规模 | ~96% |

### 9.8.4 情感分析

情感分析（Sentiment Analysis）又称意见挖掘（Opinion Mining），识别文本中的主观情感信息。按粒度分为三个层次。文档级把整篇文档归入整体情感类别，假设文档表达一种主导情感，方法从情感词典加权求和，到 BoW/TF-IDF + NB/SVM/LR（Pang 等 2002 年 SVM 达约 83%），再到 BERT（SST-2 二分类已超 95%）。句子级对单个句子判断极性，面临更严重的数据稀疏，且易受否定、反讽影响，预训练模型优势更明显。

方面级情感分析（Aspect-Based Sentiment Analysis, ABSA）针对文本中每个具体方面分别判断情感。例如"菜品非常精致，但服务态度很差，价格也偏高"中，菜品为正面、服务与价格为负面。其子任务包括方面词提取、方面情感分类、方面—情感对抽取与观点词抽取，典型方法有以方面为 query 的注意力、基于依存树与图卷积网络（GCN）的方法，以及把句子与方面拼接送入 BERT 的方法（SemEval 评测中最优）。

### 9.8.5 评估指标

分类与情感分析常用准确率、精确率、召回率、F1 与 $F_\beta$：

$$\text{Acc}=\frac{TP+TN}{TP+TN+FP+FN},\quad P=\frac{TP}{TP+FP},\quad R=\frac{TP}{TP+FN},\quad F_1=\frac{2PR}{P+R}$$

类别不平衡时准确率具有误导性，应优先使用 Macro-F1 或 Weighted-F1；关注假阳性（如垃圾邮件）时重视精确率，关注假阴性（如疾病检测）时重视召回率。多分类可用 macro-average（各类平均，受少数类影响大）或 micro-average（汇总后计算，受大类主导）。混淆矩阵直观展示各类误判分布。指标选择建议如下表。

| 场景 | 推荐指标 | 原因 |
|:---|:---|:---|
| 类别平衡 | Accuracy、Macro-F1 | 直观且公平 |
| 类别不平衡 | Macro-F1、Weighted-F1 | 避免多数类主导 |
| 关注假阳性 | Precision | 减少误判 |
| 关注假阴性 | Recall | 减少漏检 |
| 综合权衡 | F1 | 平衡精确率与召回率 |

## 9.9 信息抽取

### 9.9.1 信息抽取概述

信息抽取（Information Extraction, IE）从非结构化文本中自动提取结构化知识，关注实体之间的语义关系与文本描述的事件结构，是知识图谱构建、问答与知识推理的基础设施。其任务群包括命名实体识别（见 §9.5）、关系抽取、事件抽取、共指消解与命名实体链接。典型应用有知识图谱构建、生物医学文献挖掘（基因—疾病关联、药物—靶点）、金融事件监测与智能问答。

### 9.9.2 关系抽取

关系抽取（Relation Extraction, RE）给定句子 $s$ 与实体对 $(e_1,e_2)$，从预定义关系集合 $\mathcal{R}$ 中判定关系或判定为无关系（NA）。按关系类型集合可分为封闭关系分类与开放关系抽取；按训练信号分为有监督、远程监督与少样本；按粒度分为句子级、袋级与文档级；按架构分为管道式与联合抽取。

远程监督（Distant Supervision, Mintz 等, 2009）的核心假设是：若知识库中存在三元组 $(e_1,r,e_2)$，则任何同时包含两实体的句子都可能表达关系 $r$。它可自动对齐知识库与大规模无标注文本，但假设过强会引入噪声——例如知识库关系为"创始人"，而"马云出席阿里巴巴的云大会"并未表达该关系。缓解策略包括多实例学习（把同一实体对的所有句子构成一个"袋"，在袋级预测）、句子级注意力降噪（Lin 等 2016 的 PCNN+ATT 为每个句子赋权）、强化学习选择器（筛选干净句子）与预训练语言模型。袋级关系抽取的代表模型有 PCNN、PCNN+ATT、PCNN+RL、BERT+ATT 与 SENT（Matching the Blanks）。

有监督方法中，CNN-based RE（Zeng 等, 2014）用词嵌入加位置特征（相对实体距离的嵌入）做卷积与最大池化。BERT-based RE 则拼接 `[CLS]` 向量，或用实体标记 `[E1]`、`[/E1]`、`[E2]`、`[/E2]` 显式注入边界信息。Matching the Blanks 通过把实体替换为特殊标记做自监督预训练，使模型获得关系感知能力。在 SemEval-2010 Task 8 上，CNN+PF 约 82.7% F1，BERT-base 约 89.5%，实体标记增强约 90.2%，MTB 预训练约 92.0%。

文档级关系抽取（DocRE）需要跨句推理、多跳推理、共指消解与关系重叠处理。代表数据集有 DocRED（Wikipedia，5,053 篇文档、96 种关系）、CDR 与 GDA（生物医学）。主流架构包括异构图上的图神经网络（AGGCN、LSR）、Transformer 方法（ATLOP 用自适应阈值分类解决多标签阈值选择）与证据增强方法（DREEAM 同时识别支持关系的证据句）。少样本关系抽取把任务建模为 N-way K-shot 分类，代表方法有 SNAIL、MetaNet、PAIR、CNL 与 MTB；原型网络把每个关系类型支持样本的编码均值作为原型向量，查询样本与最近原型匹配。

联合抽取同时识别实体与关系，避免管道式的误差传播。CasRel（Wei 等, 2020）先识别所有 subject，再为每个 subject 标注 object 的首尾位置；TPLinker 把三元组抽取转化为 token 对链接；PRGC 先预测潜在关系子集再逐关系标注实体对。工业级知识图谱构建流程通常为：语料收集 → NER 与关系抽取生成候选三元组 → 去重融合 → 质量验证 → 导入图数据库。

### 9.9.3 事件抽取

事件抽取（Event Extraction, EE）从文本中识别事件及其结构化信息，关注"谁在何时何地做了什么"。ACE 框架中，事件由触发词（最能表达事件发生的词，通常是动词或名词）、事件类型、事件论元与论元角色构成。以"马云于 1999 年在杭州创立了阿里巴巴"为例，触发词为"创立"、事件类型为 `Business:Start-Org`，论元包括 Agent=马云、Patient=阿里巴巴、Time=1999 年、Place=杭州。ACE 项目定义了 8 大类、33 子类事件类型（如 Life、Movement、Transaction、Business、Conflict、Contact、Personnel、Justice），ACE 2005 数据集含 599 篇文档。

事件抽取方法分为管道式与联合式。管道式先做事件检测（识别触发词并分类，本质是词级分类），再做论元抽取，两步独立训练，存在误差传播与信息丢失。联合抽取同时进行，代表模型有 JMEE（图注意力网络编码依存树）、OneIE（BERT 之上多任务学习 NER、关系抽取与事件抽取）、EEQA（把事件抽取转为阅读理解问答）与 Text2Event（把事件抽取转为序列生成）。事件检测的核心挑战是触发词歧义——"攻击"可触发冲突事件、对应事件或不触发事件；方法从动态多池化 CNN（DMCNN），到注意力方法（JMEE），再到加入事件类型感知注意力的 BERT 方法。

### 9.9.4 命名实体链接与评估

命名实体链接（Named Entity Linking, NEL）又称实体消歧，把文本中的实体提及链接到知识库条目。例如"苹果"在科技语境链接到 Apple Inc.、在农业语境链接到水果。其流程为提及检测、候选生成与候选排序，排序特征包括先验概率 $P(e\mid m)$（常从 Wikipedia 锚文本统计）、上下文相似度与实体一致性（文档中链接实体在知识库中的共现一致性）。

信息抽取评估在实体级、关系级与事件级两个层次上进行，均使用精确率、召回率与 F1，并区分严格匹配（边界、类型、关系完全一致）与宽松匹配（边界重叠、类型或关系一致）。事件抽取的 ACE 标准包含 Trig-C（触发词与类型正确）、Trig-AC（触发词正确且至少一个论元正确）、Arg-C（论元边界与角色均正确）与 Arg-CM（边界不完全匹配但共指正确）。标准数据集上的性能可概括为：SemEval-2010 Task 8 约 92.0% F1、TACRED 约 72.5%、DocRED 约 65.0%、ACE 2005 事件检测约 73.0%、论元抽取约 62.0%。

## 9.10 机器翻译

### 9.10.1 机器翻译概述

机器翻译（Machine Translation, MT）把一种语言（源语言）的文本自动翻译为另一种语言（目标语言）。自 1954 年 Georgetown-IBM 实验以来，它经历了从基于规则（RBMT、SYSTRAN）、统计（SMT、IBM Models、Moses）到神经（NMT、Seq2Seq、Transformer）的范式转变。核心挑战包括词义歧义、结构重排（如 SVO 与 SOV 语序差异）、形态学差异、长距离依赖与低资源语言。

### 9.10.2 统计机器翻译

统计机器翻译（Statistical Machine Translation, SMT）把翻译建模为噪声信道问题，由贝叶斯定理把后验概率分解为翻译模型与语言模型：

$$\hat{e}=\arg\max_e P(e\mid f)=\arg\max_e P(f\mid e)\cdot P(e)$$

其中翻译模型 $P(f\mid e)$ 捕捉"如何翻译"，语言模型 $P(e)$ 保证译文流畅。IBM Models 1–5（Brown 等, 1993）逐步学习词对齐：Model 1 仅考虑词翻译概率并假设对齐均匀，用 EM 算法训练；Model 2 引入位置相关的对齐概率；Model 3 引入繁殖率（一个目标词产生多个源词的概率）与失真概率，能处理一对多翻译；Model 4 引入相对位置偏移以建模局部重排；Model 5 修正退化对齐问题使概率和为 1。

IBM Models 基于单词，无法捕捉多词表达与局部重排。短语级 SMT（Phrase-Based SMT, Koehn 等, 2003）通过词对齐工具（如 GIZA++）抽取短语对并计算双向翻译概率与词汇化权重，解码器（如 Moses）逐步构建翻译假设，调序模型处理语序差异：

$$\text{score}(e)=P_{\text{LM}}(e)\cdot\prod_i\phi(\bar{f}_i\mid\bar{e}_i)\cdot\prod_i d(\text{start}_i-\text{end}_{i-1}-1)$$

### 9.10.3 神经机器翻译

神经机器翻译（Neural Machine Translation, NMT）用端到端网络直接建模 $P(y\mid x)$，无需手工特征或短语表。Seq2Seq（Sutskever 等, 2014）由编码器与解码器两个 RNN 组成，编码器把源句压为上下文向量 $c$，解码器以 $c$ 为初始状态自回归生成译文。其瓶颈是整个源句信息被压缩到固定长度向量，长句信息丢失严重。Bahdanau 等（2015）的注意力机制让解码器每步动态关注源句不同部分：计算对齐分数 $e_{t,i}=v^T\tanh(W_s s_{t-1}+W_h h_i)$，softmax 归一化后对编码器隐状态加权求和得上下文向量 $c_t$；Luong 注意力则用更简洁的乘性对齐分数。

Transformer（Vaswani 等, 2017）完全抛弃 RNN，仅用自注意力实现序列建模。其编码器—解码器用于机器翻译的关键组件包括：多头自注意力（编码器内任意位置可直接交互）、掩码自注意力（解码器保证因果性）、交叉注意力（查询来自解码器、键值来自编码器，桥接源语言信息）与位置编码。组件对比如下。

| 组件 | Seq2Seq + Attention | Transformer |
|:---|:---|:---|
| 序列建模 | RNN（LSTM/GRU） | 自注意力 |
| 并行化 | 困难 | 完全并行 |
| 长距离依赖 | 受梯度消失限制 | 直接建模 |
| 编码器—解码器交互 | 注意力（单向） | 交叉注意力（双向） |
| 位置信息 | 隐式（RNN 顺序） | 显式（位置编码） |

NMT 面临开放词汇问题，BPE 分词（Sennrich 等, 2016）通过把罕见词拆为更常见的子词单元解决 OOV；SentencePiece 与 WordPiece 是其流行实现与类似算法。回译（Back-Translation）利用单语数据增强训练：先训练反向翻译模型，把目标语言单语语料译为源语言生成伪平行语料，再与真实平行语料混合训练正向模型，在低资源场景下效果尤为显著。

### 9.10.4 多语言翻译与解码

多语言 NMT 用一个模型处理多种语言对，通常采用共享编码器—解码器加语言标记（如 `<2en>`、`<2zh>`）的框架，使用统一共享词表并按温度采样平衡各语言对数据量。mBART（Liu 等, 2020）在 25 种语言单语语料上做去噪自编码预训练，微调时实现跨语言迁移；M2M-100（Meta, 2020）用 75 亿平行句对覆盖 100 种语言、4,450 个方向，是首个无需英语中转的直接多对多翻译模型。零样本翻译指翻译训练中从未见过的语言对，依赖共享编码器把各语言映射到统一语义空间；其质量通常低于枢纽翻译，但可通过对抗训练、回译增强与大模型预训练缩小差距。

推理时 NMT 自回归生成译文。贪心解码每步选概率最高的词但常非全局最优；束搜索（Beam Search）维护 $k$ 个候选假设，每步扩展并保留得分最高的 $k$ 个，为偏好短句通常做长度归一化。束宽越大质量越好但收益递减，实践中常用 4–5。多样束搜索通过在不同束组间施加多样性惩罚生成差异化候选。

### 9.10.5 机器翻译评估

BLEU（Bilingual Evaluation Understudy, Papineni 等, 2002）基于候选与参考译文的 n-gram 精度，并加简短惩罚防止生成过短译文刷高精度：

$$\text{BLEU}=\text{BP}\cdot\exp\left(\sum_{n=1}^{N}w_n\log p_n\right)$$

匹配数会被截断到参考中的最大出现次数，避免重复词刷分；$N$ 通常取 4，权重均匀；简短惩罚 $\text{BP}=\min(1,e^{1-r/c})$。BLEU 简单、快速、广泛使用，但不考虑同义词、对召回不敏感。METEOR 引入同义词、词干与释义匹配并兼顾召回，与人工判断相关性更高；TER 用编辑距离衡量把候选改为参考所需的最少编辑操作，越低越好。人类评估仍是黄金标准，维度包括充分度、流畅度、直接评估（DA）与 MQM 错误分类；近年来也用大语言模型自动评估（如 GEMBA）。各指标对比如下。

| 指标 | 核心思想 | 优点 | 缺点 |
|:---|:---|:---|:---|
| BLEU | n-gram 精度 + 短惩罚 | 简单、快、通用 | 不懂同义词、忽略召回 |
| METEOR | 精度—召回 F 值 + 对齐 | 与人类判断相关性高 | 依赖语言资源 |
| TER | 编辑距离 | 直观可解释 | 不区分错误严重程度 |
| 人类评估 | 人工判断充分度与流畅度 | 黄金标准 | 成本高、主观 |

## 9.11 文本摘要

### 9.11.1 文本摘要概述

文本摘要（Text Summarization）从一篇或多篇源文档生成简短、准确且流畅的摘要，在压缩长度的同时保留关键信息与语义完整性。按输入数量分为单文档与多文档摘要，按生成方式分为抽取式与生成式摘要——这是最核心的二分。抽取式从原文选取句子，事实一致性天然有保证、模型相对简单，但受限于原文句子衔接；生成式重新生成文本，可改写融合、更流畅，但存在幻觉风险。二者对比如下。

| 维度 | 抽取式 | 生成式 |
|:---|:---|:---|
| 生成方式 | 选取原文句子 | 重新生成文本 |
| 流畅性 | 受原文衔接限制 | 更自然流畅 |
| 事实一致性 | 天然保证 | 存在幻觉风险 |
| 模型复杂度 | 较低 | 较高 |
| 典型应用 | 新闻、法律文书 | 对话摘要、抽象场景 |

### 9.11.2 抽取式摘要

抽取式摘要把任务形式化为句子选择：为文档中每个句子计算重要性得分，选取得分最高的 $k$ 句。基于 TF-IDF 的句子评分为 $\text{score}(s_i)=\sum_{w\in s_i}\text{tf}(w,s_i)\cdot\text{idf}(w)$，直觉是包含在文档中相对稀有但在句中频繁出现词语的句子更重要；它简单高效但忽略句子间语义关系。

TextRank（Mihalcea & Tarau, 2004）把 PageRank 引入摘要：以句子为节点、句子相似度（TF-IDF 向量的余弦相似度）为边构建无向加权图，迭代更新

$$\text{TR}(v_i)=(1-d)+d\sum_{v_j\in\text{In}(v_i)}\frac{w_{ji}}{\sum_{v_k\in\text{Out}(v_j)}w_{jk}}\text{TR}(v_j)$$

阻尼因子 $d$ 通常取 0.85，迭代至收敛。连接紧密、处于图中心的句子得分高。TextRank 无需训练、能捕捉全局关系，但仅基于词袋、对句子长度敏感。位置启发式利用新闻的倒金字塔结构，为靠前句子赋更高先验权重（首句偏置、线性衰减、对数衰减、段落感知）；实验表明直接取前三句的 lead-3 基线已极具竞争力。基于 BERT 的方法为每个句子生成上下文化表示，用分类头预测是否选入摘要，以二元交叉熵训练；BertSum 是经典工作，MatchSum 引入排列感知的对比学习。

### 9.11.3 生成式摘要

生成式摘要建模为条件文本生成 $y^*=\arg\max_y\prod_{t=1}^{m}P(y_t\mid y_{<t},d)$。基础 Seq2Seq 由编码器与解码器加注意力构成，存在 OOV 词、重复生成与事实不一致三个核心问题。Pointer-Generator Network（See 等, 2017）引入复制机制，每个解码步计算生成概率 $p_{\text{gen}}$，在词汇表生成与从源文档复制之间加权混合，使模型能直接"指向"源文档中的词（含 OOV 词）。覆盖机制（Coverage）维护覆盖向量记录已关注位置并加入注意力计算与覆盖损失，缓解重复生成。

预训练模型进一步推动生成式摘要。BART（Lewis 等, 2020）基于去噪自编码，对输入施加 token 遮蔽、删除、文本填充、句子打乱、文档旋转等噪声后恢复原文，采用 12 层双向编码器加 12 层自回归解码器；T5（Raffel 等, 2020）把所有任务统一为文本到文本格式（输入 `summarize: <document>`），用跨度损坏（Span Corruption）预训练；PEGASUS（Zhang 等, 2020）专为摘要设计间隙句生成（GSG）预训练目标，用 ROUGE-1 F1 选择重要句子并遮蔽，训练模型生成这些句子，与下游任务高度对齐。多文档摘要（MDS）需处理信息冗余、冲突与时序关系，典型方法有先抽取再生成、分层编码（含 GNN 建模文档间关系）与全局—局部注意力。

### 9.11.4 摘要评估与数据集

ROUGE（Recall-Oriented Understudy for Gisting Evaluation, Lin, 2004）通过系统摘要与参考摘要的 n-gram 重叠衡量质量。ROUGE-N 基于 n-gram 召回率，ROUGE-1 衡量词汇覆盖、ROUGE-2 衡量短语流畅性；ROUGE-L 基于最长公共子序列（LCS），能捕捉句子级结构相似性；ROUGE-SU 基于允许间隔的 skip-bigram，对词序变化更鲁棒。在 CNN/DailyMail 上，ROUGE-1 常见值约 40–45、ROUGE-2 约 18–22、ROUGE-L 约 36–40。人工评估从信息性、流畅性、忠实度与冗余度打分，是金标准但成本高。基于模型的指标包括 BERTScore（token 嵌入贪心匹配）、MoverScore 与 FactCC（检测事实不一致）。

常用数据集对比如下。

| 数据集 | 领域 | 规模 | 特点 |
|:---|:---|:---|:---|
| CNN/DailyMail | 新闻 | ~312k | 抽取式风格、多句摘要 |
| XSum | 新闻 | ~227k | 极度抽象、单句摘要 |
| MultiNews | 新闻 | ~56k | 多文档摘要 |
| PubMed | 医学 | ~133k | 专业领域、长摘要 |
| arXiv | 科学 | ~215k | 长文档摘要 |
| SAMSum | 对话 | ~16k | 对话摘要 |

前沿挑战包括长文档摘要（分块编码、稀疏注意力、层次化编码）、事实一致性（幻觉检测与 RLHF/对比学习）、低资源摘要（跨语言迁移与少样本）、可控摘要（指定长度、风格、主题）以及 ROUGE 与人类判断相关性不足的问题。

## 9.12 问答系统与信息检索

### 9.12.1 问答系统与信息检索基础

信息检索（Information Retrieval, IR）从大规模文档集合中找到与查询相关的文档或段落；问答系统（Question Answering, QA）进一步直接给出精确答案，二者融合构成现代智能搜索的基础设施。问答系统按信息来源分为基于知识库（KBQA，把问题转为 SPARQL 等查询）、基于文本（检索加阅读理解）与基于表格（SQL 生成）；按生成方式分为抽取式（答案必须是原文连续片段）与生成式（自由生成，可综合推理）；按领域分为开放域（检索—阅读两阶段）与封闭域。

信息检索的经典模型有三个。布尔检索把文档与查询表示为词项的布尔组合，用 `AND`、`OR`、`NOT` 返回满足表达式的文档集合，结果是二值的、无排序，需用户掌握布尔语法。向量空间模型（VSM, Salton 等）把文档与查询表示为高维向量，以 TF-IDF 加权并用余弦相似度排序：

$$\text{sim}(q,d)=\frac{\sum_{t\in T}w_{t,q}w_{t,d}}{\sqrt{\sum_t w_{t,q}^2}\sqrt{\sum_t w_{t,d}^2}}$$

BM25（Best Matching 25）是概率检索框架下对 TF-IDF 的改进，引入词频饱和与文档长度归一化：

$$\text{BM25}(Q,D)=\sum_{t\in Q}\text{idf}(t)\cdot\frac{\text{tf}(t,D)(k_1+1)}{\text{tf}(t,D)+k_1\big(1-b+b\frac{|D|}{\text{avgdl}}\big)}$$

其中 $k_1$ 控制词频饱和（典型 1.2–2.0），$b$ 控制长度归一化（典型 0.75）。词频的边际收益递减，避免高频词过度主导；长度归一化使长短文档可公平比较。倒排索引（Inverted Index）是检索系统的核心数据结构，由词项词典与倒排列表（记录包含该词项的 docID、词频、位置）组成，`AND`/`OR`/`NOT` 对应列表的交/并/差集，排序查询则累加得分后返回 Top-K。

### 9.12.2 神经检索

传统检索基于词项匹配，存在词汇鸿沟：语义相近但用词不同的查询与文档无法匹配。稠密检索用神经网络把查询和文档编码为低维向量，以向量相似度计算相关性。双编码器（Bi-Encoder）分别编码查询与文档，可离线预计算文档向量、在线只编码查询并做近似最近邻搜索。DPR（Dense Passage Retrieval, Karpukhin 等, 2020）用两个独立 BERT 编码器，以对比损失训练，负样本常用 BM25 检索的难负样本。交叉编码器（Cross-Encoder）把查询与文档拼接后过同一 Transformer，能建模细粒度交互、相关性判断更准，但无法离线编码、开销巨大，通常只用于重排序。ColBERT（Khattab & Zaharia, 2020）保留每个 token 的上下文化表示，用延迟交互的 MaxSim 打分：

$$\text{score}(q,d)=\sum_{i=1}^{|q|}\max_{j=1}^{|d|}\vec{q}_i^\top\vec{d}_j$$

文档 token 表示可离线预计算，兼顾语义匹配与效率。各模型对比如下。

| 模型 | 编码方式 | 交互时机 | 离线文档编码 | 适用阶段 |
|:---|:---|:---|:---|:---|
| BM25 | 词袋（稀疏） | 无交互 | 倒排索引 | 粗排/召回 |
| Bi-Encoder（DPR） | 独立编码 | 无交互 | 可离线 | 召回 |
| Cross-Encoder | 拼接编码 | 即时交互 | 不可 | 精排/重排序 |
| ColBERT | 独立编码 | 延迟交互 | 可离线 | 召回+精排 |

### 9.12.3 阅读理解

阅读理解（Reading Comprehension, RC）从检索到的段落中提取或生成答案。SQuAD（Rajpurkar 等, 2016）是影响力最大的基准：SQuAD 1.1 含 10 万以上（问题、段落、答案）三元组，答案为段落中的连续 span；SQuAD 2.0 额外增加约 5 万个不可回答问题，要求模型判断问题是否可回答。BiDAF（Seo 等, 2017）是早期代表性模型，包含字符嵌入、词嵌入、上下文嵌入、双向注意力流、建模与输出层，其关键创新是注意力流层不压缩注意力，而在每步保留权重供后续使用。

BERT-for-QA 把阅读理解建模为序列标注：将问题与段落以 `[SEP]` 拼接，为段落每个 token 预测作为答案起止位置的概率，训练最大化正确起止位置的对数似然。BERT-base 在 SQuAD 1.1 上 F1 达 80.8（BiDAF 为 77.3），BERT-large 达 84.2，接近人类的 91.2。抽取式与生成式 QA 对比如下。

| 维度 | 抽取式 QA | 生成式 QA |
|:---|:---|:---|
| 答案来源 | 原文连续 span | 模型自由生成 |
| 典型模型 | BERT-for-QA、BiDAF | T5、BART、GPT |
| 答案忠实性 | 高 | 中（可能幻觉） |
| 多文档聚合 | 困难 | 可综合 |
| 不可回答检测 | 需显式建模 | 可自然表达 |

### 9.12.4 检索增强生成与评估

检索增强生成（Retrieval-Augmented Generation, RAG, Lewis 等, 2020）在生成前先从外部知识库检索相关文档，将其作为上下文注入生成模型：$\text{answer}=\text{Generator}(q,d_1,\dots,d_K)$。其优势是知识可更新、答案可溯源、减少幻觉；挑战是检索噪声、长上下文处理与检索—生成联合优化（RAG 详见 §9.16）。

检索评估指标包括：平均倒数排名（MRR）衡量第一个相关结果的排名，适合"只需一个正确答案"的场景；平均精度均值（MAP）综合各召回水平的精度；Recall@K 衡量前 $K$ 个结果中的相关文档占比；NDCG 对相关性等级与位置衰减加权。阅读理解评估用精确匹配（EM，与标准答案完全一致）与 token 级 F1（把答案视为词袋，容忍部分匹配）：

$$F_1=\frac{2PR}{P+R},\quad P=\frac{|\text{预测}\cap\text{标准}|}{|\text{预测}|},\quad R=\frac{|\text{预测}\cap\text{标准}|}{|\text{标准}|}$$

现代开放域问答把检索与阅读整合为端到端流水线，关键设计包括混合检索（BM25 与 DPR 融合，如倒数排名融合 RRF）、交叉编码器重排序、段落切分（100–256 token、含重叠）与不可回答过滤。

## 9.13 对话系统

### 9.13.1 对话系统概述

对话系统（Dialogue System）使机器与人类进行多轮自然语言交互，面临时序依赖、上下文理解与目标驱动的序列决策。两大范式是任务型对话系统（以完成订酒店、查航班等任务为目标，强调准确性与任务完成率）与开放域聊天系统（生成流畅、有趣、安全的对话，强调自然性与用户满意度）。与单轮问答相比，对话系统涉及多轮交互、需维护对话状态、任务型还需调用外部 API，评估维度更多。

### 9.13.2 任务型对话：模块化流水线

经典任务型对话采用模块化流水线，分为四个阶段。自然语言理解（Natural Language Understanding, NLU）把用户输入解析为意图与槽位—值对：意图识别是分类问题 $y_{\text{intent}}=\arg\max_i P(i\mid x)$；槽位填充是序列标注问题，常用 BIO 方案。例如"订一张明天去北京的机票"被解析为 `book_flight` 意图、槽位 `[明天]_date [北京]_dst`。NLU 从规则模板、CRF+SVM 发展到 BiLSTM-CRF 联合建模、BERT 微调，再到 LLM 的少样本或零样本识别。

对话状态追踪（Dialogue State Tracking, DST）维护并更新对话状态 $b_t$，即各槽位取值的概率分布。其挑战包括信念漂移（用户中途改主意）、隐式约束（"便宜点的"意味着价格低）、长对话历史与领域扩展。方法从手工规则、生成式（Neural Belief Tracker）、判别式（TRADE 用槽位门控与检索式值预测）、预训练微调（SOM-DST 用 BERT 编辑式更新）到端到端 LLM 隐式建模。

对话策略（Policy）根据状态决定下一步动作，形式化为部分可观测马尔可夫决策过程（POMDP），优化 $\pi^*=\arg\max_\pi\mathbb{E}[\sum_t\gamma^t r_t]$；奖励通常在任务成功时为正、每轮为小负值以鼓励简洁。策略学习可用监督学习（从人类标注数据学映射）、强化学习（DQN、PPO 直接优化累积奖励）与用户模拟器。自然语言生成（Natural Language Generation, NLG）把系统动作转为自然语言回复，方法从模板、基于规划的生成到神经网络生成与可控生成；核心挑战是语义一致性，用语义错误率（SER）衡量。

### 9.13.3 端到端与开放域对话

端到端任务型对话利用预训练 LLM 把 DST、策略与 NLG 统一建模，直接接收完整对话历史（含工具调用结果）并输出回复。代表工作有 SimpleTOD（GPT-2 生成信念状态、数据库结果与回复的统一序列）、LaMDA（从事实性、安全性、质量三维度训练，兼顾任务型与闲聊）与 MultiWOZ 基准（7 个领域、超过 1 万段对话）。工具增强（Tool-Augmented）范式让 LLM 作为控制器调用数据库查询、API 与知识检索，优势是信息新鲜、可验证、易扩展领域。

开放域聊天系统分检索式与生成式。检索式从候选回复库中选取回复：先召回 Top-K，再用深度匹配模型排序，最后多样性重排；回复质量有保障、速度快，但受限于候选库、难以处理长尾场景。生成式用 Seq2Seq 直接生成回复，其核心问题是安全回复（倾向于生成"我不知道"等万能回复），可用互信息目标、多样化解码（Top-k、Top-p、温度采样）与对抗训练缓解。基于人格的对话要求系统保持一致人格，PersonaChat 是该方向的标准数据集，评估人格一致性与 F1 重叠度。安全性与对齐涉及有害内容、隐私泄露、虚假信息与越狱攻击，技术手段包括 RLHF、DPO、Constitutional AI 与安全过滤器（详见 §9.18）。

### 9.13.4 对话系统评估

任务型对话的评估包括任务完成率（TCR）、平均对话轮次、Inform Rate（信息正确匹配用户需求的比例）与 Success Rate；在 MultiWOZ 上通常报告 Inform、Success 与 BLEU。开放域聊天的自动指标包括困惑度（PPL）、BLEU、Distinct-n（多样性）、Embedding-based 相似度与 BERTScore，但自动指标与人类偏好相关性较低——对话回复具有一对多特性，参考回复只覆盖极小部分合理回复。人工评估仍是金标准，维度包括流畅性、相关性、信息量、一致性与安全性。近年 LLM-as-Judge（如 GPT-4 成对比较）与人类评估的一致性显著更高，但存在位置偏差与冗长偏差。两类系统的对比如下。

| 维度 | 任务型对话系统 | 开放域聊天系统 |
|:---|:---|:---|
| 核心目标 | 完成用户指定任务 | 维持流畅有趣对话 |
| 评价标准 | 任务成功率、信息准确率 | 流畅性、多样性、安全性 |
| 知识来源 | 外部数据库、API | 预训练语料、检索系统 |
| 状态管理 | 显式对话状态追踪 | 隐式上下文建模 |
| 典型架构 | NLU→DST→Policy→NLG 或端到端 LLM | Seq2Seq、检索式、LLM |
| 代表数据集 | MultiWOZ | PersonaChat |

## 9.14 大语言模型预训练架构

### 9.14.1 预训练范式概述

大语言模型（Large Language Model, LLM）的核心思想是：先在大规模无标注语料上预训练（Pre-training）学习通用表示，再通过微调或提示迁移到下游任务。与传统监督学习相比，预训练只需无标注文本、数据规模可达 TB 级，且一次训练可服务大量任务；模型的隐状态是上下文相关的，同一词在不同语境中有不同表示。按 Transformer 的使用方式，预训练语言模型可分为三大架构范式。

| 范式 | 代表模型 | 架构特点 | 预训练目标 | 典型任务 |
|:---|:---|:---|:---|:---|
| Encoder-Only | BERT、RoBERTa | 双向注意力 | 掩码语言模型 | 分类、NER、抽取式 QA |
| Decoder-Only | GPT 系列、LLaMA | 单向自回归 | 因果语言模型 | 生成、少样本学习 |
| Encoder-Decoder | T5、BART | 编码器双向 + 解码器单向 | 序列到序列 | 翻译、摘要、生成式 QA |

### 9.14.2 BERT：Encoder-Only

BERT（Bidirectional Encoder Representations from Transformers, Devlin 等, 2018）用双向 Transformer 编码器加掩码语言模型（Masked Language Modeling, MLM）实现真正的双向上下文建模。输入嵌入由 token、segment 与 position 三部分相加构成，使用 WordPiece 分词、可学习位置编码，最大长度 512，并含 `[CLS]`、`[SEP]`、`[MASK]` 特殊标记。BERT-Base 为 12 层、768 维、12 头、110M 参数；BERT-Large 为 24 层、1024 维、16 头、340M 参数。

MLM 的思想来自完形填空：随机遮盖约 15% 的 token 让模型根据上下文预测，其中 80% 替换为 `[MASK]`、10% 替换为随机 token、10% 保持不变。80/10/10 策略是为了缓解预训练与微调的分布不匹配，并迫使模型对每个位置都学习有意义的表示。训练目标是最大化被掩码位置的对数似然

$$\mathcal{L}_{\text{MLM}}=-\sum_{i\in\mathcal{M}}\log P(x_i\mid x_{\backslash\mathcal{M}})$$

MLM 的局限包括：假设被掩码 token 相互独立而忽略其相关性、只有约 15% 的 token 参与损失导致效率较低、以及双向结构无法直接用于生成。第二个预训练任务下一句预测（Next Sentence Prediction, NSP）让模型判断句子 B 是否为 A 的真实下一句，用 `[CLS]` 隐状态做二分类；但 RoBERTa 发现 NSP 效果有限甚至有害，主要学到的是话题检测，移除后性能无损。BERT 的微调方式是在预训练模型上添加简单任务层并在标注数据上联合更新所有参数，可适配文本分类、NER、阅读理解、句子对分类与语义相似度等任务。

BERT 的改进变体包括：RoBERTa（移除 NSP、动态掩码、更大批次与更多数据、更长训练）、ALBERT（因式分解嵌入与跨层参数共享把参数从 110M 降至 12M，并用句子顺序预测 SOP 替换 NSP）、ELECTRA（用生成器—判别器的替换 token 检测，让所有 token 参与损失、训练效率更高）。各变体在 GLUE 上的表现如下。

| 模型 | 关键改进 | 参数量 | 训练效率 | GLUE 得分 |
|:---|:---|:---|:---|:---|
| BERT-Base | 基线 | 110M | 基线 | 79.6 |
| RoBERTa | 动态掩码 + 更多数据 | 125M | ~5× | 88.0 |
| ALBERT-xxl | 参数共享 + 因式分解 | 235M | ~3× | 89.4 |
| ELECTRA-Large | 替换 token 检测 | 340M | ~4× | 89.4 |

### 9.14.3 GPT：Decoder-Only

GPT（Generative Pre-Training, Radford 等, 2018）用 Transformer 解码器做自回归预训练，核心理念是"语言的本质是生成"。GPT-1 堆叠 12 层、768 维、12 头，用因果注意力掩码保证位置 $i$ 只能关注 $j\le i$，预训练目标是标准因果语言模型（Causal Language Modeling, CLM）：

$$\mathcal{L}_{\text{CLM}}=-\sum_{t=1}^{n}\log P(x_t\mid x_1,\dots,x_{t-1};\theta)$$

GPT-2（2019）把规模扩展到 1.5B 参数并在约 40GB 的 WebText 上训练，其核心发现是足够大的语言模型无需微调即可执行多种任务——通过文本提示（prompting）引导输出，即零样本学习。它揭示"语言模型即多任务学习"，规模效应为后续缩放定律奠定基础，但零样本性能不稳定、对 prompt 格式敏感。

GPT-3（Brown 等, 2020）把规模推至 175B 参数，系统研究上下文学习（In-Context Learning）：通过在 prompt 中提供少量示例，模型无需更新参数即可执行任务。Zero-shot 只给任务描述，One-shot 给一个示例，Few-shot 给若干示例，其条件概率为

$$P(y\mid x_1,y_1,\dots,x_k,y_k,x)=\prod_{t=1}^{|y|}P(y_t\mid x_1,y_1,\dots,x_k,y_k,x,y_{<t})$$

注意这里没有梯度更新，模型仅通过前向传播利用示例信息。GPT 系列规模与数据的增长如下。

| 模型 | 参数量 | 层数 | 隐藏维度 | 注意力头 | 训练数据量 |
|:---|:---|:---|:---|:---|:---|
| GPT-1 | 117M | 12 | 768 | 12 | ~5GB |
| GPT-2 | 1.5B | 48 | 1600 | 25 | ~40GB |
| GPT-3 | 175B | 96 | 12288 | 96 | ~570GB |
| GPT-4 | ~1.8T (MoE) | — | — | — | ~13T tokens |

GPT 系列采用自回归生成，解码策略包括贪心解码、温度采样（$\tau<1$ 更确定、$\tau>1$ 更随机）、Top-k 采样与 Top-p（核）采样。Top-p 选择累积概率达到阈值 $p$ 的最小 token 集合，自适应调整候选集大小。

### 9.14.4 T5：Encoder-Decoder

T5（Text-to-Text Transfer Transformer, Raffel 等, 2020）把所有 NLP 任务统一为文本到文本格式，输入输出都是字符串，用前缀区分任务，如翻译输入 `translate English to German: ...`、摘要输入 `summarize: ...`、情感分类输入 `sst2 sentence: ...`。其优势是任务统一（共享架构、损失与解码）、支持多任务学习、条件生成自然。

T5 采用标准 Transformer 编码器—解码器结构，使用相对位置偏置（在注意力分数中加入按相对距离对数分桶的可学习偏置 $b_{i-j}$）。预训练目标是跨度损坏（Span Corruption）：随机选择若干连续 token 跨度，各替换为一个哨兵 token（如 `<extra_id_0>`），解码端按顺序输出被替换的跨度内容。例如原文"The quick brown fox jumps over the lazy dog"损坏为"The `<X>` fox `<Y>` the lazy dog"，目标输出为"`<X>` quick brown `<Y>` jumps over"。T5 论文系统比较了预训练决策，结论是：跨度损坏在相同计算预算下优于 CLM、平均跨度长度 3 个 token 最优、约 15% 损坏比例最优、多任务混合预训练接近甚至优于两阶段预训练。T5 规模从 60M 的 Small 到 11B 的 11B。

### 9.14.5 架构对比与训练目标

三种架构的核心差异在注意力掩码：Encoder-Only 全双向可见；Decoder-Only 因果掩码（$j\le i$ 可见）；Encoder-Decoder 的编码器双向、解码器因果并通过交叉注意力查看编码器输出。综合对比如下。

| 维度 | Encoder-Only | Decoder-Only | Encoder-Decoder |
|:---|:---|:---|:---|
| 注意力方向 | 双向 | 单向（因果） | Enc 双向 + Dec 单向 |
| 预训练目标 | MLM / 替换检测 | 因果语言模型 | Span Corruption |
| 生成能力 | 不支持直接生成 | 天然支持 | 支持 |
| 理解能力 | 最强（双向上下文） | 较弱（仅左上下文） | 强 |
| 典型任务 | 分类、NER、抽取 | 生成、对话、代码 | 翻译、摘要、生成式 QA |
| 扩展性 | 中等 | 最强 | 中等 |
| 代表模型 | BERT、RoBERTa、ELECTRA | GPT、LLaMA | T5、BART、mT5 |

Decoder-Only 成为主流的原因包括：CLM 每个 token 都参与损失（100%），而 MLM 仅约 15%，训练信号更密集；天然支持生成，可统一处理理解与生成；在超大规模下展现更强的涌现能力；工程上更简洁，只需实现因果注意力与 KV Cache；自回归生成可缓存 KV，推理效率高。不过 Encoder-Decoder 在翻译（输入输出语义空间不同）、长文本理解与小规模参数受限场景下仍有优势。

三种架构的预训练目标可统一为极大似然估计的变体：CLM（GPT，每 token 参与 100%）、MLM（BERT，约 15%）、Span Corruption（T5，约 15% 输入加 100% 输出）与替换 token 检测 RTD（ELECTRA，二分类、100%）。下游适配策略也不同：Encoder-Only 添加任务头做全参数或参数高效微调；Decoder-Only 通过提示（Zero-shot、Few-shot、CoT）、指令微调与 RLHF；Encoder-Decoder 通过任务前缀与多任务微调。

### 9.14.6 缩放定律与涌现能力

缩放定律（Scaling Laws, Kaplan 等, 2020）揭示测试损失与参数量 $N$、数据量 $D$、计算量 $C$ 均呈幂律关系：$L(N)\propto N^{-0.076}$、$L(D)\propto D^{-0.095}$、$L(C)\propto C^{-0.050}$。Chinchilla 缩放定律（Hoffmann 等, 2022）修正了结论：在固定计算预算下参数量与训练 token 数应等比例增长（$N\propto D$），据此 GPT-3 175B 实际上是欠训练的——相同算力下更小但训练更充分的 Chinchilla 70B 可取得更好性能。

| 模型 | 参数量 | 训练 tokens | 计算量 (FLOPs) | 是否最优 |
|:---|:---|:---|:---|:---|
| GPT-3 | 175B | 300B | $3.1\times10^{23}$ | 欠训练 |
| Chinchilla | 70B | 1.4T | $5.8\times10^{23}$ | 接近最优 |
| LLaMA-2 | 70B | 2T | $8.4\times10^{23}$ | 接近最优 |

涌现能力（Emergent Abilities）指小模型中不存在、规模超过某阈值后突然出现的能力，呈现相变特征，无法由缩放定律平滑外推。典型涌现能力包括多步推理、思维链、代码生成、指令遵循与翻译。可能的解释有：复杂任务由多个子技能组合，需全部具备才能完成（木桶效应）；模型在特定规模下形成新的内部表示结构；以及度量敏感性——严格度量（如精确匹配）使曲线呈阶跃状，平滑度量则可能更平缓。

## 9.15 提示工程

### 9.15.1 提示工程概述

提示工程（Prompt Engineering）研究如何通过设计输入提示引导 LLM 产生期望输出，而无需修改模型参数。其兴起依赖模型的涌现能力、参数高效性、通用灵活性与可控可解释性。一个完整提示通常包含指令、上下文、输入数据、输出格式与示例五部分。

| 组成部分 | 描述 | 示例 |
|:---|:---|:---|
| 指令 | 说明任务目标 | "请将以下英文翻译为中文" |
| 上下文 | 提供背景或领域约束 | "你是一位资深工程师" |
| 输入数据 | 待处理的具体内容 | "Translate: Hello, world!" |
| 输出格式 | 指定输出结构 | "以 JSON 格式输出" |
| 示例 | 展示输入—输出对 | 见 §9.15.3 |

### 9.15.2 零样本与少样本提示

零样本提示（Zero-shot Prompting）不提供任何示例，仅靠指令与输入，依赖模型预训练的知识与指令遵循能力：$y^*=\arg\max_y P_\theta(y\mid I\oplus x)$。其优势是实现简单，适用于任务定义明确的场景；局限是对复杂或领域特定任务可能无法理解期望格式，且对措辞高度敏感。改进策略包括角色设定、任务分解与格式约束。

少样本提示（Few-shot Prompting）通过提供少量输入—输出示例引导模型，也称上下文学习（In-Context Learning, ICL）。ICL 不更新参数，而是在前向推理中隐式"学习"任务模式，其机制可能涉及贝叶斯推断、隐式梯度下降或任务向量。示例的选择对性能有决定性影响：随机选择简单无开销；相似度选择用嵌入相似度选与测试输入最接近的示例；多样性选择（如 MMR）覆盖更广变体；性能选择在验证集上挑最优子集；聚类选择兼顾相似与多样。示例的排列顺序同样显著影响性能（顺序敏感性），同一组示例的不同排列可导致准确率波动超过 20%，可用相似度递增/递减、随机多次平均或熵最小化缓解。有趣的是，即使示例标签被随机打乱，ICL 仍保持一定性能，说明它主要学习输入—输出格式映射与标签空间，但正确标签仍能显著提升表现。

### 9.15.3 思维链、自洽性与思维树

思维链提示（Chain-of-Thought, CoT, Wei 等, 2022）在提示中展示中间推理步骤，把复杂问题分解为可管理的步骤。它将条件概率分解为 $P(y\mid x)\approx\prod_t P(r_t\mid x,r_1,\dots,r_{t-1})\cdot P(y\mid x,r_1,\dots,r_m)$。CoT 能力在模型规模超过约 100B 参数时才显著涌现，对多步推理任务提升最大（PaLM 540B 在 GSM8K 上从 17.9% 提升至 58.1%），对简单事实检索提升有限。少样本 CoT 提供带推理链的示例；零样本 CoT（Kojima 等, 2022）仅需在末尾添加"Let's think step by step"，即可把 GPT-3 175B 在 GSM8K 上的准确率从 17.7% 提升至 40.7%。CoT 变体包括 Self-Ask、Least-to-Most、Complex CoT、Auto-CoT 与 Multimodal CoT。

自洽性（Self-Consistency, Wang 等, 2022）是对多条推理路径做多数投票的解码策略：用温度采样生成 $n$ 条推理路径，从每条提取答案，选取出现频率最高者。其洞察是正确路径通常多于错误路径，采样足够多次后正确答案占多数。在 PaLM 540B 上它把 GSM8K 准确率从 58.1% 提升至 74.4%（提升 16.3 个百分点）。计算成本与精度呈边际递减：$n=1$ 等价标准 CoT，$n=5\sim10$ 性价比最高，$n>40$ 提升微乎其微，实践中常用 $n=10\sim20$。加权自洽性为每条路径按对数概率、验证器分数或长度归一化赋权。

思维树（Tree-of-Thought, ToT, Yao 等, 2023）把线性推理链推广为树状搜索，使模型能探索、回溯与全局规划。它在每步生成多个候选思维，用评估函数打分，并用 BFS 或 DFS 搜索。在 24 点游戏上，ToT 把 GPT-4 的成功率从标准 CoT 的 4% 提升至 74%。各提示方法对比如下。

| 方法 | 示例需求 | 推理增强 | 计算成本 | 适用规模 |
|:---|:---|:---|:---|:---|
| Zero-shot | 无 | 无 | $O(1)$ | 所有规模 |
| Few-shot ICL | 3~8 个示例 | 无显式推理链 | $O(k)$ | >6B |
| Few-shot CoT | 3~8 个带链示例 | 显式中间步骤 | $O(k)$ | >100B |
| Zero-shot CoT | 无 | "Let's think step by step" | $O(1)$ | >100B |
| Self-Consistency | 同 CoT | 多路径投票 | $O(n\cdot k)$ | >100B |
| Tree-of-Thought | 同 CoT | 树状搜索 | $O(b^d)$ | >100B |

### 9.15.4 自动提示优化、最佳实践与局限

自动提示优化用算法搜索最优提示。APE（Automatic Prompt Engineer, Zhou 等, 2023）把提示设计建模为程序搜索：用 LLM 生成候选指令集合，在验证集上评估并选最优，可迭代精炼。OPRO（Yang 等, 2023）用 LLM 自身作为优化器，维护提示—分数历史并要求模型据此生成新提示，实现基于自然语言的元启发式搜索。

提示工程最佳实践可归纳为五条原则：明确性（用简洁无歧义语言、指定输出格式与长度）、结构化（用分隔符划分指令与输入、用编号列表组织多步指令）、示例（3~8 个、覆盖典型与边界、保证多样）、迭代优化（从简单开始、分析失败案例、管理提示版本）与鲁棒性（测试输入变体、多措辞集成、跨模型兼容）。其局限包括：模型规模依赖性（CoT 在小模型上可能有害）、提示敏感性、上下文窗口限制、幻觉无法根治、任务泛化性差与推理链评估困难。

## 9.16 检索增强生成

### 9.16.1 动机与流水线

纯参数化知识存储有三大缺陷：知识截止（参数在训练后固化，更新需重训且可能灾难性遗忘）、幻觉（缺乏知识时仍生成貌似合理但错误的内容，分事实性幻觉与忠实性幻觉）与领域适应（垂直领域知识深度有限，微调面临数据稀缺与高成本）。检索增强生成（Retrieval-Augmented Generation, RAG, Lewis 等, 2020）在生成前先从外部知识库检索相关文档并注入 LLM 输入：

$$\text{RAG}(q)=\text{LLM}\big(q,\text{Retrieve}(q,\mathcal{D})\big)$$

RAG 把 LLM 从"参数化数据库"转变为"基于检索上下文的推理引擎"，在不改参数的前提下提升事实准确性与时效性。完整流水线包含查询处理（改写、扩展、HyDE）、检索、增强与生成四个阶段。

### 9.16.2 检索组件

稀疏检索以 BM25 为代表，基于词频且无需训练、高效可解释，但无法捕捉语义等价。稠密检索用神经网络编码器把查询与文档映射到同一向量空间，以余弦相似度或内积计算相关性：

$$\text{sim}(q,d)=\frac{\mathbf{E}_q(q)^\top\mathbf{E}_d(d)}{\|\mathbf{E}_q(q)\|\cdot\|\mathbf{E}_d(d)\|}$$

训练通常用对比学习，损失为 InfoNCE，负样本常用 BM25 难负样本。代表模型有 DPR、Contriever（无监督）、E5、GTE 与 BGE（支持指令感知）。混合检索同时使用稀疏与稠密并融合，融合策略有线性融合与倒数排名融合（RRF）：$\text{RRF}(d)=\sum_{r\in\mathcal{R}}\frac{1}{k+\text{rank}_r(d)}$，$k$ 通常取 60。三种方法对比如下。

| 检索方法 | 优势 | 劣势 | 适用场景 |
|:---|:---|:---|:---|
| BM25 | 无需训练、高效、精确匹配强 | 无法处理语义等价 | 关键词明确的查询 |
| 稠密检索 | 语义理解强、处理同义词 | 需训练数据、开销大 | 自然语言查询 |
| 混合检索 | 兼顾精确与语义 | 系统复杂、需调权 | 通用 RAG |

### 9.16.3 增强策略与生成

最直接的增强是上下文注入：把检索片段拼接为上下文与查询共同构成 prompt，关键设计包括文档排序、文档数量 $k$（典型 3~10）、去重与截断。融合解码器（Fusion-in-Decoder, FiD, Izacard & Grave, 2021）更精细：编码阶段独立编码每个文档—查询对，拼接所有编码序列后由解码器通过交叉注意力融合，使解码器能动态从不同文档提取互补信息，而非简单拼成长文本。

生成组件关注三点：上下文利用能力（LLM 需长上下文理解与多文档推理，避免"Lost in the Middle"——模型倾向关注首尾而忽略中间）、忠实性约束（指令限定仅据参考资料回答、受控生成、忠实性损失）、引用与归因（句子级或段落级标注来源）。

### 9.16.4 RAG 变体与基础设施

RAG 的代表变体包括：REALM（Guu 等, 2020）端到端联合训练检索器与语言模型，用最大内积搜索近似 top-k；RETRO（Borgeaud 等, 2022）分块检索并在每层插入交叉注意力，用 7.5B 参数匹配 25 倍参数量模型；Atlas（Izacard 等, 2023）少量标注下的检索增强预训练，可检索演示与思维链；Self-RAG（Asai 等, 2023）用 `[Retrieve]`、`[IsRel]`、`[IsSup]`、`[IsUse]` 等反思标记让模型自主决定何时检索并评估结果；CRAG（Yan 等, 2024）用轻量检索评估器把结果分为正确、模糊、错误三类，错误时转为网络搜索。

分块（Chunking）把长文档切为合适大小的片段，质量直接影响检索精度。策略包括固定大小分块（256~512 token、重叠 50~100）、语义分块（在相邻段落相似度下降处切分）、递归分块（按层级分隔符递归）与基于文档结构分块。重叠机制避免跨块边界的关键信息丢失。向量数据库专门优化高维向量的近似最近邻搜索，代表有 FAISS、Pinecone、Chroma、Weaviate、Milvus、Qdrant；核心索引算法包括 IVF（聚类后只搜最近簇）、HNSW（小世界图分层，平均 $O(\log n)$）与 PQ（乘积量化，压缩存储）。

### 9.16.5 RAG 评估与挑战

RAG 评估从检索质量与生成质量两个维度展开：检索指标有 Hit@k、MRR、nDCG；生成指标有忠实性（答案是否被检索文档支持，常用 NLI 判断，RAGAS 定义为被支持声明占总声明的比例）、答案相关性（LLM 评分或反向生成查询计算相似度）与上下文精确率/召回率。

| 评估维度 | 指标 | 计算方式 | 关注点 |
|:---|:---|:---|:---|
| 检索质量 | Hit@k、MRR、nDCG | 基于标注检索结果 | 能否找到正确文档 |
| 忠实性 | Faithfulness | NLI / LLM 评估 | 答案是否被文档支持 |
| 答案质量 | Relevance、Correctness | LLM / 人工评估 | 答案是否正确相关 |
| 上下文质量 | Precision、Recall | 基于标注相关性 | 检索结果质量 |

RAG 部署面临的主要挑战包括：检索噪声（可在 top-k 中引入误导信息，缓解手段有检索评估器、重排序器与反思机制）、长上下文处理（信息利用率随长度下降，可用 prompt 压缩、FiD 与迭代检索）、延迟与成本（检索步骤增加端到端延迟，主要瓶颈是 LLM 生成，可异步流水线、向量量化与缓存优化）、多跳推理（需多步检索，代表方法有 IRCoT 与 ITER-RETGEN）与知识库维护（文档增删改需增量重新编码并做版本管理）。

## 9.17 参数高效微调

### 9.17.1 动机与方法概览

随着预训练模型从数十亿增长到数千亿参数，全参数微调（Full Fine-Tuning）面临存储成本高（每个任务保存完整副本）、训练显存巨大（Adam 优化器下总需求约为参数量字节的 14~18 倍）、灾难性遗忘与多租户部署困难。参数高效微调（Parameter-Efficient Fine-Tuning, PEFT）只训练极小比例参数（通常 0.1%~5%），即可达到接近全微调的性能，兼具参数、显存效率与任务切换灵活性，且冻结的预训练权重有助于抗遗忘。

### 9.17.2 Adapter、Prefix-Tuning 与 Prompt Tuning

Adapter Tuning（Houlsby 等, 2019）在 Transformer 每层插入小型瓶颈模块：下投影把 $d_{\text{model}}$ 降至瓶颈维度，经非线性激活后上投影恢复，并用残差连接保证初始为恒等映射：

$$\text{Adapter}(h)=h+f(hW_{\text{down}})W_{\text{up}}$$

Houlsby 等在每个 Transformer 层的自注意力子层与 FFN 子层后各插入一个 Adapter。以 $d_{\text{model}}=4096$、$d_{\text{bottleneck}}=64$ 为例，每个 Adapter 约 0.5M 参数，每层两个即 1.0M，32 层约 32M，占 7B 模型的约 0.46%。Adapter 开创了"冻结主干 + 训练小模块"，但引入推理延迟。

Prefix-Tuning（Li & Liang, 2021）为每层的 Key、Value 注入可训练前缀向量，冻结模型全部原始参数：$K'=[P_K;K]$、$V'=[P_V;V]$。前缀是"虚拟 token"，不对应真实输入。为稳定训练，用小型 MLP 把低维可训练参数重参数化为高维前缀，训练后丢弃 MLP。前缀长度 $l$ 越大表达能力越强、开销越高，$l=200$ 通常可达全微调性能的 95%~99%。Prompt Tuning（Lester 等, 2021）是简化版，仅在输入嵌入层拼接 $m$ 个可训练软提示向量，参数量为 $m\times d_{\text{model}}$，表达能力较弱但更省。其性能随模型规模增大而提升，在 T5-XXL（11B）上与全微调差距几乎消失，即"模型规模的力量"。两者对比如下。

| 维度 | Prompt Tuning | Prefix-Tuning |
|:---|:---|:---|
| 注入位置 | 仅输入嵌入层 | 每层 K/V 注意力 |
| 参数量 | $m\times d_{\text{model}}$ | 每层 K/V 前缀 |
| 表达能力 | 较弱 | 较强 |
| 适用规模 | 大模型（>10B） | 中等模型（<1B） |

### 9.17.3 LoRA 与 QLoRA

LoRA（Low-Rank Adaptation, Hu 等, 2021）的核心洞察是微调中的权重变化矩阵具有低秩特性，于是把更新分解为两个低秩矩阵之积：

$$W=W_0+\Delta W=W_0+BA,\quad h=W_0x+BAx$$

其中 $W_0$ 冻结，$B\in\mathbb{R}^{d\times r}$、$A\in\mathbb{R}^{r\times k}$，$r\ll\min(d,k)$。参数量为 $r(d+k)$，当 $d=k=4096,r=8$ 时仅 65,536 个，约为原始的 0.2%。初始化时 $A$ 随机高斯、$B$ 零初始化，保证训练开始时 $\Delta W=0$、行为与预训练模型一致。缩放因子 $\alpha$ 使更新为 $\frac{\alpha}{r}BAx$，增大 $r$ 时 $\frac{\alpha}{r}$ 自动缩小以避免更新幅度过大，经验上 $\frac{\alpha}{r}$ 保持在 $[0.5,4]$ 最佳。LoRA 通常应用于注意力的投影矩阵，实验表明同时用于 $W_Q$ 与 $W_V$ 效果最优；若扩展到全部线性层、用 $r=8$，32 层 7B 模型约 4.2M 参数（约 0.06%）。推理时 LoRA 权重可合并进原始权重 $W=W_0+\frac{\alpha}{r}BA$，实现零额外延迟，且任务切换只需替换数十 MB 的 $\{A,B\}$ 矩阵。

QLoRA（Dettmers 等, 2023）把量化与 LoRA 结合，在单张 48GB GPU 上微调 65B 模型。三项核心技术是：4-bit NormalFloat（NF4）量化（把正态分布分位数映射到 16 个离散值，量化误差最小）、双重量化（对缩放因子本身再量化，平均每参数再省约 0.37 位）与分页优化器（显存不足时把优化器状态卸载到 CPU）。其前向传播为 $h=\text{Dequant}(W_{\text{4bit}})\cdot x+\frac{\alpha}{r}BAx$，梯度仅通过 LoRA 矩阵流动、4-bit 权重不接收梯度，因此基础模型可极低精度存储而训练质量仍有保证。显存需求对比如下。

| 方法 | 模型规模 | 基础精度 | 显存需求 | 最低 GPU |
|:---|:---|:---|:---|:---|
| 全微调 | 65B | FP16 | ~900 GB | 12× A100-80G |
| LoRA | 65B | FP16 | ~130 GB | 2× A100-80G |
| QLoRA | 65B | NF4 | ~41 GB | 1× A100-48G |
| QLoRA | 33B | NF4 | ~23 GB | 1× RTX 3090/4090 |

### 9.17.4 方法对比与实践

PEFT 各方法在可训练参数、显存、延迟与适用规模上各有取舍，对比如下。

| 方法 | 年份 | 可训练参数 | 训练显存 | 推理延迟 | 适用规模 |
|:---|:---|:---|:---|:---|:---|
| 全微调 | — | 100% | 极高 | 基线 | 任意 |
| Adapter | 2019 | 0.5%~5% | 中等 | +5%~15% | 中小模型 |
| Prefix-Tuning | 2021 | 0.1%~1% | 低 | +2%~10% | 中小模型 |
| Prompt Tuning | 2021 | 0.01%~0.1% | 极低 | +1%~5% | 大模型（>10B） |
| LoRA | 2021 | 0.05%~1% | 低 | 0%（合并后） | 任意 |
| QLoRA | 2023 | 0.05%~1% | 极低 | 0%（合并后） | 任意 |

LoRA 实践中的推荐配置为：秩 $r$ 取 8~16（简单任务 4、复杂任务 32~64），$\alpha$ 取 16~32（常用 $\alpha=2r$），目标模块从 `q_proj, v_proj` 起步、可扩展到全部线性层，Dropout 0.05~0.1，学习率 $1\text{e-}4\sim3\text{e-}4$（比全微调高 1~2 个数量级）。常见陷阱包括：秩并非越大越好（小数据集易过拟合）、仅覆盖 $W_Q/W_V$ 可能次优、学习率敏感（建议 cosine 调度配合 warmup）、数据质量的影响远大于数量。主流框架有 HuggingFace PEFT、Unsloth、LLaMA-Factory 与 Axolotl。

## 9.18 对齐技术

### 9.18.1 对齐问题概述

预训练目标（预测下一个 token）并不区分"有用"与"有害"的输出，对齐（Alignment）的目标是让模型行为与人类意图、偏好和价值观一致。Anthropic 提出的 3H 原则包括有用性（Helpful）、无害性（Harmless）与诚实性（Honest），三者存在内在张力——过度追求无害会导致过度拒绝，过度追求有用可能忽略安全。对齐过程常导致模型在部分基准上的性能下降，即对齐税（Alignment Tax）。对齐可分为能力对齐（SFT、指令微调）、偏好对齐（RLHF、DPO）、价值对齐（Constitutional AI、红队测试）与目标对齐（超级对齐研究）四个层次。

### 9.18.2 RLHF

RLHF（Reinforcement Learning from Human Feedback, Ouyang 等, 2022）用人类偏好训练奖励模型，再用强化学习优化语言模型，分三阶段。阶段一是监督微调（SFT）：用人工编写的指令—回答对微调预训练模型，使其学会遵循指令格式。阶段二是奖励模型训练：对同一 prompt 生成多个回答，由人类成对比较标注偏好数据 $\mathcal{D}=\{(x,y_w,y_l)\}$，基于 Bradley-Terry 模型训练奖励模型

$$P(y_w\succ y_l\mid x)=\sigma\big(r_\phi(x,y_w)-r_\phi(x,y_l)\big)$$

阶段三是用 PPO（强化学习原理见第 7 章）优化策略，最大化奖励同时用 KL 散度惩罚防止偏离参考策略过远：

$$\max_{\pi_\theta}\mathbb{E}\big[r_\phi(x,y)-\beta D_{\text{KL}}(\pi_\theta\|\pi_{\text{ref}})\big]$$

其中 $\pi_{\text{ref}}$ 通常为 SFT 模型；$\beta$ 过大导致过于保守，过小可能 reward hacking（找到奖励模型漏洞而非真正提升质量）。InstructGPT 的关键细节包括：1.3B 的 InstructGPT 在人类评估中优于 175B 原始 GPT-3，说明对齐可弥补规模差距；使用约 40 名标注员、一致性约 73%；6B 奖励模型在稳定性与性能间取得平衡；进行多轮迭代。

### 9.18.3 DPO

DPO（Direct Preference Optimization, Rafailov 等, 2023）的核心洞察是 RLHF 的奖励建模与 PPO 可合并为一个分类损失，从而绕过显式奖励模型与强化学习。其推导起点是 KL 约束优化的闭式解

$$\pi^*(y\mid x)=\frac{1}{Z(x)}\pi_{\text{ref}}(y\mid x)\exp\left(\frac{1}{\beta}r(x,y)\right)$$

反解出 $r(x,y)=\beta\log\frac{\pi^*(y\mid x)}{\pi_{\text{ref}}(y\mid x)}+\beta\log Z(x)$，代入 Bradley-Terry 模型后，只依赖 $x$ 的 $\beta\log Z(x)$ 项在相减时消去，得到

$$\mathcal{L}_{\text{DPO}}(\theta)=-\mathbb{E}\left[\log\sigma\left(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)}-\beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}\right)\right]$$

当模型对 $y_w$ 的隐式奖励低于 $y_l$ 时梯度增大 $y_w$ 概率、减小 $y_l$ 概率；已正确排序时损失接近零。RLHF 与 DPO 的对比如下。

| 维度 | RLHF (PPO) | DPO |
|:---|:---|:---|
| 训练阶段 | SFT → RM → PPO | SFT → DPO |
| 需要奖励模型 | 是 | 否（隐式包含在策略中） |
| 需要 RL 算法 | 是，PPO 复杂不稳定 | 否，标准交叉熵 |
| 超参数数量 | 多 | 少（主要为 $\beta$） |
| 训练稳定性 | 较低，易 reward hacking | 较高 |
| 在线数据 | 可在线采样 | 通常离线 |

DPO 的局限包括分布偏移（离线偏好数据来自 SFT 分布，策略更新后逐渐不匹配，可用 Online/Iterative DPO 缓解）、对偏好数据质量敏感与隐式奖励表达能力受限。

### 9.18.4 Constitutional AI、其他方法与评估

Constitutional AI（CAI, Bai 等, 2022）用一组明确规则（"宪法"）指导 AI 自我批评与修正，减少对人类标注的依赖。阶段一是监督自我批评：给有害 prompt 让模型生成初始回答，引用宪法规则要求自我批评并修订，用修订后的回答做 SFT（可多轮）。阶段二是 RLAIF：对同一 prompt 生成两个候选，让模型据宪法判断哪个更好，构成 AI 偏好标注，再训练奖励模型并用 PPO 优化。Anthropic 的宪法含约 16 条规则，如"选择更有帮助、更诚实、更无害的回答"。RLAIF 相比 RLHF 标注成本低、一致性高、可扩展性强，价值框架显式可审计，但可能有系统性偏见且宪法覆盖有限。

其他对齐方法包括：KTO（受前景理论启发，只需单条回答的好/坏标签，对坏样本赋更大权重以体现损失厌恶，数据需求更灵活）、IPO（指出 DPO 在偏好确定时可能过拟合，直接优化隐式奖励差值趋近固定常数）、ORPO（把 SFT 与偏好对齐合并为单一阶段，无需参考模型、RM 与 RL）、SimPO（用序列平均 log 概率作隐式奖励以消除长度影响，并引入目标奖励间隔 $\gamma$，同样无需参考模型）。对齐方法总览如下。

| 方法 | 年份 | 需要 RM | 需要 RL | 数据需求 | 核心创新 |
|:---|:---|:---|:---|:---|:---|
| RLHF (PPO) | 2022 | 是 | 是 | 成对偏好 | 人类偏好 + RM + PPO |
| DPO | 2023 | 否 | 否 | 成对偏好 | 闭式解消除 RM 与 RL |
| CAI | 2022 | 是 (AI) | 是 | 宪法规则 | AI 自我批评 + RLAIF |
| KTO | 2024 | 否 | 否 | 二元标签 | 损失厌恶加权 |
| IPO | 2023 | 否 | 否 | 成对偏好 | MSE 替代 log-sigmoid |
| ORPO | 2024 | 否 | 否 | 成对偏好 | SFT + 对齐一步到位 |
| SimPO | 2024 | 否 | 否 | 成对偏好 | 长度归一化 + margin |

对齐评估依赖多个基准：TruthfulQA 测试模型在常见误解上的诚实性；Helpfulness 基准（MT-Bench、AlpacaEval）通过人类或 LLM-as-Judge 评估回答质量；安全基准如 ToxiGen、BBQ、HarmBench；HHH 评估框架；以及比较对齐前后在 MMLU、HellaSwag、ARC 等标准基准上的性能变化来测量对齐税。前沿方向包括可扩展监督（用弱模型监督强模型）、过程对齐（对齐推理中间步骤）、多目标帕累托优化、鲁棒对齐（防越狱与提示注入）与个性化对齐。

## 9.19 大语言模型评测与应用

### 9.19.1 评测基准概览

LLM 评测需覆盖语言理解、推理、代码生成、多模态与知识问答等多个维度。语言理解基准包括 GLUE（含 CoLA、SST-2、MNLI 等 9 个子任务）、SuperGLUE（增加因果推理 COPA、词义消歧 WiC、多文档阅读理解 MultiRC 等更难任务）与中文的 CLUE。推理基准包括 GSM8K（8,500 道小学数学应用题，需 2~8 步推理，前沿模型准确率已超 95%）、MATH（12,500 道竞赛级数学题，是"硬基准"）与 ARC（7,787 道小学科学选择题，含 Challenge Set）。代码生成基准包括 HumanEval（164 个 Python 函数题，指标为 pass@k）、MBPP（974 道 Python 题）与 SWE-bench（从真实 GitHub 仓库提取 2,294 个 issue，要求生成补丁）。多模态基准包括 MMBench（约 3,000 道多模态选择题，用循环评估消除位置偏差）与 MMMU（11,500 道专家级多模态问题）。综合知识基准包括 MMLU（57 个学科约 15,000 道选择题）、中文的 C-Eval（52 个学科约 13,000 道题）与 HELM（多维度评测鲁棒性、公平性、偏见、毒性与效率）。各基准概况如下。

| 基准类别 | 代表基准 | 任务类型 | 当前前沿水平 |
|:---|:---|:---|:---|
| 语言理解 | GLUE / SuperGLUE | NLI、情感、语义相似度 | 超越人类基线 |
| 数学推理 | GSM8K / MATH | 多步数学推理 | GSM8K > 95%，MATH > 70% |
| 常识推理 | ARC / HellaSwag | 多选问答 | ARC-C > 95% |
| 代码生成 | HumanEval / MBPP | 函数级代码生成 | pass@1 > 90% |
| 多模态 | MMBench / MMMU | 图文理解与推理 | MMMU ~ 60% |
| 综合知识 | MMLU / C-Eval | 多学科选择题 | MMLU > 90% |

评测报告常以雷达图呈现多维能力，其价值在于直观展示模型的能力结构（如代码与推理突出而创意写作较弱的"右偏"形态）。基准的演进趋势是从静态到动态（LiveBench、WildBench 持续更新题目）、从单一到多维（HELM）、从封闭到开放（Chatbot Arena 依赖实时用户交互抗污染）与从学术到实践（SWE-bench 直接来源于真实软件工程）。

### 9.19.2 评测方法论

评测方法分三大类。自动化指标评测包括准确率、pass@k（代码）、BLEU/ROUGE（生成）与困惑度，其中 pass@k 定义为生成 $k$ 个候选至少一个通过所有测试的概率

$$\text{pass@}k=\mathbb{E}_{\text{problems}}\left[1-\frac{\binom{n-c}{k}}{\binom{n}{k}}\right]$$

困惑度越低表示对文本建模越好，但低困惑度不等于高质量生成。LLM-as-Judge 用强大 LLM（如 GPT-4）作为裁判对输出评分或排序，能评测开放式生成任务、成本远低于人工，但存在位置偏差、冗长偏差与自我偏好偏差，可通过随机化顺序、多裁判平均与校准提示缓解。人工评测是黄金标准，形式包括成对比较、Likert 量表评分与 A/B 测试，但成本高、一致性低、难以规模化。

数据污染检测是评测中最严重的威胁之一——当评测数据或其变体出现在训练集中时，模型表现被人为抬高。检测方法包括 n-gram 重叠检测、困惑度分析（污染样本困惑度通常更低）、金丝雀测试（在基准中插入特定字符串检查是否被复现）与动态基准。

### 9.19.3 排行榜

排行榜把多个基准结果汇总为统一排名。Chatbot Arena（LMSYS, 2023）基于成对比较与 Elo 评分，用户与两个匿名模型对话后选择更好者，系统据投票计算 Elo

$$E_A=\frac{1}{1+10^{(R_B-R_A)/400}},\quad R_A'=R_A+K(S_A-E_A)$$

它数据来自真实用户、题目持续更新、反映实际偏好，被认为最可信之一，但用户群体偏技术、题目分布不均、部分模型可能靠对话风格获高分。Open LLM Leaderboard（HuggingFace, 2023）专注开源模型，包含 MMLU-Pro、GPQA、MuSR、MATH、IFEval、BBH 等基准，完全可复现，但存在"刷榜"现象。HELM 提供多维度自动化评测且流程标准化。

| 排行榜 | 评测方法 | 覆盖范围 | 更新频率 | 可信度来源 |
|:---|:---|:---|:---|:---|
| Chatbot Arena | 成对比较 + Elo | 闭源 + 开源 | 实时 | 真实用户投票 |
| Open LLM Leaderboard | 自动化指标 | 仅开源 | 按提交 | 完全可复现 |
| HELM | 多维度自动化 | 闭源 + 开源 | 定期 | 标准化评测 |

### 9.19.4 应用领域

LLM 已渗透到多个领域。代码生成与开发辅助方面，GitHub Copilot 提供上下文感知补全，Cursor 是以 LLM 为核心的 AI-native IDE，Devin 定位为自主软件工程师。科学研究方面，AlphaFold 3 以接近实验精度预测蛋白质结构，LLM 辅助文献综述与假设生成，AlphaProof 与 AlphaGeometry 2 在 2024 年 IMO 竞赛中取得接近金牌的成绩。教育方面有个性化辅导与作业批改（核心优势是无限耐心与即时反馈），但面临学术诚信与错误传播挑战。医疗方面有临床决策支持（Med-PaLM 2 在 USMLE 上正确率超 85%）、患者沟通与药物研发，但必须遵循隐私保护与安全审查，任何建议需医生审核。法律方面有合同审查与案例检索，但存在生成虚假法律条文与判例的幻觉风险。创意写作可辅助小说、剧本与文案创作，但缺乏深层叙事张力。Agent 系统把 LLM 作为核心推理引擎，代表架构有 ReAct（推理与行动交织）、AutoGPT/BabyAGI（自主分解子任务）、Computer Use（操控计算机完成跨应用任务）与 MCP（标准化 LLM 与工具交互的开放协议）。Agent 的核心局限是可靠性：若每步成功率 $p$，$n$ 步任务整体成功率约 $p^n$，即使 $p=0.95$，10 步任务也仅约 0.60。各领域应用概况如下。

| 应用领域 | 代表产品/系统 | 核心能力 | 成熟度 | 关键风险 |
|:---|:---|:---|:---|:---|
| 代码生成 | Copilot / Cursor | 补全、重构、调试 | 高 | 代码安全、许可证 |
| 科学研究 | AlphaFold / SciSpace | 文献分析、结构预测 | 中 | 结果验证、可复现性 |
| 教育 | Khanmigo / Duolingo | 个性化辅导、批改 | 中 | 学术诚信、事实错误 |
| 医疗 | Med-PaLM / PathChat | 临床决策、病历总结 | 低~中 | 隐私、安全、合规 |
| 法律 | Harvey AI / CoCounsel | 合同审查、案例检索 | 中 | 幻觉（虚假引用） |
| 创意写作 | Claude / ChatGPT | 小说、剧本、文案 | 中 | 原创性、版权 |
| Agent 系统 | AutoGPT / Computer Use | 自主任务执行 | 低 | 可靠性、安全性 |

### 9.19.5 局限与未来展望

LLM 的核心局限包括：幻觉（自信地生成与事实不符的内容，根源是训练目标是预测下一个 token 而非验证事实；分内在幻觉——与输入矛盾，与外在幻觉——无法从输入验证；缓解手段有 RAG、事实验证链与事实性 RLHF）、推理深度不足（在多步逻辑、反事实与组合泛化上仍困难，ARC-AGI 等揭示其"天花板"，提升方向有 CoT、Self-Consistency、ToT 与过程奖励模型）、上下文窗口限制（长上下文质量随长度下降，出现"中间遗忘"；扩展面临 $O(n^2)$ 计算成本，可用稀疏注意力、线性注意力与滑动窗口缓解）与成本延迟（前沿模型推理成本高，首 token 延迟通常 0.5~2 秒，对实时交互仍偏长）。

未来方向围绕四条主线。一是多模态融合：从"文本为主、图像为辅"向原生多模态演进（在文本、图像、音频、视频联合数据上预训练），具身智能是其终极形态（如 RT-2 实现语言指令到动作序列的端到端映射）。二是 Agent 能力增强：通过过程奖励模型、自我纠正与多 Agent 协作提升可靠性。三是世界模型构建：LeCun 等指出 LLM 缺乏对物理世界的内部模型，构建能模拟物理因果的内部表征是通向通用人工智能的关键路径；视频生成模型可视为一种视觉世界模型，但其是否真正理解物理定律仍开放。四是推理能力突破：推理时间计算（Test-Time Compute，如 o1/o3，把训练算力转移到推理阶段"思考更久"）、形式化推理（用 Lean、Coq 验证 LLM 生成的证明）、神经符号融合（LLM 提取符号表示、符号求解器精确推理、LLM 转回自然语言）。此外，安全与对齐将随能力增强而愈发重要，长期挑战在于平衡安全性与有用性。
