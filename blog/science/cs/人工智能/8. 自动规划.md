# 第 8 章 自动规划

**本章导读**：自动规划 (Automated Planning) 研究如何从初始状态出发，自动构造动作序列或策略以达成目标，是人工智能中连接搜索、逻辑推理与决策的核心领域。本章从经典规划的形式化表示 STRIPS 与 PDDL 出发，先讨论状态空间中的前向、后向与部分有序搜索，再介绍图规划 (GraphPlan) 与层次任务网络 (HTN) 两种结构化规划范式；随后放松经典规划的确定性假设，进入非确定性规划、概率规划与部分可观测规划；最后建立自动规划与基于模型的强化学习之间的桥梁，说明规划与学习如何在 Dyna、MPC、MCTS 与 MuZero 等系统中走向融合。

- 描述部分有序规划中的因果链接、威胁与提升/降级消解，并构建规划图、判定互斥；

## 8.1 经典规划：STRIPS 表示

### 8.1.1 从搜索问题到规划问题

自动规划的目标是让系统自行决定"做什么、按什么顺序做"，从而把智能体的高层目标转化为可执行的动作方案。它与第 2 章的搜索问题有本质区别。搜索问题通常以原子状态（如地图上的城市名）建模，动作是简单的后继函数 `RESULT(s, a) = s'`；而规划问题采用**要素化表示 (factored representation)**，状态由若干命题变量的真值组合构成，动作则是**动作模式 (action schema)**，具有**提升性 (lifted)**——一个模式经过变量绑定可实例化为许多具体动作。正因为动作带有前提条件与效果，规划器才能对动作之间的因果依赖、资源冲突与时序关系进行推理，并同时进行前向与后向分析。代价是状态空间规模急剧膨胀：若状态由 $n$ 个布尔命题描述，则共有 $2^n$ 种状态，直接枚举不可行。

**经典规划 (Classical Planning)** 建立在如下理想化假设之上：

- **完全可观测**：智能体在每个时刻完全知晓当前状态；
- **确定性**：每个动作的效果完全确定，不存在随机性或非确定性；
- **静态**：世界只在智能体执行动作时改变，没有其他外部事件；
- **有限且离散**：规划是有限长度的动作序列，动作在离散时间步上顺序执行；
- **可达性目标**：目标是必须达成的世界状态或状态的合取。

后续 8.5 节将逐条放松这些假设，得到非确定性规划、概率规划与部分可观测规划。

### 8.1.2 STRIPS 表示

**STRIPS (STanford Research Institute Problem Solver)** 由 Fikes 与 Nilsson 于 1971 年提出，是早期最具影响力的规划系统，其核心贡献是确立了以**动作算子 (operator)** 为基本单元的表示框架。一个 STRIPS 规划问题由四部分组成。

**状态 (State)** 是一组**无函数的一阶谓词正基元合取式 (function-free conjunctive ground atoms)**。给定谓词符号与对象常量集合，状态写成 $s = p_1 \land p_2 \land \dots \land p_n$，每个 $p_i$ 形如 `At(robot, roomA)` 或 `Holding(robot, box1)`。未在状态中出现的基元默认为假，这正是**封闭世界假设 (Closed-World Assumption, CWA)**。

**初始状态 (Initial State)** $s_0$ 是规划开始时世界的命题合取。**目标 (Goal)** 是目标状态的部分描述 $g$，由若干正基元合取构成；状态 $s$ 满足目标当且仅当 $g \subseteq s$，即目标只规定必须成立的事实，不排斥其他事实。

**动作 (Action)** 是一个四元组：
$$a = \langle \text{Name}, \text{Pre}(a), \text{Add}(a), \text{Del}(a) \rangle$$
其中 $\text{Name}$ 是名称与参数（如 `Pickup(?x)`），$\text{Pre}(a)$ 是必须同时为真的**前提条件 (Preconditions)**，$\text{Add}(a)$ 是执行后变为真的**添加效果 (Add Effects)**，$\text{Del}(a)$ 是执行后变为假的**删除效果 (Delete Effects)**。动作 $a$ 在状态 $s$ 下可执行当且仅当 $\text{Pre}(a) \subseteq s$，其结果由结果函数给出：
$$s' = \text{Result}(s, a) = (s \setminus \text{Del}(a)) \cup \text{Add}(a)$$

**积木世界 (Blocks World)** 是规划研究的经典基准。设桌面上有积木 A、B、C，初始时 A 在 B 上、B 与 C 在桌上、机械臂为空，目标是把 C 放到 B 上。所需谓词为 `On(?x, ?y)`、`OnTable(?x)`、`Clear(?x)`、`Holding(?x)`、`Empty`，动作定义如下。

| 动作 | 前提条件 | 添加效果 | 删除效果 |
|:---|:---|:---|:---|
| `Pickup(?x)` | `Clear(?x)`，`OnTable(?x)`，`Empty` | `Holding(?x)` | `OnTable(?x)`，`Clear(?x)`，`Empty` |
| `Putdown(?x)` | `Holding(?x)` | `OnTable(?x)`，`Clear(?x)`，`Empty` | `Holding(?x)` |
| `Unstack(?x, ?y)` | `On(?x, ?y)`，`Clear(?x)`，`Empty` | `Holding(?x)`，`Clear(?y)` | `On(?x, ?y)`，`Clear(?x)`，`Empty` |
| `Stack(?x, ?y)` | `Holding(?x)`，`Clear(?y)` | `On(?x, ?y)`，`Clear(?x)`，`Empty` | `Holding(?x)`，`Clear(?y)` |

一个可行解为 $\pi = \langle \text{Unstack}(A,B), \text{Putdown}(A), \text{Pickup}(C), \text{Stack}(C,B) \rangle$。

### 8.1.3 封闭世界假设与框架问题

STRIPS 的简洁性来自若干关键假设。除封闭世界假设外，最重要的当属它对**框架问题 (Frame Problem)** 的处理。框架问题问的是：如何在不逐条罗列的前提下，自动描述动作执行后**什么保持不变**。若用完整逻辑公理化，就必须为每个动作与每个命题编写**框架公理 (frame axiom)**，例如"除非 `Putdown(x)` 删除了 `On(y,z)`，否则 `On(y,z)` 在动作后依旧成立"。这类公理数量随动作与命题乘积增长，几乎不可维护。

STRIPS 的解决办法是**只指定变化**：凡不在 $\text{Add}(a)$ 与 $\text{Del}(a)$ 中的命题在动作后自动保持不变，等于把框架公理"编译"进了结果函数的定义里。其他假设还包括：前提条件是命题的合取（不允许析取与否定）、添加与删除列表不相交且效果确定、谓词中不含函数符号以保证状态有限。这些限制在复杂领域中日渐凸显，促成了后续的扩展。

### 8.1.4 PDDL 与 ADL 扩展

**PDDL (Planning Domain Definition Language)** 由 McDermott 等人于 1998 年提出，是国际规划竞赛 (IPC) 采用的标准交换语言。它把 STRIPS 推广为完整的规划域定义框架，并把问题拆成两个文件：**域文件 (Domain File)** 定义谓词与动作模式，**问题文件 (Problem File)** 定义具体对象、初始状态与目标。下面给出积木世界的 PDDL 片段。

```lisp
(define (domain blocksworld)
  (:requirements :strips)
  (:predicates (On ?x ?y) (OnTable ?x) (Clear ?x)
               (Holding ?x) (Empty))
  (:action Stack
    :parameters (?x ?y)
    :precondition (and (Holding ?x) (Clear ?y))
    :effect (and (On ?x ?y) (Clear ?x) (Empty)
                 (not (Holding ?x)) (not (Clear ?y)))))
```

域文件开头的 `:requirements` 声明语言特性，规划器据此判断自身是否支持。常见的需求标签包括基础 STRIPS（`:strips`）、类型系统（`:typing`）、否定与析取前提（`:negative-preconditions`、`:disjunctive-preconditions`）、量化前提（`:existential-preconditions`、`:universal-preconditions`）、条件效果（`:conditional-effects`）、动作代价（`:action-costs`）、持续动作（`:durative-actions`）与数值流（`:numeric-fluents`）等。

**ADL (Action Description Language)** 由 Pednault 于 1987 年提出，是 STRIPS 的功能性扩展。二者的主要差异如下。

| 维度 | STRIPS | ADL |
|:---|:---|:---|
| 状态 | 正基元的合取 | 正/负基元的合取（允许否定） |
| 前提条件 | 正基元的合取 | 任意一阶公式（含量化、析取） |
| 效果 | 仅合取（Add + Delete） | 合取，含条件效果 |
| 框架处理 | 隐式（不在效果中即不变） | 开放世界语义或隐式处理 |
| 世界假设 | 封闭世界 (CWA) | 开放世界 (OWA) |
| 类型系统 | 无 | 类型化对象 |

ADL 的条件效果用 `when` 子句表达，使动作效果可以依赖执行时的状态，例如移动一个箱子时，若其上有物体则连带移动该物体。除 ADL 外，STRIPS 还有若干重要扩展：**数值流 (Numeric Fluents)** 让状态包含可比较、可增减的数值变量，用于资源与燃料约束；**函数符号 (Function Symbols)** 支持 `Location(Robot) = RoomA` 这类多值状态；**持续动作 (Durative Actions)** 赋予动作显式时长与时序条件，用于时序规划；**层级类型 (Type Hierarchies)** 以子类型关系组织对象，提高动作模式的可复用性。

**SAS+ (Simplified Action Structures)** 由 Bäckström 与 Nebel 于 1995 年提出，采用**多值状态变量**而非命题：状态是各变量取值的组合，动作用变量-值对描述。它可从命题 STRIPS 经**不变式分析 (Invariant Analysis)** 自动编译得到，取值空间通常远小于命题总数。Fast Downward 规划器的核心内部表示即基于 SAS+。与之密切相关的**状态变量表示**以功能属性建模世界，天然支持数值与不等式比较，适合物流与资源调度；而**集合论表示**把状态视为命题集合、动作视为集合运算，**经典逻辑表示**则用一阶**情境演算 (Situation Calculus)** 把动作与状态编码为公式，后者更偏向知识密集的演绎规划。

### 8.1.5 经典规划的形式化、性质与复杂度

一个**经典规划问题 (Classical Planning Problem)** 可形式化为四元组 $P = (S, s_0, G, A)$：$S$ 是状态空间（命题表示下 $|S| = 2^n$），$s_0 \in S$ 是初始状态，$G \subseteq S$ 是目标状态集合（常由部分目标 $g$ 定义为 $\{s \mid g \subseteq s\}$），$A$ 是动作集合，每个动作是定义在满足 $\text{Pre}(a) \subseteq s$ 的状态上的部分函数。**规划解 (Plan)** 是动作序列 $\langle a_1, \dots, a_k \rangle$，满足每个 $a_i$ 在 $s_{i-1}$ 下可执行、$s_i = \text{Result}(s_{i-1}, a_i)$ 且 $s_k \in G$；若存在这样的解，则称问题**可解 (solvable)**。

规划系统的两个基本性质是：**可靠性 (Soundness)** 指系统返回的序列必为真正的解；**完备性 (Completeness)** 指对所有可解问题系统最终都能找到解，而不会在有解时错误报告无解。实际系统受内存与时间限制，常以牺牲完备性换取效率。

规划在计算上极其困难。命题 STRIPS 规划的判定问题是 **PSPACE 完全 (PSPACE-complete)** 的：若不加限制，判定是否存在解属于 PSPACE 难；若限定规划长度不超过多项式，则问题降为 **NP 完全 (NP-complete)**，与布尔可满足性问题同难度。根源仍是状态空间随命题数指数增长，即**状态空间爆炸 (Combinatorial Explosion)**。实践中必须借助启发式函数、规划图、约简到 SAT/约束满足等技术，才能在高维空间中有效搜索。

## 8.2 规划算法

规划的核心挑战是搜索空间通常极其庞大，算法需要借助动作描述中编码的领域知识来引导搜索。本节介绍前向搜索、后向搜索、领域无关启发式与部分有序规划。

### 8.2.1 前向状态空间搜索

**前向搜索 (Forward Search)**，又称**前展规划 (Progression Planning)**，从初始状态 $s_0$ 出发，反复应用可行动作逐步展开后继状态，直到某个状态包含目标。它本质上是在状态空间图上的前向可达性搜索：在状态 $s$ 中，动作 $a$ **适用 (applicable)** 当且仅当 $\text{precond}(a) \subseteq s$，其后继为 $s' = (s \setminus \text{delete}(a)) \cup \text{add}(a)$。

前向搜索可以直接套用第 2 章的各种搜索策略。广度优先搜索保证找到动作数最少的解，但空间消耗极大；深度优先搜索内存高效却可能陷入循环，既不完备也不最优；最佳优先搜索与 A\* 使用启发式 $h(s)$ 估计到目标的距离，是现代前向规划器的主流。其最大弱点是**分支因子过大**：任一状态下所有前提条件满足的动作都可执行，其中大量动作与目标无关，容易"无用地兜圈"。设平均分支因子为 $b$、解长为 $d$，搜索树规模为 $O(b^d)$，若无有效启发式引导，前向搜索极易被组合爆炸淹没。它的优点则是概念直观、所有状态均真实可达、目标检查只需验证 $G \subseteq s$。

### 8.2.2 后向状态空间搜索与目标回归

**后向搜索 (Backward Search)**，又称**回归规划 (Regression Planning)**，采取相反策略：从目标出发逆向推理中间条件，直到得到初始状态的子集。它的搜索节点不是具体状态，而是**目标描述 (Goal Description)**——一组必须为真的命题。

核心操作是**目标回归 (Goal Regression)**。给定目标描述 $g$ 与动作 $a$，若 $a$ 能对 $g$ 有所贡献且不破坏 $g$，则回归为：
$$\text{Regress}(g, a) = (g \setminus \text{add}(a)) \cup \text{precond}(a)$$
直观地说，要让 $g$ 在动作后成立，执行前必须满足两件事：$g$ 中那些不是由 $a$ 添加的命题，以及 $a$ 自身的前提条件。这里的动作必须**与目标相容**，即 $\text{delete}(a) \cap g = \emptyset$；同时要求 $\text{add}(a) \cap g \neq \emptyset$，这样的动作称为**相关动作 (relevant action)**。后向搜索每一步只考虑相关动作，因此分支因子通常远小于前向搜索，方向感更强；在积木世界、物流等经典基准中往往更高效。

后向搜索也有代价。回归得到的只是**部分状态描述**，一个节点对应无限多个具体状态，语义不如前向清晰；当目标为多个子目标的合取时，为子目标 $g_1$ 选择的动作可能通过删除效果破坏子目标 $g_2$，反之亦然，这就是著名的 **Sussman 异常 (Sussman Anomaly)**，它表明"先分头解决子目标再合并"的思路并不完备。此外，后向搜索需要逆向完成动作实例化，且部分状态空间仍可能很大。

### 8.2.3 领域无关启发式

启发式 $h(s)$ 是规划搜索的效率核心，其难点在于**如何为任意领域自动生成有效启发式**。答案来自对动作模型的**松弛 (relaxation)**，最主要的是**删除效果松弛 (Delete Relaxation)**：忽略所有删除效果，命题一旦为真便永远为真，子目标之间的相互破坏随之消失，于是松弛问题的最优解代价可作为原问题的一个估计。

基于删除松弛，可以构造一族启发式。$h^+$ 是松弛空间中的最优解代价，**可纳 (admissible)** 且从不高估，但精确计算它是 NP 难的。$h^{\text{add}}$ 假设各子目标完全独立并将代价相加，计算高效却会重复计数、并非可纳；$h^{\text{max}}$ 只取最难子目标的代价，可纳但过于悲观、引导力弱。$h^{\text{FF}}$ 由 Fast Forward (FF) 规划器使用，它在删除松弛空间中求一个"足够好而非最优"的松弛解，用其动作数作估计，实践效果极佳。**地标启发式 (Landmark-based Heuristics)** 另辟蹊径：**地标 (landmark)** 是在所有有效规划中都必经的命题，据此累加待实现地标的代价即可得到估计；代表系统 LAMA 曾在 IPC 中连续夺冠。

| 启发式 | 可纳性 | 计算成本 | 引导力 | 典型使用 |
|:---|:---:|:---:|:---:|:---|
| $h^{\text{max}}$ | 是 | 低 | 弱（严重低估） | 下界估计 |
| $h^{\text{add}}$ | 否 | 低 | 中偏强 | 满意规划 |
| $h^+$（精确） | 是 | 极高（NP 难） | 强 | 理论基准 |
| $h^{\text{FF}}$ | 否 | 中 | 强 | FF 规划器 |
| $h^{\text{LM}}$ | 可配置 | 中高 | 强 | LAMA |
| $h^{\text{LM-cut}}$ | 是 | 中高 | 较强 | 代价最优规划 |

FF 还提出**强制爬山搜索 (Enforced Hill-Climbing, EHC)**：在每个状态用广度优先搜索寻找严格优于当前状态的后继，一旦找到即移动；若邻域内无更优状态，则回退到最佳优先搜索。它把爬山的果断与最佳优先的全局保证结合起来。更一般地，以 $h^{\text{FF}}$ 或 $h^{\text{LM}}$ 为启发式的 A\* / 加权 A\*（$f(n) = g(n) + w \cdot h(n)$，$w > 1$）牺牲可纳性换取速度，是**满意规划 (satisficing planning)** 的常用配置；若要求**代价最优 (cost-optimal)**，则常使用可纳的地标切割启发式。

### 8.2.4 部分有序规划

前向与后向搜索都属于**全序规划 (Total-Order Planning)**，产出严格的线性动作序列。这带来**过早承诺 (Premature Commitment)** 的问题：搜索初期就必须决定两个因果无关动作的先后，而它们本可并行或任意排序。**部分有序规划 (Partial-Order Planning, POP)** 以**最小承诺原则 (Least Commitment Principle)** 应对——只记录因果关系要求的顺序，不对无关动作施加约束，因此一个规划是**偏序 (Partial Order)** 结构。

POP 由三个要素组成：**动作集合**（含虚拟的 Start 与 Finish 动作，前者无前提、效果为 $s_0$，后者前提为目标 $G$、无效果）、**排序约束 (Ordering Constraints)** $A \prec B$（传递且非自反）、以及**因果链接 (Causal Links)** $\langle A \xrightarrow{p} B \rangle$，表示命题 $p$ 由 $A$ 建立、供 $B$ 使用。因果链接是 POP 最重要的概念，它显式记录了"谁为什么提供了什么"。

不完善的规划包含两类**缺陷 (Flaws)**：**开放前提 (Open Precondition)**，即某动作的前提尚未被任何因果链接建立；以及**威胁 (Threat)**，即某动作的删除效果可能破坏已有因果链接。威胁的消解有两种方式：**提升 (Promotion)** 添加 $C \prec A$，让威胁动作在建立之前执行；**降级 (Demotion)** 添加 $B \prec C$，让威胁动作在使用之后执行。若两种方式都与现有约束矛盾，则该分支失败。规划过程就是不断消解缺陷，直到无缺陷且约束一致，此时任一满足排序约束的**线性化 (linearization)** 即为有效规划。

```text
function POP(plan):
    flaws ← OpenGoals(plan) ∪ Threats(plan)
    if flaws = ∅: return plan
    choose a flaw ∈ flaws
    for each resolver ∈ Resolve(flaw, plan):
        plan' ← Refine(plan, resolver)
        if ordering_constraints(plan') 无环:
            result ← POP(plan')
            if result ≠ failure: return result
    return failure
```

经典 POP 系统包括 UCPOP、VHPOP 与 RePOP。VHPOP 用基于状态的启发式指导缺陷选择；RePOP 则证明部分有序规划在配备现代删除松弛启发式后，性能可与全序规划器媲美，甚至在并行执行场景中更优。

### 8.2.5 算法对比

三种算法在多个维度上各有取舍。

| 特性 | 前向搜索 | 后向搜索 | 部分有序规划 |
|:---|:---|:---|:---|
| 搜索方向 | 初始状态 → 目标 | 目标 → 初始状态 | 计划空间，无固定方向 |
| 搜索节点 | 具体状态 | 目标描述（部分状态） | 不完整规划 |
| 分支因子 | 大（所有适用动作） | 较小（仅相关动作） | 取决于缺陷消解方式数 |
| 方向感 | 弱，依赖启发式 | 较强，由目标驱动 | 强，由缺陷驱动 |
| 并行性 | 不显式表示 | 不显式表示 | 显式记录 |
| 大规模效率 | 高（配合 $h^{\text{FF}}$） | 中等 | 较低（计划空间通常更大） |

前向搜索适合搜索空间能被强启发式有效引导、动作以"建设性"添加为主的场景，如 FF、LAMA 与机器人动作规划；后向搜索适合目标明确、相关动作易识别的领域，如物流与积木世界；部分有序规划适合需要并行执行或子规划复用的多机器人协调、工作流调度等场景。现代高性能规划器往往混合多种机制，例如 FF 用前向搜索加松弛启发式，GraphPlan 结合前向传播与后向提取，LAMA 在前向搜索中融入地标分析。

## 8.3 图规划（GraphPlan）

### 8.3.1 核心思想

**图规划 (GraphPlan)** 由 Blum 与 Furst 于 1995 年提出（1997 年正式发表），是规划史上的里程碑。与状态空间搜索不同，它先构造一个紧凑的图结构来近似"在前 $k$ 步内可能达到的所有命题"，再在图上提取规划，这种"先构建、再提取"的两阶段策略是它的根本特征。

规划图是一种**紧凑近似 (compact approximation)**，编码了有限层数内所有**可能**的状态与动作。这里的"可能"意味着图中包含了一些真实不可达的命题与动作，因为互斥关系被延迟检测，因此它是对真实状态空间的**过近似 (over-approximation)**。这一近似的构建代价是多项目式的，并且它在"不存在解"的判断上是保守的：若某命题不在图中或目标命题互斥，则它在真实空间中也确实不可达。GraphPlan 因此把搜索空间从"状态的幂集"压缩为"命题与动作的关系图"，实现了相对于 $O(2^n)$ 的指数级压缩。

### 8.3.2 规划图的结构

规划图是**有向无环的分层图 (Directed Acyclic Layered Graph)**，由命题层与动作层交替排列：
$$P_0 \to A_0 \to P_1 \to A_1 \to P_2 \to \dots \to P_k$$

**命题层 (Proposition Layer)** $P_i$ 收集第 $i$ 步可能成立的所有命题，$P_0$ 即初始状态中的全部命题。**动作层 (Action Layer)** $A_i$ 收集第 $i$ 步可应用的动作实例，外加为每个命题创建的**持久化动作 (No-op / Persistence Action)**。No-op 的前提与添加效果都只含该命题、无删除效果，作用是让"为真且无人删除"的命题延续到下一层，相当于框架公理的显式实现。层与层之间的边有三种：**前提边 (Precondition Edges)** 从命题指向以它为条件的动作，**添加边 (Add/Positive Effect Edges)** 从动作指向它添加的命题，**删除边 (Delete/Negative Effect Edges)** 从动作指向它删除的命题，删除边只用于标记互斥而不创建节点。

规划图不会无限扩张。随层数增加，命题层内容单调增长并最终收敛到**不动点 (Levelling-off)**，此时 $P_{k+1} = P_k$，互斥关系也不再减少：
$$P_0 \subseteq P_1 \subseteq \dots \subseteq P_{\text{levelled-off}}$$
若到达不动点仍未达成目标，GraphPlan 判定问题无解并终止。

### 8.3.3 规划图的扩张

扩张是自底向上逐层构建的迭代过程。首先初始化 $P_0$ 为初始状态命题并标记逻辑矛盾命题互斥。接着构建动作层 $A_i$：若某动作的全部前提条件都出现在 $P_i$ 中且两两不互斥，则将其加入；同时为 $P_i$ 中每个命题添加 no-op。然后由 $A_i$ 中所有动作的添加效果并集得到命题层：
$$P_{i+1} = \bigcup_{a \in A_i} \text{Add}(a)$$
随后标记动作互斥与命题互斥，并检查终止条件：若目标命题全部出现且两两不互斥，则进入解提取；否则若命题集合与互斥关系都不再变化，则报告无解；否则继续扩展下一层。

### 8.3.4 互斥关系

互斥是 GraphPlan 最核心的约束机制。没有互斥，规划图将退化为各命题独立出现的过度乐观近似，几乎无法引导搜索。**动作互斥 (Action Mutex)** 的判定有三条：**不一致效果 (Inconsistent Effects)** 指一个动作删除另一个动作的添加效果；**干扰 (Interference)** 指一个动作删除另一个动作的前提条件；**竞争需求 (Competing Needs)** 指两动作的前提条件本身在 $P_i$ 中互斥。形式化地：
$$\text{Del}(a_1) \cap \text{Add}(a_2) \neq \varnothing \;\lor\; \text{Del}(a_2) \cap \text{Add}(a_1) \neq \varnothing$$
$$\text{Del}(a_1) \cap \text{Precond}(a_2) \neq \varnothing \;\lor\; \text{Del}(a_2) \cap \text{Precond}(a_1) \neq \varnothing$$
$$\exists p_1 \in \text{Precond}(a_1),\, p_2 \in \text{Precond}(a_2): \text{mutex}_{P_i}(p_1, p_2)$$

**命题互斥 (Proposition Mutex)** 的判定有两条：**逻辑矛盾**，即 $p$ 与 $\neg p$；以及**不一致支持 (Inconsistent Support)**，即所有能产生 $p$ 的动作与所有能产生 $q$ 的动作都两两互斥，不存在一对兼容的支持动作。互斥关系按层递推：从第 0 层的逻辑矛盾出发，先由命题互斥生成动作互斥，再由动作互斥生成下一层命题互斥。一个重要性质是**互斥的单调性**——一对命题一旦不再互斥，后续层也不会重新互斥，因此互斥数量随层数增加而单调不增。

### 8.3.5 解的提取

当目标命题出现在当前层且两两不互斥时，进入解提取。一个解是动作集合的序列 $\langle \Pi_0, \Pi_1, \dots, \Pi_{k-1} \rangle$，每个 $\Pi_i$ 是 $A_i$ 中一组两两不互斥的动作（可视为第 $i$ 步并行执行的批量动作），依次执行后目标成立。由于允许并行，GraphPlan 找到的是**并行规划 (parallel plan)**，其步数刻画最短并行执行时间。

解提取采用**分级逆向搜索**。从第 $k$ 层的目标出发，为每个目标命题在 $A_{k-1}$ 中挑选一个支持动作；若这些动作两两不互斥，则把它们的全部前提条件并集作为下一层子目标 $g' = \bigcup_{a \in \Pi_{i-1}} \text{Precond}(a)$，递归向第 0 层搜索；若递归到第 0 层时子目标已包含在 $P_0$ 中，则成功返回空规划。为提升效率，解提取通常结合**备忘录 (Memoization)**（缓存已确认失败的子目标-层组合）、**目标排序启发式**（优先处理支持动作最少的命题）与前向可达性剪枝。

```text
function GRAPHPLAN(problem):
    P[0] ← problem.init; mark_mutexes_P(0); i ← 0
    loop:
        if problem.goal ⊆ P[i] and no_pair_mutex(P[i], goal):
            plan ← EXTRACT(goal, i)
            if plan ≠ failure: return plan
        if graph_has_levelled_off(i): return failure
        i ← i + 1; EXPAND(i)
```

### 8.3.6 GraphPlan 的性质、影响与局限

对确定性、全观测、静态的经典规划问题，GraphPlan 是**完备的 (complete)**：若存在长度不超过 $k$ 的并行解，扩展到第 $k$ 层必能找到；若无解，则必在不动点处终止并返回失败。它同时是**步骤最优 (step-optimal)** 的——在第 $n$ 层首次满足目标时，不存在步数少于 $n$ 的并行解。需要强调，步骤最优不等同于动作数最优，GraphPlan 优化的是并行时间步数 (makespan) 而非动作总数。

| 子过程 | 时间复杂度 | 说明 |
|:---|:---|:---|
| 图构建（每层） | $O(m \cdot l \cdot n^2)$ | $m$ 动作数、$l$ 平均效果数、$n$ 命题数 |
| 动作互斥标记（每层） | $O(m^2 \cdot l \cdot n)$ | 检查所有动作对 |
| 命题互斥标记（每层） | $O(n^2 \cdot m)$ | 检查所有命题对 |
| 解提取 | 最坏 NP-hard | 等价于找无冲突动作子图 |

GraphPlan 催生了一系列以规划图为核心的规划器。IPP、STAN 扩展了启发式排序与类型机制；**Blackbox** 把规划图连同互斥约束编码为 CNF 公式，再调用 SAT 求解器完成解提取，可概括为"规划图 + 互斥约束 → CNF → SAT 求解 → 规划解"；**Fast Forward (FF)** 则用**放松规划图 (Relaxed Planning Graph, RPG)** 计算 $h^{\text{FF}}$，在 IPC 中连续夺冠。GraphPlan 的主要局限在于要求**全量实例化 (Full Grounding)**，对对象众多的一阶领域会导致节点爆炸；每层互斥检查带来 $O(m^2 + n^2)$ 的二次开销；规划图内存占用随命题和动作数增长；解提取在某些复杂子目标交互领域可能退化为穷举；此外它天然只适用于经典规划，扩展到时序、不确定性与部分可观测需要额外机制。

## 8.4 层次任务网络规划（HTN）

### 8.4.1 核心概念与范式差异

经典规划需要在巨大的状态空间中搜索，而人类专家处理复杂任务时并不盲目枚举，而是凭借对问题层次结构的理解，从高层抽象逐步细化到具体操作。**层次任务网络规划 (Hierarchical Task Network Planning, HTN)** 正是以此为出发点，用层次化任务分解引导规划。

HTN 的核心隐喻是"分而治之"：给定一个高层复合任务，系统通过预定义的**方法 (Methods)** 将其递归分解为更具体的子任务，形成一棵**任务分解树 (Task Decomposition Tree)**；当所有任务都化为可直接执行的**原语动作 (Primitive Actions)** 时，规划完成。若某条分解路径最终无法产生合法的原语序列，则**回溯 (Backtracking)** 尝试其他方法。

这与经典规划存在根本范式差异。经典规划的核心操作是**状态变换 (State Transformation)**，规划器从初始状态出发逐动作改变状态直至满足目标，搜索空间是所有动作序列；HTN 的核心操作是**问题分解 (Problem Decomposition)**，规划器不断把复合任务替换为子任务网络，依赖方法的预设约束保证合法性，搜索空间是"任务网络的展开方式"。简言之，经典规划问"下一步做什么动作"（**状态驱动 / State-Driven**），HTN 问"这个任务如何分解"（**任务驱动 / Task-Driven**）。HTN 特别适合游戏 AI（如 F.E.A.R.、Killzone 的战术行为）、机器人任务规划、军事后勤与制造过程规划等结构化领域。

### 8.4.2 基本元素

HTN 的规划单元是**任务 (Task)**，分为两类。**原语任务 (Primitive Tasks)** 可直接执行，具备前提条件与效果，例如 `(load ?truck ?cargo ?loc)`；**复合任务 (Compound Tasks)** 代表高层目标，不能直接执行，必须由方法进一步分解，例如 `(transport ?goods ?from ?to)`，其语义由所有可能的分解方式定义。

**方法 (Methods)** 是 HTN 的核心知识库，形式为 $(\text{method}, h, \text{precond}, \text{st})$：`method` 是名称，$h$ 是被分解的复合任务，`precond` 是规定该方法在当前状态下是否适用的前提条件，`st` 是分解得到的**子任务网络 (Subtask Network)**。前提条件把当前世界状态纳入分解决策，例如"用卡车运输"的方法要求有可用卡车且两地道路连通。

**任务网络 (Task Network)** 形式化为 $TN = [(T_1, \dots, T_n), \{\text{constraints}\}]$，其中约束主要包括**排序约束**（$T_i \prec T_j$，定义部分有序的执行安排，无约束的子任务可并行）与**变量绑定约束**（规定不同子任务共享的变量绑定到同一实体）。**初始任务网络 (Initial Task Network)** 定义了问题的目标语义：HTN 的目标不是一个状态公式，而是一组需要完成的任务，初始时通常只包含一个表示整个问题的高层复合任务。

### 8.4.3 规划算法与回溯

HTN 规划通过递归展开复合任务，逐步把初始任务网络化简为仅含原语任务的序列。其总体流程是：

- 以初始任务网络为当前网络，检查任务间排序与变量绑定是否冲突，冲突则回溯；
- 若网络中不再有复合任务，检查原语序列是否合法（顺序执行时各动作前提均成立）；
- 否则选择一个复合任务及其适用方法，把该任务替换为方法的子任务网络，并继承原有排序约束；
- 若当前路径失败，则回溯到方法选择点尝试其他方案。

HTN 的分解是**递归下降 (Recursive Descent)** 过程，每一层面临两个关键选择：**任务选择**（先分解哪个复合任务）通常不影响完备性，只影响效率；**方法选择**则是一个**非确定性 (Nondeterministic)** 决策点，错误选择会导致后续失败并触发回溯。与 STRIPS 不同，HTN 的回溯主要发生在方法选择层面而非动作选择层面，因此搜索的深度与分叉显著更小。

**有序任务分解 (Ordered Task Decomposition, OTD)** 是提升效率的关键技巧：要求每个方法产生的子任务完全有序。这样做的好处是规划器可以边处理边前进——每个原语任务被处理时当前状态已确定，因而可以立即应用其效果、立即检查其前提，无需像偏序规划那样做威胁消解，整个规划过程退化为一个带回溯的深度优先搜索。SHOP 系列正是基于 OTD。

### 8.4.4 代表系统与游戏应用

**SIPE-2** 由 Wilkins 在 SRI International 于 20 世纪 80/90 年代开发，是最早成熟并实际部署的 HTN 系统之一，支持部分有序规划、资源推理、条件效果与多层次回溯，曾用于多项 DARPA 军事后勤项目。**SHOP (Simple Hierarchical Ordered Planner)** 由 Nau 等人开发，以 OTD 保证简洁高效；其继任者 **SHOP2** 进一步支持部分有序方法、用于动态推导事实的**公理 (Axioms)** 以及数值约束，表达能力更强。**O-Plan** 把 HTN 与偏序规划的威胁消解结合，I-X 则面向多智能体的协同规划与执行。

HTN 在游戏 AI 中取得了标志性成功。F.E.A.R.（2005）用 HTN 驱动敌人的小队战术，高层任务如压制玩家被分解为"寻找掩体 → 投掷手雷 → 开火"；当掩体被破坏时，规划器自动回溯到"寻找掩体"的方法选择点，表现出比有限状态机更自然的应变能力。Killzone 2/3 把包抄、火力压制、撤退、呼叫支援等战术编码为 HTN 领域知识，由规划器依据战场状态动态选择方法。游戏中的 HTN 通常是**实时 HTN (Real-time HTN)** 变体：规划器持续维护当前分解状态，仅当环境变化"意外"地使方法前提失效时才触发局部重规划。

### 8.4.5 与经典规划的对比及扩展

HTN 与经典规划在多个维度上形成鲜明对照。

| 维度 | 经典规划（STRIPS / GraphPlan） | HTN 规划 |
|:---|:---|:---|
| 搜索范式 | 状态驱动，搜索动作序列 | 任务驱动，分解任务网络 |
| 搜索空间 | 合法动作序列的组合空间 | 合法任务分解方式的空间 |
| 领域知识 | 仅需动作模型，需求低 | 需额外编写方法库，需求高 |
| 表达力 | 等价于确定性状态变换系统 | 无限制时是图灵完备的 |
| 搜索效率 | 依赖启发式引导 | 层次结构天然缩减搜索空间 |
| 典型系统 | STRIPS、GraphPlan、FF | SIPE-2、SHOP2、O-Plan、PANDA |

在表达力上，Erol、Hendler 与 Nau（1996）证明：在明确的程序语义下，无约束 HTN 是**图灵完备 (Turing-complete)** 的，因为方法库允许条件分支、递归调用与变量绑定；而 STRIPS 规划的判定问题属于 PSPACE。这种理论优势的来源也正是它的实际代价——**知识工程 (Knowledge Engineering)**：编写和维护方法库需要领域专家与工程师协作，前提过严会漏解，过宽会搜索爆炸，这一"知识获取瓶颈"是 HTN 在开放领域难以普及的主因。

HTN 的常见变体包括：**递归 HTN** 允许方法子任务调用同一复合任务（如多段中转运输），表达力强但有无限递归风险；**非递归 HTN** 要求每步分解严格变简单以保证终止，SHOP 系列属于此类。**目标推理 (Goal Reasoning)** 扩展允许智能体在规划执行中动态修改任务网络，以适应动态环境。实践上，编写高质量方法库有几条经验：方法前提应尽量保守以尽早过滤、每个方法只做一类事、优先选用约束最强的方法、避免过拟合导致漏解、对重复模式使用递归分解。

## 8.5 非确定性规划与概率规划

### 8.5.1 超越经典规划的假设

经典规划依赖确定性、完全可观测、静态、单一初始状态与逻辑公式目标等一系列强假设。现实问题却常违反其一：传感器噪声使观测不完全或出错，执行器误差使动作偏离预期，其他智能体可能同时行动，环境建模本身也不精确。STRIPS 与经典 PDDL 子集无法表达"拧螺丝有 90% 成功率"或"门可能锁着而你看不到"这类情景。由此有两条扩展路径：**非确定性规划**允许动作有多个可能结果但无概率信息；**概率规划**进一步为结果赋予显式概率分布。

| 假设 | 经典规划 | 非确定性规划 | 概率规划 |
|:---|:---|:---|:---|
| 动作效果 | 唯一确定 | 可能结果集合 | 概率分布 |
| 状态观测 | 完全可观测 | 完全可观测 | 可部分可观测 |
| 规划形式 | 动作序列 | 策略 (Policy) | 策略 + 值函数 |
| 最优性 | 任意/最短序列 | 强/弱/强循环 | 期望奖励最大化 |

### 8.5.2 非确定性规划

非确定性规划的转移函数不再是单一后继，而是可能状态集合：
$$\gamma(s, a) \subseteq S$$
执行 $a$ 后可能到达多个状态之一，规划器无法预知是哪一个。**完全可观测非确定性规划 (Fully Observable Non-Deterministic Planning, FOND)** 是最基本的模型：状态完全可观测而动作效果非确定，其判定问题为 EXPTIME 完全，是介于 STRIPS 与 MDP 之间的复杂度层次。

FOND 有三种解的概念。**弱规划 (Weak Planning)** 只要求存在某条执行路径达成目标，即"运气足够好就能成功"；**强规划 (Strong Planning)** 要求无论非确定选择如何，目标都必然在有限步内达成，等价于在 AND-OR 搜索空间中找到一个无环解子图；**强循环规划 (Strong Cyclic Planning)** 允许路径包含循环，但在**公平性假设 (Fairness Assumption)** 下必然最终达成目标——即反复尝试开门直到成功。由于执行结果不确定，解不再是动作序列，而是**策略 (Policy)** $\pi: S \rightarrow A$，把每个可达状态映射到应执行的动作；策略可以用决策列表、决策树或值函数隐式策略表示。

经典 FOND 规划器各具特色。**PRP (Planner for Relevant Policies)** 由 Muise、McIlraith 与 Beck 于 2012 年提出，把 FOND 编译为经典规划问题求解再提取策略，其关键洞察是只需为非确定分支可能到达的"相关"状态制定策略；**MyND** 使用基于 BDD 或 SAT 的符号化搜索，直接在 AND-OR 空间中寻找强循环策略；**GRENDEL** 采用显式状态空间搜索并借助强化学习中的 Q 值思想指导方向。

### 8.5.3 概率规划与 MDP

当非确定性结果被赋予概率度量，就进入**概率规划 (Probabilistic Planning)**。其转移为条件概率分布 $P(s' \mid s, a) = \Pr(s' \mid s, a)$，满足 $\sum_{s'} P(s' \mid s, a) = 1$。目标通常有两种：**最大化目标达成概率**，或**最大化期望累积奖励** $\mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, a_t, s_{t+1})\right]$，其中 $\gamma \in [0,1]$ 是折扣因子。

概率规划与基于模型的强化学习本质上是同一枚硬币的两面：前者假设模型已知、离线求解策略，后者从经验中估计模型再求解；前者多用 PPDDL/RDDL 表示、属于 ICAPS 规划社区传统，后者多用 MDP 转移矩阵、属于机器学习社区传统。第 7 章的 Q-Learning、SARSA 等无模型算法，本质上是在模型未知时逼近概率规划的解。

**马尔可夫决策过程 (Markov Decision Process, MDP)** 是概率规划的核心数学框架，定义为五元组 $\mathcal{M} = \langle S, A, P, R, \gamma \rangle$：$S$ 是状态集，$A$ 是动作集，$P(s' \mid s, a)$ 满足马尔可夫性（下一状态仅依赖当前状态与动作），$R$ 是即时奖励，$\gamma$ 是折扣因子。规划目标是寻找策略 $\pi$ 最大化值函数：
$$V^\pi(s) = \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, \pi(s_t), s_{t+1}) \;\middle|\; s_0 = s\right]$$
最优值函数满足**贝尔曼最优方程 (Bellman Optimality Equation)**：
$$V^*(s) = \max_{a \in A} \sum_{s' \in S} P(s' \mid s, a)\left[ R(s, a, s') + \gamma V^*(s') \right]$$

### 8.5.4 值迭代与策略迭代

**值迭代 (Value Iteration)** 以动态规划方式逼近贝尔曼最优方程的不动点，每轮把所有状态的值估计向最优值收紧一步，类似最短路径中的 Bellman-Ford 算法。从规划视角看，它相当于进行"深度无限的期望式前向搜索"。其每轮复杂度为 $O(|S|^2 \cdot |A|)$，对大型状态空间不可行，这正是"维数灾难"在规划中的体现。

```text
输入：MDP ⟨S, A, P, R, γ⟩，精度 ε
V[s] ← 0 对所有 s
repeat:
    δ ← 0
    for 每个 s ∈ S:
        v_old ← V[s]
        V[s] ← max_a Σ_{s'} P(s'|s,a) [R(s,a,s') + γ·V[s']]
        δ ← max(δ, |v_old − V[s]|)
until δ < ε(1−γ)/γ
π[s] ← argmax_a Σ_{s'} P(s'|s,a)[R(s,a,s') + γ·V[s']]
```

**策略迭代 (Policy Iteration)** 交替执行策略评估与策略改进：策略评估对当前策略解线性方程组或迭代求 $V^\pi$，策略改进则对每个状态取贪心动作，直到策略稳定。它通常以更少的轮次收敛（因为每次改进都是单调的且策略数量有限），但每轮开销更大；策略评估可用的高斯消元法复杂度为 $O(|S|^3)$。当状态空间过大时，还需要 LAO\*、RTDP 等启发式规划技术，它们与第 7 章的 Dyna 架构形成呼应。

### 8.5.5 部分可观测环境下的规划

当状态无法被完全观测时，需要**部分可观测马尔可夫决策过程 (Partially Observable MDP, POMDP)** $\mathcal{P} = \langle S, A, P, R, \Omega, O, \gamma \rangle$，其中 $\Omega$ 是观测集合，$O(o \mid s', a)$ 是执行动作后到达 $s'$ 时观测到 $o$ 的概率。智能体永远不知道真实状态，只能依据历史 $h_t = \langle a_0, o_1, \dots, a_{t-1}, o_t \rangle$ 推断。

解决方案是维护**信念状态 (Belief State)** $b$——状态空间上的概率分布，$b(s)$ 表示智能体认为当前处于 $s$ 的主观概率。所有信念状态构成 $|S|-1$ 维的概率单纯形。执行动作 $a$ 并观测到 $o$ 后，信念按贝叶斯规则更新：
$$b'(s') = \eta \cdot O(o \mid s', a) \sum_{s \in S} P(s' \mid s, a) \cdot b(s)$$
其中 $\eta$ 是归一化常数。这样 POMDP 就转化为信念空间上的连续 MDP（**信念 MDP**）：状态为信念 $b$，奖励为期望奖励 $R(b, a) = \sum_s b(s) R(s, a)$。其最优值函数是**分段线性且凸的 (Piecewise Linear and Convex, PWLC)**，这是精确求解算法的理论基础。

在信念空间做值迭代面临**双重维数灾难**：状态数大导致信念空间维度极高，且表示值函数的 $\alpha$ 向量数量每轮可能指数增长。精确算法（如 Witness 算法）仅能处理 $|S| \lesssim 50$ 的小问题，因此实践中以近似方法为主。

### 8.5.6 近似与在线求解

**点基值迭代 (Point-Based Value Iteration, PBVI)** 只在选定的信念点集合 $\mathcal{B}$ 上执行备份，而非覆盖整个信念空间。它交替进行两个操作：为每个信念点构造候选 $\alpha$ 向量，以及**剪枝 (Pruning)** 掉在任何信念点都不构成最大值上界的向量以控制规模。信念点通常由从初始信念出发的随机游走收集。**SARSOP** 是 PBVI 的经典变体，通过聚焦于最优策略下可达的信念区域进行自适应采样，是迄今最成功的离线 POMDP 求解器之一。

当状态空间大到无法离线维护完整值函数时，采用**在线规划**，在遇到每个信念状态时即时前瞻搜索。**POMCP (Partially Observable Monte Carlo Planning)** 由 Silver 与 Veness 于 2010 年提出，把 UCT 蒙特卡洛树搜索扩展到 POMDP，其核心洞察是在**历史空间**而非信念空间建树：每个历史节点由一个到达该历史的粒子集合隐式表示信念，从而避免显式维护信念分布。**DESPOT (Determinized Sparse Partially Observable Tree)** 于 2015 年提出，通过**确定化场景**固定随机数序列以减少随机分支，并用上下界剪枝把搜索集中到有希望的分支，在机器人导航等领域取得领先性能。

POMDP 的应用非常广泛：对话管理中用户意图是隐藏状态、系统问询是动作、用户回复是观测；机器人导航中真实位姿是隐藏状态、控制命令是动作、激光雷达读数是观测；医疗决策中真实病情是隐藏状态、治疗方案是动作、检测结果是观测。

### 8.5.7 描述语言、竞赛与选型

**RDDL (Relational Dynamic Influence Diagram Language)** 是 Sanner 于 2010 年为国际概率规划竞赛 (IPPC) 设计的问题描述语言，具有关系化表示、动态贝叶斯网络语义、并发动作与显式奖励函数等特点。**PROST (Probabilistic Planning via Search)** 是 IPPC 历史上最成功的系统之一，融合了 UCT 搜索、跨问题实例学习搜索控制知识以及确定化技术。IPPC 自 2004 年起举办，推动语言从 PPDDL 演进到 RDDL，方法趋势从 UCT/MCTS 主导到深度强化学习进入，再到近年大语言模型辅助规划。

| 维度 | 经典规划 | FOND | MDP | POMDP |
|:---|:---|:---|:---|:---|
| 动作效果 | 唯一确定 | 结果集合 | 概率分布 | 概率分布 |
| 状态观测 | 完全 | 完全 | 完全 | 部分，有 $O(o\mid s',a)$ |
| 解的形式 | 动作序列 | 策略 $\pi:S\to A$ | 策略 $\pi:S\to A$ | 信念策略 $\pi:\Delta(S)\to A$ |
| 最优性 | 最短序列 | 强/弱/强循环 | 期望奖励最大 | 期望奖励最大 |
| 典型求解器 | FF、Fast Downward | PRP、MyND | 值迭代、LAO\* | PBVI、SARSOP、POMCP |

工程选型可遵循如下思路：环境确定且完全可观测时用经典 PDDL 规划器；动作不确定但无可靠概率时用 FOND 求强循环策略；有可靠概率模型且状态空间适中时用 MDP 规划；存在传感器噪声或遮挡时用 POMDP（离线用 SARSOP，在线用 POMCP/DESPOT）；若状态动作空间巨大且无法完整建模，则转向第 7 章的无模型深度强化学习。从经典规划到概率规划再到深度强化学习，核心演进逻辑是**不确定性建模能力逐步增强、计算复杂度显著上升**。

## 8.6 规划与强化学习的联系：基于模型的 RL

### 8.6.1 规划与学习的统一视角

**规划 (Planning)** 使用已知或学习到的环境模型 $M = (P, R)$，通过内部模拟或前向搜索推理动作，无需与真实环境交互；**学习 (Learning)** 则通过与真实环境交互收集经验 $(s_t, a_t, r_t, s_{t+1})$ 来直接改进值函数或策略，不构建显式模型。Sutton 与 Barto（2018）指出，规划与学习的本质都是**利用经验改进策略**，区别仅在于经验的来源：模型无关 (Model-Free) RL 只用真实经验，基于模型 (Model-Based) RL 则用模型生成模拟经验或直接前瞻推理。这一视角与认知科学中**系统一 (System 1)** 的快速直觉反应和**系统二 (System 2)** 的审慎模型推理相映照，说明规划与学习是一个连续光谱而非二分范畴。

### 8.6.2 Dyna：在模型中规划

**Dyna** 架构由 Sutton 于 1990 年提出，首次把规划与学习整合为闭环。**Dyna-Q** 交替执行三步：**直接强化学习**，执行动作、观察奖励与下一状态并用 Q-Learning 更新 $Q(s,a)$；**模型学习**，把 $(s,a,r,s')$ 存入表格模型或用于训练参数模型；**规划**，从模型中反复采样并做 $n$ 步 Q-Learning 式更新。

```text
初始化 Q(s,a), Model(s,a)
每个 episode:
    观察状态 S
    每步:
        A ← ε-贪心(Q(S,·))
        执行 A，观察 R, S'
        Q(S,A) ← Q(S,A) + α[R + γ·max_a Q(S',a) − Q(S,A)]   # 直接 RL
        Model(S,A) ← (R, S')                                   # 模型学习
        重复 n 次:                                             # 规划
            S ← 随机选一个曾观察状态; A ← 随机选曾执行动作
            R, S' ← Model(S,A)
            Q(S,A) ← Q(S,A) + α[R + γ·max_a Q(S',a) − Q(S,A)]
        S ← S'
```

规划步数 $n$ 需要权衡：$n=0$ 退化为标准无模型 Q-Learning；$n$ 较小时有有限加速且对模型误差不敏感；$n$ 很大时样本效率显著提升，但模型偏差会被累积放大并污染值函数，使策略偏离最优。Dyna-Q 的核心优势正在于用模型生成的模拟经验大幅扩充有效训练样本，从而提升**样本效率 (Sample Efficiency)**。

### 8.6.3 基于模型的强化学习框架

基于模型的 RL (Model-Based RL, MBRL) 由**模型学习 (Model Learning)** 与**模型使用 (Model Usage)** 两大支柱构成。

模型学习的目标是逼近真实动力学 $\hat{M} = (\hat{P}, \hat{R})$。在确定性环境中直接回归下一状态与奖励 $\hat{s}_{t+1} = f_\theta(s_t, a_t), \hat{r}_t = g_\phi(s_t, a_t)$；在随机环境中则预测下一状态的概率分布，通常用神经网络以监督学习最小化预测误差。**概率集成模型 (Probabilistic Ensemble Models, PETS)** 维护一组网络，每个输出一个概率分布，采样时随机选取网络预测，从而捕获**认知不确定性 (Epistemic Uncertainty)** 与**偶然不确定性 (Aleatoric Uncertainty)**。不确定性建模至关重要：当模型对某状态-动作预测不确定时，策略应谨慎行事，避免基于错误模型做出灾难性决策。模型学习有两个关键问题：**分布偏移 (Distribution Shift)** 使模型在训练分布外产生外推误差，可用迭代重训练、不确定性惩罚与保守规划缓解；**复合误差 (Compounding Error)** 使多步预测误差指数累积，可用多步损失训练、短视界规划与 MPC 重规划缓解。

模型使用有两种基本范式。**背景规划 (Background Planning)** 在后台持续用模型生成模拟数据改进值函数或策略（如 Dyna-Q），其优势是计算摊销、改进是全局性的，劣势是模型偏差会全局污染值函数；**决策时规划 (Decision-Time Planning)** 仅在需要决策时针对当前状态做有限深度前瞻搜索，每次从零开始规划，因此不存在全局累积偏差、对模型误差更鲁棒，代价是每次决策计算开销较大。

### 8.6.4 决策时规划方法

**模型预测控制 (Model Predictive Control, MPC)** 源于控制理论，采用**滚动时域优化 (Receding Horizon Control)**：从当前状态出发，在 $H$ 步时域内用模型求最优动作序列，只执行第一个动作，观察真实下一状态后重新规划。开环 MPC 规划完整序列而不依赖未来观测，计算简单但在随机环境中表现差；闭环 MPC 规划策略或在每次重规划时根据观测调整，天然具有部分闭环特性。**随机射击 (Random Shooting)** 是最简单的采样方法：随机生成 $K$ 条动作序列，用模型模拟并累加奖励，执行最优序列的首个动作，简单可并行但高维动作空间采样效率低。

**蒙特卡洛树搜索 (Monte Carlo Tree Search, MCTS)** 的基本原理见第 2 章 §2.5。在 RL 语境下，MCTS 的核心角色是在**学习到的模型**中执行树搜索，为当前状态生成改进的策略目标。AlphaGo 用 MCTS 在已知围棋规则中搜索并由神经网络提供先验与叶节点评估；AlphaZero 去除人工特征、完全通过自对弈学习；**MuZero** 则学习隐式动力学模型而无需显式重建状态，在隐空间中使用 MCTS 规划，把 MCTS 推广到 Atari 等视觉任务。MCTS 的规划质量高度依赖模型精度与评估函数质量。

**交叉熵方法 (Cross-Entropy Method, CEM)** 是适用于高维连续动作空间的采样优化方法：维护动作序列的高斯分布 $\mathcal{N}(\mu, \Sigma)$，采样 $K$ 条序列并用模型评估累积奖励，保留表现最好的精英样本重新拟合分布参数，迭代若干次后执行 $\mu$ 的首个动作。相比纯随机射击，CEM 通过迭代精炼搜索分布，在高维空间中效率远胜，已成为 MBRL 中最广泛使用的规划算法之一。

### 8.6.5 端到端可微规划

一个引人注目的新范式是把**规划过程本身变为可微计算图**，使梯度可以从任务目标反向传播通过规划步骤。**价值迭代网络 (Value Iteration Networks, VIN)** 观察到值迭代的每个迭代步本质上是卷积操作——展开贝尔曼方程可表示为状态空间上的 CNN 卷积加跨通道取最大，于是把可微的"值迭代模块"嵌入神经网络，输入奖励图、输出展开后的值函数，梯度回传使奖励图等参数可被学习。类似地，**可微规划网络**对策略迭代或 MCTS 展开进行可微化重写，MCTSnets 把 MCTS 的模拟过程嵌入端到端网络。可微规划让模型学习与规划使用紧密结合，但计算图通常很深且含固有循环，训练不稳定、内存消耗大，目前主要限于网格世界等小规模问题。

### 8.6.6 模型驱动与模型无关方法对比

| 维度 | 模型无关 (Model-Free) | 基于模型 (Model-Based) |
|:---|:---|:---|
| 数据来源 | 仅真实环境交互 | 真实交互 + 模型模拟 |
| 样本效率 | 低（需海量交互） | 高（模型放大经验） |
| 渐近性能 | 高（不受模型偏差限制） | 受模型偏差制约 |
| 建模需求 | 无需 | 需学习 $P(s' \mid s,a)$ 与 $R$ |
| 推理策略 | 缓存策略/值函数 (System 1) | 前向搜索与规划 (System 2) |
| 每步计算开销 | 低 | 高（模拟 + 搜索） |
| 泛化到新目标 | 差（需重训练） | 好（模型可复用） |
| 典型算法 | DQN、PPO、SAC | Dyna-Q、PETS、MPC、MuZero |

实践中最好的方法往往是融合：在模型中进行有限深度前向搜索以指导无模型策略学习（如 AlphaGo/MuZero），或用模型生成额外数据加速无模型算法收敛（Dyna 风格）。

前沿方向进一步巩固了这一融合趋势。**World Models** 用 VAE 学习紧凑的隐空间表示、用 MDN-RNN 建模动力学、用 CMA-ES 训练控制器，在视觉任务上展现出极高样本效率；**Dreamer 系列**在隐空间中用 Actor-Critic 通过"想象轨迹"学习策略，其中 DreamerV3 以固定超参数在 150 多个任务上一致地实现高性能；**MuZero** 证明规划的有效性不需要重建环境的完整状态，只需学习对预测未来奖励和价值有用的特征。此外，**大语言模型 (LLM) 作为规划器** 利用预训练中隐含的"内在世界模型"进行任务分解与步骤推理（如 SayCan、ReAct、Plan-and-Solve），但其世界模型不精确、不完整，容易产生幻觉式规划，需要外部验证器或环境反馈对正。若从规划视角理解 RLHF，第 7 章 §7.7 的奖励模型 $r_\phi(y|x)$ 相当于文本生成任务中简化的环境模型，PPO 则可视为在固定奖励模型中进行基于策略梯度的局部规划，从而把语言模型对齐问题纳入 MBRL 框架。

## 8.7 本章小结

**核心要点回顾**

| 主题 | 要点 |
|:---|:---|
| **经典规划** | 用要素化状态、前提/添加/删除动作建模；封闭世界假设与"只指定变化"隐式处理框架问题；命题 STRIPS 判定问题为 PSPACE 完全 |
| **规划算法** | 前向搜索直观但分支大，后向搜索由目标回归驱动分支小；删除松弛衍生 $h^{\text{add}}$、$h^{\text{max}}$、$h^{\text{FF}}$ 与地标启发式；POP 用因果链接与最小承诺处理并行与子目标交互 |
| **图规划** | 命题层与动作层交替，no-op 实现框架公理；不一致效果、干扰、竞争需求与不一致支持定义互斥；对经典规划完备且步骤最优；Blackbox 化为 SAT、FF 用放松规划图做启发式 |
| **层次任务网络** | 用方法把复合任务递归分解为原语任务；OTD 以全序换高效，SHOP2、SIPE-2 为代表；无约束 HTN 图灵完备，代价是知识工程瓶颈 |
| **非确定性与概率规划** | FOND 区强弱与强循环规划，解为策略；MDP 用值迭代/策略迭代求最优；POMDP 维护信念状态并用 PBVI、SARSOP、POMCP、DESPOT 近似求解 |
| **规划与 RL** | 规划用已知模型推理、学习从经验改进；Dyna 用模拟经验规划；MBRL 分背景规划与决策时规划；MPC、MCTS、CEM、可微规划与 MuZero 体现规划–学习的深度融合 |
