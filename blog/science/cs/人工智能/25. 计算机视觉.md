# 第 25 章 计算机视觉（Computer Vision）

**本章导读**：视觉的目标是"从二维像素恢复三维世界"。这条逆问题链条很长：光 → 成像 → 特征 → 语义 → 三维结构与运动。本章按此链路组织：图像如何形成（25.2）、传统特征（25.3）、深度分类（25.4）、检测与分割（25.5）、三维视觉（25.6）、应用与边界（25.7）。它和第 21 章的分工是：第 21 章讲"网络怎么训"，本章讲"视觉问题怎么建模"。

**学习目标**：完成本章学习后，你应当能够：

- 用针孔模型描述成像几何，解释焦距、主点与透视投影；
- 说明滤波、边缘、角点、SIFT/HOG 的原理与不变性；
- 比较 CNN 与 ViT 在分类任务上的归纳偏置与数据需求；
- 区分两阶段与单阶段检测器，说明 IoU/NMS/mAP 的含义；
- 区分语义、实例、全景分割，说明 Mask R-CNN 的结构；
- 用立体视觉、SfM、深度估计与 NeRF 描述三维重建路线；
- 判断视觉系统在分布外、对抗与长尾场景下的失效模式。

**预备知识**：第 21 章的 CNN 与训练；线性代数（矩阵变换、SVD）；基本的信号处理（卷积、傅里叶变换）。

---

## 25.1 引言

**视觉任务的层次**：

| 层次 | 任务 | 输出 |
| --- | --- | --- |
| 低层 | 去噪、增强、超分 | 图像 |
| 中层 | 边缘、角点、光流、特征匹配 | 几何/运动 |
| 高层 | 分类、检测、分割、跟踪 | 语义 |
| 三维 | 深度、重建、位姿、SLAM | 结构与相机 |
| 生成 | 图像/视频生成、编辑 | 新图像 |

**核心困难**：

- **逆问题病态**：同一张图可能对应多个三维场景（遮挡、光照、反照率）；
- **语义鸿沟**：像素值到"猫"的概念没有解析映射；
- **组合爆炸**：物体、姿态、光照、遮挡的组合近乎无限；
- **分布偏移**：新场景、新相机、新天气。

## 25.2 图像形成

**针孔相机模型**：

$$\begin{bmatrix} u \\ v \\ 1 \end{bmatrix} \sim K\,[R \mid t] \begin{bmatrix} X \\ Y \\ Z \\ 1 \end{bmatrix},\qquad K = \begin{bmatrix} f_x & s & c_x \\ 0 & f_y & c_y \\ 0 & 0 & 1 \end{bmatrix}$$

- $K$：内参（焦距、主点、倾斜）；
- $[R \mid t]$：外参（相机位姿）；
- 透视除法：$u = f_x X/Z + c_x$，$v = f_y Y/Z + c_y$。

**关键现象**：

- **透视缩短**：远处物体小；
- **遮挡**：近物挡住远物；
- **径向畸变**：广角镜头的桶形/枕形畸变，需标定校正。

**颜色**：RGB 是设备相关的加色模型；HSV 分离色调与亮度；**颜色恒常性**（color constancy）是难题——同一物体在不同光源下像素值差异巨大。

**光照模型**：Lambertian 反射 $I = \rho \max(0, n^\top l)$；镜面反射、环境光需要更复杂模型。**本征分解**（intrinsic decomposition）试图分离反照率与光照，是病态问题。

## 25.3 简单图像特征

**滤波（卷积）**：

| 滤波器 | 作用 |
| --- | --- |
| 均值/高斯 | 去噪、平滑 |
| 中值 | 去除椒盐噪声 |
| Sobel/Prewitt | 一阶梯度（边缘） |
| Laplacian | 二阶导数（斑点、锐化） |
| 双边滤波 | 保边平滑 |

**边缘检测**：Canny 的四步——高斯平滑 → 梯度计算 → 非极大值抑制 → 双阈值滞后连接。**尺度空间**用高斯金字塔，**DoG** 近似 LoG 用于斑点检测。

**角点检测（Harris）**：结构张量

$$M = \sum_{x,y} w(x,y)\begin{bmatrix} I_x^2 & I_xI_y \\ I_xI_y & I_y^2 \end{bmatrix}$$

两个特征值都大 → 角点；一大一小 → 边缘；都小 → 平坦。Harris 对旋转不变，对尺度不不变。

**SIFT（尺度不变特征变换）** 的四步：

1. **尺度空间极值检测**：DoG 金字塔找关键点；
2. **关键点定位**：去除低对比度与边缘响应点；
3. **方向分配**：用梯度直方图赋予主方向（旋转不变）；
4. **描述子**：$4\times4$ 子区域 × 8 方向 = 128 维，归一化（光照鲁棒）。

**HOG（方向梯度直方图）**：把图像分成 cell，统计梯度方向直方图，块内归一化。配合 SVM 曾是行人检测的标准（Dalal–Triggs）。

**特征匹配**：最近邻 + 比值检验（Lowe's ratio test）+ RANSAC 估计几何变换（单应、基础矩阵）。

**为什么深度学习取代了手工特征**：手工特征需要设计者对"什么是不变特征"有先验；CNN 从数据中学到分层特征，且在大数据下显著更优。但 SIFT/SURF 在**小样本、可解释、几何验证**场景仍有用（如三维重建的初始匹配）。

## 25.4 图像分类

**任务**：给定图像，输出类别。评估：Top-1/Top-5 准确率、混淆矩阵、每类 F1。

**CNN 的归纳偏置**：局部性、平移等变、层次化。适合数据量中等、纹理/局部模式主导的任务。

**ViT（Vision Transformer）**：把图像切成 $16\times16$ patch，线性投影为 token，加位置编码后送入 Transformer。

| 对比 | CNN | ViT |
| --- | --- | --- |
| 归纳偏置 | 强（局部、平移） | 弱（需从数据学） |
| 小数据 | 表现好 | 易过拟合 |
| 大数据 | 有上限 | 更好扩展 |
| 计算 | 卷积高效 | 全局注意 $O(n^2)$ |

**混合方案**：ConvNeXt（用卷积模拟 Transformer 设计）、Swin（窗口注意力 + 层次结构）、DeiT（蒸馏训练 ViT）。

**训练技巧**：

- **数据增强**：随机裁剪、翻转、颜色抖动、MixUp/CutMix、RandAugment；
- **正则**：标签平滑、Dropout、Stochastic Depth、权重衰减；
- **迁移**：ImageNet/CLIP 预训练 + 微调；
- **自监督**：SimCLR、MoCo、MAE、DINO——减少对标注的依赖。

**长尾与偏见**：类别不平衡导致尾部类性能差；数据中的性别/肤色偏差会被放大。对策：重采样、logit 调整、鲁棒损失、审计数据集。

**校准与不确定度**：现代网络常**过度自信**（ECE 高）；用温度缩放、深度集成、MC Dropout 改善。

## 25.5 目标检测

**任务**：定位（框）+ 分类。**评估**：

- **IoU**：预测框与真值框的交并比；
- **mAP**：各类 AP 的平均，AP 是 PR 曲线下面积；COCO 用 IoU 0.5:0.95 的平均。

**（1）两阶段检测器**：

- **R-CNN**：选择性搜索候选框 → CNN 特征 → SVM 分类（慢）；
- **Fast R-CNN**：整图卷积 + RoI Pooling（共享计算）；
- **Faster R-CNN**：**RPN（区域提议网络）** 端到端生成候选，锚框（anchor）+ 回归。

**（2）单阶段检测器**：

| 模型 | 关键思想 |
| --- | --- |
| YOLO | 把检测变成回归，网格预测，速度快 |
| SSD | 多尺度特征图 + 默认框 |
| RetinaNet | Focal Loss 解决正负样本极不平衡 |
| YOLOv5–v8 | 工程优化（数据增强、解耦头、锚框自适应） |
| DETR | 用 Transformer + 匈牙利匹配，**无需 NMS** |

**（3）后处理**：**NMS（非极大值抑制）** 去除重叠框；Soft-NMS、可学习 NMS（DETR 免去此步）。

**（4）分割**：

| 类型 | 输出 | 代表 |
| --- | --- | --- |
| 语义分割 | 每像素类别 | FCN、U-Net、DeepLab（空洞卷积 + ASPP） |
| 实例分割 | 每个物体的掩码 | Mask R-CNN（RoIAlign + mask 分支）、YOLACT |
| 全景分割 | 语义 + 实例统一 | Panoptic FPN、Mask2Former |
| 通用分割 | 提示驱动 | SAM（Segment Anything） |

**（5）跟踪与视频理解**：

- **多目标跟踪**：检测 + 数据关联（SORT/DeepSORT、ByteTrack），本质是 §15.3 的多目标滤波；
- **光流**：Lucas–Kanade（局部）、FlowNet/RAFT（学习型）；
- **视频理解**：动作识别（3D CNN、TimeSformer）、时序动作定位、视频问答。

**开放词汇检测**：GLIP、Grounding DINO 用文本提示检测任意类别；CLIP 提供图文对齐的零样本能力。

## 25.6 三维世界

**（1）立体视觉（stereo）**。两个相机水平放置，视差 $d = x_L - x_R$ 与深度成反比：

$$Z = \frac{f\, B}{d}$$

其中 $B$ 是基线。难点是**对应点匹配**（纹理缺失、重复纹理、遮挡）。

**（2）运动恢复结构（SfM）**：从多视图恢复相机位姿与三维点。

流程：特征提取匹配 → 本质矩阵/基础矩阵估计 → 三角化 → 光束法平差（bundle adjustment）：

$$\min_{\{R_i,t_i\},\{X_j\}} \sum_{i,j} \big\| \pi(K_i, R_i, t_i, X_j) - x_{ij} \big\|^2$$

**（3）深度估计**：

| 方法 | 说明 |
| --- | --- |
| 双目/多目 | 几何三角化 |
| 结构光/ToF | 主动投射，精度高、距离短 |
| 单目深度 | 学习先验（MiDaS、Depth Anything），尺度不确定 |
| 激光雷达 | 直接测距，稀疏但精确 |

**（4）神经辐射场（NeRF）**：用 MLP 表示 $F(x, d) \to (\sigma, c)$，沿射线积分渲染：

$$C(r) = \int_{t_n}^{t_f} T(t)\,\sigma(t)\,c(t)\,dt,\qquad T(t) = \exp\Big(-\int_{t_n}^{t}\sigma(s)ds\Big)$$

优点是**新视角合成**质量极高；缺点是训练/渲染慢（后续 3DGS 用高斯点云大幅加速）。

**（5）SLAM 与位姿估计**：

- **视觉里程计**：帧间位姿（特征法或直接法）；
- **回环检测**：识别"来过这里"，消除累积漂移；
- **地图**：稀疏点云、稠密地图、语义地图；
- **现代系统**：ORB-SLAM、LIO-SAM（激光 + IMU）、视觉惯性里程计（VIO）。

**（6）三维表示谱系**：

| 表示 | 优点 | 缺点 |
| --- | --- | --- |
| 点云 | 直接、稀疏 | 无拓扑、渲染难 |
| 体素 | 规则、易卷积 | 分辨率爆炸 |
| 网格 | 渲染高效、工业标准 | 拓扑变化难 |
| 隐式（SDF/NeRF） | 连续、细节好 | 推理慢、编辑难 |
| 高斯点云（3DGS） | 渲染快、质量高 | 存储大、动态场景难 |

## 25.7 计算机视觉的应用

| 领域 | 任务 | 关键约束 |
| --- | --- | --- |
| 自动驾驶 | 检测、车道线、可行驶区域、深度 | 实时、安全、恶劣天气 |
| 医疗影像 | 分割、病灶检测、配准 | 小样本、可解释、法规 |
| 工业质检 | 缺陷检测、定位 | 高精度、少样本、节拍 |
| 遥感 | 地物分类、变化检测 | 多光谱、大尺度、标注稀缺 |
| 安防与零售 | 人脸、行为、客流 | 隐私、公平性、误报成本 |
| AR/VR | 位姿跟踪、三维重建、渲染 | 低延迟、功耗 |
| 内容创作 | 生成、编辑、风格化 | 版权、真实性、可控性 |

**生成式视觉**：GAN → 扩散模型（Stable Diffusion、DALL·E、Sora）→ 视频生成。可控性靠 **ControlNet**（结构条件）、**LoRA**（风格）、**inpainting**（局部编辑）。

**失效模式与测试**：

| 失效 | 例子 | 缓解 |
| --- | --- | --- |
| 分布外 | 雪天、夜间、罕见视角 | 域随机化、更多数据、OOD 检测 |
| 对抗样本 | 贴纸让检测器"看不见" | 对抗训练、输入净化、集成 |
| 长尾 | 罕见类别的低召回 | 重采样、开放词表、少样本学习 |
| 偏见 | 人脸识别对不同人群误差差异 | 分层评估、数据平衡、审计 |
| 幻觉 | 生成不存在的物体 | 一致性校验、人工审核 |

**工程建议**：

1. 先定义**错误的代价**（漏检 vs 误检），再选指标与阈值；
2. 用**私有场景数据**做测试，公开基准只作参考；
3. 把**不确定度**暴露给下游（拒识、人工复核）；
4. 对安全关键场景，视觉只是**一个传感器**，必须多模态冗余。

## 本章小结

**核心要点**

1. 成像是**透视投影**：内参 + 外参决定像素与三维点的映射；视觉是病态逆问题。
2. 传统特征（Canny、Harris、SIFT、HOG）以**不变性**为核心设计；深度特征以**数据驱动**取代手工设计。
3. **CNN 与 ViT** 的差别是归纳偏置与数据需求的权衡；混合架构与自监督预训练是当前主流。
4. 检测分**两阶段（精度）与单阶段（速度）**；IoU、NMS、mAP 是通用语言；DETR 用集合预测去掉 NMS。
5. 分割从**语义 → 实例 → 全景 → 提示驱动（SAM）** 逐步细化。
6. 三维视觉有四条主线：**立体/SfM（几何）、深度传感器、NeRF/3DGS（表示）、SLAM（在线定位建图）**。
7. 视觉系统的风险集中在**分布外、对抗、长尾与偏见**；安全关键场景需要多传感器冗余与不确定度输出。
