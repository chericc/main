# 第 23 章 自然语言处理（Natural Language Processing）

**本章导读**：语言是离散、歧义、长程依赖的符号系统，这三点决定了 NLP 的方法论。本章按"统计 → 语法 → 语义"的顺序铺开：用 n-gram 与平滑刻画语言模型（23.1）、用上下文无关文法刻画句法（23.2）、用 CKY/图表/依存方法做句法分析（23.3）、用特征结构与组合语义把句法映射到意义（23.4），最后是两大经典应用：统计机器翻译（23.5）与语音识别（23.6）。深度学习方法见第 24 章。

**学习目标**：完成本章学习后，你应当能够：

- 计算 n-gram 概率、困惑度，并用加法/Kneser–Ney 平滑处理零频；
- 写出 CFG 四元组，判定句子的语法歧义与解析树；
- 用 CKY 算法做自底向上句法分析，说明其复杂度；
- 用特征结构与合一实现一致性问题，解释组合语义的 λ 演算表示；
- 说明统计机器翻译的词对齐、短语模型与解码；
- 画出语音识别流程，说明声学模型、发音词典与语言模型的分工。

**预备知识**：概率与条件概率（第 12 章）；动态规划（第 3、9 章）；形式语言与自动机基础（文法、推导）。

## 23.1 语言模型

**语言模型（LM）** 给出词序列的概率 $P(w_1, \dots, w_n)$，用于语音识别、翻译、拼写纠错与生成。

**链式法则**：

$$P(w_1,\dots,w_n) = \prod_{t=1}^{n} P(w_t \mid w_1,\dots,w_{t-1})$$

**n-gram 近似（马尔可夫假设）**：

$$P(w_t \mid w_{<t}) \approx P(w_t \mid w_{t-n+1:t-1})$$

| 模型 | 近似 | 参数量 |
| --- | --- | --- |
| unigram | $P(w_t)$ | $\lvert V\rvert$ |
| bigram | $P(w_t \mid w_{t-1})$ | $\lvert V\rvert^2$ |
| trigram | $P(w_t \mid w_{t-2},w_{t-1})$ | $\lvert V\rvert^3$ |

**最大似然估计**（相对频率）：

$$P(w_t \mid w_{t-1}) = \frac{c(w_{t-1}, w_t)}{c(w_{t-1})}$$

**零频问题与平滑**：

| 方法 | 思路 |
| --- | --- |
| 加一（Laplace） | 所有计数 $+1$，简单但粗糙 |
| 加 $k$ / Lidstone | 计数 $+k$，$k<1$ 更好 |
| 回退（backoff） | 高阶为 0 时退到低阶 |
| 插值 | $P = \lambda P_\text{high} + (1-\lambda)P_\text{low}$ |
| **Kneser–Ney** | 按"接续计数"折扣，现代 n-gram 的标配 |
| Stupid backoff | 不归一化但大规模可用 |

**评估**：**困惑度（perplexity）** 是平均每词的逆概率几何平均：

$$\text{PPL} = \exp\Big(-\frac{1}{N}\sum_{i=1}^{N}\log P(w_i \mid \text{context})\Big) = 2^{H}$$

困惑度越低越好，可理解为"平均在多少个词之间犹豫"。注意：**不同词表的 PPL 不可比**。

**n-gram 的局限**：

- 数据稀疏：长上下文几乎必然零频；
- 无法捕捉长程依赖与语义相似性；
- 词表固定，未登录词（OOV）需 `<unk>`。

这些局限由神经语言模型解决（§24.6）：用**分布式表示**泛化到未见组合。

## 23.2 语法

**为什么需要语法**：语言模型的局部窗口看不到"主谓一致""嵌套结构"，而语法提供了**组合的骨架**。

**上下文无关文法（CFG）** 四元组 $G = (N, \Sigma, R, S)$：

- $N$：非终结符（NP、VP、S…）；
- $\Sigma$：终结符（词）；
- $R$：产生式 $A \to \beta$；
- $S$：起始符号。

```
S  → NP VP
NP → Det N | NP PP | "John"
VP → V NP | VP PP
PP → P NP
Det → "the" | "a"
N  → "man" | "telescope"
V  → "saw"
P  → "with"
```

**歧义（ambiguity）** 是自然语言的常态：

| 类型 | 例子 | 说明 |
| --- | --- | --- |
| 词性歧义 | "book" 名词/动词 | 词法层 |
| 结构歧义 | "saw the man with the telescope" | PP 附着位置 |
| 语义歧义 | "Everyone loves someone" | 量词辖域 |
| 指代歧义 | "他打了他的球" | 代词消解 |

**歧义的数量级**：一个 20 词句子的可能解析树可达数百万（Catalan 数增长），因此**必须有概率**来排序。

**概率上下文无关文法（PCFG）**：给每个产生式加概率 $P(A \to \beta \mid A)$，

$$P(T) = \prod_{(A\to\beta) \in T} P(A \to \beta \mid A)$$

最佳解析即 $\arg\max_T P(T \mid S)$。PCFG 的独立性假设过强（子树的概率与上下文无关），但有高效的动态规划算法。

**语法形式族谱**：

| 形式 | 表达力 | 典型用途 |
| --- | --- | --- |
| 正则文法 | 有限状态 | 词形、简单模式 |
| CFG | 嵌套结构 | 句法分析 |
| 特征结构文法 | CFG + 一致约束 | 主谓一致、格 |
| 树邻接文法（TAG） | 略强于 CFG | 长距离依赖 |
| 依存文法 | 词间关系 | 依存分析、跨语言 |

**乔姆斯基层级**与**弱/强生成能力**：CFG 能生成大多数自然语言句法，但难以自然表达"跨序列依赖"（如荷兰语的交叉依存），需要 TAG 或轻上下文敏感机制。

## 23.3 句法分析

**句法分析（parsing）** 的目标：给定文法与句子，找出所有合法解析树（或最优树）。

**（1）CKY 算法**（Cocke–Kasami–Younger）。要求文法为**乔姆斯基范式（CNF）**：$A \to BC$ 或 $A \to a$。

用 $P[i,j,A]$ 表示"从 $i$ 到 $j$ 的子串能否由 $A$ 推出"，递推：

$$P[i,j,A] = \max_{B,C,k} P(A \to BC)\cdot P[i,k,B]\cdot P[k,j,C]$$

- 复杂度 $O(n^3 |N|^3)$（朴素实现 $O(n^3|R|)$）；
- 优点：简单、可求最优与全部解析；
- 缺点：需先转 CNF（可能增大文法）、对左递归不友好。

**（2）图表分析（chart parsing）与 Earley 算法**。用"点规则（dotted rule）"记录"已匹配到产生式的哪个位置"，边（edge）存在图表中。Earley 是**自顶向下 + 动态规划**，复杂度：

| 文法 | 复杂度 |
| --- | --- |
| 一般 CFG | $O(n^3)$ |
| 无歧义 CFG | $O(n^2)$ |
| 确定性/正则 | $O(n)$ |

**（3）自底向上 vs 自顶向下**：前者从词出发组合（CKY），后者从 S 出发预测（Earley、递归下降）。**Chart parsing** 用统一数据结构避免重复计算。

**（4）依存分析（dependency parsing）**。不构造短语结构，而是给每个词指定**中心词（head）** 与**依存关系标签**：

```
saw(ROOT) ──nsubj──> John
          ──obj────> man
          ──det────> the
          ──obl────> with ──case──> telescope
```

方法：

- **基于转移（transition-based）**：用栈与缓冲区做 shift/reduce，分类器预测动作，线性时间；
- **基于图（graph-based）**：为每个可能的边打分，求最大生成树（Eisner 算法）。

依存分析对**跨语言、长距离依赖**更友好，是 Universal Dependencies 项目的标准表示。

**（5）神经句法分析**：用 BiLSTM/Transformer 编码上下文，再做转移或图打分，准确率大幅超过 PCFG。但**结构化输出**仍需句法约束（如树的合法性）。

**解析的评估**：**标记准确率（labeled precision/recall）** 与 **F1**；依存分析用 **UAS/LAS**（无标签/有标签依存正确率）。

## 23.4 扩展语法与语义解释

**（1）特征结构与合一（unification）**。CFG 无法保证主谓一致：

```
*John see Mary     （应为 sees）
```

**特征结构**用属性-值矩阵表示：

```text
[ CAT: S
  SUBJ: [ CAT: NP, AGR: [ NUM: sg, PERS: 3 ] ]
  VP:   [ CAT: VP, AGR: [ NUM: sg, PERS: 3 ] ] ]
```

**合一**是合并两个特征结构：属性相同则递归合一，冲突则失败。它把"语法约束"变成**可计算的等式求解**，与第 9 章的一阶合一同源。

**（2）组合语义**。句法树如何映射到意义？**蒙塔古语法**用 λ 演算做**组合**：

- 每个词对应一个 λ 项；
- 组合规则（函数应用）把子树的语义组合起来。

例：

| 成分 | 语义（λ 项） |
| --- | --- |
| John | $\text{john}$ |
| loves | $\lambda y.\lambda x.\ \text{loves}(x,y)$ |
| loves Mary | $\lambda x.\ \text{loves}(x, \text{mary})$ |
| John loves Mary | $\text{loves}(\text{john}, \text{mary})$ |

**类型驱动的组合**：$VP$ 需要 $NP$ 的参数，函数应用消去类型。这解释了"为什么语序影响意义"。

**（3）语义角色标注（SRL）**。给定谓词，标出各论元角色：Agent、Patient、Instrument、Location 等。

```
[Agent John] [Predicate broke] [Patient the window] [Instrument with a hammer]
```

方法：序列标注（BIO 标签）、span 分类、或作为**语义依存**的一部分。SRL 是"浅层语义"的实用折中，比完整逻辑形式更易标注。

**（4）语义解析（semantic parsing）**。把句子映射到可执行的逻辑形式（SQL、SPARQL、程序）：

```
"销售额最高的三个产品" → SELECT name FROM ... ORDER BY sales DESC LIMIT 3
```

方法：**组合式**（语法驱动，需词典）、**序列到序列**（§24.3）、**约束解码**（保证输出合法）。现代 Text-to-SQL 主要用 Seq2Seq + 模式链接。

**（5）语用与指代**。超越句子层面的意义：**指代消解**（coreference）、**预设**（presupposition）、**言语行为**（speech act）。这些仍是开放问题，大模型在指代与常识推理上仍不可靠（§27.1）。

## 23.5 机器翻译

**任务**：给定源语言句子 $f$，求目标语言 $g$。

**噪声信道模型**（统计 MT 的经典框架）：

$$\hat g = \arg\max_g P(g \mid f) = \arg\max_g \underbrace{P(f \mid g)}_{\text{翻译模型}} \underbrace{P(g)}_{\text{语言模型}}$$

**（1）词对齐与 IBM 模型**。需要从**平行语料**学词级对应，但语料只给句子对（**隐变量**）。IBM 模型 1–5 用 EM 迭代：

- E 步：按当前参数算每个词对的期望对齐数；
- M 步：用期望计数更新翻译概率。

IBM 模型 1 有闭式解（期望只依赖长度），后续模型加入词序（失真，distortion）与繁衍（fertility）。

**（2）短语-based SMT**。把词对齐扩展为**短语对**，解码时做"短语拼接 + 语言模型打分 + 失真惩罚"：

$$\hat g = \arg\max_g \sum_i \phi(\bar f_i, \bar g_i) + \lambda_\text{LM}\log P_\text{LM}(g) + \lambda_d \cdot d(g)$$

解码是 NP 难的，用**柱搜索（beam search）** 近似。

**（3）神经机器翻译（NMT）**（2014–）：

- **编码器-解码器**：RNN/Transformer 把源句编码为向量序列，解码器自回归生成；
- **注意力**：解码每步关注源句的不同位置（§24.4）；
- **训练**：最大似然（teacher forcing）；**推理**：beam search；
- **评估**：BLEU（n-gram 精确率 + 长度惩罚）、chrF、COMET（学习型指标）、人工评估。

**BLEU 的局限**：只衡量表面重叠，对语序变化与同义改写不敏感；高分不代表可读。现代评估倾向 COMET 与人工评估并用。

**（4）低资源与多语言**：

| 场景 | 方法 |
| --- | --- |
| 低资源语言对 | 回译（back-translation）、跨语言迁移、多语言预训练 |
| 零资源 | 无监督 MT（同空间对齐 + 去噪自编码） |
| 领域适配 | 领域微调、术语约束解码 |
| 文档级 | 上下文感知（拼接、缓存、文档级注意力） |

**（5）NMT 的失败模式**：漏译、重复、数字/实体错误、长句结构崩塌、幻觉（尤其在多模态与低资源场景）。对策：约束解码、术语词典、质量估计（QE）、人工译后编辑。

## 23.6 语音识别

**任务**：把声波 $O$ 转成词序列 $W$。经典框架是**噪声信道**：

$$\hat W = \arg\max_W P(O \mid W)\, P(W)$$

- $P(O \mid W)$：**声学模型**；
- $P(W)$：**语言模型**（§23.1）。

**传统流水线**：

```
波形 → 分帧 → 特征（MFCC/梅尔谱）→ 声学模型（HMM-GMM/DNN）→ 解码（词典 + LM）→ 文本
```

**（1）特征提取**：

- **分帧**：25 ms 窗、10 ms 帧移；
- **MFCC**：预加重 → 分帧 → 加窗 → FFT → 梅尔滤波器组 → 取对数 → DCT；
- **梅尔谱**：省去 DCT，保留更多信息，是现代神经 ASR 的常用输入。

**（2）HMM-GMM 时代**。每个音素建模为从左到右的 HMM（3–5 个状态），观测概率用 GMM。解码用 **Viterbi** 在"词典 + 语言模型"构成的搜索图上找最优路径。**三音素（triphone）** 与 **决策树绑定** 处理协同发音。

**（3）CTC（connectionist temporal classification）**。允许神经网络直接输出字符序列，引入 **blank** 符号处理"输入帧多于输出标签"的对齐问题：

$$P(Y \mid X) = \sum_{\pi \in \mathcal{B}^{-1}(Y)} \prod_t P(\pi_t \mid X)$$

其中 $\mathcal{B}$ 是"去重 + 去 blank"的映射。CTC 用动态规划（前向-后向）高效求和，可端到端训练。缺点是**条件独立假设**（各帧输出独立）与难以建模语言上下文。

**（4）注意力编码器-解码器（LAS）**。用注意力替代 CTC，能建模输出间的依赖，但需要完整输入（非流式），且可能"跳字/重复"。

**（5）混合与前沿**：

| 方法 | 特点 |
| --- | --- |
| RNN-T | 流式、联合建模声学与语言，工业部署广 |
| Conformer | 卷积 + Transformer，兼顾局部与全局 |
| Whisper | 大规模弱监督多语言模型，鲁棒性强 |
| 自监督预训练 | wav2vec 2.0、HuBERT：用未标注语音学表示 |

**（6）评估**：**词错误率（WER）** $= (S + D + I)/N$（替换 + 删除 + 插入）。

**（7）难点**：口音与方言、噪声与远场、说话人重叠（鸡尾酒会问题）、代码切换、专有名词。工程上常做**语言模型重打分**、**热词注入**与**领域自适应**。

## 本章小结

**核心要点**

1. **n-gram 语言模型**用马尔可夫近似 + 平滑处理稀疏；**困惑度**是标准评估，但跨词表不可比。
2. **CFG** 提供句法骨架，**歧义**是常态，需 PCFG 或神经模型排序。
3. **CKY** 用动态规划做自底向上分析（$O(n^3)$）；**Earley** 与图表分析更通用；**依存分析**以词间关系表示结构。
4. **特征结构与合一**处理一致性约束；**组合语义**用 λ 演算把句法映射为意义；SRL 与语义解析是浅层/深层语义的两端。
5. 统计 MT 用**噪声信道 + 词对齐（EM）+ 短语解码**；NMT 用编码器-解码器 + 注意力，BLEU 是常用但粗糙的指标。
6. 语音识别是"声学模型 + 语言模型 + 解码"；**CTC** 解决对齐问题，**RNN-T/Conformer/Whisper** 是当前主流。
