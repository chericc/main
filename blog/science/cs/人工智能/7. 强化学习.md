# 第 7 章 强化学习

## 7.1 马尔可夫决策过程：状态、动作、奖励与值函数

强化学习要解决的问题是**序贯决策（sequential decision making）**：智能体（agent）与环境（environment）在离散时间步上反复交互，在每个时刻观察状态、选择动作，环境则返回即时奖励并转移到新状态。与监督学习"给定输入预测标签"的一次性映射不同，序贯决策中**当前动作会影响未来的状态与收益**，因此最优选择不能只看眼前。**马尔可夫决策过程（Markov Decision Process, MDP）**正是刻画这类问题的标准数学框架，它在**不确定性（uncertainty）**下为决策提供了统一的语言。

一个 MDP 由五元组 `(S, A, P, R, γ)` 完全确定，各要素的含义如下表。

| 符号 | 名称 | 说明 |
|:---|:---|:---|
| **S** | **状态空间 (State Space)** | 所有可能状态的集合，可以是有限集 `{s₁, …, sₙ}`，也可以是连续或无限空间 |
| **A** | **动作空间 (Action Space)** | 所有可能动作的集合，同样可为有限或无限 |
| **P** | **转移概率 (Transition Probability)** | `P(s'\|s,a)` 表示在状态 `s` 执行动作 `a` 后转移到 `s'` 的概率 |
| **R** | **奖励函数 (Reward Function)** | `R(s,a,s')` 表示该转移带来的**即时奖励 (Immediate Reward)**，也可简记为 `R(s,a)` 或 `R(s)` |
| **γ** | **折扣因子 (Discount Factor)** | `γ ∈ [0,1]`，平衡即时奖励与未来奖励；无限时域下 `γ < 1` 保证累积回报收敛 |

五元组中最深刻的假设是**马尔可夫性（Markov Property）**：给定现在，未来与过去条件独立，即下一状态只取决于当前状态与动作，而与更早的历史无关，形式化为 `P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, …)`。这一性质把复杂的长期依赖压缩为"当前状态已包含全部相关信息"，使值函数可以递归定义、策略可以用动态规划求解；若环境不满足马尔可夫性，则需要把历史观测也纳入状态，或用循环网络等记忆结构来近似。

一次完整的交互过程称为一个**回合 (Episode)**，其轨迹（trajectory）写作 `τ = (s₀, a₀, r₁, s₁, a₁, r₂, …)`，到达**终止状态 (Terminal State)** 或有限时域结束时终止。从时刻 `t` 起可获得的**回报 (Return)** 定义为折扣累积奖励 `G_t = r_{t+1} + γ·r_{t+2} + γ²·r_{t+3} + … = Σ_{k=0}^{∞} γ^k · r_{t+k+1}`。折扣因子 `γ` 的取值直接塑造智能体的"性格"：`γ = 0` 时它只关心即时奖励，表现短视（myopic）；`γ → 1` 时未来奖励几乎与即时奖励同等重要，适合长期规划；一般 `0 < γ < 1` 则在两者之间折中，同时保证无限时域下回报级数收敛。

智能体的行为方式由**策略 (Policy) π** 描述，它是从状态到动作（或动作分布）的映射。若给定状态直接输出一个动作，称为**确定性策略 (Deterministic Policy)** `π(s) = a`；若输出每个动作被选中的概率，则称为**随机策略 (Stochastic Policy)** `π(a|s)`。随机策略既是处理部分可观测环境的必要手段，也是策略梯度方法天然的表达形式。

衡量策略好坏的工具是**值函数 (Value Function)**，它分为状态值函数与动作值函数两种，分别回答"这个状态有多好"与"在这个状态做这个动作有多好"。

| 值函数 | 定义 | 含义 |
|:---|:---|:---|
| **状态值函数 `V^π(s)`** | `V^π(s) = E_π[G_t \| S_t = s]` | 从 `s` 出发后一直遵循策略 `π` 所能获得的**期望回报 (Expected Return)** |
| **动作值函数 `Q^π(s,a)`** | `Q^π(s,a) = E_π[G_t \| S_t = s, A_t = a]` | 从 `s` 出发先执行动作 `a`、之后遵循 `π` 所能获得的期望回报 |

值函数之间满足**贝尔曼方程（Bellman Equation）**，它把当前值拆解为"即时奖励的期望"加上"折扣后下一状态值的期望"，从而建立起递归关系：

`V^π(s) = Σ_a π(a|s) · Σ_{s'} P(s'|s,a) · [ R(s,a,s') + γ · V^π(s') ]`

`Q^π(s,a) = Σ_{s'} P(s'|s,a) · [ R(s,a,s') + γ · Σ_{a'} π(a'|s') · Q^π(s',a') ]`

这一"用自身的估计来更新自身"的做法称为**自举（Bootstrapping）**，它构成了动态规划与几乎所有时序差分方法的基础。

最优策略对应**最优值函数** `V*(s) = max_π V^π(s)` 与 `Q*(s,a) = max_π Q^π(s,a)`。将贝尔曼方程中的策略替换为取最大值，就得到**贝尔曼最优方程（Bellman Optimality Equation）**：

`V*(s) = max_a Σ_{s'} P(s'|s,a) · [ R(s,a,s') + γ · V*(s') ]`

`Q*(s,a) = Σ_{s'} P(s'|s,a) · [ R(s,a,s') + γ · max_{a'} Q*(s',a') ]`

这两个方程因含 `max` 而是非线性的，通常没有闭式解，必须迭代求解。一旦得到 `Q*`，**最优策略 (Optimal Policy)** 就退化为对 `Q*` 的**贪心选择** `π*(s) = argmax_a Q*(s,a)`；可以证明，任何 MDP 都至少存在一个确定性的最优策略。求解 MDP 的方法因此按模型是否已知分为两条路线：当 `P` 与 `R` 已知时，用**动态规划（Dynamic Programming）**在模型内部规划，见 §7.2；当 `P` 与 `R` 未知时，只能通过与环境的交互来学习，即真正的强化学习，见 §7.3 及之后。

一个贯穿全章的直观例子是**网格世界 (GridWorld)**。设想一个 4×4 的网格，智能体从起点出发，目标是抵达终止格：状态空间为 16 个格子，动作为 `{↑, ↓, ←, →}` 四个方向，转移是确定性的（撞墙则原地不动），每走一步得 `-1` 以鼓励尽快到达目标，抵达终止格分别获得 `+10` 与 `+1`，折扣因子取 `0.9`。这个简单模型足以演示后面 §7.2 的策略迭代与值迭代如何算出最优值函数 `V*(s)` 与最优策略 `π*(s)`。

## 7.2 动态规划：策略迭代与值迭代

**动态规划（Dynamic Programming, DP）**是求解 MDP 的经典方法，它要求**完整模型已知**，即转移概率 `P(s'|s,a)` 与奖励函数 `R(s,a,s')` 全部可得。DP 的核心是利用贝尔曼方程的结构，把全局最优问题分解为可由子问题递归求解的迭代过程，其两大主干是**策略迭代（Policy Iteration）**与**值迭代（Value Iteration）**。

**策略评估（Policy Evaluation）**，又称预测（Prediction），负责计算给定策略 `π` 的状态值函数 `V^π(s)`。它反复套用贝尔曼期望方程做迭代更新：

`V_{k+1}(s) = Σ_a π(a|s) · Σ_{s'} P(s'|s,a) · [ R(s,a,s') + γ · V_k(s') ]`

可以证明 `V_k → V^π`（当 `k → ∞`）。收敛性由**压缩映射（Contraction Mapping）**与 **Banach 不动点定理（Banach Fixed-Point Theorem）**保证：由于折扣因子 `γ < 1`，贝尔曼算子是压缩的，迭代必然收敛到唯一不动点。实践中不必等到无穷，只要相邻两次迭代的最大变化 `max_s |V_{k+1}(s) − V_k(s)|` 小于阈值 `θ` 即可停止。

有了 `V^π`，就可以进行**策略改进（Policy Improvement）**。先计算当前策略下的动作值函数 `Q^π(s,a) = Σ_{s'} P(s'|s,a) · [ R(s,a,s') + γ · V^π(s') ]`，再对每个状态做**贪心改进** `π'(s) = argmax_a Q^π(s,a)`。**策略改进定理（Policy Improvement Theorem）**指出 `V^{π'}(s) ≥ V^π(s)` 对所有状态成立；若处处取等号，则 `π` 与 `π'` 均为最优策略。

**策略迭代（Policy Iteration）**把上述两步交替进行：完整评估当前策略，再贪心改进，如此循环直到策略不再变化。由于每轮都严格提升（或保持不变），而有限 MDP 中确定性策略总数 `|A|^{|S|}` 有限，算法必在有限步内收敛。其代价在于每轮策略评估本身需要多次扫描，单次评估迭代的计算量约为 `O(|S|²·|A|)`。

**值迭代（Value Iteration）**则把评估与改进压缩为一步，直接使用**贝尔曼最优方程**作为更新式：

`V_{k+1}(s) = max_a Σ_{s'} P(s'|s,a) · [ R(s,a,s') + γ · V_k(s') ]`

它每轮只做一次全状态扫描，收敛到 `V*` 后再提取最优策略 `π*(s) = argmax_a Σ_{s'} P(s'|s,a)·[R + γ·V*(s')]`，单轮复杂度同为 `O(|S|²·|A|)`。两种方法的对比如下表。

| 特性 | 策略迭代 (Policy Iteration) | 值迭代 (Value Iteration) |
|:---|:---|:---|
| **每轮步骤** | 完整策略评估 + 策略改进 | 一次贝尔曼最优算子更新 |
| **外层迭代次数** | 少（有限步内收敛） | 较多（渐进逼近） |
| **每步计算量** | 评估阶段需多轮扫描，较重 | 单轮更新，轻量 |
| **收敛方式** | 策略稳定后立即收敛 | 值函数渐进逼近 `V*` |
| **中间结果** | 每轮都有明确的确定性策略 | 收敛前无显式策略 |

两者并非彼此割裂。**广义策略迭代（Generalized Policy Iteration, GPI）**指出：只要评估与改进两种操作交替进行，任意组合都能收敛到最优，不必严格区分阶段。策略迭代（评估到收敛）与值迭代（评估走一步）恰是 GPI 的两个极端，而现代强化学习中的 Actor-Critic 等方法本质上都是 GPI 的变体。

DP 的局限同样明显。首当其冲的是**维度灾难（Curse of Dimensionality）**：状态数随状态变量个数指数增长，使全状态扫描在大规模问题上不可承受；其次它要求完整模型已知，而真实场景中 `P` 与 `R` 几乎不可能精确获得。**异步动态规划（Asynchronous DP）**对此作出改进：不要求同步全量扫描，而是按任意顺序更新状态。其中**就地更新（In-Place Update）**立即使用最新值以加速信息传播，**优先扫描（Prioritized Sweeping）**按贝尔曼误差大小优先更新"变化最大"的状态，**实时动态规划（Real-Time DP）**只更新智能体实际访问过的状态，适合在线场景。

## 7.3 蒙特卡洛方法与时序差分学习

DP 需要环境的完整模型，但多数真实问题中智能体只能获得一段段交互经验。**蒙特卡洛方法（Monte Carlo, MC）**与**时序差分学习（Temporal Difference, TD）**是两类**无模型（Model-Free）**方法，它们直接从经验（episodes 或 samples）中学习值函数，无需知道 `P` 与 `R`。

**蒙特卡洛方法**的核心思想朴素而直接：对每个状态 `s`，收集智能体在它之后实际获得的回报 `G_t`，用这些回报的均值来估计 `V(s)`。它必须等待**完整回合**结束后才能计算回报，因此仅适用于回合制（episodic）任务，即每个回合必然终止。根据同一回合中多次访问同一状态时如何计数，MC 分为**首次访问 MC（First-Visit MC）**与**每次访问 MC（Every-Visit MC）**两种：前者只取每个回合中第一次访问该状态后的回报，后者对所有访问都计入平均。二者在极限下都收敛到真实值。

MC 的更新可采用增量形式，避免保存全部回报：

`V(s) ← V(s) + α · [ G_t − V(s) ]`

其中 `α` 是学习率，可取常数或随访问次数递减的 `1/N(s)`；`G_t − V(s)` 是误差项。对动作值则有完全类似的 `Q(s,a) ← Q(s,a) + α·[G_t − Q(s,a)]`。

MC 面临一个探索难题：若策略始终确定，大量 `(s,a)` 永远不被访问，其动作值就无法估计。理论上的补救是**探索性开局（Exploring Starts）**，即保证每个回合起始的 `(s,a)` 都有非零被选概率，但这一假设在实践中往往不现实。更实用的方案是采用带探索的策略。**ε-贪婪策略（ε-Greedy）**以概率 `ε` 随机选动作进行探索，以概率 `1−ε` 选择当前最优动作进行利用；它属于**在策略（On-Policy）**方法，因为采样回合所用的策略就是被优化的目标策略。若希望评估与改进一个确定性目标策略，则需**离策略（Off-Policy）**学习：用行为策略 `b`（如 ε-greedy）生成经验，用**重要性采样（Importance Sampling）**修正 `b` 与目标策略 `π` 之间的分布差异。其重要性比 `ρ_{t:T-1} = Π_{k=t}^{T-1} π(a_k|s_k) / b(a_k|s_k)`，普通重要性采样无偏但方差极大，加权重要性采样有偏但方差更低、实践中更常用。

MC 的性质可以概括为：好处是估计无偏、不依赖自举、收敛到真实值；代价是方差高（长回合尤甚）、必须等待回合结束、信息传播慢。**时序差分学习（Temporal Difference, TD）**正是为克服这些缺点而生。

**TD(0)** 的核心是每一步都用当前值估计做**自举**，更新式为

`V(s_t) ← V(s_t) + α · [ r_{t+1} + γ·V(s_{t+1}) − V(s_t) ]`

其中 `r_{t+1} + γ·V(s_{t+1})` 称为 **TD 目标（TD Target）**，`δ_t = r_{t+1} + γ·V(s_{t+1}) − V(s_t)` 称为 **TD 误差（TD Error）**。与 MC 相比，TD(0) 用"一步真实奖励 + 下一状态的估计值"替代完整回报：它引入偏差，但方差显著降低，并且每一步都能在线更新，因此同时适用于回合制与持续（continuing）任务。二者的差异是强化学习中最核心的一组对照。

| 维度 | 蒙特卡洛 (MC) | 时序差分 TD(0) |
|:---|:---|:---|
| **偏差** | 无偏 | 有偏（自举引入） |
| **方差** | 高 | 低 |
| **需要回合终止** | 是（完整回合） | 否（持续任务亦可） |
| **是否自举** | 否 | 是 |
| **更新时机** | 回合结束后 | 每步在线更新 |
| **收敛速度** | 通常较慢 | 通常较快 |
| **对初值敏感度** | 低 | 较高 |
| **适用任务** | 回合制任务 | 回合制与持续任务 |

为了在 MC 与 TD(0) 之间连续插值，**TD(λ)** 引入**资格迹（Eligibility Trace）**。前向视角（forward view）用 λ-回报 `G_t^λ = (1−λ) Σ_{n=1}^{∞} λ^{n-1} · G_t^{(n)}` 定义目标，其中 `G_t^{(n)}` 是 n 步回报，`λ ∈ [0,1]` 调节远期的权重：`λ = 0` 退化为 TD(0)，`λ = 1` 退化为 MC。后向视角（backward view）则用资格迹 `e_t(s) = γλ·e_{t-1}(s) + 1(s_t = s)` 记录各状态被访问的新近程度，并按 `V(s) ← V(s) + α·δ_t·e_t(s)` 更新。两者在理论上等价，但后向视角可以在线增量计算：最近访问过的状态分得当前 TD 误差的大部分信用。

最后是批量更新下的收敛性。给定固定数据集反复应用 MC 或 TD(0)，MC 收敛到该数据上的**最小均方误差（Mean Squared Error, MSE）**解，而 TD(0) 收敛到**最大似然 MDP 模型**的解。这一区别说明：当环境确实满足马尔可夫性时，TD(0) 因利用了 MDP 结构而通常优于 MC，能避免对采样噪声的过拟合。

## 7.4 Q-Learning 与 SARSA

在无模型设定下直接学习动作值函数 `Q(s,a)` 并据此改进策略，称为 **TD 控制（TD Control）**。其中最基础的两类算法是 **SARSA** 与 **Q-Learning**，它们的差别仅在于更新目标中如何对待下一动作，却决定了在策略与离策略的根本分野。

**SARSA** 的名字来自更新所依赖的五元组 `(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})`，其更新式为

`Q(s_t, a_t) ← Q(s_t, a_t) + α · [ r_{t+1} + γ·Q(s_{t+1}, a_{t+1}) − Q(s_t, a_t) ]`

关键在于 `a_{t+1}` 由**当前行为策略**在 `s_{t+1}` 下真正选出，因此 SARSA 学习的是当前行为策略的 `Q^π`，属于**在策略（On-Policy）**方法。实践中行为策略通常取 ε-greedy，随着学习逐步趋近贪心，SARSA 最终收敛到**近似最优的 ε-greedy 策略**。一个著名例子是悬崖行走（Cliff Walking）：SARSA 倾向于学会一条远离悬崖的**安全路径**，因为它把 ε-greedy 探索时可能产生的随机坠崖动作也计入了价值。

**Q-Learning** 由 Watkins 于 1989 年提出，其更新式把下一动作的选择替换为对所有动作取最大值：

`Q(s_t, a_t) ← Q(s_t, a_t) + α · [ r_{t+1} + γ·max_a Q(s_{t+1}, a) − Q(s_t, a_t) ]`

由于目标中使用 `max_a Q(s_{t+1}, a)` 而非实际采取的 `a_{t+1}`，Q-Learning 直接逼近最优动作值 `Q*`，与生成经验的行为策略无关，属于**离策略（Off-Policy）**方法。这意味着行为策略可以是任意探索策略——ε-greedy、均匀随机或 Boltzmann 均可。在悬崖行走中，Q-Learning 学到的是**贴着悬崖边缘的最短路径**，因为它优化的是确定性贪心策略；但在线学习期间，探索动作导致的坠崖使其实际表现反而可能逊于 SARSA。Q-Learning 的收敛需要每个 `(s,a)` 被无限次访问，且学习率满足 Robbins-Monro 衰减条件。

两者对比如下。

| 维度 | SARSA | Q-Learning |
|:---|:---|:---|
| **在/离策略** | 在策略 | 离策略 |
| **更新目标** | `r + γ·Q(s', a')` | `r + γ·max_a Q(s', a)` |
| **学习对象** | 当前行为策略的 `Q^π` | 最优动作值 `Q*` |
| **策略风格** | 保守，计入探索风险 | 激进，直接逼近最优 |
| **收敛目标** | 近似最优 ε-greedy 策略 | 最优确定性策略 `π*` |
| **在线性能** | 风险环境中更好 | 可能较差 |

**期望 SARSA（Expected SARSA）**进一步用策略 `π` 在 `s_{t+1}` 下所有动作的**期望值**替代采样目标：

`Q(s_t, a_t) ← Q(s_t, a_t) + α · [ r_{t+1} + γ·Σ_a π(a|s_{t+1})·Q(s_{t+1}, a) − Q(s_t, a_t) ]`

它消除了动作选择带来的方差，更新更稳定，且灵活性更强：行为与目标用同一 `π` 时是在策略，行为用 `π` 而目标取贪心时是离策略；当目标策略为贪心时，它恰好退化为 Q-Learning。**Double Q-Learning**（van Hasselt, 2010）则针对 Q-Learning 的**最大化偏差（Maximization Bias）**：由于 `max` 算子作用于带噪声的估计会系统性地抬高值，导致过估计。其对策是维护两套独立 Q 函数 `Q_A` 与 `Q_B`，以一半概率用一套选择动作、另一套评估该动作，实现**动作选择与动作评估的解耦**，从而得到更接近无偏的估计。这一思想后来成为 **Double DQN** 的核心组件。

在实际选择上，若目标是直接学习最优策略且风险较低，可选 Q-Learning；若探索过程中的惩罚代价高（如机器人导航、交易回撤），需要保守策略时选 SARSA；若希望更低的方差且可接受额外计算，选 Expected SARSA；若观察到 Q 值持续被高估，尤其在状态动作空间大、噪声严重的深度强化学习场景，则应采用 Double Q-Learning。

## 7.5 深度强化学习：DQN 及其变体

表格型方法把每个 `(s,a)` 的值单独存储，一旦状态或动作空间巨大甚至连续，Q 表既无法存储也无法泛化，这一困境正是**维度灾难**的体现。**深度强化学习（Deep RL）**的核心思想是用**神经网络作为函数逼近器（Function Approximator）**，把高维状态直接映射到动作价值或策略，从而端到端地学习。

**深度 Q 网络（DQN, Deep Q-Network）**由 Mnih 等人于 2015 年发表在《Nature》，是深度强化学习的开创性工作。它以原始游戏画面像素（如连续 4 帧 84×84 灰度图）为输入，用**卷积神经网络（Convolutional Neural Network, CNN）**提取空间特征，再由全连接层输出每个合法动作的 Q 值 `Q(s,a;θ)`，无需任何手工特征。训练通过最小化 TD 误差的均方误差进行：

`L(θ) = E_{(s,a,r,s')~D} [ ( r + γ·max_{a'} Q(s', a'; θ⁻) − Q(s, a; θ) )² ]`

其中 `θ⁻` 是目标网络参数，`D` 是经验回放缓冲区。DQN 之所以能稳定训练，靠的是两大关键创新。

其一是**经验回放（Experience Replay）**：把交互产生的转移 `(s, a, r, s', done)` 存入**回放缓冲区（Replay Buffer）**，训练时随机抽取小批量（mini-batch），而非使用连续的经验序列。这样做一方面打破了连续样本间的时序相关性，满足随机梯度下降对独立同分布（i.i.d.）假设的要求；另一方面让每条转移可被多次重放，提高了样本效率，也避免稀有经验被遗忘。其二是**目标网络（Target Network）**：额外维护一个参数冻结的网络 `Q(s,a;θ⁻)` 来计算 TD 目标，使目标值不会随在线网络快速漂移。目标网络的更新有两种方式——**硬更新（Hard Update）**每隔 `C` 步把在线参数整体复制到目标网络，**软更新（Soft Update）**每步按 `θ⁻ ← τθ + (1−τ)θ⁻` 缓慢逼近（常用于 DDPG、TD3 等连续控制算法）。二者共同作用，显著降低了训练的不稳定性与发散风险。

DQN 还依赖一些工程技巧：**ε-贪婪探索**从高值（如 1.0）逐步衰减到低值（如 0.1 或 0.01）；**奖励裁剪（Reward Clipping）**把奖励限制在 `[-1, 1]`，使同一套超参数能适应不同奖励尺度的游戏。凭借这些设计，DQN 在 49 款 Atari 游戏中有 29 款达到或超过人类职业玩家水平，标志着深度强化学习的突破。

此后一系列改进针对 DQN 的不同弱点展开，下面逐一说明。

**双 Q 网络（Double DQN, van Hasselt et al. 2016）**解决 Q 值系统性过估计：标准 DQN 用同一组参数既选中最大 Q 的动作、又评估该动作，噪声被正偏差放大。Double DQN 改为**用在线网络选动作、用目标网络评估其价值**，即 `Target = r + γ·Q(s', argmax_a Q(s', a; θ); θ⁻)`。它改动极小、几乎零额外计算，却能显著降低高估并提升得分。**优先经验回放（Prioritized Experience Replay, PER, Schaul et al. 2016）**认为不同转移的学习价值不同，TD 误差越大的转移包含越多"意外"信息，应被更频繁采样。其优先级定义为 `p_i = |δ_i| + ε`，采样概率 `P(i) ∝ p_i^α`；由于非均匀采样引入分布偏差，还需用重要性采样权重 `w_i = (N·P(i))^{-β}` 修正梯度，`β` 从 0.4 逐步退火到 1。PER 在稀疏奖励环境中加速尤为明显，工程上常用**和树（Sum Tree）**实现 `O(log N)` 的采样与更新。

**竞争网络（Dueling DQN, Wang et al. 2016）**把 Q 函数分解为状态价值与动作优势之和 `Q(s,a) = V(s) + A(s,a)`，其中 `V(s)` 衡量"处于状态 s 有多好"，`A(s,a)` 衡量"在该状态选动作 a 比平均水平好多少"。由于仅由 Q 无法唯一确定这一分解，需通过减去均值来强制约束 `Q = V + A − (1/|A|)·Σ_{a'} A(s,a')`，使优势均值约为零。它的收益在于：当许多状态下动作选择对结果影响不大时（如赛车前方无车时左右移动的 Q 值几乎相同），网络可以**不依赖动作区分地学准 `V(s)`**，从而获得更好的泛化。**多步学习（Multi-step / n-step Returns）**则用前看 `n` 步的回报 `R_t^{(n)} = Σ_{k=0}^{n-1} γ^k r_{t+k} + γ^n·Q(s_{t+n}, a_{t+n}; θ⁻)` 替代单步目标，在偏差与方差之间提供可调折中，Rainbow 取 `n = 3`。

**分布式强化学习（Distributional RL, C51）**不满足于只建模回报的期望 `Q(s,a) = E[Z(s,a)]`，而是建模完整回报分布 `Z(s,a)`，以捕捉方差、多模态等信息。C51 把分布离散化为 51 个**原子（atoms）**，网络输出各原子的概率 `p_i(s,a)`，并通过分布 Bellman 算子投影后用 KL 散度作为损失 `L = D_KL(Φ(T Z_{θ⁻}) ‖ Z_θ)`，其中 `Φ` 把更新后的支撑投影回原离散网格。**噪声网络（Noisy Nets, Fortunato et al. 2017）**针对 ε-greedy 探索**无状态（stateless）**、在所有状态下以相同概率扰动的缺点，把参数化噪声注入网络权重：`y = (μ_w + σ_w ⊙ ε_w)·x + (μ_b + σ_b ⊙ ε_b)`，其中 `μ, σ` 可学习、`ε` 为随机噪声。它常用的**因子化高斯噪声（Factorized Gaussian）**可大幅减少噪声变量，使网络通过梯度下降**自主学习状态依赖的探索策略**。

**Rainbow**（Hessel et al. 2018）把上述六种改进集成到统一框架，是 Atari 基准上的里程碑算法。其组件与贡献如下表。

| 组件 | 核心贡献 |
|:---|:---|
| **Double Q-Learning** | 解耦动作选择与评估，减少 Q 值高估 |
| **优先经验回放 (PER)** | 按 TD 误差优先采样关键转移 |
| **竞争网络 (Dueling)** | `Q = V + A` 架构，提升泛化 |
| **多步回报 (n-step)** | 前向 n 步自举，平衡偏差与方差 |
| **分布式 RL (C51)** | 建模完整回报分布而非仅期望 |
| **噪声网络 (Noisy Nets)** | 参数化噪声替代 ε-greedy，状态依赖探索 |

Rainbow 默认使用 `n = 3`、51 类分布与因子化高斯噪声，并用分布 RL 的 KL 散度替代单值 `|δ|` 计算优先级。消融实验表明：每个组件单独加入都有帮助，集成后性能超越任何单一组件，移除任何一个都会导致性能下降。数据效率也从原始 DQN 的约 2 亿帧提升到约 1800 万帧，提升超过 10 倍。

各变体的横向对比如下。

| 方法 | 年份 | 核心机制 | 主要优势 | 额外开销 |
|:---|:---:|:---|:---|:---|
| **DQN** | 2015 | CNN + 经验回放 + 目标网络 | 首个从像素端到端学习 | 基准 |
| **Double DQN** | 2016 | 在线选动作 + 目标估值 | 消除 Q 值高估 | 几乎为零 |
| **Prioritized ER** | 2016 | TD 误差决定采样优先级 | 稀疏奖励加速显著 | 和树 `O(log N)` |
| **Dueling DQN** | 2016 | `Q = V + A − mean(A)` | 动作区分度低时泛化更优 | 少量参数 |
| **C51** | 2017 | 51 原子离散化回报分布 | 分布信息更丰富、更鲁棒 | 51 倍输出维度 |
| **Noisy Nets** | 2017 | `μ + σ⊙ε` 参数化噪声 | 状态条件探索，免调度 | 参数量翻倍 |

从 DQN 到 Rainbow 的演进揭示了一条清晰的方法论：**核心挑战始终是打破样本相关性与稳定优化目标**，而每个改进组件解决的是一个正交的特定问题——Double 解决高估、PER 解决样本效率、Dueling 解决跨动作泛化、分布式 RL 解决信息丰富度、噪声网络解决探索效率，因此它们可以叠加。若要在新环境应用深度强化学习，以 Rainbow 或至少 DQN + Double + Dueling + PER 的组合为起点通常是稳妥的选择。此后 Ape-X、R2D2、Agent57 等进一步引入分布式并行、循环状态与自适应探索，把 Atari 全部 57 款游戏提升到超越人类水平。

## 7.6 策略梯度：REINFORCE、Actor-Critic、A2C/A3C

基于价值的方法先学 `Q(s,a)` 再由 `argmax` 导出动作，存在三个固有困难：**连续动作空间**中无法对无限多个动作直接求 `argmax`；**部分可观测环境（Partially Observable MDP, POMDP）**下确定性策略可能次优，而随机策略更鲁棒；价值函数的微小误差会因 `argmax` 的不连续性导致策略大幅跳变。**策略梯度（Policy Gradient）**方法从根本上规避这些问题——它直接参数化策略 `π_θ(a|s)` 并沿期望回报的梯度优化，天然输出随机策略，也天然支持连续动作。

参数化策略在离散动作下常用 softmax 输出概率，在连续动作下常输出高斯分布的均值与方差。优化目标是期望回报 `J(θ) = E_{τ~π_θ}[R(τ)]`，其中 `R(τ)` 是轨迹的折扣累积回报。**策略梯度定理（Policy Gradient Theorem）**给出梯度：

`∇_θ J(θ) = E_{π_θ}[ ∇_θ log π_θ(a|s) · Q^{π_θ}(s,a) ]`

其关键洞察是梯度**不依赖环境转移动态 `P(s'|s,a)`**，因此完全无模型；其直觉是提高高 `Q` 动作的概率、降低低 `Q` 动作的概率，而 `∇_θ log π_θ` 决定参数调整的方向。

**REINFORCE**（Williams, 1992）是最直接的蒙特卡洛策略梯度：用采样得到的累积回报 `G_t` 作为 `Q^{π_θ}(s_t,a_t)` 的无偏估计，更新 `θ ← θ + α·γ^t·∇_θ log π_θ(a_t|s_t)·G_t`。它先用当前策略采集一条完整回合，再对每个时间步计算 `G_t` 并做梯度上升。REINFORCE 无偏但方差极高，因为 `G_t` 在不同回合间波动巨大；它不进行自举，必须等回合结束才能更新，收敛缓慢，通常只适合短回合任务或教学演示。

方差问题的一个通用解法是引入**基线（Baseline）**：从回报中减去一个不依赖动作 `a` 的函数 `b(s)`，即 `∇_θ J = E[∇_θ log π_θ(a|s)·(Q(s,a) − b(s))]`。由于 `E[∇_θ log π_θ·b(s)] = 0`，这一操作不引入偏差，却能在 `G_t` 恒为正时避免"所有动作概率一起上升"的弱学习信号。最常用的基线是状态价值函数 `V(s)`，由此引出**优势函数（Advantage Function）** `A(s,a) = Q(s,a) − V(s)`，它衡量该动作比平均水平好多少：`A > 0` 增强其概率，`A < 0` 削弱其概率。

**演员-评论家（Actor-Critic）**架构用一个策略网络（Actor）加一个价值网络（Critic）协同学习。Actor `π_θ(a|s)` 决定执行哪个动作，Critic `V_φ(s)` 或 `Q_φ(s,a)` 评估状态或动作的好坏。其精妙之处在于可用 TD 误差作为优势的估计：`δ_t = r_{t+1} + γ·V(s_{t+1}) − V(s_t) ≈ A(s_t,a_t)`。于是 Actor 按 `θ ← θ + α·∇_θ log π_θ(a_t|s_t)·δ_t` 更新，Critic 则通过最小化 `δ_t²` 学习。相比 REINFORCE 的完整回报，单步 TD 目标方差更低，但引入了偏差，因为 `V(s_{t+1})` 自身仍在学习中；n 步回报则在两者之间折中。

**同步优势演员-评论家（A2C, Advantage Actor-Critic）**让多个并行环境同时采集经验，汇总成一批后统一计算梯度、平均后更新、再同步到所有环境。其优势估计采用 n 步回报 `A(s_t,a_t) = Σ_{k=0}^{n-1} γ^k r_{t+k} + γ^n V(s_{t+n}) − V(s_t)`，`n = 1` 退化为 TD(0)，`n → ∞` 退化为 MC。同步结构使训练更稳定、更易调试，也能利用 GPU 批量处理。其异步版本 **A3C（Asynchronous Advantage Actor-Critic, Mnih et al. 2016）**让多个 Worker 在各自环境中并行运行：每个 Worker 先同步全局参数，执行 `t_max` 步或直到终止，从后向前累积回报与梯度，再异步地无锁更新全局网络。A3C 无需经验回放，因为并行 Worker 天然提供了去相关的数据；它还常加入**熵正则（Entropy Bonus）** `β·H(π(·|s))` 鼓励探索，防止策略过早收敛到次优解。A3C 在 Atari 上匹配或超越 DQN，同时适用于连续控制，证明了策略梯度方法在大规模强化学习中的可行性。

各策略梯度方法的对比如下。

| 维度 | REINFORCE | Actor-Critic | A2C | A3C |
|:---|:---|:---|:---|:---|
| **估计类型** | 蒙特卡洛 | TD 自举 | n 步回报 | n 步回报 |
| **方差 / 偏差** | 极高 / 无偏 | 低 / 有偏 | 低 / 有偏 | 低 / 有偏 |
| **网络结构** | 仅策略网络 | 策略 + 价值 | 策略 + 价值 | 策略 + 价值 |
| **并行方式** | 不支持 | 不支持 | 同步多环境 | 异步多 Worker |
| **更新频率** | 回合结束 | 每步 | 每 n 步批量 | 每 `t_max` 步异步 |
| **典型场景** | 短回合 / 教学 | 连续控制 | 通用 GPU 训练 | Atari / MuJoCo |

与基于价值的方法相比，策略梯度直接优化 `π` 而非由 `argmax Q` 导出，天然支持连续动作与随机策略，但样本效率较低（主要在策略、难以利用经验回放）；价值方法则样本效率更高，却可能因**致命三元组（Deadly Triad，函数逼近 + 自举 + 离策略）**而不收敛。此外，**广义优势估计（Generalized Advantage Estimation, GAE）**用指数加权多步 TD 误差在偏差与方差之间做平滑折中，是 PPO 等现代算法中估计优势的标准工具。

## 7.7 前沿方法：TRPO、PPO、SAC、Dreamer

策略梯度对步长极为敏感：更新过大会导致策略崩溃且难以恢复。**信赖域策略优化（TRPO, Trust Region Policy Optimization, Schulman et al. 2015）**用 KL 散度约束新旧策略的差异，确保每轮更新都落在"信任域"内。它在最大化 `E[ (π_θ(a|s)/π_old(a|s))·A(s,a) ]` 的同时满足 `KL[π_old ‖ π_θ] ≤ δ`，借助**共轭梯度（Conjugate Gradient）**与**线搜索（Line Search）**求解。TRPO 具有单调改进的理论保证，但因需要近似二阶信息（Hessian-vector product），计算代价高，实践中逐步被 PPO 取代。

**近端策略优化（PPO, Proximal Policy Optimization, Schulman et al. 2017）**是 TRPO 的简化实用版，也是 OpenAI 的默认强化学习算法。它最常用的 **PPO-Clip** 变体定义概率比 `r_t(θ) = π_θ(a_t|s_t) / π_old(a_t|s_t)`，并优化

`L^{CLIP}(θ) = E[ min( r_t(θ)·A_t, clip(r_t(θ), 1−ε, 1+ε)·A_t ) ]`

其直觉是：对好动作（`A_t > 0`）把比率截断在 `1+ε`，避免其概率上升过快；对坏动作（`A_t < 0`）截断在 `1−ε`，避免其概率下降过快，典型 `ε` 取 0.1 或 0.2。另一变体 **PPO-Penalty** 则用自适应系数的 KL 惩罚项。PPO 实现简单、支持离散与连续动作、兼容循环策略且样本效率不错，被广泛用于 OpenAI Five（Dota 2）、机器人操控以及 ChatGPT 的 RLHF 训练流程。

**软演员-评论家（SAC, Soft Actor-Critic, Haarnoja et al. 2018）**建立在**最大熵强化学习（Maximum Entropy RL）**之上：目标不再是单纯最大化累积奖励，而是在回报中加入策略熵 `H(π(·|s_t))`，即 `J(π) = Σ_t E[ r(s_t,a_t) + α·H(π(·|s_t)) ]`，其中 `α` 为温度系数，控制探索与利用的平衡。熵正则化自动鼓励探索、避免过早收敛到次优确定性策略，并对噪声与扰动更鲁棒。其架构包含三个要素：输出均值与方差的随机高斯策略 Actor、取两个 Q 网络较小值以缓解高估的 **Twin Q-Networks**，以及自动调节 `α` 使策略熵逼近目标熵的**自动温度调节（Automatic Temperature Tuning）**。SAC 是离策略方法，可利用经验回放，样本效率远高于 PPO/TRPO，在 MuJoCo、DM Control 等连续控制基准上长期保持最优，适合机器人关节控制、自动驾驶等连续空间任务。

**Dreamer 系列（Hafner et al. 2019 / V2 / V3）**代表**世界模型（World Model）**范式：它先学习环境的内部动态模型（latent dynamics model），再在"想象中的潜在轨迹"上训练策略，而不频繁与真实环境交互。版本演进中，DreamerV1 首次统一了世界模型学习与潜在想象训练，DreamerV2 引入离散潜在变量与 KL 平衡大幅提升表征质量，DreamerV3 则以**跨域固定超参数**实现了跨任务零样本迁移。Dreamer 极度样本高效、天然适合长时域任务，被用于 Atari、DM Control 与 Minecraft 的钻石挑战。

四者的综合对比如下。

| 维度 | TRPO | PPO | SAC | Dreamer |
|:---|:---|:---|:---|:---|
| **类型** | 在策略 | 在策略 | 离策略 | 基于模型 |
| **样本效率** | 低 | 低 | 较高 | 极高 |
| **稳定性** | 好（KL 约束） | 好（clip 控制） | 好（熵自平衡） | 依赖世界模型质量 |
| **动作空间** | 离散/连续 | 离散/连续 | 连续（最擅长） | 离散/连续 |
| **实现难度** | 高 | 低 | 中 | 高 |
| **适用场景** | 理论研究与基线 | 通用首选（含 RLHF） | 连续控制 SOTA | 样本稀缺、长时域 |

近年趋势中，PPO 成为大语言模型对齐的事实标准，SAC 主导机器人仿真，Dreamer 系列在 Minecraft、自动驾驶等真样本稀缺领域快速崛起。

## 7.8 博弈与强化学习：AlphaGo、AlphaZero 与 MuZero

围棋长期被视为人工智能的"圣杯"级难题，原因在于其搜索空间远超穷举。围棋的分支因子（branching factor）约 `b ≈ 250`，对局深度约 `d ≈ 150`，理论搜索空间高达 `250^{150}`，任何暴力枚举都不可行。因此必须像人类棋手那样先形成**直觉（intuition）**来引导搜索，而非遍历所有可能，这正是深度神经网络与**蒙特卡洛树搜索（Monte Carlo Tree Search, MCTS）**结合的动机。

**AlphaGo**（Silver et al., 2016）的核心思路是"深度神经网络 + MCTS"的深度融合：用神经网络压缩局面评估与落子直觉，用 MCTS 做前瞻推演。它使用三个网络协同工作。**监督学习策略网络 SL** 用 3000 万人类专家落子做监督学习，提供快速走子策略；**强化学习策略网络 RL** 从 SL 初始化，通过自我对弈微调，目标是战胜上一版本的自己，得到更强的落子策略；**价值网络**用自我对弈数据做回归，输入局面输出胜负预测，用于评估局面的优劣。其 MCTS 在原四步流程（选择、扩展、评估、回传）之上引入神经网络增强：选择阶段按 `a = argmax_a ( Q(s,a) + P(s,a)·√(Σ_b N(s,b)) / (1 + N(s,a)) )` 进行，其中先验概率 `P(s,a)` 来自策略网络；扩展阶段用策略网络为子节点赋予先验；评估阶段混合价值网络与快速走子的结果；回传阶段沿路径更新 `Q` 与访问计数 `N`。训练按"SL 策略 → RL 策略（自我对弈）→ 价值网络"的管线进行，计算量巨大。2016 年 3 月，AlphaGo 以 4-1 击败李世石九段，标志着人工智能攻克围棋这一智力巅峰。

**AlphaGo Zero**（Silver et al., 2017）完成了去人类先验的跨越：它不依赖任何人类棋谱，甚至不依赖气、眼、征子等围棋领域知识，仅从规则出发，实现纯粹自我对弈的**白板学习（tabula rasa）**。它把多个网络合并为单一网络 `f_θ(s) = (p, v)`，同时输出策略向量 `p` 与价值标量 `v`。训练循环为：用当前网络引导 MCTS 搜索生成数据 `(s, π, z)`，其中 `π` 是 MCTS 提升后的访问概率、`z` 是终局胜负；再最小化联合损失 `L = (z − v)² − π^T·log p + c·‖θ‖²`，三项分别是价值损失（均方误差）、策略损失（交叉熵）与 L2 正则；最后通过锦标赛评估，新网络若对旧网络胜率不低于 55% 则替换之。AlphaGo Zero 训练 3 天后以 100-0 击败此前击败李世石的 AlphaGo，并从零重新发现了人类数千年的定式，还发明了人类从未见过的新定式。

**AlphaZero**（Silver et al., 2018）将 AlphaGo Zero 的算法通用化，直接应用于国际象棋与日本将棋，不改网络结构、不改超参数，仅做少量适配：围棋中采用棋盘旋转/翻转的数据增强，国际象棋因王车易位等非对称规则不做数据增强，并调整探索噪声与 MCTS 超参数。它训练国际象棋仅 9 小时便压倒性击败当时最强引擎 Stockfish，训练将棋 12 小时击败 Elmo，证明了同一套**通用强化学习算法**可跨不同规则达到超人类水平。

**MuZero**（Schrittwieser et al., 2019）则解决了 AlphaZero 依赖完美模拟器的问题。当环境未知（如真实世界或 Atari）无法获得状态转移规则时，MuZero 用神经网络学习三个函数，在**隐空间（latent space）**中完成 MCTS 规划。这三个函数分别是：**表示函数（Representation）** `s_t = h(o_{1:t})`，把历史观测编码为隐状态；**动态函数（Dynamics）** `s_{t+1}, r_t = g(s_t, a_t)`，预测下一隐状态与即时奖励；**预测函数（Prediction）** `p_t, v_t = f(s_t)`，从隐状态输出策略与价值。其关键设计是**无重建损失（No Reconstruction Loss）**——不要求从隐状态重建原始观测，只预测对规划有用的量，从而大幅提升学习效率与泛化。训练时先收集真实经验，再在隐空间用 MCTS 展开搜索，最后用 MCTS 产生的提升策略与价值目标联合训练 `h`、`g`、`f`。MuZero 在棋类上达到 AlphaZero 水平，在 Atari 上达到超人类水平，首次证明大规模模型驱动强化学习在真实领域也可行。

四代算法的演进对比如下。

| 维度 | AlphaGo (2016) | AlphaGo Zero (2017) | AlphaZero (2018) | MuZero (2019) |
|:---|:---|:---|:---|:---|
| **数据来源** | 人类棋谱 + 自我对弈 | 纯自我对弈 | 纯自我对弈 | 环境交互 |
| **网络数量** | 3 | 1（双输出） | 1（双输出） | 3（表示/动态/预测） |
| **是否模型驱动** | 否 | 否 | 否 | 是（学习隐空间模型） |
| **泛化能力** | 仅围棋 | 仅围棋 | 围棋/象棋/将棋 | 棋类 + Atari + 通用 |
| **核心突破** | 首次击败人类顶级棋手 | 去除人类先验，自学习 | 同一算法跨棋种通用 | 无模拟器下模型驱动规划 |

## 7.9 探索-利用权衡

强化学习最根本的困境之一是**探索-利用权衡（Exploration-Exploitation Trade-off）**：**利用（Exploit）**是选择当前已知最优的动作以最大化即时收益，**探索（Explore）**是尝试未知或不确定的动作以发现可能更优的策略。在有限资源下，探索过多会浪费机会，利用过多则可能长期困在次优解。一个贴切的类比是选择餐厅——反复光顾最爱的店是利用，尝试新店则是探索。

最简单的平衡手段是 **ε-贪婪（ε-Greedy）**：以概率 `ε` 均匀随机选动作，以概率 `1−ε` 贪心选当前最优。它直观易实现，是应用最广的探索策略，但探索是盲目的，对明显很差的动作也分配概率，浪费样本；实践中常让 `ε` 随时间衰减（如 `ε_t = ε_0/√t` 或指数衰减）。它适合动作空间小、环境平稳的经典 DQN 场景。

**乐观初始化（Optimistic Initialization）**把所有 `Q(s,a)` 的初值设得过高，于是智能体先选择"看似最优"的动作，实际奖励低于预期产生"失望"，从而自然转向未被尝试的动作——它在初期驱动系统性探索而无需显式探索策略。优点是对平稳问题前期探索充分，缺点是非平稳问题中初值影响会随更新消失。把它推广到 MDP 就得到 **Rmax 算法**：对访问足够多次的 `(s,a)` 用经验估计，对未知转移则假设获得最大奖励，体现"面对不确定性时的乐观"。

**置信上界（Upper Confidence Bound, UCB）**在价值估计上叠加不确定性的探索奖励：`a_t = argmax_a [ Q_t(a) + c·√(ln t / N_t(a)) ]`。第一项 `Q_t(a)` 负责利用，第二项 `c·√(ln t / N_t(a))` 负责探索：访问次数越少该项越大，时间越长该项增长越慢，超参数 `c` 控制探索强度。UCB 有累积悔恨界 `O(log T)` 的渐进最优保证。在蒙特卡洛树搜索中，其变体 **UCT** 以 `UCT(v) = X̄_v/N_v + 2C_p·√(2 ln N_parent / N_v)` 选择分支，是 MCTS 的标准选择规则。

**汤普森采样（Thompson Sampling）**是贝叶斯方法：为每个 `Q(s,a)` 维护后验分布，每步从各动作的后验中抽样一个值、对这些抽样值贪心选择，再观察奖励更新后验。其核心性质是"选择某动作的概率恰等于该动作是最优动作的概率"，天然平衡探索与利用。实现上可对二项奖励用 Beta-Bernoulli，对连续奖励用高斯后验，深度强化学习中则用贝叶斯神经网络。它实证表现优异，悔恨界与 UCB 相当甚至更优，代表应用是 DeepMind 的 Bootstrapped DQN。

在稀疏奖励场景，更需要**基于计数与内在动机（Count-based / Intrinsic Motivation）**的探索。最直接的**计数奖励**形如 `r⁺(s,a) = r(s,a) + β/√N(s)`，访问越少的状态获得越多额外奖励；对连续或大规模状态空间，可用密度模型或哈希替代精确计数。**内在动机**把好奇心形式化为预测误差：预测越不准，说明环境越"新奇"，奖励越大。**内在好奇心模块（Intrinsic Curiosity Module, ICM, Pathak et al. 2017）**用一个**逆动力学模型**从 `(s_t, s_{t+1})` 预测动作以学习状态表示，再用**前向动力学模型**从 `(s_t, a_t)` 预测下一状态特征，其预测误差即好奇心奖励。**随机网络蒸馏（Random Network Distillation, RND, Burda et al. 2019）**更简单：固定一个随机初始化网络 `f`，训练预测网络 `f̂` 去拟合 `f` 的输出，用预测误差 `‖f̂(s) − f(s)‖²` 作为新异度奖励，见过状态误差小、未见状态误差大。这类方法会遭遇 **Noisy-TV 问题**：若环境存在无法预测的随机噪声（如随机跳动的电视），预测误差永远很大，智能体被其吸引而停止有意义的探索；缓解办法是分离可控与不可控特征或引入规划。

**信息论探索（Information-Theoretic Exploration）**把目标设为最大化对环境的信息增益。**变分信息最大化探索（Variational Information Maximizing Exploration, VIME, Houthooft et al. 2016）**用贝叶斯神经网络建模环境动态，把每次更新前后的 KL 散度变化作为探索奖励。**赋权（Empowerment）**则最大化动作与未来状态之间的互信息 `I(A; S_{t+1}|S_t)`，衡量智能体对环境的控制力，追求"有影响力"的状态以产生更丰富的探索。

**Go-Explore**（Ecoffet et al. 2019）提出一个关键洞察：把探索与利用策略解耦，记住并回到有前景的状态。它分两阶段：先运行探索策略并把访问过的有前景状态存入存档（archive），再从存档中采样并直接复位到该状态重新探索。正是这种"存档 + 回到好状态"的策略，使它首次攻克长期被认为不可解的 Atari 游戏 Montezuma's Revenge。

主要探索策略对比如下。

| 探索策略 | 原理 | 理论保证 | 适用场景 | 主要缺点 |
|:---|:---|:---:|:---|:---|
| **ε-greedy** | 小概率随机动作 | 弱 | 简单、稠密奖励 | 盲目探索，效率低 |
| **乐观初始化** | 高初始 Q 值驱动尝试 | 无 | 平稳 Bandit、小 MDP | 非平稳环境失效 |
| **UCB** | 价值 + 不确定性奖励 | `O(log T)` 悔恨界 | Bandit、MCTS | 需精确计数 |
| **Thompson 采样** | 后验采样后贪心 | `O(log T)` 悔恨界 | Bandit、小 MDP | 先验敏感 |
| **ICM / RND** | 预测误差作为内在奖励 | 无 | 视觉稀疏奖励任务 | Noisy-TV、计算开销 |
| **Go-Explore** | 存档 + 回到好状态 | 无 | 极稀疏、确定性环境 | 需能回到已访问状态 |

实践上，稠密奖励通常只需 ε-greedy 或衰减 ε-greedy；离散动作 Bandit 首选 Thompson 采样或 UCB；稀疏奖励则考虑 ICM/RND 或 Go-Explore；MCTS 场景以 UCT 为标准。许多现代方法把多种技术组合使用，例如 R2D2 = RNN + DQN + 内在奖励。前沿方向包括无奖励探索、技能发现、大语言模型引导探索以及持续探索。

## 7.10 离线强化学习与 RLHF

在医疗、自动驾驶、机器人等高风险领域，在线交互成本高昂甚至存在安全隐患，只能依赖预先收集好的静态数据集进行学习，这就是**离线强化学习（Offline RL / Batch RL）**的动机。与在线学习最大的不同在于：离线场景下无法通过采集新数据来纠正错误。

离线学习的核心障碍是**分布偏移（Distribution Shift）**。策略在优化过程中会查询到数据集分布之外的动作（out-of-distribution actions），而 Q 函数在这些未见区域的外推极不准确，往往给出过高的估计，策略于是利用这些虚假的高 Q 值，导致失败。针对这一问题形成了四类方法。**策略约束（Policy Constraint）**类方法（如 BCQ、BEAR）显式约束学习到的策略不偏离行为策略；**价值惩罚（Value Penalty）**类方法以 **保守 Q 学习（Conservative Q-Learning, CQL, Kumar et al. 2020）**为代表，通过压低分布外动作的 Q 值、抬高数据集内动作的 Q 值来学习一个保守（下界）Q 函数，只需对标准 Q-Learning 做简单修改；**不确定性估计**类方法（如 UWAC、MOPO）只信任置信度高的 Q 值区域；**序列建模**类方法以 **决策 Transformer（Decision Transformer, Chen et al. 2021）**为代表，把强化学习重塑为序列建模问题，以目标回报与历史状态为条件，用 GPT 风格的因果 Transformer 自回归地生成动作。

**隐式 Q 学习（Implicit Q-Learning, IQL）**则完全避免查询分布外动作，它用**期望回归（Expectile Regression）**这一非对称 L2 损失估计 TD 目标的上期望值，从而在不做策略查询的情况下得到价值函数，再通过**优势加权回归（Advantage-Weighted Regression, AWR）**提取策略，训练更稳定。离线方法的对比如下。

| 方法类别 | 核心思想 | 策略约束 | 不确定性估计 | 典型算法 |
|:---|:---|:---:|:---:|:---|
| **策略约束** | 约束策略不偏离行为策略 | 是 | 否 | BCQ, BEAR |
| **价值惩罚** | 压低 OOD 动作的 Q 值 | 否 | 否 | CQL |
| **不确定性估计** | 只信任高置信的 Q 值区域 | 否 | 是 | UWAC, MOPO |
| **序列建模** | 将 RL 视为条件序列预测 | 否 | 否 | Decision Transformer |

**基于人类反馈的强化学习（Reinforcement Learning from Human Feedback, RLHF）**则把强化学习用于大语言模型对齐。传统下一词预测损失无法刻画**有帮助性（helpfulness）**、**无害性（harmlessness）**与**诚实性（honesty）**等标准，RLHF 通过三阶段流程解决这一问题。**第一阶段是监督微调（Supervised Fine-Tuning, SFT）**：收集人类标注者书写的高质量演示数据，在 `(prompt, response)` 对上微调基座模型得到 `π_SFT`，让模型初步学会遵循指令。**第二阶段是奖励模型训练（Reward Model Training）**：对每个提示用 `π_SFT` 采样多个回复，由人类标注者排序，再训练奖励模型 `R_φ(x,y)` 预测偏好分数，损失基于 **Bradley-Terry 成对偏好模型** `L = −log σ( R_φ(x, y_w) − R_φ(x, y_l) )`，其中 `y_w` 是优胜回复、`y_l` 是败者回复。**第三阶段是 PPO 微调**：用 PPO 针对奖励模型优化策略，目标为 `max E[ R_φ(x,y) − β·KL(π_θ(y|x) ‖ π_ref(y|x)) ]`，其中 KL 惩罚项防止策略偏离参考模型太远，以保留语言能力并避免"奖励黑客（reward hacking）"；InstructGPT 的 PPO-ptx 变体还混入预训练损失以防止灾难性遗忘。

**直接偏好优化（Direct Preference Optimization, DPO, Rafailov et al. 2023）**指出 RLHF 目标下的最优策略有闭式解，因而可以跳过显式奖励模型、直接从偏好数据优化策略。其损失为 `L_DPO = −log σ( β·[ log(π_θ(y_w|x)/π_ref(y_w|x)) − log(π_θ(y_l|x)/π_ref(y_l|x)) ] )`，等价于在参考模型归一化空间中增大优胜回复的相对概率。DPO 无需在线采样、无需训练独立奖励模型，因而更简单、更稳定，其变体（IPO、KTO、ORPO）正迅速成为大语言模型对齐的标准方案。RLHF（PPO）与 DPO 的差异可总结为：前者三步流程、需在线采样与显式奖励模型、计算开销高但成熟验证，后者两步流程、仅用静态偏好数据、类似分类问题般稳定收敛。此外，**宪法 AI（Constitutional AI, RLAIF）**用 AI 依据"宪法"规则自我评判来替代人类标注，实现可扩展的自对齐；**SPIN（Self-Play Fine-Tuning）**通过自我对弈逐步提升；**ORPO（Odds Ratio Preference Optimization）**则把 SFT 与偏好对齐合并为单阶段。

## 7.11 本章小结

本章沿"模型已知 → 模型未知 → 深度化 → 前沿方法 → 系统与对齐"的脉络，梳理了强化学习的核心框架与算法谱系。贯穿始终的主线是三类权衡：**偏差与方差**（MC 与 TD、n 步回报）、**样本效率与稳定性**（在策略与离策略、自举与目标网络）、**探索与利用**（从 ε-greedy 到内在动机）。理解这些权衡，比记住某个具体算法更重要。

**核心要点回顾**

| 方法族 | 核心思想 | 在/离策略 | 代表算法与适用场景 |
|:---|:---|:---|:---|
| **动态规划 (DP)** | 已知完整模型，用 Bellman 方程迭代求解 | 需模型，无需采样 | 策略迭代、值迭代、异步 DP（小规模已知 MDP） |
| **蒙特卡洛 (MC)** | 用完整回合的实际回报平均估计值函数 | 在/离策略均可 | First-Visit/Every-Visit MC（回合制任务） |
| **时序差分 (TD)** | 一步奖励加自举值估计，在线低方差 | 取决于控制算法 | TD(0)、TD(λ)、SARSA、Q-Learning（通用无模型） |
| **深度值方法** | 神经网络逼近 Q，经验回放 + 目标网络 | 离策略 | DQN、Double/Dueling DQN、PER、Rainbow（离散高维） |
| **策略梯度** | 直接对策略参数求梯度，提升高回报动作概率 | 主要在策略 | REINFORCE、Actor-Critic、A2C/A3C（连续/随机策略） |
| **信赖域与剪裁** | 限制新旧策略差异，保证稳定改进 | 在策略 | TRPO、PPO（通用首选，含 RLHF） |
| **最大熵方法** | 最大化回报同时最大化策略熵 | 离策略 | SAC（连续控制 SOTA） |
| **世界模型** | 学习环境动态，在隐空间想象中训练策略 | 基于模型 | DreamerV1/V2/V3（样本稀缺、长时域） |
| **搜索与规划** | 神经网络先验与 MCTS 结合，压缩搜索 | 基于模型规划 | AlphaGo、AlphaZero、MuZero（棋类与通用决策） |
| **探索机制** | 用乐观、计数、好奇心或信息增益驱动探索 | 可叠加于任意算法 | ε-greedy、UCB、Thompson 采样、ICM/RND、Go-Explore |
| **离线 RL 与对齐** | 从静态数据或人类偏好中学习 | 离策略 / 偏好学习 | CQL、IQL、Decision Transformer、RLHF、DPO |

| 中文 | English | 一句话说明 |
|:---|:---|:---|
| 马尔可夫决策过程 | Markov Decision Process (MDP) | 用状态、动作、转移、奖励、折扣描述序贯决策的框架 |
| 马尔可夫性 | Markov Property | 下一状态只取决于当前状态与动作，与更早历史无关 |
| 折扣因子 | Discount Factor | 平衡即时奖励与未来奖励，无限时域下保证回报收敛 |
| 回报 | Return | 从某时刻起的累积折扣奖励 |
| 策略 | Policy | 从状态到动作（或动作分布）的映射 |
| 状态值函数 | State-Value Function | 从某状态出发按策略行动所得的期望折扣回报 |
| 动作值函数 | Action-Value Function | 在某状态先执行某动作再按策略行动所得的期望回报 |
| 贝尔曼方程 | Bellman Equation | 将值函数分解为即时奖励与下一状态值的递归关系 |
| 自举 | Bootstrapping | 用当前值估计来更新自身的方法 |
| 动态规划 | Dynamic Programming (DP) | 在已知模型下迭代求解 Bellman 方程 |
| 蒙特卡洛方法 | Monte Carlo (MC) | 用完整回合的实际回报估计值函数 |
| 时序差分 | Temporal Difference (TD) | 结合采样与自举、可在线更新的学习方法 |
| 资格迹 | Eligibility Trace | 记录状态访问新近程度以分配 TD 误差信用的机制 |
| 在策略 / 离策略 | On-Policy / Off-Policy | 采样策略与目标策略是否相同的区分 |
| 经验回放 | Experience Replay | 存储并随机重放转移以打破样本相关性 |
| 目标网络 | Target Network | 参数延迟更新的网络，用于稳定 TD 目标 |
| 优先级经验回放 | Prioritized Experience Replay (PER) | 按 TD 误差大小优先采样关键转移 |
| 竞争网络 | Dueling Network | 将 Q 分解为状态价值与动作优势的架构 |

| 广义优势估计 | Generalized Advantage Estimation (GAE) | 用指数加权多步 TD 误差折中偏差与方差 |
| 策略梯度 | Policy Gradient | 直接对策略参数求期望回报梯度的方法 |
| 演员-评论家 | Actor-Critic | 策略网络与价值网络协同学习的架构 |
| 信赖域 / 剪裁 | Trust Region / Clipping | 限制策略更新幅度的机制，如 TRPO 的 KL 约束与 PPO 的 clip |
| 最大熵强化学习 | Maximum Entropy RL | 在回报目标中加入策略熵以鼓励探索 |
| 世界模型 | World Model | 学习环境动态并在隐空间中进行规划或想象 |
| 蒙特卡洛树搜索 | Monte Carlo Tree Search (MCTS) | 用随机模拟与统计选择引导的启发式搜索 |
| 探索-利用权衡 | Exploration-Exploitation Trade-off | 在尝试新动作与利用已知最优间的取舍 |
| 离线强化学习 | Offline RL | 仅从固定静态数据集学习策略，不与环境在线交互 |
| 基于人类反馈的强化学习 | Reinforcement Learning from Human Feedback (RLHF) | 用人类偏好训练奖励模型并优化语言模型的对齐流程 |
| 直接偏好优化 | Direct Preference Optimization (DPO) | 跳过显式奖励模型、直接从偏好数据优化策略 |
