# 第 26 章 机器人学（Robotics）

**本章导读**：机器人是 AI 的"具身"形态：它必须在物理世界中感知、规划、行动，并承担错误的后果。本章按"身体 → 问题 → 感知 → 规划控制 → 不确定性 → 学习 → 人机关系"展开。它与前几章的分工是：第 3–6 章提供搜索与 CSP，第 11 章提供规划，第 14 章提供状态估计，第 17 章提供 POMDP，第 21–22 章提供学习——机器人学是把这些**装进闭环**的工程学科。

**学习目标**：完成本章学习后，你应当能够：

- 描述机器人的执行器、传感器与自由度，说明非完整约束的含义；
- 把机器人任务分解为状态估计、规划、控制三个子问题；
- 用贝叶斯滤波统一描述定位与 SLAM；
- 实现 PID 与 MPC 的基本形式，说明各自的适用条件；
- 用 RRT/PRM 做高维运动规划，说明概率完备性的含义；
- 说明不确定运动规划与 POMDP 的关系；
- 判断强化学习在机器人中的适用场景与 sim-to-real 的难点；
- 讨论人机协作中的安全、信任与责任问题。

**预备知识**：第 14 章的状态估计；第 17 章的 MDP/POMDP；第 25 章的视觉；线性代数与控制基础（状态空间、稳定性）。

---

## 26.1 机器人

**机器人的三个组成部分**：

1. **身体（body）**：机械结构、关节、执行器；
2. **感知（perception）**：传感器与状态估计；
3. **大脑（brain）**：规划、控制、学习。

**分类维度**：

| 维度 | 类型 |
| --- | --- |
| 运动方式 | 轮式、腿式、飞行、水下、轨道 |
| 工作空间 | 工业机械臂、移动机器人、人形 |
| 自主程度 | 遥操作、半自主、全自主 |
| 环境 | 结构化（工厂）vs 非结构化（野外/家庭） |

**AIMA 的机器人学定义**：机器人是"能感知环境并作用于环境的物理智能体"。关键词是**物理**——这意味着：

- 动作有**后果**（碰撞、损坏、伤人）；
- 感知有**噪声与延迟**；
- 世界**连续且高维**；
- 计算与能量**受限**。

**应用谱**：工业焊接/装配、物流分拣、手术辅助、农业采摘、巡检、配送、家庭服务、太空与深海探索。

## 26.2 机器人硬件

**执行器（actuators）**：

| 类型 | 特点 | 用途 |
| --- | --- | --- |
| 直流/无刷电机 | 高转速、需减速器 | 关节、轮子 |
| 步进电机 | 开环定位 | 3D 打印机、轻负载 |
| 舵机 | 集成控制 | 小型机器人 |
| 液压/气动 | 高力矩 | 重载、仿生 |
| 形状记忆合金/人工肌肉 | 柔性 | 研究、软体机器人 |

**传感器（sensors）**：

| 类别 | 例子 | 测量 |
| --- | --- | --- |
| 本体感受 | 编码器、IMU、力矩传感器 | 关节角、加速度、力 |
| 外部感知 | 摄像头、激光雷达、超声、ToF | 环境几何与外观 |
| 触觉 | 电容/压阻阵列、GelSight | 接触位置与力分布 |
| 定位 | GPS、UWB、磁导航 | 全局位置 |

**自由度（DOF）** 与**构型空间（configuration space, C-space）**：

- $n$ 个独立关节 → $n$ 维构型空间；
- **工作空间**（task space）是末端执行器可达的位姿集合；
- 映射 $\text{FK}: \mathcal{C} \to \text{SE}(3)$（正运动学），逆映射是**逆运动学（IK）**，可能无解或多解。

**非完整约束（nonholonomic）**：约束在**速度**层面不可积，如汽车不能横移、独轮车不能侧滑。它使"构型空间中的直线"不可行，运动规划必须考虑**可行路径**（Dubins 曲线、Reeds–Shepp 曲线）。

**欠驱动（underactuated）**：自由度多于执行器（如人形机器人、无人机），控制难度显著提升，需要利用动力学而非仅靠位置控制。

## 26.3 机器人学是什么样的问题？

把机器人任务拆成三个耦合的子问题：

| 子问题 | 问题形式 | 主要工具 |
| --- | --- | --- |
| **状态估计** | 由带噪观测推断位姿/地图 | 贝叶斯滤波（第 14 章） |
| **规划** | 找从当前到目标的可行路径/动作序列 | 搜索、采样规划、优化（第 3、11 章） |
| **控制** | 在扰动下跟踪轨迹 | PID、LQR、MPC |

**三者不是串行流水线**，而是闭环：

```
感知 → 估计 → 规划 → 控制 → 执行 → 世界变化 → 感知 …
```

**分层架构**（工程常用）：

| 层 | 时间尺度 | 内容 |
| --- | --- | --- |
| 任务层 | 秒–分 | 任务分解、调度（HTN，§11.4） |
| 运动层 | 0.1–1 s | 路径规划、轨迹优化 |
| 控制层 | 1–10 ms | 关节伺服、力矩控制 |

**为什么机器人比下棋难**：

- 状态连续且部分可观测（POMDP，§17.4）；
- 动作空间连续且受动力学约束；
- 误差累积、延迟、噪声；
- 试错代价高，仿真与现实有差距。

## 26.4 机器人感知

**定位（localization）**：已知地图，估计位姿。用贝叶斯滤波：

- **马尔可夫定位**：离散网格上的直方图滤波；
- **卡尔曼定位**：线性高斯假设下的连续版本；
- **蒙特卡洛定位（AMCL）**：粒子滤波，支持多峰与全局定位（"绑架问题"）。

**SLAM（同时定位与建图）**：地图未知时，位姿与地图必须**联合估计**：

$$P(x_{1:t}, m \mid z_{1:t}, u_{1:t})$$

| 方法 | 思路 | 代表 |
| --- | --- | --- |
| EKF-SLAM | 把地图点加入状态向量 | 早期方法，$O(n^2)$ |
| 粒子 SLAM（FastSLAM） | 粒子表示轨迹，每粒子一张地图 | 大规模、结构化 |
| 图优化（pose graph） | 位姿为节点、约束为边，最小二乘 | 现代主流（g2o、GTSAM、Cartographer） |
| 视觉/激光惯性 | 多传感器紧耦合 | ORB-SLAM3、LIO-SAM、VINS |

**图优化的目标**：

$$\min_{\{x_i\}} \sum_{(i,j)\in\mathcal{E}} \big\| e_{ij}(x_i, x_j, z_{ij}) \big\|^2_{\Omega_{ij}}$$

即最小化所有观测残差的马氏距离。**回环检测**（词袋、NetVLAD、扫描上下文）提供长程约束，消除漂移。

**感知的其他任务**：障碍物检测与跟踪（§25.5）、可通行区域分割、抓取位姿检测（6-DoF grasp）、触觉反馈。

**多传感器融合**：卡尔曼滤波/因子图融合 IMU（高频、漂移）与视觉/激光（低频、绝对），是 VIO/LIO 的核心。

## 26.5 规划与控制

**（1）控制：PID**。

$$u(t) = K_p e(t) + K_i\int_0^t e(\tau)d\tau + K_d \frac{de}{dt}$$

| 项 | 作用 | 副作用 |
| --- | --- | --- |
| $P$ | 快速响应 | 稳态误差、振荡 |
| $I$ | 消除稳态误差 | 积分饱和、超调 |
| $D$ | 抑制振荡 | 放大噪声 |

工程要点：**抗积分饱和**（clamping/back-calculation）、微分滤波、增益调度。PID 简单、无需模型，是关节伺服的主力。

**（2）基于模型的控制：LQR 与 MPC**。

- **LQR**：线性系统 + 二次代价，解 Riccati 方程得最优反馈 $u = -Kx$；
- **MPC（模型预测控制）**：每步求解有限时域优化

$$\min_{u_{0:H-1}} \sum_{k=0}^{H-1} \big(x_k^\top Q x_k + u_k^\top R u_k\big) + x_H^\top Q_f x_H \quad \text{s.t. 动力学与约束}$$

只执行第一步，下一步重算（滚动时域）。优点：**显式处理约束**（避障、力矩上限），是自动驾驶与机械臂的主流。缺点：计算量大，需实时求解器（如 OSQP、acados）。

**（3）运动规划**：

| 方法 | 类型 | 特点 |
| --- | --- | --- |
| A\*/Dijkstra | 图搜索 | 需离散化，最优（在图上） |
| 势场法 | 反应式 | 简单，但易陷入局部极小 |
| **RRT** | 采样式 | 快速探索，**概率完备**，非最优 |
| RRT\* | 采样式 | 渐近最优 |
| **PRM** | 采样式 | 多查询场景，预处理路图 |
| CHOMP/TrajOpt | 优化式 | 平滑轨迹，可加约束 |
| 轨迹优化（MINCO 等） | 优化式 | 满足动力学与避障，实时性好 |

**RRT 的骨架**：从起点生长树，每次随机采样 $q_\text{rand}$，找最近节点 $q_\text{near}$，向它扩展一步 $q_\text{new}$，若边无碰撞则加入树；到达目标邻域即成功。

**概率完备性**：采样次数趋于无穷时，找到解的概率趋于 1（若解存在）。它**不保证**找到最优解，也不保证有限时间。

**（4）抓取与操作**：解析法（力闭合、形闭合）+ 学习方法（GG-CNN、GraspNet、扩散策略）。**灵巧操作**仍是开放问题。

## 26.6 不确定运动规划

真实机器人的动作**不确定**（轮子打滑、执行器噪声、人推了一把），且感知**部分可观测**。这与第 4 章、第 17 章直接对应。

**（1）不确定动作下的规划**：用 **MDP** 或**与或搜索**（§4.3）。目标是**策略**而非路径：对每个可能的结果都有应对。

**（2）信念空间规划**：用 **POMDP**（§17.4）。状态是信念 $b$，动作会改变信念（主动感知）。难点是信念空间连续高维，实践中用：

| 方法 | 思路 |
| --- | --- |
| 信念树搜索 | 采样观测分支（POMCP） |
| 机会约束规划 | 以高概率满足避障约束（$\text{Prob} \ge 1-\delta$） |
| 鲁棒规划 | 对最坏扰动保证安全（管状 MPC） |
| 反应式安全层 | 用控制屏障函数（CBF）做最后防线 |

**（3）不确定性来源与应对**：

| 来源 | 例子 | 应对 |
| --- | --- | --- |
| 执行噪声 | 轮子打滑 | 反馈控制、MDP |
| 感知噪声 | 定位漂移 | 滤波、多传感器融合 |
| 环境动态 | 行人走动 | 预测 + 重规划 |
| 模型误差 | 摩擦参数不准 | 自适应控制、在线辨识 |

**（4）安全约束**。机器人的"不可逆代价"要求**硬约束**而非仅期望最优：

- **控制屏障函数（CBF）**：构造 $h(x) \ge 0$ 的安全集，约束控制使 $\dot h + \alpha h \ge 0$；
- **安全层（shield）**：在策略输出后加一层"过滤"，禁止危险动作；
- **可达性分析**：计算"无论怎么控制都不可避免"的状态集，用于保守规划。

## 26.7 机器人中的强化学习

**为什么用 RL**：许多任务（灵巧操作、行走、飞行特技）难以手工设计控制器，但可以用仿真大量试错。

**典型流程**：

```
仿真环境 → 域随机化 → 并行采样 → 策略优化（PPO/SAC）→ 部署 → 在线微调
```

**关键挑战与技术**：

| 挑战 | 说明 | 技术 |
| --- | --- | --- |
| 样本效率 | 真实交互昂贵 | 仿真、并行、基于模型 |
| **仿真到现实（sim-to-real）** | 仿真与现实的物理差异 | 域随机化、系统辨识、域适应 |
| 奖励设计 | 稀疏奖励难学 | 奖励塑形、课程学习、模仿学习 |
| 安全 | 探索可能损坏硬件 | 约束 MDP、安全层、仿真预筛 |
| 部分可观测 | 真实传感器有噪声与延迟 | RNN 策略、非对称 Actor-Critic |

**模仿学习（imitation）**：遥操作采集示范 → 行为克隆/DAgger（§22.6）→ 部署。优点是数据效率高，缺点是需要人采集且分布偏移。

**扩散策略（diffusion policy）**：把动作生成建模为去噪过程，能表达**多模态**动作分布（同一位置有多种抓法），在精细操作中表现优于单峰高斯策略。

**世界模型（附录 E.4）**：在潜在空间预测未来，用"想象"训练策略（Dreamer 系列），提升样本效率。

**分层与组合**：高层用符号规划选任务（§11.4），低层用 RL/MPC 执行；这是当前机器人系统最务实的架构。

## 26.8 人类与机器人

**人机交互（HRI）** 的核心问题是**共同理解**：人如何知道机器人要做什么，机器人如何理解人的意图。

**关键议题**：

| 议题 | 内容 |
| --- | --- |
| 安全 | 人机共处的物理安全（ISO 10218/TS 15066 的协作机器人标准） |
| 可预测性 | 动作意图可读（legibility）、运动平滑 |
| 信任与校准 | 过度信任导致误用，不信任导致弃用 |
| 自然交互 | 语音、手势、视线、示范教学 |
| 价值对齐 | 机器人服务谁的目标？冲突时如何取舍（§16、§27.3） |

**安全设计的工程原则**：

1. **本质安全**：限速、限力、柔性材料、圆角；
2. **冗余感知**：多传感器交叉验证；
3. **失效安全（fail-safe）**：断电/通信中断时进入安全状态；
4. **人在回路**：关键决策需人类确认（如手术、载人）；
5. **可解释**：给出"为什么这么做"的理由（第 27 章）。

**伦理与治理**：

- **责任归属**：事故由制造商、运营者还是算法开发者承担？
- **隐私**：家庭机器人的摄像头与数据；
- **自主武器**：致命性自主武器的国际讨论；
- **就业与再培训**：自动化对劳动市场的影响（§27.3）。

**未来方向**：通用机器人基础模型（RT-2、π0 类视觉-语言-动作模型）、跨形态迁移、长程任务自主、与人协作的社会规范。

## 本章小结

**核心要点**

1. 机器人 = 身体 + 感知 + 决策；物理性带来**后果、噪声、连续高维与资源约束**。
2. 任务分解为**状态估计、规划、控制**三层，闭环耦合而非串行。
3. **SLAM** 联合估计位姿与地图，现代主流是**因子图优化 + 回环检测**。
4. **PID** 简单鲁棒，**MPC** 显式处理约束，是高动态任务的主流。
5. **RRT/PRM** 概率完备、适合高维；优化式方法给出平滑可行轨迹。
6. 不确定环境用 **MDP/POMDP**，安全关键场景需**硬约束**（CBF、shield、可达性分析）。
7. RL 在机器人中的瓶颈是**样本效率与 sim-to-real**；模仿学习、域随机化、世界模型是主要手段。
8. 人机共处要求**安全、可预测、可解释与责任清晰**。
