# 第 9 章 一阶逻辑中的推理（Inference in First-Order Logic）

**本章导读**：有了 FOL 的知识，接下来要让它"能动"——从公理推出结论。直接的思路是把 FOL 命题化（用所有可能的项实例替换量词），但那会无穷膨胀。本章的三条主线逐级提升效率：**命题化 + 合一**得到提升推理（lifted inference），**前向链接**从事实推结论，**后向链接**从目标找证据，**归结**则是一条规则覆盖全部。它们分别对应产生式系统、Prolog 与通用定理证明器。

**学习目标**：完成本章学习后，你应当能够：

- 写出全称/存在量词的实例化规则与量词等价律；
- 说明命题化的代价，以及 Herbrand 定理的意义；
- 实现合一算法并求出最一般合一子（MGU）；
- 用提升版 Modus Ponens 做一阶推理，解释"提升"的含义；
- 描述前向链接与后向链接的算法流程、复杂度与适用边界（Datalog、Prolog）；
- 把 FOL 公式化为 CNF（含 Skolem 化），用归结证明并抽取答案。

**预备知识**：第 8 章的语法与语义；第 7 章的归结与 Horn 子句；替换与递归的基本概念。

---

## 9.1 命题推理与一阶推理

**最朴素的方法：命题化（propositionalization）**。把 FOL 知识库转成命题逻辑：

- **全称实例化（universal instantiation, UI）**：
$$\frac{\forall x\, \alpha(x)}{\text{SUBST}(\{x/\tau\}, \alpha)}$$
其中 $\tau$ 是任意**基项**（无变量的项）。一个全称句子蕴含无穷多个实例。

- **存在实例化（existential instantiation, EI）**：
$$\frac{\exists x\, \alpha(x)}{\text{SUBST}(\{x/k\}, \alpha)}$$
其中 $k$ 是一个**新常量**（Skolem 常量），且该常量在整个证明中只能用于这一处。直觉：既然存在某物满足 $\alpha$，就给它起个名字。

**量词的等价律**（与德摩根对偶）：

$$\neg\forall x\,\alpha \equiv \exists x\,\neg\alpha \qquad \neg\exists x\,\alpha \equiv \forall x\,\neg\alpha$$
$$\forall x\,\alpha \land \forall x\,\beta \equiv \forall x\,(\alpha \land \beta) \qquad \exists x\,\alpha \lor \exists x\,\beta \equiv \exists x\,(\alpha \lor \beta)$$
$$\forall x\,\alpha \lor \beta \equiv \forall x\,(\alpha \lor \beta)\ (x \notin \text{free}(\beta)) \qquad \exists x\,\alpha \land \beta \equiv \exists x\,(\alpha \land \beta)\ (x \notin \text{free}(\beta))$$

**命题化的三个问题**：

1. **无穷实例**：$\forall x\, \text{Nat}(x) \Rightarrow \text{Nat}(S(x))$ 有无穷多实例；
2. **命题数爆炸**：$k$ 个项、$p$ 个谓词可产生 $O(p k^r)$ 个基原子；
3. **丢失结构**：命题化后无法复用"对所有 $x$ 都成立"这一事实。

**Herbrand 定理**给出一线希望：若子句集不可满足，则存在**有限**的基实例集不可满足。因此"命题化 + 命题归结"是**完备**的——但可能永不终止（因为要枚举越来越多的项）。这解释了 FOL 的半可判定性。

**结论**：命题化在理论上可行，在工程上不可行。需要**合一**。

## 9.2 合一与一阶推理

**替换（substitution）** 是变量到项的映射，如 $\theta = \{x/\text{John}, y/\text{Father}(z)\}$。把它作用于表达式，写作 $\text{SUBST}(\theta, \alpha)$。

**合一（unification）**：求替换 $\theta$ 使两个表达式相同，即 $\text{SUBST}(\theta, p) = \text{SUBST}(\theta, q)$。**最一般合一子（most general unifier, MGU）** 是限制最少、能导出其他所有合一子的那个。

例如：

| 待合一 | MGU |
| --- | --- |
| $\text{Knows}(\text{John}, x)$ 与 $\text{Knows}(y, \text{Jane})$ | $\{y/\text{John},\ x/\text{Jane}\}$ |
| $\text{Knows}(\text{John}, x)$ 与 $\text{Knows}(y, \text{Mother}(y))$ | $\{y/\text{John},\ x/\text{Mother}(\text{John})\}$ |
| $\text{Knows}(x, x)$ 与 $\text{Knows}(y, \text{John})$ | 失败（occurs check 阻止 $\{x/\text{John}, y/\text{John}\}$ 以外的解） |

**合一算法**（递归）：

```
function UNIFY(x, y, θ):
    if θ = failure: return failure
    if x = y: return θ
    if x 是变量: return UNIFY-VAR(x, y, θ)
    if y 是变量: return UNIFY-VAR(y, x, θ)
    if x, y 都是复合式且谓词/函数相同:
        return UNIFY(ARGS(x)[2:], ARGS(y)[2:], UNIFY(ARGS(x)[1], ARGS(y)[1], θ))
    return failure

function UNIFY-VAR(var, x, θ):
    if var 已在 θ 中: return UNIFY(θ[var], x, θ)
    if x 已包含 var: return failure        # occurs check
    return θ ∪ {var/x}
```

**提升版 Modus Ponens（generalized modus ponens, GMP）**：

$$\frac{p_1', \dots, p_n',\quad (q_1 \land \cdots \land q_n \Rightarrow r)}{\text{SUBST}(\theta, r)} \quad \text{其中 } \text{UNIFY}(p_i', q_i) = \theta$$

例：已知 $\text{King}(\text{John})$、$\text{Greedy}(y)$、"$\text{King}(x) \land \text{Greedy}(x) \Rightarrow \text{Evil}(x)$"，MGU $\theta = \{x/\text{John}, y/\text{John}\}$，推出 $\text{Evil}(\text{John})$。

"**提升（lifting）**"的含义：一阶推理把"命题级的规则应用"提升到"合一后的模式匹配"，一次推理覆盖无限多实例。

**关键定理**：GMP 是**可靠的**；对 Horn 子句知识库是**完备的**（不需归结）。这使它成为逻辑程序设计与产生式系统的推理引擎。

## 9.3 前向链接

**前向链接（forward chaining）** 是数据驱动的推理：从已知事实出发，反复应用规则，直到没有新事实可推。

```
function FC(KB, 新事实):
    agenda ← 新事实
    while agenda 非空:
        p ← agenda.pop()
        if p 未被记录:
            记录 p
            for 每个匹配 p 的规则前提:
                若该规则所有前提已知:
                    结论 q ← SUBST(θ, 规则结论)
                    if q 是新的: agenda.push(q)
            for 每个匹配 p 的查询: 报告已解答
```

**Datalog**：前向链接的典型语言，是**无函数符号的 Horn 子句**子集，即规则形如

$$\text{Ancestor}(x,y) \Leftarrow \text{Parent}(x,y)$$
$$\text{Ancestor}(x,z) \Leftarrow \text{Parent}(x,y) \land \text{Ancestor}(y,z)$$

Datalog 的性质：

- **可判定**：无函数符号 ⇒ 基原子数有限；
- **数据复杂度**：$O(|R| \cdot |\text{DB}|)$ 级别，可高效实现；
- **递归查询**：支持传递闭包（如祖先、可达性），这是 SQL 早期版本难以表达的；
- **语义**：最小不动点（least fixed point），即"能推出的事实集合"。

**增量维护**：Datalog 引擎（如 Soufflé）用半朴素求值（semi-naive evaluation）避免重复推导；产生式系统（Rete 算法）为每次事实更新只重算受影响的规则。

**专家系统中的前向链接**：

- 优点：数据到来即可推理，适合监控、告警、实时决策；
- 缺点：可能推出大量无关结论，**目标导向弱**；
- 典型应用：MYCIN 类诊断（从症状推结论）、风控规则引擎、网络入侵检测。

**前向链接与查询**：若知识库含 $10^6$ 条事实，前向链接会把所有结论都算出来，即使你只关心一个查询。此时后向链接更合适。

## 9.4 后向链接

**后向链接（backward chaining）** 是目标驱动的推理：从查询出发，寻找能推出它的规则，把规则前提作为新的子目标（subgoal），递归求解。

```
function BC(KB, goal, θ):
    for 每个 (规则, 标准化的变量):
        若规则结论与 goal 合一（MGU = θ'）:
            if 规则前提为空: return θ'
            else:
                θ'' ← BC(KB, 规则前提, COMPOSE(θ, θ'))
                if θ'' ≠ failure: return θ''
    return failure
```

**与逻辑程序设计（Prolog）的对应**：

| 逻辑概念 | Prolog 语法 |
| --- | --- |
| 事实 $\text{Parent}(\text{John}, \text{Mary})$ | `parent(john, mary).` |
| 规则 $\text{Ancestor}(x,z) \Leftarrow \text{Parent}(x,y) \land \text{Ancestor}(y,z)$ | `ancestor(X,Z) :- parent(X,Y), ancestor(Y,Z).` |
| 查询 $\exists x\, \text{Ancestor}(\text{John}, x)$ | `?- ancestor(john, X).` |

**Prolog 的工程现实**：

- **深度优先 + 子句顺序**：搜索顺序由程序书写顺序决定，可能陷入无限递归（左递归规则）；
- **无 occurs check**（多数实现）：$\text{Unify}(x, f(x))$ 会构造无限项，需程序员避免；
- **否定即失败（negation as failure）**：`\+ Goal` 表示"无法证明"，而非"证明为假"——这是非单调推理的入口（§10.6）；
- **割（cut, `!`）**：控制搜索，破坏逻辑纯洁性但提升效率。

**后向链接 vs 前向链接**：

| 维度 | 前向链接 | 后向链接 |
| --- | --- | --- |
| 驱动 | 数据（事实） | 目标（查询） |
| 适合 | 事实多、规则少、实时更新 | 查询明确、规则多、事实少 |
| 风险 | 推导无关结论 | 无限递归、重复子目标 |
| 典型系统 | Rete、Datalog、规则引擎 | Prolog、SLD 归结、定理证明器 |

**优化**：子目标缓存（memoization）避免重复计算；迭代加深避免无限递归；**表格化逻辑编程（tabling）** 如 XSB，把 SLD 与动态规划结合，可处理左递归并保证终止（对 Datalog 片段）。

## 9.5 归结

**归结**是唯一一条既可靠又反驳完备的规则，可覆盖全部 FOL。

**化为 CNF 的步骤**：

1. 消去 $\Rightarrow$、$\Leftrightarrow$；
2. 内移否定（德摩根、量词对偶）；
3. **变量标准化**：不同量词用不同变量名；
4. **Skolem 化**：删去存在量词，用 Skolem 函数替换。$\forall x \exists y\, P(x,y)$ → $\forall x\, P(x, f(x))$；若 $\exists$ 不在任何 $\forall$ 辖域内，则用 Skolem 常量。
5. 删去全称量词（所有变量默认全称量化）；
6. 分配律把公式化为子句合取。

**Skolem 化的正确性**：它**保持可满足性**（不是逻辑等价）。因此它适用于反证法：$KB \land \neg\alpha$ 不可满足 ⟺ Skolem 化后不可满足。

**归结规则**（一阶版）：

$$\frac{\ell_1 \lor \cdots \lor \ell_k,\quad m_1 \lor \cdots \lor m_n}{\text{SUBST}(\theta,\ \ell_1 \lor \cdots \lor \ell_{i-1} \lor \ell_{i+1} \lor \cdots \lor \ell_k \lor m_1 \lor \cdots \lor m_{j+1} \lor \cdots \lor m_n)}$$

其中 $\text{UNIFY}(\ell_i, \neg m_j) = \theta$。若一个子句内部有两个可合一的文字（如 $P(x) \lor P(a)$），需先做**因子化（factoring）**，否则不完备。

**归结反演与答案抽取**：

- 证明 $KB \models \exists x\, Q(x)$：加入 $\neg Q(x)$（Skolem 化为 $\neg Q(c)$），归结出空子句；
- **抽取答案**：把目标否定写成 $\neg Q(x) \lor \text{Answer}(x)$，归结完成后 $\text{Answer}$ 的参数即为答案项。这在程序合成与问答系统中很实用。

**搜索策略**（决定实用性的关键）：

| 策略 | 说明 |
| --- | --- |
| 单元优先（unit preference） | 优先用单文字子句归结，子句变短快 |
| 支撑集（set of support） | 只让与目标相关的子句参与归结 |
| 线性归结 | 每步至少用一个"新"子句，形成链 |
| 超归结（hyperresolution） | 一次归结多个负文字，适合 Horn |
| 包含删除 | 若子句 $A$ 包含子句 $B$，删 $A$ |

**复杂度**：一般 FOL 归结是半可判定的；对 Datalog 是多项式数据复杂度；对命题逻辑是指数（但 CDCL 实践中很好）。

## 本章小结

**核心要点**

1. **命题化**（UI/EI）理论完备但实例无穷，实践中不可行；Herbrand 定理只保证"有限子集存在"，不告诉你怎么找。
2. **合一 + MGU** 是一次匹配覆盖无穷实例的关键；GMP 是提升推理的核心规则。
3. **前向链接**数据驱动，Datalog 可判定、支持递归，适合规则引擎与监控；代价是推导无关结论。
4. **后向链接**目标驱动，是 Prolog 的推理机制；需处理递归、重复子目标与"否定即失败"。
5. **归结**一条规则覆盖 FOL：CNF + Skolem 化 + 合一 + 因子化，反驳完备；实用性取决于搜索策略。
6. 三者适用面不同：Datalog ⊂ Horn ⊂ FOL；工程上优先选可判定片段。
