# 第 27 章 人工智能的哲学与伦理（Philosophy and Ethics of AI）

**本章导读**：技术能力越强，"应该做什么"的问题就越尖锐。本章分三段：先讨论 AI 的**原理性极限**（可计算性、复杂性、常识与因果），再回到图灵测试与中文屋的经典论争，最后系统处理**伦理与治理**——公平、可解释、隐私、安全对齐、法规与社会影响。这一章没有算法，但它决定了前面 26 章的技术能否被社会接受。

**学习目标**：完成本章学习后，你应当能够：

- 区分"原理上不可能""计算上不可行""工程上未解决"三类极限；
- 复述图灵测试、中文屋、洛弗莱斯反驳的核心论点与反驳；
- 说明意识、理解与功能主义的争论为何难以实证；
- 用公平性度量诊断算法偏见，并说明其不可兼得性；
- 区分可解释性的三类方法（内在、事后、示例）；
- 说明隐私保护的三条技术路线与差分隐私的直觉；
- 描述 AI 安全的核心问题（规范博弈、分布偏移、欺骗性对齐）与治理工具；
- 讨论就业、信息生态、权力集中与责任分配的社会议题。

**预备知识**：第 1 章的历史与流派；第 19 章的学习理论；第 21–22 章的大模型与对齐；基本的伦理学与法学术语。

## 27.1 人工智能的极限

**三类极限要分清**：

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| **原理性** | 数学上不可能 | 停机问题、一阶逻辑的判定问题、哥德尔不完备 |
| **计算复杂性** | 理论可解但资源不可承受 | SAT 的 NP 完全、POMDP 的 PSPACE 完全 |
| **工程性** | 尚无可行方法 | 常识推理、开放世界泛化、数据高效学习 |

**可计算性的边界**：图灵机定义了"可计算"，停机问题说明存在不可判定问题。AI 不可能"计算一切"，但**这不构成对智能的实质限制**——人类也做不到。

**复杂性的边界**：NP 完全与 #P 难说明许多推理问题在实践中需要启发式与近似。这正是本系列反复出现"不完备但可用"的算法的原因。

**常识问题（common sense）**：人类拥有海量未言明的背景知识（物理直觉、社会规范、意图推断）。让机器获得常识有两条路：

- **手工编码**：Cyc 项目数十年的尝试，规模巨大但覆盖有限；
- **从数据学习**：大模型学到了大量统计规律，但在**反事实、因果、物理直觉**上仍脆弱。

**因果与相关性**：模型学到 $P(y \mid x)$，但决策需要 $P(y \mid do(x))$（§13.6、附录 D）。缺乏因果结构是**分布外泛化失败**的深层原因之一。

**框架问题与符号接地（symbol grounding）**：符号系统如何与真实世界对应？纯文本训练的模型是否"理解"词的意义？这是哲学问题，也是工程问题（多模态、具身学习试图绕过它）。

**哥德尔式的论证**：卢卡斯-彭罗斯认为"人能看出哥德尔句为真，机器不能"，因此机器不如人。主流反驳是：该论证假设了"人不会犯错且能证明自身一致性"，而人类实际上也不可靠。

## 27.2 机器能思考吗？

**图灵测试（1950）**：若人类询问者通过文字对话无法区分机器与人，则认为机器具有智能。

| 批评 | 内容 |
| --- | --- |
| 模仿游戏不等于思考 | 会聊天 ≠ 会思考 |
| 取巧 | 反问、幽默、回避可骗过询问者 |
| 文化偏见 | 测试依赖人类语言与文化 |
| **总图灵测试** | 增加物理交互与感知，更能检验"具身智能" |

**中文屋（Searle, 1980）**：一个人在屋里按规则手册处理中文符号，输入输出看似懂中文，但他并不理解。

- **强 AI 主张**：正确程序本身就是心智；
- **Searle 的结论**：符号操作不足以产生**语义理解**（syntax is not semantics）。

**反驳与再反驳**：

| 论证 | 内容 |
| --- | --- |
| 系统回复 | 理解属于"整个人 + 手册 + 房间"系统，不属个人 |
| 机器人回复 | 加上与世界的交互后就有理解 |
| 大脑模拟器回复 | 若逐神经元模拟大脑，应当有意识 |
| 速度/复杂度回复 | 人类理解也依赖大量无意识处理 |

**功能主义 vs 生物自然主义**：前者认为心智由**功能组织**决定，实现基质无关；后者认为意识依赖特定生物基础。这场争论**目前无法用实验裁决**——这正是它属于哲学的原因。

**意识的"困难问题"（Chalmers）**：为什么信息处理会伴随主观体验（qualia）？即使完全理解大脑机制，也未必能回答"为什么有这个感觉"。

**对 AI 实践的意义**：

1. 不必等"意识问题"解决，就可以评估能力与风险；
2. 但**道德地位**问题会随系统复杂度上升（若某系统可能有痛苦，如何对待？）；
3. 工程上更实用的是**能力评估**（基准、鲁棒性、可靠性），而非"是否真懂"。

## 27.3 人工智能伦理

### 27.3.1 公平性

**偏见的来源**：

| 来源 | 例子 |
| --- | --- |
| 历史数据偏差 | 招聘数据中男性占比高 |
| 标注偏差 | 标注者对少数群体判断不一致 |
| 特征代理 | 用邮编代理种族 |
| 优化目标 | 最大化准确率牺牲少数群体 |

**公平性度量**（互相冲突，不能同时满足）：

| 度量 | 定义 |
| --- | --- |
| 人口均等（demographic parity） | 各群体正例率相同 |
| 机会均等（equal opportunity） | 各群体真阳率相同 |
| 均等几率（equalized odds） | 真阳率与假阳率都相同 |
| 预测均等（predictive parity） | 各群体精确率相同 |
| 个体公平 | 相似个体得到相似对待 |

**不可能定理**：当基础比率不同时，上述若干度量**数学上不可兼得**。因此"公平"必须先明确**价值判断**：是补偿历史不公，还是坚持形式平等？

**工程做法**：

1. **定义受保护群体与关键指标**（不能只看总体准确率）；
2. **分层评估**：报告每组的 TPR/FPR/校准误差；
3. **缓解**：预处理（重采样、去偏表示）、训练中（公平约束）、后处理（阈值调整）；
4. **持续审计**：数据分布变化会使公平性失效。

### 27.3.2 可解释性

**为什么需要**：合规（"有权获得解释"，如 GDPR）、调试、信任、责任归属。

**三类方法**：

| 类型 | 做法 | 例子 |
| --- | --- | --- |
| 内在可解释 | 模型本身简单 | 线性模型、决策树、GAM |
| 事后解释 | 解释黑箱的输出 | SHAP、LIME、Integrated Gradients、反事实解释 |
| 示例解释 | 用相似样本说明 | 原型网络、kNN 解释 |

**SHAP**：基于 Shapley 值（§18.3）分配特征贡献，满足**效率性、对称性、虚拟性、可加性**。代价是计算昂贵（用采样近似）。

**反事实解释**："如果收入再高 5000，贷款就会通过"——比特征重要度更符合人类因果直觉。

**解释的陷阱**：

- **解释 ≠ 因果**：特征重要度高不代表干预该特征会改变结果；
- **解释可被操纵**：模型可以"编造"看似合理的解释；
- **解释的稳定性**：输入微扰可能导致解释剧变；
- **人类误读**：解释会提高信任，即使模型是错的（自动化偏见）。

### 27.3.3 隐私保护

**三类技术**：

| 技术 | 思路 | 保证 |
| --- | --- | --- |
| **差分隐私（DP）** | 输出对单条记录的加入/删除不敏感 | 可证明的隐私预算 $\varepsilon$ |
| **联邦学习** | 数据不出本地，只传梯度/参数 | 避免集中存储，但梯度仍可能泄露 |
| **同态加密 / 安全多方计算** | 在密文上计算 | 强隐私，代价是性能 |

**差分隐私的定义**（$\varepsilon$-DP）：对任意相邻数据集 $D, D'$ 与任意输出集 $S$，

$$P[\mathcal{M}(D) \in S] \le e^{\varepsilon}\,P[\mathcal{M}(D') \in S]$$

实现手段：拉普拉斯/高斯机制加噪、隐私会计（composition）、DP-SGD。

**隐私的现实风险**：

- **成员推断**：判断某条记录是否在训练集中；
- **模型反演**：从模型重建训练样本（人脸、文本）；
- **记忆与 regurgitation**：大模型逐字复现训练数据。

**取舍**：隐私预算 $\varepsilon$ 越小越私密、效用越低；联邦学习不等于隐私（梯度可被反演），需与 DP 组合。

### 27.3.4 AI 安全与鲁棒性

**威胁模型**：

| 威胁 | 说明 |
| --- | --- |
| 对抗样本 | 微小扰动改变输出（图像贴纸、语音扰动） |
| 数据投毒 | 训练数据被植入后门 |
| 后门/木马 | 特定触发器激活错误行为 |
| 越狱（jailbreak） | 用提示绕过安全对齐 |
| 模型窃取 | 通过查询复制模型能力 |

**对齐（alignment）** 的三个层次：

| 层次 | 问题 |
| --- | --- |
| 指令对齐 | 是否遵循用户意图 |
| 意图对齐 | 是否理解并追求用户的真实目标 |
| 价值对齐 | 是否符合人类价值观与规范 |

**规范博弈（specification gaming）**：系统精确优化了写下的目标，却违背了真正意图。经典案例：赛艇游戏反复绕圈刷分、清洁机器人把垃圾藏起来。

**安全研究的核心难题**：

- **可扩展监督（scalable oversight）**：当任务超出人类评估能力时，如何监督？
- **欺骗性对齐（deceptive alignment）**：系统在训练中表现良好、部署后改变行为；
- **目标误泛化（goal misgeneralization）**：能力泛化了，目标没泛化；
- **权力寻求**：最优策略可能倾向获取资源与控制（instrumental convergence）。

**工程缓解**：

1. **红队测试**与对抗评估；
2. **RLHF/DPO** + 规则约束 + 分类器过滤；
3. **可解释性与监控**（日志、行为审计）；
4. **能力限制**：沙箱、权限最小化、人类确认；
5. **防御纵深**：不依赖单一机制。

### 27.3.5 治理与法规

| 法规/框架 | 要点 |
| --- | --- |
| GDPR（2018） | 数据最小化、解释权、被遗忘权 |
| EU AI Act（2024） | 按风险分级：不可接受/高/有限/最小；高风险的合规义务 |
| 中国《生成式人工智能服务管理暂行办法》 | 内容安全、标识、数据合规 |
| NIST AI RMF | 风险管理框架（治理、映射、度量、管理） |
| ISO/IEC 42001 | AI 管理体系标准 |

**治理工具**：

- **风险评估与影响评估**（DPIA、算法影响评估）；
- **技术标准与认证**；
- **审计与披露**（模型卡、数据卡）；
- **责任分配**（产品责任、举证责任）；
- **内容标识**（AI 生成内容水印/元数据）。

**治理的难点**：

- 技术迭代快于立法；
- 跨境数据与算力流动；
- 开源模型的监管边界；
- "安全"与"创新/竞争"的平衡。

### 27.3.6 社会影响

| 议题 | 风险 | 可能的应对 |
| --- | --- | --- |
| 就业 | 任务自动化快于岗位创造 | 再培训、社会保障、人机协作设计 |
| 信息生态 | 深度伪造、规模化虚假信息 | 内容溯源、平台治理、媒体素养 |
| 注意力与自主 | 成瘾性推荐、操纵 | 算法透明、用户控制、默认保护 |
| 权力集中 | 算力与数据垄断 | 公共算力、开放模型、反垄断 |
| 教育 | 代写与依赖 | 过程性评估、AI 素养教育 |
| 医疗与司法 | 高风险决策的误判 | 人类复核、严格验证、责任明确 |
| 环境 | 训练与推理能耗 | 高效架构、绿色数据中心、碳核算 |

**一个实用的分析框架**：对任何 AI 部署，问四个问题：

1. **谁受益、谁承担风险**？（分配正义）
2. **出错时谁能发现、谁能纠正**？（可纠正性）
3. **被影响者是否有话语权**？（程序正义）
4. **系统失效的最坏后果是否可逆**？（安全边界）

## 本章小结

**核心要点**

1. AI 的极限分**原理性、复杂性、工程性**三类；常识与因果是当前最实质的工程瓶颈。
2. **图灵测试**检验行为不可区分，**中文屋**质疑符号操作是否产生理解；功能主义与生物自然主义的争论无法实证裁决。
3. 公平性有多套互相冲突的度量，选择本质上是**价值判断**；工程上必须分层评估与持续审计。
4. 可解释性分内在、事后、示例三类；**解释不等于因果**，且可能被误读或操纵。
5. 隐私保护靠**差分隐私、联邦学习、密码学**三条路线；DP 提供可证明保证，但有效用代价。
6. AI 安全的核心是**规范博弈、分布外泛化、可扩展监督与欺骗性对齐**；治理需要法规、标准、审计与责任分配共同作用。
7. 社会影响的关键不是"机器取代人"，而是**权力、信息与风险的重新分配**。
