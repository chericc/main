# 第 20 章 概率模型学习（Learning Probabilistic Models）

**本章导读**：第 12–15 章假设概率模型的参数已知；本章讨论如何从数据中学出它们。三件事：参数的**最大似然**与**贝叶斯估计**（20.1）、数据完整时贝叶斯网络的参数与结构学习（20.2）、以及含隐变量时的 **EM 算法**（20.3）。EM 是本章的核心——它统一了高斯混合、HMM 的 Baum–Welch、缺失数据插补与主题模型。

**学习目标**：完成本章学习后，你应当能够：

- 写出最大似然估计并说明它与 KL 散度的关系；
- 用共轭先验做贝叶斯参数估计，解释后验预测与平滑；
- 从完整数据估计贝叶斯网络的 CPT，用 BIC/评分搜索学结构；
- 推导 EM 的 E 步与 M 步，说明它为何单调提升似然；
- 写出高斯混合模型的 EM 更新公式；
- 说明隐变量模型的可辨识性与局部最优问题。

**预备知识**：第 12–14 章的概率模型；第 19 章的偏差-方差与模型选择；微积分中的导数与对数似然；拉格朗日乘子。

## 20.1 统计学习

**最大似然估计（MLE）**：选参数使观测数据的概率最大：

$$\hat\theta_\text{ML} = \arg\max_\theta \prod_{i=1}^{N} P(x_i \mid \theta) = \arg\max_\theta \sum_i \log P(x_i \mid \theta)$$

**与 KL 散度的关系**：最大化似然等价于最小化经验分布 $\hat p$ 与模型 $p_\theta$ 的 KL 散度：

$$\hat\theta_\text{ML} = \arg\min_\theta \mathrm{KL}(\hat p \,\|\, p_\theta)$$

这正是"用模型逼近数据分布"的精确表述。

**MLE 的例子**：

| 模型 | MLE |
| --- | --- |
| 伯努利 $P(1)=p$ | $\hat p = \frac{\#1}{N}$ |
| 多项分布 | $\hat p_k = \frac{n_k}{N}$ |
| 高斯 $\mathcal{N}(\mu,\sigma^2)$ | $\hat\mu = \bar x$，$\hat\sigma^2 = \frac{1}{N}\sum(x_i-\bar x)^2$ |
| 指数分布 | $\hat\lambda = 1/\bar x$ |

**MLE 的缺陷**：小样本时**过拟合**（伯努利中 $\hat p$ 可能为 0 或 1，导致"未见即不可能"）。**贝叶斯估计**通过先验修正。

**贝叶斯参数学习**：把参数也看作随机变量，

$$P(\theta \mid D) = \alpha\, P(D \mid \theta)\, P(\theta)$$

**共轭先验**使后验与先验同族：

| 似然 | 共轭先验 | 后验更新 |
| --- | --- | --- |
| 伯努利 | Beta$(\alpha,\beta)$ | $\alpha' = \alpha + \#1$，$\beta' = \beta + \#0$ |
| 多项 | Dirichlet$(\boldsymbol\alpha)$ | $\alpha_k' = \alpha_k + n_k$ |
| 高斯（已知方差） | 高斯 | 精度加权平均 |
| 高斯（未知均值方差） | 正态-逆 Gamma | 解析更新 |

**后验预测分布**：

$$P(x_\text{new} \mid D) = \int P(x_\text{new} \mid \theta) P(\theta \mid D)\, d\theta$$

对 Beta-伯努利，$P(x_\text{new}=1 \mid D) = \frac{\alpha + n_1}{\alpha+\beta+N}$——**拉普拉斯平滑**的来源，也是朴素贝叶斯处理零频词的标准做法。

**MAP 与 MLE 的关系**：MAP 是 $\arg\max_\theta P(D \mid \theta)P(\theta)$，等价于在负对数似然上加正则项（$-\log P(\theta)$）：高斯先验 → $L_2$，拉普拉斯先验 → $L_1$。**贝叶斯 → 正则化**的对应关系由此建立。

## 20.2 完整数据下的学习

**（1）朴素贝叶斯的参数学习**。在条件独立假设下，MLE 分解为若干计数：

$$P(x_i = v \mid c) = \frac{\#(x_i = v, c)}{\#(c)}$$

用 Dirichlet 先验得平滑估计（拉普拉斯/加一平滑）：

$$P(x_i = v \mid c) = \frac{\#(x_i=v,c) + \alpha}{\#(c) + \alpha |V_i|}$$

**（2）贝叶斯网络的参数学习**。数据完整时，每个节点的 CPT 可**独立**估计：

$$P(X_i = v \mid \text{Pa}(X_i) = \mathbf{u}) = \frac{\#(X_i=v, \text{Pa}=\mathbf{u})}{\#(\text{Pa}=\mathbf{u})}$$

原因是似然按节点因子化，参数之间不耦合（**全局分解**）。这是贝叶斯网络的一大优势：参数学习可并行、可增量。

**（3）结构学习**。当结构未知时，需同时学结构与参数。

**评分函数**：

| 评分 | 形式 | 特点 |
| --- | --- | --- |
| 对数似然 | $\log P(D \mid G,\theta)$ | 偏向稠密图（过拟合） |
| BIC | $\log\hat L - \frac{\log N}{2}\cdot\lvert\theta\rvert$ | 一致（$N\to\infty$ 选真结构） |
| AIC | $\log\hat L - \lvert\theta\rvert$ | 预测导向，倾向复杂 |
| BDeu | 贝叶斯边际似然（Dirichlet 先验） | 小样本稳定 |
| MDL | 描述长度 | 与 BIC 近似 |

**搜索策略**：

- **贪心等价搜索（GES）**：从空图开始，加边/删边/转边，选评分提升最大者；
- **爬山 + 随机重启**：加禁忌表避免循环；
- **精确搜索**：动态规划（$O(n 2^n)$，适合 $n \le 20$）；
- **约束-based（PC）**：用条件独立检验确定骨架与方向（附录 D.6）。

**结构学习中必须尊重的约束**：

- **无环**（DAG）；
- **马尔可夫等价类**：同一等价类的 DAG 无法由观测数据区分（需干预数据，见附录 D）；
- **先验知识**：禁止某些边、强制某些边（如时间顺序）。

**Chow–Liu 树**：若限制结构为树，最优结构可由**最大生成树**（权重为互信息）在 $O(n^2\log n)$ 内求出，是"结构学习的精确可解特例"。

**（4）参数共享与分层模型**。当某些节点"同类"（如多个用户的行为），可用**分层贝叶斯**共享超参数：

$$\theta_j \sim P(\theta \mid \eta),\qquad \eta \sim P(\eta)$$

样本少的组从组分布"借力"，这就是关系概率模型（§15.1）与经验贝叶斯的核心。

## 20.3 隐变量学习：EM 算法

**问题**：模型含未观测变量 $Z$（如聚类归属、HMM 的隐状态），直接最大化边际似然

$$\log P(X \mid \theta) = \log \sum_z P(X, z \mid \theta)$$

因对数内有求和而难以优化。

**EM 的思路**：迭代地"猜测 $Z$"（E 步）与"用猜测更新参数"（M 步）。

**E 步**：计算后验 $q(z) = P(z \mid X, \theta^{(t)})$；
**M 步**：最大化期望完全数据对数似然

$$\theta^{(t+1)} = \arg\max_\theta \sum_z q(z) \log P(X, z \mid \theta)$$

**单调性**：EM 每轮使 $\log P(X \mid \theta)$ **不减**。证明用 Jensen 不等式构造下界（ELBO）：

$$\log P(X\mid\theta) \ge \underbrace{\mathbb{E}_q[\log P(X,Z\mid\theta)] + H(q)}_{\text{ELBO}}$$

E 步令下界与真实值在 $\theta^{(t)}$ 处相切，M 步抬高下界，因此目标单调上升。收敛到**局部最优**（或鞍点），不保证全局。

**（1）高斯混合模型（GMM）**。模型：

$$p(x) = \sum_{k=1}^{K} \pi_k\, \mathcal{N}(x \mid \mu_k, \Sigma_k)$$

EM 更新：

**E 步**（责任度）：

$$r_{ik} = \frac{\pi_k \mathcal{N}(x_i \mid \mu_k,\Sigma_k)}{\sum_j \pi_j \mathcal{N}(x_i \mid \mu_j,\Sigma_j)}$$

**M 步**：

$$N_k = \sum_i r_{ik},\quad \pi_k = \frac{N_k}{N},\quad \mu_k = \frac{1}{N_k}\sum_i r_{ik}x_i$$
$$\Sigma_k = \frac{1}{N_k}\sum_i r_{ik}(x_i-\mu_k)(x_i-\mu_k)^\top$$

**（2）HMM 的 Baum–Welch**。隐状态是 $Z$，参数是 $(\pi, A, B)$：

- E 步：前向-后向算 $\gamma_t(i) = P(z_t = i \mid e_{1:t})$ 与 $\xi_t(i,j)$；
- M 步：$\hat A_{ij} = \frac{\sum_t \xi_t(i,j)}{\sum_t \gamma_t(i)}$，$\hat B_{ik} = \frac{\sum_{t: e_t=k}\gamma_t(i)}{\sum_t \gamma_t(i)}$。

**（3）潜在狄利克雷分配（LDA）**。文档-主题-词的三层生成模型，EM/变分或 Gibbs 采样求主题分布。它的关系模型版本是 §15.1 的板块记号。

**（4）缺失数据插补**。把缺失值看作隐变量，EM 交替"用当前参数填缺失"与"用填好的数据估参数"。它比"用均值填充"更合理，因为保留了不确定性。

**EM 的实践要点**：

| 问题 | 对策 |
| --- | --- |
| 局部最优 | 多随机初始化、取最优；或 warm start |
| 收敛慢 | 用加速 EM（SQUAREM）、或换用梯度/变分 |
| 奇异解 | GMM 中某分量塌缩到单点（$\Sigma \to 0$，似然 $\to\infty$）→ 加正则 $\Sigma + \epsilon I$ |
| 模型选择 | 用 BIC/交叉似然选 $K$，或用 Dirichlet 过程（非参数贝叶斯） |
| 可辨识性 | 高斯混合的标签可交换（label switching）；需固定顺序或用后处理对齐 |

**从 EM 到变分与 GAN**：

- **变分自编码器（VAE）**：用网络参数化 $q_\phi(z\mid x)$，最大化 ELBO——是 EM 的"摊销 + 可微"版本（§21.7）；
- **生成对抗网络（GAN）**：用判别器代替似然，避开对 $Z$ 的积分（§21.7）；
- **扩散模型**：把生成分解为多步去噪，可看作"层次隐变量"的变分推断。

## 本章小结

**核心要点**

1. **MLE** = 最小化经验分布与模型的 KL 散度；小样本会过拟合，需贝叶斯平滑。
2. **共轭先验**给出解析后验；后验预测导出拉普拉斯平滑；MAP 等价于加正则。
3. 数据完整时贝叶斯网络参数**按节点独立估计**；结构学习用评分 + 搜索，需处理无环与马尔可夫等价类。
4. **EM** 交替 E 步（后验责任度）与 M 步（加权 MLE），通过 ELBO 保证似然单调不减，收敛到局部最优。
5. GMM 与 Baum–Welch 是 EM 的两个标准实例；LDA、缺失数据插补同理。
6. EM 的工程问题是**局部最优、奇异解、可辨识性与模型选择**。
