# 附录 D 因果推断

**本章导读**：第 13.6 节已经区分了"看"与"做"。本附录把因果推断展开成可操作的流程：为什么相关不等于因果（D.1）→ 如何用图表示因果假设（D.2）→ 如何计算干预分布（D.3）→ 如何用观测数据估计因果效应（D.4）→ 如何回答反事实（D.5）→ 如何从数据发现结构（D.6）。它的价值在于：**预测模型回答"会发生什么"，因果模型回答"如果我这样做，会发生什么"**。

**学习目标**：完成本附录学习后，你应当能够：

- 用辛普森悖论与混杂说明相关与因果的分离；
- 画出 DAG，判断后门路径、对撞与中介；
- 使用后门/前门准则与 do-演算识别因果效应；
- 选择匹配、倾向得分、双重差分、工具变量等估计方法；
- 区分干预与反事实，写出反事实查询；
- 说明因果发现算法的假设与局限。

**预备知识**：第 12–13 章的概率图模型；基本统计（回归、期望、方差）；第 12.5 节的贝叶斯法则。

## D.1 相关与因果

**三个经典反例**：

**（1）辛普森悖论**。某药在两组（轻症/重症）中都更有效，但合并后整体看起来更差：

| 分组 | 用药治愈率 | 未用药治愈率 |
| --- | --- | --- |
| 轻症 | 90% (18/20) | 80% (8/10) |
| 重症 | 60% (6/10) | 50% (10/20) |
| 合并 | 80% (24/30) | 60% (18/30) |

（数值可构造为合并后反转。）原因：**用药组重症比例更高**。分层与合并给出相反结论，说明"该控制什么"决定了答案。

**（2）混杂（confounding）**。$Z$ 同时影响 $X$ 与 $Y$，导致 $X$ 与 $Y$ 相关但无因果：

```
Z → X
Z → Y
```

经典例子：气温 → 冰淇淋销量与溺水人数。

**（3）对撞（collider）**。$X \to Z \leftarrow Y$，$X$ 与 $Y$ 本来独立，**控制 $Z$ 后反而相关**：

```
X → Z ← Y
```

经典例子：名人（$X$）与外表（$Y$）都影响"是否成为演员"（$Z$）；只统计演员群体时，二者负相关。这叫 **Berkson 悖论 / 选择偏差**。

**教训**：

- "控制所有变量"是错的——控制对撞会**制造**偏差；
- "相关"可以为因果提供证据，但需要**假设**（图结构）来定向；
- 因果推断的本质是**在假设下做识别**，而非从数据中"读出"因果。

## D.2 因果图模型

**结构因果模型（SCM）**：

$$X_i = f_i\big(\text{Pa}(X_i), U_i\big)$$

其中 $U_i$ 是外生噪声。它比贝叶斯网络多一层语义：**边是函数依赖**，因此支持干预。

**干预（do-算子）**：$do(X=x)$ 表示"把 $X$ 强制设为 $x$"，等价于**删除所有指向 $X$ 的边**并令 $X = x$：

$$P(Y \mid do(X=x)) = P_{\mathcal{G}_{\overline{X}}}(Y \mid X=x)$$

其中 $\mathcal{G}_{\overline{X}}$ 是删去入边后的图。

**三条 do-演算规则**（Pearl）：

| 规则 | 内容 | 用途 |
| --- | --- | --- |
| 规则 1 | 若 $Y \perp Z \mid X, W$ 在删去 $Z$ 出边的图中成立，则可插入/删除观测 | 简化 |
| 规则 2 | 若 $Y \perp Z \mid X, W$ 在删去指向 $X$ 的边的图中成立，则 $do(Z)$ 可换为观测 | 去干预 |
| 规则 3 | 若 $Y \perp Z \mid X, W$ 在删去指向 $X$ 的边的图中成立，则可删除/插入 $do(Z)$ | 去观测 |

**可识别性**：若存在 do-演算序列把含 $do$ 的表达式化为纯观测表达式，则效应**可识别**；否则不可识别（需要额外假设或实验）。

**三个基本结构**（与 §12.4、§13.2 对应）：

| 结构 | 是否混杂 | 控制策略 |
| --- | --- | --- |
| 链 $X \to M \to Y$ | 否（$M$ 是中介） | 不要控制 $M$（会切断通路） |
| 分叉 $X \leftarrow Z \to Y$ | 是 | 控制 $Z$ |
| 对撞 $X \to Z \leftarrow Y$ | 否 | **不要**控制 $Z$ |

## D.3 do-算子与干预

**干预与观测的差别**：

$$P(Y \mid X=x) \neq P(Y \mid do(X=x))$$

**例子（药物与康复）**：重症患者更可能用药，用药组康复率反而低。观测到的是"用药与康复相关"，但干预"给所有人用药"可能提高康复率。

**干预的计算**（已知结构时）：在 SCM 中把 $X$ 的方程替换为常数，再前向模拟（**因果推断的"生成式"路线**）。

**四种效应**：

| 效应 | 定义 | 用途 |
| --- | --- | --- |
| ATE（平均处理效应） | $\mathbb{E}[Y(1) - Y(0)]$ | 政策评估 |
| ATT（处理组平均效应） | $\mathbb{E}[Y(1)-Y(0) \mid T=1]$ | 对已处理者的影响 |
| CATE（条件平均效应） | $\mathbb{E}[Y(1)-Y(0) \mid X=x]$ | 异质性、个体化决策 |
| LATE（局部效应） | 工具变量识别的人群效应 | 依从性不完全的实验 |

**潜在结果框架（Rubin 因果模型）** 与 **SCM** 等价，只是语言不同：$Y(1), Y(0)$ 是潜在结果，**因果推断的根本问题**是二者只能观测到一个。

## D.4 因果效应估计：后门与前门准则

**后门准则（back-door criterion）**：变量集 $Z$ 满足

1. $Z$ 阻断了 $X$ 与 $Y$ 之间所有**含指向 $X$ 的边**的路径；
2. $Z$ 中不含 $X$ 的后代，

则

$$P(Y \mid do(X=x)) = \sum_z P(Y \mid X=x, Z=z)\,P(z)$$

**前门准则（front-door criterion）**：当 $X$ 与 $Y$ 之间有未观测混杂、但存在中介 $M$ 满足

1. $M$ 阻断了 $X \to Y$ 的所有有向路径；
2. 没有未观测的 $X \to M$ 混杂；
3. $X$ 阻断了 $M \to Y$ 的所有后门路径，

则

$$P(Y \mid do(x)) = \sum_m P(m \mid x)\sum_{x'} P(Y \mid m, x')\,P(x')$$

**常用估计方法**：

| 方法 | 适用 | 核心假设 |
| --- | --- | --- |
| **随机实验（RCT）** | 金标准 | 随机化消除混杂 |
| **匹配（matching）** | 观测数据 | 无未观测混杂（条件可忽略） |
| **倾向得分（PSM/IPW）** | 高维协变量 | 同上 + 重叠性 |
| **回归调整** | 线性关系 | 函数形式正确 |
| **双重差分（DiD）** | 面板数据、政策冲击 | 平行趋势 |
| **合成控制** | 单一处理单元 | 处理前拟合良好 |
| **断点回归（RDD）** | 阈值分配 | 阈值附近连续 |
| **工具变量（IV）** | 有未观测混杂 | 相关性 + 排他性 |

**倾向得分的直觉**：$e(x) = P(T=1\mid X=x)$，用 $1/e(x)$ 加权构造"伪随机化"：

$$\hat\tau_\text{IPW} = \frac{1}{n}\sum_i \Big[\frac{T_i Y_i}{\hat e(X_i)} - \frac{(1-T_i)Y_i}{1-\hat e(X_i)}\Big]$$

**双重稳健（AIPW）** 结合倾向得分与结果回归，二者之一正确即一致。

**敏感性分析**：估计结果对"未观测混杂"的稳健性（如 E-value、Rosenbaum 界）。**任何观测研究的结论都应附带敏感性分析**。

## D.5 反事实推理

**反事实**：对**已经发生**的事问"如果当时不同会怎样"。

**三层级（Pearl 的因果阶梯）**：

| 层级 | 问题 | 数学 |
| --- | --- | --- |
| 关联（association） | 看到 $X$，$Y$ 会怎样 | $P(Y\mid X)$ |
| 干预（intervention） | 如果做 $X$，$Y$ 会怎样 | $P(Y\mid do(X))$ |
| 反事实（counterfactual） | 已经发生了 $X=x$，若改为 $x'$，$Y$ 会怎样 | $P(Y_{x'} \mid X=x, Y=y)$ |

**反事实的计算**（SCM 三步）：

1. **溯因（abduction）**：用观测到的 $(X=x, Y=y)$ 更新外生变量 $U$ 的后验；
2. **干预（action）**：把 $X$ 的方程替换为 $x'$；
3. **预测（prediction）**：在更新后的模型中计算 $Y$。

**例子**：某患者服药后康复，问"如果不服药会怎样"。需要知道该患者的个体特征与噪声，因此反事实**依赖模型假设**，比干预更难识别。

**应用**：

- **责任归因**：事故中"如果系统不这样做，事故是否避免"；
- **个性化决策**：对某个病人，治疗 A 还是 B；
- **可解释性**：反事实解释（"改变哪个特征能改变结果"，§27.3.2）；
- **公平性**：反事实公平（"若改变受保护属性，决策是否改变"）。

## D.6 因果发现算法

**目标**：从数据推断图结构。**根本困难**：观测数据只能确定**马尔可夫等价类**（同一骨架 + 同一 v-结构），边的方向通常不可唯一确定。

**三类方法**：

| 类型 | 代表 | 思路 | 假设 |
| --- | --- | --- | --- |
| 基于约束 | PC、FCI | 条件独立检验 → 骨架 → 定向 | 因果充分性、 faithfulness |
| 基于评分 | GES、Hill-climbing | 评分（BIC/BDeu）+ 搜索等价类 | 同上 |
| 基于函数 | LiNGAM、ANM | 利用噪声的非高斯/非线性不对称定向 | 特定函数形式 |

**PC 算法的骨架**：

1. 从完全无向图开始；
2. 对每对变量，检验在逐渐增大的条件集下是否独立，独立则删边；
3. 用 v-结构（对撞）与 Meek 规则定向。

**FCI**：允许**未观测混杂**（隐变量），输出部分有向图（PAG），边可能表示"某个方向"或"存在混杂"。

**LiNGAM**：假设 $X_i = \sum_{j} b_{ij}X_j + U_i$ 且 $U_i$ 非高斯，则可用 ICA 唯一确定方向。

**实用建议**：

1. 因果发现的结果必须用**领域知识**校验（时间顺序、物理约束）；
2. 样本量、噪声、非线性都会导致错误边；
3. 用**干预实验**验证关键边（A/B 测试）；
4. 报告**不确定性**（bootstrap 边稳定性）。

**因果与机器学习的前沿**：

- **因果表征学习**：学跨环境不变的特征（invariant causal prediction）；
- **因果强化学习**：用因果模型做反事实数据增广、提升样本效率与鲁棒性；
- **因果与大模型**：用因果图约束生成、评估反事实一致性。

## 本附录小结

**核心要点**

1. **相关 ≠ 因果**：辛普森悖论、混杂与对撞是三类基本陷阱；"控制所有变量"会引入偏差。
2. **SCM** 用函数依赖定义因果；$do(X=x)$ 等价于删除入边，do-演算是识别干预效应的完备工具。
3. **后门准则**通过阻断含指向 $X$ 的路径识别效应；**前门准则**在中介存在时绕过未观测混杂。
4. 估计方法从 RCT 到 PSM/IPW、DiD、IV、RDD，各自依赖不同的识别假设；**敏感性分析必不可少**。
5. **反事实**是因果阶梯的第三层，需要溯因—干预—预测三步，比干预更依赖模型假设。
6. **因果发现**只能确定马尔可夫等价类；约束/评分/函数三类方法各有假设，结果需领域校验与实验验证。
