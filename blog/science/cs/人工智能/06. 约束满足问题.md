# 第 6 章 约束满足问题（Constraint Satisfaction Problems）

**本章导读**：很多问题不是"找一条路径"，而是"给一组变量赋值使所有约束都被满足"——排课、地图着色、数独、电路布线、装箱都属于此类。这类问题称为约束满足问题（CSP），它的强结构使我们能比通用搜索快几个数量级。本章按"定义 → 约束传播 → 回溯搜索 → 局部搜索 → 结构分解"的顺序展开，核心是三类推理：在变量层面剪枝（弧相容）、在搜索中剪枝（前向检验）、在问题结构上分解（树分解）。

**学习目标**：完成本章学习后，你应当能够：

- 用变量、值域、约束三元组形式化 CSP，并画约束图；
- 辨析节点相容、弧相容、路径相容与全局约束；
- 手算 AC-3 与边界传播的迭代过程；
- 用 MRV、度启发式、LCV 改进回溯搜索，并说明前向检验与 MAC 的差异；
- 用 min-conflicts 局部搜索求解大规模 CSP；
- 识别树结构 CSP 并给出线性时间算法，理解割集条件与树分解的作用。

**预备知识**：图论（连通分量、树、环）、第 3 章的回溯思想、第 4 章的局部搜索。

---

## 6.1 约束满足问题的定义

**形式定义**。一个 CSP 由三元组 $(\mathcal{X}, \mathcal{D}, \mathcal{C})$ 构成：

- $\mathcal{X} = \{X_1,\dots,X_n\}$：变量集合；
- $\mathcal{D} = \{D_1,\dots,D_n\}$：值域，$X_i$ 取值于 $D_i$；
- $\mathcal{C} = \{C_1,\dots,C_m\}$：约束集合，每个约束 $C_j = \langle \text{scope}, \text{rel} \rangle$ 限定作用域内变量的合法取值组合。

**解**是一个**完整且一致**的赋值：每个变量都取了值，且所有约束都被满足。**部分赋值**只给部分变量赋值，一致的部分赋值称为**相容赋值**。

**约束图（constraint graph）**：节点是变量，边连接同一个约束涉及的变量。约束图的结构直接决定求解难度（§6.5）。

**四类经典问题**：

| 问题 | 变量 | 值域 | 约束 |
| --- | --- | --- | --- |
| 地图着色 | 各行政区 | 颜色集合 | 相邻区域颜色不同（二元、不等） |
| 数独 | 81 个格 | 1–9 | 行/列/宫互不相同（全局 alldiff） |
| 八皇后 | 8 个皇后所在行 | 0–7 列 | 任意两皇后不同列、不同对角线 |
| 密码算术 | 字母 | 0–9 | 各位加法成立且首位非零（高元约束） |

密码算术 `TWO + TWO = FOUR` 是"高元约束"的典型：$O + O = R + 10 C_1$ 这类约束同时涉及 3–4 个变量，不能简单拆成二元约束而不引入辅助变量。

**约束的类型学**：

- **一元 / 二元 / 高元**：作用域大小；
- **绝对 / 偏好**：硬约束必须满足，软约束用代价表示（可转为约束优化问题 CSPCOP）；
- **内蕴 / 显式**：由公式定义（如 $X < Y$）还是枚举允许的组合。

**CSP 与一般搜索的关系**：CSP 是第 3 章搜索的特例，但它的三个特性使专用算法更快：

1. **可交换性（commutativity）**：赋值顺序不影响最终结果，因此可以固定变量顺序；
2. **约束可提前检验**：不必等到完整赋值才发现矛盾；
3. **结构可分解**：约束图常可拆成独立子问题。

## 6.2 约束传播：CSP 中的推理

约束传播用局部推理**缩小值域**，从而提前排除不可能的分支。

**节点相容（node consistency）**。每个变量的每个值都满足一元约束；否则从值域删去。它是最弱的相容性，通常作为预处理。

**弧相容（arc consistency）**。变量 $X$ 相对 $Y$ 是弧相容的，若 $X$ 的每个值都能在 $Y$ 中找到至少一个值与之相容：

$$\forall x \in D_X,\ \exists y \in D_Y : (x,y) \in C_{XY}$$

**AC-3 算法**：维护约束队列，每次删值后把受影响的所有弧重新入队。

```
function AC-3(csp):
    queue ← csp 中所有弧
    while queue 非空:
        (X, Y) ← queue.pop()
        if REVISE(csp, X, Y):          # 删除了 X 的某些值
            if D_X 为空: return false
            for Z in X 的邻居 \ {Y}:
                queue.push((Z, X))     # 邻居的弧可能受影响
    return true

function REVISE(csp, X, Y):
    revised ← false
    for x in D_X:
        if 不存在 y ∈ D_Y 使 (x,y) 相容:
            D_X.remove(x); revised ← true
    return revised
```

**复杂度**：$O(e d^3)$，$e$ 为弧数、$d$ 为最大值域大小（每条弧最多检查 $d^2$ 组合，每条弧最多入队 $d$ 次）。

**性质**：

- AC-3 是**不完备**的：弧相容的 CSP 仍可能无解（如三元环的 2-着色问题）；
- 但它是**安全**的：删去的值一定不出现在任何解中；
- 它是求解前性价比最高的预处理，常把搜索树缩小几个数量级。

**路径相容（path consistency）**。对每对变量 $X,Y$ 与第三个变量 $Z$，任何相容的 $(x,y)$ 都能延拓到 $Z$。它等价于在约束图的"三角形"上做推理，代价更高（$O(n^3 d^3)$），实践较少单独使用。

**全局约束与专门传播**。`alldiff`（所有变量取值互异）与 `sum`、`cumulative`（调度）有比"拆成二元约束"强得多的专用算法：

- **alldiff 的匹配视角**：若 $n$ 个变量、$n$ 个值，`alldiff` 可行 ⇔ 二分图存在完美匹配；用 Hopcroft–Karp 检测，并可用"值图"（value graph）的强连通分量删去不参与任何完美匹配的值。
- **边界传播（bounds propagation）**：对整数变量只维护 $[\min,\max]$，适用于大规模线性约束（资源、时间窗），是调度与配置系统的核心。

## 6.3 CSP 的回溯搜索

**基本回溯**：按固定顺序选变量，逐个试值，一发现不一致就回溯。它是 DFS 在 CSP 上的版本，最坏 $O(d^n)$。

改进有三个层次：**选哪个变量、试哪个值、如何提前发现矛盾**。

### 6.3.1 变量与值的排序

| 启发式 | 规则 | 目的 |
| --- | --- | --- |
| **MRV**（minimum remaining values） | 优先选剩余合法值最少的变量 | 尽快触发失败，减少分支 |
| **度启发式**（degree） | MRV 并列时选约束邻居最多的变量 | 尽早约束他人 |
| **LCV**（least constraining value） | 优先试对邻居限制最小的值 | 保留后续灵活性 |

MRV 也叫"fail-first"：它把失败提前，而 LCV 把成功提前，二者互补。

### 6.3.2 前向检验与 MAC

**前向检验（forward checking）**：每给 $X$ 赋值，就从 $X$ 的**未赋值邻居**值域中删去不相容的值。只检查一层，代价低，但看不到"未来的矛盾"。

**MAC（maintaining arc consistency）**：每步赋值后对受影响弧运行 AC-3，维持**全局弧相容**。代价高于前向检验，但剪枝强得多，是现代 CSP 求解器（如 MiniZinc、OR-Tools CP-SAT 的前身）的默认策略。

**对比**：

| 方法 | 剪枝强度 | 每步代价 | 适用 |
| --- | --- | --- | --- |
| 回溯 | 只检查当前赋值 | 低 | 小问题、教学 |
| 前向检验 | 一层 | 中 | 中等规模 |
| MAC | 全局弧相容 | 高 | 大规模、强约束 |

另有**冲突导向回跳（conflict-directed backjumping）**：记录每个失败由哪些变量引起，直接跳回"责任变量"，跳过无关层次；配合**约束学习**（记录冲突的禁止组合）可进一步加速。

## 6.4 CSP 的局部搜索

当问题规模大、且**存在解的概率高**时，局部搜索往往比回溯快得多。

**min-conflicts 算法**：

```
current ← 随机完整赋值
loop:
    if 无冲突: return current
    var ← 随机选一个冲突变量
    value ← 使 var 冲突数最少的值（并列随机）
    current[var] ← value
```

特点：

- 每步 $O(d)$ 计算冲突数（可用增量更新）；
- 在**百万皇后**问题上，随机初始赋值后通常只需几十步就能求解；
- 在"难解区"（约束密度临界点附近）会陷入局部极小，需要重启或加入随机扰动（类似模拟退火）；
- 缺点：**不完备**，无法证明无解。

**适用判据**：解密度高、约束局部化、允许近似 → min-conflicts；需要完备性或证明不可满足 → 回溯 + 传播。

## 6.5 问题的结构

CSP 的真正加速来自**结构**而非更聪明的搜索。

**（1）独立子问题**。若约束图分成若干**连通分量**，则问题分解为互不影响的子问题，总复杂度为各分量之和。例如把一个大棋盘拆成互不接壤的区域。

**（2）树结构 CSP**。若约束图是树，可在**线性时间**内求解：

1. 任选一个根，把树转为有向树；
2. **自底向上**做弧相容（每个节点对父节点做 REVISE）；
3. **自顶向下**逐个赋值：父节点选定后，子节点必存在相容值（由步骤 2 保证）。

复杂度 $O(nd^2)$。这是"结构即算法"的最漂亮例子。

**（3）割集条件（cutset conditioning）**。若约束图接近树，选一个小**割集**（删去后成树），枚举割集的所有赋值，对每个赋值解树结构子问题：

- 复杂度 $O(d^c \cdot (n-c) d^2)$，$c$ 为割集大小；
- 割集越小越好，找最小割集是 NP 难，实践中用启发式。

**（4）树分解（tree decomposition）**。把约束图分解成"簇（bag）"组成的树，使每个约束都落在某个簇中，且同一变量出现在一个连通的簇子树里。**树宽（treewidth）** 是最小分解中最大簇的大小减一：

- 树宽有界时，CSP 可在线性时间求解；
- 树宽是问题"固有难度"的度量：大多数难解实例的树宽随规模增长；
- 求最小树宽是 NP 难，启发式算法（最小度、最小填入）在实践中够用。

**（5）对称性消解**。地图着色中"交换颜色名"、数独中"行列置换"都会产生等价解，加对称破缺约束可成倍减少搜索。

## 本章小结

**核心要点**

1. CSP = 变量 + 值域 + 约束；解是完整且一致的赋值，约束图刻画其结构。
2. **弧相容（AC-3）** 是性价比最高的预处理：安全但不完备，复杂度 $O(ed^3)$。
3. 回溯搜索的三项改进：**MRV/度启发式**选变量、**LCV** 选值、**前向检验/MAC** 提前发现矛盾。
4. 大规模高解密度问题用 **min-conflicts** 局部搜索，代价是不完备。
5. 结构决定难度：**独立分量**可分解、**树结构**线性可解、**割集条件**与**树分解**把近似树的问题压到可控复杂度。
6. 全局约束（`alldiff`、`sum`、`cumulative`）有专用传播算法，比拆成二元约束强得多。
