# 第 21 章 深度学习（Deep Learning）

**本章导读**：深度学习的核心主张是"**表示**可以学"——不必手工设计特征，多层非线性变换就能从原始输入中逐级构造出有用的表示。本章从单个神经元讲到训练工程：前馈网络与万能近似（21.1）、计算图与反向传播（21.2）、卷积（21.3）、优化与正则（21.4）、泛化之谜（21.5）、循环网络（21.6）、无监督与迁移（21.7）、应用与代价（21.8）。

**学习目标**：完成本章学习后，你应当能够：

- 写出前馈网络的表达式，说明激活函数的作用与选择；
- 用计算图与反向传播推导梯度，解释自动微分的工作方式；
- 说明卷积的局部连接、权值共享与等变性，计算输出尺寸；
- 比较 SGD、Momentum、Adam 等优化器，解释批归一化、Dropout、初始化与学习率调度的作用；
- 分析深度网络的泛化现象（双下降、隐式正则），说明样本效率与规模法则；
- 写出 RNN/LSTM/GRU 的状态更新，说明梯度消失与门控机制；
- 区分自编码器、VAE、GAN、扩散模型的生成思路；
- 说明预训练-微调范式与模型压缩（量化、蒸馏、剪枝）的工程取舍。

**预备知识**：第 19 章的线性模型、损失与正则；矩阵微积分（链式法则、雅可比）；概率基础。

## 21.1 简单前馈网络

**单个神经元**：

$$z = w^\top x + b,\qquad a = g(z)$$

**多层网络**：把神经元按层堆叠，

$$h^{(l)} = g\big(W^{(l)} h^{(l-1)} + b^{(l)}\big),\qquad \hat y = h^{(L)}$$

**激活函数**：

| 激活 | 形式 | 特点 |
| --- | --- | --- |
| Sigmoid | $1/(1+e^{-z})$ | 饱和、梯度消失；用于输出概率 |
| Tanh | $(e^z-e^{-z})/(e^z+e^{-z})$ | 零中心，仍饱和 |
| ReLU | $\max(0,z)$ | 稀疏、缓解梯度消失；有"死亡 ReLU" |
| Leaky ReLU / GELU / SiLU | 平滑变体 | 现代网络默认 |

**为什么需要非线性**：没有激活函数，多层线性变换的复合仍是线性变换——深度就失去了意义。

**万能近似定理（universal approximation）**：含足够多隐单元的单隐层网络可以任意精度逼近紧集上的连续函数。但定理**不说明**：

- 需要多少单元（可能指数多）；
- 能否用有限数据学到（样本复杂度）；
- 梯度下降能否找到（优化景观）。

**深度为何优于宽度**：深度对应**表示的层次复用**——低层学边缘，中层学部件，高层学对象。同样的函数用浅层网络表示可能需要指数多参数（深度分离定理）。

## 21.2 深度学习的计算图

**计算图**把复合函数表示为有向无环图：节点是运算，边是张量。

**反向传播** = **链式法则 + 动态规划**。对 $L = f(g(h(x)))$：

$$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial f}\cdot\frac{\partial f}{\partial g}\cdot\frac{\partial g}{\partial h}\cdot\frac{\partial h}{\partial x}$$

**关键技巧**：从输出向输入逐层传"上游梯度"，每层只算**局部雅可比 × 上游梯度**，避免重复计算共享子表达式。

**自动微分（autodiff）**：

| 模式 | 方向 | 适用 |
| --- | --- | --- |
| 前向模式 | 输入 → 输出，一次算一个输入的导数 | 输入维度小、输出维度大 |
| 反向模式 | 输出 → 输入，一次算一个输出的全部梯度 | **深度学习默认**（参数多、损失是标量） |

**实现要点**：

- **算子融合**：把多个小算子合并，减少内存读写；
- **检查点（checkpointing）**：不保存全部中间激活，反向时重算，用时间换显存；
- **混合精度**：FP16/BF16 前向 + FP32 主权重，需 loss scaling 防下溢；
- **数值稳定**：softmax + log 用 log-sum-exp，sigmoid 用分段实现。

## 21.3 卷积网络

**卷积层**的核心是三个归纳偏置：

1. **局部连接**：每个输出只看输入的一个邻域（感受野）；
2. **权值共享**：同一卷积核在空间上滑动，参数量与输入尺寸无关；
3. **平移等变性**（配合池化得到近似不变性）。

**输出尺寸**：

$$H_\text{out} = \left\lfloor \frac{H_\text{in} + 2P - K}{S} \right\rfloor + 1$$

其中 $K$ 核大小、$P$ 填充、$S$ 步长。

**感受野**：$r_l = r_{l-1} + (K_l - 1)\prod_{i<l} S_i$。堆叠小核（$3\times3$）比单个大核更省参数且非线性更多。

**经典架构的演进**：

| 网络 | 关键贡献 |
| --- | --- |
| LeNet-5 | 卷积 + 池化 + 全连接的基本范式 |
| AlexNet | ReLU、Dropout、GPU 训练、数据增强 |
| VGG | 用小卷积堆深，结构规整 |
| GoogLeNet | Inception 多尺度并行 + $1\times1$ 降维 |
| ResNet | **残差连接** $y = x + F(x)$，解决深层退化 |
| DenseNet | 密集连接，特征复用 |
| MobileNet | 深度可分离卷积，移动端高效 |
| EfficientNet | 复合缩放（深度/宽度/分辨率） |
| ViT | 把图像切成 patch 用 Transformer（§24.5） |

**残差连接**为何关键：它使梯度可以"短路"回传，缓解梯度消失，使上百层的网络可训练；同时把"学习恒等映射"变容易。

**其他卷积变体**：空洞卷积（扩大感受野）、转置卷积（上采样）、可变形卷积、分组卷积。

## 21.4 学习算法

**损失函数**：

| 任务 | 损失 |
| --- | --- |
| 分类 | 交叉熵 |
| 回归 | MSE / Huber |
| 分割 | 像素级交叉熵 + Dice |
| 检测 | 分类 + 框回归 + 目标性 |
| 对比学习 | InfoNCE |

**优化器**：

| 优化器 | 更新 | 特点 |
| --- | --- | --- |
| SGD | $\theta \leftarrow \theta - \eta g$ | 简单、泛化常好 |
| Momentum | 累积速度 | 抑制振荡、加速 |
| Nesterov | 前瞻梯度 | 更快收敛 |
| AdaGrad | 按历史梯度平方缩放 | 稀疏特征友好 |
| RMSProp | 指数滑动平均 | 非平稳目标 |
| Adam | 动量 + 二阶矩 + 偏差修正 | 默认首选 |
| AdamW | Adam + 解耦权重衰减 | 正则更正确 |

**学习率调度**：步进衰减、余弦退火、one-cycle、warmup + 线性衰减（Transformer 标配）。**warmup** 对深层网络与大 batch 很重要。

**归一化**：

| 方法 | 归一化维度 | 适用 |
| --- | --- | --- |
| BatchNorm | 跨 batch | CNN，依赖 batch 大小 |
| LayerNorm | 跨特征 | RNN/Transformer |
| GroupNorm | 分组通道 | 小 batch |
| RMSNorm | 均方根 | 大模型常用 |

**正则化**：权重衰减、Dropout、标签平滑、数据增强、随机深度、早停、集成。

**初始化**：Xavier（适合 tanh/sigmoid）、He（适合 ReLU），目的是保持各层方差稳定，避免信号爆炸/消失。

**训练诊断**：

- 训练损失不降 → 学习率、初始化、数据管线、标签错误；
- 训练降、验证升 → 过拟合（加正则/数据）；
- 两者都不降且差距小 → 容量不足或优化困难；
- 损失 NaN → 学习率过大、除零、log(0)。

## 21.5 泛化

**经典理论解释不了深度学习**：参数量远超样本量，VC 界给出的泛化误差上界远大于 1，但实测泛化很好。这一"谜题"的现有解释包括：

| 视角 | 要点 |
| --- | --- |
| **隐式正则** | SGD 偏好平坦极小（flat minima），平坦解泛化更好 |
| **双下降** | 参数量超过插值阈值后，测试误差先升后降（经典 U 形曲线之外） |
| **良性过拟合** | 过参数化网络能记住噪声，但仍对真实模式泛化 |
| **数据分布** | 真实数据有强结构，任务本身的"有效复杂度"低 |
| **规模法则** | 损失随数据/参数/算力呈幂律下降（scaling laws） |

**平坦极小与锐利极小**：参数的微小扰动不改变损失的区域更可能泛化；SAM（sharpness-aware minimization）显式优化这一目标。

**分布偏移与鲁棒性**：

- **协变量偏移**：$P(x)$ 变，$P(y\mid x)$ 不变；
- **标签偏移**：$P(y)$ 变；
- **概念漂移**：$P(y\mid x)$ 变；
- 对策：领域自适应、重要性加权、因果不变性（§13.6）、持续学习。

**样本效率**：深度学习通常需要大量数据。提升途径：预训练 + 微调、数据增强、自监督、少样本学习（附录 E.2）、归纳偏置（如卷积、等变网络）。

## 21.6 循环网络

**RNN** 用隐状态传递历史：

$$h_t = g(W_h h_{t-1} + W_x x_t + b),\qquad y_t = W_y h_t$$

**梯度消失/爆炸**：反向传播穿越 $T$ 步时需连乘 $T$ 个 Jacobian，谱半径 $<1$ 则消失，$>1$ 则爆炸。

**对策**：

| 方法 | 机制 |
| --- | --- |
| 梯度裁剪 | 限定范数，防爆炸 |
| 门控（LSTM/GRU） | 用门控制信息保留与遗忘 |
| 残差连接 | 提供梯度捷径 |
| 正交初始化 | 保持 Jacobian 谱半径接近 1 |
| 截断 BPTT | 限制回传步数 |

**LSTM** 的四组门：

$$f_t = \sigma(W_f[h_{t-1},x_t]),\quad i_t = \sigma(W_i[\cdot]),\quad o_t = \sigma(W_o[\cdot])$$
$$c_t = f_t \odot c_{t-1} + i_t \odot \tanh(W_c[\cdot]),\qquad h_t = o_t \odot \tanh(c_t)$$

**细胞状态** $c_t$ 的加法更新是关键：它让梯度沿"高速公路"回传，缓解消失。

**RNN 的地位**：在序列建模中长期主导（语音、翻译、时序预测），如今多数场景被 **Transformer**（§24.5）取代，但在**流式、低延迟、小模型**场景仍有一席之地（如状态空间模型 Mamba 是另一条复兴路线）。

## 21.7 无监督学习与迁移学习

**（1）自编码器（AE）**：编码 $z = f(x)$、解码 $\hat x = g(z)$，最小化重构误差。它学到的 $z$ 是压缩表示。

- **去噪自编码器**：输入加噪，目标为原始输入；
- **稀疏自编码器**：对 $z$ 加稀疏惩罚；
- **掩码自编码器（MAE）**：随机遮住 patch 再重建，是视觉自监督的主流。

**（2）变分自编码器（VAE）**：假设 $z \sim \mathcal{N}(0,I)$，最大化 ELBO：

$$\mathcal{L} = \mathbb{E}_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)] - \mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big)$$

- 第一项是重构，第二项是正则（让后验接近先验）；
- **重参数化技巧** $z = \mu + \sigma\odot\epsilon$ 使梯度可穿过采样；
- 优点是生成平滑、有似然；缺点是生成偏模糊（重构项主导）。

**（3）生成对抗网络（GAN）**：生成器 $G$ 与判别器 $D$ 对抗：

$$\min_G \max_D\ \mathbb{E}_{x\sim p_\text{data}}[\log D(x)] + \mathbb{E}_{z}[\log(1 - D(G(z)))]$$

- 优点：样本锐利、无需显式似然；
- 缺点：训练不稳定（模式崩塌、梯度消失），需 WGAN-GP、谱归一化等技巧。

**（4）扩散模型**：前向逐步加噪，反向学习去噪；训练目标是预测噪声：

$$\mathcal{L} = \mathbb{E}_{t,x_0,\epsilon}\big[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\big]$$

它是当前图像/视频生成的**主流**，质量高、训练稳定，代价是采样慢（需多步，可用 DDIM/蒸馏加速）。

**（5）迁移学习与预训练**：

| 范式 | 做法 | 适用 |
| --- | --- | --- |
| 特征提取 | 冻结预训练主干，只训分类头 | 小数据 |
| 微调 | 全网络小学习率训练 | 中等数据 |
| 线性探测 | 只训最后一层线性分类器 | 评估表示质量 |
| 领域自适应 | 对齐源域与目标域分布 | 跨域部署 |
| 提示/适配器 | 只训少量新增参数 | 大模型（§24.6） |

**（6）对比学习**（自监督的代表）：拉近正样本对、推远负样本对：

$$\mathcal{L}_\text{InfoNCE} = -\log \frac{\exp(\text{sim}(q,k_+)/\tau)}{\sum_{k}\exp(\text{sim}(q,k)/\tau)}$$

SimCLR、MoCo、CLIP（图文对齐）都是这一范式。CLIP 的图文对比使"零样本分类"成为可能。

## 21.8 应用

| 领域 | 代表进展 | 关键使能技术 |
| --- | --- | --- |
| 视觉 | 分类、检测、分割、生成 | CNN、ViT、扩散 |
| 语音 | 识别、合成、分离 | 卷积 + 序列模型、自监督预训练 |
| 语言 | 翻译、摘要、对话、代码 | Transformer、预训练、RLHF（第 24 章） |
| 科学 | 蛋白结构（AlphaFold）、分子生成、材料筛选 | 等变网络、图网络、几何深度学习 |
| 推荐与广告 | 排序、召回、创意生成 | 深度 CTR 模型、序列模型 |
| 控制与机器人 | 视觉伺服、抓取、自动驾驶 | 模仿学习、强化学习、世界模型 |
| 生成式媒体 | 图像/视频/音频生成 | 扩散、自回归、流模型 |

**工程代价**：

| 维度 | 现实 |
| --- | --- |
| 算力 | 大模型训练耗资数百万美元，推理成本决定产品可行性 |
| 数据 | 高质量标注昂贵，版权与隐私约束增强 |
| 能耗 | 训练与推理的碳排成为选型因素 |
| 可解释性 | 归因方法（SHAP、注意力）只能部分回答"为什么" |
| 安全 | 对抗样本、后门、数据投毒、越狱 |

**模型压缩**（详见附录 E.8）：

| 方法 | 思路 | 压缩比 |
| --- | --- | --- |
| 量化 | FP32 → INT8/INT4 | 2–8× |
| 剪枝 | 去掉冗余权重/通道 | 2–10× |
| 蒸馏 | 小学生模仿教师 | 与架构相关 |
| 低秩分解 | 分解大矩阵 | 2–4× |

**一句话总结**：深度学习用**通用架构 + 大数据 + 大算力 + 好工程**替代了手工特征，代价是可解释性、能耗与数据依赖；它的边界仍在**长程推理、因果、样本效率与可靠性**。

## 本章小结

**核心要点**

1. 深度 = 层次化表示；非线性激活是前提，万能近似只保证表达力，不保证可学。
2. **反向传播 = 链式法则 + 动态规划**；反向模式自动微分是深度学习的基础设施。
3. 卷积用**局部连接 + 权值共享 + 等变性**大幅降低参数；ResNet 的残差连接是深层可训练的关键。
4. 优化与正则共同决定成败：AdamW + warmup + 归一化 + 数据增强是常见组合。
5. 深度网络的泛化不能用 VC 维解释；**隐式正则、双下降、规模法则**提供了部分答案。
6. RNN 的梯度消失在 LSTM 的门控与细胞状态中被缓解；Transformer 已成为序列建模主流。
7. 生成模型四条路线：AE/VAE（似然）、GAN（对抗）、扩散（去噪）、自回归（下一项预测）。
8. 预训练-微调与压缩（量化/蒸馏/剪枝）是落地的两大杠杆。
