# 第 11 章 自动规划（Automated Planning）

**本章导读**：搜索回答"怎么走"，规划回答"做什么"——在给定动作模型与目标条件下，自动合成一个动作序列（或策略）。规划是第 3 章搜索的"符号化升级"：状态由逻辑事实描述，动作由前提与效果描述，因此可以复用领域知识做启发式、可以做层次分解、可以处理时间与资源。本章从经典规划（STRIPS/PDDL）出发，依次讨论规划算法、启发式、层次规划、非确定性规划、时间与调度，最后给出方法选型。

**学习目标**：完成本章学习后，你应当能够：

- 用 STRIPS/PDDL 写出规划领域与问题，说明封闭世界假设与框架问题；
- 比较前向、后向状态空间搜索与偏序规划，说明规划图（GraphPlan）的构造与提取；
- 用删除松弛构造 $h_\text{add}$、$h_\text{max}$ 启发式，解释 FF 的爬山策略；
- 描述 HTN 的分解过程及其与经典规划的差异；
- 区分有条件规划、无感知规划与 POMDP 规划；
- 把时间、资源约束编码为调度问题或 SMT；
- 说明规划问题的复杂度（PSPACE 完全）及各方法的适用边界。

**预备知识**：第 3 章的启发式搜索、第 4 章的与或搜索与信念状态、第 6 章的 CSP（调度问题的基础）、第 8 章的 FOL。

## 11.1 经典规划的定义

**经典规划的假设**（四条，缺一即"非经典"）：

1. **完全可观察**；2. **确定性**；3. **静态**（无外部事件）；4. **仅目标驱动**（无软约束与效用）。

**STRIPS 表示**。一个**动作模式（action schema）** 由三部分组成：

```
Action(Fly(p, from, to))
  PRECOND: At(p, from) ∧ Plane(p) ∧ Airport(from) ∧ Airport(to)
  EFFECT:  ¬At(p, from) ∧ At(p, to)
```

- **前提（precondition）**：动作可执行的条件（合取）；
- **效果（effect）**：执行后的变化，分**添加表（add list）** 与**删除表（delete list）**；
- **封闭世界假设**：未列出的命题保持真；未被声明的原子为假。

**状态**是基原子（ground atom）的集合；**规划问题**是四元组 $(\text{Init}, \text{Goal}, \text{Actions}, \text{Cost})$。

**PDDL（Planning Domain Definition Language）** 是 STRIPS 的标准化扩展：

```lisp
(define (domain logistics)
  (:predicates (at ?x ?p) (in ?x ?v) (connected ?a ?b))
  (:action drive
    :parameters (?t ?from ?to)
    :precondition (and (truck ?t) (at ?t ?from) (connected ?from ?to))
    :effect (and (not (at ?t ?from)) (at ?t ?to))))

(define (problem log1)
  (:init (at truck1 cityA) (connected cityA cityB))
  (:goal (at truck1 cityB)))
```

扩展包括：**类型化参数**、**否定前提**、**条件效果**（`when`）、**量化效果**（`forall`）、**数值流**（`increase`、`decrease`，即 ADL 与 PDDL 2.1 的 fluents）。

**规划 vs 搜索**：规划问题可以被展平成状态空间搜索（第 3 章），但显式的动作模式带来两个优势：状态数的**符号压缩**（一个模式代表成千上万个基动作）与**领域知识的可表达性**（用于计算启发式）。

**复杂度**：经典规划（命题 STRIPS）的**有界长度**可解性是 **PSPACE 完全**的；带数值流时可判定性是开放的（取决于具体片段）。这意味着规划器必须依赖启发式，而非穷举。

## 11.2 经典规划算法

**（1）前向状态空间搜索**。从初始状态出发，对每个状态枚举所有"前提满足"的基动作。优点：简单、可直接用 A\*；缺点：分支因子大（每个动作模式可实例化出许多基动作）。

**（2）后向状态空间搜索（回归）**。从目标出发，反向应用动作：把目标中的动作效果"撤销"，加入前提。

- **相关性（relevance）**：只考虑能影响目标或已选动作的动作，剪枝明显；
- **难点**：回归需处理**部分状态**（目标只指定部分事实），且动作的删除效果可能使前提消失；
- 与 STRIPS 相比，**ADL 的条件效果**使回归复杂得多。

**（3）偏序规划（partial-order planning, POP）**。不预设动作顺序，只记录**必须先后**的约束：

- **步骤（steps）**：动作实例；
- **顺序约束（ordering）**：$A \prec B$；
- **因果链（causal links）**：$A \xrightarrow{p} B$，表示 $A$ 为 $B$ 提供前提 $p$；
- **开放前提（open precondition）**：尚无提供者的前提。

算法循环：**选开放前提 → 选提供者 → 加因果链 → 加顺序约束 → 处理威胁（threats）**。威胁指某动作可能删除因果链上的前提 $p$，需加顺序约束（把威胁动作排到提供者之前或消费者之后）或"分离（demotion/promotion）"。

优点：只对必要顺序做承诺，解空间更小，天然产生**偏序计划**（可并行执行）。

**（4）规划图与 GraphPlan**。**规划图（planning graph）** 是分层的：

- 命题层 $P_0, P_1, \dots$：第 $i$ 层能成立的事实；
- 动作层 $A_0, A_1, \dots$：第 $i$ 层可执行的动作。

每层由前一层按**添加效果**扩张，并计算**互斥关系（mutex）**：

- 两个动作互斥：前提冲突，或效果互相删除；
- 两个命题互斥：所有能产生它们的动作组合都互斥。

**GraphPlan 算法**：

1. 前向扩张规划图，直到所有目标出现在某层（否则不可解）；
2. 从目标层**后向提取**一个"不相冲突"的动作子集；
3. 若失败，回溯到更早的层重新提取（提取等价于搜一个 CSP）；
4. 若层数增加而不再出现新字面量（图已**稳定**），则不可解。

GraphPlan 的价值：**互斥约束**提供了强剪枝，且"图稳定即不可解"给出完备的终止条件。

## 11.3 规划的启发式

经典规划的启发式来自**松弛（relaxation）**：删掉动作的某些效果，让问题变简单但可解，其最优代价即为原问题的**可纳**估计。

**删除松弛（delete relaxation）**：忽略所有删除效果，只保留添加效果。此时子目标之间不再互相破坏，问题变成"从初始状态到目标的可达性"，可用**动态规划**在多项式时间（对命题情形）求解。

- **$h_\text{add}$**：假设子目标代价可加（但会重复计数），用于**快速估计**：$h_\text{add}(s) = \sum_{g} \text{cost}(g)$，简单但可能高估；
- **$h_\text{max}$**：取子目标代价的最大值，**可纳**（从不高估），但过于乐观；
- 两者之差刻画了子目标间的"正交互"程度。

**hFF 与 FF 规划器**。FF 用 $h_\text{add}$ 做**爬山搜索**（不做完整 A\*），并配合**有利动作（helpful actions）** 剪枝：只扩展那些"在松弛计划中出现过"的动作。它在多数基准上极快。

**其他启发式**：

| 启发式 | 思路 | 特点 |
| --- | --- | --- |
| 地标（landmarks） | 必经过的事实/动作 | 提供顺序约束与下界 |
| 模式数据库 | 对子问题预计算精确代价 | 昂贵但精确 |
| 状态抽象 | 合并状态（如只保留位置） | 可纳，粒度可控 |
| 学习型 | 用回归/网络预测 $h^*$ | 需要训练数据，泛化受限 |

**成本最优规划**：LAMA、Fast Downward 等使用**多启发式组合**（$h = \max(h_1, \dots, h_k)$ 仍可纳）与**惰性评估**（lazy evaluation），在 IPC（国际规划竞赛）中形成标准基线。

## 11.4 层次规划

**层次任务网络（hierarchical task network, HTN）** 把"怎么做"的知识直接编码进规划：任务分**复合任务**与**原始任务**，复合任务通过**方法（method）** 分解为子任务。

```
复合任务: 去机场
方法: 若 有车 → [开车到停车场, 走到航站楼]
      若 无车 → [叫出租车, 上车, 到机场]
```

HTN 的规划过程是**分解**而非搜索：从初始任务网络出发，反复选一个复合任务，用某方法替换为子任务，直到全为原始任务。

**与经典规划的对比**：

| 维度 | 经典规划 | HTN |
| --- | --- | --- |
| 知识形式 | 状态与目标 | 任务分解方法 |
| 搜索空间 | 状态空间 | 分解选择 |
| 优势 | 通用、可证明最优 | 高效、可编码领域经验 |
| 弱点 | 启发式难设计 | 需人工编写方法库 |
| 典型应用 | 基准竞赛、通用求解 | 游戏 AI、机器人任务编排、业务流程 |

HTN 的核心价值是**把"如何做"的经验前置**：它不搜索"世界状态序列"，而搜索"任务分解树"。代价是方法库必须覆盖所有情况，否则规划失败（**方法完备性**问题）。

**混合方法**：SHOP2 允许在分解过程中调用外部计算（如几何规划），把符号分解与数值计算结合，是真实机器人系统常用的架构。

## 11.5 非确定性领域中的规划与行动

放松"确定性"假设，规划从"序列"变成"策略"（第 4 章 §4.3–4.4）。

**（1）无感知规划（conformant planning）**。没有传感器，求一个动作序列，使**所有**可能的初始状态都达成目标。搜索在**信念状态空间**中进行，用 SAT/CP 编码常比显式搜索更有效。

**（2）有条件规划（conditional planning）**。有部分感知，策略按感知分支：

```
if 门开着 then 进入
else if 有钥匙 then 开门; 进入
else 找钥匙
```

**（3）FOND（fully observable non-deterministic）**。完全可观察但动作结果不确定，用**强解**（第 4 章）或**强循环解**。求解方法：

- **与或搜索** + 环检测；
- **归约为 AND-OR 图的可达性**；
- **策略迭代**（类 MDP，但用集合值而非概率）。

**（4）概率规划**。动作结果有概率分布时，规划问题就是 **MDP/POMDP**（第 17 章）：目标是最大化期望折扣回报，而非"保证达成"。此时"规划"与"决策"合流。

**（5）基于模型的强化学习**。学一个环境模型，在其上做规划（如 MCTS、Dyna，第 22 章），把"规划"与"学习"统一起来。

**关键对比**：

| 设定 | 解的形式 | 目标 |
| --- | --- | --- |
| 经典规划 | 动作序列 | 达成目标 |
| 无感知规划 | 序列（对所有初始状态有效） | 保证达成 |
| 有条件规划 | 策略树（按感知分支） | 保证达成 |
| FOND | 强解/强循环解 | 保证达成 |
| MDP/POMDP | 策略（状态/信念到动作） | 期望回报最大 |

## 11.6 时间、调度与资源

真实任务的动作用时、互相重叠、消耗资源，需要**时间规划（temporal planning）** 与**调度（scheduling）**。

**时间表示**：

- **时间点（time point）** 与**持续时间（duration）**；
- **区间约束**：动作 $A$ 结束到 $B$ 开始至少 $d$（simple temporal problem, STP），用差分约束求解（Bellman–Ford）；
- **STN（simple temporal network）**：把时间约束表示为 $t_j - t_i \le c$，一致性检查为负环检测。

**资源与调度**。调度问题通常是：

$$\min\ \text{makespan} \quad \text{s.t.}\ \text{任务顺序、资源容量、时限}$$

建模方式：

| 方法 | 表达 | 工具 |
| --- | --- | --- |
| 约束规划（CP） | 区间变量 + `cumulative` 约束 | OR-Tools CP-SAT |
| 混合整数规划（MIP） | 0-1 变量 + 线性约束 | Gurobi、CBC |
| SMT | 整数/实数理论 + 布尔结构 | Z3、cvc5 |
| 启发式调度 | 优先规则 + 局部搜索 | 遗传算法、禁忌搜索 |

**PDDL 2.1 的数值流**：

```lisp
(:action refuel
  :parameters (?t ?amount)
  :precondition (and (truck ?t) (>= (fuel ?t) ?amount))
  :effect (and (decrease (fuel ?t) ?amount)
               (increase (total-cost) 1)))
```

**时间与不确定性的交叉**：带持续时间的概率规划（MDP with durative actions）是机器人任务与制造调度的共同难题；实践中常用**分层**：上层用符号规划选任务，下层用优化或控制处理时间。

## 11.7 规划方法分析

**方法对比总表**：

| 方法 | 假设 | 解 | 优势 | 弱点 |
| --- | --- | --- | --- | --- |
| 前向 A\*+启发式 | 确定性、完全可观察 | 序列 | 通用、可最优 | 分支大 |
| 后向回归 | 同上 | 序列 | 相关性剪枝 | 部分状态难处理 |
| 偏序规划 | 同上 | 偏序计划 | 少做承诺、可并行 | 威胁处理复杂 |
| GraphPlan | 同上 | 并行计划 | 互斥剪枝强 | 规模受限 |
| HTN | 任务知识可得 | 分解树 | 高效、可编码经验 | 方法库需完备 |
| 有条件规划 | 部分可观察 | 策略树 | 鲁棒 | 指数膨胀 |
| MDP/POMDP | 概率转移 | 策略 | 期望最优 | 状态空间大 |
| 调度/CP/SMT | 时间资源约束 | 时间表 | 精确 | 建模成本高 |

**选择判据**：

1. **动作结果是否确定**？确定 → 经典规划；不确定但可观察 → FOND/MDP；不可观察 → conformant/POMDP。
2. **是否需要"如何做"的经验**？需要 → HTN；不需要 → 通用规划器。
3. **是否有时间/资源约束**？有 → 时间规划 + CP/SMT 调度。
4. **是否要求最优**？要求 → A\* + 可纳启发式；不要求 → FF/LAMA 类贪心。

**规划器的工程实践**：

- 用 **PDDL** 建模，交给 Fast Downward / LAMA / pyperplan；
- 用 **CP-SAT** 处理调度与资源；
- 用 **HTN** 层编排长期任务（机器人、游戏 AI）；
- 用 **MDP/POMDP** 处理不确定执行，与规划器形成"符号高层 + 概率低层"的分层架构。

**开放问题**：跨领域的启发式自动构造、规划与学习的紧耦合（附录 E.4）、大规模多智能体规划（第 18 章）、以及"目标从哪来"——规划只能优化给定目标，目标本身的正确性属于第 27 章的伦理问题。

## 本章小结

**核心要点**

1. 经典规划 = 完全可观察 + 确定性 + 静态 + 目标驱动；**STRIPS/PDDL** 用前提与效果描述动作模式，实现符号压缩。
2. 前向/后向状态空间搜索、偏序规划、**规划图 + GraphPlan** 是四类经典算法；偏序规划少做承诺，GraphPlan 用互斥做剪枝。
3. **删除松弛**是规划启发式的核心来源；$h_\text{max}$ 可纳但乐观，$h_\text{add}$ 快速但会重复计数，FF 用爬山 + 有利动作。
4. **HTN** 把"如何做"的经验编码为方法，用分解替代搜索；效率高但依赖方法库完备性。
5. 非确定性规划产出**策略**而非序列：无感知 → conformant，部分可观察 → 有条件规划，概率 → MDP/POMDP。
6. 时间与资源用 **STN + CP/SMT/MIP** 建模；真实系统常采用"符号高层 + 数值低层"的分层架构。
