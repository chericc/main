# 第 5 章 机器学习

**本章导读**：机器学习研究如何让程序从数据中自动改进性能。本章先建立统一视角——学习范式、泛化与偏差-方差权衡，再依次展开模型评估、线性模型、决策树、集成学习、支持向量机、聚类、降维与特征工程、贝叶斯学习，最后延伸到半监督与弱监督学习。阅读时建议始终抓住两条主线：一是"偏差-方差权衡"，用它解释过拟合、欠拟合与各种正则化手段；二是"归纳偏置"，理解每个算法为何在特定问题上有效。

## 5.1 基本概念

机器学习的形式化定义源自 Tom Mitchell (1998)：对于某类任务 `T` 和性能度量 `P`，若程序在 `T` 上以 `P` 衡量的性能随经验 `E` 而提升，则称该程序从经验 `E` 中学习。简言之，机器学习是让程序通过数据自动改进性能的计算方法。

按训练数据的标注情况，学习范式可分为五类。**监督学习**使用全标注样本 `(x_i, y_i)`，学习从输入到输出的映射，典型任务是分类（输出离散标签）与回归（输出连续值）；**无监督学习**只有输入 `{x_i}`，目标是在无标签数据中发现结构，包括聚类、降维与密度估计；**半监督学习**结合少量标注与大量无标注数据；**自监督学习**从数据自身构造前置任务自动生成标签，主要用于表征学习；**强化学习**则在奖励信号下做序贯决策，其完整主题见第 7 章。

| 类型 | 数据标注 | 核心任务 | 典型算法 |
|:---|:---|:---|:---|
| **监督学习** | 全标注 `(x_i, y_i)` | 分类、回归 | 线性模型、决策树、SVM、神经网络 |
| **无监督学习** | 无标注 `{x_i}` | 聚类、降维、密度估计 | K-Means、PCA、GMM、Autoencoder |
| **半监督学习** | 少量标注 + 大量无标注 | 分类、回归 | Self-training、Co-training、图方法 |
| **自监督学习** | 自动生成标签（前置任务） | 表征学习 | SimCLR、MoCo、BERT、GPT |
| **强化学习** | 奖励信号 | 序贯决策 | Q-Learning、Policy Gradient、DQN |

监督学习是最常讨论的范式。分类任务中二分类取 `y ∈ {0, 1}`、多分类取 `y ∈ {1, …, K}`，常用交叉熵损失；回归任务取 `y ∈ ℝ`，常用均方误差 (MSE)。下表汇总常见监督学习算法及其特点：

| 算法 | 类型 | 核心思想 | 可解释性 | 计算复杂度 |
|:---|:---|:---|:---:|:---:|
| k-近邻 (KNN) | 分类/回归 | 近邻投票/平均 | 高 | `O(n)` 推理 |
| 线性回归 | 回归 | 最小二乘拟合 | 高 | `O(d³)` 闭式解 |
| 逻辑回归 | 分类 | Sigmoid + 交叉熵 | 高 | `O(nd)` 迭代 |
| 决策树 | 分类/回归 | 递归划分特征空间 | 高 | `O(n d log n)` |
| SVM | 分类/回归 | 最大间隔 + 核技巧 | 中 | `O(n²)`~`O(n³)` |
| 神经网络 | 分类/回归 | 多层非线性变换 | 低 | `O(epochs·n·params)` |

无监督学习包含三条主线：**聚类**把数据划分为簇内相似、簇间相异的若干组（K-Means、DBSCAN、层次聚类、GMM）；**降维**把高维数据映射到低维并尽量保留结构（PCA、t-SNE、UMAP、Autoencoder）；**密度估计**估计数据分布 `p(x)`，用于异常检测与生成模型。

半监督学习结合少量标注 `{(x_i,y_i)}_{i=1}^L` 与大量无标注 `{x_j}_{j=L+1}^{L+U}`（通常 `L ≪ U`）。它依赖三个核心假设：**聚类假设**（同一簇内的点倾向同标签）、**流形假设**（高维数据分布在低维流形上，邻近点标签相似）与**平滑性假设**（输入相近则输出相近）。经典方法有 Self-training（用高置信度预测作为伪标签迭代扩充训练集）与 Co-training（在两个独立特征视图上互相标注），现代方法（一致性正则化、FixMatch、图半监督）详见 §5.10。

自监督学习不从外部标注学习，而从数据自身构造前置任务 (Pretext Task)：如掩码语言建模 (MLM)、判断数据变换类型、预测下一词 (NTP) 等，在此过程中学到可迁移的表征，代表应用包括 BERT、GPT 与对比学习（详见第 6 章 §6.13）。

**假设空间、版本空间与归纳偏置**是理解泛化的基础。**假设空间 (Hypothesis Space)** `H` 是算法可能输出的所有函数的集合；**版本空间 (Version Space)** 是其中与训练数据完全一致的所有假设的集合，随样本增加而收缩。**归纳偏置 (Inductive Bias)** 是算法在未见数据上做预测时先天具有的偏好，是从有限样本泛化的必要条件。例如线性回归偏好线性关系，KNN 偏好局部平滑，SVM 偏最大间隔，决策树偏好简单结构。**没有免费午餐定理 (No Free Lunch, NFL)** 指出：在所有可能的问题上平均而言，所有学习算法的性能相同——不存在在所有任务上都最优的算法。其实践启示是：模型选择的本质是把算法的归纳偏置与问题结构相匹配，需借助交叉验证与领域知识为具体任务选型。

| 算法 | 归纳偏置 | 偏好假设 |
|:---|:---|:---|
| 线性回归 | 线性假设 | 目标与特征线性相关 |
| 决策树 | 奥卡姆剃刀 | 更短更简单的树优先 |
| KNN | 局部平滑性 | 邻近点标签相似 |
| SVM | 最大间隔 | 分类边界离数据越远越好 |
| 神经网络 | 分布式表示、组合性 | 层级抽象特征 |
| 朴素贝叶斯 | 特征条件独立 | 特征间互不影响 |
| 随机森林 | 集成 + 随机子空间 | 多个弱模型平均更稳定 |
| CNN | 平移等变性、局部连接 | 空间局部模式重复出现 |

**泛化 (Generalization)** 关注模型在未见数据上的表现。**训练误差**是模型在训练集上的经验误差，**测试误差 / 泛化误差**是在独立同分布测试集上的误差，二者之差称为**泛化差距**——差距越小泛化越好。通常假设训练与测试数据独立同分布 (i.i.d.)；当分布偏移时泛化变难。

**过拟合 (Overfitting)** 指模型过度复杂，学到了训练数据中的噪声，表现为训练误差极低而测试误差很高（泛化差距大）。常见原因包括模型容量过高、训练数据不足、数据噪声大、迭代次数过多。检测方法是观察训练/验证误差随复杂度或训练轮数的曲线——验证误差开始上升而训练误差继续下降即为过拟合起点。缓解手段汇总如下：

| 方法 | 原理 | 典型手段 |
|:---|:---|:---|
| **正则化** | 约束模型复杂度 | L1/L2 正则化、Dropout |
| **早停** | 验证误差不再下降时终止 | 监控验证集，保留最优 checkpoint |
| **增加数据** | 使噪声被平均化 | 收集更多数据、数据增强 |
| **交叉验证** | 多次划分评估并选模型 | k-fold CV、留一法 |
| **模型简化** | 降低容量 | 减少层/神经元、特征选择、剪枝 |
| **集成学习** | 多模型综合降低方差 | Bagging、随机森林 |

**欠拟合 (Underfitting)** 则是模型过于简单，无法捕捉真实模式，训练与测试误差都高。对策是增加模型容量、引入更多特征、减弱正则化、延长训练或换用更强模型。

**偏差-方差权衡 (Bias-Variance Tradeoff)** 把泛化误差分解为三部分（详见 §5.2）：**偏差**是模型期望预测与真实值的差距，反映拟合能力不足，高偏差对应欠拟合；**方差**是模型在不同训练集上预测的波动，反映对数据扰动的敏感度，高方差对应过拟合；另有数据固有噪声（不可约误差）。随着模型复杂度增加，偏差下降、方差上升，总误差呈 U 形曲线，最优模型在二者平衡处。

最后，**维数灾难 (Curse of Dimensionality)** 指出：特征维数增加会使数据在空间中变稀疏，任意两点距离趋于相等（距离度量失效），维持相同密度所需样本量指数增长，基于距离的算法（KNN、K-Means）性能急剧下降。对策包括降维、特征选择、流形学习与利用稀疏性先验。

## 5.2 模型评估与选择

模型评估要回答的核心问题是：给定一个训练好的模型，它在未见数据上表现如何？评估既用于在候选模型中做选择，也用于诊断欠拟合/过拟合与调参。

最基础的方案是**留出法 (Holdout)**：把数据划分为训练集与测试集，在训练集拟合、测试集评估，比例常取 70/30 或 80/20。其优点是简单、开销小，缺点是结果对划分敏感、小样本时方差大。对分类任务常配合**分层采样 (Stratified Sampling)**，保持训练集与测试集中类别比例一致，以应对不平衡数据。

**交叉验证 (Cross-Validation)** 解决了留出法方差大的问题。**k 折交叉验证**把数据等分为 `k` 个互斥子集，依次以其中一个为测试集、其余 `k-1` 个为训练集，最终取 `k` 次评估的均值；`k=5` 或 `10` 最常用，`k` 越大偏差越小但计算量越大。当 `k=N` 时即**留一交叉验证 (LOOCV)**，评估几乎无偏但需训练 `N` 次、开销巨大。分类任务的标准做法是**分层 k 折**，而**重复 k 折**通过多次随机划分取平均进一步降低方差。

**偏差-方差分解**是理解泛化误差的经典框架。设真实关系 `y = f(x) + ε`（`E[ε]=0`，`Var[ε]=σ²`），则平方误差下：

$$E[(y - \hat{f}(x))^2] = \underbrace{(Bias[\hat{f}(x)])^2}_{(\text{偏差})^2} + \underbrace{Var[\hat{f}(x)]}_{\text{方差}} + \underbrace{\sigma^2}_{\text{不可约误差}}$$

其中偏差 `Bias[f̂(x)] = E[f̂(x)] - f(x)` 衡量拟合能力，高偏差意味着欠拟合；方差 `Var[f̂(x)] = E[(f̂(x) - E[f̂(x)])²]` 衡量对训练数据扰动的敏感度，高方差意味着过拟合；`σ²` 是数据噪声下界，任何模型都无法消除。模型复杂度低时高偏差低方差，复杂度高时低偏差高方差，最优模型使总误差最小——训练误差持续下降而测试误差呈 U 形先降后升。

分类任务的评估指标以**混淆矩阵**为基础：

|  | 预测为正 | 预测为负 |
|:---|:---:|:---:|
| **实际为正** | **TP** | **FN** |
| **实际为负** | **FP** | **TN** |

由此定义常用指标。**准确率** `ACC = (TP+TN)/(TP+TN+FP+FN)` 简单直观，但在类别不平衡时严重误导（99% 负样本时全判负仍有 99% 准确率）。**精确率** `P = TP/(TP+FP)` 回答"模型说正时有多可信"，关注误报代价；**召回率** `R = TP/(TP+FN)` 回答"捕捉到了多少正例"，关注漏报代价；**F₁** `= 2PR/(P+R)` 是二者的调和平均，只有两者都高时 F₁ 才高；**F_β** `= (1+β²)PR/(β²P+R)` 是加权推广，`β>1` 侧重召回（如医学筛查），`β<1` 侧重精确（如垃圾邮件检测）；**特异性** `TNR = TN/(TN+FP)` 是负样本的召回率。

**ROC 曲线**以真正例率 (TPR/Recall) 为纵轴、假正例率 `FPR = FP/(FP+TN)` 为横轴，在不同阈值下绘制，从左下 `(0,0)` 到右上 `(1,1)`，理想模型贴近左上角。**AUC** 是 ROC 曲线下面积：`AUC=1` 为完美分类器，`0.5` 等同随机猜测，`<0.5` 比随机还差。AUC 等价于随机取一正一负样本、模型给正样本打分更高的概率，具有尺度不变性，且因 TPR 与 FPR 都是类内比例而对类别不平衡不敏感。当负样本极多时，**PR 曲线**（精确率为纵轴、召回率为横轴）比 ROC 更能反映稀有正类的真实表现，其曲线下面积称为 **Average Precision (AP)**。

回归任务常用指标包括：**MSE** `= (1/N)Σ(y_i - ŷ_i)²` 对大误差惩罚重；**RMSE** `= √MSE` 恢复原始量纲但对异常值敏感；**MAE** `= (1/N)Σ|y_i - ŷ_i|` 对异常值鲁棒但导数不连续；**R²** `= 1 - SS_res/SS_tot` 衡量解释的方差比例（`R²=0` 等效于用均值预测，`<0` 比均值还差）；**调整 R²** 对特征数施加惩罚；**MAPE** 以百分比衡量、尺度无关，但目标接近 0 时失效。

**正则化 (Regularization)** 通过在损失上添加惩罚项约束模型复杂度：`J(θ) = Loss(θ) + λ·R(θ)`，`λ` 越大惩罚越强、模型越简单。**L1 正则化 (Lasso)** 惩罚 `∥w∥₁ = Σ|w_j|`，产生稀疏解、实现自动特征选择，适合特征数远大于样本数或需要可解释稀疏模型的场景；**L2 正则化 (Ridge)** 惩罚 `∥w∥₂² = Σw_j²`，使权重整体缩小但不为零、产生更平滑稳定的解，又称权重衰减 (Weight Decay)，对共线性特征会均匀分配权重；**Elastic Net** 结合两者 `R(w) = α∥w∥₁ + (1-α)∥w∥₂²`，兼具稀疏性与稳定性。从贝叶斯视角看，L2 等价于对参数施加高斯先验的 MAP 估计，L1 等价于拉普拉斯先验。

| 正则化方法 | 惩罚项 | 稀疏解 | 特征选择 | 共线性处理 | 等效先验 |
|:---|:---|:---:|:---:|:---|:---|
| **L1 (Lasso)** | `λ∥w∥₁` | ✅ | ✅ 自动 | 随机选一个 | Laplace |
| **L2 (Ridge)** | `λ∥w∥₂²` | ❌ | ❌ | 均匀分配 | Gaussian |
| **Elastic Net** | `λ(α∥w∥₁+(1-α)∥w∥₂²)` | ✅ | ✅ 组选择 | 折中 | 混合 |

**超参数调优**针对训练前设定、不通过训练学习的参数（如 `λ`、`k`、学习率）。**网格搜索**穷举候选组合并用交叉验证评估，简单可并行，但组合数随维度指数爆炸；**随机搜索**在超参数空间随机采样，因并非所有超参数同等重要，通常能在同样预算下探索更多关键维度，Bergstra & Bengio (2012) 证明其多数情况下不劣于网格搜索；**贝叶斯优化**构建"超参数→验证性能"的代理模型（常用高斯过程），由采集函数（如 Expected Improvement）在探索与利用间权衡，用更少评估找到更优解，适合单次评估代价高昂的场景；此外还有 Hyperband、进化算法等。

比较模型时需判断性能差异是否显著。**配对 t 检验**在相同划分下比较两模型多轮结果的均值差异，但假设差值正态且样本独立，而 k 折 CV 各折训练集重叠会导致独立性不成立、高估显著性。**McNemar 检验**针对两分类器在同一测试集上的对错构造 2×2 列联表，不依赖正态假设但只用 0/1 信息。**Wilcoxon 符号秩检验**是配对 t 检验的非参数替代，更稳健，是机器学习实验比较的推荐方法 (Demšar, 2006)。**5×2 交叉验证配对 t 检验**通过 5 次 2 折 CV 的设计缓解独立性问题。

| 检验方法 | 假设 | 适用场景 | 注意事项 |
|:---|:---|:---|:---|
| **配对 t 检验** | 差值正态、样本独立 | 多数据集/多轮比较 | 常规 k 折违背独立性 |
| **McNemar 检验** | 卡方分布 | 两分类器同一测试集比较 | 仅用对错信息 |
| **Wilcoxon 符号秩** | 差值对称分布 | 通用稳健的配对比较 | 推荐为默认方法 |
| **5×2 CV t 检验** | 改进的 t 分布 | 需要较严格检验时 | 一定程度上修复独立性 |

## 5.3 线性模型

线性模型用特征的线性组合做预测或分类，是最基础也最可解释的一类模型。

**线性回归 (Linear Regression)** 的模型为 `y = w·x + b`，目标是最小化均方误差 `J(w,b) = (1/n)Σ(y_i - ŷ_i)²`。对 `J` 求导令梯度为零可得**正规方程**闭式解 `w* = (XᵀX)⁻¹Xᵀy`，适用条件是 `XᵀX` 可逆（`d < n` 且特征线性无关）。当 `n` 或 `d` 很大时改用**梯度下降**迭代 `w := w - α·∇_w J`，其中 `∇_w J = (1/n)Xᵀ(Xw - y)`。其基本假设包括线性性、同方差性、误差独立，以及误差正态性（主要用于统计推断而非最小二乘计算本身）。通过构造高次特征 `ŷ = w_0 + w_1x + … + w_kx^k` 可得到**多项式回归**，它本质仍是关于参数的线性模型。在线性回归上加 L2 惩罚得 Ridge 回归，闭式解为 `w* = (XᵀX + λI)⁻¹Xᵀy`，`λI` 项同时保证可逆并适合处理多重共线性；加 L1 惩罚得 Lasso，产生稀疏解但无闭式解，需用坐标下降等数值方法。

**逻辑回归 (Logistic Regression)** 虽名"回归"，实为分类模型。它用 Sigmoid 函数 `σ(z) = 1/(1+e^{-z})` 把线性输出映射到 `(0,1)` 区间：`P(y=1|x) = σ(w·x + b)`。其决策边界 `w·x + b = 0` 是一个超平面，与线性回归共享相同的决策面结构；损失函数为交叉熵（对数损失）`L(w) = -(1/n)Σ[y_i log ŷ_i + (1-y_i)log(1-ŷ_i)]`，其梯度 `∂L/∂w = (1/n)Xᵀ(ŷ - y)` 与线性回归 MSE 梯度形式完全一致，唯一差别是 `ŷ` 换成了 Sigmoid 输出。逻辑回归天然输出概率、权重可直接解释为对 log-odds 的影响、推理高效，是风险建模与排序的常用工具。多分类时可用 **One-vs-Rest (OvR)**（训练 `K` 个二分类器取最高概率）或 **One-vs-One (OvO)**（训练 `K(K-1)/2` 个分类器投票），二者都是基于二分类器的组合策略。

**Softmax 回归**直接处理多分类，对每个类别计算线性得分后经 softmax 归一化：`P(y=k|x) = exp(w_k·x) / Σ_j exp(w_j·x)`。为避免参数冗余（概率和为 1 引入一个自由度），实践中常固定 `w_1=0`。其损失为类别交叉熵 `L(W) = -(1/n)Σ_i Σ_k y_{ik} log P(y_i=k|x_i)`，其中 `y_{ik}` 为 one-hot 标签。当 `K=2` 时 softmax 退化为逻辑回归；与 OvR/OvO 不同，softmax 联合训练所有类别参数，且输出满足概率公理化。

**线性判别分析 (LDA)** 是生成式模型，直接对 `P(x|y)` 建模再用贝叶斯公式得 `P(y|x)`。它假设每类条件分布为多元高斯 `P(x|y=k) ~ N(μ_k, Σ)` 且**共享协方差矩阵**，由此得到的对数概率比是 `x` 的线性函数，产生线性决策边界，判别函数为 `δ_k(x) = xᵀΣ⁻¹μ_k - ½μ_kᵀΣ⁻¹μ_k + log π_k`，预测取 `argmax_k δ_k(x)`。**Fisher's LDA** 从另一视角出发，不假设高斯分布，而是寻找投影方向 `v` 使类间散度 `S_B` 最大、类内散度 `S_W` 最小，即最大化广义 Rayleigh 商 `J(v) = (vᵀS_B v)/(vᵀS_W v)`，最优解为 `S_W⁻¹S_B` 最大特征值对应的特征向量。若放松共享协方差假设、令每类各有 `Σ_k`，则对数概率比含二次项，决策边界变为二次曲面，即**二次判别分析 (QDA)**。

LDA 与逻辑回归都产生线性边界，但建模方式不同：

| 维度 | Logistic Regression | LDA |
|:---|:---|:---|
| 模型类型 | 判别式 | 生成式 |
| 建模对象 | 直接建模 `P(y\|x)` | 建模 `P(x\|y)` 与 `P(y)` |
| 分布假设 | 无（更鲁棒） | 高斯 + 共享协方差 |
| 优势场景 | 稳健，不依赖分布假设 | 高斯假设成立时（尤其小样本）效率更高 |
| 参数估计 | 迭代优化 | 闭式解（均值 & 协方差） |
| 异常值敏感 | 相对鲁棒 | 敏感（均值/协方差易受影响） |

四个线性模型可归纳为：线性回归做连续预测，逻辑回归做二分类且与线性回归梯度同形，softmax 是逻辑回归的多类联合推广，LDA 则从生成式角度假设高斯分布——它们共同构成经典线性分类与回归框架。

## 5.4 决策树

**决策树 (Decision Tree)** 通过对特征空间的**递归划分**完成分类或回归，模拟"分而治之"的决策过程：从根节点开始依次测试样本属性，按结果分配到不同分支，最终在叶节点得到预测。树由三类节点构成：**根节点**包含全部样本并执行首次划分，**内部节点**对应属性测试，**叶节点**输出预测（分类树取多数类，回归树取均值）。

决策树学习的核心是选择最优分裂属性，关键在于**分裂准则 (Splitting Criteria)**——衡量划分前后节点"纯度 (Purity)"变化的指标。

**熵 (Entropy)** 度量节点不确定性，对含 `K` 个类别的数据集 `S`，设第 `i` 类比例为 `p_i`，则 `H(S) = -Σ p_i log₂ p_i`。样本同属一类时 `H=0`（最纯），均匀分布时 `H=log₂K`（最不纯），单位为比特。**基尼不纯度 (Gini Impurity)** 是 CART 分类树的默认准则：`Gini(S) = 1 - Σ p_i²`，可解释为随机抽两个样本类别不一致的概率，值越小越纯，最大为 `1-1/K`；它不涉及对数运算、计算更快，且倾向产生更均衡的分裂。**分类误差** `Error(S) = 1 - max(p_i)` 只关注多数类比例，对纯度细微变化不敏感，故很少直接用于分裂（多用作剪枝参考）。

| 分裂准则 | 公式 | 最小值（最纯） | 最大值（最不纯） | 主要算法 |
|:---|:---|:---:|:---:|:---|
| **Entropy** | `-Σ p_i log₂ p_i` | 0 | `log₂ K` | ID3, C4.5 |
| **Gini Impurity** | `1 - Σ p_i²` | 0 | `1 - 1/K` | CART（分类） |
| **Classification Error** | `1 - max(p_i)` | 0 | `1 - 1/K` | 极少用于分裂 |

**信息增益 (Information Gain)** 是 ID3 的准则：`IG(S,A) = H(S) - Σ_v (|S_v|/|S|) H(S_v)`，即父节点熵减去加权子节点熵之和，IG 越大说明该属性越能降低不确定性。其关键缺陷是**偏好取值数目多的属性**——极端如"身份证号"每个值只对应一个样本，`H(S_v)=0`、IG 最大，却完全过拟合。

**增益率 (Gain Ratio)** 是 C4.5 的改进：`GR(S,A) = IG(S,A)/SplitInfo(S,A)`，其中分裂信息 `SplitInfo = -Σ_v (|S_v|/|S|)log₂(|S_v|/|S|)` 度量划分子集的均匀程度，取值多且均匀时很大，从而**惩罚多值属性**。C4.5 实际采用两阶段筛选：先选 IG 高于平均值的候选，再取 GR 最高者；但 GR 有时又会极端偏好取值极少的属性，故需与 IG 配合。

**ID3 (Quinlan 1986)** 每次选择信息增益最大的属性分裂，递归构建直到样本同类或无属性可用。其局限性包括：仅支持离散特征、无剪枝机制、IG 固有偏差、无缺失值处理、不支持回归。通用决策树归纳过程如下：

```text
TreeGenerate(D, A):                      # D 样本集, A 候选属性集
    生成节点 node
    if D 中样本全属同一类别 C: return 叶节点(C)
    if A 为空 或 D 在 A 上取值相同: return 叶节点(D 中多数类)
    选择最优分裂属性 a* ∈ A            # ID3: 最大 IG; C4.5: 最大 GR; CART: 最大 Gini/MSE 增益
    for a* 的每个取值 v:
        生成分支; D_v ← D 中 a* = v 的子集
        if D_v 为空: 分支 → 叶节点(D 中多数类)
        else: 分支 → TreeGenerate(D_v, A \ {a*})
    return 以 node 为根的子树
```

**C4.5 (Quinlan 1993)** 在 ID3 基础上做了四项改进：用增益率替代信息增益以缓解多值偏好；对连续属性排序后取相邻点中位数为候选阈值做二元分裂，选择 IG 最大的阈值，且同一属性可在不同节点重复使用；对缺失值采用**概率分配**——计算信息增益时只用无缺失样本并加权，分配缺失样本时按各分支已知样本比例拆分；引入**后剪枝**，包括需要额外验证集的减少误差剪枝 (REP)、基于训练集统计校正的悲观剪枝 (PEP)，以及将树转为规则后独立泛化剪枝的规则后剪枝（C4.5 默认策略）。

**CART (Breiman 1984)** 最本质的特点是始终产生**二叉树**，每个内部节点恰有两个子节点。分类树用基尼增益 `ΔGini = Gini(S) - (|S_left|/|S|)Gini(S_left) - (|S_right|/|S|)Gini(S_right)` 作为准则；回归树用方差缩减或最小化 MSE，叶节点输出该节点样本均值。处理缺失值采用**代理分裂 (Surrogate Splits)**——为每个节点存储若干与最优分裂高度相关的备用规则，预测时据此决定缺失样本的去向。其剪枝采用**代价复杂度剪枝 (CCP)**：定义 `R_α(T) = R(T) + α|T|`，`R(T)` 为误分类代价、`|T|` 为叶节点数、`α≥0` 为复杂度惩罚；先生成充分大的树 `T₀`，再自底向上剪除"最弱链接"，得到一系列嵌套子树，最后用交叉验证选最优 `α`。

| 维度 | ID3 | C4.5 | CART |
|:---|:---|:---|:---|
| 分裂准则 | Information Gain | Gain Ratio | Gini / MSE |
| 树结构 | 多叉树 | 多叉树 | 仅二叉树 |
| 连续属性 | 不支持 | 二元分裂（阈值） | 二元分裂（阈值） |
| 缺失值处理 | 不支持 | 概率分配 | 代理分裂 |
| 剪枝方式 | 无 | 后剪枝（PEP/REP/Rule） | 代价复杂度剪枝 (CCP) |
| 回归支持 | 不支持 | 不支持 | 支持 |

**过拟合与剪枝**是决策树实用化的关键。不加限制的树会生长到每个叶节点只含极少量样本，完美记忆训练数据。剪枝分两类：**预剪枝**在生长过程中提前终止，通过最大深度、叶节点/内部节点最小样本数、最小不纯度减少等阈值实现，优点是训练快、无需额外数据，缺点是可能"近视"地错失后续有益分裂；**后剪枝**先完全生长再自底向上修剪，包括 REP、CCP、PEP，通常效果更好（先看到全局结构再修剪）但开销更大。

决策树的优点包括：**高度可解释**（决策路径可追踪，适合金融风控、医疗诊断等需要解释的场景）、**无需特征缩放**、**自动处理混合数据类型**、**隐含特征选择**（靠近根节点的即最有区分力的特征）、对异常值和缺失值有一定鲁棒性。其缺点也很突出：**不稳定**（对训练数据微小变化极敏感，方差高）、**贪心**（每次只做局部最优，无法保证全局最优树）、**偏向多数类**、**难以捕捉 XOR 类交互**（需多层交替分裂）、以及**轴平行分裂**的局限（斜决策边界需大量阶梯状划分逼近）。为克服这些局限，出现了**斜决策树**（内部节点用特征线性组合做超平面切割）与**模型树**（叶节点是局部线性回归模型，如 M5/M5'），而更主流的方案是**集成学习**——用 Bagging 或 Boosting 组合多棵树，见 §5.5。

## 5.5 集成学习

**集成学习 (Ensemble Learning)** 的核心思想是组合多个**弱学习器**（准确率略高于随机猜测的模型）构造一个**强学习器**，从而获得比单一模型更优的泛化性能。其理论基础来自 Kearns & Valiant (1988) 提出的"弱学习器能否被提升为强学习器"。

集成为何有效，可从三个角度理解：**统计原因**——训练数据有限时可能有多个假设表现相当，集成通过投票/平均降低选错假设的风险；**计算原因**——许多算法容易陷入局部最优，从不同起点训练多个模型并集成可降低陷于局部最优的概率；**表示原因**——单一模型的假设空间可能不包含真实目标函数，组合多个简单模型可扩展可表达的假设空间。

**Bagging (Bootstrap Aggregating, Breiman 1996)** 通过重采样降低方差。它对包含 `n` 个样本的数据集**有放回**抽取 `n` 个样本形成 Bootstrap 样本，每个样本在 `n` 次抽取中从未被选中的概率为 `(1-1/n)^n ≈ e⁻¹ ≈ 0.368`，故每个样本约含 63.2% 的原始样本，剩余约 36.8% 称为**袋外样本 (OOB)**。在每个 Bootstrap 样本上独立训练基学习器（通常用对扰动敏感的决策树），分类任务用多数投票、回归任务用简单平均聚合。

```text
输入: 数据 D = {(x_i, y_i)}_{i=1}^n, 基学习器算法 L, 轮数 M
for m = 1, 2, ..., M:
    D_m ← Bootstrap(D)                 # 有放回抽样 n 个样本
    h_m ← L(D_m)
分类: H(x) = argmax_y Σ_m I(h_m(x) = y)
回归: H(x) = (1/M) Σ_m h_m(x)
输出: 集成模型 H
```

设基学习器方差为 `σ²`、两两相关系数为 `ρ`，则 `M` 个模型平均后的方差为 `ρσ² + (1-ρ)σ²/M`——Bagging 通过降低相关性 `ρ` 显著降低方差。其 OOB 样本可用于估计泛化误差，相当于"免费"的交叉验证；Bagging 主要降低方差，对决策树、神经网络等不稳定学习器效果显著，对 kNN、SVM 等稳定学习器效果有限。

**随机森林 (Random Forest, Breiman 2001)** 在 Bagging 基础上引入**随机特征选择**，形成双重随机性：数据层面的 Bootstrap 采样，以及特征层面的随机子空间——每个分裂节点先从全部 `d` 个特征中随机选取 `m` 个候选，再在其中找最优分裂。分类通常取 `m ≈ √d`，回归取 `m ≈ d/3`；`m=d` 时退化为普通 Bagging。由于强特征总在根节点附近被选中，普通 Bagging 的树仍可能高度相关，随机特征选择强制各树从不同子空间构建，**进一步降低相关性 `ρ`** 从而降低集成方差。

随机森林可输出**特征重要性**：平均纯度减少 (MDI) 统计每个特征带来的不纯度减少量并在树上平均，计算快但偏好高基数特征；排列重要性则打乱 OOB 样本中某特征的值、观察误差增幅，更无偏但代价更高。它还可构造**邻近矩阵**（两样本落入同一叶节点的频率），用于离群点检测、缺失值填补与无监督聚类；OOB 误差随树数 `M` 的曲线可帮助选择 `M`。

**Boosting** 的思想与 Bagging 相反：将弱学习器**串行训练**，每个后续学习器聚焦前序的错误，最终加权组合。**AdaBoost (Freund & Schapire 1995)** 给每个样本赋权重，初始相等；每轮训练后提高被错分样本的权重、降低正确分类样本的权重，迫使下一轮关注"难题"。第 `t` 个学习器的加权错误率为 `ε_t`，其投票权重 `α_t = ½ ln((1-ε_t)/ε_t)`——`ε_t=0.5`（随机猜测）时 `α_t=0` 被忽略，`ε_t→0` 时 `α_t→∞` 获得极大话语权；权重更新为 `w_i ← w_i exp(-α_t y_i h_t(x_i))`，最终预测 `H(x) = sign(Σ_t α_t h_t(x))`。从损失视角看，AdaBoost 等价于在**指数损失** `L = exp(-y f(x))` 下做前向分步加法建模。其理论性质是训练误差上界 `≤ exp(-2Σ γ_t²)`（`γ_t = 0.5-ε_t`），只要每个弱学习器略优于随机猜测，误差就指数衰减；即使训练误差降为 0，继续迭代仍可能通过增大分类间隔提升测试性能。AdaBoost 的缺点是**对噪声和离群点敏感**，被错标样本会持续获得高权重。

**梯度提升 (Gradient Boosting, Friedman 2001)** 把 Boosting 推广到任意可微损失，视为**函数空间中的梯度下降**：每轮训练新学习器拟合当前损失关于预测值的**负梯度（伪残差）**。设前 `m-1` 轮模型为 `F_{m-1}`，计算伪残差 `r_{im} = -[∂L(y_i, F(x_i))/∂F(x_i)]`，训练 `h_m` 拟合 `{(x_i, r_{im})}`，再更新 `F_m = F_{m-1} + η·h_m`，其中学习率（收缩）`η` 通常取 `(0.01, 0.1]`——小 `η` 配更多树通常泛化更好。常见损失对应不同伪残差：平方误差给出普通残差 `y-F`，绝对误差给出 `sign(y-F)`，Huber 损失在小残差用平方、大残差用绝对值以兼顾精度与鲁棒性。AdaBoost 本质上是梯度提升在指数损失下的特例。

**GBDT (Gradient Boosting Decision Tree)** 将基学习器固定为决策树（通常为 CART 回归树），每棵树拟合当前负梯度。树通常很浅（深度 3~6），作为弱学习器仅捕捉少量模式，大量浅树叠加后逼近复杂函数；叶子输出该叶内伪残差的均值，或通过一维线搜索优化。

**XGBoost (Chen & Guestrin 2016)** 在 GBDT 上做了多项关键改进。它明确加入正则化目标 `Obj = Σ L(y_i, ŷ_i) + Σ_k Ω(f_k)`，其中 `Ω(f) = γT + ½λ∥w∥²`，`T` 为叶子数、`w` 为叶子权重，有效防止过拟合。它对目标做**二阶泰勒展开**，同时使用一阶梯度 `g_i` 与二阶 Hessian `h_i`，既更精确地衡量分裂增益，也让自定义损失只需提供 `g`、`h`。叶子最优权重为 `w_j* = -Σ_{i∈I_j} g_i / (Σ_{i∈I_j} h_i + λ)`，分裂增益为 `Gain = ½[G_L²/(H_L+λ) + G_R²/(H_R+λ) - (G_L+G_R)²/(H_L+H_R+λ)] - γ`，仅当增益为正才分裂（天然预剪枝）。此外还有**近似分裂查找**（用加权分位数略图提出候选切分点）、**稀疏感知**（自动学习缺失值的默认方向）、**列块**缓存感知与**核外计算**等系统优化。

**LightGBM (微软 2017)** 主打训练速度与内存效率。**GOSS** 保留所有大梯度样本、对小梯度样本随机采样并放大其贡献，减少参与训练的样本数；**EFB** 利用高维稀疏数据中特征互斥的特性，通过图着色把互斥特征捆绑为一个，将特征数减少一个数量级；**Leaf-wise** 生长策略每次分裂当前损失下降最大的叶子，同等叶子数下误差更低，但需用 `max_depth`、`min_data_in_leaf` 约束以防过深；**直方图算法**把连续值离散为 `k`（通常 255）个 bin，并利用父节点直方图减子节点得到兄弟节点直方图来加速；此外原生支持类别特征，无需 One-Hot。大规模数据上，LightGBM 通常比 XGBoost 快 5~10 倍、内存更低。

| 维度 | Bagging | 随机森林 | AdaBoost | GBDT | XGBoost | LightGBM |
|:---|:---|:---|:---|:---|:---|:---|
| 训练方式 | 并行 | 并行 | 串行 | 串行 | 串行 | 串行 |
| 基学习器 | 任意 | 决策树 | 任意弱学习器 | 浅决策树 | CART 回归树 | 直方图决策树 |
| 主要降低 | 方差 | 方差（更优） | 偏差 + 方差 | 偏差 | 偏差 + 方差 | 偏差 + 方差 |
| 特征扰动 | 无 | 随机子集 | 无 | 无 | 列采样可选 | EFB 可选 |
| 缺失值 | 需预处理 | 需预处理 | 需预处理 | 需预处理 | 自动 | 自动 |
| 类别特征 | 需编码 | 需编码 | 需编码 | 需编码 | 需编码 | 原生支持 |

从偏差-方差角度看：Bagging/随机森林的基学习器通常是强拟合的深树（低偏差高方差），集成后主要降方差；Boosting 的基学习器通常是弱拟合的浅树（高偏差低方差），串行组合后主要降偏差；XGBoost/LightGBM 则通过学习率、正则化与子采样同时控制偏差和方差。

**Stacking (Wolpert 1992)** 不采用固定规则，而是用**元学习器 (Meta-Learner)** 学习如何最优组合基学习器的输出。标准流程用 `K` 折交叉验证避免数据泄露：把训练数据分为 `K` 折，对每个基学习器用 `K-1` 折训练、留出 1 折预测，轮转完毕后每个训练样本都得到一个**袋外预测特征**；再以所有基学习器的 OOF 预测为**元特征**、原始标签为目标训练元学习器（常为线性模型或简单 GBDT）；测试时用完整训练数据重训基学习器，其预测输入元学习器得最终结果。元学习器能学到"哪个基学习器在哪类样本上更可靠"，但两级训练增加了过拟合风险，必须严格用交叉验证避免泄漏。**Blending** 是其简化变体：直接把训练集划分为两部分，用一部分训练基学习器、另一部分产生元特征训练元学习器——更简单更快，但训练数据利用率低、元学习器可能不稳定，适合大数据量或快速实验。

## 5.6 支持向量机

**支持向量机 (SVM)** 的核心思想是寻找一个**最大间隔超平面**分隔不同类别，超平面由距其最近的**支持向量**唯一决定，天然适合小样本、高维数据。

**硬间隔 SVM** 处理线性可分情形。超平面为 `w·x + b = 0`，样本到超平面的**函数间隔**为 `γ̂_i = y_i(w·x_i + b)`，归一化后的**几何间隔**为 `γ_i = γ̂_i/∥w∥`，两类间隔边界之间的宽度为 `γ = 2/∥w∥`。最大化间隔等价于最小化 `½∥w∥²`，约束为 `y_i(w·x_i + b) ≥ 1`（所有样本正确分类且距超平面至少 1）。恰好落在间隔边界上、满足 `w·x + b = ±1` 的点即支持向量。这是一个凸二次规划问题，存在唯一全局最优解。

**软间隔 SVM** 处理线性不可分或含噪声的情形，引入松弛变量 `ξ_i ≥ 0` 允许部分样本不满足约束，将约束放松为 `y_i(w·x_i + b) ≥ 1 - ξ_i`，目标改为 `min ½∥w∥² + CΣξ_i`，在最大化间隔与最小化误分类间折中。惩罚参数 `C` 控制权衡：`C` 大则趋向硬间隔、对误分类惩罚重、可能过拟合；`C` 小则容忍更多误分类、间隔更宽、正则化更强、可能欠拟合。

**对偶问题**通过 Lagrange 乘子 `α_i ≥ 0` 将原始问题转化为对偶形式 `max Σα_i - ½ΣΣα_iα_jy_iy_j(x_i·x_j)`，约束为 `0 ≤ α_i ≤ C` 且 `Σα_i y_i = 0`。其关键性质是：只有支持向量的 `α_i > 0`，非支持向量 `α_i = 0`，故解是稀疏的；决策函数仅依赖支持向量 `f(x) = sign(Σα_i y_i(x_i·x) + b)`；对偶形式中只出现内积 `x_i·x_j`，这为核方法铺平了道路。

**核方法 (Kernel Trick)** 把数据映射到高维特征空间 `x → φ(x)`，在高维中寻找线性超平面以处理非线性可分数据。由于对偶形式只需内积 `φ(x_i)·φ(x_j)`，定义核函数 `K(x_i, x_j) = φ(x_i)·φ(x_j)` 即可在原空间直接计算高维内积，无需显式计算 `φ(x)`。

| 核函数 | 表达式 | 特点 |
|:---|:---|:---|
| **线性核** | `x_i·x_j` | 等价于原始线性 SVM |
| **多项式核** | `(γ x_i·x_j + r)^d` | `d` 控制映射维度，参数多、易过拟合 |
| **RBF/高斯核** | `exp(-γ∥x_i-x_j∥²)` | 最常用，隐式映射到无穷维 |
| **Sigmoid 核** | `tanh(γ x_i·x_j + r)` | 类似两层神经网络，不总满足 Mercer 条件 |

**Mercer 定理**要求有效核矩阵半正定，以保证优化问题的凸性。RBF 核参数 `γ` 控制影响半径：`γ` 大则单点影响范围小、决策边界复杂弯曲、易过拟合；`γ` 小则边界平滑、可能欠拟合。带核的决策函数为 `f(x) = sign(Σα_i y_i K(x_i, x) + b)`。

**SVM 回归 (SVR)** 引入 **ε-不敏感损失**：预测值落在真实值 ±ε 范围内不计损失，相当于构造一个宽度为 `2ε` 的管道，落在管道内的样本不产生惩罚，目标为 `min ½∥w∥² + CΣ(ξ_i + ξ_i*)`。

**SMO 算法 (Platt 1998)** 解决了标准 QP 求解器 `O(n³)` 复杂度难以扩展的问题。其核心思想是把大 QP 分解为最小子问题，每次只优化**恰好两个** `α` 变量（受等式约束 `Σα_i y_i = 0`，至少需同时优化两个）。具体地：用等式约束 `α_i y_i + α_j y_j = -Σ_{k≠i,j} α_k y_k` 把两变量优化化为一元二次函数的极值问题，求得解析解；再用**裁剪 (Clipping)** 把更新后的 `α` 限制在 `[0, C]`（超出则取边界）；随后根据新 `α` 重新计算偏置 `b` 以满足 KKT 条件；迭代直到所有样本在容差 `ε`（通常 `10⁻³`）内满足 KKT 条件。其经验复杂度介于 `O(n)` 到 `O(n²)` 之间，远优于标准 QP，配合核函数缓存与收缩启发式可进一步加速。

**多分类 SVM** 常用策略包括：**一对多 (OvA)** 训练 `n` 个二分类器区分"某类 vs 其余"；**一对一 (OvO)** 对每对类别训练 `n(n-1)/2` 个分类器并投票（scikit-learn 默认）；**DAG-SVM** 把 OvO 组织为有向无环图，推理只需 `n-1` 次比较；此外还有直接多分类的 **Crammer-Singer** 与 **Weston-Watkins**。

SVM 与逻辑回归都用于分类，但侧重不同：

| 维度 | SVM | Logistic Regression |
|:---|:---|:---|
| 输出 | 符号决策 `sign(f(x))` | 概率 `P(y\|x)` |
| 损失函数 | Hinge Loss | Log Loss（交叉熵） |
| 非线性能力 | 核方法 | 需手动特征工程 |
| 对异常值 | 仅依赖支持向量，较鲁棒 | 受所有样本影响，较敏感 |
| 概率校准 | 需 Platt Scaling | 天然输出概率 |
| 样本量大 | 较慢 `O(n²)`~`O(n³)` | 更快 `O(n)` |

**Hinge 损失** 定义为 `L(y, f(x)) = max(0, 1 - y·f(x))`：正确分类且距超平面 ≥1 时不产生损失（稀疏解的来源），置信度低或误分类时线性惩罚。与 Log Loss 对比，Hinge Loss 对已正确分类的样本完全置零，而 Log Loss 始终非零，因此 SVM 解更稀疏。SVM 的优势在于高维空间极其有效、内存高效（只存支持向量）、核方法灵活，并有间隔最大化等价于结构风险最小化的理论保障、凸优化保证全局最优；局限在于不直接输出概率（需 Platt Scaling）、对 `C/γ/核选择` 敏感、大规模样本训练慢、核 SVM 不易解释、对缺失数据与类别不平衡敏感。实践中常用指数增长的网格搜索调 `C` 与 `γ`（如 `C ∈ {10⁻³,…,10³}`、`γ ∈ {10⁻⁴,…,10¹}`）配合 5/10 折交叉验证，且务必先做特征标准化（SVM 对尺度敏感，推荐 StandardScaler）。

## 5.7 聚类分析

**聚类分析 (Cluster Analysis)** 是无监督学习的核心任务：在无标签信息下把数据划分为若干簇，目标是**最大化簇内相似度、最小化簇间相似度**。它不依赖预定义类别，而是从数据本身发现分组结构。其基本假设是簇内紧密、簇间分离，而"相近"的确切含义取决于所选的**距离/相似度度量**。

常用的距离度量包括：**欧氏距离** `√(Σ(x_i-y_i)²)`（连续数据最常用）、**曼哈顿距离** `Σ|x_i-y_i|`（对异常值敏感度低于欧氏）、**余弦相似度** `(x·y)/(∥x∥∥y∥)`（衡量方向、忽略长度，常用于文本与高维稀疏数据）、**相关系数距离** `1-ρ`（关注变化趋势，用于基因表达等）与 **Jaccard 相似系数** `|A∩B|/|A∪B|`（集合/二值数据）。度量选择没有绝对最优，需结合数据特征与业务场景；高维时还需警惕维数灾难——距离趋于相等、度量失去分辨力，通常要先降维再聚类。

**K-Means (Lloyd's Algorithm)** 是最经典的原型聚类方法，把数据划分为 `K` 个簇，每个簇由其**质心**（簇内点的均值）代表。算法迭代执行两步：**分配**——把每个点分到距离最近的质心所在簇；**更新**——把每个质心更新为其簇内点的均值；重复直到质心不再移动或达到最大迭代数。

```text
输入: 数据 X = {x_1, ..., x_n}, 簇数 K, 最大迭代 T
初始化质心 μ_1, ..., μ_K          # 随机选点或 K-Means++
repeat t = 1, 2, ..., T:
    分配: 对每个 x_i: C(x_i) ← argmin_k ||x_i − μ_k||²
    更新: 对每个簇 k: μ_k ← mean{ x_i : C(x_i) = k }
until 质心不再变化 或 达到 T
输出: 簇划分 {C_1, ..., C_K} 与质心
```

其优化目标为**簇内平方和 (WCSS)** `J = Σ_k Σ_{x∈C_k} ∥x-μ_k∥²`。Lloyd 迭代本质是**坐标下降**：分配步固定质心优化划分，更新步固定划分优化质心，每步单调减小 WCSS，保证收敛到局部最优。K-Means 也可视为各向同性高斯混合模型在等先验、协方差 `σ²I → 0` 时的极限情形，此时 EM 的软分配退化为硬分配。

K-Means 的局限包括：必须预设 `K`；**对初始化敏感**（不同初始质心可能收敛到不同局部最优）；假设**球形簇**（对拉长、月牙形、环形簇效果差）；**对异常值敏感**（异常值会拉偏质心，鲁棒替代是 K-Medoids/PAM，用簇内真实点作中心）；无法处理非凸簇。

针对初始化问题，**K-Means++** 按概率分散选择初始质心：先均匀随机选第一个质心，再按 `p(x) = D(x)²/ΣD(x')²`（`D(x)` 为到最近已有质心的距离）选下一个，距离越远概率越大；重复至选出 `K` 个，理论期望近似比为 `O(log K)`。选择 `K` 常用**肘部法则**——绘制 `K` 与 WCSS 的曲线，在下降速率明显放缓的"肘部"取 `K`；**轮廓系数** `s(i) = (b(i)-a(i))/max(a(i),b(i))` 则同时衡量凝聚度 `a(i)`（到同簇其他点的平均距离）与分离度 `b(i)`（到最近其他簇的平均距离），取值 `[-1,1]`，越高越好。

**DBSCAN (1996)** 是基于密度的聚类方法，由参数 `(ε, MinPts)` 定义密度：`ε-邻域` 是距点 `p` 不超过 `ε` 的点集 `N_ε(p)`，`MinPts` 是构成密集区域所需的最小点数。点据此分为三类：邻域内点数 ≥ `MinPts` 的**核心点**、非核心但落在某核心点邻域内的**边界点**、以及既非核心也非边界的**噪声点**。密度关系定义了簇结构：`q` 为核心点且 `p∈N_ε(q)` 时 `p` 从 `q` **直接密度可达**，其传递闭包为**密度可达**，存在公共点使两点都密度可达则为**密度相连**；一个簇即满足"任意两点密度相连、且包含所有密度可达点"的最大点集。

DBSCAN 流程为：标记所有点未访问；任取未访问点 `p` 并计算其 ε-邻域，若为核心点则新建簇并把邻域点加入，再对簇内未检查的核心点扩展其邻域，直到无法加入新点；若为边界点或噪声点则暂标记为噪声（之后可能被其他核心点拉入）；重复直到所有点访问完毕，仍标记为噪声的即真正异常点。其优点是**自动发现簇数**、能识别**任意形状的簇**、**对异常值鲁棒**；局限是**对 `ε` 与 `MinPts` 敏感**（常用 k-distance 图的拐点选 `ε`）、**难以处理变密度数据**（可用 OPTICS 或 HDBSCAN）、且受**维数灾难**影响通常不适用于高维数据。

**层次聚类 (Hierarchical Clustering)** 构建嵌套的簇层次，生成一棵**树状图 (Dendrogram)**，无需预先指定 `K`，可在任意高度"切一刀"得到期望簇数。最常用的是**凝聚层次聚类**：初始把每个点视为一个簇，反复合并距离最近的两个簇，直到合并为一个；关键决策是**链接准则**——**单链接**取两簇最近点对距离（易产生链状簇、能处理非凸形状）；**全链接**取最远点对距离（倾向紧凑球状簇、对异常值敏感）；**平均链接**取所有点对距离均值（折中、较鲁棒，最常用）；**Ward 方法**合并使簇内方差增加最少的簇（倾向大小均衡的簇，与 K-Means 目标一致）。**分裂层次聚类**（如 DIANA）从整体递归分裂，但计算量远大于凝聚法。朴素实现复杂度 `O(N³)`，优化后 `O(N² log N)`；层次聚类提供多粒度结果、无需预设簇数，但合并决策一旦做出便不可撤销，早期错误会传播，且大规模数据扩展性不如 K-Means。

**高斯混合模型 (GMM)** 是基于概率生成模型的软聚类方法，假设数据由 `K` 个高斯分布混合生成：`P(x) = Σ_k π_k N(x|μ_k, Σ_k)`，其中 `π_k` 为混合系数（满足和为 1、非负）、`μ_k` 为均值、`Σ_k` 为协方差。它用 **EM 算法**做极大似然估计：引入隐变量 `z` 表示样本由哪个分量生成，**E 步**计算每个点属于各分量的后验概率（责任）`γ_{ik} = π_k N(x_i|μ_k,Σ_k) / Σ_j π_j N(x_i|μ_j,Σ_j)`，即**软分配**；**M 步**用 `γ_{ik}` 加权更新参数 `N_k = Σ_i γ_{ik}`、`μ_k = (1/N_k)Σ_i γ_{ik}x_i`、`Σ_k = (1/N_k)Σ_i γ_{ik}(x_i-μ_k)(x_i-μ_k)ᵀ`、`π_k = N_k/N`；迭代至收敛。

GMM 的协方差类型平衡灵活性与参数量：**完整 (Full)** 每个分量一个正定矩阵（`K·d(d+1)/2` 参数，最灵活但易过拟合）、**绑定 (Tied)** 所有分量共享 `Σ`、**对角 (Diagonal)** 各特征独立（轴对齐椭球）、**球形 (Spherical)** 各向同性（退化为软版 K-Means）。与 K-Means 相比，GMM 提供概率软分配、能建模椭圆簇，但参数更多、对初始化更敏感（常用 K-Means 结果初始化），同样需预设 `K`。其 `K` 可用 **BIC** `= ln(N)·q - 2ln(L̂)` 或 **AIC** `= 2q - 2ln(L̂)` 选择，取值最小者——BIC 惩罚更重、倾向简单模型，AIC 惩罚较轻、有时选偏大的 `K`。

| 维度 | K-Means | DBSCAN | 层次聚类 | GMM |
|:---|:---|:---|:---|:---|
| **K 的选择** | 需预设 | 自动发现 | 无需预设 | 需预设 |
| **簇的形状** | 仅球形 | 任意形状 | 取决于链接准则 | 椭圆 |
| **异常值处理** | 敏感 | 鲁棒（显式标记噪声） | 单链接敏感，Ward 较鲁棒 | 低概率分配，有一定容忍 |
| **输出类型** | 硬分配 | 硬分配 + 噪声标记 | 树状图（多粒度） | 软分配 |
| **可扩展性** | `O(tKNd)`，高效 | `O(N log N)` | `O(N² log N)`~`O(N³)` | `O(tKNd²)`~`O(tKNd³)` |

**聚类验证**用于评估聚类质量并选择参数。**内部指标**仅用聚类结果本身：轮廓系数综合凝聚与分离，`[-1,1]` 越高越好；Davies-Bouldin 指数衡量各簇与最相似簇的平均相似度，越小越好；Calinski-Harabasz 指数是簇间与簇内方差之比，越大越好。**外部指标**在有真实标签时使用：调整兰德指数 (ARI) 对随机划分做机会校正（范围 `[-1,1]`）；归一化互信息 (NMI) 衡量聚类标签与真实标签的互信息（范围 `[0,1]`）；同质性度量"每个簇是否只含单一真实类"、完整性度量"每个真实类是否集中在单一簇"，二者调和平均即 V-Measure。此外还有基于扰动的稳定性指标。工程实践中，聚类前通常需要**标准化**（对基于距离的算法尤其重要），高维数据可先降维再聚类（但需注意 t-SNE 会破坏全局簇间距离）。

## 5.8 降维与特征工程

降低维度的动机来自**维数灾难**：特征越多数据越稀疏、距离度量失效、所需样本量指数增长。降维可提升计算效率、抑制噪声、便于可视化、消除多重共线性。

**PCA (主成分分析)** 寻找一组正交方向（主成分），使数据投影到这些方向上的方差最大。其推导为：中心化数据 `X' = X - μ`，计算协方差矩阵 `Σ = (1/n)X'ᵀX'`，做特征分解 `Σv_i = λ_i v_i`，取前 `k` 个最大特征值对应的特征向量构成投影矩阵，得到 `Z = X'V_k`。第 `i` 个主成分解释的方差比例为 `λ_i/Σ_j λ_j`，累计解释率的拐点（**碎石图**）可用于选 `k`。PCA 也可通过对中心化数据做 **SVD** `X' = UΣVᵀ` 实现，此时右奇异向量即主成分方向、`σ_i² = nλ_i`，数值上更稳定。PCA 的局限是只能捕捉线性关系、对特征尺度敏感（必须先标准化）、基于二阶统计量（隐含高斯假设）、主成分缺乏可解释性；**核 PCA** 通过核技巧可发现非线性结构。

**SVD (奇异值分解)** 把任意 `m×n` 矩阵分解为 `X = UΣVᵀ`，其中 `U`、`V` 为正交矩阵，`Σ` 的对角元 `σ_1≥σ_2≥…≥0` 为奇异值。对中心化数据做 SVD 等价于 PCA。**截断 SVD** 只保留前 `k` 个最大奇异值得到秩-k 近似 `X_k = U_kΣ_kV_kᵀ`，由 **Eckart-Young 定理**，这是 Frobenius 范数意义下最优的秩-k 近似。其典型应用包括降维、潜在语义分析 (LSA/LSI)、协同过滤与图像压缩。相比协方差矩阵特征分解，SVD 直接分解原始矩阵、数值更稳定，且同时给出左右奇异向量。

**t-SNE** 专为高维数据的 2D/3D 可视化设计，在保持局部邻域结构方面效果卓著。它的思路是在高维和低维空间分别用概率定义相似性，再最小化二者的 **KL 散度**。高维用高斯核定义条件概率 `P_{j|i}`，其中 `σ_i` 由**困惑度 (Perplexity)**（约等于有效近邻数量，典型取 5~50）自适应决定，再对称化为 `P_{ij}`；低维用自由度为 1 的重尾 **Student-t 分布** `Q_{ij} ∝ (1+∥y_i-y_j∥²)⁻¹`，重尾是解决**拥挤问题**的关键。目标 `KL(P∥Q)` 的惩罚不对称：高相似点被拉远时代价极高，低相似点被拉近时代价较低，因此 t-SNE **优先保证局部结构、允许全局结构失真**。其优点是可视化效果极佳；局限是非确定性（随机初始化、非凸优化）、`O(N²)` 复杂度、簇间距离无意义、无 `transform` 函数、对困惑度敏感。

**UMAP** 基于黎曼几何与拓扑数据分析，假设数据分布在低维流形上，通过构建模糊拓扑结构建模高维拓扑，再优化交叉熵损失保持该结构。

| 维度 | t-SNE | UMAP |
|:---|:---|:---|
| 理论基础 | 概率分布 + KL 散度 | 黎曼几何 + 模糊单纯形 |
| 速度 | 慢 `O(N²)` | 快 `O(N log N)` |
| 全局结构 | 几乎不保留 | 较好保留 |
| 可扩展性 | 数千~数万点 | 百万级 |
| transform() | ❌ | ✅ 支持新数据 |
| 超参数 | perplexity | n_neighbors + min_dist |

**特征工程**是提升模型效果的关键环节。**特征缩放**中，标准化 `(x-μ)/σ`（均值 0、方差 1）适用于 PCA、SVM、线性模型与神经网络等基于距离或梯度的模型；Min-Max 缩放把特征映射到 `[0,1]`；鲁棒缩放 `(x-median)/IQR` 对异常值不敏感。**编码类别特征**的方法包括 One-Hot（无序类别，类别多时维度爆炸）、标签编码（有序类别或树模型）、目标编码（用目标均值替换，需注意数据泄露）与特征哈希（大量类别时固定向量、可能碰撞）。**处理缺失值**可删除、用均值/中位数/众数填充、KNN 填补、多重插补 (MICE)，或添加缺失指示变量。此外可通过**特征交互** `x₁·x₂` 与**多项式特征** `x², x₁x₂, …` 让线性模型拟合非线性关系。

**特征选择**分三类。**过滤法**独立于模型、基于统计评分：方差阈值、相关系数、互信息（可捕获非线性关联）、卡方检验、ANOVA F 检验。**包装法**以模型性能评价特征子集：递归特征消除 (RFE)、前向选择、后向消除、穷举搜索（仅适合极少特征）。**嵌入法**把特征选择融入训练：Lasso 的 L1 惩罚压缩不重要系数为零、树模型基于分裂重要性输出排序、排列重要性通过打乱特征观察性能下降（与模型无关）。

降维与特征选择的目标不同：降维产生**新的合成特征**（可解释性差、丢失原始含义，但能自动去冗余），特征选择输出**原始特征的子集**（保留物理含义、便于解释）。

| 维度 | 降维 (PCA/SVD/t-SNE) | 特征选择 |
|:---|:---|:---|
| 输出特征 | 新构造的合成特征 | 原始特征的子集 |
| 可解释性 | 差（主成分难解释） | 好（保留原始含义） |
| 去冗余 | 自动去除共线性 | 需手动或结合方法 |
| 非线性 | PCA 不行，t-SNE/UMAP 可以 | 取决于评分方法 |
| 适合场景 | 信号处理、压缩、可视化 | 需要解释模型的业务场景 |

## 5.9 贝叶斯学习

**朴素贝叶斯 (Naive Bayes)** 是基于贝叶斯定理的**生成式概率分类器**，核心是**条件独立性假设**——给定类别 `y` 时所有特征相互独立，即 `P(x_1,…,x_d|y) = ∏_j P(x_j|y)`。尽管该假设现实中极少成立，但在文本分类等领域表现极佳。分类决策为 `ŷ = argmax_y P(y)∏_j P(x_j|y)`（分母 `P(x)` 对所有类别相同可省略），实际计算通常取对数以避免下溢。

按特征类型，朴素贝叶斯常见四种变体：**Gaussian NB** 假设连续特征每类内服从高斯分布；**Multinomial NB** 处理离散计数特征（文本词频）；**Bernoulli NB** 处理二元出现/不出现特征（短文本）；**Complement NB** 用互补类别统计量，适合不平衡数据。当某特征值在某类中从未出现时，MLE 估计概率为 0 会导致整个后验坍塌（**零频率问题**），需用平滑修正：`P(x_j=k|y) = (N_{y,k}+α)/(N_y+α|V|)`，`α=1` 为 Laplace 平滑、`α<1` 为 Lidstone 平滑——平滑不仅解决零概率，也起到正则化作用。

朴素贝叶斯的典型应用包括垃圾邮件过滤、文档分类、情感分析与实时预测。优势是极速（训练 `O(Nd)`、预测 `O(d)`）、小样本有效、高维友好、可解释、对无关特征鲁棒；局限是独立假设偏离时会"重复计算"证据导致概率过度置信（但分类排名通常仍准确）、零频率问题、不能建模特征交互、对连续特征分布假设敏感。

朴素贝叶斯可视为贝叶斯网络的**特例**：其结构固定为类别作为所有特征的共同父节点 `y → x_1,…,y → x_d`、特征间无边。贝叶斯网络的表示、推理与学习详见第 3 章 §3.10，本节仅作对照：

| 维度 | 朴素贝叶斯 | 通用贝叶斯网络 |
|:---|:---|:---|
| **结构** | 固定树状 `y → x_j` | 任意 DAG，需从数据学习或领域知识构建 |
| **条件独立** | 强假设：`x_j` 在给定 `y` 下互独立 | 仅图结构隐含的独立性成立 |
| **参数学习** | 直接计数 (MLE/MAP) | MLE/MAP/EM（有隐变量） |
| **推理** | `O(d)` 直接计算 | 变量消元/联接树（精确）或 MCMC（近似） |
| **适用场景** | 高维分类（尤其文本）、训练数据有限 | 领域建模、因果推理、不确定性诊断 |

**高斯过程 (Gaussian Process, GP)** 是非参数贝叶斯方法，直接为函数空间赋予概率先验——任何有限个函数值的集合服从联合高斯分布。GP 完全由**均值函数** `m(x)` 与**协方差函数/核函数** `k(x,x')` 决定：`f(x) ~ GP(m(x), k(x,x'))`，其中 `m(x)` 为函数值先验均值（通常设 0），`k(x,x')` 刻画两点函数值的相似度，编码了对所要学习函数的平滑性、周期性、趋势性等先验。

给定训练数据 `D=(X,y)` 与观测噪声 `ε ~ N(0,σ_n²)`，测试点 `X*` 的预测分布为高斯 `f*|X,y,X* ~ N(μ*,Σ*)`，其中

`μ* = K(X*,X)[K(X,X)+σ_n²I]⁻¹y`，`Σ* = K(X*,X*) - K(X*,X)[K(X,X)+σ_n²I]⁻¹K(X,X*)`。

均值 `μ*` 是训练目标的加权平均（权重由核函数分配的相似度决定），方差 `Σ*` 给出预测不确定性——训练样本附近方差小、远离处方差大。

核的选择是 GP 建模最重要的决策：

| 核函数 | 公式 `k(x,x')` | 性质与适用场景 |
|:---|:---|:---|
| **RBF/平方指数** | `σ²exp(−∥x−x'∥²/(2ℓ²))` | 无限可微、极平滑，最常用缺省核 |
| **Matérn (ν=3/2)** | `σ²(1+√3r/ℓ)exp(−√3r/ℓ)` | 一次可微，更接近真实物理过程 |
| **Matérn (ν=5/2)** | `σ²(1+√5r/ℓ+5r²/(3ℓ²))exp(−√5r/ℓ)` | 二次可微，常用默认 Matérn 取值 |
| **周期核** | `σ²exp(−2sin²(π∥x−x'∥/p)/ℓ²)` | 建模季节性或周期性变化 |

其中 `r=∥x−x'∥`，长度尺度 `ℓ` 是核心超参数：`ℓ` 小则函数变化剧烈，`ℓ` 大则函数平滑。核的和表示多个独立过程叠加，核的积表示逐元素乘积过程。

GP 的核超参数 `θ={ℓ,σ²,σ_n²,…}` 通过**最大化对数边际似然 (LML)** 学习：`log P(y|X,θ) = -½yᵀ(K_θ+σ_n²I)⁻¹y - ½log|K_θ+σ_n²I| - (N/2)log(2π)`。第一项衡量数据拟合，第二项是复杂度惩罚——行列式越大模型越灵活、惩罚越重，这是 GP 的**自动 Occam's Razor**，无需交叉验证或留出验证集。超参数用梯度上升优化，每次迭代需 `O(N³)` 求逆，因此 GP 在小数据（`N<1000`）下极其优雅。

当输出为离散类别时，似然非高斯、后验无解析解，需**近似推断**：拉普拉斯近似用二阶泰勒展开以高斯近似后验（高效，经典基线）；期望传播 (EP) 以指数族分布逐步逼近真实后验（更精确但更贵）。GP 分类天然输出概率与不确定性区间，适合医学诊断等高风险决策。

标准 GP 的 `O(N³)` 时间与 `O(N²)` 空间复杂度限制其用于大数据（`N>10⁴`），**稀疏 GP** 通过引入 `M≪N` 个**诱导点**作为全局函数值的低秩代表来近似：稀疏 GP/FITC 用诱导点伪输入替代完整核矩阵；变分稀疏 GP (SVGP/VFE) 把变分推断与稀疏近似统一、下界严格；随机傅里叶特征 (RFF) 用 Bochner 定理把移位不变核近似为随机傅里叶基的线性组合；深度核学习用神经网络变换输入后接 GP 顶层。

GP 的优势是原则性不确定性量化、小样本优异、自动模型选择、核可模块化组合以编码专家知识；局限是 `O(N³)` 计算瓶颈、核工程依赖经验、对离散/类别输入需专门设计核、非高斯似然下近似可能引入偏差。

三种贝叶斯学习方法对比如下：

| 维度 | 朴素贝叶斯 | 贝叶斯网络 | 高斯过程 |
|:---|:---|:---|:---|
| **模型类型** | 生成式分类器 | 生成式概率图模型 | 非参数贝叶斯函数先验 |
| **核心假设** | 特征在给定类别下条件独立 | DAG 编码条件独立性 | 核函数编码函数光滑性 |
| **适用任务** | 分类（尤其高维离散） | 领域建模、因果推理、分类 | 回归与带不确定性预测 |
| **输出** | 类别标签 + 后验概率 | 任意变量的后验分布 | 预测均值 ± 置信区间 |
| **不确定性** | 依赖独立假设准确度 | 完整贝叶斯后验 | 原则性高斯不确定性 |
| **训练复杂度** | `O(Nd)` | `O(N·2^k)`；结构学习 NP-hard | `O(N³)`；稀疏近似 `O(NM²)` |
| **典型应用** | 垃圾邮件、文档分类 | 医疗诊断、故障检测 | 贝叶斯优化、地质统计、机器人 |

从更高视角看，本节三类方法都体现了**贝叶斯视角**——把概率视为对不确定性的主观信念，通过先验 + 数据的更新获得后验预测分布。这与**频率主义视角**（概率是长期频率、参数是固定值、用点估计与置信区间）形成对照：贝叶斯方法用后验预测分布对参数做完整平均，以边际似然自动实现 Occam's Razor，小数据表现好但计算代价高；频率主义方法用 MLE 点估计、交叉验证或 AIC/BIC 选模型，大数据下有一致性保证、计算代价低。朴素贝叶斯处于谱系中的独特位置——它是对 `P(x,y)` 建模的生成式模型，却通常用 MLE/MAP 做点估计；高斯过程则代表另一极端——完整的贝叶斯非参数推断，在同一形式下完成先验编码、超参数学习与后验预测的全链路推理。


## 5.10 半监督学习与弱监督学习

**半监督学习 (SSL)** 的动机是有标注数据昂贵稀缺、而无标注数据广泛可得，目标是利用无标注数据改进模型。它依赖四个核心假设：**平滑性假设**（相近点大概率同标签）、**聚类假设**（同一簇内的点倾向同标签）、**低密度分离假设**（决策边界应穿过数据分布的低密度区，是 TSVM/S3VM 的理论基础）与**流形假设**（高维数据分布在低维流形上，流形上近的点应共享标签）。

**自训练 (Self-Training)** 是最简单的方法：在标注数据上训练初始模型，用它预测无标注数据，将高置信度预测作为**伪标签**加入训练集，迭代重复。其核心风险是**确认偏误**——早期错误预测被当作正确标签，模型在后续迭代中不断强化该错误；缓解策略包括仅保留高置信度预测、使用模型集成、向伪标签加噪声。**协同训练 (Co-Training, Blum & Mitchell 1998)** 利用数据的两个独立视图：在两个视图上分别训练分类器，各自把最有信心的预测交给对方作为额外训练数据。其假设是每个视图单独足以分类且给定标签下条件独立；**三体训练 (Tri-Training)** 用三个分类器，任意两个一致时将其加入第三个的训练集以降低伪标签噪声。

**生成式 SSL** 同时建模 `P(x,y)`，用标注数据提供标签关联、无标注数据补齐 `P(x)`，通过 EM 框架迭代：E 步用当前参数估计无标注样本的软标签 `P(y|x;θ)`，M 步基于完整数据（确定标签 + 软标签期望）重估参数。经典模型有 GMM + EM、朴素贝叶斯 + EM；深度生成式 SSL 包括 VAE 与 CatGAN/Triple-GAN。

**基于图的 SSL** 把样本（含标注与无标注）作为节点、以相似度作为边权构成图。**标签传播**让标注标签沿边扩散，迭代公式 `F^{(t+1)} = αSF^{(t)} + (1-α)Y`（`S` 为归一化相似矩阵、`Y` 为初始标注矩阵），可闭式求解 `F* = (I-αS)⁻¹Y`；**图最小割**把图划分为正负区域使割边权重最小；**调和函数**让无标注节点取邻居加权平均（离散拉普拉斯方程 `Δf=0` 的解）；**流形正则化 (Laplacian SVM)** 在 SVM 损失上增加 `λ·fᵀLf` 项（`L` 为图拉普拉斯算子）。

现代深度 SSL 的主要方向是一致性正则化：**Π-Model** 对同一样本施加两次增强并要求预测一致；**时序集成**用历史预测的指数滑动平均 (EMA) 作为目标以降低方差；**Mean Teacher** 用学生网络的 EMA 作为教师，要求学生与教师对两次增强的输出一致；**MixMatch** 把标注样本与无标注样本的锐化预测经 MixUp 混合训练；**ReMixMatch** 增加分布对齐与更强增强；**FixMatch** 对无标注样本施加弱增强产生伪标签（保留高置信度者）、强增强要求预测与伪标签一致，仅需极少标注即可达到强性能；**FlexMatch** 用动态阈值避免易学类先获得伪标签的 Matthew Effect。

| 方法 | 核心机制 | 关键技巧 | 标注需求 |
|:---|:---|:---|:---|
| **Self-Training** | 迭代加入高置信度伪标签 | 阈值过滤 | 中 |
| **Co-Training** | 两个独立视图相互教学 | 视图条件独立 | 中 |
| **GMM + EM** | 生成式联合建模 `P(x,y)` | EM 填补缺失标签 | 中 |
| **图方法** | 图上标签传播 | 图拉普拉斯、RBF 核 | 少 |
| **Mean Teacher** | 学生-教师 EMA | EMA 稳定目标 | 少 |
| **MixMatch** | MixUp + 温度锐化 | Sharpen + MixUp | 极少 |
| **FixMatch** | 弱增强伪标签 + 强增强一致性 | 高置信度阈值 | 极少 |

**弱监督学习**的动机是完美标注代价高，而不完美的监督信号廉价丰富。**含噪标签学习**中，噪声类型包括随机/对称噪声（标签均匀翻转到其他类）、类条件/非对称噪声（翻转概率取决于真实类）与实例依赖噪声（取决于样本特征，最贴近真实但最难建模）。应对方法包括：**鲁棒损失**（MAE 对噪声比交叉熵鲁棒；广义交叉熵 GCE 在两者间插值；对称交叉熵 SCE 引入反向交叉熵项）；**标签修正**（用模型预测重新估计真实标签）；**样本选择**（协同教学 Co-Teaching 让两个网络各自选择低损失样本交给对方；Loss-Based Filtering 按损失排序只保留最干净的样本）；**损失修正**（用噪声转移矩阵 `T_{ij}=P(ỹ=j|y=i)` 做前向修正 `ℓ(Tᵀf(x), ỹ)` 或后向修正 `T⁻¹ℓ(f(x), ỹ)`，转移矩阵可用锚点估计）；**课程学习**（MentorNet 先用损失小、梯度一致的样本训练学生网络）。

**多示例学习 (MIL)** 以**包**为单位训练，每个包含若干**示例**，只知包标签、不知示例标签。标准假设是包为正包当且仅当至少有一个正示例（包标签 = `max(示例标签)`）。典型场景是医学影像——一张全切片病理图被切成大量小图块作为一个包，只知患者诊断结果。方法分两类：**实例空间方法**先分类每个示例再聚合（最大/均值/注意力池化）；**包空间/嵌入空间方法**把整包映射为固定向量再分类。**注意力 MIL** 用可学习的注意力权重聚合 `z = Σ_i a_i h_i`，权重天然可解释。

Snorkel 框架代表**数据编程**范式：用**标注函数 (LF)** 对样本投票（可弃权），再用**生成式模型**从所有 LF 的投票矩阵学习每个 LF 的准确率与相关性、输出概率化标签，最后用**判别式模型**在概率化标签上训练最终分类器。其优点是标注逻辑可版本控制、可复用、可扩展且人类可理解。

SSL 与弱监督的核心区别在于：SSL 假设少量标注质量高、额外信息是大量无标注数据及其结构假设；弱监督则假设标注质量低但数量可多、额外信息是廉价的不完美信号（规则、知识库、众包）。SSL 有效的前提是标注极度稀缺、数据满足结构假设、标注与无标注分布一致、有有效数据增强；若标注已足够多、数据违背假设、类别极度不平衡或领域无增强手段，SSL 可能退化。弱监督有效的前提是能编写有信息量的 LF、噪声模式已知可估计、MIL 假设成立；若 LF 全是随机猜测、存在系统性偏差或噪声具对抗性，则效果有限。

## 5.11 本章小结

**核心要点回顾**

| 学习范式 / 算法族 | 核心思想 | 代表算法 | 适用场景 |
|:---|:---|:---|:---|
| **监督学习** | 学习 `x → y` 映射，最小化预测误差 | 线性/逻辑回归、SVM、决策树、神经网络 | 分类、回归 |
| **无监督学习** | 发现无标注数据的内在结构 | K-Means、DBSCAN、GMM、PCA | 聚类、降维、密度估计 |
| **半监督 / 自监督 / 弱监督** | 借助无标注、自生成或不完美信号提升性能 | Self-Training、FixMatch、BERT、Snorkel | 标注稀缺或昂贵 |
| **强化学习** | 与环境交互最大化长期累积奖励 | Q-Learning、Policy Gradient、DQN | 序贯决策、控制 |
| **线性模型** | 用线性函数（或其概率映射）拟合/分类 | 线性回归、逻辑回归、Softmax、LDA | 可解释基线、高维稀疏数据 |
| **决策树** | 递归划分特征空间提升节点纯度 | ID3、C4.5、CART | 混合类型特征、需可解释性 |
| **集成学习** | 组合多个弱/基学习器降低偏差或方差 | Bagging、随机森林、AdaBoost、GBDT、XGBoost、LightGBM、Stacking | 表格数据建模主流 |
| **支持向量机** | 最大化分类间隔，用核技巧处理非线性 | 硬/软间隔 SVM、SVR、SMO | 小样本、高维分类 |
| **聚类分析** | 按相似度将样本分组 | K-Means、DBSCAN、层次聚类、GMM | 探索性分析、异常检测 |
| **降维与特征工程** | 保留结构的同时压缩维度或筛选特征 | PCA、SVD、t-SNE、UMAP、Lasso、RFE | 可视化、去噪、加速训练 |
| **贝叶斯学习** | 用概率与先验建模不确定性并更新后验 | 朴素贝叶斯、贝叶斯网络、高斯过程 | 文本分类、因果诊断、小样本带不确定性预测 |
