# 附录 B 语音处理

**本章导读**：第 23.6 节讲了语音识别（ASR）。本附录补齐语音的另一半：**信号怎么表示**（B.1）、**怎么合成语音**（B.2）、**怎么识别说话人**（B.3）、**怎么把语音与语言模型结合**（B.4）。语音是典型的"信号 → 符号"问题，它的方法论（分帧、特征、序列模型、对齐）与 NLP、视觉都有相通之处。

- 用 i-vector/x-vector 描述说话人建模，解释 EER；
- 说明语音识别中声学模型、发音词典、语言模型的分工；
- 讨论多模态语音模型（Whisper、音频 LLM）的能力与局限。

**预备知识**：数字信号处理基础（采样定理、DFT/FFT）；第 23.6 节的 ASR 流程；第 21 章的序列模型。

## B.1 语音信号基础

**语音的产生**：肺部气流 → 声带振动（浊音）或湍流（清音）→ 声道滤波。声学上表现为**基频（F0）** 与**共振峰（formant）**。

**数字化**：

| 步骤 | 说明 | 典型值 |
| --- | --- | --- |
| 采样 | 按奈奎斯特频率采样 | 16 kHz（语音）、44.1 kHz（音乐） |
| 量化 | 幅度离散化 | 16 bit |
| 预加重 | 提升高频（补偿声道辐射） | $y[n] = x[n] - 0.97x[n-1]$ |
| 分帧 | 短时平稳假设 | 25 ms 窗，10 ms 帧移 |
| 加窗 | 减少频谱泄漏 | 汉明窗、汉宁窗 |

**频谱分析**：对每帧做 FFT 得到**功率谱**，再用**梅尔滤波器组**（模拟人耳对低频更敏感）压缩为 **梅尔谱**：

$$m_k = \log \sum_f H_k(f)\,|X(f)|^2$$

**MFCC** 在梅尔谱上再做 DCT，得到倒谱系数（通常取前 13 维 + 一阶/二阶差分）。梅尔谱保留更多信息，是神经 ASR 的首选输入。

**其他特征**：

| 特征 | 用途 |
| --- | --- |
| F0 / 基频轨迹 | 韵律、情感、声调 |
| 能量 / 过零率 | 语音活动检测（VAD） |
| 谱质心、谱通量 | 音色、音乐信息检索 |
| 嵌入特征（wav2vec、HuBERT） | 自监督学到的表示 |

**语音活动检测（VAD）**：区分语音与非语音，是流式系统的第一道关；传统用能量 + 过零率，现代用小型神经网络。

## B.2 语音合成（TTS）

**TTS 的三段式**：文本分析（分词、注音、韵律预测）→ 声学模型（文本 → 声学特征）→ 声码器（特征 → 波形）。

**（1）拼接式合成**：从录音库中选取单元拼接。自然度高但库大、覆盖有限、拼接处不连续。

**（2）参数式合成（统计参数 TTS）**：HMM/DNN 预测声学参数（梅尔倒谱、F0、时长），再由声码器合成。灵活但音质"闷"。

**（3）神经 TTS 的三代**：

| 模型 | 贡献 | 局限 |
| --- | --- | --- |
| **Tacotron / Tacotron 2** | 序列到序列 + 注意力，端到端生成梅尔谱 | 注意力易错位（重复/漏字） |
| **WaveNet** | 自回归原始波形生成，音质接近人类 | 推理极慢 |
| **FastSpeech 1/2** | 非自回归 + 时长预测，速度快 | 需对齐信息（可由教师蒸馏） |
| **VITS** | 变分推断 + 对抗训练 + 端到端，音质与速度兼顾 | 训练复杂 |
| **扩散声码器**（DiffWave、Grad-TTS） | 高质量、稳定 | 采样步数多 |

**声码器（vocoder）** 的演进：Griffin–Lim（相位重建）→ WaveNet（自回归）→ WaveRNN/Parallel WaveGAN（并行）→ HiFi-GAN（GAN，实时高质量）→ 扩散模型。

**可控性**：

| 维度 | 方法 |
| --- | --- |
| 韵律（停顿、重音） | 显式预测时长/音高，或用参考音频 |
| 音色 | 说话人嵌入（x-vector、GST） |
| 情感/风格 | 风格嵌入、细粒度标签 |
| 零样本克隆 | 参考音频编码（如 YourTTS、VALL-E） |

**评估**：**MOS（平均意见分）** 是主观金标准；客观指标有 MCD（梅尔倒谱失真）、WER（用 ASR 回识）、F0 RMSE。MOS 昂贵且不稳定，实践中常用**众包 + 多指标**组合。

**风险**：语音克隆带来诈骗与伪造风险，需要**水印、溯源与同意识别**（§27.3）。

## B.3 声纹识别与说话人验证

**任务区分**：

| 任务 | 问题 |
| --- | --- |
| 说话人识别（identification） | 这是谁（闭集/开集） |
| 说话人验证（verification） | 是不是某人（1:1） |
| 说话人分离（diarization） | 谁在什么时候说话 |

**传统方法**：GMM-UBM（通用背景模型 + MAP 自适应）→ i-vector（总变化空间，把说话人与信道因素分离）→ PLDA（概率线性判别分析）打分。

**深度方法**：

- **d-vector / x-vector**：TDNN 提取帧级特征，统计池化得到句级嵌入；
- **ECAPA-TDNN**：多尺度卷积 + 注意力池化，当前强基线；
- **自监督前端**：wav2vec/HuBERT 特征 + 微调。

**损失函数**：softmax、**AAM-softmax（角度间隔）**、**triplet/contrastive**。间隔损失使同类更紧、异类更远。

**评估指标**：

- **EER（等错误率）**：FAR = FRR 时的错误率，越低越好；
- **minDCF**：给定代价下的最小检测代价；
- **打分归一化**：score normalization（AS-norm）消除不同测试集的偏移。

**挑战**：短语音、跨信道（电话 vs 麦克风）、噪声、年龄变化、**欺骗攻击（重放、合成语音）**。后者需要**反欺骗（anti-spoofing）** 模块（ASVspoof 挑战）。

**隐私**：声纹是生物特征，属于敏感数据；需模板保护（可撤销生物特征）与本地化处理。

## B.4 多模态语音模型

**（1）语音识别与语言模型的融合**。

- **浅融合**：解码时把 LM 分数与声学分数加权相加；
- **深融合**：把 LM 的隐状态送入声学模型；
- **重打分（rescoring）**：用大 LM 对 N-best 候选重新排序；
- **端到端**：RNN-T、Whisper 等把两者隐式联合学习。

**（2）Whisper**：大规模弱监督（68 万小时多语言音频）的编码器-解码器模型。

- 输入：80 维对数梅尔谱；
- 输出：多语言文本 + 时间戳 + 任务标记（转写/翻译/语言识别）；
- 优点：**零样本跨领域/跨语言**、鲁棒性强；
- 缺点：非流式、幻觉（静音段生成文本）、计算成本高。

**（3）音频大模型（Audio LLM）**：

| 类型 | 代表 | 能力 |
| --- | --- | --- |
| 语音理解 | Qwen-Audio、SALMONN | 语音+音乐+环境声的问答 |
| 语音生成 | VALL-E、CosyVoice | 零样本语音克隆、情感控制 |
| 全双工对话 | GPT-4o 类 | 低延迟语音对话 |
| 音频生成 | MusicGen、AudioLDM | 音乐/音效生成 |

**架构范式**：音频编码器（如 Whisper encoder）→ 投影层 → LLM → 文本/语音解码器。**语音 token**（离散化）使 LLM 能直接建模语音。

**（4）语音分离与增强**：

- **分离**：鸡尾酒会问题，方法有 ICA、深度聚类、Conv-TasNet、SepFormer；
- **增强**：降噪、去混响、回声消除；常用复数域掩码与生成式方法；
- **目标说话人提取**：给定注册语音，提取该人的声音。

**（5）评估与伦理**：

- ASR 用 WER/CER；TTS 用 MOS；声纹用 EER；
- 多语言与方言覆盖不足会加剧数字鸿沟；
- 合成语音的滥用需要**内容凭证（C2PA）与水印**；
- 医疗、司法等场景的转写必须**人工复核**。

## 本附录小结

**核心要点**

1. 语音特征的核心是**短时分析**：分帧、加窗、FFT、梅尔滤波；MFCC 与梅尔谱是最常用的表示。
2. TTS 从拼接 → 参数 → 神经（Tacotron/WaveNet/FastSpeech/VITS），声码器从 Griffin–Lim 演进到 HiFi-GAN 与扩散。
3. 声纹识别用 i-vector/x-vector/ECAPA-TDNN 嵌入 + 间隔损失，评估用 **EER**；需防重放与合成攻击。
4. ASR 的三件套是**声学模型 + 发音词典 + 语言模型**；端到端模型把它们隐式联合。
5. **Whisper** 代表大规模弱监督的鲁棒性；**音频 LLM** 把语音、音乐与环境声统一到生成式框架。
6. 语音技术的风险集中在**伪造、隐私与覆盖不均**，需要水印、模板保护与人工复核。
