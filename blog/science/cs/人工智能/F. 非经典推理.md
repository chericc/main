# 附录 F 非经典推理

**本章导读**：第 7–10 章讲的是经典逻辑——单调、二值、确定性。现实推理常需要"软"机制：**条件随机场**处理结构化预测中的相关性（F.1）、**模糊逻辑**处理"程度"（F.2）、**证据理论**处理"不知道"与"矛盾"（F.3）。本附录给出这三套工具的基本定义、推理方式与适用边界。

**学习目标**：完成本附录学习后，你应当能够：

- 写出马尔可夫随机场的能量函数与吉布斯分布；
- 说明 CRF 用于序列标注的建模与推断；
- 用隶属函数与 t-范数做模糊推理，并说明去模糊化；
- 用信任函数与似然函数表达"不知道"，执行 Dempster 组合；
- 判断三类方法各自适合与不适合的问题。

**预备知识**：第 12–13 章的概率图模型；第 14 章的前向-后向算法；集合论与布尔代数。

## F.1 马尔可夫随机场与条件随机场

**马尔可夫随机场（MRF）** 是无向图模型：节点是变量，边表示**相互依赖**，联合分布用**势函数（factor）** 的乘积定义：

$$P(\mathbf{x}) = \frac{1}{Z}\prod_{c \in \mathcal{C}} \psi_c(\mathbf{x}_c),\qquad Z = \sum_{\mathbf{x}}\prod_c \psi_c(\mathbf{x}_c)$$

或用**能量函数** $E$：

$$P(\mathbf{x}) = \frac{1}{Z}\exp\big(-E(\mathbf{x})\big)$$

**与贝叶斯网络的差别**：

| 维度 | 贝叶斯网络 | MRF |
| --- | --- | --- |
| 边 | 有向、因果 | 无向、相关 |
| 参数 | CPT（条件概率） | 势函数（不必归一化） |
| 独立性 | d-分离 | 无向分离（去掉节点集后图断开） |
| 局部性 | 给定父节点 | 给定邻居（马尔可夫毯 = 邻居） |

**为什么需要无向模型**：某些依赖是**对称**的（图像像素的平滑性、社交网络中的相互影响），用有向边表示会引入虚假的方向与因果解释。

**吉布斯分布**：能量越低概率越大。**配分函数** $Z$ 的计算是 #P 难的，这是 MRF 推断的核心困难。

**（1）图像去噪与分割**：

$$E(\mathbf{x}) = \sum_i \phi_i(x_i) + \sum_{(i,j)\in\mathcal{N}} \psi_{ij}(x_i, x_j)$$

第一项是"与观测的吻合度"，第二项是"相邻像素应相似"（Ising/Potts 模型）。求解用图割（graph cut）、ICM、置信传播。

**（2）条件随机场（CRF）**：直接建模条件分布 $P(y \mid x)$，避免生成模型对 $x$ 的建模：

$$P(y \mid x) = \frac{1}{Z(x)}\exp\Big(\sum_t \sum_k \lambda_k f_k(y_{t-1}, y_t, x, t)\Big)$$

线性链 CRF 是序列标注的标准形式：

- 特征 $f_k$ 可任意设计（词、词性、前后缀、上下文窗口）；
- 转移矩阵建模标签间约束（如 IOB 格式）；
- 推断用前向-后向（边缘）与 Viterbi（解码）；
- 训练用最大似然，梯度为"经验特征期望 − 模型特征期望"（凸优化）。

**（3）与其他模型的关系**：

| 模型 | 关系 |
| --- | --- |
| HMM | CRF 的特例（特征受限、生成式） |
| 逻辑回归 | 单变量、无结构的 CRF |
| 结构化 SVM | 用间隔代替似然 |
| 图神经网络 | 可看作"学习的势函数 + 近似推断" |

**应用**：命名实体识别、词性标注、图像分割、语义分割后处理（DenseCRF）、姿态估计。

## F.2 模糊逻辑与粗糙集

**为什么需要模糊**：经典逻辑中"高"是一个二值概念（是/否），但现实中身高、温度、满意度都是**程度**问题。

**模糊集合**：用**隶属函数** $\mu_A(x) \in [0,1]$ 代替特征函数：

| 概念 | 隶属函数示例 |
| --- | --- |
| "高个子" | $\mu(x) = \sigma\big((x-175)/10\big)$ |
| "温暖" | 梯形/三角函数 |
| "年轻" | 分段线性递减 |

**模糊运算**（用 t-范数与 t-余范数代替与/或）：

| 运算 | 常见定义 |
| --- | --- |
| 交集（AND） | $\min(\mu_A, \mu_B)$ 或乘积 |
| 并集（OR） | $\max(\mu_A, \mu_B)$ 或概率和 |
| 补集（NOT） | $1 - \mu_A$ |
| 蕴含 | Mamdani：$\min(\mu_A, \mu_B)$；Larsen：乘积 |

**模糊推理系统（FIS）** 的三步：

1. **模糊化**：把精确输入转成隶属度；
2. **规则推理**：`IF 温度高 AND 湿度大 THEN 风速大`，用 t-范数合成前提，用蕴含算子得到结论；
3. **去模糊化**：把模糊输出转成精确值，常用**重心法**：

$$z^* = \frac{\int z\,\mu(z)\,dz}{\int \mu(z)\,dz}$$

**应用**：家电控制（洗衣机、空调）、工业过程控制、决策支持、图像处理。优点是**可解释、贴近人类语言**；缺点是**规则爆炸、难以学习、缺乏概率语义**。

**模糊 vs 概率**：

| 维度 | 模糊 | 概率 |
| --- | --- | --- |
| 刻画 | 概念的程度（模糊性） | 事件的不确定性 |
| 组合 | t-范数 | 乘积/贝叶斯 |
| 决策 | 重心/最大隶属 | 期望效用 |
| 混用风险 | 用模糊值代替概率会导致决策不自洽 | — |

**粗糙集（rough sets）**：用**不可区分关系**刻画知识粒度。

- **下近似**：一定属于某集合的对象；
- **上近似**：可能属于的对象；
- **边界域**：上近似减下近似，即"无法判定"的部分。

粗糙集用于**属性约简**（找最小特征子集）、**规则提取**与**不确定性度量**，适合离散、带噪声的数据。它与模糊集的区别是：粗糙集处理"知识不足导致的不可区分"，模糊集处理"概念本身的渐变"。

## F.3 证据理论

**动机**：概率要求对每个命题给出精确的信念度，但有时我们**只知道"不知道"**（ epistemic uncertainty）。证据理论（Dempster–Shafer, DS）允许把信念分配给**集合**而非单点。

**基本函数**：

- **识别框架** $\Theta$：所有可能状态的集合；
- **基本概率分配（BPA）** $m: 2^\Theta \to [0,1]$，满足 $m(\emptyset)=0$、$\sum_{A \subseteq \Theta} m(A) = 1$；
- **信任函数** $\text{Bel}(A) = \sum_{B \subseteq A} m(B)$：对 $A$ 的**下界**；
- **似然函数** $\text{Pl}(A) = \sum_{B \cap A \neq \emptyset} m(B) = 1 - \text{Bel}(\bar A)$：对 $A$ 的**上界**。

**与概率的差别**：概率要求 $\text{Bel}(A) + \text{Bel}(\bar A) = 1$；DS 只要求 $\text{Bel}(A) \le \text{Pl}(A)$，区间 $[\text{Bel}, \text{Pl}]$ 表示"不知道"的程度。

**例子**：医疗诊断中，若只知"70% 可能是肺炎，30% 不确定"，则 $m(\{\text{肺炎}\}) = 0.7$，$m(\Theta) = 0.3$，于是 $\text{Bel}(\text{肺炎}) = 0.7$，$\text{Pl}(\text{肺炎}) = 1.0$。

**Dempster 组合规则**（合并两个独立证据源）：

$$m_{12}(A) = \frac{1}{1-K}\sum_{B \cap C = A} m_1(B)\,m_2(C),\qquad K = \sum_{B \cap C = \emptyset} m_1(B)m_2(C)$$

$K$ 是**冲突系数**；$K \to 1$ 时规则失效（**Zadeh 悖论**：两个高度冲突的证据会给出反直觉结果）。

**改进**：

| 方法 | 思路 |
| --- | --- |
| Yager 规则 | 把冲突分配给 $\Theta$（不归一化） |
| 平均/加权组合 | 先对证据加权再组合 |
| Murphy 平均 | 先平均 BPA 再组合 |
| 可信度折扣 | 按来源可靠性折扣 $m^\alpha(A) = \alpha m(A)$ |

**应用**：多传感器融合（雷达 + 红外）、故障诊断、风险评估、专家意见聚合。

**权衡**：

| 优点 | 缺点 |
| --- | --- |
| 能表达"不知道" | 组合规则在冲突时失效 |
| 不需先验 | 计算随 $2^{\lvert\Theta\rvert}$ 增长 |
| 可处理多源异质证据 | 结果对 BPA 分配敏感 |

## 本附录小结

**核心要点**

1. **MRF** 用势函数/能量定义无向依赖，配分函数难算；适合对称依赖（图像、社交）。
2. **CRF** 直接建模 $P(y\mid x)$，特征可任意设计，线性链上用前向-后向与 Viterbi。
3. **模糊逻辑**用隶属函数刻画程度，三步推理（模糊化—规则—去模糊化）；适合控制与可解释规则。
4. **粗糙集**用上下近似刻画"知识不足导致的不可区分"，用于属性约简。
5. **证据理论**用信任/似然区间表达"不知道"，Dempster 组合能融合多源证据，但冲突时需改进规则。
6. 三类方法都不能替代概率的规范性；混用时要明确各自刻画的是"模糊""粒度"还是"信念"。
