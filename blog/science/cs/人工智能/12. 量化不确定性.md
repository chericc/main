# 第 12 章 量化不确定性（Quantifying Uncertainty）

**本章导读**：逻辑智能体只能在"真/假"两值间推理，但现实中的诊断、预测、决策几乎都伴随不确定性：症状不唯一对应疾病，传感器有噪声，未来不可预知。概率论提供了唯一自洽的不确定性演算。本章给出概率记号、用全联合分布做推断、独立性与条件独立性、贝叶斯法则，并以朴素贝叶斯与瓦普斯世界为例，说明"用概率做智能体"的第一步。

**学习目标**：完成本章学习后，你应当能够：

- 说明为什么纯逻辑不足以处理不确定性（懒惰、理论无知、实践无知）；
- 正确使用随机变量、概率分布、联合分布与条件概率的记号；
- 用全联合分布回答任意查询（边缘化 + 条件化）；
- 判断变量独立与条件独立，并用独立性压缩分布规模；
- 推导贝叶斯法则并解释其在诊断中的"因果反转"作用；
- 写出朴素贝叶斯的条件独立假设，说明其优势与失效场景。

**预备知识**：概率论基础（样本空间、条件概率、期望）；第 7 章的命题逻辑（作为对照）；第 2 章的理性智能体。

## 12.1 不确定性下的行动

**为什么需要概率**。逻辑智能体要求知识库推出确定结论，但真实知识有三种缺陷：

| 缺陷 | 例子 |
| --- | --- |
| **懒惰（laziness）** | 列出牙痛的所有可能原因太繁琐，干脆不列 |
| **理论无知（theoretical ignorance）** | 医学尚未完全理解某种疾病的机制 |
| **实践无知（practical ignorance）** | 即使机制已知，也无法获得某个病人的全部检查数据 |

面对缺陷，理性的做法不是"拒绝决策"，而是**用信念度（degree of belief）** 表示把握程度，并让决策最大化**期望效用**。

**决策示例**：牙医面对"病人牙痛、有蛀牙概率 0.8"时：

- 拔牙：期望效用 = $0.8 \times 100 + 0.2 \times (-50) = 70$；
- 补牙：期望效用 = $0.8 \times 80 + 0.2 \times 20 = 68$；
- 不处理：$0.8 \times 10 + 0.2 \times 0 = 8$。

概率把"不确定"变成了可比较的数字。第 16 章会把这一框架形式化为**最大期望效用（MEU）**。

**概率 vs 逻辑**：概率是逻辑的推广。当所有概率为 0 或 1 时，概率推理退化为逻辑推理；概率还额外要求**一致性**（概率公理）与**可计算性**（如何高效算），后者正是第 13 章的主题。

## 12.2 概率记号基础

**随机变量**：取值不确定的量，如 $\text{Cavity} \in \{\text{true}, \text{false}\}$、$\text{Weather} \in \{\text{sunny}, \text{rain}, \text{cloudy}\}$。

**基本记号**：

| 记号 | 含义 |
| --- | --- |
| $P(A)$ | 变量 $A$ 的概率分布（向量） |
| $P(A \mid B)$ | 给定 $B$ 时 $A$ 的条件分布 |
| $P(A, B)$ | 联合分布 |
| $\mathbf{P}(A=true)$ 或 $P(a)$ | 某个具体取值的概率（标量） |
| $\sum_a P(a) = 1$ | 归一化 |

**联合分布与查询**。对 $n$ 个二值变量，全联合分布有 $2^n$ 个条目。任何查询都可由它算出：

- **边缘化（marginalization）**：
$$P(Y) = \sum_z P(Y, Z=z)$$
- **条件化（conditioning）**：
$$P(Y \mid E=e) = \frac{P(Y, E=e)}{P(E=e)} = \alpha\, P(Y, E=e)$$

其中 $\alpha = 1/P(E=e)$ 是归一化常数。

**瓦普斯世界的概率版**。给定 $P(\text{Pit}_{ij})$、$P(\text{Wumpus})$ 与感知的条件概率，可以算：

$$P(P_{1,3} \mid \neg B_{1,1}, B_{2,1}) = \alpha \sum_{\text{其他}} P(\text{全部变量})$$

结论往往令人惊讶：即使没有在 $(1,3)$ 感知到微风，$P(P_{1,3})$ 也可能不为零——因为 $(1,3)$ 未被访问，无法排除。**概率让智能体在"不能证明安全"时仍能评估风险**。

**概率公理**（Kolmogorov）：

$$0 \le P(a) \le 1, \qquad P(\text{true}) = 1, \qquad P(a \lor b) = P(a) + P(b) - P(a \land b)$$

由此导出**全概率公式**与**补律**：$P(\neg a) = 1 - P(a)$。

**为什么用概率而非模糊逻辑**：概率有唯一的、可公理化的"不确定性演算"；模糊逻辑刻画的是"模糊性"（程度），二者不可混用。用模糊值代替概率会导致决策不自洽（违背 Dutch book 论证）。

## 12.3 利用全联合分布进行推断

**推断（inference）** 的目标：给定证据 $E = e$，计算查询变量 $Y$ 的后验分布 $P(Y \mid E=e)$，其余变量 $H$（隐变量）被边缘化。

**算法**：

$$P(Y \mid E=e) = \alpha \sum_{h} P(Y, E=e, H=h)$$

- 若用表格存储全联合分布，单次查询需 $O(2^n)$ 次求和；
- 对 $n = 30$ 个变量，$2^{30} \approx 10^9$ 条目——存储与计算都不可行。

**复杂度**：一般贝叶斯网络上的精确推断是 **NP 难**的（#P 难），但**结构**可以大幅降低复杂度（§13.4 的变量消元）。

**两个实用技巧**：

1. **只保留相关变量**：与查询和证据都无关的变量先边缘化掉（利用独立性）。
2. **避免重复计算**：把求和顺序按网络结构安排，复用中间因子（变量消元的本质）。

## 12.4 独立性

**绝对独立**：

$$P(A, B) = P(A)P(B) \quad \text{或等价地} \quad P(A \mid B) = P(A)$$

独立使联合分布可分解：$n$ 个独立变量只需 $n$ 个参数，而非 $2^n$。

**条件独立**：给定 $C$ 时 $A$ 与 $B$ 独立：

$$P(A, B \mid C) = P(A \mid C)P(B \mid C)$$

**条件独立比绝对独立更常见、更有用**。"下雨"与"洒水器开启"通常不独立（都能解释草地湿），但给定"草地湿"后它们独立（解释被"吸收"）。

**三条必须记住的直觉**（第 13 章会用 d-分离精确化）：

| 结构 | 形式 | 结论 |
| --- | --- | --- |
| 链（chain） | $A \to B \to C$ | 给定 $B$ 时 $A \perp C$ |
| 分叉（fork） | $A \leftarrow B \to C$ | 给定 $B$ 时 $A \perp C$ |
| 对撞（collider） | $A \to B \leftarrow C$ | **给定 $B$ 时反而相关**（解释消除，explaining away） |

对撞结构是初学者最常错的地方：**条件化会打开一条本已阻断的路径**。

**独立性在建模中的作用**：

- 它决定**参数数量**：链式分解 $P(X_1,\dots,X_n) = \prod_i P(X_i \mid \text{Parents}(X_i))$；
- 它决定**推断复杂度**：稀疏的条件依赖使变量消元高效；
- 它是因果推断的基础：混杂（confounder）就是对撞/分叉结构的误读（§13.6 与附录 D）。

## 12.5 贝叶斯法则及其应用

**贝叶斯法则**：

$$P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)} = \alpha\, P(B \mid A)\,P(A)$$

各部分的名字很重要：

| 名称 | 含义 |
| --- | --- |
| $P(A)$ | 先验（prior） |
| $P(B \mid A)$ | 似然（likelihood） |
| $P(B)$ | 证据（evidence，归一化常数） |
| $P(A \mid B)$ | 后验（posterior） |

**多值形式**（对 $A$ 的所有取值）：

$$P(A \mid B) = \alpha\, \mathbf{P}(B \mid A)\, \mathbf{P}(A)$$

**诊断中的"因果反转"**。医学知识通常写成因果方向：$P(\text{症状} \mid \text{疾病})$；但诊断需要反方向 $P(\text{疾病} \mid \text{症状})$。贝叶斯法则正是这个反转工具：

$$P(\text{Cavity} \mid \text{Toothache}) = \alpha\, P(\text{Toothache} \mid \text{Cavity})\, P(\text{Cavity})$$

**经典陷阱：基率忽视（base rate neglect）**。某病患病率 $0.1\%$，检测灵敏度 $99\%$、特异度 $99\%$。阳性后患病概率？

$$P(D \mid +) = \frac{0.99 \times 0.001}{0.99\times0.001 + 0.01\times0.999} \approx \frac{0.00099}{0.01098} \approx 9\%$$

只有 9%，而非 99%。**先验（基率）的影响远大于似然**，这是医学筛查、反欺诈、内容审核中的普遍问题。

**贝叶斯更新是"信念修正"**：后验可作为下一次观测的先验，迭代进行。这与第 10 章 AGM 信念修正的目标一致，但概率版本给出了"修正多少"的定量答案。

## 12.6 朴素贝叶斯模型

**问题**：已知类别 $C$ 与 $n$ 个特征 $X_1,\dots,X_n$，求 $P(C \mid X_1,\dots,X_n)$。直接建模需要 $C \times \prod |X_i|$ 个参数。

**朴素贝叶斯假设**：给定类别时，各特征**条件独立**：

$$P(C \mid X_1,\dots,X_n) = \alpha\, P(C) \prod_{i=1}^{n} P(X_i \mid C)$$

参数数量从指数降到 $O(|C| \cdot \sum_i |X_i|)$。

**分类决策**：

$$\hat{c} = \arg\max_c\ P(c) \prod_i P(x_i \mid c)$$

**为什么"朴素"假设是错的却仍然好用**：

1. 分类只需**排序**正确，不需要概率校准；条件独立的偏差常常对所有类别"同等偏移"，因此不影响 $\arg\max$；
2. 在特征维度高、样本少时，偏差换来的**方差降低**收益更大（偏差-方差权衡，§19.4）；
3. 对文本分类（垃圾邮件、情感分析）等特征弱相关场景，效果接近强模型。

**失效场景**：

- 特征高度相关（如同一文章的字数与词数）：概率被重复计数，输出**过度自信**；
- 需要**校准概率**（如风险定价）：需 Platt scaling 或改用生成式模型；
- 有强交互特征（XOR 型）：条件独立假设彻底破坏。

**变体**：

| 变体 | 似然假设 | 适用 |
| --- | --- | --- |
| 高斯朴素贝叶斯 | 连续特征服从正态分布 | 传感器数据 |
| 多项式朴素贝叶斯 | 词频多项分布 | 文本分类 |
| 伯努利朴素贝叶斯 | 词是否出现（0/1） | 短文本 |
| 半朴素贝叶斯（TAN、AODE） | 允许特征间有限依赖 | 中等规模数据 |

**与逻辑的联系**：朴素贝叶斯是"概率化的规则集合"——每个 $P(x_i \mid c)$ 相当于一条软规则，$\alpha$ 相当于规则的权重。这种"软规则"思想在第 13、19 章会以更一般的形式出现。

## 12.7 再论瓦普斯世界

把概率推理完整地用在瓦普斯世界上，可以看清"概率智能体"与"逻辑智能体"的差别。

**建模**：

- 先验：每格有陷阱的概率 $0.2$（相互独立）；
- 感知模型：$P(B_{ij} \mid \text{相邻有陷阱}) = 0.9$，$P(B_{ij} \mid \text{相邻无陷阱}) = 0.1$（传感器有噪声）。

**推断**：

- 起点 $(1,1)$ 无微风 → $P(P_{1,2})$、$P(P_{2,1})$ 从先验 $0.2$ 大幅下降（约 $0.03$）。注意：因为传感器有噪声，它**不能**像逻辑智能体那样断言"必无陷阱"；
- 走到 $(2,1)$ 感到微风 → $(1,1)$ 已被实际访问验证为空，风险集中到 $(3,1)$ 与 $(2,2)$，二者后验升到 $0.3$ 以上；
- 若再到 $(1,2)$ 仍无微风 → $(2,2)$ 的概率下降，而 $(2,3)$、$(3,2)$ 等从未观测的相邻格仍保留 $0.2$ 的先验。

**决策**：逻辑智能体只走"已被证明安全"的格；概率智能体计算**期望效用**：

$$EU(\text{前进}) = P(\text{安全}) \cdot U(\text{前进}) + P(\text{危险}) \cdot U(\text{死亡})$$

当没有完全安全的格时，概率智能体仍会选**风险最小**的动作——这就是理性的差别。第 16–17 章会把这一逻辑形式化为决策网络与 MDP。

**关键洞察**：概率不消除不确定性，而是让不确定性**可比较、可优化**。这是从"逻辑智能体"迈向"现实智能体"的分水岭。

## 本章小结

**核心要点**

1. 不确定性源于**懒惰、理论无知、实践无知**；理性应对方式是信念度 + 期望效用。
2. 全联合分布可回答任意查询：**边缘化 + 条件化 + 归一化**，但规模指数增长。
3. **独立性**把参数从 $2^n$ 降到线性；**条件独立性**更常见，且对撞结构会"条件化后反而相关"。
4. **贝叶斯法则**实现因果反转，是诊断的核心；**基率忽视**是最常见的误用。
5. **朴素贝叶斯**以条件独立换取参数效率，分类效果好但概率常不校准。
6. 概率智能体在无法证明安全时仍能按期望效用决策，这是它优于逻辑智能体之处。
