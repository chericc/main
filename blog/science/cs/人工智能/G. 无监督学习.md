# 附录 G 无监督学习

**本章导读**：AIMA 第 4 版没有为聚类、降维与半监督学习设立专章，但它们是机器学习实践的主力：没有标签时如何发现结构（G.1、G.2），标签很少时如何利用未标注数据（G.3）。本附录按"分组 → 压缩 → 半监督"的顺序展开，重点在**如何评价**与**何时该用**——无监督学习最大的风险不是算法不强，而是**结果无法验证**。

**学习目标**：完成本附录学习后，你应当能够：

- 比较 K-means、GMM、DBSCAN、层次聚类与谱聚类的适用条件；
- 说明聚类评估的内部/外部指标及其局限；
- 用 PCA 解释方差，用 t-SNE/UMAP 做可视化并说明其陷阱；
- 区分自编码器与线性降维的关系；
- 描述自训练、协同训练、标签传播与一致性正则；
- 说明弱监督与噪声标签的处理策略。

**预备知识**：第 19–20 章的模型与 EM；第 12 章的概率；线性代数（特征分解、SVD）。

---

## G.1 聚类分析

**聚类**把无标签样本分成若干组，使组内相似、组间相异。核心困难是"相似"与"组数"都由人定义。

**（1）K-means**。目标：

$$\min_{\{\mu_k\},\{r_{ik}\}} \sum_i \sum_k r_{ik}\|x_i - \mu_k\|^2$$

交替两步：分配样本到最近中心（E 步）→ 更新中心为均值（M 步）。等价于**球状、等方差高斯混合**的特例。

| 优点 | 缺点 |
| --- | --- |
| 简单、快（$O(NKd)$/轮） | 需指定 $K$ |
| 易并行 | 只适合凸、球状簇 |
| 收敛快 | 对初始化敏感（用 k-means++） |

**（2）高斯混合模型（GMM）**。软分配 + 任意协方差：

$$p(x) = \sum_k \pi_k \mathcal{N}(x \mid \mu_k, \Sigma_k)$$

用 **EM** 求解（§20.3）。相比 K-means：

- 输出**后验概率**（软聚类）；
- 可建模椭圆簇与不同大小；
- 需更多数据与参数，且可能塌缩（加正则）。

**（3）DBSCAN（密度聚类）**。基于"核心点—可达"定义簇：

- 参数：邻域半径 $\varepsilon$、最小点数 MinPts；
- 优点：**不需指定簇数**、能识别噪声、可发现任意形状；
- 缺点：参数敏感、密度不均时失效（HDBSCAN 改进）。

**（4）层次聚类**。自底向上合并（凝聚）或自顶向下分裂：

- 距离度量：单链（min）、全链（max）、平均链、Ward（最小方差）；
- 输出**树状图（dendrogram）**，可在不同粒度切分；
- 复杂度 $O(N^2)$ 或 $O(N^2\log N)$，适合中小规模。

**（5）谱聚类**。用图拉普拉斯矩阵的特征向量嵌入后再 K-means：

$$L = D - W,\qquad \text{解 } L v = \lambda D v \text{ 的前 } k \text{ 个特征向量}$$

能处理**非凸簇**（如双月形），代价是 $O(N^3)$ 的特征分解（可用 Nyström 近似）。

**（6）其他**：Mean Shift（核密度爬山）、Affinity Propagation（消息传递选代表）、BIRCH（大规模增量）、高斯混合的变分版本。

**评估**：

| 类型 | 指标 | 说明 |
| --- | --- | --- |
| 内部 | 轮廓系数（silhouette） | 簇内紧、簇间远 |
| 内部 | Calinski–Harabasz | 方差比 |
| 内部 | Davies–Bouldin | 越小越好 |
| 外部 | ARI、NMI、纯度 | 有真标签时 |
| 稳定性 | bootstrap 重采样一致性 | 无标签时最实用 |

**注意**：内部指标偏好凸簇，不能用于比较不同形状的算法；**"聚类结果好不好"最终取决于下游用途**。

## G.2 降维与流形学习

**（1）PCA（主成分分析）**。找方差最大的正交方向：

$$\max_{w} w^\top \Sigma w \quad \text{s.t.}\ \|w\|=1$$

解为协方差矩阵的前 $k$ 个特征向量；等价于对中心化数据做 **SVD**：$X = U\Sigma V^\top$，投影 $Z = U_k\Sigma_k$。

- 解释：保留的方差比例 = $\sum_{i\le k}\lambda_i / \sum_i \lambda_i$；
- 用途：去相关、降噪、可视化、特征压缩；
- 局限：**只捕捉线性结构**，对异常值敏感（可用稳健 PCA）。

**（2）核 PCA**：在核空间做 PCA，捕捉非线性结构。

**（3）t-SNE**。把高维距离转成概率，最小化与低维分布的 KL 散度：

$$p_{j|i} = \frac{\exp(-\|x_i-x_j\|^2/2\sigma_i^2)}{\sum_{k\ne i}\exp(-\|x_i-x_k\|^2/2\sigma_i^2)},\qquad \mathcal{L} = \mathrm{KL}(P \| Q)$$

- 优点：**局部结构**保留极好，可视化美观；
- 陷阱：**簇间距离无意义**、对困惑度（perplexity）敏感、随机性大、不能用于新样本（除非训练时加 transform）。

**（4）UMAP**。基于拓扑与黎曼几何的近似，速度更快、全局结构保留更好，但同样**不能过度解读距离**。

**（5）其他**：

| 方法 | 特点 |
| --- | --- |
| LDA | 有监督，最大化类间/类内比 |
| ICA | 分离独立源（盲源分离） |
| NMF | 非负分解，可解释（主题、谱） |
| 随机投影 | Johnson–Lindenstrauss，快速保距 |
| 自编码器 | 非线性降维，可学习表示（§21.7） |
| 扩散映射 / Isomap / LLE | 流形学习，保留测地距离 |

**降维的三条实用建议**：

1. **先用 PCA 白化**再做其他方法（去相关、加速）；
2. 可视化用 t-SNE/UMAP，但**结论只用于局部**；
3. 下游任务需要可解释性时，优先 PCA/NMF 而非 t-SNE。

## G.3 半监督与弱监督学习

**半监督学习**：少量标注 + 大量未标注。

**（1）自训练（self-training）**：用已有模型给未标注数据打伪标签，选高置信度的加入训练，迭代。

- 简单通用；
- 风险：**确认偏差**（错误伪标签自我强化）；
- 对策：置信度阈值、类别平衡、教师集成、一致性正则。

**（2）协同训练（co-training）**：两个**视角**（特征子集）各自训练，互相给对高置信样本打标签。要求视角**条件独立**，实际中常放宽。

**（3）标签传播（label propagation）**：在相似图上把标签从有标注节点扩散到未标注节点：

$$F \leftarrow \alpha S F + (1-\alpha)Y$$

$S$ 是归一化相似度矩阵，$Y$ 是初始标签。适合小规模、图结构明确的数据。

**（4）一致性正则**：对同一输入做不同扰动，要求输出一致（$\Pi$-model、Mean Teacher、FixMatch）。它是现代半监督的主流，在图像分类上用少量标签即可接近全监督。

**（5）生成式半监督**：用 VAE/GAN 的隐空间做半监督分类（如 M2 模型），或用**混合**（MixMatch、MixUp）构造插值样本。

**弱监督**：标签**不精确**——不完全、不精确、不准确。

| 类型 | 例子 | 方法 |
| --- | --- | --- |
| 不完全 | 只有部分样本有标签 | 半监督 |
| 不精确 | 只有包级标签（多示例） | MIL |
| 不准确 | 众包噪声标签 | 噪声鲁棒损失、样本重加权、标签纠正 |
| 间接 | 规则/启发式标注（Snorkel） | 标签模型（生成式）估计准确率 |

**噪声标签的处理**：

1. **损失层**：对称交叉熵、广义交叉熵、bootstrapping；
2. **样本层**：small-loss 选择、co-teaching（两个网络互选干净样本）；
3. **模型层**：标签平滑、正则、集成；
4. **数据层**：清洗、重新标注、置信学习（confident learning）。

**评估**：半监督的收益要用**相同标注预算**下的对比实验证明；弱监督要报告**标签质量**（准确率、覆盖率）与**噪声率敏感性**。

**原则**：

- 未标注数据要**与测试分布一致**才有帮助，否则可能有害；
- 半监督的假设（聚类假设、流形假设）必须与任务匹配；
- 噪声标签下，"更多数据"可能不如"更干净的数据"。

## 本附录小结

**核心要点**

1. 聚类算法各有形状假设：**K-means（球状）、GMM（椭圆、软分配）、DBSCAN（密度）、谱聚类（非凸）**；簇数选择与评估同样重要。
2. 聚类评估的**内部指标偏好凸簇**，无真标签时**稳定性**是最实用的判据。
3. **PCA** 是线性降维的基线，解释方差比例；**t-SNE/UMAP** 只适合可视化，不能解读簇间距离。
4. 自编码器是非线性降维与表示学习的桥梁；生成模型提供概率化的隐空间。
5. **半监督**四条路线：自训练、协同训练、标签传播、一致性正则；一致性正则（FixMatch 类）是当前主流。
6. **弱监督**的核心是标签噪声建模：损失层、样本层、模型层、数据层四类手段。
