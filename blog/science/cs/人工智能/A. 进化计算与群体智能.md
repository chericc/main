# 附录 A 进化计算与群体智能

**本章导读**：进化计算与群体智能是第 4 章"局部搜索"的自然延伸——它们用**种群**代替单个解，用**随机变异 + 选择**代替梯度。它们不要求目标函数可微，也不要求问题的连续结构，因此在组合优化、参数调优、工程设计中被广泛使用。本附录按"个体 → 种群 → 群体 → 多目标"的顺序介绍：遗传算法（A.1）、遗传编程与进化策略（A.2）、粒子群（A.3）、蚁群（A.4）、人工蜂群与差分进化（A.5）、多目标优化（A.6）。

**学习目标**：完成本附录学习后，你应当能够：

- 写出 GA 的编码、适应度、选择、交叉、变异五要素，并说明模式定理的直觉；
- 区分 GA、GP、ES 的表示与变异方式；
- 写出 PSO 的速度更新式，解释惯性权重与认知/社会项；
- 说明 ACO 的信息素更新机制与 MMAS 的改进；
- 说明 ABC 与 DE 的算子设计；
- 用 Pareto 支配与拥挤距离解释 NSGA-II，并比较 SPEA2 与 MOEA/D。

**预备知识**：第 4 章的局部搜索与模拟退火；概率与期望；基本的组合优化概念。

## A.1 遗传算法

**遗传算法（genetic algorithm, GA）** 模拟自然选择：种群中的个体是候选解，适应度高的个体更可能繁殖。

**五要素**：

| 要素 | 说明 | 常见选择 |
| --- | --- | --- |
| 编码 | 解的表示 | 二进制、实数、排列、树 |
| 适应度 | 评价函数 | 目标函数（需最大化） |
| 选择 | 谁繁殖 | 轮盘赌、锦标赛、排名 |
| 交叉 | 如何组合 | 单点、多点、均匀、OX（排列） |
| 变异 | 如何扰动 | 位翻转、高斯扰动、交换 |

**选择算子**：

| 算子 | 机制 | 特点 |
| --- | --- | --- |
| 轮盘赌 | 按适应度比例 | 简单，易早熟（超级个体） |
| 锦标赛 | 随机取 $k$ 个，选最好的 | 常用，选择压力可调 |
| 排名 | 按名次而非绝对值 | 抗适应度尺度问题 |
| 精英保留 | 最优个体直接进入下一代 | 保证不退化 |

**交叉算子**：

- **单点/多点**：在若干位置交换片段；
- **均匀**：逐位随机来自父母；
- **顺序交叉（OX）/ PMX**：用于排列编码（TSP），保证不重复；
- **实数交叉**：模拟二进制（SBX）、算术交叉。

**变异**：二进制翻转概率通常 $1/L$（$L$ 为串长）；实数用高斯扰动；排列用交换/逆序。

**模式定理（schema theorem）** 的直觉：短定义距、低阶、高适应度的"积木块"在代际中以指数速度增长。这是 GA 的理论支撑，但它假设了**积木块独立**，实际常被违反。

**GA 的实践问题**：

| 问题 | 表现 | 对策 |
| --- | --- | --- |
| 早熟收敛 | 种群失去多样性 | 增大变异、岛屿模型、共享适应度 |
| 参数敏感 | 交叉/变异率难调 | 自适应参数（如自适应 GA） |
| 评价昂贵 | 适应度计算慢 | 代理模型、并行评估 |
| 无梯度信息 | 收敛慢 | 局部搜索杂交（Memetic 算法） |

**应用**：TSP、调度、电路布局、天线设计、超参数搜索、特征选择。

## A.2 遗传编程与进化策略

**遗传编程（genetic programming, GP）**：个体是**程序/表达式树**，用交叉（子树交换）与变异（子树替换、节点变异）进化。

- **表示**：树（Lisp 表达式）、线性指令序列（线性 GP）；
- **适应度**：任务误差 + **简约惩罚**（防止表达式膨胀，bloat）；
- **应用**：符号回归、自动特征构造、策略搜索、程序合成。

**进化策略（evolution strategies, ES）**：个体是实数向量，变异是**高斯扰动**，选择基于排名。

- $(\mu, \lambda)$-ES：从 $\lambda$ 个子代中选 $\mu$ 个（父代不参与）；
- $(\mu + \lambda)$-ES：父代与子代一起选（精英保留）；
- **协方差矩阵自适应（CMA-ES）**：自适应学习扰动的协方差，能捕捉变量间的相关性，是连续黑箱优化的强基线。

**CMA-ES 的核心**：维护分布 $\mathcal{N}(m, \sigma^2 C)$，每代采样 $\lambda$ 个个体，按排名加权更新 $m$、$C$ 与步长 $\sigma$。它在 10–100 维的连续优化上常优于 GA。

**三者的对比**：

| 方法 | 表示 | 主要算子 | 适合 |
| --- | --- | --- | --- |
| GA | 串/向量 | 交叉为主 | 离散、组合 |
| GP | 树/程序 | 子树交换 | 符号、程序 |
| ES | 实数向量 | 高斯变异 | 连续、参数优化 |

## A.3 粒子群优化（PSO）

**PSO** 模拟鸟群觅食：每个粒子有位置 $x_i$ 与速度 $v_i$，向"自己的历史最优" $p_i$ 与"群体最优" $g$ 靠拢。

$$v_i \leftarrow w v_i + c_1 r_1 (p_i - x_i) + c_2 r_2 (g - x_i)$$
$$x_i \leftarrow x_i + v_i$$

| 项 | 含义 | 典型值 |
| --- | --- | --- |
| $w$ | 惯性权重 | 0.4–0.9（线性递减） |
| $c_1$ | 认知系数 | 1.5–2.0 |
| $c_2$ | 社会系数 | 1.5–2.0 |
| $r_1, r_2$ | 均匀随机数 | $U(0,1)$ |

**变体**：

| 变体 | 改进 |
| --- | --- |
| 全局/局部 PSO | 用邻域最优替代全局最优，保持多样性 |
| 收缩因子 PSO | 用约束因子保证收敛 |
| 自适应 PSO | 动态调整 $w$ 与系数 |
| 离散 PSO | 重新定义速度（交换序列） |

**优缺点**：实现极简、参数少、收敛快；但**易早熟**、理论保证弱（无全局收敛证明，除非加随机扰动）。

## A.4 蚁群算法（ACO）

**ACO** 模拟蚂蚁用信息素通信寻找最短路径。以 TSP 为例：

1. 每只蚂蚁从随机城市出发，按**转移概率**逐步构造路径：

$$p_{ij} = \frac{\tau_{ij}^\alpha \eta_{ij}^\beta}{\sum_{k \in \text{allowed}} \tau_{ik}^\alpha \eta_{ik}^\beta}$$

其中 $\tau$ 是信息素，$\eta = 1/d_{ij}$ 是启发式（短边优先），$\alpha, \beta$ 控制两者权重。

2. 所有蚂蚁完成后，**信息素挥发 + 沉积**：

$$\tau_{ij} \leftarrow (1-\rho)\tau_{ij} + \sum_k \Delta\tau_{ij}^k,\qquad \Delta\tau_{ij}^k = \frac{Q}{L_k}\ (\text{若蚂蚁 } k \text{ 走过边 } ij)$$

**主要变体**：

| 变体 | 改进 |
| --- | --- |
| 蚂蚁系统（AS） | 原始版本 |
| 精英蚂蚁 | 最优路径额外加信息素 |
| 蚁群系统（ACS） | 伪随机比例规则 + 局部更新 |
| **MMAS（最大最小蚂蚁系统）** | 信息素限幅 $[\tau_\min, \tau_\max]$，防早熟 |
| 排序蚂蚁 | 按路径质量加权沉积 |

**应用**：TSP、车辆路径、网络路由、作业调度、图着色。

## A.5 人工蜂群与差分进化

**人工蜂群（artificial bee colony, ABC）** 把蜂群分为三类：

| 角色 | 职责 |
| --- | --- |
| 雇佣蜂 | 在已知蜜源附近搜索 |
| 观察蜂 | 按蜜源质量概率选择跟随 |
| 侦察蜂 | 放弃枯竭蜜源，随机探索新位置 |

新位置生成：$v_{ij} = x_{ij} + \phi_{ij}(x_{ij} - x_{kj})$，$\phi \in [-1,1]$。ABC 的优点是**探索与开发分工明确**，参数少；缺点是在某些问题上收敛慢。

**差分进化（differential evolution, DE）**：用"个体差"作为变异方向：

1. **变异**：$v_i = x_{r1} + F(x_{r2} - x_{r3})$；
2. **交叉**：与目标向量逐维混合（二项或指数）；
3. **选择**：子代优于父代才替换（贪婪）。

参数：缩放因子 $F \in [0.4, 1.0]$、交叉率 $CR \in [0.1, 0.9]$。变体包括 DE/rand/1、DE/best/1、DE/current-to-best/1、自适应 DE（JADE、SHADE）。

**对比**：

| 方法 | 机制 | 适合 |
| --- | --- | --- |
| ABC | 角色分工 + 邻域搜索 | 多峰连续优化 |
| DE | 差分变异 + 贪婪选择 | 连续参数优化，收敛快 |
| PSO | 速度更新 + 群体最优 | 连续、快速近似 |

## A.6 多目标进化优化

**多目标问题**：$\min \mathbf{f}(x) = (f_1(x),\dots,f_m(x))$，目标之间冲突，没有单一最优，只有 **Pareto 最优集**。

**Pareto 支配**：$a$ 支配 $b$ 当且仅当 $a$ 在所有目标上不差且至少一个更好。不被任何解支配的解构成 **Pareto 前沿**。

**NSGA-II** 的三个关键组件：

1. **非支配排序**：把种群分成若干前沿 $F_1, F_2, \dots$；
2. **拥挤距离**：同一前沿内，按各目标排序后计算邻居距离，保留"稀疏区域"的解；
3. **精英保留 + 锦标赛选择**：按（前沿等级，拥挤距离）比较。

复杂度 $O(mN^2)$，是应用最广的多目标算法。

**其他算法**：

| 算法 | 特点 |
| --- | --- |
| SPEA2 | 用外部档案 + 强度值，精细的适应度分配 |
| MOEA/D | 把多目标分解为若干标量化子问题，邻域协同进化 |
| NSGA-III | 用参考点处理超多目标（$m > 3$） |
| IBEA | 基于指标（如超体积）的选择 |
| RVEA | 参考向量引导，适合高维目标 |

**评价指标**：

| 指标 | 衡量 |
| --- | --- |
| 超体积（hypervolume） | 前沿支配的区域体积（越大越好） |
| 反向世代距离（IGD） | 到真实前沿的平均距离（越小越好） |
| 间距（spacing） | 解的均匀性 |
| 覆盖率（C-metric） | 两个前沿的相对优劣 |

**应用**：工程设计（成本 vs 性能）、调度（时间 vs 能耗）、机器学习（精度 vs 延迟 vs 公平性）、投资组合。

## 本附录小结

**核心要点**

1. **GA** 的五要素是编码、适应度、选择、交叉、变异；模式定理给出"积木块增长"的直觉，但实际受早熟与参数敏感困扰。
2. **GP** 进化程序树，需简约惩罚防膨胀；**ES/CMA-ES** 是连续黑箱优化的强基线。
3. **PSO** 用速度 + 个体最优 + 群体最优，简单快速但易早熟。
4. **ACO** 用信息素 + 启发式构造路径，MMAS 的限幅是防早熟的关键。
5. **ABC** 靠角色分工平衡探索与开发；**DE** 用差分变异 + 贪婪选择，收敛快。
6. **多目标**优化求 Pareto 前沿；NSGA-II 的（非支配排序 + 拥挤距离）是标准范式，评价用超体积/IGD。
