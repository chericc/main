# 第 4 章 复杂环境中的搜索（Search in Complex Environments）

**本章导读**：第 3 章假设环境完全可观察、确定性、已知，且我们需要一条完整路径。现实常常三条都不满足：目标只需"到达"，不必关心路径（局部搜索）；状态与动作连续（数值优化）；动作结果不确定（与或搜索）；状态看不全（信念状态）。本章逐一给出这四种复杂环境下的搜索方法，并以在线搜索收尾——智能体在完全未知的环境中边探索边行动。

**学习目标**：完成本章学习后，你应当能够：

- 用爬山法、模拟退火、局部束搜索求解最优化问题，并解释局部极大与平台问题；
- 在连续空间中做梯度上升/下降、线搜索与牛顿法，说明学习率的作用；
- 把非确定性动作建模为与或图，用与或搜索找到强解；
- 用信念状态处理部分可观测问题，区分无感知（conformant）与有感知（contingent）规划；
- 说明在线搜索与离线搜索的差别，写出在线 DFS 与 LRTA\* 的更新规则。

**预备知识**：第 3 章的搜索框架与复杂度记号；微积分（偏导、梯度、Hessian）；贝叶斯法则（§12.5）。

---

## 4.1 局部搜索与最优化问题

**局部搜索（local search）** 不关心路径，只关心**最终状态**。它维护单个（或少量）当前状态，每步移动到邻居中更好的状态。适用于状态空间巨大、但只需找到满足目标的状态的问题（八皇后、TSP、调度、电路布局）。

**爬山法（hill climbing）**。每步选择使目标函数改进最大的邻居：

```
current ← 初始状态
loop:
    neighbor ← 使 value 最大的邻居
    if value(neighbor) ≤ value(current): return current
    current ← neighbor
```

三类失败模式：

| 模式 | 表现 | 对策 |
| --- | --- | --- |
| 局部极大（local maximum） | 邻居都比自己差，但不是全局最优 | 随机重启、模拟退火 |
| 平台（plateau） | 邻居与自己同值，无梯度 | 横向移动、随机扰动 |
| 山脊（ridge） | 单步方向都不改进，但组合方向可以 | 尝试更大步长或组合动作 |

**随机重启爬山法**：重复爬山并以随机初始点启动，成功率随重启次数上升。八皇后（$n=8$）中，纯爬山 + 侧向移动在数千次重启内即可解出；$n$ 很大时，单次爬山的成功概率约 $0.14$ 量级不变，因此重启次数与 $n$ 近似线性。

**模拟退火（simulated annealing）**。以概率接受更差的移动，从而跳出局部极大：

$$P(\text{接受}) = \begin{cases} 1, & \Delta E > 0 \\ e^{\Delta E / T}, & \Delta E \le 0 \end{cases}$$

其中 $\Delta E$ 是目标函数增量，$T$ 是温度。理论保证（对数降温 $T_t \propto 1/\log t$）下以概率 1 收敛到全局最优，但该速率慢到不可用；实践中用几何降温 $T_{t+1} = \alpha T_t$（$\alpha \in [0.8, 0.99]$）。

**局部束搜索（local beam search）**。同时维护 $k$ 个状态，每步生成全部后继，从中挑最好的 $k$ 个。注意：**它与并行运行 $k$ 次随机重启不同**——束搜索的 $k$ 个状态共享信息，会向"有希望的"区域聚集，因此更容易早熟收敛。**随机束搜索**从后继中按概率采样以保持多样性。

**进化算法**。把"状态"变成"种群"，"邻居"变成"交叉+变异"，是局部束搜索的种群版本。完整的遗传算法、遗传编程、粒子群与蚁群见**附录 A**，此处只记住一点：**它们都是基于种群的无梯度局部搜索**。

**局部搜索的取舍**：

- 优点：内存常数级、每步代价低、可处理巨大状态空间、天然适合连续与组合优化；
- 缺点：不完备、不最优、对目标函数形态敏感。

## 4.2 连续空间中的局部搜索

当状态是实数向量 $\mathbf{x} \in \mathbb{R}^n$、目标函数 $f(\mathbf{x})$ 可微时，局部搜索变成**数值优化**。

**梯度上升/下降**。沿梯度方向移动：

$$\mathbf{x}_{t+1} = \mathbf{x}_t + \alpha \nabla f(\mathbf{x}_t) \quad(\text{下降则取} -\nabla f)$$

其中 $\alpha$ 是**步长（学习率）**。三个实践要点：

1. $\alpha$ 太大振荡发散，太小收敛慢；常用线搜索或自适应方案（Adam 等，见 §21.4）。
2. 梯度为零的点可能是局部极小、局部极大或**鞍点**——高维空间中鞍点远比局部极小常见。
3. 数值梯度用中心差分 $\frac{f(x+\epsilon)-f(x-\epsilon)}{2\epsilon}$，或反向传播自动微分（§21.2）。

**线搜索（line search）**。在方向 $\mathbf{d}$ 上解一维问题 $\min_\alpha f(\mathbf{x} + \alpha \mathbf{d})$，常用黄金分割或 Armijo 条件（充分下降）实现。

**牛顿法**。用二阶信息加速：

$$\mathbf{x}_{t+1} = \mathbf{x}_t - H^{-1} \nabla f(\mathbf{x}_t)$$

二次收敛，但需 $O(n^3)$ 求解线性系统，且要求 Hessian 正定。**拟牛顿法**（BFGS、L-BFGS）用梯度差近似 Hessian 的逆，兼顾速度与代价。**高斯-牛顿与 Levenberg–Marquardt** 用于非线性最小二乘。

**约束优化**。等式约束用拉格朗日乘子；不等式约束用 KKT 条件与内点法。机器人轨迹优化与强化学习的策略优化都落在这里（§17.2、§22.5）。

**无梯度方法**。目标不可微或为黑盒时，用**坐标下降**、**Nelder–Mead 单纯形**、**CMA-ES**（协方差自适应进化策略，属附录 A 的进化算法家族）。

## 4.3 非确定性动作下的搜索

当动作的结果不确定（吸尘器可能把灰甩到别处、机器人轮子可能打滑），解的形态从"一条路径"变成**一棵策略树**：每个可能的结果都要有应对。

**与或树（AND-OR tree）**。节点分两类：

- **或节点（OR node）**：智能体可选择的动作，只需**一个**子节点可解；
- **与节点（AND node）**：环境给出的可能结果，**所有**子节点都必须可解。

**与或图搜索（AND-OR graph search）**：

```
function AND-OR-GRAPH-SEARCH(problem):
    return OR-SEARCH(problem.INITIAL, problem, [])
function OR-SEARCH(state, problem, path):
    if GOAL-TEST(state): return 空策略
    if state ∈ path: return failure            # 环检测
    for action in ACTIONS(state):
        plan ← AND-SEARCH(RESULTS(state, action), problem, [state|path])
        if plan ≠ failure: return [action | plan]
    return failure
function AND-SEARCH(states, problem, path):
    for s_i in states:
        plan_i ← OR-SEARCH(s_i, problem, path)
        if plan_i = failure: return failure
    return 所有 plan_i 的组合
```

关键点：

- **环**：非确定性环境中，环可能是合法的"循环解"（如"一直扫地直到干净"）。若允许循环，需在策略中记录状态并检测重复。
- **强解 vs 弱解**：与或搜索求的**强解（strong solution）**在**所有**结果下都能达成目标；只对某些结果成功的称弱解，通常不满足需求。
- **复杂度**：与或树的规模是"动作数 × 结果数"的指数，实际需剪枝与启发式。

## 4.4 部分可观测环境中的搜索

部分可观察时，智能体不知道确切状态，只能维护**信念状态（belief state）**：所有可能当前状态的集合。

- 初始信念状态 $b_0$ 是可能初始状态的集合；
- 执行动作 $a$ 后，预测：$b' = \bigcup_{s \in b} \text{RESULTS}(s,a)$；
- 得到感知 $e$ 后，更新：$b'' = \{\, s \in b' : \text{POSSIBLE-PERCEPT}(s) = e \,\}$。

**无感知问题（sensorless / conformant problem）**。完全没有感知，目标是找**一个动作序列**，使执行后无论实际初始状态如何都达成目标。它把问题变成"在信念状态空间中的搜索"，规模可达 $2^{|S|}$，但常有压缩结构（如吸尘器世界可只用"哪些格子可能脏"描述）。

**有条件规划（contingent planning）**。有部分感知时，策略依赖感知：为每个可能的感知分支准备不同动作。这等价于在**信念状态空间**上做与或搜索：或节点是动作，与节点是可能的感知结果。

**关键洞察**：部分可观察问题可以**转化为**完全可观察问题——只要把"状态"换成"信念状态"。代价是状态空间指数膨胀，因此工程上常用**因子化信念**（每个变量独立维护分布，§13.2）或**粒子滤波**（§14.5）近似。

## 4.5 在线搜索智能体与未知环境

**离线搜索**先算出完整解再执行；**在线搜索**边行动边学习，只保证"走一步算一步"。当环境完全未知、或模型难以获得时，只能在线。

**在线搜索的四条要求**：

1. **行动必须安全**（不能走进去就回不来的状态）；
2. **可探索**：能发现新状态；
3. **有界回溯**：允许回头，否则死路即终局；
4. **竞争比**（competitive ratio）：在线代价 / 离线最优代价，衡量"无知"的代价。

**在线深度优先搜索（online DFS）**。维护"未探索动作表"，每到一个状态就尝试一个未试动作，无路可走则回溯。空间 $O(\text{状态数})$，适合无向、可逆的图。

**LRTA\*（learning real-time A\*）**。为每个状态维护启发值 $H(s)$，每步执行：

$$H(s) \leftarrow \max\Big\{ H(s),\ \min_{a} \big[ c(s,a,s') + H(s') \big] \Big\}$$

即"用邻居的最优估计更新自己"（值迭代的单步版本，见 §17.2）。特点：

- 每步只扩展一个状态，**实时性**好；
- 在有限、确定、可逆的环境中，$H$ 收敛到真实代价，路径代价收敛到最优；
- 与 A\* 的关系：A\* 是"先想清楚再走"，LRTA\* 是"边走边想"。

**探索与利用的张力**在在线搜索中首次出现：探索新区域能改进模型，但会增加当前代价。第 17.3 节的多臂老虎机与第 22 章的强化学习会把这一权衡形式化。

## 本章小结

**核心要点**

1. 局部搜索只关心最终状态，内存常数级；爬山法受**局部极大、平台、山脊**困扰，用随机重启与模拟退火缓解。
2. 连续空间优化依赖梯度与二阶信息；学习率、鞍点与条件数是实践中的三大问题。
3. 非确定性动作产生**与或树**，解是策略树而非路径；与或搜索求**强解**，环可能是合法循环解。
4. 部分可观察问题通过**信念状态**转化为完全可观察问题，代价是指数膨胀；无感知问题求无条件序列，有条件规划求感知相关策略。
5. 在线搜索在未知环境中边探索边行动，用**竞争比**衡量代价；LRTA\* 是"实时版值迭代"。
