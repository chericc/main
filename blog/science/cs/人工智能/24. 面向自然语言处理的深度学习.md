# 第 24 章 面向自然语言处理的深度学习（Deep Learning for NLP）

**本章导读**：第 23 章的 n-gram 与 CFG 是"符号 + 计数"的路线；本章是"表示 + 注意力"的路线。主线很清楚：**词嵌入**把离散符号变成连续向量（24.1）→ **RNN** 编码序列（24.2）→ **Seq2Seq** 做生成（24.3）→ **注意力**解决信息瓶颈（24.4）→ **Transformer** 把注意力堆成通用架构（24.5）→ **预训练**用海量文本自监督学习（24.6）→ 大模型承担摘要、问答、对话与工具调用（24.7）。

**学习目标**：完成本章学习后，你应当能够：

- 比较 one-hot、word2vec、GloVe 与子词嵌入的取舍；
- 说明 RNN 在序列标注中的用法与梯度问题；
- 画出编码器-解码器结构，解释信息瓶颈与 teacher forcing；
- 写出缩放点积注意力与多头注意力，说明位置编码的必要性；
- 描述 Transformer 块的结构与 $O(n^2)$ 复杂度及其改进方向；
- 区分 BERT（编码器/掩码）、GPT（解码器/自回归）、T5（编码器-解码器）的预训练目标；
- 说明 LoRA、RLHF/DPO、RAG、工具调用在大模型落地中的角色。

**预备知识**：第 21 章的神经网络、反向传播、优化与正则；第 23 章的 n-gram 与 Seq2Seq 的统计版本。

## 24.1 词嵌入

**one-hot 的问题**：词表 $10^5$ 时向量维度 $10^5$，且任意两词的内积为 0——**无法表达相似性**。

**分布假说**：一个词的意义由它的上下文决定。词嵌入把词映射到低维稠密空间，使"语义相近 → 向量相近"。

**（1）word2vec**。两种训练方式：

| 模型 | 任务 | 特点 |
| --- | --- | --- |
| CBOW | 用上下文预测中心词 | 训练快，高频词效果好 |
| Skip-gram | 用中心词预测上下文 | 低频词与语义关系更好 |

**负采样（negative sampling）** 把 softmax 变成二分类：正样本是真实上下文词，负样本按 $P(w) \propto f(w)^{3/4}$ 采样。目标：

$$\log\sigma(u_o^\top v_c) + \sum_{k=1}^{K}\mathbb{E}_{w_k \sim P_n}\big[\log\sigma(-u_{w_k}^\top v_c)\big]$$

**（2）GloVe**：基于**共现矩阵**分解，目标使 $w_i^\top \tilde w_j + b_i + \tilde b_j \approx \log X_{ij}$。它把全局统计与局部窗口结合。

**（3）子词嵌入（subword）**：

- **BPE（byte pair encoding）**：反复合并最高频的字符对，得到子词词表；
- **WordPiece / Unigram**：类似思想的变体；
- **FastText**：词 = 字符 n-gram 之和，可处理未登录词与形态丰富语言。

子词使模型能表示未见词（如 `unbelievably` → `un` + `believ` + `ably`），是**现代 LLM 分词器的默认**（GPT 用 BPE，BERT 用 WordPiece）。

**静态嵌入的局限**：一个词只有一个向量，无法区分多义（"银行" vs "河岸"）。**上下文嵌入**（ELMo、BERT）按句子动态生成——这是 §24.6 的起点。

**语义关系的几何**：$v_\text{king} - v_\text{man} + v_\text{woman} \approx v_\text{queen}$。但这类类比也暴露**社会偏见**：嵌入会复制语料中的刻板印象，需要去偏（debiasing）。

## 24.2 循环神经网络

**序列标注**（词性、NER、分块）的典型结构：

```
x_1 … x_n → BiLSTM → 每步表示 → 分类层 → y_1 … y_n
```

**双向性**：前向 LSTM 看左侧上下文，后向看右侧，拼接后每步同时拥有两侧信息。

**结构化输出**：标签之间有约束（如 IOB 格式），用 **CRF 层**建模标签转移：

$$P(y \mid x) = \frac{\exp\big(\sum_t s_t(y_t) + \sum_t T(y_{t-1}, y_t)\big)}{\sum_{y'} \cdots}$$

训练用负对数似然，解码用 Viterbi（§14.3）。BiLSTM-CRF 曾是 NER 的标准架构。

**RNN 的局限**：

| 局限 | 后果 |
| --- | --- |
| 串行计算 | 无法并行，训练慢 |
| 长程依赖 | 即使有门控，信息仍衰减 |
| 固定长度隐状态 | 编码长句时成为瓶颈 |

这三点分别由 Transformer 的并行性、注意力与"直接连接任意两位置"解决。

## 24.3 序列到序列模型

**编码器-解码器**：编码器把源序列压缩为隐状态，解码器逐词生成目标：

$$h_t = \text{Enc}(x_1,\dots,x_m)_t,\qquad s_t = \text{Dec}(s_{t-1}, y_{t-1}, c)$$
$$P(y_t \mid y_{<t}, x) = \text{softmax}(W s_t)$$

**信息瓶颈**：整个源句被压成一个向量 $c$，长句信息丢失严重。

**Teacher forcing**：训练时把**真实**的上一词喂给解码器，收敛快；但推理时用**自己生成**的上一词，造成**曝光偏差（exposure bias）**——训练与推理分布不一致。对策：scheduled sampling、强化学习微调（§22.6）。

**解码策略**：

| 策略 | 说明 | 特点 |
| --- | --- | --- |
| 贪心 | 每步取最大概率 | 快，易陷入次优 |
| 束搜索（beam search） | 保留 $k$ 个候选 | 质量好，成本 $k$ 倍 |
| 采样（top-k / top-p） | 按概率采样 | 多样，适合开放生成 |
| 对比解码 | 比较模型与弱模型 | 减少重复与退化 |

**长度归一化**：束搜索对短句有偏好，需除以长度惩罚 $|y|^\alpha$（$\alpha \approx 0.6$）。

## 24.4 注意力

**注意力**让解码器每步"看"源序列的不同位置，从而绕过信息瓶颈。

**缩放点积注意力**：

$$\text{Attention}(Q,K,V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

- $Q$（查询）、$K$（键）、$V$（值）分别是线性变换后的矩阵；
- 除以 $\sqrt{d_k}$ 防止点积随维度增大而进入 softmax 饱和区（梯度过小）。

**多头注意力**：并行做 $h$ 组注意力，拼接后再投影：

$$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1,\dots,\text{head}_h)W^O$$

不同头可关注不同关系（句法、指代、位置），是 Transformer 表达力的重要来源。

**注意力作为"软对齐"**：注意力权重可可视化，常被当作可解释性证据——但要注意**注意力 ≠ 解释**（权重高不代表因果重要）。

**自注意力**：$Q,K,V$ 都来自同一序列，每个位置直接与所有位置交互，路径长度 $O(1)$（RNN 是 $O(n)$），这是长程依赖建模的关键优势。

## 24.5 Transformer

**Transformer 块**（编码器层）：

```
x → LayerNorm → 多头自注意力 → 残差相加
  → LayerNorm → 前馈网络（FFN）→ 残差相加
```

**解码器层**多一个**交叉注意力**（Q 来自解码器，K/V 来自编码器）与**因果掩码**（防止看到未来）。

**位置编码**：自注意力本身**无序**（置换等变），必须注入位置信息。

| 方式 | 说明 |
| --- | --- |
| 正弦位置编码 | 固定函数，可外推到更长序列（有限） |
| 可学习位置嵌入 | 简单，但受最大长度限制 |
| 相对位置（RoPE、ALiBi） | 编码相对距离，长度外推更好，现代 LLM 主流 |

**复杂度**：

| 操作 | 时间 | 空间 |
| --- | --- | --- |
| 自注意力 | $O(n^2 d)$ | $O(n^2)$ |
| FFN | $O(n d^2)$ | $O(nd)$ |

**长序列的改进**：

| 方向 | 代表 |
| --- | --- |
| 稀疏/局部注意力 | Longformer、BigBird |
| 线性注意力 | Performer、Linformer |
| 状态空间模型 | S4、Mamba（$O(n)$ 且可并行） |
| 分块 + 记忆 | Transformer-XL、Memorizing Transformers |
| KV 缓存压缩 | MQA、GQA、量化 KV |

**为什么 Transformer 能取代 RNN**：训练可并行（GPU 友好）、路径短（长程依赖好）、可扩展（堆层 + 加宽即提升）。代价是推理时 KV 缓存占用大、长上下文成本高。

**训练稳定性技巧**：Pre-LN（比 Post-LN 稳）、warmup、梯度裁剪、混合精度、QK-norm。

## 24.6 预训练语言模型

**核心思想**：先用海量无标注文本做**自监督预训练**，再用少量标注数据**微调**或**提示**。

**三大范式**：

| 模型 | 结构 | 预训练目标 | 擅长 |
| --- | --- | --- | --- |
| BERT | 编码器 | 掩码语言模型（MLM）+ 下一句预测 | 理解类任务（分类、抽取、检索） |
| GPT | 解码器 | 自回归下一词预测 | 生成类任务（写作、对话、代码） |
| T5 | 编码器-解码器 | span 去噪（text-to-text） | 统一为"文本到文本" |

**MLM 的细节**：随机遮 15% 的 token，其中 80% 换 `[MASK]`、10% 换随机词、10% 不变——缓解预训练与微调的 `[MASK]` 不一致。

**规模法则（scaling laws）**：损失随参数量 $N$、数据量 $D$、算力 $C$ 呈幂律下降：

$$L(N, D) \approx \Big(\frac{N_c}{N}\Big)^{\alpha_N} + \Big(\frac{D_c}{D}\Big)^{\alpha_D} + L_\infty$$

它指导"同等算力下应该加参数还是加数据"（Chinchilla 结论：参数与数据应同比扩展，约 20 tokens/参数）。

**涌现能力（emergent abilities）**：某些能力（多步推理、指令遵循）在小模型上接近随机，规模超过阈值后突然出现。这一现象仍有争议（可能部分是度量伪影），但对"越大越好"的工程判断影响巨大。

**参数高效微调（PEFT）**：

| 方法 | 做法 | 可训练参数 |
| --- | --- | --- |
| Adapter | 插入小模块 | 1–5% |
| Prefix/Prompt tuning | 学虚拟 token | <1% |
| **LoRA** | 低秩分解 $\Delta W = BA$ | 0.1–1% |
| QLoRA | LoRA + 4bit 量化基座 | 更低显存 |

LoRA 的形式：

$$W' = W + \frac{\alpha}{r}BA,\qquad B \in \mathbb{R}^{d\times r},\ A \in \mathbb{R}^{r\times k},\ r \ll \min(d,k)$$

**对齐（alignment）**：

1. **SFT**：指令-回答数据监督微调；
2. **奖励建模**：人类偏好比较训练 $r_\phi$；
3. **RL 优化**：PPO 最大化奖励，KL 约束防止偏离；
4. **DPO**：直接在偏好对上优化，无需奖励模型与 RL 循环。

**提示与上下文学习**：

- **零样本/少样本**：把任务描述与示例放进上下文；
- **思维链（CoT）**：让模型先写推理步骤再给答案；
- **自一致性**：多次采样投票；
- **ReAct**：交替"思考—行动—观察"，配合工具调用。

**局限**：

| 问题 | 表现 | 缓解 |
| --- | --- | --- |
| 幻觉 | 编造事实与引用 | RAG、工具校验、约束解码 |
| 上下文长度 | 长文性能下降（"迷失在中间"） | 检索、分段、重排 |
| 推理深度 | 多步数学/逻辑易错 | CoT、验证器、代码执行 |
| 训练数据截止 | 不知新事实 | RAG、增量更新 |
| 成本 | 推理贵、延迟高 | 蒸馏、量化、小模型路由 |

## 24.7 大语言模型的典型任务

**（1）摘要**。抽取式（选原句）与生成式（重写）。评估用 ROUGE（n-gram 重叠）与 BERTScore，但**事实一致性**才是关键——常用 NLI 模型做蕴含检验，或用"问答式"评估（生成的问题能否从原文回答）。

**（2）问答与检索增强生成（RAG）**。流程：

```
问题 → 检索（稠密/稀疏/混合）→ 重排 → 上下文拼接 → 生成 → 引用与校验
```

RAG 的价值：把"记忆事实"变成"检索事实"，降低幻觉、支持更新、可溯源。工程要点：

| 环节 | 关键决策 |
| --- | --- |
| 切分（chunking） | 按语义/标题切，重叠窗口 |
| 嵌入模型 | 领域适配、多语言、维度与成本 |
| 索引 | 向量库（HNSW/IVF）+ 关键词（BM25）混合 |
| 重排 | cross-encoder 精排，控制上下文预算 |
| 生成 | 引用标注、拒答策略、冲突处理 |

**（3）对话系统**。从规则/检索式到端到端生成：

- **任务型**：意图识别 + 槽位填充 + 对话状态跟踪（§14 的滤波）+ 策略（§17 的 MDP）；
- **开放域**：大模型直接生成，靠系统提示、人格设定与安全过滤；
- **多轮一致性**：需要记忆管理（摘要、向量记忆、结构化状态）。

**（4）代码与工具使用**。代码生成、补全、修复、测试生成；**函数调用（function calling）** 让模型输出结构化参数，由外部执行器完成实际动作。这是"Agent"的基础：规划 → 调用工具 → 观察 → 再规划。

**（5）Agent 与大模型协作**（详见附录 E.7）：

| 能力 | 技术 |
| --- | --- |
| 规划 | ReAct、Plan-and-Execute、树搜索 |
| 记忆 | 短期上下文 + 长期向量库 + 结构化状态 |
| 工具 | API 调用、代码执行、浏览器、数据库 |
| 协作 | 多智能体角色分工（第 18 章） |
| 可靠性 | 验证器、单元测试、人工审核、回滚 |

**（6）评估的困难**：

- **基准污染**：测试集进入训练数据；
- **指标饱和**：选择题分数高不代表真实能力；
- **主观性**：写作、对话质量难自动评估；
- **长尾**：平均分掩盖特定群体的失败。

实践建议：建立**领域内私有评测集**，结合自动指标、模型裁判（LLM-as-judge，需校准）与人工抽检。

## 本章小结

**核心要点**

1. **词嵌入**用分布假说把符号变向量；子词（BPE/WordPiece）解决未登录词，是 LLM 的默认分词。
2. RNN 适合序列标注，但串行、长程依赖弱；BiLSTM-CRF 曾是 NER 标准。
3. **Seq2Seq + 注意力**解决了编码器-解码器的信息瓶颈；teacher forcing 带来曝光偏差。
4. **Transformer** = 多头自注意力 + FFN + 残差 + LayerNorm + 位置编码；复杂度 $O(n^2)$，长序列靠稀疏/线性/状态空间模型改进。
5. 预训练三范式：**BERT（掩码）、GPT（自回归）、T5（text-to-text）**；规模法则指导参数与数据的配比。
6. **LoRA/QLoRA** 降低微调成本；**RLHF/DPO** 做偏好对齐；**RAG** 把事实外置以降低幻觉。
7. 大模型的典型任务是摘要、问答/检索、对话、代码与工具调用；评估需私有集 + 多重手段。
