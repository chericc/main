# 第 22 章 强化学习（Reinforcement Learning）

**本章导读**：监督学习告诉你"正确答案是什么"，强化学习只告诉你"刚才得了多少分"。智能体必须在**延迟奖励**、**试错**与**不确定环境**中自己发现好策略。本章依次讨论：RL 的问题结构（22.1）、只评估策略的被动学习（22.2）、边学边改进的主动学习（22.3）、用函数近似扩展到大规模状态（22.4）、直接优化策略（22.5）、从人类示范中学习（22.6）与应用边界（22.7）。

**学习目标**：完成本章学习后，你应当能够：

- 说明 RL 与监督学习的差别，识别延迟奖励与信用分配问题；
- 推导 TD(0) 更新并比较它与蒙特卡洛、动态规划的偏差-方差；
- 写出 Q-learning 与 SARSA 的更新式，区分 on-policy 与 off-policy；
- 用函数近似扩展 Q-learning，说明"致命三角"的成因；
- 推导策略梯度定理，比较 REINFORCE、Actor-Critic、PPO 的方差与稳定性；
- 描述行为克隆、DAgger、逆强化学习与 RLHF 的流程与失败模式；
- 判断一个实际任务是否适合用 RL，并说明样本效率、仿真差距与安全约束的应对。

**预备知识**：第 17 章的 MDP、值函数与 Bellman 方程；第 19–21 章的回归、梯度与神经网络；概率期望。

## 22.1 从奖励中学习

**RL 的问题设定**：智能体与环境交互，在状态 $s_t$ 执行动作 $a_t$，得到奖励 $r_{t+1}$ 与新状态 $s_{t+1}$，目标是最大化期望折扣回报。

**与监督学习的四个差别**：

| 维度 | 监督学习 | 强化学习 |
| --- | --- | --- |
| 反馈 | 每步有正确标签 | 只有标量奖励，可能延迟 |
| 数据 | 独立同分布 | 由策略产生，**分布随策略变化** |
| 探索 | 无 | 必须主动试错 |
| 评价 | 单步误差 | 长期回报（信用分配） |

**信用分配（credit assignment）**：一步好棋可能在 50 步后才带来胜利，哪一步该得功劳？这是 RL 的核心难题，TD 与策略梯度都在解决它。

**探索-利用**（第 17.3 节的 bandit 是它的最简形式）：

- **利用**：按当前估计选最优动作；
- **探索**：尝试其他动作以改进估计。

**RL 算法谱系**：

| 维度 | 取值 |
| --- | --- |
| 有无模型 | model-free / model-based |
| 学什么 | 值函数 / 策略 / 两者（Actor-Critic） |
| 数据来源 | on-policy（当前策略）/ off-policy（可复用旧数据） |
| 更新时机 | 每步（TD）/ 每幕（MC）/ 批量 |
| 动作空间 | 离散（Q-learning）/ 连续（策略梯度） |

## 22.2 被动强化学习

**被动学习**：策略 $\pi$ 固定，只估计 $V^\pi$（或 $Q^\pi$），不改进策略。它是理解 RL 的"脚手架"。

**（1）直接效用估计（direct utility estimation）**：每幕结束后，把该幕的回报作为对应状态的样本，做回归。问题是**方差大**（回报包含大量随机性），且未利用状态之间的关联。

**（2）自适应动态规划（ADP）**：先从经验估计转移模型 $T$ 与奖励 $R$，再用第 17 章的值迭代求解。样本效率高，但"模型误差会传播"。

**（3）时序差分（TD）**：用**自举（bootstrapping）** 更新：

$$V(s_t) \leftarrow V(s_t) + \alpha\big[\underbrace{r_{t+1} + \gamma V(s_{t+1})}_{\text{TD 目标}} - V(s_t)\big]$$

括号内是 **TD 误差** $\delta_t$。TD 不需要等到幕结束，也不需要模型。

**TD(0) vs 蒙特卡洛**：

| 方法 | 目标 | 偏差 | 方差 | 需终止 |
| --- | --- | --- | --- | --- |
| 蒙特卡洛 | 实际回报 $G_t$ | 无偏 | 高 | 是 |
| TD(0) | $r + \gamma V(s')$ | 有偏（自举） | 低 | 否 |

**TD($\lambda$)**：在两者之间插值，用**资格迹（eligibility trace）** 分配信用：

$$V(s) \leftarrow V(s) + \alpha \delta_t e_t(s)$$

$\lambda = 0$ 退化为 TD(0)，$\lambda = 1$ 接近蒙特卡洛。资格迹使"最近访问的状态"获得更大更新，是信用分配的一种实现。

**批量更新与收敛**：TD(0) 在固定策略下收敛到 $V^\pi$（表格情形，$\alpha$ 满足 Robbins–Monro 条件）。

## 22.3 主动强化学习

主动学习同时改进策略。核心工具是**动作价值** $Q(s,a)$。

**Q-learning（off-policy）**：

$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha\big[r_{t+1} + \gamma \max_{a'} Q(s_{t+1},a') - Q(s_t,a_t)\big]$$

- 更新用的是 $\max$，即"假设之后按最优行动"，因此学的是 $Q^*$，**与行为策略无关**；
- 优点：可复用旧数据、可用贪婪行为；
- 缺点：$\max$ 导致**过高估计偏差**（maximization bias），在噪声大时明显。

**SARSA（on-policy）**：

$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha\big[r_{t+1} + \gamma Q(s_{t+1},a_{t+1}) - Q(s_t,a_t)\big]$$

- 用实际执行的 $a_{t+1}$，因此学的是**当前行为策略**的价值；
- 在"悬崖行走"中，SARSA 学到更保守的安全路径，Q-learning 学到最优但危险的路径——这是 on/off-policy 差异的经典演示。

**探索策略**：

| 策略 | 说明 |
| --- | --- |
| $\varepsilon$-贪心 | 以 $\varepsilon$ 概率随机，简单有效 |
| 衰减 $\varepsilon$ | 后期趋于贪婪 |
| 乐观初始化 | 初始 $Q$ 设高，促使尝试 |
| 玻尔兹曼（softmax） | 按 $Q$ 值概率选择 |
| UCB / Thompson | 有理论保证的探索（§17.3） |
| 内在奖励 | 新奇度、预测误差（curiosity）驱动探索 |

**过高估计的修正**：

- **Double Q-learning**：用两个网络，一个选动作、另一个估值；
- **DQN 的 Double DQN 变体**：在线网络选动作、目标网络估值。

**经验回放（experience replay）**：把 $(s,a,r,s')$ 存入缓冲区，随机采样小批量训练。它打破了样本的时间相关性，提高数据利用率——这是 DQN 成功的关键组件之一。

## 22.4 强化学习中的泛化

表格方法要求状态可枚举，真实问题状态连续或巨大，必须用**函数近似**：$\hat V(s; w)$、$\hat Q(s,a; w)$ 或 $\pi(a\mid s;\theta)$。

**近似方法**：

| 方法 | 说明 |
| --- | --- |
| 线性近似 | $\hat V = w^\top \phi(s)$，特征 $\phi$ 手工或学得 |
| 瓦片编码（tile coding） | 粗粒度网格叠加，适合低维连续 |
| 径向基函数 | 局部响应，平滑 |
| 神经网络 | 通用近似，DQN 的基础 |

**致命三角（deadly triad）**：以下三者同时出现时，价值估计可能**发散**：

1. 函数近似（无法精确表示）；
2. 自举（TD 目标依赖当前估计）；
3. off-policy 训练（数据分布与目标策略不一致）。

对策：目标网络（冻结目标）、经验回放、梯度裁剪、小学习率、Double DQN、或改用 on-policy 方法。

**DQN（Deep Q-Network）** 的五个关键设计：

| 组件 | 作用 |
| --- | --- |
| 卷积/全连接网络 | 从像素直接估 $Q$ |
| 经验回放 | 打破相关性、提高样本效率 |
| 目标网络 | 稳定 TD 目标（定期同步） |
| 奖励裁剪 | 稳定不同游戏的尺度 |
| $\varepsilon$ 衰减 + 跳帧 | 探索与计算效率 |

**DQN 的改进谱**：Double DQN（去过高估计）、Dueling DQN（拆分 $V$ 与优势 $A$）、Prioritized Replay（按 TD 误差采样）、Rainbow（组合以上 + 分布式 + 噪声网络）。

**泛化问题**：神经网络在"见过的状态"附近泛化，但 RL 的数据分布随策略变化，容易出现**灾难性遗忘**与**过拟合到局部区域**。对策：更大回放池、正则化、分布式训练、表征学习（辅助任务）。

**基于模型的方法**：学 $T$ 与 $R$，在其上规划（第 11 章）或生成想象数据（Dyna、MBPO、Dreamer）。优点是**样本效率高**；缺点是模型误差在长视野上累积。

## 22.5 策略搜索

当动作连续、或策略需要随机性时，直接参数化策略 $\pi_\theta(a \mid s)$ 并优化期望回报：

$$J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta}\Big[\sum_t \gamma^t r_t\Big]$$

**策略梯度定理**：

$$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\Big[\sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t)\, \hat A_t\Big]$$

其中 $\hat A_t$ 是**优势**（相对基线的超额回报）。**基线**（如 $V(s)$）不改变期望但大幅降低方差。

**REINFORCE**：用蒙特卡洛回报作为 $\hat A_t$。无偏但方差大，样本效率低。

**Actor-Critic**：Actor 更新策略，Critic 估计 $V$ 或 $Q$ 作为基线：

$$\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t),\qquad \theta \leftarrow \theta + \alpha_\theta \delta_t \nabla_\theta \log \pi_\theta(a_t\mid s_t)$$

- **A2C/A3C**：并行环境去相关（同步/异步）；
- **GAE**：用 $\lambda$ 加权的优势估计，在偏差与方差间插值。

**信赖域方法**：

| 方法 | 核心 |
| --- | --- |
| TRPO | 约束策略更新的 KL 散度，保证单调改进 |
| **PPO** | 用裁剪替代约束，实现简单、稳定，工业界默认 |
| SAC | 最大熵 RL，自动温度调节，连续控制强 |
| DDPG/TD3 | 确定性策略梯度 + 双 Critic，连续控制经典 |

**PPO 的裁剪目标**：

$$L^\text{CLIP}(\theta) = \mathbb{E}\Big[\min\big(\rho_t \hat A_t,\ \mathrm{clip}(\rho_t, 1-\epsilon, 1+\epsilon)\hat A_t\big)\Big],\quad \rho_t = \frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_\text{old}}(a_t|s_t)}$$

**最大熵 RL**：在回报之外鼓励策略熵，提升探索与鲁棒性；SAC 的目标为

$$J = \mathbb{E}\Big[\sum_t \gamma^t\big(r_t + \alpha \mathcal{H}(\pi(\cdot|s_t))\big)\Big]$$

**策略搜索的实践要点**：

- 优势估计的**偏差-方差**调节（GAE 的 $\lambda$）；
- **奖励缩放**与**观测归一化**对稳定性影响巨大；
- 并行环境数决定吞吐，batch 大小影响梯度质量；
- 策略梯度对超参数敏感，需多次随机种子评估。

## 22.6 学徒学习与逆强化学习

**问题**：很多任务难以写出奖励函数（"像人一样开车"），但容易获得**示范**。

**（1）行为克隆（behavior cloning, BC）**：把示范当作监督学习，学 $\pi(a\mid s)$。

- 优点：简单、无需交互；
- 缺点：**分布偏移**——错误动作把智能体带到示范未覆盖的状态，误差累积（**复合误差**，$O(T^2)$）。

**（2）DAgger（dataset aggregation）**：迭代地让专家标注"学生当前访问到的状态"，把新数据加入训练集。它把复合误差降到 $O(T)$，但需要专家在线参与。

**（3）逆强化学习（IRL）**：从示范反推奖励，再用 RL 求最优策略。

- **最大熵 IRL**：在所有能解释示范的奖励中，选熵最大的（假设专家近似最优但有噪声）；
- **MaxEnt 的求解**：奖励参数用梯度更新，使"专家特征期望"与"策略特征期望"匹配；
- **GAIL**：用对抗方式匹配占用度量（occupancy measure），不需显式恢复奖励。

**（4）从人类反馈中学习（RLHF）**：当代大模型对齐的标准流程（§24.6）：

1. **监督微调（SFT）**：用示范数据训练初始策略；
2. **奖励建模**：用人类对回答的**成对比较**训练奖励模型 $r_\phi$；
3. **RL 优化**：用 PPO 最大化 $r_\phi$，同时用 KL 惩罚约束"不要偏离 SFT 太远"。

**DPO（直接偏好优化）** 跳过显式奖励模型，直接在偏好数据上优化策略，等价于带 KL 约束的 RLHF 目标的闭式重构，训练更稳定。

**失败模式**：

| 模式 | 表现 | 对策 |
| --- | --- | --- |
| 奖励黑客（reward hacking） | 策略钻奖励模型空子 | KL 约束、集成奖励、人工审核 |
| 分布偏移 | 上线后遇到新状态 | 在线数据、DAgger、鲁棒训练 |
| 偏好不一致 | 标注者互相矛盾 | 多人标注、置信度加权 |
| 过度优化 | 奖励上升但人类评价下降（Goodhart） | 早停、奖励模型集成、定期重训 |

## 22.7 强化学习应用

| 领域 | 代表成果 | 关键挑战 |
| --- | --- | --- |
| 游戏 | Atari（DQN）、AlphaGo/AlphaZero、星际争霸（AlphaStar）、Dota（OpenAI Five） | 长视野、巨大动作空间、自我对弈 |
| 机器人 | 抓取、行走、灵巧操作、无人机 | 仿真到现实（sim-to-real）、安全 |
| 大模型对齐 | RLHF、DPO、推理模型（RLVR） | 奖励设计、可扩展监督 |
| 推荐与广告 | 长期用户价值优化 | 反事实评估、探索成本 |
| 芯片与系统 | 芯片布局（AlphaChip）、数据中心制冷 | 组合优化、约束满足 |
| 交通与能源 | 信号控制、电网调度、自动驾驶 | 安全约束、多智能体 |
| 科学 | 分子设计、可控核聚变（等离子体控制） | 昂贵仿真、奖励稀疏 |

**决定是否使用 RL 的判据**：

1. **是否有可交互的环境**（真实或仿真）？
2. **奖励是否可定义且不易被钻空子**？
3. **试错代价是否可接受**（安全、成本）？
4. **是否有示范数据**（可用模仿学习降难度）？
5. **是否真的需要序贯决策**（很多问题其实是 bandit 或监督学习）？

**三大现实挑战**：

| 挑战 | 说明 | 应对 |
| --- | --- | --- |
| 样本效率 | 真实环境交互昂贵 | 基于模型、离线 RL、模仿、迁移 |
| 仿真差距 | 仿真中学到的策略在现实中失效 | 域随机化、系统辨识、在线微调 |
| 安全与可靠性 | 探索可能造成不可逆损害 | 约束 MDP、安全层（shield）、人工监督 |

**离线 RL（offline RL）** 值得单独一提：只能使用固定数据集、不能交互，核心问题是**分布外动作的过高估计**。方法包括保守 Q 学习（CQL）、隐式 Q 学习（IQL）、决策 Transformer——它把 RL 变成"序列建模"，与第 24 章的大模型路线相通。

## 本章小结

**核心要点**

1. RL 与监督学习的关键差别是**延迟奖励、数据分布随策略变化、必须探索**；信用分配是核心难题。
2. **TD(0)** 用自举换取低方差；TD($\lambda$) 用资格迹在偏差与方差间插值。
3. **Q-learning 是 off-policy、SARSA 是 on-policy**；前者激进、后者保守，$Q$-learning 有最大化偏差。
4. 函数近似 + 自举 + off-policy 构成**致命三角**；目标网络、回放、Double DQN 是主要对策。
5. **策略梯度**用优势加权；REINFORCE 方差大，Actor-Critic 用基线降方差，PPO 用裁剪换稳定。
6. 示范学习有三条路线：BC（简单但复合误差）、DAgger（在线纠偏）、IRL/GAIL（反推奖励）；**RLHF/DPO** 是大模型对齐的主流。
7. RL 的落地瓶颈是**样本效率、仿真差距与安全**；离线 RL 与模仿学习是降低成本的两条主路。
