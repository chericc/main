# 第 7 章 逻辑智能体（Logical Agents）

**本章导读**：前面几章的智能体只会"搜索"或"反射"，它们无法把"世界的规律"写成知识并加以推理。逻辑提供了一套精确的语言与推理规则：用命题描述世界，用蕴含推出新结论，用可满足性检验一致性。本章以瓦普斯世界（Wumpus World）为试验台，介绍基于知识的智能体、命题逻辑的语法与语义、等价变换、归结证明与高效的模型检验（DPLL、CDCL、WalkSAT），最后把智能体控制回路与逻辑推导接上。

**学习目标**：完成本章学习后，你应当能够：

- 画出基于知识智能体的 TELL/ASK 回路，解释蕴含、可靠性与完备性；
- 在瓦普斯世界中写出命题化的知识库并推导安全动作；
- 熟练使用命题逻辑的等价律把公式化为 CNF；
- 用归结反演证明命题公式，并说明其完备性来源；
- 描述 DPLL 的单位传播与纯符号规则，说明 CDCL 的冲突学习；
- 解释"规划即 SAT"的编码思路与命题逻辑表达力的边界。

**预备知识**：布尔代数、集合与模型的概念；第 2 章的智能体结构；第 3 章的搜索（用于模型检验）。

---

## 7.1 基于知识的智能体

**知识库（knowledge base, KB）** 是一组用形式语言写成的句子。基于知识的智能体有两个接口：

- `TELL(KB, sentence)`：把新知识写入知识库；
- `ASK(KB, query)`：询问知识库能否推出某结论。

其控制回路是：

```
感知 → TELL(KB, 感知转换成的句子)
     → ASK(KB, 应执行什么动作)
     → TELL(KB, 已执行动作)
     → 执行动作
```

**语义与蕴含**。句子的真假依赖于**模型（model）**——对世界的一种完整解释。$KB \models \alpha$（$KB$ 蕴含 $\alpha$）定义为：

> 在**所有**使 $KB$ 为真的模型中，$\alpha$ 也为真。

这与"从 $KB$ 能推导出 $\alpha$"（$KB \vdash \alpha$）是两件事，后者依赖推理算法。二者由两条性质连接：

- **可靠性（soundness）**：$KB \vdash \alpha \Rightarrow KB \models \alpha$（推出的都是对的）；
- **完备性（completeness）**：$KB \models \alpha \Rightarrow KB \vdash \alpha$（对的都能推出）。

**可满足性（satisfiability）**：存在模型使句子为真。SAT 与蕴含的关系是逻辑推理的核心技巧：

$$KB \models \alpha \iff KB \land \neg\alpha \text{ 不可满足}$$

即**反证法**：要证明 $\alpha$，就证明"$KB$ 且非 $\alpha$"矛盾。几乎所有实用定理证明器都走这条路。

## 7.2 瓦普斯世界

瓦普斯世界是一个 $4\times4$ 的洞穴网格，智能体从 $(1,1)$ 出发，需找到金子并爬出，同时避开瓦普斯（Wumpus）与陷阱（pit）。

**PEAS 描述**：

| 要素 | 内容 |
| --- | --- |
| 性能 | 拿到金 $+1000$，死亡 $-1000$，每步 $-1$，用箭 $-10$ |
| 环境 | $4\times4$ 网格，1 个瓦普斯、若干陷阱、1 块金，局部感知 |
| 执行器 | 前进、左转、右转、射箭、抓取、爬出 |
| 传感器 | 臭气（瓦普斯相邻）、微风（陷阱相邻）、闪光（金）、撞击（撞墙）、尖叫（射中） |

**逻辑化的建模要点**：

1. **原子命题**：$P_{i,j}$（该格有陷阱）、$W_{i,j}$（有瓦普斯）、$B_{i,j}$（感知到微风）、$S_{i,j}$（感知到臭气）、$G_{i,j}$（有金）。
2. **感知公理**：$B_{i,j} \leftrightarrow (P_{i+1,j} \lor P_{i-1,j} \lor P_{i,j+1} \lor P_{i,j-1})$，即"微风当且仅当相邻有陷阱"。
3. **世界公理**：$B_{1,1}$ 为假（起点无风），$\neg P_{1,1}$。
4. **推导**：从 $B_{1,1} \leftrightarrow (P_{1,2} \lor P_{2,1})$ 与 $\neg B_{1,1}$ 可推出 $\neg P_{1,2} \land \neg P_{2,1}$，从而确定 $(1,2)$、$(2,1)$ 安全。

**这个世界的教学价值**：

- 感知只覆盖相邻格 → 需要**推理**补全未知；
- 知识随探索**单调增长**（只 TELL 不遗忘）；
- 存在"知识不完备"的格：不能证明安全，也不能证明危险 → 理性智能体需要在风险与收益间权衡（第 16 章效用）。

## 7.3 逻辑

**逻辑系统**由语法（句子如何构成）、语义（句子在模型中的真值）、推理规则（如何产生新句子）三部分组成。

**关键语义概念**：

| 概念 | 定义 |
| --- | --- |
| 有效性（validity） | 在所有模型中为真，如 $P \lor \neg P$ |
| 可满足（satisfiability） | 至少一个模型为真 |
| 不可满足（unsatisfiable） | 没有任何模型，如 $P \land \neg P$ |
| 等价（equivalence） | $\alpha \equiv \beta$ 当且仅当二者在所有模型中同真 |

**两条元定理**：

- **演绎定理**：$KB \models \alpha \iff (KB \Rightarrow \alpha)$ 是有效式；
- **单调性**：若 $KB \models \alpha$，则 $KB \land \beta \models \alpha$——加知识不会推翻旧结论。这一点在"缺省推理"中会被打破（§10.6），是经典逻辑的局限之一。

**推理方法的三大类**：

1. **模型检验**：枚举所有模型，检查蕴含。可靠且完备，但指数级。
2. **定理证明**：应用推理规则逐步推导。可高效（如归结 + 启发式），也可不完备（如只允许某些规则）。
3. **可满足性求解**：转为 SAT 交给工业级求解器，是现代主流（§7.6）。

## 7.4 命题逻辑：一种非常简单的逻辑

**语法**：

$$\text{Sentence} \to \text{Atom} \mid \neg\text{Sentence} \mid (\text{Sentence} \land \text{Sentence}) \mid (\text{Sentence} \lor \text{Sentence}) \mid (\text{Sentence} \Rightarrow \text{Sentence}) \mid (\text{Sentence} \Leftrightarrow \text{Sentence})$$

原子是布尔变量（真/假）。**语义**由真值表给出，例如：

| $P$ | $Q$ | $P \land Q$ | $P \lor Q$ | $P \Rightarrow Q$ | $P \Leftrightarrow Q$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| T | T | T | T | T | T |
| T | F | F | T | **F** | F |
| F | T | F | T | T | F |
| F | F | F | F | T | T |

注意**实质蕴含**（material implication）的非直觉之处：$P \Rightarrow Q$ 在 $P$ 为假时恒真（"前件假，条件句为真"）。这与日常语言的条件句不同，但在逻辑推理中必须如此，否则蕴含的语义无法一致。

**常用等价律**（应熟记到能条件反射）：

| 名称 | 形式 |
| --- | --- |
| 交换/结合 | $(\alpha \land \beta) \equiv (\beta \land \alpha)$ 等 |
| 双重否定 | $\neg\neg\alpha \equiv \alpha$ |
| 蕴含消除 | $\alpha \Rightarrow \beta \equiv \neg\alpha \lor \beta$ |
| 逆否 | $\alpha \Rightarrow \beta \equiv \neg\beta \Rightarrow \neg\alpha$ |
| 德摩根 | $\neg(\alpha \land \beta) \equiv \neg\alpha \lor \neg\beta$ |
| 分配 | $\alpha \land (\beta \lor \gamma) \equiv (\alpha \land \beta) \lor (\alpha \land \gamma)$ |
| 吸收 | $\alpha \land (\alpha \lor \beta) \equiv \alpha$ |

**CNF 与 DNF**：

- **合取范式（CNF）**：子句的合取，每个子句是文字的析取，如 $(P \lor \neg Q) \land (R \lor S)$；
- **析取范式（DNF）**：合取项的析取。

**任何命题公式都能化为 CNF**，标准流程：消蕴含 → 内移否定（德摩根）→ 分配律展开。最坏情况下 CNF 会指数膨胀，实用上用 Tseitin 变换（引入辅助变量）保持线性规模，代价是多出变量——这正是 SAT 编码的常用手法。

## 7.5 命题定理证明

**推理规则**（可靠，但不完备的组合）：

$$\frac{\alpha \Rightarrow \beta,\ \alpha}{\beta}\ \text{(Modus Ponens)} \qquad \frac{\alpha \land \beta}{\alpha}\ \text{(And-Elimination)} \qquad \frac{\alpha}{\alpha \lor \beta}\ \text{(Or-Introduction)}$$

**归结（resolution）** 是单一而完备的规则。它作用于**子句**：

$$\frac{\ell_1 \lor \cdots \lor \ell_k,\quad m_1 \lor \cdots \lor m_n}{\ell_1 \lor \cdots \lor \ell_{i-1} \lor \ell_{i+1} \cdots \lor \ell_k \lor m_1 \cdots \lor m_{j-1} \lor m_{j+1} \cdots \lor m_n}$$

其中 $\ell_i$ 与 $m_j$ 是互补文字（如 $P$ 与 $\neg P$）。

**归结反演**（refutation）证明 $KB \models \alpha$ 的步骤：

1. 把 $KB$ 与 $\neg\alpha$ 都化为 CNF，得到子句集；
2. 反复对互补子句做归结，把新子句加入集合；
3. 若推出**空子句** $\square$，则矛盾，原命题得证。

**完备性**：归结反演是**反驳完备**的——若子句集不可满足，一定能在有限步内推出空子句（归结的完备性定理，Robinson 1965）。

**Horn 子句与高效推理**。Horn 子句是**至多一个正文字**的子句，例如 $\neg P \lor \neg Q \lor R$，等价写作 $P \land Q \Rightarrow R$。它的两个性质使其极高效：

- **判定**：Horn 子句集的满足性可在线性时间判定；
- **前向链接**（数据驱动）与**后向链接**（目标驱动）都是线性时间，且不需回溯。

这就是**逻辑程序设计**（Prolog）与**专家系统**（产生式系统）的理论基础。第 9 章会把 Horn 子句推广到一阶逻辑的 Datalog。

**归结的局限**：搜索空间随子句数爆炸，需要**子句选择策略**（单元优先、最短子句优先）、**子句删除**（包含删除、纯文字删除）与**子句学习**。

## 7.6 有效的命题模型检验

现代 SAT 求解器能在数百万变量的工业实例上工作，其核心是三种技术。

**（1）DPLL 算法**。Davis–Putnam–Logemann–Loveland 在回溯搜索上加了三条规则：

- **单元传播（unit propagation）**：若某子句只剩一个未赋值文字，则该文字必须为真；
- **纯符号（pure symbol）**：只以同一符号出现的文字，可直接赋使其为真的值；
- **分裂（splitting）**：选一个变量尝试真/假两支。

```
function DPLL(clauses, symbols, model):
    if 所有子句在 model 下为真: return true
    if 存在子句为假: return false
    P, value ← FIND-UNIT-CLAUSE(clauses, model)   # 或纯符号
    if 找到: return DPLL(clauses, symbols, model ∪ {P=value})
    P ← 选择一个未赋值符号
    return DPLL(clauses, symbols\{P}, model∪{P=true}) or
           DPLL(clauses, symbols\{P}, model∪{P=false})
```

**（2）CDCL（冲突驱动子句学习）**。DPLL 的现代增强：

- **冲突分析**：从冲突子句反向推导出导致冲突的变量组合，生成**学习子句**（一定为真）；
- **非时序回跳（backjumping）**：直接跳回冲突的责任层，跳过无关决策；
- **重启策略**：周期性回到根节点但保留学习子句；
- **VSIDS 启发式**：优先选择近期参与冲突最多的变量。

CDCL 是把 SAT 从"理论完备"变成"工程可用"的关键。

**（3）局部搜索（WalkSAT）**。不保证完备，但在随机 SAT 实例上极快：

```
随机赋值
loop:
    若满足则返回
    随机选一个未满足子句 c
    以概率 p 随机翻转 c 中一个变量
    否则翻转使冲突数最少（break-count 最小）的变量
```

**复杂度**：命题 SAT 是 **NP 完全**的（Cook–Levin）。这意味着：

- 不存在已知的多项式算法；
- 但工业实例的**结构**常使求解器表现良好；
- 3-SAT 在子句/变量比约 $4.26$ 处出现**相变**，最难求解（约束密度临界点），这与第 6 章 CSP 的"难解区"是同一现象。

**其他有效方法**：二元决策图（BDD）、#SAT 计数、MaxSAT（软约束最优化）、SMT（把命题逻辑扩展到整数/实数与函数符号，见 §11.6）。

## 7.7 基于命题逻辑的智能体

把逻辑回路装进智能体，有三条实现路线。

**（1）状态估计**。智能体维护"可能世界"的集合（信念状态）：

- 初始时，所有与初始感知一致的命题赋值构成信念状态；
- 执行动作后，按动作的转移公理更新；
- 收到感知后，过滤掉与之矛盾的赋值。

当可能世界数过多时，改用**CNF 编码 + SAT 查询**：要判断"某格是否必然有陷阱"，就询问 $KB \models P_{ij}$ 与 $KB \models \neg P_{ij}$ 哪个成立。

**（2）电路型智能体（circuit-based agent）**。直接用组合逻辑电路表示"感知 → 动作"的映射，用**模型检验**验证其满足安全性质（如"永不进入有瓦普斯的格"）。这是硬件验证与安全强化学习中的标准做法。

**（3）规划即 SAT（planning as SAT）**。把长度为 $T$ 的计划编码成命题公式：

- 变量 $A_{t,a}$：第 $t$ 步执行动作 $a$；
- 变量 $S_{t,f}$：第 $t$ 步事实 $f$ 为真；
- **初始状态公理**、**后继状态公理**（$S_{t+1,f} \leftrightarrow \text{原因}$）、**动作前提公理**、**互斥公理**（一步只能一个动作）、**目标公理**。

交给 SAT 求解器，可满足即得到一个计划。优点是复用高度优化的求解器与增量求解；缺点是需要预先固定**步数**（可用迭代加深）与编码规模较大。

**命题逻辑的边界**：

- 无法简洁表达"所有格都有某个性质"这类**量化**陈述；
- 状态数随对象数指数增长（$n$ 个格需要 $n$ 个命题）；
- 无法表达关系与对象身份。

这些局限正是第 8 章引入一阶逻辑的动机。

## 本章小结

**核心要点**

1. 基于知识的智能体用 `TELL`/`ASK` 维护知识库；推理正确性由**可靠性**与**完备性**衡量。
2. 蕴含是语义概念，可转为**不可满足性**检验——这是所有实用证明器的共同路径。
3. 命题逻辑表达力有限但语义清晰；任何公式可化为 **CNF**，实用中用 Tseitin 变换控制规模。
4. **归结**是单一、反驳完备的规则；**Horn 子句**可线性时间推理，是 Prolog 与专家系统的基础。
5. 现代 SAT 依赖 **DPLL + 单元传播 + CDCL 冲突学习 + 重启 + VSIDS**；SAT 是 NP 完全的，但结构良好的实例可解。
6. 逻辑智能体可实现状态估计、电路验证与**规划即 SAT**；量化与关系的缺失推动一阶逻辑。
