# 第 15 章 概率编程（Probabilistic Programming）

**本章导读**：贝叶斯网络要求"变量数固定、结构手工指定"，真实问题却常涉及数量可变的对象（用户、传感器、事件）。概率编程把**程序**当作概率模型：随机数生成、递归、条件分支与高阶函数都成为建模语言的一部分，推断交给通用引擎。本章按表达力递进：关系概率模型（对象与关系）→ 开放宇宙模型（对象数未知）→ 跟踪复杂世界（时序 + 对象）→ 通用概率程序 → 推断引擎。

**学习目标**：完成本章学习后，你应当能够：

- 说明贝叶斯网络作为建模语言的三个局限；
- 用关系概率模型（plate notation / 逻辑程序）表达"同类对象共享参数"；
- 解释开放宇宙模型的"存在性与身份不确定性"；
- 用概率程序（采样、条件、递归）写出生成式模型；
- 区分前向模拟、MCMC、重要性采样与变分在概率编程中的角色；
- 说明概率编程语言的表达力与推断可扩展性之间的张力。

**预备知识**：第 12–14 章的概率图模型；编程语言基础（函数、递归、闭包）；第 9 章的逻辑程序（可选）。

## 15.1 关系概率模型

**贝叶斯网络的三个局限**：

1. **结构固定**：变量在建模时就必须确定，无法表达"有多少个用户就有多少个变量"；
2. **不能共享**：1000 个用户各有一个"点击率"，需要 1000 组独立参数，无法体现"同类对象参数相同"；
3. **不能表达关系**：用户与商品、论文与引用之间的图结构难以直接编码。

**关系概率模型（relational probabilistic model）** 用**对象 + 关系 + 参数共享**解决。典型语言是 **plate notation（板块记号）**：

- 方框表示"对集合中的每个对象重复"；
- 同一个方框内的参数共享。

例如"每个用户对每个商品有偏好"：

$$u_i \sim \mathcal{N}(0, \sigma_u^2),\quad v_j \sim \mathcal{N}(0, \sigma_v^2),\quad r_{ij} \sim \mathcal{N}(u_i^\top v_j, \sigma^2)$$

这就是矩阵分解（附录 C.1）的概率版本，板块把 $i$ 与 $j$ 的重复显式化。

**逻辑编程版本**（ProbLog 风格）：

```prolog
0.3::edge(a, b).
0.6::edge(b, c).
path(X, Y) :- edge(X, Y).
path(X, Y) :- edge(X, Z), path(Z, Y).
```

查询 `path(a, c)` 的概率由所有支持它的世界加权求和。这类语言把**逻辑规则**与**概率事实**结合，得到"每个可能世界是一组事实选择"的语义。

**参数共享的三种形态**：

| 形态 | 说明 | 例子 |
| --- | --- | --- |
| 完全共享 | 所有对象同一参数 | 全局点击率 |
| 分组共享 | 按类别共享 | 按品类的转化率 |
| 分层共享 | 组参数来自上层分布 | 分层贝叶斯（§20.1） |

分层共享是关系模型的核心价值：样本少的对象通过组分布"借力"，避免过拟合。

## 15.2 开放宇宙概率模型

**开放宇宙（open-universe）** 模型允许**对象集本身不确定**：可能有 3 个人也可能有 5 个人，可能有 1 个传感器也可能有 10 个。

**两个新问题**：

1. **存在性不确定性（existence uncertainty）**：某对象是否存在；
2. **身份不确定性（identity uncertainty）**：两条记录是否指同一对象（实体消歧 / 数据关联）。

**建模工具**：

- **编号变量（number statement）**：$|Person| \sim \text{Poisson}(\lambda)$，表示人数服从泊松分布；
- **属性分布**：给定人数，每个对象的属性按共享机制生成；
- **引用不确定性**：关系指向"某个对象"而非"特定对象"，如"Alice 的书"可能指多本。

**贝叶斯逻辑（BLOG）** 是开放宇宙模型的代表语言：

```
#Person ~ Poisson[6];
for i = 1 to #Person:
    Gender[i] ~ Bernoulli[0.5];
    Height[i] ~ Gaussian[if Gender[i] then 175 else 162, 8];
```

**身份不确定性**的例子（Citation Matching）：数据库中有两条作者记录 `J. Smith` 与 `John Smith`，它们可能是同一人，也可能是两人。模型需要联合推断"实体集合"与"属性值"，本质是**聚类 + 属性估计**的联合问题。

**开放宇宙的推断难点**：状态空间包含"所有可能的对象集合"，规模是超指数的；常用**MCMC over worlds**（在对象集合空间上跳转）与**关系推断**（lifted inference）技术。

## 15.3 跟踪复杂世界

把时序（第 14 章）与关系/开放宇宙结合，就是"跟踪复杂世界"：对象可能出现、消失、被遮挡、被误检。

**多目标跟踪（multi-target tracking）** 的典型难点：

| 难点 | 表现 | 建模方式 |
| --- | --- | --- |
| 检测不确定 | 漏检、误检 | 观测模型含 $P(\text{detect})$、$P(\text{false alarm})$ |
| 数据关联 | 哪个观测对应哪个目标 | 隐变量表示关联（§15.2 的身份不确定性） |
| 目标数变化 | 进入/离开视野 | 出生-死亡过程（birth-death process） |
| 遮挡 | 长时间无观测 | 状态保持 + 预测扩散 |

**概率编程的表达**：

```python
targets = []
for t in range(T):
    # 新目标出生
    for _ in range(poisson(birth_rate)):
        targets.append(sample(InitialState))
    # 每个目标按运动模型转移
    for tr in targets:
        tr.state = sample(MotionModel(tr.state))
    # 观测关联
    for obs in observations[t]:
        z = sample(Assignment(targets))     # 关联变量
        observe(ObservationModel(targets[z].state), obs)
    # 目标死亡
    targets = [tr for tr in targets if not sample(DeathModel(tr))]
```

这就是**概率编程的价值**：用普通代码的循环、条件与递归表达"数量变化 + 关联不确定性"，而无需手写巨大的图模型。

**与多目标滤波的关系**：经典方法（JPDA、GM-PHD）是"手工推导的近似"；概率编程版本是"通用推断引擎 + 生成式模型"，更易修改但通常更慢。

## 15.4 作为概率模型的程序

**核心思想**：任何带有**随机采样（sample）** 与**条件观测（observe/condition）** 的程序都定义了一个概率分布：

$$P(\text{执行路径}) = \prod_{\text{sample}} P(\text{采样值} \mid \text{此前采样})$$

观测语句相当于对路径加权（似然），条件分支使分布**非参数化**（分支数取决于采样值）。

**表达力的三级跳**：

| 层次 | 能表达 | 例子 |
| --- | --- | --- |
| 图模型 | 固定变量集的条件独立结构 | 贝叶斯网络、HMM |
| 关系模型 | 数量可变的同类对象 | plate、逻辑程序 |
| 通用程序 | 递归、任意控制流、随机阶 | 随机文法、生成式模拟器 |

**经典例子**：

- **随机上下文无关文法**：语法规则带概率，生成句子；
- **生成式图像模型**：场景 → 物体 → 像素；
- **贝叶斯网络编译器**：从领域特定语言生成概率程序；
- **强化学习环境模拟器**：把物理引擎当作生成模型（simulation-based inference）。

**建模要点**：

1. **sample 与 observe 分离**：sample 生成潜变量，observe 施加条件；
2. **可重参数化**：连续变量用 $z = \mu + \sigma\epsilon$ 形式，使梯度可通过（§21.4）；
3. **随机控制流**：`if`、`while`、递归都可依赖采样值，这使模型成为"可执行的世界假说"。

**代价**：程序越通用，推断越难。图模型有专门的高效算法（变量消元、前向-后向），而通用程序只能靠**通用推断引擎**（MCMC、重要性采样、变分），效率通常低几个数量级。

## 15.5 概率程序的推断

通用引擎有四大类。

**（1）前向模拟（forward sampling）**。直接运行程序采样，得到先验样本。它不能利用观测，只能用于检验模型与生成数据。

**（2）重要性采样（importance sampling）**。在采样时按观测加权：

$$P(\text{query} \mid \text{obs}) \approx \sum_i w_i \delta(\text{query} - q_i), \qquad w_i = P(\text{obs} \mid \text{path}_i)$$

问题是：若观测极不可能（罕见事件），几乎所有样本权重近零——**权重退化**。

**（3）MCMC（Metropolis–Hastings / Gibbs / HMC）**。在程序的状态空间（所有采样值）上构造马尔可夫链，使平稳分布正比于"先验 × 似然"。

- **单点更新 MH**：每次只改一个采样值，接受率 $\min(1, \text{likelihood ratio})$；
- **HMC/NUTS**：利用对数密度的梯度，在高维连续空间高效探索，是 Stan/PyMC 的默认；
- **难点**：离散变量与随机控制流使梯度不可用；多模态导致混合慢。

**（4）变分推断（variational inference）**。用可微的 $q_\phi(z)$ 近似后验，最大化 ELBO：

$$\text{ELBO} = \mathbb{E}_{q_\phi}\big[\log P(x, z) - \log q_\phi(z)\big]$$

- **自动微分变分推断（ADVI）**：自动构造 $q_\phi$，适合连续变量；
- **摊销推断（amortized inference）**：用网络从观测直接预测后验参数（VAE 的核心，§21.7）；
- 优点是快、可扩展；缺点是有偏，且对离散/随机控制流支持弱。

**引擎对比**：

| 引擎 | 代表实现 | 优势 | 局限 |
| --- | --- | --- | --- |
| 重要性采样 | WebPPL、ProbLog | 简单、可并行 | 罕见证据失效 |
| Gibbs/MH | BUGS、PyMC | 通用、渐近精确 | 慢、难诊断 |
| HMC/NUTS | Stan、PyMC、NumPyro | 高维连续高效 | 需可微、离散弱 |
| 变分 | Pyro、TFP | 快、可大规模 | 有偏 |
| 编译到图模型 | Dice、Figaro | 可利用结构 | 受限于可编译子集 |

**工程建议**：

1. 先用**前向模拟**检验模型能否生成合理数据（prior predictive check）；
2. 用**模拟数据**做后验校准（SBC，simulation-based calibration）；
3. 对离散结构用 MCMC/Gibbs，对高维连续用 HMC/变分；
4. 关心速度时考虑"**摊销**"：训练一个网络学后验（§21.7）。

## 本章小结

**核心要点**

1. 贝叶斯网络的局限是**结构固定、不能共享、不能表达关系**；关系概率模型用对象、关系与 plate 解决。
2. **开放宇宙**模型引入存在性与身份不确定性，是实体消歧与多目标跟踪的自然表达。
3. **概率程序** = 随机采样 + 观测条件 + 任意控制流；表达力强但推断只能靠通用引擎。
4. 四类引擎：前向模拟（检验模型）、重要性采样（简单但有退化）、MCMC（渐近精确但慢）、变分（快但有偏）。
5. 实践路径是"先模拟检验、再选引擎、最后用 SBC 校准"。
