# 附录 A 现代进展：从 Transformer 到基础模型

**本章导读**：花书成书于 2016 年，彼时的主角是 CNN、RNN、GAN 与深度强化学习。此后十年，领域经历了三次结构性变化：**注意力取代循环**（A.1）、**预训练取代从零训练**（A.2）、**规模与对齐成为工程核心**（A.3–A.4）；同时扩散模型重塑生成（A.5），状态空间模型、混合专家与长上下文拓展了架构边界（A.6），量化/蒸馏/LoRA 让大模型可部署（A.7）。本附录把这些进展接到正文的概念上，并列出开放问题（A.8）。

**学习目标**：完成本附录学习后，你应当能够：

- 写出缩放点积注意力、多头注意力与 Transformer 块；
- 区分 BERT、GPT、T5 的预训练目标与适用任务；
- 解释规模法则、Chinchilla 最优配比与“涌现能力”的争议；
- 描述指令微调、RLHF、DPO 的目标与差异；
- 说明 CLIP、潜空间扩散、流匹配在多模态生成中的角色；
- 比较 Mamba、MoE、长上下文与检索增强的取舍；
- 解释量化、蒸馏、剪枝、LoRA、投机解码的工程价值；
- 识别幻觉、数据污染、版权、安全与评估等风险。

**预备知识**：第 6–10 章的网络与序列建模、第 19–20 章的变分/生成模型、第 12 章的应用与大规模训练；概率与线性代数基础。

## A.1 Transformer 与注意力

**缩放点积注意力**：

$$\mathrm{Attention}(Q,K,V) = \operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.$$

- $Q\in\mathbb{R}^{n\times d_k}$、$K\in\mathbb{R}^{m\times d_k}$、$V\in\mathbb{R}^{m\times d_v}$；
- 除以 $\sqrt{d_k}$ 防止点积随维度增大进入 softmax 饱和区；
- 复杂度 $O(nm d)$，自注意力（$n=m$）为 $O(n^2d)$。

**多头注意力**：

$$\mathrm{MultiHead}(Q,K,V) = \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)W^O,$$

$$\mathrm{head}_i = \mathrm{Attention}(QW_i^Q,KW_i^K,VW_i^V).$$

不同头可关注不同关系（句法、指代、位置、局部/全局）。

**Transformer 块**（Pre-LN 版本）：

```
x = x + MultiHead(LN(x))
x = x + FFN(LN(x))
```

FFN 通常是两层 MLP，中间维度为 $4d$，激活为 GELU/SiLU。Pre-LN 比 Post-LN 更稳定，允许不用 warmup 训练；Post-LN 表达力略强但需要 warmup。

**位置信息**：

| 方法 | 机制 | 特点 |
| --- | --- | --- |
| 正弦位置编码 | 固定三角函数 | 可外推性有限 |
| 可学习位置嵌入 | 每个位置一个向量 | 简单，长度受限 |
| 相对位置 | 注意力偏置 | 适合长序列 |
| RoPE | 旋转 query/key | 现代 LLM 主流，可插值外推 |
| ALiBi | 距离线性偏置 | 外推好，简单 |

**为什么注意力取代 RNN**：

- 任意两位置的路径长度 $O(1)$，长程依赖更容易；
- 时间维可并行，训练吞吐高；
- 可扩展到多模态（图像 patch、音频帧、视频 token）。

**注意力的代价**：$O(n^2)$ 时间与内存。改进方向：

| 方法 | 思路 |
| --- | --- |
| 稀疏/局部注意力 | 只连接邻近/固定模式 |
| 线性注意力 | 用核函数近似 softmax |
| 低秩/压缩 | 压缩 KV |
| FlashAttention | IO 感知的精确注意力，减少显存读写 |
| 多查询/分组查询注意力（MQA/GQA） | 共享 KV 头，降低推理缓存 |
| 滑动窗口 | 长文本局部建模 |
| 检索/记忆 | 只关注相关片段 |

**视觉 Transformer（ViT）**：把图像切成 $16\times16$ patch，线性投影成 token，加位置编码，送入 Transformer。ViT 的归纳偏置弱，需要大量数据或强增强/自监督；混合架构（卷积 stem + Transformer）在中等数据上更实用。

**ConvNeXt**：把 Transformer 的设计元素（大核、LayerNorm、GELU、倒瓶颈）移植回 CNN，说明“架构趋同”而非“卷积已死”。

## A.2 预训练与基础模型

**预训练范式**：

| 模型 | 结构 | 目标 | 适用 |
| --- | --- | --- | --- |
| BERT | 编码器 | 掩码语言模型 + NSP | 理解、分类、抽取 |
| GPT | 解码器 | 自回归下一 token | 生成、对话、代码 |
| T5/BART | 编码器-解码器 | Span corruption / denoising | 翻译、摘要、seq2seq |
| CLIP | 双塔 | 图文对比 | 零样本分类、检索 |
| Whisper | 编码器-解码器 | 多任务语音转写 | 多语言 ASR |

**基础模型（foundation model）**：在大规模、广泛数据上预训练，可通过微调/提示适配多种下游任务的模型。关键词是**规模、通用性、可迁移性**。

**Tokenization**：BPE、WordPiece、Unigram。子词平衡词表大小与未登录词；tokenizer 影响序列长度、成本与多语言性能。

**上下文学习（in-context learning）**：在提示中给少量示例，模型不更新参数即可“学会”任务。它可视为一种隐式元学习，但对示例顺序、格式与分布敏感。

**预训练数据**：网页、书籍、代码、论文、多语言语料；需要去重、过滤、质量分类、去毒、版权与隐私处理。数据质量往往比架构更能决定最终性能。

## A.3 规模法则与涌现能力

**规模法则（scaling laws）**：在固定架构与数据分布下，测试损失随参数量 $N$、数据量 $D$、算力 $C$ 呈幂律下降：

$$L(N,D) \approx L_\infty + aN^{-\alpha} + bD^{-\beta}.$$

**Kaplan 等（2020）** 给出早期经验指数；**Chinchilla（2022）** 进一步指出，在固定算力下，模型与数据应近似按比例扩展，最优约 **20 tokens/参数**。许多早期大模型“参数过大、数据不足”，Chinchilla 后训练配比普遍上调。

**涌现能力（emergent abilities）**：某些任务性能在模型规模超过阈值后突然提升。**争议**：部分“涌现”可能是指标不连续（如 exact match）造成的假象；用连续指标看，性能可能是平滑提升。因此应谨慎使用“涌现”一词，区分**能力突变**与**度量突变**。

**混合专家（MoE）**：每层有多个专家 FFN，路由器为每个 token 选择 Top-$k$ 专家：

$$y = \sum_{i\in\mathrm{TopK}} g_i(x)\,\mathrm{FFN}_i(x).$$

- 参数量大但每 token 计算量小（稀疏激活）；
- 需要负载均衡损失、容量因子、专家并行；
- 路由不稳定与通信成本是工程难点。

**数据质量与课程**：去重、过滤、领域配比、数据混合、课程学习、合成数据。规模不是唯一变量，“用什么数据、按什么顺序”同样重要。

## A.4 对齐：指令微调、RLHF 与 DPO

**预训练模型**只是“下一个 token 预测器”，不等于“有用的助手”。**对齐（alignment）** 让模型遵循指令、符合人类偏好、拒绝有害请求。

**（1）监督指令微调（SFT）**：用“指令 → 回答”数据做监督学习。它教会模型对话格式与任务意图，但难以覆盖所有偏好。

**（2）RLHF**：

1. 收集人类对多个回答的偏好排序；
2. 训练奖励模型 $r_\phi(x,y)$；
3. 用强化学习（PPO）最大化奖励，同时加 KL 惩罚防止偏离参考策略：

$$\max_\pi\;\mathbb{E}_{x,y\sim\pi}\big[r_\phi(x,y)\big] - \beta\,\mathrm{KL}\big(\pi(y\mid x)\|\pi_\text{ref}(y\mid x)\big).$$

**（3）DPO（Direct Preference Optimization）**：把偏好学习转化为分类损失，不需要显式奖励模型与 RL：

$$\mathcal{L}_\text{DPO} = -\mathbb{E}_{(x,y_w,y_l)}\log\sigma\left(\beta\log\frac{\pi_\theta(y_w\mid x)}{\pi_\text{ref}(y_w\mid x)} - \beta\log\frac{\pi_\theta(y_l\mid x)}{\pi_\text{ref}(y_l\mid x)}\right).$$

- $y_w$ 是偏好回答，$y_l$ 是较差回答；
- 更简单稳定，但依赖偏好数据质量与分布覆盖。

**（4）RLAIF / 宪法式 AI**：用模型/规则代替部分人类标注，降低成本，但可能引入模型偏见。

**安全与评估**：红队测试、越狱防护、拒答策略、内容过滤、工具调用权限、审计日志。对齐不是一次性任务，而是持续评测与迭代。

## A.5 多模态与扩散

**CLIP**：图文双塔，对比学习对齐图像与文本：

$$\mathcal{L}_\text{InfoNCE} = -\log\frac{\exp(\mathrm{sim}(I,T_+)/\tau)}{\sum_{T}\exp(\mathrm{sim}(I,T)/\tau)}.$$

CLIP 的嵌入可用于零样本分类、检索、条件生成（作为条件编码器）。

**文本到图像**：

- **GAN 路线**：StyleGAN、StackGAN；
- **扩散路线**：Stable Diffusion（潜空间扩散 + 文本编码器 + cross-attention）、DALL·E 2/3、Imagen、Midjourney；
- **自回归路线**：Parti、ImageGPT、VQ-VAE + Transformer。

**潜空间扩散（LDM）**：先用 VAE 把图像压到低维隐空间，再在隐空间做扩散；降低计算量，保留感知质量。文本条件通过 cross-attention 注入。

**流匹配（Flow Matching）**：学习从噪声到数据的连续变换速度场，目标比扩散的噪声预测更直接；是新一代生成模型（如 Stable Diffusion 3）的基础之一。

**视频与音频**：时空注意力、3D VAE、时序扩散；音频用 WaveNet/扩散/流匹配；语音合成与音乐生成都在快速演进。

**多模态大模型**：视觉编码器 + 投影层 + 语言模型（LLaVA 类），或原生多模态 Transformer；支持图像问答、文档理解、屏幕操作、机器人指令。

## A.6 状态空间模型、混合专家与长上下文

**状态空间模型（SSM）**：

$$h_t = A h_{t-1} + B x_t,\qquad y_t = C h_t + D x_t.$$

线性 SSM 可并行训练（卷积形式）、推理时 $O(1)$ 递推。**Mamba** 引入**选择性**（输入依赖的 $A,B,C$）与硬件感知扫描，兼顾长程建模与线性复杂度，是 Transformer 的有力补充。

**MoE**：见 A.3。它把“参数量”与“每 token 计算量”解耦，是千亿/万亿参数模型的常见选择。

**长上下文**：

| 方法 | 思路 |
| --- | --- |
| RoPE 插值/缩放 | 扩展位置编码 |
| 滑动窗口/稀疏注意力 | 局部 + 全局 |
| 检索增强（RAG） | 只把相关文档放进上下文 |
| 记忆/压缩 | 摘要、KV 压缩、状态复用 |
| 线性/SSM 层 | 长序列线性复杂度 |

**检索增强生成（RAG）**：检索器从外部知识库取回相关片段，拼接进提示，生成器据此回答。优点是知识可更新、可溯源；难点是检索质量、上下文冲突与引用一致性。

**Agent**：把大模型作为控制器，配合规划、工具调用、记忆、验证与环境反馈。它把“生成”扩展为“行动”，但可靠性、权限与错误传播仍是核心问题。

## A.7 高效训练与推理

**训练侧**：

| 技术 | 作用 |
| --- | --- |
| 混合精度（BF16/FP16） | 提升吞吐、降低显存 |
| 梯度检查点 | 用计算换显存 |
| ZeRO/FSDP | 分片优化器状态/梯度/参数 |
| 张量/流水线/序列并行 | 扩展到大模型 |
| FlashAttention | IO 感知，减少显存读写 |
| 激活重计算/编译 | 优化算子与内存 |
| 数据/课程/配比 | 提升单位算力收益 |

**推理侧**：

| 技术 | 思路 | 收益 |
| --- | --- | --- |
| 量化 | FP16 → INT8/INT4（GPTQ、AWQ、GGUF） | 2–4× 显存/带宽 |
| 蒸馏 | 小学生模仿教师 | 小模型接近大模型 |
| 剪枝 | 去掉冗余权重/头/层 | 2–10× |
| LoRA/QLoRA | 低秩适配器，少量参数微调 | 低成本定制 |
| KV cache | 缓存历史 key/value | 避免重复计算 |
| GQA/MQA | 共享 KV 头 | 降低缓存 |
| 投机解码 | 小模型草稿 + 大模型验证 | 2–3× 加速 |
| 连续批处理 | 动态合并请求 | 提升吞吐 |
| 编译/算子融合 | TensorRT、vLLM、Triton | 降低延迟 |

**LoRA**：

$$W' = W + BA,\qquad B\in\mathbb{R}^{d\times r},\;A\in\mathbb{R}^{r\times k},\;r\ll\min(d,k).$$

只训练 $A,B$，冻结 $W$；可合并回原权重，推理无额外延迟。

**量化**：把权重/激活映射到低比特，需处理离群值、校准数据与反量化；QLoRA 在 4-bit 基座上训练 LoRA，显著降低微调显存。

**成本与延迟**：大模型推理常受**内存带宽**而非算力限制；batch、序列长度、KV cache 大小共同决定吞吐。产品设计要在质量、延迟、成本之间取舍。

## A.8 开放问题与风险

| 问题 | 表现 | 方向 |
| --- | --- | --- |
| 幻觉 | 生成看似合理但错误的内容 | RAG、工具、验证器、不确定性 |
| 推理 | 多步数学/逻辑/规划不稳定 | 思维链、搜索、程序化验证、RL |
| 因果 | 学到相关而非干预 | 因果推断、实验、世界模型 |
| 数据污染 | 测试集泄漏进训练 | 去重、动态评测、污染检测 |
| 评估 | 基准饱和、指标与人类不一致 | 新基准、人工评估、对抗评测 |
| 版权/隐私 | 训练数据与记忆 | 许可、去重、机器遗忘、差分隐私 |
| 安全 | 越狱、有害内容、滥用 | 红队、护栏、内容凭证、审计 |
| 能源 | 训练/推理碳排 | 高效架构、稀疏、绿色算力 |
| 科学可信度 | 生成错误假设/数据 | 人机协同、实验验证 |

**“规模是否足够”**：规模法则在语言/视觉的损失上成立，但不自动带来可靠性、因果理解与长程规划。**架构、数据、训练目标、工具与评估**仍是开放的研究问题。

**一句话总结**：现代深度学习 = **Transformer 作为通用骨架 + 大规模自监督预训练 + 规模法则 + 对齐/工具 + 高效推理**；它把花书中的表示学习、序列建模、生成模型与优化工程推到了极致，但没有消除数据、因果、可靠性与责任的根本问题。

## 本附录小结

**核心要点**

1. 缩放点积注意力与多头注意力让任意位置直接交互；Transformer 以并行性与长程建模取代 RNN。
2. 预训练范式分编码器（BERT）、解码器（GPT）、编码器-解码器（T5）；基础模型的核心是规模 + 通用性 + 可迁移性。
3. 规模法则给出损失随参数/数据/算力的幂律；Chinchilla 强调数据与参数的最优配比；涌现能力需区分能力突变与指标突变。
4. 对齐包括 SFT、RLHF、DPO；目标是对齐人类偏好，同时用 KL 约束防止漂移。
5. CLIP 连接图文；潜空间扩散与流匹配是文本到图像/视频的主流；多模态大模型把视觉编码器接入语言模型。
6. Mamba/SSM、MoE、长上下文与 RAG 分别从架构、稀疏性、位置与检索角度扩展能力边界。
7. 量化、蒸馏、剪枝、LoRA、投机解码与连续批处理是大模型落地的关键工程。
8. 幻觉、推理、因果、数据污染、版权、安全与能源仍是开放问题；规模不是可靠性的充分条件。
