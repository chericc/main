# 第 10 章 序列建模：循环与递归网络（Sequence Modeling: Recurrent and Recursive Nets）

**本章导读**：前馈网络假设输入是固定维度的向量，但语言、语音、视频、传感器读数都是**变长序列**，且当前位置的预测依赖历史。循环神经网络（RNN）用共享参数在时间上展开计算图，把“历史”压缩进隐状态。本章讨论：展开计算图（10.1）、RNN 的前向与训练（10.2–10.3）、LSTM/GRU 的门控（10.4）、序列建模的设计模式（10.5）、递归网络（10.6）、显式记忆（10.7），最后说明 RNN 如何过渡到注意力与 Transformer（10.8）。

**学习目标**：完成本章学习后，你应当能够：

- 画出 RNN 的展开计算图，写出前向公式与参数量；
- 推导 BPTT，解释梯度消失/爆炸与谱半径的关系；
- 使用梯度裁剪、正交初始化、门控与截断 BPTT；
- 写出 LSTM/GRU 的门控更新，说明细胞状态为何缓解长程依赖；
- 设计序列标注、编码器-解码器、双向/深层 RNN；
- 区分递归网络与循环网络，说明树/图结构的建模；
- 解释外部记忆与注意力之间的联系。

**预备知识**：第 6 章的反向传播、第 8 章的优化与梯度裁剪、第 9 章的参数共享；第 3 章的链式法则与概率。

## 10.1 展开计算图

**循环计算**：

$$h_t = f(h_{t-1}, x_t;\theta),\qquad \hat y_t = g(h_t;\theta).$$

参数 $\theta$ 在所有时间步共享。把时间维展开，就得到一个**深度为 $T$、每层共享参数**的前馈计算图：

```
x_1 → h_1 → h_2 → h_3 → ... → h_T
        ↓     ↓     ↓           ↓
       y_1   y_2   y_3   ...   y_T
```

**输入/输出模式**：

| 模式 | 例子 | 结构 |
| --- | --- | --- |
| 多对一 | 情感分类 | 最后隐状态 → 分类 |
| 一对多 | 图像描述 | 初始状态 → 逐词生成 |
| 多对多（同步） | 词性标注 | 每步输出 |
| 多对多（异步） | 机器翻译 | 编码器 → 解码器 |
| 序列到序列 | 摘要、对话 | Encoder–Decoder |

**参数量**：若隐状态维度 $d_h$、输入维度 $d_x$、输出维度 $d_y$，则

$$W_h \in \mathbb{R}^{d_h\times d_h},\quad W_x \in \mathbb{R}^{d_h\times d_x},\quad W_y \in \mathbb{R}^{d_y\times d_h},$$

参数量与序列长度 $T$ 无关。这是 RNN 相对“每步一个全连接层”的最大优势。

**深层 RNN**：把多个循环层堆叠，第 $l$ 层的输入是第 $l-1$ 层的隐状态序列。深层 RNN 能学更抽象的时序特征，但训练更难，通常配合残差与归一化。

**双向 RNN**：用前向与后向两个 RNN 分别编码左右上下文，拼接后输出：

$$\overrightarrow h_t = f(\overrightarrow h_{t-1}, x_t),\qquad \overleftarrow h_t = f(\overleftarrow h_{t+1}, x_t),$$

$$h_t = [\overrightarrow h_t; \overleftarrow h_t].$$

双向适用于**离线**任务（已获得完整序列），不适用于实时流式预测（不能看未来）。

## 10.2 循环神经网络

**基本 RNN**：

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b_h),$$

$$\hat y_t = \operatorname{softmax}(W_y h_t + b_y).$$

**损失**：对所有时间步求和（或平均）：

$$L = \sum_{t=1}^{T} L_t(\hat y_t, y_t).$$

**前向传播**：按时间顺序计算并缓存 $h_t$；每个时间步的计算量相同，但无法像 CNN 那样在时间维并行（这是 RNN 慢的根本原因）。

**初始状态**：$h_0$ 通常为零向量，也可作为可学习参数或由编码器给出。

**输出层**：分类用 softmax，回归用线性，序列标注可用 CRF（10.5 节）。

**RNN 的表达力**：在理论上，足够大的 RNN 是图灵完备的，可以模拟任意有限状态机；但“能表示”不等于“能学到”，长程依赖仍是难点。

## 10.3 反向传播随时间与梯度问题

**BPTT（backpropagation through time）**：把展开图当作前馈网络，用反向传播求梯度。对 $h_t$ 的梯度包含两部分：

$$\frac{\partial L}{\partial h_t} = \frac{\partial L_t}{\partial h_t} + \frac{\partial L_{>t}}{\partial h_t},$$

其中第二项通过 $h_{t+1}$ 回传：

$$\frac{\partial L}{\partial h_t} = \frac{\partial L_t}{\partial h_t} + \left(\frac{\partial h_{t+1}}{\partial h_t}\right)^\top \frac{\partial L}{\partial h_{t+1}}.$$

**梯度消失/爆炸**：跨越 $T$ 步的梯度包含连乘

$$\prod_{k=t}^{T-1}\frac{\partial h_{k+1}}{\partial h_k} = \prod_{k=t}^{T-1} \operatorname{diag}\big(g'(z_{k+1})\big) W_h^\top.$$

若 $W_h$ 的谱半径 $<1$，梯度指数衰减（消失）；$>1$ 则指数增长（爆炸）。tanh 的导数最大为 1，进一步加剧消失。

**后果**：

- 长距离依赖学不到（梯度消失）；
- 训练不稳定、损失突然 NaN（梯度爆炸）；
- 梯度被少数近处时间步主导。

**对策**：

| 方法 | 机制 |
| --- | --- |
| 梯度裁剪 | 限制范数，防爆炸 |
| 正交初始化 | 保持 Jacobian 奇异值接近 1 |
| 门控（LSTM/GRU） | 用加性路径保留信息 |
| 残差连接 | 提供梯度捷径 |
| 截断 BPTT | 只回传固定步数，牺牲长程 |
| 学习率调度/小学习率 | 稳定训练 |
| 注意力 | 直接连接任意两位置（10.8） |

**截断 BPTT**：把长序列切成固定长度的小段，每段单独回传；隐状态跨段传递但不回传梯度。它降低显存与计算，但限制了可学的依赖长度。

**Teacher forcing**：训练解码器时，把**真实**的上一 token 作为输入；推理时用模型自己生成的 token。训练收敛快，但训练/推理分布不一致，造成**曝光偏差（exposure bias）**。对策：scheduled sampling、强化学习微调、对抗训练。

**梯度检查**：RNN 的 BPTT 容易写错，应用小序列做数值梯度检查。

## 10.4 长短期记忆与门控循环单元

**LSTM**（Hochreiter & Schmidhuber，1997）引入**细胞状态** $c_t$ 与三个门：

$$f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f),$$

$$i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i),$$

$$o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o),$$

$$\tilde c_t = \tanh(W_c x_t + U_c h_{t-1} + b_c),$$

$$c_t = f_t\odot c_{t-1} + i_t\odot\tilde c_t,$$

$$h_t = o_t\odot\tanh(c_t).$$

- **遗忘门** $f_t$：保留多少旧细胞状态；
- **输入门** $i_t$：写入多少新信息；
- **输出门** $o_t$：暴露多少细胞状态给隐状态；
- $\odot$ 是逐元素乘。

**为什么细胞状态关键**：$c_t$ 的更新是**加法**，梯度可以沿 $c_t$ 的路径直接回传，不必每步乘 Jacobian。只要遗忘门接近 1，信息就能跨越很多步；这缓解了梯度消失，但并非完全解决。

**GRU**（Cho 等，2014）是简化版：

$$z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z),$$

$$r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r),$$

$$\tilde h_t = \tanh\big(W_h x_t + U_h(r_t\odot h_{t-1}) + b_h\big),$$

$$h_t = (1-z_t)\odot h_{t-1} + z_t\odot\tilde h_t.$$

- **更新门** $z_t$ 控制新旧状态混合；
- **重置门** $r_t$ 控制忽略多少历史；
- 参数量比 LSTM 少，性能常相当。

**LSTM vs GRU**：

| 维度 | LSTM | GRU |
| --- | --- | --- |
| 状态 | 隐状态 + 细胞状态 | 仅隐状态 |
| 门数 | 3（+候选） | 2 |
| 参数量 | 较多 | 较少 |
| 长程依赖 | 强 | 强（略逊/相当，视任务） |
| 训练速度 | 较慢 | 较快 |

**变体**：peephole 连接（门看细胞状态）、coupling gates（输入/遗忘门联动）、projection layer（降维）、LayerNorm LSTM。大多数任务中，标准 LSTM/GRU + 调参已足够。

**正则化**：Dropout 在 RNN 中应施加于**非循环连接**（输入/输出），而不是隐状态（会破坏记忆）；variational dropout 在时间步间共享掩码。

## 10.5 序列建模的设计模式

**（1）序列标注**：每个位置输出标签。BiLSTM + CRF 是经典组合：

$$P(y\mid x) = \frac{\exp\big(\sum_t s_t(y_t) + \sum_t T(y_{t-1},y_t)\big)}{\sum_{y'}\exp(\cdots)}.$$

CRF 层建模标签转移约束（如 IOB 格式），解码用 Viterbi。第 16 章会从图模型角度再讲。

**（2）编码器-解码器**：

$$c = \text{Encoder}(x_1,\dots,x_m),\qquad s_t = \text{Decoder}(s_{t-1}, y_{t-1}, c).$$

它把变长输入映射到变长输出。瓶颈是整个源序列被压成一个向量 $c$，长句信息丢失；**注意力**通过每步读取源序列的不同位置解决这一点（10.8）。

**（3）注意力解码**：

$$\alpha_{t,i} = \frac{\exp(e_{t,i})}{\sum_j\exp(e_{t,j})},\qquad c_t = \sum_i \alpha_{t,i} h_i,$$

其中 $e_{t,i}$ 是解码器状态与编码器状态的匹配分数。注意力既是信息通路，也是可解释性的窗口（但“注意力权重 = 解释”并不总成立）。

**（4）层次 RNN**：词级 RNN → 句级 RNN → 文档级 RNN，建模层次结构。

**（5）卷积序列模型**：用因果卷积（WaveNet、TCN）在时间维并行，感受野随层数指数增长；比 RNN 更容易并行，适合音频与长序列。

**（6）序列到序列的训练技巧**：teacher forcing、beam search、长度归一化、label smoothing、copy mechanism、coverage penalty。

## 10.6 递归网络

**递归神经网络（recursive neural network）** 在**树结构**上递归组合：

$$h_\text{parent} = f\big(W[h_\text{left}; h_\text{right}] + b\big).$$

它适合句法树、表达式树、分子图等具有显式层次结构的数据。与 RNN 的区别：

| 维度 | 循环网络 | 递归网络 |
| --- | --- | --- |
| 结构 | 链式（时间） | 树/图 |
| 参数共享 | 所有时间步 | 所有节点 |
| 深度 | 序列长度 | 树深 |
| 输入 | 序列 | 树结构 |

**应用**：句法分析、情感组合、程序语义、分子性质预测。树结构通常由外部解析器给出，或通过强化学习/可微搜索学习。

**图神经网络（GNN）** 是递归思想在图上的推广：节点通过邻居消息传递更新表示。它是附录 E.1 的主题，也是分子、社交网络、知识图谱的主力。

## 10.7 显式记忆与外部存储

**神经图灵机（NTM）**：控制器（RNN）+ 外部记忆矩阵 $M\in\mathbb{R}^{N\times d}$，通过可微的读/写头访问：

$$w_t = \text{softmax}\big(\text{address}(h_t)\big),\qquad r_t = \sum_i w_t(i)M_t(i).$$

写入用擦除向量与添加向量，整个操作可微，可用梯度训练。它让网络学会“存储—检索”算法（复制、排序、 associative recall）。

**可微神经计算机（DNC）**：在 NTM 基础上加入动态记忆分配与链接矩阵，能处理更复杂的关系推理。

**记忆网络（Memory Networks）**：用外部记忆存储事实，通过注意力检索；是检索增强生成（RAG）的思想前身。

**与注意力的关系**：注意力是“软寻址”的特例——键值记忆 + 查询。Transformer 的自注意力可以看作“序列自身作为记忆”的检索机制。区别在于：NTM 的记忆可读写、容量可扩展；自注意力的“记忆”就是当前输入，成本随长度平方增长。

**现代对应物**：检索增强、外部工具、长上下文、向量数据库，都是“显式记忆”思想的工程化。

## 10.8 从 RNN 到注意力

**RNN 的三个瓶颈**：

1. **串行计算**：时间步无法并行，长序列训练慢；
2. **固定容量隐状态**：所有历史压进一个向量，长程信息衰减；
3. **路径长度**：任意两位置之间的梯度路径为 $O(T)$，难学长程依赖。

**注意力**直接连接任意两位置，路径长度为 $O(1)$，且可并行。**Transformer** 用自注意力 + 前馈层堆叠，彻底取代了 RNN 在多数序列任务中的位置（附录 A.1）。

**但 RNN 并未消失**：

- 流式/低延迟场景（在线语音、传感器）仍适合 RNN/状态空间模型；
- 小模型、边缘设备上，GRU 的参数量与内存更友好；
- 状态空间模型（S4、Mamba）用线性递推 + 选择性机制，兼顾并行训练与长程建模；
- RNN 的思想（状态、门控、递推）仍是理解序列模型的基础。

**一句话总结**：RNN 用**共享参数 + 隐状态**把序列变成可微的计算图；LSTM/GRU 用门控与加性状态缓解长程依赖；注意力用“直接连接”取代“逐步传递”，把序列建模推向 Transformer 时代。

## 本章小结

**核心要点**

1. RNN 在时间上共享参数，参数量与序列长度无关；展开后是深层共享权重的计算图。
2. BPTT 的梯度是 Jacobian 的连乘；谱半径偏离 1 导致梯度消失/爆炸。
3. 梯度裁剪、正交初始化、门控、残差与截断 BPTT 是主要对策。
4. LSTM 的细胞状态用加法更新，提供长程梯度路径；GRU 用两个门简化且性能常相当。
5. 编码器-解码器解决变长映射；注意力解决信息瓶颈；teacher forcing 带来曝光偏差。
6. 递归网络在树/图结构上组合表示；GNN 是其图上的推广。
7. 外部记忆（NTM/DNC）用可微读写扩展容量，是注意力与检索增强的前身。
8. Transformer 用自注意力取代循环，但 RNN 在流式、小模型与状态空间模型中仍有位置。
