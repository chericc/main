# 第 7 章 深度学习中的正则化（Regularization for Deep Learning）

**本章导读**：正则化是“让模型在训练集之外也表现好”的所有手段的总称。它不只是加一个 $L_2$ 项：数据增强、噪声注入、早停、参数共享、Dropout、对抗训练、集成，甚至网络架构本身都在施加先验。本章按“参数 → 数据 → 训练过程 → 结构 → 随机性 → 鲁棒性”的顺序展开：参数范数惩罚（7.1）、数据与噪声（7.2）、早停（7.3）、共享与多任务（7.4）、稀疏与 Dropout（7.5）、对抗与切空间（7.6）、集成与迁移（7.7），最后给出实践配方（7.8）。

**学习目标**：完成本章学习后，你应当能够：

- 写出 $L_2$ 与 $L_1$ 正则的目标，解释权重衰减与稀疏性；
- 说明数据增强为何等价于编码先验；
- 解释早停与 $L_2$ 正则的联系；
- 区分参数共享、多任务学习与迁移学习；
- 推导 Dropout 的训练/推理规则并解释其集成视角；
- 描述对抗训练与切空间正则的目标；
- 组合多种正则化手段，按“先数据、后结构、再惩罚”的顺序调参。

**预备知识**：第 5 章的过拟合与偏差-方差、第 6 章的前馈网络与反向传播；第 3 章的贝叶斯先验。

## 7.1 参数范数惩罚

**通用形式**：

$$\tilde J(\theta; X,y) = J(\theta; X,y) + \alpha\Omega(\theta),$$

其中 $J$ 是原始损失，$\Omega$ 是正则项，$\alpha \ge 0$ 控制强度。贝叶斯视角下，$-\log p(\theta)$ 就是正则项，$\alpha$ 对应先验的尺度。

**$L_2$ 正则（权重衰减）**：

$$\Omega(\theta) = \frac12\|\theta\|_2^2,\qquad \tilde J = J + \frac{\alpha}{2}\|\theta\|_2^2.$$

梯度更新：

$$\theta \leftarrow \theta - \eta(\nabla_\theta J + \alpha\theta) = (1-\eta\alpha)\theta - \eta\nabla_\theta J.$$

每一步先把权重按比例缩小，再沿梯度走，因此叫**权重衰减（weight decay）**。

**线性回归的闭式解**：

$$w = (X^\top X + \alpha I)^{-1}X^\top y.$$

$\alpha I$ 改善条件数，使解更稳定；当特征共线时，$L_2$ 把权重分摊到相关特征上，而不是任意选一个。

**为什么 $L_2$ 有效**：它偏好“小权重”，使函数对输入的微小变化不敏感，从而降低方差。对深层网络，小权重还意味着激活不会爆炸，训练更稳定。

**$L_1$ 正则**：

$$\Omega(\theta) = \|\theta\|_1 = \sum_i \lvert\theta_i\rvert.$$

梯度为 $\operatorname{sign}(\theta)$（在 0 处取次梯度），更新会把小权重推向 0，产生**稀疏解**。稀疏性可用于特征选择、压缩与可解释性。

**$L_1$ vs $L_2$**：

| 性质 | $L_1$ | $L_2$ |
| --- | --- | --- |
| 解的特征 | 稀疏 | 平滑、权重分散 |
| 几何 | 菱形等高线，易碰坐标轴 | 圆形，不特别偏向坐标轴 |
| 先验 | 拉普拉斯 | 高斯 |
| 优化 | 非光滑，需近端方法 | 光滑 |
| 适用 | 高维稀疏、特征选择 | 一般正则、稳定训练 |

**注意**：在 Adam 等自适应优化器中，直接加 $L_2$ 项与“解耦权重衰减”并不等价。**AdamW** 把权重衰减从梯度中分离出来，通常泛化更好（第 8 章、附录 A.7）。

**偏置是否正则化**：通常只对权重做惩罚，偏置不惩罚。偏置不控制函数曲率，惩罚它收益很小，反而可能欠拟合。

## 7.2 数据增强与噪声注入

**数据增强**：对训练样本施加保持标签的变换，扩充有效数据。它把“任务不变性”这一先验编码进训练。

| 模态 | 常见增强 |
| --- | --- |
| 图像 | 随机裁剪、翻转、旋转、颜色抖动、Cutout、Mixup、CutMix |
| 语音 | 变速、变调、加噪、SpecAugment、混响 |
| 文本 | 同义替换、回译、随机删除/交换、掩码 |
| 表格 | 噪声注入、特征丢弃、SMOTE（谨慎使用） |

**为什么增强有效**：它让模型在变换前后给出相同输出，等价于对模型施加**不变性约束**；同时扩大数据分布覆盖，减少对训练集细节的记忆。

**增强的风险**：增强必须**保持标签**。例如数字“6”和“9”旋转后标签改变；医学图像的翻转可能改变解剖语义。增强过强会引入分布偏移，反而伤害性能。

**噪声注入**：

- **输入噪声**：$x \to x + \epsilon$，等价于 Tikhonov 正则（对小噪声）；
- **权重噪声**：$w \to w + \epsilon$，鼓励平坦极小，是贝叶斯神经网络的一种近似；
- **激活噪声**：Dropout；
- **标签噪声**：标签平滑、噪声鲁棒损失。

**标签平滑**：把 one-hot $y$ 换成

$$\tilde y = (1-\epsilon)y + \frac{\epsilon}{K}\mathbf{1},$$

损失为 $-\sum_k \tilde y_k\log p_k$。它防止模型过度自信，改善校准，常与蒸馏一起使用。

**Mixup / CutMix**：在样本或标签空间做线性插值：

$$\tilde x = \lambda x_i + (1-\lambda)x_j,\qquad \tilde y = \lambda y_i + (1-\lambda)y_j.$$

它们鼓励模型在训练样本之间线性行为，属于强正则，在图像分类中常用。

## 7.3 早停

**做法**：在验证集损失开始上升时停止训练，返回验证性能最好的参数。

**为什么是正则化**：早停限制参数离开初始化的距离，等价于限制模型的有效容量。对二次近似，早停与 $L_2$ 正则有明确的对应关系：训练步数 $t$ 与正则强度 $\alpha$ 之间存在映射。

**实现要点**：

- 监控验证损失（或目标指标），不是训练损失；
- 设 `patience`（连续多少轮无改善后停止）；
- 保存最佳 checkpoint，而不是最后一轮；
- 学习率调度与早停交互：余弦退火末期可能再降损失，需谨慎判断。

**早停的代价**：需要验证集；小数据时验证集噪声大，早停可能过早。对策：交叉验证、平滑验证曲线、用多个指标。

## 7.4 参数共享与多任务学习

**参数共享（weight tying）**：

- CNN 的卷积核在空间共享；
- RNN 在时间步共享；
- 嵌入层与输出层共享（语言模型中常见，减少参数并改善低频词）；
- 多任务网络共享主干。

**多任务学习（multi-task learning）**：同时优化多个相关任务，

$$L = \sum_{t=1}^{T} \lambda_t L_t.$$

共享表示迫使模型学习对多个任务都有用的特征，相当于用任务作为归纳偏置。风险是**负迁移**：任务冲突时，共享层可能互相拖累。对策：任务分组、软共享、梯度手术（PCGrad）、动态权重。

**辅助任务**：在主任务之外加一个容易学习的辅助损失（如深度估计、掩码预测、对比损失），帮助主任务学表示。辅助任务只在训练时使用。

**迁移学习**：在源任务上预训练，在目标任务上微调。它不严格是正则化，但通过“好的初始化 + 共享表示”显著降低目标任务的样本需求（第 15 章、附录 A.2）。

## 7.5 稀疏表示与 Dropout

**稀疏表示**：对隐层激活 $h$ 加 $L_1$ 惩罚，或限制平均激活接近 $\rho$（稀疏自编码器）。稀疏性使表示更可解释、更省存储，也常带来更好的泛化。

**Dropout**：训练时以概率 $p$ 随机把隐藏单元置零：

$$m_j \sim \mathrm{Bernoulli}(1-p),\qquad h'_j = m_j h_j.$$

**推理时的两种做法**：

1. **原始做法**：推理时使用全部单元，但把输出乘以 $(1-p)$，以匹配训练时的期望；
2. **Inverted dropout**（现代默认）：训练时把保留的单元除以 $(1-p)$，推理时不变。

**为什么有效**：

- **集成视角**：Dropout 训练了 $2^n$ 个共享参数的子网络，推理近似对这些子网络做几何平均；
- **防止共适应**：单元不能依赖特定邻居，必须学冗余特征；
- **噪声正则**：等价于对激活加乘性噪声。

**Dropout 的变体**：

| 变体 | 做法 | 场景 |
| --- | --- | --- |
| Spatial Dropout | 按通道丢弃整张特征图 | CNN |
| DropConnect | 丢弃权重而非激活 | 小网络 |
| Variational Dropout | 学习每个单元的丢弃率 | 贝叶斯近似 |
| MC Dropout | 推理时也开启，多次采样估不确定度 | 不确定性估计 |
| Stochastic Depth | 随机跳过整个残差块 | 深层网络 |

**注意事项**：

- Dropout 与 BatchNorm 同时使用可能不稳定（训练/推理方差估计冲突），可用 GroupNorm 或调整顺序；
- 大模型 + 大数据时 Dropout 收益下降，现代 LLM 常在最后几层才用；
- 推理时忘记切换 `eval()` 是常见 bug。

## 7.6 对抗训练与切空间正则

**对抗样本**：对输入加一个肉眼不可见的小扰动 $\delta$，使模型预测错误。**对抗训练**把最坏扰动下的损失纳入目标：

$$\min_\theta \mathbb{E}_{(x,y)}\left[\max_{\|\delta\|\le\epsilon} L\big(f_\theta(x+\delta), y\big)\right].$$

**FGSM**（单步）：

$$\delta = \epsilon\,\operatorname{sign}\big(\nabla_x L(f_\theta(x), y)\big).$$

**PGD**（多步迭代）：

$$\delta_{t+1} = \Pi_{\|\delta\|\le\epsilon}\big(\delta_t + \alpha\operatorname{sign}(\nabla_x L(f_\theta(x+\delta_t), y))\big).$$

对抗训练显著提升鲁棒性，但通常降低干净样本精度，且计算成本高（每步需反向传播到输入）。

**切空间正则（tangent prop）**：若已知数据变换（旋转、平移），惩罚模型输出沿变换方向的导数：

$$\Omega = \sum_i \left\|\frac{\partial f(x_i)}{\partial t}\right\|^2.$$

它把“不变性”直接写进损失，而不是靠数据增强隐式学习。

**契约自编码器（contractive autoencoder）**：惩罚编码器雅可比的 Frobenius 范数，使表示对输入扰动不敏感（第 14 章）。

**鲁棒性与准确率的权衡**：对抗训练学到的特征更接近人类语义，但可能牺牲对自然噪声的精度；是否使用取决于部署场景的威胁模型。

## 7.7 集成、迁移与正则化组合

**集成（ensemble）**：训练多个模型并平均预测：

$$\hat y = \frac{1}{M}\sum_{m=1}^{M} f_m(x).$$

- **Bagging**：对数据重采样，降低方差；
- **Boosting**：序列训练，降低偏差；
- **Deep Ensembles**：不同初始化/数据顺序的独立网络，简单有效，是不确定性估计的强基线；
- **Snapshot Ensembles**：沿一个训练轨迹保存多个快照；
- **MC Dropout**：用 Dropout 采样近似集成。

**集成的代价**：$M$ 倍推理成本。可用蒸馏把集成知识压回单模型（第 12 章、附录 A.7）。

**迁移学习与微调**：

| 策略 | 做法 | 适用 |
| --- | --- | --- |
| 特征提取 | 冻结主干，只训新头 | 目标数据少 |
| 全量微调 | 解冻全部层，小学习率 | 目标数据中等 |
| 分层微调 | 先训头，再逐层解冻 | 稳定、省算力 |
| 差分学习率 | 浅层小学习率、深层大学习率 | 保留通用特征 |
| 适配器/LoRA | 只训少量新增参数 | 大模型、多任务 |

**正则化组合的经验顺序**：

1. **先加数据**：更多数据、数据增强、迁移学习；
2. **再调结构**：归一化、残差、合适的容量；
3. **再加训练技巧**：早停、学习率调度、标签平滑；
4. **最后加显式惩罚**：权重衰减、Dropout、稀疏约束；
5. **对抗/鲁棒训练**：仅在威胁模型明确时使用。

**不要同时开所有正则**：它们可能相互抵消或让模型欠拟合。每次只改一个因素，用消融实验确认收益。

## 7.8 正则化的实践配方

**图像分类的常见组合**：

```
数据增强（RandomResizedCrop, Flip, ColorJitter, Mixup/CutMix）
+ 权重衰减（AdamW, 0.01–0.1）
+ Label Smoothing（0.1）
+ 早停
+ （大模型）Stochastic Depth / Dropout
+ （需要鲁棒性）对抗训练
```

**语言模型的常见组合**：

```
大规模预训练 + 权重衰减 + Dropout（小模型）/ 低 Dropout（大模型）
+ 梯度裁剪 + 学习率 warmup + 早停（微调时）
+ 指令微调/对齐（附录 A.3–A.4）
```

**诊断正则化是否有效**：

- 训练误差与验证误差的差距是否缩小？
- 验证误差是否真的下降，而不是只让训练更慢？
- 在不同随机种子下是否稳定？
- 是否损害了校准、鲁棒性或少数群体性能？

**一句话总结**：正则化的本质是**把先验写进模型**；数据增强写“不变性”，权重惩罚写“简单性”，Dropout 写“冗余性”，早停写“不要走太远”，集成写“平均更稳”。好的正则化不是堆技巧，而是选对与任务匹配的先验。

## 本章小结

**核心要点**

1. 正则化 = 所有提升泛化手段的总称；参数惩罚只是其中一种。
2. $L_2$ 促小权重、改善条件数；$L_1$ 促稀疏；AdamW 的解耦权重衰减更合理。
3. 数据增强把不变性先验编码进训练；增强必须保持标签，过强会引入偏移。
4. 早停限制有效容量，与 $L_2$ 有理论联系；应监控验证指标并保存最佳 checkpoint。
5. 参数共享、多任务与迁移学习通过“共享表示”降低样本需求，但需警惕负迁移。
6. Dropout 可视为共享参数的子网络集成；推理时注意 train/eval 模式。
7. 对抗训练提升鲁棒性但代价高；切空间正则把已知变换的不变性直接写入损失。
8. 正则化组合应遵循“数据 → 结构 → 训练 → 惩罚”的顺序，并用消融验证。
