# 第 18 章 直面配分函数（Confronting the Partition Function）

**本章导读**：能量模型 $p(x)=\exp(-E(x))/Z$ 的归一化常数 $Z$ 通常不可计算：它是对所有状态的求和/积分，状态数随维度指数增长。没有 $Z$，似然、梯度、采样与评估都变得困难。本章讨论：为什么难（18.1）、对数似然梯度（18.2）、随机最大似然与对比散度（18.3）、伪似然/比率匹配/得分匹配（18.4）、噪声对比估计（18.5）、配分函数估计（18.6），最后讨论生成模型的似然比较（18.7）。

**学习目标**：完成本章学习后，你应当能够：

- 写出能量模型的配分函数与对数似然梯度；
- 解释正相/负相，说明 MCMC 负相为何昂贵；
- 比较 CD、持续 CD、伪似然、得分匹配、NCE 的偏差与成本；
- 用 AIS/桥接采样估计配分函数比；
- 说明“对数似然不可比”对生成模型评估的影响；
- 根据模型与数据规模选择训练/评估策略。

**预备知识**：第 16 章的 RBM/能量模型、第 17 章的 MCMC 与重要性采样、第 3 章的 KL 与最大似然。

---

## 18.1 配分函数为什么难

**定义**：

$$p(x) = \frac{1}{Z}\exp\big(-E(x)\big),\qquad Z = \sum_x \exp\big(-E(x)\big)$$

（连续情形为积分）。$Z$ 是**所有可能状态**的指数和。

**难点**：

- 状态数随维度指数增长（$2^d$ 或更多）；
- 能量函数高度非线性，无法解析积分；
- $Z$ 的数值范围可能极大，直接计算上溢/下溢；
- 许多模型只给出未归一化密度，$Z$ 恰好是训练与评估的关键。

**为什么不能忽略 $Z$**：

- 最大似然需要 $\log Z$；
- 比较不同模型的似然需要各自的 $Z$；
- 采样需要知道相对概率，虽然 MCMC 可绕过 $Z$，但训练负相仍需模型样本；
- 评估生成质量时，$Z$ 决定概率的绝对尺度。

**一个直觉**：$Z$ 是“所有可能世界的总权重”。高维空间中，绝大多数状态能量很高、权重极小，但数量巨大；$Z$ 由少数低能量状态与海量高能量状态共同决定，难以用朴素采样估计。

## 18.2 对数似然的梯度

对单个样本 $x$，

$$\log p(x) = -E(x) - \log Z.$$

**梯度**：

$$\frac{\partial\log p(x)}{\partial\theta} = -\frac{\partial E(x)}{\partial\theta} + \mathbb{E}_{x'\sim p_\text{model}}\left[\frac{\partial E(x')}{\partial\theta}\right].$$

推导用到

$$\frac{\partial\log Z}{\partial\theta} = -\mathbb{E}_{p_\text{model}}\left[\frac{\partial E}{\partial\theta}\right].$$

**正相与负相**：

- **正相（positive phase）**：用数据样本 $x$ 降低能量；
- **负相（negative phase）**：用模型样本 $x'$ 提高能量，防止模型把所有状态都压到低能量。

**RBM 的例子**：

$$E(v,h) = -b^\top v - c^\top h - v^\top W h,$$

$$\frac{\partial E}{\partial W} = -v h^\top,$$

$$\frac{\partial\log p(v)}{\partial W} = \mathbb{E}_{p_\text{data}}[v h^\top] - \mathbb{E}_{p_\text{model}}[v h^\top].$$

第一项用数据与条件期望易算；第二项需要从模型分布采样。

**核心困难**：负相需要“模型当前认为可能”的样本。训练初期模型很差，样本质量低；训练后期模型接近数据，MCMC 混合可能变慢。负相的方差与偏差直接决定训练质量。

## 18.3 随机最大似然与对比散度

**随机最大似然（SML）/持续对比散度（PCD）**：维护一条持续运行的 Gibbs 链，每次更新从上次状态继续，而不是从数据重新初始化。

- 优点：链更接近模型分布，负相偏差小；
- 缺点：需要保存链状态；链可能“遗忘”某些模式；训练与采样耦合。

**对比散度（CD-$k$）**：从数据初始化链，跑 $k$ 步 Gibbs，得到“重构”样本，用它近似负相。

```
v0 = data
for t = 1..k:
    h_t ~ p(h | v_{t-1})
    v_t ~ p(v | h_t)
gradient ≈ E_data[v h^T] - v_k h_k^T
```

- $k=1$ 很常用，计算便宜；
- CD 不是最大似然的梯度（它最小化的是数据分布与 $k$ 步链分布之间的差异），但在 RBM 上效果不错；
- CD 的偏差随 $k$ 增大而减小；$k\to\infty$ 时趋于 SML。

**持续 CD 的技巧**：

- 用 **fast weights** 或 **temperature** 帮助混合；
- 并行回火/退火采样；
- 链的初始化与数据混合；
- 监控链的能量与样本质量。

**CD 的局限**：

- 高维、多峰时混合差；
- 学习率大时不稳定；
- 对某些模型（如 DBM）效果有限，需要更精细的推断。

## 18.4 伪似然、比率匹配与得分匹配

**伪似然（pseudolikelihood）**：用条件概率的乘积替代联合概率：

$$\mathcal{L}_\text{PL} = \sum_{i=1}^{d}\log p(x_i\mid x_{-i}) = \sum_i\left[-E(x)-\log\sum_{x_i'}\exp(-E(x_{-i},x_i'))\right].$$

- 条件概率只需对单个变量求和，计算可行；
- 伪似然估计是一致的（在正则条件下），但**不是**最大似然，方差通常更大；
- 对二值 RBM，条件概率是 sigmoid，计算很方便；
- 缺点：忽略了变量间的联合依赖，可能学到不同的参数。

**比率匹配（ratio matching）**：对离散数据，匹配模型在“翻转一个变量”前后的概率比。由于比值可写成能量差，损失只依赖 $E(x)-E(x^{(i)})$，不需要 $Z$；它适合二值/离散能量模型，其中 $x^{(i)}$ 表示翻转第 $i$ 位。

**得分匹配（score matching）**：

$$J(\theta) = \mathbb{E}_{p_\text{data}}\left[\operatorname{tr}\left(\nabla_x s_\theta(x)\right) + \frac12\|s_\theta(x)\|_2^2\right],\qquad s_\theta(x)=\nabla_x\log p_\theta(x).$$

- 只依赖 score，不需要 $Z$；
- 需要计算雅可比的迹（Hutchinson 估计可近似）；
- 对连续数据、扩散模型特别重要（第 20 章、附录 A.5）；
- 对离散数据需用比率匹配等变体。

**三种方法的比较**：

| 方法 | 需要 $Z$ | 偏差 | 计算 | 适用 |
| --- | --- | --- | --- | --- |
| MLE + MCMC | 否（但需采样） | 渐近无偏 | 高 | 小模型、RBM |
| CD | 否 | 有偏 | 中 | RBM/能量模型 |
| 伪似然 | 否 | 一致但有偏（有限样本） | 低 | 离散/条件易算 |
| 得分匹配 | 否 | 一致 | 中 | 连续、扩散 |
| NCE | 否 | 一致（噪声足够） | 中 | 大模型、文本 |

## 18.5 噪声对比估计

**NCE** 把“密度估计”转化为“二分类”：区分数据样本与噪声样本。

设噪声分布 $p_n(x)$，模型 $p_\theta(x)=e^{-E(x)}/Z$。训练一个判别器

$$D(x) = \frac{p_\theta(x)}{p_\theta(x)+p_n(x)},$$

对数损失：

$$\mathcal{L} = -\mathbb{E}_{x\sim p_\text{data}}\log D(x) - \mathbb{E}_{x\sim p_n}\log(1-D(x)).$$

把 $p_\theta(x)/p_n(x)=e^{-E(x)}/(Z p_n(x))$ 代入，得到

$$D(x) = \sigma\big(-E(x) - \log Z - \log p_n(x)\big).$$

$\log Z$ 可以作为一个可学习偏置（或只估计密度比而忽略其绝对校准）；关键是训练只需要未归一化能量与噪声密度，不需要对 $Z$ 做求和。

**关键**：NCE 估计的是**密度比**，不是绝对密度；若噪声分布已知且覆盖数据，$Z$ 可由密度比恢复。实践中常把 $\log Z$ 作为可学习参数，或只关心相对概率。

**优点**：

- 不需要 MCMC；
- 训练稳定，适合大模型；
- 噪声分布可设计（如 unigram、混合噪声）。

**缺点**：

- 噪声分布选择影响方差与可辨识性；
- 需要负采样，计算随负样本数增长；
- 对高维/结构化数据，噪声可能太容易区分。

**应用**：word2vec 的负采样、语言模型的 NCE、能量模型的训练、对比学习（InfoNCE 是 NCE 的变体）。

## 18.6 配分函数的估计

**目标**：估计 $Z_1/Z_0$（两个分布的配分函数比），或 $\log Z$。

**退火重要性采样（AIS）**：

1. 定义中间分布 $p_{\beta_k}\propto p_0^{1-\beta_k}p_1^{\beta_k}$，$0=\beta_0<\dots<\beta_K=1$；
2. 从 $p_0$ 采样 $x_0$；
3. 对每个 $\beta_k$，用 MCMC 转移核 $T_k$ 不变 $p_{\beta_k}$，从 $x_{k-1}$ 采样 $x_k$；
4. 累积权重：

$$w = \prod_{k=1}^{K}\frac{\tilde p_{\beta_k}(x_{k-1})}{\tilde p_{\beta_{k-1}}(x_{k-1})}.$$

则 $\mathbb{E}[w]=Z_1/Z_0$。多次运行取平均，用 log-sum-exp 稳定计算 $\log(Z_1/Z_0)$。

**直觉**：从简单的 $p_0$（如先验/高斯）逐步“退火”到复杂的 $p_1$（模型），每一步只差一点，重要性权重不会退化。

**桥接采样（bridge sampling）**：利用两个分布的重叠区域估计比值：

$$\frac{Z_1}{Z_0} = \frac{\mathbb{E}_{p_0}[p_1(x)\alpha(x)]}{\mathbb{E}_{p_1}[p_0(x)\alpha(x)]},$$

其中 $\alpha$ 是桥接函数。最优桥接可降低方差。

**反向 AIS**：从 $p_1$ 退火回 $p_0$，得到另一个估计；正向与反向估计的差异可用于诊断，也可构造 $\log Z$ 的上下界。

**其他方法**：

| 方法 | 思路 |
| --- | --- |
| 简单重要性采样 | 从 $p_0$ 直接采样，估计 $Z_1/Z_0$ |
| 热力学积分 | $\log Z_1-\log Z_0=\int \mathbb{E}_{p_\beta}[-\Delta E]\,d\beta$ |
| 变分上界 | 用变分分布构造 $\log Z$ 的界 |
| 平均场 | 快速但偏差大 |
| 精确计算 | 小规模/树结构/低树宽 |

**对数域的坑**：$\log \mathbb{E}[w] \ne \mathbb{E}[\log w]$。AIS 的无偏性是针对 $w$ 的，$\log$ 平均是有偏的；报告时应说明估计的是 $Z$ 还是 $\log Z$，并使用反向估计/多链诊断。

## 18.7 生成模型的似然比较

**为什么似然比较难**：

- 不同模型的定义域/预处理不同（像素 vs 量化 token）；
- 连续模型的对数似然可任意大（密度可尖）；
- 离散模型可用 bits/dim 比较，但 tokenizer 影响大；
- 近似似然（变分下界、AIS）有偏差/方差；
- 似然高不一定样本质量好（VAE vs GAN 的经典对比）。

**统一指标**：

- **离散数据**：bits per dimension（bpd）= $-\log_2 p(x)/d$；
- **连续数据**：需固定量化/噪声模型，否则不可比；
- **生成质量**：FID、IS、CLIPScore、人工评估；
- **多样性**：召回率、覆盖度、模式计数；
- **下游可用性**：用生成样本训练分类器的收益。

**实践建议**：

1. 在同一数据预处理、同一 tokenizer 下比较；
2. 报告似然的估计方法与方差（AIS 的 $k$、桥接函数）；
3. 不要跨模型族直接比较“似然”；
4. 结合样本质量、多样性与下游任务；
5. 对小模型/低维数据，用精确 $Z$ 校验近似方法。

**一句话总结**：配分函数是能量模型的“归一化税”；MCMC 负相、CD、伪似然、得分匹配、NCE 是五种“避税”方式，各有偏差与成本；AIS/桥接采样用于估计 $Z$，但似然比较必须谨慎。

## 本章小结

**核心要点**

1. 配分函数 $Z$ 是对所有状态的指数和，高维下不可精确计算；它影响似然、梯度、采样与评估。
2. 对数似然梯度 = 正相（数据降能量）- 负相（模型样本升能量）；负相是核心困难。
3. SML/PCD 用持续 MCMC 链近似负相；CD-$k$ 用数据初始化短链，便宜但有偏。
4. 伪似然用条件概率乘积避开 $Z$，一致但方差大；比率匹配适合离散数据；得分匹配适合连续数据与扩散模型。
5. NCE 把密度估计变成“数据 vs 噪声”的二分类，估计密度比，训练稳定。
6. AIS 通过退火路径估计 $Z_1/Z_0$；桥接采样与反向 AIS 可降低方差/诊断。
7. 生成模型的似然比较需统一定义域、预处理与估计方法；似然高不等于样本好。
