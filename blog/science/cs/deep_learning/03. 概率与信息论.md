# 第 3 章 概率与信息论（Probability and Information Theory）

**本章导读**：深度学习处理的是**不确定性**：数据有噪声、标签有歧义、模型参数未知、预测需要置信度。概率论给出“如何表示不确定性”，信息论给出“如何度量信息与差异”。本章覆盖随机变量与分布（3.1–3.2）、贝叶斯法则与条件独立（3.3）、结构化概率模型（3.4）、熵与 KL（3.5），最后说明这些工具在损失函数、生成模型与表示学习中的角色（3.6）。

**学习目标**：完成本章学习后，你应当能够：

- 区分 pmf、pdf、联合分布、边缘分布与条件分布；
- 熟练使用贝叶斯法则、链式法则与条件独立；
- 写出常见分布并说明其适用场景；
- 计算期望、方差、协方差与相关系数；
- 用有向图/无向图表示概率模型的因子分解；
- 计算熵、交叉熵、KL 散度与互信息，并解释其非负性；
- 说明最大似然、交叉熵损失与 KL 最小化的等价关系。

**预备知识**：微积分（积分、偏导）、第 2 章的向量与矩阵记号；排列组合基础。

## 3.1 随机变量与概率分布

**随机变量**是把随机试验的结果映射到数值的函数。离散随机变量取有限或可数多个值，用**概率质量函数（pmf）**描述：

$$P(X = x) = p(x),\qquad \sum_x p(x) = 1.$$

连续随机变量用**概率密度函数（pdf）**描述：

$$P(a \le X \le b) = \int_a^b p(x)\,dx,\qquad \int_{-\infty}^{\infty} p(x)\,dx = 1.$$

注意 pdf 的值可以大于 1，只有积分才代表概率。

**联合分布** $p(x,y)$ 描述多个变量的联合行为；**边缘分布**通过对其他变量求和/积分得到：

$$p(x) = \sum_y p(x,y) \quad \text{或} \quad p(x) = \int p(x,y)\,dy.$$

**条件分布**：

$$p(y\mid x) = \frac{p(x,y)}{p(x)},\qquad p(x) > 0.$$

**链式法则**：

$$p(x_1,\dots,x_n) = p(x_1)\prod_{i=2}^{n} p(x_i \mid x_1,\dots,x_{i-1}).$$

这是自回归模型（语言模型、PixelCNN）的数学基础：把高维联合分布拆成一系列条件分布。

**独立与条件独立**：

- 独立：$p(x,y) = p(x)p(y)$，等价于 $p(y\mid x) = p(y)$；
- 条件独立：给定 $z$ 时 $p(x,y\mid z) = p(x\mid z)p(y\mid z)$。

条件独立比独立更常见，也是图模型能把高维分布拆成小因子的关键。

**期望、方差与协方差**：

$$\mathbb{E}[X] = \sum_x x\,p(x) \quad \text{或} \quad \int x\,p(x)\,dx,$$

$$\operatorname{Var}(X) = \mathbb{E}\big[(X - \mathbb{E}[X])^2\big] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2,$$

$$\operatorname{Cov}(X,Y) = \mathbb{E}\big[(X-\mathbb{E}X)(Y-\mathbb{E}Y)\big].$$

**协方差矩阵** $\Sigma$ 的对角线是各维方差，非对角线是协方差。相关系数 $\rho = \operatorname{Cov}(X,Y)/(\sigma_X\sigma_Y) \in [-1,1]$ 只刻画**线性**相关。

**期望的线性性**：$\mathbb{E}[aX + bY] = a\mathbb{E}[X] + b\mathbb{E}[Y]$，**不要求独立**。但 $\operatorname{Var}(X+Y) = \operatorname{Var}(X) + \operatorname{Var}(Y) + 2\operatorname{Cov}(X,Y)$，独立时协方差项为零。

## 3.2 常用概率分布

| 分布 | 记号 | 取值 | 用途 |
| --- | --- | --- | --- |
| 伯努利 | $\mathrm{Bern}(p)$ | $\{0,1\}$ | 二分类、丢弃掩码 |
| 类别 | $\mathrm{Cat}(\boldsymbol p)$ | $\{1,\dots,K\}$ | 多分类、词表分布 |
| 多项 | $\mathrm{Mult}(n,\boldsymbol p)$ | 计数向量 | 词频、骰子 |
| 均匀 | $U(a,b)$ | $[a,b]$ | 初始化、先验 |
| 正态 | $\mathcal{N}(\mu,\sigma^2)$ | $\mathbb{R}$ | 噪声、权重先验、VAE |
| 多元正态 | $\mathcal{N}(\boldsymbol\mu,\Sigma)$ | $\mathbb{R}^d$ | 特征建模、高斯混合 |
| 指数 | $\mathrm{Exp}(\lambda)$ | $[0,\infty)$ | 等待时间、稀疏先验 |
| 拉普拉斯 | $\mathrm{Laplace}(\mu,b)$ | $\mathbb{R}$ | $L_1$ 正则、稀疏 |
| Dirac | $\delta(x-\mu)$ | 点质量 | 经验分布、硬标签 |
| 经验分布 | $\hat p$ | 训练集 | 用样本近似真实分布 |

**伯努利与类别分布**：

$$\mathrm{Bern}(x;p) = p^x(1-p)^{1-x},\qquad \mathrm{Cat}(x;\boldsymbol p) = \prod_{k=1}^{K} p_k^{[x=k]}.$$

**正态分布**：

$$\mathcal{N}(x;\mu,\sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).$$

多元形式：

$$\mathcal{N}(\boldsymbol x;\boldsymbol\mu,\Sigma) = \frac{1}{(2\pi)^{d/2}\lvert\Sigma\rvert^{1/2}}\exp\left(-\frac12(\boldsymbol x-\boldsymbol\mu)^\top\Sigma^{-1}(\boldsymbol x-\boldsymbol\mu)\right).$$

**为什么正态无处不在**：中心极限定理说明大量独立微小随机因素之和趋近正态；最大熵原理说明在给定均值与方差时，正态是熵最大的分布。这两个性质使它成为默认噪声模型与先验。

**混合分布**：若 $p(x) = \sum_{k} \pi_k p_k(x)$，其中 $\pi_k \ge 0$、$\sum_k \pi_k = 1$，则称混合分布。高斯混合（GMM）可以逼近任意平滑密度，是聚类与密度估计的经典工具（第 19 章 EM）。

**sigmoid 与 softmax**：

$$\sigma(z) = \frac{1}{1+e^{-z}},\qquad \operatorname{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}.$$

sigmoid 把实数压到 $(0,1)$，softmax 把向量变成概率单纯形。它们分别是二分类与多分类的**归一化**工具，也是概率模型与神经网络输出层的接口。

**数值稳定**：直接计算 $e^{z_i}$ 可能上溢；实现时先减去最大值：

$$\operatorname{softmax}(z)_i = \frac{e^{z_i - \max_j z_j}}{\sum_j e^{z_j - \max_j z_j}}.$$

## 3.3 贝叶斯法则与条件独立

**贝叶斯法则**：

$$P(H \mid E) = \frac{P(E \mid H)P(H)}{P(E)}.$$

- $P(H)$ 是先验，$P(E\mid H)$ 是似然，$P(H\mid E)$ 是后验，$P(E)$ 是证据（归一化常数）。

**一个医学检验的例子**：某病患病率 1%，检验灵敏度和特异度都为 99%。若检验阳性，患病概率并非 99%，而是

$$P(D\mid +) = \frac{0.99\times0.01}{0.99\times0.01 + 0.01\times0.99} = 0.5.$$

**基率（base rate）** 被忽略是常见的认知偏差，也是模型评估中“类别不平衡”问题的根源。

**贝叶斯法则的深度学习用法**：

- **贝叶斯参数估计**：$p(\theta\mid D) \propto p(D\mid\theta)p(\theta)$，先验对应正则化；
- **贝叶斯神经网络**：对权重设分布，预测时对后验积分，给出不确定度；
- **生成模型**：$p(z\mid x) \propto p(x\mid z)p(z)$，是 VAE 编码器的目标；
- **朴素贝叶斯**：假设特征在类别下条件独立，把联合分布拆成乘积。

**条件独立的图语言**：若 $p(a,b\mid c) = p(a\mid c)p(b\mid c)$，记作 $a \perp b \mid c$。图模型用“路径是否被阻断”来判断条件独立（第 16 章）。

**独立与不相关**：独立 ⇒ 不相关，但反之不成立。$X\sim U(-1,1)$、$Y=X^2$ 时 $\operatorname{Cov}(X,Y)=0$，但 $Y$ 完全由 $X$ 决定。深度学习中的“解耦表示”追求的是统计独立，而不只是去相关。

## 3.4 结构化概率模型

当变量很多时，直接建模联合分布 $p(x_1,\dots,x_n)$ 需要指数级参数。**结构化概率模型**利用条件独立，把联合分布分解为少量因子的乘积。

**有向图模型（贝叶斯网络）**：

$$p(x_1,\dots,x_n) = \prod_{i=1}^{n} p\big(x_i \mid \mathrm{Pa}(x_i)\big),$$

其中 $\mathrm{Pa}(x_i)$ 是节点 $i$ 的父节点。例如：

```
天气 → 草地湿
天气 → 洒水器 → 草地湿
```

联合分布为 $p(W,S,G) = p(W)p(S\mid W)p(G\mid W,S)$。给定 $W$ 时，$S$ 与 $G$ 的条件独立性由图的“d-分离”判定。

**无向图模型（马尔可夫随机场）**：

$$p(x) = \frac{1}{Z}\prod_{c\in\mathcal{C}} \phi_c(x_c),$$

其中 $\mathcal{C}$ 是团（clique），$\phi_c$ 是非负势函数，$Z = \sum_x \prod_c \phi_c(x_c)$ 是**配分函数**（第 18 章）。无向图适合建模对称关系：图像像素、社交网络、词共现。

**因子图**：用方形因子节点显式表示每个 $\phi_c$，是信念传播与变量消元的自然表示。

**深度学习中为什么需要图模型**：

- 为生成模型提供**因子分解**的假设，控制参数量与推断复杂度；
- 明确变量间的条件独立，便于设计采样与近似推断；
- 解释 RBM、DBN、CRF 等模型的结构（第 16 章）。

## 3.5 信息论：熵、KL 与互信息

**自信息**：事件 $x$ 发生带来的“惊讶程度”为 $-\log p(x)$。概率越小，信息量越大。

**熵（entropy）**：随机变量不确定性的期望度量：

$$H(X) = -\sum_x p(x)\log p(x) = \mathbb{E}_{x\sim p}[-\log p(x)].$$

- 底为 2 时单位是 bit，底为 $e$ 时是 nat；
- 均匀分布熵最大；确定性分布熵为 0；
- 对连续变量，微分熵可为负，且依赖坐标尺度。

**联合熵与条件熵**：

$$H(X,Y) = H(X) + H(Y\mid X),\qquad H(Y\mid X) = -\sum_{x,y}p(x,y)\log p(y\mid x).$$

**KL 散度**：衡量两个分布的差异：

$$\mathrm{KL}(p\,\|\,q) = \sum_x p(x)\log\frac{p(x)}{q(x)} = \mathbb{E}_{x\sim p}\left[\log\frac{p(x)}{q(x)}\right].$$

性质：

- 非负：$\mathrm{KL}(p\|q) \ge 0$，当且仅当 $p=q$（几乎处处）取 0；
- **不对称**：$\mathrm{KL}(p\|q) \ne \mathrm{KL}(q\|p)$，因此不是距离；
- 前向 KL（$p\|q$）倾向覆盖 $p$ 的所有模式（mass-covering）；反向 KL（$q\|p$）倾向锁定单个模式（mode-seeking）。这解释了变分推断与生成模型的许多行为。

**交叉熵**：

$$H(p,q) = -\sum_x p(x)\log q(x) = H(p) + \mathrm{KL}(p\|q).$$

当 $p$ 是数据分布、$q_\theta$ 是模型分布时，最小化交叉熵等价于最小化 KL，也等价于最大似然：

$$\hat\theta = \arg\min_\theta H(\hat p, p_\theta) = \arg\max_\theta \sum_i \log p_\theta(x_i).$$

**互信息**：

$$I(X;Y) = \mathrm{KL}\big(p(x,y)\,\|\,p(x)p(y)\big) = H(X) - H(X\mid Y) = H(Y) - H(Y\mid X).$$

它衡量“知道 $Y$ 后对 $X$ 的不确定性减少多少”，是非负的，且在独立时为 0。互信息常用于表示学习（InfoMax、对比学习）、特征选择与解耦。

**困惑度（perplexity）**：语言模型常用指标：

$$\mathrm{PPL} = \exp\left(-\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(x_i\mid x_{<i})\right) = \exp(H).$$

直观上，困惑度是“模型平均在多少个等概率选项之间犹豫”。它依赖词表与分词方式，跨模型比较时需谨慎。

**Jensen 不等式**：对凸函数 $f$，$\mathbb{E}[f(X)] \ge f(\mathbb{E}[X])$。它是证明 KL 非负、EM 单调性、变分下界（ELBO）的核心工具。

## 3.6 信息论在深度学习中的角色

| 场景 | 用到的量 | 说明 |
| --- | --- | --- |
| 分类损失 | 交叉熵 | 等价于负对数似然 |
| 语言模型 | 交叉熵 / 困惑度 | 下一 token 预测 |
| 变分自编码器 | ELBO 中的 KL | 后验接近先验 |
| 对比学习 | 互信息下界（InfoNCE） | 拉近正样本、推远负样本 |
| 知识蒸馏 | 前向 KL / 交叉熵 | 学生拟合教师软标签 |
| 标签平滑 | 交叉熵 + 均匀分布混合 | 防止过度自信 |
| 强化学习 | 策略熵 | 鼓励探索 |
| 表示解耦 | 互信息、总相关 | 减少冗余 |

**标签平滑**：把 one-hot 目标 $p$ 换成 $(1-\epsilon)p + \epsilon/K$，等价于在交叉熵中加入一个常数偏置，抑制模型对训练标签的过度自信。它不是“更好的概率校准”，而是一种正则化。

**温度（temperature）**：对 logits 除以 $T$ 再 softmax。$T>1$ 让分布更平滑（知识蒸馏中的软标签），$T<1$ 让分布更尖锐（采样时更保守）。

**KL 的两个方向**：

- $\mathrm{KL}(p_\text{data}\|p_\theta)$：最大似然的方向，要求模型覆盖数据的所有模式；
- $\mathrm{KL}(p_\theta\|p_\text{data})$：变分推断中常见，倾向让模型集中在少数模式。

理解这一点，就能解释为什么 VAE 的生成样本偏模糊（覆盖模式）、GAN 容易模式崩塌（锁定模式）、强化学习中的熵正则鼓励探索。

## 本章小结

**核心要点**

1. 概率分布描述不确定性；联合、边缘、条件分布由链式法则与贝叶斯法则联系。
2. **条件独立**是图模型与深度生成模型控制复杂度的核心假设。
3. 常见分布中，伯努利/类别对应分类，正态对应回归与噪声，拉普拉斯对应稀疏先验。
4. **熵**度量不确定性，**KL** 度量分布差异且不对称，**交叉熵**是分类与语言模型的标准损失。
5. 最小化交叉熵 = 最小化 KL = 最大似然；先验对应正则化，后验对应贝叶斯推断。
6. 互信息衡量依赖程度，是表示学习、对比学习与解耦的目标；困惑度是语言模型的熵的指数形式。
7. KL 的方向决定模型行为：前向 KL 覆盖模式，反向 KL 锁定模式。
