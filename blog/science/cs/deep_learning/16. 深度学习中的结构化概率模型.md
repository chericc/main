# 第 16 章 深度学习中的结构化概率模型（Structured Probabilistic Models for Deep Learning）

**本章导读**：深度网络可以看作“函数逼近器”，也可以看作“概率模型”。当数据有明确结构（像素网格、序列、图、多变量依赖）时，用**图**描述变量间的条件独立，可以把高维联合分布拆成小因子，降低参数与推断成本。本章讨论：图模型的语言（16.1）、条件独立（16.2）、采样（16.3）、受限玻尔兹曼机（16.4）、深度信念网络与深度玻尔兹曼机（16.5）、结构化输出与 CRF（16.6），最后总结深图模型的核心难题（16.7）。

**学习目标**：完成本章学习后，你应当能够：

- 用有向图/无向图/因子图表示联合分布；
- 用 d-分离判断条件独立，写出马尔可夫毯；
- 从图模型做祖先采样与 Gibbs 采样；
- 写出 RBM 的能量函数、条件分布与自由能；
- 区分 DBN、DBM 与 RBM 的结构与训练；
- 写出线性链 CRF 的似然与 Viterbi 解码；
- 解释配分函数与推断为何是深图模型的核心难题。

**预备知识**：第 3 章的概率与图模型初步、第 6 章的前馈网络、第 14 章的自编码器；第 17–19 章会深入采样与推断。

## 16.1 用图描述概率模型

**有向图模型（贝叶斯网络）**：

$$p(x_1,\dots,x_n) = \prod_{i=1}^{n} p\big(x_i \mid \mathrm{Pa}(x_i)\big),$$

其中 $\mathrm{Pa}(x_i)$ 是父节点。边表示“直接影响”，联合分布自动归一化（每个条件分布都是概率分布）。

**无向图模型（马尔可夫随机场，MRF）**：

$$p(x) = \frac{1}{Z}\prod_{c\in\mathcal{C}}\phi_c(x_c),\qquad Z = \sum_x\prod_{c\in\mathcal{C}}\phi_c(x_c),$$

其中 $\mathcal{C}$ 是团（clique），$\phi_c\ge0$ 是势函数，$Z$ 是**配分函数**。无向图适合对称关系：图像像素、空间统计、词共现。

**因子图**：用方形因子节点显式表示每个 $\phi_c$，变量节点与因子节点相连。它比普通无向图更细，便于描述推断算法（信念传播、变量消元）。

**能量模型**：令 $\phi_c(x_c)=\exp(-E_c(x_c))$，则

$$p(x) = \frac{1}{Z}\exp\big(-E(x)\big).$$

能量越低，概率越高。RBM、DBM、Ising 模型都是能量模型。

**例子：图像去噪**。像素 $x_i$ 的观测为 $y_i$，先验用 MRF 鼓励相邻像素相似：

$$p(x\mid y) \propto \exp\left(\sum_i \psi_i(x_i,y_i) + \sum_{(i,j)\in\mathcal{E}}\phi_{ij}(x_i,x_j)\right).$$

这是图像分割/去噪的经典模型（如 Potts 模型）。

## 16.2 条件独立与图的结构

**d-分离**：在有向图中，若从 $A$ 到 $B$ 的所有路径都被 $C$ 阻断，则 $A\perp B\mid C$。路径被阻断的规则：

- **链式** $A\to C\to B$：观测 $C$ 阻断；
- **分叉** $A\leftarrow C\to B$：观测 $C$ 阻断；
- **对撞** $A\to C\leftarrow B$：不观测 $C$ 时阻断；观测 $C$ **打开**路径（explaining away）。

**对撞的直觉**：如果“草地湿”由“下雨”或“洒水器”导致，观测到草地湿后，下雨与洒水器变得**负相关**（一个原因成立会降低另一个的概率）。这就是“解释消除”。

**马尔可夫毯（Markov blanket）**：节点 $x_i$ 的马尔可夫毯是使其与其余节点条件独立的最小集合：

- 有向图：父节点、子节点、子节点的其他父节点；
- 无向图：邻居节点。

**应用**：Gibbs 采样只需按马尔可夫毯更新；特征选择、因果发现、模型简化都依赖条件独立。

**图结构与参数复杂度**：全连接图有指数级团，参数爆炸；稀疏图（链、树、网格）参数少、推断高效。深度图模型通常在“表达力”与“可推断性”之间折中。

## 16.3 从图模型采样

**祖先采样（有向图）**：按拓扑顺序，从根节点开始，依次从 $p(x_i\mid \mathrm{Pa}(x_i))$ 采样。它精确、高效，但只适用于有向图。

**无向图的采样**：没有天然的拓扑顺序，通常用 MCMC：

- **Gibbs 采样**：固定其他变量，从条件分布 $p(x_i\mid x_{-i})$ 采样；
- **块 Gibbs**：一次更新一组变量；
- **Metropolis–Hastings**：从提议分布采样，按接受率接受/拒绝。

**未归一化分布**：图模型通常只给出 $\tilde p(x)=\prod_c\phi_c(x_c)$，采样与推断只需比值 $\tilde p(x)/\tilde p(x')$，配分函数 $Z$ 会约掉。这是 MCMC 在能量模型中广泛使用的原因。

**采样与学习**：RBM/DBM 的训练需要从模型分布采样估计梯度（正相/负相），但精确采样不可行，常用 CD、持续对比散度、温度退火（第 18 章）。

## 16.4 玻尔兹曼机与受限玻尔兹曼机

**玻尔兹曼机（BM）**：可见层 $v$ 与隐藏层 $h$ 全连接（包括层内），能量

$$E(v,h) = -b^\top v - c^\top h - v^\top W h - \frac12 v^\top L v - \frac12 h^\top R h.$$

层内连接使条件分布复杂，推断困难。

**受限玻尔兹曼机（RBM）**：去掉层内连接，能量

$$E(v,h) = -b^\top v - c^\top h - v^\top W h.$$

**条件分布**（二值单元）：

$$p(h_j=1\mid v) = \sigma\left(c_j + \sum_i W_{ij}v_i\right),$$

$$p(v_i=1\mid h) = \sigma\left(b_i + \sum_j W_{ij}h_j\right).$$

**关键性质**：给定可见层，隐藏单元**条件独立**；给定隐藏层，可见单元条件独立。因此可以块采样，训练效率高。

**边缘分布**：

$$p(v) = \frac{1}{Z}\exp\big(-F(v)\big),$$

$$F(v) = -b^\top v - \sum_j \log\left(1+\exp\left(c_j + \sum_i W_{ij}v_i\right)\right).$$

$F(v)$ 是**自由能**，$Z=\sum_v e^{-F(v)}$。

**训练**：对数似然梯度

$$\frac{\partial\log p(v)}{\partial W} = \mathbb{E}_{p_\text{data}}[v h^\top] - \mathbb{E}_{p_\text{model}}[v h^\top].$$

第一项（正相）易算；第二项（负相）需从模型采样。**对比散度（CD-$k$）** 用数据初始化 Gibbs 链，跑 $k$ 步近似负相。CD 不是真正的最大似然梯度，但在实践中有效（第 18 章）。

**RBM 的用途**：二值特征学习、协同过滤、深度信念网络的积木、能量模型的教学范例。

## 16.5 深度信念网络与深度玻尔兹曼机

**深度信念网络（DBN）**：多层随机隐变量。典型结构是“顶层无向 RBM + 下层有向生成”：

```
v ← h1 ← h2 ← ... ← hL（有向，自上而下生成）
顶层 hL-1 ↔ hL 为 RBM
```

**训练**：逐层贪心预训练（每层 RBM），再整体微调。预训练提供了好的生成式初始化，是 2006 年深度学习复兴的关键。

**深度玻尔兹曼机（DBM）**：所有层都是无向的，能量

$$E(v,h^{(1)},\dots,h^{(L)}) = -v^\top W^{(1)}h^{(1)} - \sum_{l=1}^{L-1} h^{(l)\top}W^{(l+1)}h^{(l+1)} - \text{bias}.$$

**特点**：

- 表达力强，可学习层次化表示；
- 推断与训练都比 DBN 难（需要更复杂的 MCMC/变分）；
- 成功训练需要大量技巧（贪婪预训练、持续 CD、并行回火）。

**DBN vs DBM**：

| 维度 | DBN | DBM |
| --- | --- | --- |
| 连接 | 顶层无向 + 下层有向 | 全无向 |
| 生成 | 自上而下 | 无向联合 |
| 训练 | 逐层 RBM + 微调 | 预训练 + 联合 |
| 推断 | 较易 | 较难 |

**历史地位**：DBN/DBM 证明了“深层生成模型可训练”，但在大规模判别任务上被 ReLU/CNN/ResNet 取代；GAN、VAE、扩散模型成为生成主流。RBM 的思想（能量、自由能、CD）仍是理解深度生成模型的重要基础。

## 16.6 结构化输出与条件随机场

**结构化预测**：输出不是单个标签，而是序列、树、图、分割掩码；输出变量之间有依赖。

**条件随机场（CRF）**：直接建模条件分布

$$p(y\mid x) = \frac{1}{Z(x)}\exp\big(\text{score}(x,y)\big),$$

其中 $Z(x)=\sum_{y'}\exp(\text{score}(x,y'))$ 只对输出求和，输入 $x$ 是给定的。

**线性链 CRF**：

$$\text{score}(x,y) = \sum_{t=1}^{T} s_t(y_t;x) + \sum_{t=1}^{T-1} T(y_t,y_{t+1}),$$

其中 $s_t$ 是位置 $t$ 的发射分数（可由 BiLSTM/Transformer 给出），$T$ 是标签转移矩阵。

**推断**：

- **边缘概率**：前向-后向算法，$O(TK^2)$；
- **最可能序列**：Viterbi 算法，$O(TK^2)$；
- **配分函数**：前向算法在对数域求和（log-sum-exp）。

**训练**：最小化负对数似然

$$L = -\log p(y\mid x) = -\,\text{score}(x,y) + \log Z(x).$$

梯度为“经验特征 - 期望特征”，需要前向-后向计算期望。

**CRF vs HMM**：HMM 是生成模型（建模 $p(x,y)$），CRF 是判别模型（建模 $p(y\mid x)$），后者不需要建模输入的分布，通常判别性能更好。

**深度结构化模型**：CNN/Transformer 提取特征 + CRF/结构化解码；也可用可微的近似推断（Gumbel-Softmax、Sinkhorn）端到端训练。

## 16.7 深图模型的核心难题

| 难题 | 说明 | 影响 |
| --- | --- | --- |
| 配分函数 | $Z$ 不可精确计算 | 似然、梯度、评估都难 |
| 推断 | 后验/边缘不可解 | 需要 MCMC/变分/BP |
| 学习 | 负相采样成本高 | CD/持续链/伪似然 |
| 表达力 vs 可推断性 | 复杂图表达强但难推断 | 结构设计折中 |
| 模式坍塌/混合 | MCMC 混合慢 | 温度退火、并行回火 |
| 评估 | 似然不可比 | 用近似似然/下游指标 |

**三条出路**：

1. **限制结构**：链、树、网格，使推断精确且高效（CRF、HMM）；
2. **近似推断**：MCMC、变分、信念传播（第 17–19 章）；
3. **避开似然**：GAN、得分匹配、扩散（第 20 章、附录 A.5）。

**深度图模型 vs 深度函数模型**：

- 函数模型（普通 NN）直接参数化 $p(y\mid x)$ 或 $f(x)$，训练简单；
- 图模型显式建模变量依赖，适合结构化输出、缺失数据、因果/不确定性；
- 现代趋势是“神经网络 + 概率图”的混合：神经网络提供柔性函数，图模型提供结构与推断。

**一句话总结**：图模型用**条件独立**把高维联合分布拆成可管理的因子；RBM/DBN/DBM 把图模型堆深，CRF 把结构输出条件化。它们的核心困难是配分函数与推断，这正是第 17–19 章的主题。

## 本章小结

**核心要点**

1. 有向图用条件分布乘积因子化，无向图用团势函数 + 配分函数因子化；因子图显式表示因子。
2. d-分离判断条件独立；对撞节点被观测会“打开”路径（解释消除）。
3. 有向图可祖先采样；无向图用 Gibbs/MCMC，配分函数在比值中约掉。
4. RBM 去掉层内连接，条件分布为 sigmoid，可用块 Gibbs 采样；训练用 CD 近似负相。
5. DBN 顶层无向、下层有向，逐层预训练 + 微调；DBM 全无向，表达强但推断难。
6. 线性链 CRF 用发射分数 + 转移矩阵建模序列输出，前向-后向/Viterbi 做推断。
7. 深图模型的核心是配分函数与推断；出路是限制结构、近似推断或避开似然。
