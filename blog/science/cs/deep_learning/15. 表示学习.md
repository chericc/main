# 第 15 章 表示学习（Representation Learning）

**本章导读**：机器学习传统上依赖人设计特征，表示学习则让模型自己学。第 1 章已经提出这个主张，本章把它展开：什么是一个“好表示”？如何通过无监督/自监督预训练得到它？如何迁移到新任务？如何评价它？本章讨论：从特征工程到表示学习（15.1）、逐层预训练（15.2）、迁移与领域自适应（15.3）、半监督与自监督（15.4）、分布式表示（15.5）、流形与自然聚类（15.6）、表示的先验（15.7），最后是评价方法（15.8）。

**学习目标**：完成本章学习后，你应当能够：

- 列出好表示的关键性质，并说明其取舍；
- 解释贪心逐层预训练的历史作用与局限；
- 区分特征提取、微调、线性探针与领域自适应；
- 说明对比学习、掩码建模、一致性正则的机制；
- 用分布式表示解释组合泛化与维度灾难的缓解；
- 描述流形假设、自然聚类假设与不变性先验；
- 设计表示学习的评估协议，避免常见偏差。

**预备知识**：第 5 章的机器学习基础、第 6 章的前馈网络、第 7 章的正则化、第 13–14 章的因子模型与自编码器；第 3 章的互信息。

## 15.1 从特征工程到表示学习

**传统流水线**：原始数据 → 人工特征（SIFT、HOG、MFCC、TF-IDF）→ 浅层模型。特征的质量决定上限，而特征设计依赖领域专家。

**表示学习**：学习映射 $h=f_\theta(x)$，使下游任务在 $h$ 上更容易。它可以是有监督的（用标签学特征），也可以是无监督/自监督的（用数据结构学特征）。

**好 representation 的性质**：

| 性质 | 含义 | 代价/风险 |
| --- | --- | --- |
| 充分性 | 保留预测所需信息 | 可能保留噪声 |
| 紧致性 | 维度低、冗余少 | 可能丢掉细节 |
| 解耦性 | 不同因素对应不同方向 | 难以定义与度量 |
| 不变性 | 对任务无关变换不敏感 | 可能丢失有用信息 |
| 可迁移性 | 多任务共享 | 负迁移 |
| 稀疏性 | 少量单元激活 | 可能不稳定 |
| 层次性 | 低层局部、高层抽象 | 训练更难 |

**没有免费的表示**：保留哪些信息、丢弃哪些信息，取决于任务。一个对分类好的表示，未必适合重建、检测或控制。因此“预训练 + 微调”需要任务匹配，迁移不总是有效。

**监督 vs 无监督表示**：

- 有监督特征通常判别性强，但依赖大量标签，且可能过拟合任务偏见；
- 无监督/自监督特征更通用，但可能保留与任务无关的变化；
- 现代范式常用“大规模自监督预训练 + 少量监督微调”。

## 15.2 贪心逐层无监督预训练

**历史背景**：2006 年前后，深层网络难以训练。Hinton 的深度信念网络（DBN）与 Bengio 的堆叠自编码器提出：**逐层无监督预训练**，再整体微调。

**做法**（以堆叠自编码器为例）：

1. 用原始数据训练第一层 AE，得到隐表示 $h^{(1)}$；
2. 把 $h^{(1)}$ 当作输入，训练第二层 AE，得到 $h^{(2)}$；
3. 重复直到第 $L$ 层；
4. 在顶层加分类器，用标签**微调**整个网络。

**为什么曾经有效**：

- 无监督预训练提供了好的初始化，缓解梯度消失；
- 逐层训练把难问题分解为多个易问题；
- 相当于一种正则化/先验。

**为什么现在不主流**：

- ReLU、BatchNorm、残差连接、更好的初始化让深层网络可以直接训练；
- 大规模标注数据与自监督预训练更有效；
- 逐层贪心不是全局最优，且训练流程复杂。

**现代对应物**：预训练 + 微调、对比学习、掩码建模。思想仍然是“先学好表示，再适配任务”，只是预训练目标从重构变成了更有效的自监督任务。

## 15.3 迁移学习与领域自适应

**迁移学习**：在源任务/源域上学习，迁移到目标任务/目标域。

| 策略 | 做法 | 数据需求 | 风险 |
| --- | --- | --- | --- |
| 特征提取 | 冻结主干，只训新头 | 少 | 源特征与目标不匹配 |
| 全量微调 | 解冻全部层，小学习率 | 中 | 灾难性遗忘、过拟合 |
| 分层微调 | 先头后逐层解冻 | 中 | 调参复杂 |
| 差分学习率 | 浅层小、深层大 | 中 | 需经验 |
| 适配器/LoRA | 只训少量新增参数 | 少 | 容量受限 |
| 领域自适应 | 对齐源/目标分布 | 无标签目标 | 对齐假设可能错 |

**分布偏移的类型**：

- **协变量偏移**：$P(x)$ 变，$P(y\mid x)$ 不变；
- **标签偏移**：$P(y)$ 变，$P(x\mid y)$ 不变；
- **概念漂移**：$P(y\mid x)$ 随时间变；
- **子群体偏移**：整体分布相似，但某些群体差异大。

**领域自适应方法**：

- **重要性加权**：用密度比 $P_\text{target}(x)/P_\text{source}(x)$ 加权源样本；
- **对抗对齐**：用域判别器迫使特征域不变（DANN）；
- **MMD/ CORAL**：最小化分布矩差异；
- **自训练/伪标签**：用目标域高置信预测训练；
- **测试时适应**：在推理时用目标域统计量更新 BN/参数。

**负迁移**：源任务与目标任务冲突时，迁移反而变差。对策：任务相似性评估、选择性共享、多任务学习中的梯度手术。

## 15.4 半监督与自监督

**半监督学习**：少量标注 + 大量未标注。常见假设：

- **平滑性**：相近样本应有相近标签；
- **聚类**：同一簇样本共享标签；
- **流形**：数据在低维流形上。

**方法**：

| 方法 | 思路 |
| --- | --- |
| 自训练 | 用模型伪标签训练自己 |
| 协同训练 | 多个视图互相标注 |
| 标签传播 | 在相似图上扩散标签 |
| 一致性正则 | 对同一输入的不同扰动给一致预测 |
| 熵最小化 | 鼓励预测尖锐 |
| 混合方法 | FixMatch、MixMatch、UDA |

**自监督学习**：从数据本身构造监督信号，不需要人工标签。

| 类型 | 目标 | 代表 |
| --- | --- | --- |
| 对比学习 | 拉近正对、推远负对 | SimCLR、MoCo、CLIP |
| 掩码建模 | 预测被遮挡部分 | BERT、MAE、Span Corruption |
| 自回归 | 预测下一项 | GPT、PixelCNN、WaveNet |
| 预测编码 | 预测未来/上下文 | CPC、BYOL |
| 前置任务 | 旋转、拼图、排序 | 早期自监督 |

**InfoNCE**：

$$\mathcal{L} = -\log\frac{\exp(\mathrm{sim}(q,k_+)/\tau)}{\sum_{j}\exp(\mathrm{sim}(q,k_j)/\tau)}.$$

它是互信息的下界（在适当条件下），因此对比学习可以理解为“最大化输入与表示之间的互信息”。

**自监督的风险**：

- **捷径解**：利用低层统计（颜色、压缩伪影）而非语义；
- **表示坍塌**：所有样本映射到同一向量（BYOL/SimSiam 用停止梯度/预测器缓解）；
- **增强设计**：增强必须保留语义，否则正对不可靠。

## 15.5 分布式表示

**核心思想**：一个概念由多个单元的组合表示，而不是一个单元对应一个概念。$n$ 个二值单元可以表示 $2^n$ 种组合，表示容量随维度**指数增长**。

**例子**：颜色可以用“色调、明度、饱和度”三个维度表示；词可以用“性别、数、时态、语义域”等潜在维度表示。每个维度不是“一个词”，而是“一个可组合的属性”。

**优势**：

- **参数效率**：不需要为每个组合单独参数；
- **组合泛化**：见过“红色汽车”和“蓝色卡车”，可以理解“红色卡车”；
- **平滑性**：相似概念在表示空间中接近，便于插值与迁移；
- **维度灾难的缓解**：高维空间中的局部变化可以由少量因素解释。

**词嵌入的几何**：$v_\text{king} - v_\text{man} + v_\text{woman} \approx v_\text{queen}$。这类类比说明嵌入空间捕捉了部分语义关系，但也暴露偏见：语料中的性别/种族刻板印象会被编码。去偏（debiasing）是重要的工程问题。

**解耦表示（disentanglement）**：希望每个潜在维度对应一个独立因素。VAE 的 $\beta$-VAE、FactorVAE、独立成分约束都在追求这一点；但“解耦”的定义与度量仍有争议，且无监督解耦在理论上需要强假设。

**分布式表示 vs 符号表示**：符号表示精确、可组合、易解释；分布式表示鲁棒、可泛化、难解释。神经符号系统试图结合两者（附录 E.5）。

## 15.6 流形假设与自然聚类

**流形假设**：真实数据（图像、语音、文本）虽然维度高，但集中在低维流形附近。例如人脸图像受姿态、光照、身份等少数因素控制，像素维度远高于内在维度。

**推论**：

- 高维空间中的“距离”不可靠，应沿流形测地线度量；
- 局部线性近似可行（切空间）；
- 表示学习的目标之一是恢复流形坐标；
- 生成模型应在流形附近生成样本，而不是填满整个空间。

**自然聚类假设**：同一类别的样本在流形上形成连通的簇，不同类别被低密度区域分开。半监督学习利用这一点：决策边界应穿过低密度区域（低密度分离）。

**切空间与不变性**：在流形上，沿切空间方向移动仍属于同一类；沿法向量移动则离开流形。收缩 AE、切空间正则、对抗训练都在利用这一几何。

**流形学习的局限**：

- 真实流形可能高度弯曲、多尺度、有孔洞；
- 估计内在维度困难；
- 流形假设不保证类别线性可分；
- 对抗样本可能位于流形外但靠近数据点。

## 15.7 表示学习的先验

表示学习不是“从零发现一切”，而是把先验编码进模型。常见先验：

| 先验 | 编码方式 | 例子 |
| --- | --- | --- |
| 平滑性 | 相似输入 → 相似表示 | 正则化、核方法 |
| 线性性 | 因素可线性组合 | PCA、词嵌入类比 |
| 稀疏性 | 少量因子激活 | 稀疏编码、$L_1$ |
| 独立性 | 因子统计独立 | ICA、解耦表示 |
| 时间连贯 | 相邻时刻表示相似 | SFA、CPC、视频自监督 |
| 空间局部性 | 邻近像素相关 | CNN |
| 平移等变 | 共享卷积核 | CNN |
| 层次组合 | 低层组部件、高层组物体 | 深层网络 |
| 因果不变性 | 跨环境不变的机制 | IRM、因果表示学习 |

**先验的取舍**：先验越强，样本效率越高，但模型偏差越大。CNN 的平移等变先验在图像上有效，在需要绝对位置的任务上可能有害；Transformer 的弱先验更通用，但需要更多数据。

**“表示学习 = 用先验换数据”**：没有先验，模型只能记忆；先验太强，模型无法拟合。深度学习工程的核心之一就是选对先验。

## 15.8 如何评价表示

**下游评估**：

| 方法 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 线性探针 | 冻结表示，训线性分类器 | 衡量线性可分性 | 忽略非线性可用性 |
| 微调 | 解冻部分/全部层 | 衡量实际任务性能 | 受调参影响 |
| 少样本 | $k$-shot 分类 | 衡量样本效率 | 方差大 |
| 检索 | 用表示做近邻检索 | 衡量语义相似性 | 依赖距离度量 |
| 生成/重建 | 从表示重建输入 | 衡量信息保留 | 与任务不一定相关 |
| 探测分类器 | 预测属性（深度、光照） | 分析表示内容 | 相关性≠因果 |

**内在指标**：

- **重构误差**：保留多少信息；
- **互信息**：表示与因素/标签的依赖；
- **稀疏性/有效维度**：表示是否紧凑；
- **解耦指标**：DCI、MIG、SAP（各有局限）；
- **稳定性**：对输入扰动/随机种子的敏感度。

**评估陷阱**：

- **信息泄漏**：探针训练用了测试数据；
- **超参数不公平**：不同表示的探针调参预算不同；
- **任务选择偏差**：只选对某表示有利的任务；
- **线性探针的局限**：线性不可分不代表表示无用；
- **单一指标**：应结合多个下游任务与切片评估。

**实践建议**：

1. 固定探针架构与调参预算；
2. 报告多个下游任务与少样本结果；
3. 检查表示的最近邻与可视化；
4. 评估分布外/切片鲁棒性；
5. 报告随机种子方差。

**一句话总结**：表示学习的目标不是“压缩”，而是**保留对任务有用的因素、丢弃无关变化**；分布式表示提供组合泛化，流形假设提供几何直觉，自监督提供数据，评估必须以下游任务为准。

## 本章小结

**核心要点**

1. 表示学习用模型替代手工特征；好表示应充分、紧致、解耦、不变、可迁移，但这些目标存在取舍。
2. 逐层无监督预训练是历史方法，现代由“大规模自监督预训练 + 微调”取代，但思想一脉相承。
3. 迁移学习有特征提取、微调、适配器/LoRA、领域自适应等策略；需警惕负迁移与灾难性遗忘。
4. 半监督利用平滑/聚类/流形假设；自监督用对比、掩码、自回归等任务构造监督信号。
5. 分布式表示用组合而非查表，带来参数效率与组合泛化；词嵌入的类比也暴露偏见。
6. 流形假设与自然聚类解释了几何结构、不变性与半监督的低密度分离。
7. 表示学习的关键是**选对先验**：局部性、平移等变、稀疏、独立、时间连贯、因果不变。
8. 评价表示应以下游任务为主，结合线性探针、微调、少样本、检索与内在指标，避免泄漏与调参偏差。
