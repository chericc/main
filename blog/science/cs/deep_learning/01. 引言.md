# 第 1 章 引言（Introduction）

**本章导读**：深度学习不是“更深的神经网络”这么简单，它的核心主张是：**表示（representation）本身可以从数据中学出来**。传统机器学习依赖人设计特征，深度学习把“特征提取器”也交给优化。本章给出全书的地图：什么是深度学习（1.1）、它从哪来（1.2）、为什么在 2010 年代爆发（1.3）、表示学习与深度为何关键（1.4）、它能做什么与不能做什么（1.5），最后说明本书的组织方式（1.6）。

**学习目标**：完成本章学习后，你应当能够：

- 说清人工智能、机器学习、表示学习与深度学习的关系；
- 用“因素（factors of variation）”解释为什么学习表示比手工特征更有扩展性；
- 概述深度学习的三次浪潮与关键节点；
- 解释数据、算力、算法与软件共同促成深度学习复兴；
- 区分深度网络的“表达力”与“可学习性”，说明万能近似的局限；
- 识别深度学习在推理、因果、数据效率、可靠性与能耗上的边界。

**预备知识**：基础线性代数（向量、矩阵乘法）、概率常识、微积分中的导数；不要求先学过机器学习。

## 1.1 什么是深度学习

**三个同心圆**：

| 层次 | 关注点 | 典型问题 |
| --- | --- | --- |
| 人工智能（AI） | 让机器表现出智能行为 | 推理、规划、感知、语言 |
| 机器学习（ML） | 从数据中自动改进性能 | 分类、回归、聚类、决策 |
| 深度学习（DL） | 用多层表示学习完成 ML 任务 | 视觉、语音、语言、生成 |

深度学习是机器学习的一个子领域，它使用**由多个层组成的可微模型**，把输入逐级变换为越来越抽象的特征表示：

$$x \;\longrightarrow\; h^{(1)} \;\longrightarrow\; h^{(2)} \;\longrightarrow \cdots \longrightarrow\; h^{(L)} \;\longrightarrow\; \hat y$$

每一层通常写作

$$h^{(l)} = g\big(W^{(l)} h^{(l-1)} + b^{(l)}\big),$$

其中 $W^{(l)}$、$b^{(l)}$ 是待学参数，$g$ 是非线性激活函数。**没有非线性**，多层复合仍然只是一个线性变换，深度就失去意义。

**与传统机器学习的分工**：

```
传统 ML：原始数据 → 人工特征 → 浅层分类器/回归器 → 输出
深度学习：原始数据 → 可学习的多层表示 → 输出
```

传统流水线中，特征工程决定模型上限；深度学习中，特征本身由数据与任务目标共同塑造。这使深度学习特别适合**感知类、高维、结构化**的问题：图像、语音、文本、视频、蛋白质序列。

**“深度”的含义**：深度指**从输入到输出经过的非线性变换层数**，而不是参数总量。一个很宽的单隐层网络参数可能更多，但它的“表示层级”只有一层。深度带来的关键是**组合性（compositionality）**：复杂函数可以由较简单的函数嵌套而成。

**一个容易混淆的点**：深度网络并不一定模仿大脑。它受神经科学启发，但现代 CNN、Transformer 的设计更多来自数学、优化与工程约束。把“人工神经网络”理解为“可微的参数化函数族”更准确。

## 1.2 深度学习的历史

深度学习经历了三次明显的浪潮，每一浪都伴随着“连接主义”与“符号主义”的争论。

| 时期 | 关键词 | 代表工作 | 兴衰原因 |
| --- | --- | --- | --- |
| 1940s–1960s | 控制论（cybernetics） | McCulloch–Pitts 神经元（1943）、感知机（1958） | 单层感知机无法解决 XOR，Minsky & Papert（1969）指出局限 |
| 1980s–1990s | 连接主义（connectionism） | 反向传播（1986）、LeNet（1989）、LSTM（1997） | 数据与算力不足，梯度消失，SVM 等方法的竞争 |
| 2006– | 深度学习 | 深度信念网络预训练（2006）、AlexNet（2012）、ResNet（2015）、Transformer（2017） | 大数据、GPU、ReLU/Dropout/BN、开源框架 |

**几个关键节点**：

- **1943**：McCulloch 与 Pitts 提出二值阈值神经元模型，把逻辑运算与神经活动联系起来；
- **1958**：Rosenblatt 的感知机用可学习的权重做线性分类，引发第一轮乐观；
- **1969**：Minsky 与 Papert 的《Perceptrons》证明单层感知机不能表示 XOR，连接主义进入低谷；
- **1986**：Rumelhart、Hinton 与 Williams 推广反向传播，多层网络第一次可以系统训练；
- **1989–1998**：LeCun 的 LeNet 用手写数字识别证明卷积网络可行；Hochreiter & Schmidhuber 提出 LSTM；
- **2006**：Hinton 等人用逐层无监督预训练（深度信念网络、自编码器）缓解深层网络的优化困难，重新点燃兴趣；
- **2012**：AlexNet 在 ImageNet 上大幅领先，GPU + ReLU + Dropout + 大数据成为范式；
- **2014–2016**：GAN、ResNet、AlphaGo；深度强化学习进入公众视野；
- **2017 以后**：Transformer、预训练语言模型、扩散模型、基础模型（详见附录 A）。

**历史给我们的三个教训**：

1. **算法、数据、算力是乘法关系**：任何一项接近零，整体都上不去；
2. **旧方法不是被“证伪”，而是被更好的工程折中取代**：SVM 仍在小数据、可解释场景有用；
3. **符号与连接不是非此即彼**：现代系统同时使用神经网络、搜索、规则与工具。

## 1.3 为什么是现在

深度学习的数学基础（反向传播、卷积、循环网络）在 1980–1990 年代就已具备，真正的爆发来自四个条件的汇合：

| 条件 | 具体变化 | 影响 |
| --- | --- | --- |
| **数据** | 互联网、ImageNet、网页文本、传感器 | 参数多也需要足够样本才能泛化 |
| **算力** | GPU、TPU、高速互联 | 矩阵乘与卷积的并行吞吐提升数个数量级 |
| **算法** | ReLU、Dropout、BatchNorm、Adam、残差连接 | 深层网络变得可训练、更稳定 |
| **软件** | Theano、Caffe、TensorFlow、PyTorch | 自动微分 + 算子库降低实现成本 |

**规模法则（scaling laws）** 是这一逻辑的极端体现：在足够大的数据与算力下，增加参数量与训练 token 数会带来可预测的损失下降。它把“深度学习是工程”这句话推到了前台——架构重要，但**规模与数据质量**同样重要。

**反过来说**：深度学习并不是“只要堆大就行”。数据偏差、目标错位、分布偏移、推理成本与安全风险都会随规模放大。规模是必要条件之一，不是充分条件。

## 1.4 表示学习与深度

**因素（factors of variation）**：现实数据由少量潜在因素生成。例如一张人脸照片，受身份、姿态、光照、表情、遮挡、相机参数等影响。原始像素是这些因素的高维、纠缠的观测；分类任务只关心其中少数因素。

**表示学习**的目标是找到一个映射 $h = f(x)$，使下游任务在 $h$ 上更容易完成。好的表示通常具备：

- **充分性**：保留预测所需的信息；
- **紧致性**：维度低、冗余少；
- **解耦性**：不同因素对应不同方向（理想状态）；
- **不变性**：对任务无关的变换（平移、光照、语速）不敏感；
- **可迁移性**：在多个任务间共享。

**深度如何帮助表示**：深度网络把复杂函数分解为多层简单函数的复合。低层捕捉局部、低阶模式，高层组合成全局、抽象概念。例如图像网络中，低层学边缘与色块，中层学纹理与部件，高层学物体与场景；语言模型中，低层学词形与局部搭配，高层学句法、指代与语义角色。

**分布式表示（distributed representation）**：一个概念由多个神经元/维度的组合表示，而不是“一个概念一个单元”。$n$ 个二值单元可以表示 $2^n$ 种组合，因此表示容量随维度**指数增长**。这也是深度网络比“查表式”模型更节省参数的原因。

**深度 vs 宽度**：万能近似定理说明，足够宽的单隐层网络可以逼近紧集上的连续函数。但：

- 所需宽度可能随输入维度指数增长；
- 浅层网络可能无法高效表示某些**层次化**函数；
- 定理只谈存在性，不谈样本复杂度、优化可解性与泛化。

因此“深度”不是理论上的绝对优势，而是在**表示效率、样本效率与优化可行性**之间的经验折中。现代架构（ResNet、Transformer、ConvNeXt）都在利用“层次复用”这一归纳偏置。

## 1.5 成功、边界与代价

**已经改变的能力**：

| 领域 | 典型任务 | 关键技术 |
| --- | --- | --- |
| 视觉 | 分类、检测、分割、生成 | CNN、ViT、扩散模型 |
| 语音 | 识别、合成、分离、说话人 | 序列模型、自监督、Conformer |
| 语言 | 翻译、摘要、问答、对话、代码 | Transformer、预训练、对齐 |
| 科学 | 蛋白结构、分子设计、天气、材料 | 等变网络、图网络、神经算子 |
| 决策 | 游戏、机器人、推荐 | 深度强化学习、模仿学习、世界模型 |

**不能自动解决的事**：

| 局限 | 具体表现 | 可能方向 |
| --- | --- | --- |
| 数据效率 | 需要大量标注或交互 | 自监督、迁移、少样本、归纳偏置 |
| 分布外泛化 | 换背景、换口音、换城市就失效 | 领域自适应、因果不变性、鲁棒训练 |
| 长程推理 | 多步规划、严格证明容易出错 | 工具调用、搜索、神经符号、验证器 |
| 因果理解 | 学到相关而非干预效果 | 因果推断、实验设计 |
| 可解释性 | 归因方法只能给出局部线索 | 可解释模型、机制分析、不确定性 |
| 可靠性 | 幻觉、对抗样本、后门 | 评测、红队、护栏、人机协同 |
| 成本 | 训练与推理的算力、能耗、碳排 | 压缩、蒸馏、稀疏化、专用硬件 |

**“没有免费的午餐”**：没有一种模型在所有任务上最优。深度学习之所以在感知任务上强，是因为它把**局部性、平移等变、层次组合**等先验编码进了架构；换到符号推理或小样本表格数据，其他方法可能更合适。

**一句话总结**：深度学习用**可学习的层次表示 + 端到端优化 + 大规模数据与算力**，把“特征工程”从人转移给了模型；代价是数据、算力、可解释性与可靠性方面的额外要求。

## 1.6 本书的结构与读法

本书沿花书的三部分展开：

1. **应用数学与机器学习基础（第 2–5 章）**：线性代数、概率与信息论、数值计算、机器学习基础。它们是后面所有推导的工具箱。
2. **现代实用深度网络（第 6–12 章）**：前馈网络、正则化、优化、卷积、序列建模、实践方法论与应用。这一部分回答“怎么把网络训起来、用起来”。
3. **深度学习研究（第 13–20 章）**：线性因子模型、自编码器、表示学习、结构化概率模型、蒙特卡洛、配分函数、近似推断、深度生成模型。这一部分回答“为什么这样设计、背后的概率与统计是什么”。

**三种读法**：

- **工程入门**：第 5 → 6 → 7 → 8 → 9 → 11 章，先能训练与评估模型；
- **理论纵深**：第 2 → 3 → 4 章打底，再读第 13–20 章；
- **方向选读**：视觉读第 9、12.2 节；语言读第 10、12.4 节与附录 A；生成读第 16–20 章。

**记号约定**：$x$ 输入、$y$ 目标、$\hat y$ 预测、$h$ 隐表示、$\theta$ 参数、$L$ 损失、$\eta$ 学习率；矩阵用大写字母，向量用粗体或小写字母；$\odot$ 表示逐元素乘；$\|\\cdot\|_p$ 表示 $L_p$ 范数。每章末尾的“关键术语”表给出中英文对照，便于读论文。

## 本章小结

**核心要点**

1. 深度学习是机器学习的子领域，核心是**用多层可微模型学习表示**；非线性是深度有意义的前提。
2. 深度学习的三次浪潮分别由控制论、连接主义与“数据 + 算力 + 算法 + 软件”推动；历史提醒我们工程条件与理论同样重要。
3. **表示学习**替代手工特征工程；好表示应充分、紧致、解耦、不变且可迁移。
4. **分布式表示**让参数量随维度指数级地利用组合空间；**深度**提供层次复用，但万能近似不保证可学、可泛化。
5. 深度学习已改变感知、语言、科学与决策，但在数据效率、分布外泛化、长程推理、因果、可靠性与成本上仍有明确边界。
6. 学习本书的建议是“先框架、再数学、后研究”：第 5–9 章建立工程直觉，第 13–20 章补齐概率与推断视角。
