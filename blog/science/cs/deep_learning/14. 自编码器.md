# 第 14 章 自编码器（Autoencoders）

**本章导读**：自编码器（AE）是一类“用输入监督自己”的网络：编码器把 $x$ 压成表示 $h$，解码器从 $h$ 重建 $x$，训练目标是重构误差。它的价值不在“复制输入”，而在**被迫学习有用的表示**。本章讨论：欠完备 AE（14.1）、正则化 AE（14.2）、去噪 AE 与得分匹配（14.3）、收缩 AE（14.4）、预测型/掩码 AE（14.5）、表示能力与流形（14.6），最后是应用与边界（14.7）。

**学习目标**：完成本章学习后，你应当能够：

- 写出自编码器的编码/解码/损失，说明瓶颈的作用；
- 证明线性欠完备 AE 学到 PCA 子空间；
- 区分稀疏、去噪、收缩、掩码自编码器的正则方式；
- 解释去噪 AE 与得分匹配、RBM 的联系；
- 说明“恒等映射”问题与过完备 AE 的风险；
- 选择 AE 做预训练、异常检测、去噪或压缩；
- 理解 AE 如何过渡到 VAE 与掩码自监督。

**预备知识**：第 6 章的前馈网络、第 7 章的正则化、第 13 章的线性因子模型、第 3 章的高斯与 KL。

## 14.1 欠完备自编码器

**结构**：

$$h = f_\theta(x),\qquad r = g_\phi(h),\qquad L(x,r) = \|x-r\|_2^2 \quad \text{或} \quad -\log p(x\mid r).$$

- 编码器 $f$ 把 $x\in\mathbb{R}^d$ 映射到 $h\in\mathbb{R}^k$；
- 解码器 $g$ 把 $h$ 映射回 $\mathbb{R}^d$；
- **欠完备**：$k<d$，瓶颈迫使模型保留最重要的信息。

**线性 AE 与 PCA**：若 $f$、$g$ 都是线性、无偏置、损失为 MSE，则最优解张成的子空间与 PCA 的主子空间相同。直观上，编码器把数据投影到 $k$ 维，解码器再投影回来；最小化重构误差等价于最大化保留的方差。**权重不一定正交**，但子空间一致。

**非线性 AE**：用 MLP 替代线性映射，可以学到**非线性流形**上的坐标。它比 PCA 更灵活，但也更难训练、更难解释，且没有 PCA 的闭式解与全局最优保证。

**瓶颈的权衡**：

| 容量 | 效果 |
| --- | --- |
| 太小 | 欠拟合，丢失重要信息 |
| 合适 | 学到紧凑、可用的表示 |
| 太大 | 可能学恒等映射，表示无意义 |

**训练技巧**：与普通网络相同——ReLU/GELU、归一化、Adam、早停、权重衰减；瓶颈层可用线性或 tanh。

**用途**：降维、可视化、去噪、预训练、异常检测、生成模型的编码器（VAE）。

## 14.2 正则化自编码器

当 $k\ge d$ 或容量过大时，AE 可能直接学恒等映射，表示没有价值。正则化迫使它学习**结构化**的表示。

**（1）稀疏自编码器**：在损失中加稀疏惩罚：

$$L = \|x-r\|_2^2 + \lambda\|\sigma(h)\|_1,$$

或约束平均激活接近目标稀疏度 $\rho$：

$$L = \|x-r\|_2^2 + \beta\sum_j \mathrm{KL}(\rho\,\|\,\hat\rho_j),$$

其中 $\hat\rho_j = \frac{1}{N}\sum_i h_{ij}$。稀疏性使表示可解释、抗噪，类似生物神经元的低发放率。

**（2）权重衰减**：对编码器/解码器权重加 $L_2$，限制容量，防止恒等映射。

**（3）去噪自编码器（DAE）**：见 14.3。

**（4）收缩自编码器（CAE）**：惩罚编码器雅可比，见 14.4。

**（5）掩码自编码器（MAE）**：遮挡部分输入，重建缺失部分，见 14.5。

**（6）变分自编码器（VAE）**：对编码分布加 KL 正则，见第 19–20 章。

**正则化的共同目标**：让表示对**噪声、遮挡、微小变化**鲁棒，同时保留**语义信息**。这与第 7 章的正则化思想一致：用先验换泛化。

## 14.3 去噪自编码器与得分匹配

**做法**：对输入加噪或遮挡，得到 $\tilde x$，让网络重建**干净**的 $x$：

$$L = \mathbb{E}_{x\sim p_\text{data},\,\tilde x\sim C(\tilde x\mid x)}\big[\|x - g(f(\tilde x))\|_2^2\big].$$

**为什么有效**：网络不能简单复制输入，必须“理解”数据流形，才能从损坏的样本恢复出来。去噪任务迫使它学习数据分布的结构，而不是恒等映射。

**与得分匹配的联系**：对高斯噪声 $\tilde x = x + \epsilon$、$\epsilon\sim\mathcal{N}(0,\sigma^2 I)$，最优去噪函数满足

$$\hat x(\tilde x) = \tilde x + \sigma^2 \nabla_{\tilde x}\log p(\tilde x).$$

也就是说，**去噪 AE 隐式地学习了数据分布的对数密度梯度（score）**。这解释了为什么 DAE 能用于生成（采样时沿 score 走）与异常检测（低密度区域 score 大）。

**得分匹配（score matching）**：直接匹配 score：

$$J(\theta) = \mathbb{E}_{x\sim p_\text{data}}\big[\|\nabla_x\log p_\theta(x) - \nabla_x\log p_\text{data}(x)\|_2^2\big].$$

通过分部积分，可写成只依赖模型的形式：

$$J(\theta) = \mathbb{E}_{p_\text{data}}\left[\operatorname{tr}\big(\nabla_x s_\theta(x)\big) + \frac12\|s_\theta(x)\|_2^2\right],$$

避免估计未知的 $p_\text{data}$ 梯度。**denoising score matching** 用加噪样本近似，是现代扩散模型（第 20 章、附录 A.5）的理论基础。

**与 RBM 的联系**：DAE 的采样过程与 RBM 的对比散度有相似之处；某些 DAE 可以看作 RBM 的近似。这个联系在 2010 年代推动了深度生成模型的发展。

**实践参数**：噪声类型（高斯、掩码、椒盐）、噪声强度、是否共享权重。噪声太弱学不到结构，太强则任务不可解。

## 14.4 收缩自编码器与切空间

**收缩自编码器（CAE）**：在损失中惩罚编码器对输入的雅可比：

$$L = \|x-g(f(x))\|_2^2 + \lambda\left\|\frac{\partial f(x)}{\partial x}\right\|_F^2.$$

**直觉**：表示 $f(x)$ 应对输入的小扰动不敏感，即沿数据流形方向的变化被保留，垂直于流形的噪声被压缩。雅可比的 Frobenius 范数衡量这种敏感度。

**与去噪 AE 的关系**：对小高斯噪声，DAE 的损失近似为

$$\mathbb{E}\big[\|x-g(f(x))\|^2\big] + \sigma^2\mathbb{E}\left[\left\|\frac{\partial f}{\partial x}\right\|_F^2\right] + o(\sigma^2),$$

因此 CAE 可视为 DAE 的小噪声极限。两者都鼓励**收缩**（contractive）表示。

**切空间正则（tangent prop）**：若已知数据变换（旋转、平移、光照），惩罚输出沿变换方向的导数；它把“不变性”写进损失，而不是靠数据增强。

**应用**：特征学习、去噪、流形学习；CAE 的表示对输入扰动稳定，适合后续分类/检索。

## 14.5 预测型与掩码自编码器

**预测型自编码器**：不是重建整个输入，而是用一部分预测另一部分。例如：

- 用过去预测未来（时间序列）；
- 用上下文预测中心词（word2vec/CBOW）；
- 用图像块预测相邻块（context prediction）；
- 用遮挡区域预测缺失内容（inpainting）。

**掩码自编码器（MAE）**：

1. 随机遮挡图像的高比例 patch（如 75%）；
2. 只用可见 patch 编码；
3. 解码器重建被遮挡 patch 的像素；
4. 损失只在遮挡位置计算。

**为什么 MAE 有效**：

- 遮挡比例高 → 任务难，迫使模型学语义而非局部插值；
- 只编码可见 patch → 计算高效；
- 重建像素 → 保留细节，适合视觉预训练；
- 与 NLP 的 BERT 掩码预测同源，但视觉信号冗余度高，需要更高遮挡率。

**MAE 与 VAE 的区别**：MAE 是**确定性**的重建，没有显式潜变量分布；VAE 有概率编码器与 KL 正则，能生成新样本。MAE 更接近“自监督预训练 + 微调”的范式。

**其他掩码/预测任务**：Span Corruption（T5）、Next Sentence Prediction（BERT，后来被证明不是必需）、对比预测编码（CPC）、掩码语言建模。

## 14.6 表示能力与流形

**恒等映射问题**：若 AE 容量足够且没有正则，最简单的解是 $g(f(x))=x$，此时 $h$ 可以是任意编码，表示没有语义。**瓶颈与正则化**是防止这一点的手段。

**过完备 AE**：$k>d$ 时，AE 仍可能学到有用表示，但必须加稀疏/去噪/收缩等约束；否则容易退化为恒等映射。

**流形假设**：真实数据集中在低维流形上。AE 的编码器学习流形坐标，解码器学习嵌入映射；瓶颈维度应接近**内在维度**，而不是观测维度。

**重构 vs 有用**：

- 重构误差低只说明“能压缩”，不说明“表示适合下游任务”；
- 分类/检索任务可能需要保留判别信息，而重构可能丢弃；
- 评估表示应做**线性探针/微调**，而不是只看重构损失（第 15.8 节）。

**AE 与概率模型**：

| 模型 | 潜变量 | 训练目标 | 生成 |
| --- | --- | --- | --- |
| 线性 AE | 确定性 | MSE | 否 |
| DAE | 加噪输入 | 去噪 MSE | 近似（score） |
| VAE | 随机 | ELBO | 是 |
| GAN | 随机 | 对抗 | 是 |
| 扩散 | 多步噪声 | 去噪 | 是 |

**一句话总结**：自编码器用“重建”作为自监督信号，用瓶颈与正则迫使表示保留结构；它是降维、去噪、预训练与生成模型的共同基础。

## 14.7 应用与边界

**应用**：

| 场景 | 做法 | 注意 |
| --- | --- | --- |
| 降维/可视化 | 欠完备 AE、卷积 AE | 与 PCA/UMAP 对比 |
| 去噪 | DAE、CAE | 噪声类型匹配真实退化 |
| 异常检测 | 重构误差/score | 阈值需验证集校准 |
| 预训练 | 无监督/自监督预训练 | 现代多用对比/掩码预训练 |
| 压缩 | 瓶颈表示 + 量化 | 率失真权衡 |
| 图像修复 | 掩码 AE/inpainting | 大面积缺失需生成先验 |
| 推荐 | 用户/物品表示 | 与矩阵分解对比 |

**异常检测的细节**：AE 在正常数据上训练，异常样本重构误差大。但若异常与正常共享低层特征，误差可能不大；应结合 score、密度估计、重构概率与下游验证。

**边界**：

- 重构目标可能与任务目标不一致；
- 过完备/无正则时学恒等映射；
- 对复杂分布，MSE 重构产生模糊；
- 训练不稳定、超参数敏感；
- 生成能力有限（除 VAE/扩散外）。

**现代视角**：纯 AE 作为预训练已不如对比学习/掩码建模主流，但“编码-瓶颈-解码”的思想仍是 VAE、MAE、U-Net、表示学习的基础。**去噪即得分**的洞察直接通向扩散模型。

## 本章小结

**核心要点**

1. AE 用重构误差做自监督；瓶颈迫使模型保留重要信息，线性欠完备 AE 等价于 PCA 子空间。
2. 过完备/大容量 AE 会学恒等映射，需要稀疏、权重衰减、去噪、收缩或掩码等正则。
3. 去噪 AE 从损坏输入重建干净输入，隐式学习数据分布的 score；这是扩散模型的理论前身。
4. 收缩 AE 惩罚编码器雅可比，鼓励表示对输入扰动不敏感；它与小噪声 DAE 近似等价。
5. 掩码 AE 用高比例遮挡 + 仅可见 patch 编码，是视觉自监督预训练的有效方法。
6. 重构误差低不等于表示有用；应通过线性探针/微调/下游任务评估。
7. AE 是 VAE、MAE、U-Net 与表示学习的共同基础，但纯 AE 的生成与预训练地位已被更强的方法取代。
