# 第 9 章 卷积网络（Convolutional Networks）

**本章导读**：卷积网络（CNN）是深度学习在视觉、语音、科学计算中最重要的架构之一。它的核心不是“卷积”这个数学运算本身，而是**局部连接、权值共享、平移等变与层次组合**这四个归纳偏置。本章讨论：卷积的定义与维度（9.1）、四个动机（9.2）、池化（9.3）、经典架构（9.4）、实现算法（9.5）、变体与设计（9.6），最后回到神经科学背景与局限（9.7）。

**学习目标**：完成本章学习后，你应当能够：

- 计算卷积输出的空间尺寸与参数量；
- 解释局部连接、权值共享、平移等变与池化不变性；
- 写出感受野的递推公式，设计小卷积堆叠；
- 比较 LeNet、AlexNet、VGG、ResNet、MobileNet 等架构的关键思想；
- 说明 im2col、Winograd、深度可分离卷积的加速原理；
- 判断何时用 CNN、何时用 Transformer，并理解两者的取舍。

**预备知识**：第 2 章的矩阵乘法与张量、第 6 章的前馈网络与反向传播、第 8 章的优化与归一化。

## 9.1 卷积运算

**二维离散卷积**（严格定义）：

$$(K * X)_{ij} = \sum_{m}\sum_{n} K_{mn} X_{i-m,\,j-n}.$$

深度学习框架实际实现的是**互相关（cross-correlation）**：

$$Y_{ij} = \sum_{m=0}^{K_h-1}\sum_{n=0}^{K_w-1} K_{mn} X_{i+m,\,j+n}.$$

两者只差一个核翻转，而核是学出来的，所以不影响表达力；本书按惯例称“卷积”。

**多通道**：输入 $X\in\mathbb{R}^{C_\text{in}\times H\times W}$，每个卷积核也是 $C_\text{in}\times K_h\times K_w$，输出通道数等于卷积核个数 $C_\text{out}$：

$$Y_{o,i,j} = b_o + \sum_{c=0}^{C_\text{in}-1}\sum_{m,n} K_{o,c,m,n} X_{c,i+m,j+n}.$$

**参数量**：$C_\text{out}\times C_\text{in}\times K_h\times K_w + C_\text{out}$。与输入空间尺寸无关，这是权值共享的直接结果。

**步长、填充与输出尺寸**：

$$H_\text{out} = \left\lfloor\frac{H_\text{in}+2P-K_h}{S}\right\rfloor + 1,$$

宽度同理。常见约定：

- **valid**：$P=0$，输出变小；
- **same**：$P=(K-1)/2$（$S=1$ 时），输出与输入同尺寸；
- **full**：$P=K-1$，输出变大。

**1×1 卷积**：不混合空间邻居，只做跨通道线性组合。它用于降维/升维（Inception 的瓶颈）、增加非线性、跨通道信息融合。参数量为 $C_\text{out}C_\text{in}$。

**空洞卷积（dilated convolution）**：在核元素之间插入间隔 $d$，不增加参数就扩大感受野，常用于语义分割（DeepLab）与音频。

**分组卷积（grouped convolution）**：把通道分成 $g$ 组，每组独立卷积。ResNeXt、MobileNet 的深度卷积（$g=C_\text{in}$）都是特例；它降低计算量，但组间不通信，需要后续 $1\times1$ 卷积融合。

**转置卷积（transposed convolution）**：不是卷积的逆，而是“反向上采样”的线性运算，输出尺寸

$$H_\text{out} = (H_\text{in}-1)S - 2P + K.$$

它会产生棋盘格伪影，现代生成模型常用“插值 + 卷积”或“像素重排（pixel shuffle）”替代。

**感受野**：第 $l$ 层一个神经元对应的输入区域。递推：

$$r_l = r_{l-1} + (K_l-1)\prod_{i<l} S_i.$$

堆叠两个 $3\times3$ 卷积（$S=1$）的感受野等于一个 $5\times5$，但参数更少（$2\times9$ vs $25$）、非线性更多。三个 $3\times3$ 等效 $7\times7$，这是 VGG 的核心思想。

## 9.2 卷积的四个动机

**（1）局部连接（sparse interactions）**：每个输出只连接输入的一个局部邻域。自然图像中相邻像素高度相关，远距离关系可以通过多层堆叠间接建立。相比全连接，参数量与计算量大幅下降。

**（2）权值共享（parameter sharing）**：同一个核在整张图上滑动。一个“边缘检测器”无论在图像左上角还是右下角都应适用，因此共享是合理的先验。它使参数量与图像尺寸无关。

**（3）平移等变（translation equivariance）**：若输入平移 $\Delta$，输出也平移 $\Delta$：

$$f(\mathrm{shift}_\Delta(x)) = \mathrm{shift}_\Delta(f(x)).$$

卷积本身具有平移等变性（在边界处理理想的情况下）；池化与全局池化进一步带来**近似平移不变性**。注意“等变”与“不变”不同：等变是“输入怎么动，输出怎么动”；不变是“输入动，输出不动”。

**（4）层次组合**：堆叠卷积可以逐级扩大感受野，组合出边缘 → 纹理 → 部件 → 物体的层次表示。这与第 1 章的表示学习主张一致。

**CNN 的归纳偏置**：

| 先验 | 编码方式 | 失效场景 |
| --- | --- | --- |
| 局部性 | 小卷积核 | 长程依赖、全局上下文 |
| 平移等变 | 权值共享 | 需要绝对位置的任务 |
| 尺度/旋转不变 | 数据增强/多尺度 | 未覆盖的变换 |
| 通道语义 | 多通道卷积 | 通道顺序重要时 |

**与全连接网络的对比**：全连接层可以表示任意线性变换，但需要 $O(H^2W^2)$ 参数且没有平移先验；卷积用先验换样本效率。数据少时 CNN 优势明显；数据极大时，Transformer 可以用注意力学出类似甚至更强的空间交互（附录 A.1）。

## 9.3 池化

**最大池化**：

$$Y_{ij} = \max_{(m,n)\in\mathcal{R}_{ij}} X_{mn}.$$

**平均池化**：

$$Y_{ij} = \frac{1}{\lvert\mathcal{R}_{ij}\rvert}\sum_{(m,n)\in\mathcal{R}_{ij}} X_{mn}.$$

**全局池化**：对整个空间求最大/平均，输出 $C$ 维向量，替代全连接层，减少参数并支持任意输入尺寸。

**池化的作用**：

- 降低空间分辨率，减少计算与内存；
- 扩大后续层的感受野；
- 提供局部平移/形变的鲁棒性；
- 最大池化保留最强响应，平均池化保留整体证据。

**池化的局限**：

- 丢失精确位置信息，不利于检测/分割；
- 最大池化的梯度只回传到最大值位置，稀疏但可能不稳定；
- 现代架构常用**步长卷积**替代池化，让下采样也可学习；
- 对需要精细定位的任务，用空洞卷积/上采样/跳连保留分辨率。

**自适应池化**：指定输出尺寸，框架自动选择核与步长，使模型支持任意输入分辨率。

**池化与等变性**：池化带来的是**局部不变性**，不是全局不变性；输入移动超过池化窗口时，输出仍会变化。真正的全局不变性需要全局池化或显式对齐。

## 9.4 经典架构的演进

| 网络 | 年份 | 关键贡献 | 备注 |
| --- | --- | --- | --- |
| LeNet-5 | 1998 | 卷积 + 池化 + 全连接 | 手写数字识别 |
| AlexNet | 2012 | ReLU、Dropout、GPU、数据增强 | ImageNet 突破 |
| VGG | 2014 | 全部用 $3\times3$ 堆深 | 结构规整、参数多 |
| GoogLeNet | 2014 | Inception 多尺度并行 + $1\times1$ 降维 | 计算高效 |
| ResNet | 2015 | 残差连接、BatchNorm | 可训练上百层 |
| DenseNet | 2016 | 密集连接、特征复用 | 参数效率高 |
| MobileNet | 2017 | 深度可分离卷积 | 移动端 |
| EfficientNet | 2019 | 复合缩放（深度/宽度/分辨率） | NAS 思想 |
| ConvNeXt | 2022 | 借鉴 Transformer 的现代 CNN | 大核、LayerNorm、GELU |
| ViT | 2020 | 图像切 patch + 自注意力 | 数据需求大（附录 A.1） |

**AlexNet**：8 层网络，ReLU 替代 sigmoid，Dropout 抑制过拟合，两块 GPU 并行训练；它证明了“大数据 + 深网络 + GPU”的可行性。

**VGG**：用连续的 $3\times3$ 卷积替代大核，每段后接池化；结构简单，常作为特征提取 backbone。缺点是参数量大（约 1.38 亿）。

**GoogLeNet/Inception**：在同一层并行使用 $1\times1$、$3\times3$、$5\times5$ 卷积与池化，再拼接；$1\times1$ 卷积先降维，控制计算量。它把“宽度”做成多尺度。

**ResNet**：残差块

$$y = x + F(x),$$

其中 $F$ 通常是两层 $3\times3$ 卷积 + BN + ReLU。恒等映射让梯度直接回传，缓解深层退化；瓶颈结构（$1\times1$ 降维 → $3\times3$ → $1\times1$ 升维）降低计算量。ResNet-50/101/152 是视觉的经典基线。

**DenseNet**：每层接收前面所有层的特征，$x_l = H_l([x_0,\dots,x_{l-1}])$；特征复用、梯度流动好，但显存占用高。

**MobileNet**：深度可分离卷积 = 逐通道卷积 + $1\times1$ 点卷积。计算量约为标准卷积的 $1/N + 1/K^2$，适合移动端。

**EfficientNet**：用复合系数同时缩放深度、宽度与分辨率：

$$\text{depth} = \alpha^\phi,\quad \text{width} = \beta^\phi,\quad \text{resolution} = \gamma^\phi,\quad \alpha\beta^2\gamma^2 \approx 2.$$

**ConvNeXt**：把 Transformer 的设计元素（大核 $7\times7$、LayerNorm、GELU、倒瓶颈、较少激活）移植回 CNN，证明卷积架构仍具竞争力。

## 9.5 卷积的实现算法

**直接卷积**：按定义循环，简单但慢；现代框架用高度优化的 GEMM 或专用指令。

**im2col + GEMM**：把每个感受野展开成列向量，把卷积变成矩阵乘法。优点是复用高度优化的 GEMM；缺点是展开后的矩阵有 $K^2$ 倍冗余，显存占用大。

**FFT 卷积**：在频域做逐点乘法，复杂度 $O(N\log N)$，适合大核；小核时 FFT 的开销反而更大。

**Winograd**：用多项式变换减少乘法次数，$3\times3$ 卷积可显著加速；但数值精度较低，训练时需注意。

**深度可分离卷积**：逐通道空间卷积 + $1\times1$ 跨通道卷积；MobileNet、Xception 的核心。

**稀疏/量化卷积**：剪枝后的稀疏核、INT8 量化、结构化稀疏，配合专用硬件（Tensor Core、NPU）提升吞吐。

**复杂度**：

$$\text{FLOPs} \approx 2 H_\text{out}W_\text{out}C_\text{out}C_\text{in}K_hK_w.$$

内存瓶颈往往比 FLOPs 更关键；推理框架会做算子融合、内存复用与布局优化。

## 9.6 卷积网络的变体与设计

**现代 CNN 的设计原则**：

1. 用**小核堆叠**而不是大核（除非用大核 + 深度可分离）；
2. 用**残差/密集连接**保证深层可训练；
3. 用**归一化**（BN/LN/GN）稳定训练；
4. 用**瓶颈/分组/深度可分离**控制计算量；
5. 用**数据增强 + 正则**提升泛化；
6. 用**全局池化 + 线性头**减少参数；
7. 用**迁移学习**复用预训练 backbone。

**CNN 的变体**：

| 变体 | 思想 | 场景 |
| --- | --- | --- |
| 空洞卷积 | 扩大感受野不降分辨率 | 分割、音频 |
| 可变形卷积 | 学习采样位置 | 形变物体 |
| 转置卷积 | 上采样 | 生成、分割 |
| 深度可分离 | 分解空间与通道 | 移动端 |
| 分组卷积 | 通道分组 | 高效计算 |
| 注意力卷积 | 卷积 + 通道/空间注意力 | 增强表达 |
| 等变网络 | 旋转/平移群等变 | 分子、医学图像 |

**CNN vs Transformer**：

| 维度 | CNN | ViT |
| --- | --- | --- |
| 归纳偏置 | 局部性、平移等变 | 弱，需从数据学 |
| 数据需求 | 较小 | 较大（或强增强/自监督） |
| 长程依赖 | 需堆叠/空洞 | 单层全局 |
| 计算复杂度 | 线性于像素 | 二次于 patch 数 |
| 高分辨率 | 友好 | 需窗口/分层设计 |

**实践建议**：数据量中等、部署受限 → CNN（ResNet/EfficientNet/MobileNet）；数据量大、需要多模态/长程 → ViT 或混合架构。现代视觉系统常用“CNN 主干 + Transformer  neck”或“ViT + 卷积 stem”。

## 9.7 神经科学背景与局限

**Hubel & Wiesel（1959–1962）** 发现猫视觉皮层有**简单细胞**（对特定方向的边缘响应）与**复杂细胞**（对位置略不敏感）。这启发了**神经认知机（Neocognitron，Fukushima，1980）**：交替的卷积与池化层，局部特征逐级组合。

**CNN 与生物视觉的差异**：

- 生物视觉是双向、循环、多尺度的，CNN 前馈为主；
- 生物神经元有脉冲时间、适应、注意调制，CNN 是连续激活；
- 生物学习依赖局部可塑性，CNN 用全局反向传播；
- 生物视觉对旋转/尺度不变性更强，CNN 需要数据增强。

**CNN 的局限**：

- **全局上下文**：大物体、场景关系需要很深的堆叠或注意力；
- **精确位置**：池化与下采样损失定位精度；
- **分布外鲁棒性**：纹理偏差、对抗样本、天气/传感器变化；
- **长尾**：稀有类别与组合泛化差；
- **计算**：高分辨率 3D/视频的显存与延迟。

**一句话总结**：CNN 用**局部连接 + 权值共享 + 层次堆叠**把图像先验写进架构，用少量参数学到强大的视觉表示；它不是视觉的终点，但仍是大多数视觉系统的可靠基线。

## 本章小结

**核心要点**

1. 卷积输出尺寸由 $H,P,K,S$ 决定；参数量与输入尺寸无关，这是权值共享的结果。
2. 局部连接、权值共享、平移等变与层次组合是 CNN 的四个核心先验。
3. 池化降分辨率、扩感受野、提供局部不变性，但损失定位精度；现代网络常用步长卷积替代。
4. 小核堆叠（VGG）、多尺度并行（Inception）、残差（ResNet）、深度可分离（MobileNet）是四条关键设计路线。
5. im2col+GEMM、FFT、Winograd、深度可分离是主要实现/加速手段；内存与 FLOPs 同样重要。
6. CNN 与 ViT 是归纳偏置与数据需求的权衡；混合架构是当前主流之一。
7. CNN 受生物视觉启发，但机制不同；它在全局上下文、定位精度、鲁棒性与长尾上仍有局限。
