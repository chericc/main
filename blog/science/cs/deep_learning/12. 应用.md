# 第 12 章 应用（Applications）

**本章导读**：前 11 章讲原理与方法，本章看它们如何落到真实系统。深度学习应用的共同模式是：**大规模数据 + 可扩展训练 + 领域特定的归纳偏置 + 工程部署**。本章覆盖大规模训练基础设施（12.1）、计算机视觉（12.2）、语音（12.3）、自然语言处理（12.4）、推荐/图/强化学习/科学计算（12.5），最后讨论从论文到产品的工程问题（12.6）。

**学习目标**：完成本章学习后，你应当能够：

- 说明数据并行、模型并行、流水线并行与混合精度的取舍；
- 描述视觉分类、检测、分割、生成的典型流程与代表模型；
- 解释语音识别中 CTC 与编码器-解码器的作用；
- 概述 NLP 从词嵌入到预训练语言模型的演进；
- 举例说明深度学习在推荐、图、强化学习与科学计算中的应用；
- 评估从论文复现到产品部署的主要风险与成本。

**预备知识**：第 6–11 章的网络、优化、正则、CNN、序列建模与实践方法；对视觉/语音/NLP 的基本了解有帮助，但不要求先修。

## 12.1 大规模深度学习

**为什么需要分布式**：单个 GPU 的显存装不下大模型，单机算力也无法在合理时间内完成训练。分布式训练的核心是把**计算、参数、数据、梯度**切分到多个设备。

| 并行方式 | 切分对象 | 优点 | 瓶颈 |
| --- | --- | --- | --- |
| 数据并行 | batch | 实现简单、吞吐高 | 梯度 all-reduce 通信 |
| 模型并行（张量） | 单层权重 | 能装下超大层 | 层内通信频繁 |
| 流水线并行 | 层 | 跨设备切层 | 流水线气泡 |
| 序列并行 | 序列长度 | 长上下文 | 实现复杂 |
| 专家并行 | MoE 专家 | 稀疏激活、容量大 | 路由/负载均衡 |

**数据并行**：每个 worker 持完整模型副本，处理不同数据分片，计算梯度后 all-reduce 平均。同步 SGD 需要等待最慢的 worker（straggler）；异步 SGD 吞吐高但可能 stale。

**张量并行**：把矩阵乘按行/列切分，例如 Megatron-LM 的列并行 + 行并行。每层需要 all-reduce，通信量大，适合高带宽互联（NVLink/TPU pod）。

**流水线并行**：把层分到不同设备，微批依次流过；用 1F1B（一前一后）调度减少气泡。GPipe、PipeDream 是代表。

**ZeRO / FSDP**：把优化器状态、梯度、参数分片到数据并行组，降低单卡显存；本质是“用通信换显存”。

**混合精度**：FP16/BF16 前向与反向，FP32 主权重与归一化统计；需要 loss scaling（FP16）或依赖 BF16 的动态范围。它能显著提升吞吐、降低显存。

**梯度检查点**：不保存全部激活，反向时重算，用计算换显存；适合长序列/大模型。

**训练稳定性**：大 batch 需要 warmup、LAMB/LARS、梯度裁剪、数值监控；loss spike 常见于大模型训练，需回滚 checkpoint、跳数据、调学习率。

**成本**：大模型训练是“算力 + 数据 + 工程”的系统工程；推理成本往往比训练更影响产品可行性（附录 A.7）。

## 12.2 计算机视觉

**图像预处理**：解码、缩放/裁剪、归一化（ImageNet 均值方差）、颜色空间、数据增强。预处理必须训练/推理一致。

**图像分类**：

```
输入图像 → CNN/ViT backbone → 全局池化 → 线性分类头 → softmax
```

代表：AlexNet、VGG、ResNet、EfficientNet、ConvNeXt、ViT。评估用 top-1/top-5 准确率；真实场景还要看校准、鲁棒性、长尾与推理成本。

**目标检测**：输出类别 + 边界框。

| 方法 | 思路 | 代表 |
| --- | --- | --- |
| 两阶段 | 先提候选区域，再分类/回归 | R-CNN、Fast/Faster R-CNN |
| 单阶段 | 直接在特征图上预测 | YOLO、SSD、RetinaNet |
| 无锚框 | 关键点/中心点 | FCOS、CenterNet |
| 集合预测 | 直接输出框集合，去 NMS | DETR |

关键概念：IoU、锚框（anchor）、非极大值抑制（NMS）、多尺度特征金字塔（FPN）、正负样本分配。评估用 mAP（IoU 阈值 0.5/0.75/0.5:0.95）。

**语义/实例/全景分割**：

- **语义分割**：每个像素分类（FCN、U-Net、DeepLab）；
- **实例分割**：区分同类不同个体（Mask R-CNN）；
- **全景分割**：语义 + 实例统一；
- **提示分割**：SAM 用点/框/掩码提示分割任意对象。

**图像生成**：GAN、VAE、扩散模型、自回归模型（第 20 章、附录 A.5）。评估用 FID、IS、CLIPScore 与人工评价。

**视觉的其他任务**：关键点/姿态、深度估计、光流、立体匹配、SLAM、NeRF/3D Gaussian Splatting、视频理解。

**视觉的工程挑战**：分辨率与显存、长尾类别、域偏移（医院/城市/天气）、对抗样本、实时性、隐私（人脸）。

## 12.3 语音处理

**语音识别（ASR）流水线**：

```
波形 → 特征（MFCC/滤波器组）→ 声学模型 → 解码（声学 + 语言模型）→ 文本
```

**传统混合系统**：HMM + GMM/DNN 做声学建模，发音词典 + n-gram 语言模型做解码。

**端到端 ASR**：

| 方法 | 思路 | 特点 |
| --- | --- | --- |
| CTC | 引入 blank，边缘化所有对齐 | 不需要帧级对齐，条件独立假设强 |
| Seq2Seq + Attention | 编码器-解码器逐字生成 | 建模语言上下文，需注意力 |
| RNN-Transducer | 联合声学/预测/联合网络 | 流式友好 |
| Conformer | 卷积 + 自注意力 | 兼顾局部与全局 |
| Whisper | 大规模弱监督 + 多任务 | 多语言、鲁棒、零样本 |

**CTC 的目标**：

$$\mathcal{L}_\text{CTC} = -\log P(y\mid x) = -\log\sum_{\pi\in\mathcal{B}^{-1}(y)}P(\pi\mid x),$$

其中 $\pi$ 是含 blank 的帧级路径，$\mathcal{B}$ 删除重复与 blank。前向后向算法可高效求和。

**语音合成（TTS）**：文本分析 → 声学模型（Tacotron、FastSpeech）→ 声码器（WaveNet、HiFi-GAN、扩散声码器）。评估用 MOS、自然度、相似度。

**说话人识别**：embedding（x-vector、ECAPA-TDNN）+ 余弦相似度/PLDA；需处理短语音、跨信道、防伪（anti-spoofing）。

**自监督语音模型**：wav2vec 2.0、HuBERT、WavLM 用掩码预测/对比学习预训练，少量标注即可微调。它们是低资源语言与语音理解的重要路线。

**语音的挑战**：噪声/混响、口音/方言、重叠说话人、流式低延迟、隐私。

## 12.4 自然语言处理

**文本处理流程**：分词（BPE/WordPiece/Unigram）→ 嵌入 → 编码器 → 任务头/解码器。

**任务谱系**：

| 任务 | 输入 → 输出 | 代表模型 |
| --- | --- | --- |
| 文本分类 | 文本 → 标签 | TextCNN、BERT |
| 序列标注 | 文本 → 每 token 标签 | BiLSTM-CRF、BERT |
| 机器翻译 | 源语言 → 目标语言 | Transformer、mBART |
| 问答 | 问题 + 文档 → 答案 | BERT、RAG |
| 摘要 | 长文 → 短文 | BART、T5、GPT |
| 对话 | 上下文 → 回复 | GPT、指令微调模型 |
| 代码 | 自然语言/代码 → 代码 | Codex、StarCoder |

**词嵌入**：word2vec、GloVe、FastText；上下文嵌入（ELMo、BERT）解决多义。

**预训练范式**：

- **编码器 + 掩码语言模型**（BERT）：适合理解类任务；
- **解码器 + 自回归**（GPT）：适合生成；
- **编码器-解码器 + span corruption**（T5、BART）：适合 seq2seq；
- **指令微调 + 对齐**（RLHF/DPO）：让模型遵循人类意图（附录 A.3–A.4）。

**评估**：分类用准确率/F1，翻译用 BLEU/chrF/COMET，摘要用 ROUGE/BERTScore，开放生成用人工评估与 LLM-as-judge（需谨慎）。困惑度用于语言模型内部比较，不直接代表任务性能。

**NLP 的挑战**：歧义、长文档、事实性/幻觉、数据污染、版权、偏见、多语言覆盖、推理与工具使用。

## 12.5 推荐、图、强化学习与科学计算

**推荐系统**：

```
召回（候选生成）→ 排序（精排）→ 重排（多样性/业务规则）
```

- 协同过滤/矩阵分解是基线；
- 深度模型：双塔（用户/物品）、DeepFM、DIN、序列推荐（SASRec、BERT4Rec）；
- 图神经网络用于社交/物品关系；
- 强化学习用于长期收益与探索；
- 评估：AUC/GAUC、NDCG、召回率、在线 CTR/CVR/留存。

**图上的深度学习**：消息传递 GNN 用于分子性质、知识图谱补全、社交推荐、欺诈检测、代码分析。挑战：过平滑、过挤压、大规模采样、异质图。

**强化学习**：

- 游戏（AlphaGo、DQN、MuZero）；
- 机器人（模仿学习、Sim2Real、世界模型）；
- 推荐/广告（长期收益）；
- 大模型对齐（RLHF，附录 A.4）。

**科学计算**：

| 领域 | 应用 | 方法 |
| --- | --- | --- |
| 生物 | 蛋白结构（AlphaFold）、分子生成 | 等变网络、图网络、扩散 |
| 物理 | 天气、流体、粒子 | 神经算子、GNN、PINN |
| 材料 | 性质预测、逆向设计 | GNN、生成模型、主动学习 |
| 医学 | 影像诊断、病理、药物发现 | CNN/ViT、自监督、多模态 |
| 数学 | 定理证明、符号计算 | 语言模型 + 搜索/验证器 |

**游戏与决策**：AlphaGo/AlphaZero 用 MCTS + 价值/策略网络；MuZero 学世界模型；这些系统说明“学习 + 搜索”的组合威力。

## 12.6 从论文到产品

**复现的难点**：

- 论文省略数据清洗、增强、调参细节；
- 计算资源不同导致 batch/学习率不可直接照搬；
- 评估协议、预处理、后处理差异；
- 随机种子与框架版本影响结果。

**落地的关键问题**：

| 维度 | 问题 | 对策 |
| --- | --- | --- |
| 数据 | 标注成本、隐私、版权、偏差 | 主动学习、合成数据、联邦学习、合规审查 |
| 模型 | 泛化、鲁棒性、可解释 | 领域自适应、对抗训练、解释工具 |
| 系统 | 延迟、吞吐、显存、功耗 | 量化、蒸馏、剪枝、专用硬件 |
| 业务 | 指标错位、反馈回路 | 离线/在线一致性、A/B、长期指标 |
| 风险 | 幻觉、滥用、安全 | 评测、护栏、红队、人工审核 |

**模型选择**：不是越大越好。要综合精度、延迟、成本、可维护性与合规。小模型 + 好数据 + 好工程，常胜过大模型 + 差管线。

**一句话总结**：应用章节的共性是**用领域先验设计表示、用大规模数据训练、用工程手段部署**；真正困难的不在模型结构，而在数据、评估、成本与责任。

## 本章小结

**核心要点**

1. 大规模训练靠数据/张量/流水线/专家并行与混合精度；通信与显存是主要瓶颈。
2. 视觉的四大任务是分类、检测、分割、生成；CNN 与 ViT 各有归纳偏置，检测/分割依赖多尺度与精细定位。
3. 语音识别从混合 HMM 系统走向 CTC/Seq2Seq/Conformer/Whisper；自监督预训练显著降低标注需求。
4. NLP 从词嵌入走到预训练 Transformer；理解用编码器、生成用解码器、seq2seq 用编码器-解码器。
5. 推荐是“召回 → 排序 → 重排”的多阶段系统；图、强化学习与科学计算各有领域特定的结构与评估。
6. 从论文到产品的难点是数据、复现、延迟、成本、合规与反馈回路，而不是模型结构本身。
7. 应用的成功公式：**领域先验 + 大规模数据 + 可扩展训练 + 严谨评估 + 工程部署**。
