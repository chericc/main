# 第 17 章 蒙特卡洛方法（Monte Carlo Methods）

**本章导读**：很多概率量无法解析计算：高维积分、配分函数、后验期望、生成模型的负相。蒙特卡洛（MC）用**随机采样**近似这些量，把“积分”变成“平均”。本章讨论：MC 估计（17.1）、重要性采样（17.2）、马尔可夫链蒙特卡洛（17.3）、Gibbs 采样（17.4）、Metropolis–Hastings 与哈密顿蒙特卡洛（17.5）、混合与诊断（17.6），最后是深度学习中的用途（17.7）。

**学习目标**：完成本章学习后，你应当能够：

- 写出 MC 估计、方差与标准误，判断需要多少样本；
- 用重要性采样估计期望，计算有效样本量并识别权重退化；
- 说明 MCMC 的平稳分布、细致平衡与混合；
- 推导 Gibbs 采样的条件更新，说明其适用与局限；
- 写出 Metropolis–Hastings 接受率与 HMC 的 leapfrog 步骤；
- 用 trace、$\hat R$、ESS 诊断收敛；
- 判断何时用采样、何时用变分/精确推断。

**预备知识**：第 3 章的概率与期望、第 16 章的图模型与配分函数；第 4 章的对数域计算；基础马尔可夫链概念。

## 17.1 蒙特卡洛估计

**目标**：估计

$$s = \mathbb{E}_{x\sim p}[f(x)] = \int f(x)p(x)\,dx.$$

**MC 估计**：从 $p$ 独立采样 $x_1,\dots,x_n$，

$$\hat s_n = \frac{1}{n}\sum_{i=1}^{n} f(x_i).$$

**性质**：

- **无偏**：$\mathbb{E}[\hat s_n] = s$；
- **方差**：$\operatorname{Var}(\hat s_n) = \operatorname{Var}(f(x))/n$；
- **标准误**：$\mathrm{SE} = \hat\sigma_f/\sqrt n$；
- **大数定律**：$n\to\infty$ 时 $\hat s_n \to s$（依概率）；
- **中心极限定理**：$\sqrt n(\hat s_n - s) \Rightarrow \mathcal{N}(0,\sigma_f^2)$。

**误差尺度**：误差约 $O(1/\sqrt n)$，与维度 $d$ **无关**（这是 MC 相对网格积分的优势）。但若 $f$ 的方差大，常数项可能很大；高维中 $f$ 的方差通常随维度增长，实际精度仍受“维度灾难”影响。

**例子**：估计 $\pi$：在单位正方形内均匀采样，落在四分之一圆内的比例乘以 4。误差约 $1/\sqrt n$，要精确到小数点后 3 位需要约 $10^6$ 个样本。

**方差缩减**：

| 方法 | 思路 |
| --- | --- |
| 重要性采样 | 换一个更好的提议分布 |
| 控制变量 | 减去已知期望的项 |
| 分层/拟蒙特卡洛 | 更均匀地覆盖空间 |
| 对偶变量 | 利用负相关样本 |
| Rao–Blackwellization | 对部分变量解析积分 |
| 并行/多链 | 独立链平均 |

## 17.2 重要性采样

**问题**：$p$ 难采样，但 $q$ 易采样。用 $q$ 的样本估计 $p$ 下的期望：

$$\mathbb{E}_{p}[f(x)] = \mathbb{E}_{q}\left[\frac{p(x)}{q(x)}f(x)\right] \approx \frac{1}{n}\sum_{i=1}^{n} w_i f(x_i),$$

其中 $w_i = p(x_i)/q(x_i)$，$x_i\sim q$。

**要求**：$q(x)>0$  wherever $p(x)f(x)\ne0$；否则估计有偏。

**未归一化分布**：若只知道 $\tilde p$、$\tilde q$，用**自归一化重要性采样**：

$$\hat s = \frac{\sum_i \tilde w_i f(x_i)}{\sum_i \tilde w_i},\qquad \tilde w_i = \frac{\tilde p(x_i)}{\tilde q(x_i)}.$$

它是有偏的（有限样本），但一致且通常更实用；配分函数比 $Z_p/Z_q$ 也被隐式估计。

**有效样本量（ESS）**：

$$\mathrm{ESS} = \frac{\left(\sum_i w_i\right)^2}{\sum_i w_i^2} = \frac{1}{\sum_i \tilde w_i^2}\quad(\text{归一化后}).$$

ESS 衡量“多少个样本真正起作用”。若权重集中在少数样本，ESS 远小于 $n$，估计方差大。

**权重退化**：高维中 $p$ 与 $q$ 稍有差异，权重比就会指数级波动。对策：更好的提议分布、退火/桥接、重采样、分层。

**选择提议分布**：希望 $q$ 在 $p$ 高概率且 $f$ 大的区域有足够覆盖，同时权重方差小。最优提议（在最小化 $\operatorname{Var}$ 意义下）为 $q^*(x)\propto |f(x)|p(x)$，但通常不可采样。

## 17.3 马尔可夫链蒙特卡洛

**问题**：$p$ 复杂，无法独立采样。MCMC 构造一个马尔可夫链，使其**平稳分布**为 $p$。

**转移核** $T(x'\mid x)$：从 $x$ 跳到 $x'$ 的概率密度。若

$$\pi(x)T(x'\mid x) = \pi(x')T(x\mid x'),$$

则称链满足**细致平衡（detailed balance）**，此时 $\pi$ 是平稳分布：

$$\pi(x') = \int \pi(x)T(x'\mid x)\,dx.$$

**收敛**：在不可约、非周期、正常返等条件下，链从任意初始分布出发都会收敛到 $\pi$。收敛速度由**混合时间**决定。

**实践要点**：

- **burn-in**：丢弃初期未收敛的样本；
- ** thinning**：每隔若干步取一个样本，降低自相关（但通常不如直接增加样本有效）；
- **多链**：从不同初始点出发，帮助发现多峰；
- **自相关**：相邻样本相关，有效样本量小于总样本数。

**自相关与 ESS**：

$$\mathrm{ESS} = \frac{n}{1+2\sum_{k=1}^{\infty}\rho_k},$$

其中 $\rho_k$ 是滞后 $k$ 的自相关。正相关越高，ESS 越小。

## 17.4 Gibbs 采样

**思想**：每次固定其他变量，从条件分布 $p(x_i\mid x_{-i})$ 采样。它是 Metropolis–Hastings 的一个特例，接受率恒为 1。

**算法**：

```
初始化 x
for t = 1..T:
    for i = 1..d:
        x_i ~ p(x_i | x_1,...,x_{i-1}, x_{i+1},...,x_d)
```

**优点**：

- 不需要调提议分布；
- 条件分布常是简单的（如 RBM 的 sigmoid、高斯模型的条件高斯）；
- 对图模型，只需按马尔可夫毯更新。

**缺点**：

- 变量强相关时混合慢（“之”字形）；
- 需要能采样条件分布；
- 多峰分布可能长期卡在一个峰。

**块 Gibbs**：一次更新一组变量，减少相关；**折叠 Gibbs（collapsed Gibbs）**：对部分变量解析积分，降低方差、加速混合（LDA 的常用做法）。

**RBM 的 Gibbs**：给定 $v$ 采样 $h$，再给定 $h$ 采样 $v$，交替进行；这是 CD 的基础。

## 17.5 Metropolis–Hastings 与哈密顿蒙特卡洛

**Metropolis–Hastings（MH）**：从提议分布 $q(x'\mid x)$ 采样候选，以概率

$$A(x\to x') = \min\left(1,\;\frac{p(x')q(x\mid x')}{p(x)q(x'\mid x)}\right)$$

接受。若拒绝，保留原样本。只需知道 $p$ 的未归一化值，配分函数约掉。

**随机游走 MH**：$q(x'\mid x)=\mathcal{N}(x';\;x,\sigma^2 I)$。步长 $\sigma$ 太小 → 接受率高但移动慢；太大 → 拒绝率高。理想接受率约 0.234（高维）。

**哈密顿蒙特卡洛（HMC）**：引入辅助动量 $p$，定义哈密顿量

$$H(q,p) = U(q) + K(p),\qquad U(q)=-\log\tilde p(q),\qquad K(p)=\frac12 p^\top M^{-1}p.$$

用**leapfrog** 积分模拟哈密顿动力学：

```
p ← p - (ε/2) ∇U(q)
q ← q + ε M^{-1} p
p ← p - (ε/2) ∇U(q)
```

再用 MH 接受/拒绝修正离散误差。HMC 利用梯度，能沿概率等高线高效移动，适合高维连续后验。

**NUTS**（No-U-Turn Sampler）：自动选择轨迹长度，避免手调；是 Stan/PyMC 的默认采样器之一。

**温度退火与并行回火**：

$$p_\beta(x) \propto \exp(-\beta E(x)),\qquad \beta\in[0,1].$$

高温链（$\beta$ 小）容易跨越能量壁垒，低温链（$\beta=1$）采样目标分布；链间交换状态，帮助多峰混合。

**序贯蒙特卡洛（SMC）**：用一系列中间分布逐步逼近目标，配合重采样；常用于状态空间模型、配分函数估计与贝叶斯推断。

## 17.6 混合与诊断

**混合（mixing）**：链多快“忘记”初始状态并覆盖目标分布。混合慢的常见原因：

- 维度高、变量强相关；
- 多峰、窄谷；
- 提议步长不合适；
- 条件分布难采样。

**诊断工具**：

| 工具 | 作用 |
| --- | --- |
| Trace plot | 看链是否稳定、是否卡住 |
| $\hat R$（Gelman–Rubin） | 多链之间与链内方差比，接近 1 表示收敛 |
| ESS | 有效独立样本数 |
| 自相关函数 | 看滞后相关性 |
| 接受率 | MH/HMC 调步长 |
| 后验预测检查 | 模型是否捕捉数据 |

**$\hat R$**：

$$\hat R = \sqrt{\frac{\hat{\operatorname{Var}}^+}{W}},$$

其中 $W$ 是链内方差，$\hat{\operatorname{Var}}^+$ 是混合方差估计。经验上 $\hat R<1.01$ 可认为收敛（但并非绝对）。

**多峰问题**：单链可能只探索一个峰，$\hat R$ 看起来很好却漏掉其他峰。对策：多起点、并行回火、SMC、变分推断提供初始点。

## 17.7 在深度学习中的用途

| 场景 | 用法 |
| --- | --- |
| 贝叶斯神经网络 | 对权重后验采样（HMC、MC Dropout、SGLD） |
| 生成模型 | RBM/DBM 的负相、能量模型采样 |
| 扩散模型 | 反向去噪采样（Langevin/score-based） |
| 配分函数 | AIS、桥接采样、退火（第 18 章） |
| 不确定性 | 预测分布、置信区间、异常检测 |
| 强化学习 | 基于采样的规划（MCTS、PETS） |
| 数据增强/合成 | 从生成模型采样 |

**采样 vs 变分**：

| 维度 | MCMC | 变分推断 |
| --- | --- | --- |
| 渐近性 | 一致（足够时间） | 有偏（近似族限制） |
| 速度 | 慢、串行 | 快、可并行/摊销 |
| 诊断 | 有成熟工具 | 难判断偏差 |
| 多峰 | 可探索（需技巧） | 常锁定单峰 |
| 大规模 | 难 | 易 |

**实践建议**：

- 低维、需要精确后验 → MCMC（HMC/NUTS）；
- 高维、大批量、需要快速预测 → 变分/摊销推断；
- 生成模型训练 → 结合 CD/得分匹配/变分；
- 评估生成模型 → AIS/桥接采样估计对数似然（小模型/低维）。

**一句话总结**：蒙特卡洛把“难算的积分”变成“可采样的平均”；MCMC 用平稳分布构造采样，Gibbs/MH/HMC 是三种核心机制；它的代价是方差、混合与计算时间。

## 本章小结

**核心要点**

1. MC 估计无偏，误差约 $O(1/\sqrt n)$，与维度无关但方差随问题增长。
2. 重要性采样用提议分布换样本，ESS 衡量有效样本；高维中权重退化是主要风险。
3. MCMC 构造平稳分布为目标分布的马尔可夫链；细致平衡是常用充分条件。
4. Gibbs 按条件分布逐变量更新，简单但强相关时混合慢；块/折叠 Gibbs 可改善。
5. MH 用接受率修正提议；HMC 用梯度与哈密顿动力学高效探索高维连续空间。
6. 混合受多峰、维度、步长影响；trace、$\hat R$、ESS 是基本诊断。
7. 深度学习用采样做贝叶斯推断、能量模型训练、扩散生成与配分函数估计；采样与变分各有取舍。
