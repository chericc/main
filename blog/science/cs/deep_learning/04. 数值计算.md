# 第 4 章 数值计算（Numerical Computation）

**本章导读**：深度学习算法最终要在有限精度的浮点数上执行。数学上等价的公式，在计算机上可能一个稳定、一个溢出。本章讨论数值计算的基本问题：上溢与下溢（4.1）、病态条件（4.2）、基于梯度的优化（4.3）、约束优化（4.4）、线性最小二乘（4.5），最后汇总深度学习中常见的数值陷阱（4.6）。本章的目标不是证明定理，而是建立“写公式时先想数值”的工程直觉。

**学习目标**：完成本章学习后，你应当能够：

- 用 log-sum-exp 稳定计算 softmax 与对数概率；
- 解释条件数、病态矩阵与误差放大的关系；
- 写出梯度、雅可比、Hessian 与二阶泰勒展开；
- 区分局部极小、全局极小与鞍点，说明高维优化的特点；
- 用拉格朗日乘子与 KKT 条件处理约束优化；
- 推导线性最小二乘的正规方程与 SVD 解；
- 识别并修复 NaN、log(0)、除零、梯度爆炸等常见问题。

**预备知识**：第 2 章的矩阵与特征值；第 3 章的概率与期望；多元微积分（偏导、梯度、泰勒展开）。

---

## 4.1 上溢、下溢与数值稳定

**浮点数的现实**：FP32 的最大值约为 $3.4\times10^{38}$，最小值正规数约为 $1.2\times10^{-38}$；FP16 的范围更窄。超出范围会产生 `inf`（上溢）或 `0`（下溢），随后的运算可能出现 `nan`。

**softmax 的溢出**：直接计算

$$\operatorname{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

时，若某个 $z_i = 1000$，$e^{1000}$ 会溢出。解决方案是减去最大值：

$$\operatorname{softmax}(z)_i = \frac{e^{z_i - m}}{\sum_j e^{z_j - m}},\qquad m = \max_j z_j.$$

由于分子分母同乘 $e^{-m}$，结果不变；指数最大为 0，不会上溢，分母至少为 1，不会下溢为零。

**log-sum-exp**：计算 $\log\sum_j e^{z_j}$ 时同理：

$$\log\sum_j e^{z_j} = m + \log\sum_j e^{z_j - m}.$$

这是“对数域加法”的标准实现，广泛用于 HMM 的前向算法、CRF 的配分函数、变分推断与混合模型。

**对数概率**：概率连乘容易下溢。用对数把乘法变加法：

$$\log p(x_1,\dots,x_n) = \sum_i \log p(x_i\mid x_{<i}).$$

语言模型、序列标注、朴素贝叶斯都应在对数域计算。需要恢复概率时，用 `exp` 并注意范围。

**sigmoid 的稳定实现**：

$$\sigma(z) = \begin{cases}\dfrac{1}{1+e^{-z}}, & z \ge 0,\\[4pt] \dfrac{e^{z}}{1+e^{z}}, & z < 0.\end{cases}$$

两种写法避免 $e^{|z|}$ 上溢。类似地，`log(1+exp(z))` 应使用 `softplus` 的稳定版本。

**概率归一化的累计误差**：反复乘除会让概率偏离 1；训练时优先用 logits 与 `log_softmax`，而不是先 softmax 再取 log。

## 4.2 病态条件

**条件数**衡量函数对输入扰动的敏感度。对线性系统 $Ax = b$，

$$\kappa(A) = \|A\|\,\|A^{-1}\| = \frac{\sigma_{\max}}{\sigma_{\min}}.$$

条件数大意味着 $b$ 的微小误差会被放大 $\kappa$ 倍。若 $\kappa = 10^6$，FP32 的约 7 位有效数字可能只剩 1 位可信。

**几何直觉**：$Ax=b$ 的解是多个超平面的交点。若两个平面几乎平行，交点对扰动极其敏感。特征值跨越多个数量级时，优化问题的等高线是狭长椭球，梯度下降会在窄方向上反复震荡。

**深度学习的对应物**：

- Hessian 的条件数大 → 优化困难（第 8 章）；
- 特征尺度差异大 → 需要标准化或归一化；
- 协方差矩阵接近奇异 → 求逆不稳定，应使用正则化或伪逆；
- RNN 的 Jacobian 谱半径偏离 1 → 梯度消失/爆炸（第 10 章）。

**对策**：标准化输入、使用伪逆或截断 SVD、加 $\epsilon I$ 正则、用 QR/Cholesky 分解代替显式求逆、采用对数域计算。

## 4.3 基于梯度的优化

**导数与梯度**：对 $f:\mathbb{R}^n\to\mathbb{R}$，梯度

$$\nabla_x f(x) = \left(\frac{\partial f}{\partial x_1},\dots,\frac{\partial f}{\partial x_n}\right)^\top$$

指向函数增长最快的方向。**方向导数**为 $\nabla f(x)^\top u$（$\|u\|=1$），因此负梯度方向是局部下降最快的方向。

**梯度下降**：

$$x_{t+1} = x_t - \eta \nabla f(x_t),$$

其中 $\eta$ 是学习率。学习率过大震荡/发散，过小收敛慢。

**雅可比与 Hessian**：对向量值函数 $f:\mathbb{R}^n\to\mathbb{R}^m$，雅可比 $J\in\mathbb{R}^{m\times n}$，$J_{ij} = \partial f_i/\partial x_j$。对标量函数，Hessian $H_{ij} = \partial^2 f/\partial x_i\partial x_j$，是对称矩阵。

**二阶泰勒展开**：

$$f(x+\Delta) \approx f(x) + \nabla f(x)^\top \Delta + \frac12 \Delta^\top H(x)\Delta.$$

- 一阶项决定下降方向；
- 二阶项决定曲率：$H$ 正定 → 局部凸，负定 → 局部凹，不定 → 鞍点。

**临界点**：$\nabla f(x)=0$ 的点。可能是局部极小、局部极大或鞍点。**高维空间中鞍点远多于局部极小**：一个 $n$ 维临界点要成为局部极小，Hessian 的 $n$ 个特征值必须全为正；随机情况下概率约 $2^{-n}$。这是“深度网络难优化不是因为局部极小”的重要论据。

**牛顿法**：用二阶近似求步长：

$$x_{t+1} = x_t - H(x_t)^{-1}\nabla f(x_t).$$

它在极小点附近二次收敛，但需要计算/存储 $n\times n$ 的 Hessian 并求逆，$n$ 很大时不可行。**拟牛顿法**（BFGS、L-BFGS）用梯度差近似 Hessian 的逆，**共轭梯度**只利用 Hessian-向量乘积。

**线搜索**：选步长 $\eta$ 使 $f(x - \eta g)$ 充分下降。Armijo 条件：

$$f(x-\eta g) \le f(x) - c\eta \|g\|^2,\qquad c\in(0,1).$$

**凸性**：$f$ 是凸函数当且仅当

$$f(\alpha x + (1-\alpha)y) \le \alpha f(x) + (1-\alpha)f(y),\qquad \alpha\in[0,1].$$

凸函数的局部极小就是全局极小；Hessian 半正定是其判据。深度网络的损失通常非凸，但实践中的优化仍能取得好解，这涉及损失 landscape、过参数化与隐式正则（第 8 章）。

## 4.4 约束优化

**等式约束**：

$$\min_x f(x)\quad \text{s.t.}\quad h(x)=0.$$

构造拉格朗日函数

$$\mathcal{L}(x,\lambda) = f(x) + \lambda^\top h(x),$$

在正则点处，最优解满足 $\nabla_x \mathcal{L}=0$、$h(x)=0$。几何上，$f$ 的梯度必须与约束曲面的法向量平行，否则可以沿曲面继续下降。

**不等式约束**：

$$\min_x f(x)\quad \text{s.t.}\quad g(x)\le 0,\quad h(x)=0.$$

**KKT 条件**（在约束品性成立时是必要条件）：

1. 平稳性：$\nabla f(x) + \sum_i \lambda_i \nabla g_i(x) + \sum_j \mu_j \nabla h_j(x) = 0$；
2. 原始可行：$g_i(x)\le 0$，$h_j(x)=0$；
3. 对偶可行：$\lambda_i \ge 0$；
4. 互补松弛：$\lambda_i g_i(x) = 0$。

互补松弛的含义是：要么约束不起作用（$g_i<0$，$\lambda_i=0$），要么约束起作用（$g_i=0$，$\lambda_i\ge0$）。

**深度学习的例子**：

- **投影梯度**：先做无约束梯度步，再投影回可行域。例如把参数投影到 $L_2$ 球（权重约束）、把输出投影到概率单纯形；
- **对抗扰动**：在 $\|\delta\|_\infty \le \epsilon$ 约束下最大化损失（FGSM/PGD）；
- **公平性约束**：在满足统计 parity 的约束下最小化损失；
- **资源约束**：在 FLOPs/延迟预算下搜索架构。

**拉格朗日对偶**：对凸问题，强对偶成立，可以通过对偶问题求解。SVM 的对偶形式就是这样得到的。

## 4.5 线性最小二乘

**问题**：

$$\min_x \|Ax - b\|_2^2.$$

**正规方程**：展开并求导，

$$A^\top A x = A^\top b.$$

若 $A^\top A$ 可逆，则 $x = (A^\top A)^{-1}A^\top b$。但显式构造 $A^\top A$ 会把条件数平方，数值上不推荐。

**SVD 解**：若 $A = U\Sigma V^\top$，则

$$x^+ = V\Sigma^+ U^\top b = A^+ b.$$

它自动处理秩亏与欠定情形：零奇异值对应的方向被丢弃，得到最小范数解。

**欠定与过定**：

- 过定（$m>n$，方程多于未知数）：通常无精确解，最小二乘找最近点；
- 欠定（$m<n$）：无穷多解，伪逆给最小 $L_2$ 范数解；
- 秩亏：某些方向不可辨识，需正则化。

**岭回归（Tikhonov 正则）**：

$$\min_x \|Ax-b\|_2^2 + \lambda\|x\|_2^2$$

的解为

$$x = (A^\top A + \lambda I)^{-1}A^\top b.$$

$\lambda>0$ 改善条件数，等价于高斯先验下的 MAP 估计。这体现了“正则化 = 数值稳定 + 先验”的双重身份。

**深度学习中的最小二乘**：

- 最后一层是线性的回归问题，闭式解可作为基线；
- 用随机投影/草图（sketching）近似大矩阵的最小二乘；
- 线性探针（linear probe）评估表示质量时，本质上是带正则的最小二乘/逻辑回归。

## 4.6 深度学习中常见的数值陷阱

| 陷阱 | 表现 | 修复 |
| --- | --- | --- |
| `log(0)` | `-inf`，污染梯度 | 加 $\epsilon$，或用 `log_softmax` |
| `exp` 上溢 | `inf`，随后 `nan` | 减最大值，log-sum-exp |
| 除以零 | `inf`/`nan` | 加 $\epsilon$，用 `where` 保护 |
| `sqrt(0)` 求导 | 梯度 `inf` | 加 $\epsilon$，或用平滑近似 |
| 概率连乘下溢 | 全为 0 | 对数域计算 |
| 混合精度下溢 | 梯度变 0 | loss scaling、BF16 |
| 方差计算误差 | 大方差时精度损失 | 用 `E[x^2]-E[x]^2` 的稳定版本或 Welford |
| 协方差奇异 | 求逆失败 | 加 $\epsilon I$、Cholesky、伪逆 |
| 梯度爆炸 | loss 变 `nan` | 梯度裁剪、降低学习率、更好的初始化 |
| 梯度消失 | 深层不更新 | ReLU/残差/归一化/门控 |

**调试顺序**：

1. 用 `torch.autograd.gradcheck` 或小规模数值梯度检查自定义算子；
2. 在 FP64 下复现，排除精度问题；
3. 打印中间张量的最小值、最大值、均值、范数；
4. 关闭混合精度、数据增强、复杂正则，先让模型在小数据上过拟合；
5. 检查学习率与初始化；用学习率扫描找发散点。

**一条实用原则**：**先保证公式在数学上正确，再保证它在浮点数上稳定，最后才谈速度**。很多“模型不收敛”的问题，根源是一个没有保护的 `log` 或一次错误的广播。

## 本章小结

**核心要点**

1. 浮点数有范围与精度限制；softmax、对数概率、sigmoid 都必须用稳定实现。
2. **条件数**衡量误差放大；病态问题需要标准化、正则化或分解方法，而不是硬求逆。
3. 梯度给出局部最速下降方向；Hessian 的谱决定曲率与临界点类型；高维中鞍点比局部极小更常见。
4. 牛顿法利用二阶信息但代价高；拟牛顿、共轭梯度、随机优化是大规模替代方案。
5. 约束优化用拉格朗日乘子与 KKT 条件描述；投影梯度是深度学习中最常见的实现。
6. 最小二乘的正规方程简单但数值不稳；SVD/伪逆与岭回归是更稳健的选择。
7. 数值 bug 的排查应遵循“FP64 复现 → 中间量检查 → 简化模型 → 学习率/初始化”的顺序。
