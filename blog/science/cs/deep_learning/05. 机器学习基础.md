# 第 5 章 机器学习基础（Machine Learning Basics）

**本章导读**：深度学习是机器学习的一种，因此“怎么定义学习、怎么评估泛化、怎么选模型”这些问题与具体网络无关。本章给出全书共同的语言：学习算法的形式定义（5.1）、容量与过拟合（5.2）、验证与超参数（5.3）、偏差-方差（5.4）、最大似然（5.5）、学习范式（5.6）、随机梯度下降（5.7），以及构建系统时的主要挑战（5.8）。

**学习目标**：完成本章学习后，你应当能够：

- 用“任务 $T$、性能 $P$、经验 $E$”描述一个学习问题；
- 解释容量、过拟合、欠拟合与正则化的关系；
- 正确划分训练/验证/测试集，选择交叉验证策略；
- 推导偏差-方差分解，诊断模型问题；
- 写出最大似然估计并说明它与 MSE、交叉熵的关系；
- 区分监督、无监督、自监督与强化学习；
- 说明 SGD 为何适合深度学习，以及 batch size 与学习率的关系；
- 列出构建机器学习系统的主要工程与统计陷阱。

**预备知识**：第 3 章的概率与期望、第 4 章的梯度与最小二乘；基础统计（均值、方差、抽样）。

## 5.1 学习算法

**Mitchell 的形式定义**：若程序在任务 $T$ 上的性能 $P$ 随着经验 $E$ 的增加而改善，则称它从 $E$ 中学习。

| 要素 | 例子（图像分类） |
| --- | --- |
| 任务 $T$ | 把图像分为 1000 类 |
| 性能 $P$ |  top-1 准确率 |
| 经验 $E$ | 带标签的图像集合 |

**监督学习的标准设定**：给定训练集

$$D = \{(x_i, y_i)\}_{i=1}^{N},$$

假设样本独立同分布（i.i.d.）地来自未知分布 $p_\text{data}$，学习一个假设 $f_\theta$，使期望风险最小：

$$R(f) = \mathbb{E}_{(x,y)\sim p_\text{data}}\big[L(f(x), y)\big].$$

由于 $p_\text{data}$ 未知，用**经验风险**替代：

$$\hat R(f) = \frac{1}{N}\sum_{i=1}^{N} L(f(x_i), y_i).$$

**经验风险最小化（ERM）** 是绝大多数训练算法的起点。深度学习的特殊之处在于：$f_\theta$ 是高度非线性的深层网络，$\hat R$ 非凸，用随机梯度法近似求解。

**一个完整的例子：线性回归**。模型 $\hat y = w^\top x + b$，损失为平方误差：

$$\hat R(w,b) = \frac{1}{N}\sum_i (w^\top x_i + b - y_i)^2.$$

令导数为零得正规方程（第 4.5 节）。线性回归有闭式解、凸目标、可解释，是理解“容量—正则—泛化”的最佳玩具模型。

**泛化**：训练误差低不代表在新数据上好。泛化误差可分解为

$$R(f) = \hat R(f) + \underbrace{(R(f) - \hat R(f))}_{\text{泛化间隙}}.$$

深度学习的关键问题不是“能不能拟合训练集”，而是“泛化间隙有多小、如何控制”。

## 5.2 容量、过拟合与欠拟合

**容量（capacity）**：模型能拟合的函数族的丰富程度。容量太小 → **欠拟合**（训练误差就高）；容量太大 → **过拟合**（训练误差低、测试误差高）。

| 现象 | 训练误差 | 验证误差 | 典型对策 |
| --- | --- | --- | --- |
| 欠拟合 | 高 | 高 | 增大模型、加特征、减少正则、训练更久 |
| 过拟合 | 低 | 高 | 更多数据、正则化、早停、数据增强、集成 |
| 刚好 | 低 | 低 | 保持，并监控分布偏移 |

**容量从哪里来**：

- 参数数量、网络深度/宽度；
- 假设空间的复杂度（多项式次数、核函数）；
- 训练时间与优化程度（早停会限制有效容量）；
- 数据增强与正则化会**降低有效容量**。

**VC 维**：VC 维是模型能“打散（shatter）”的最大样本数。对线性分类器，VC 维约为 $d+1$。PAC 学习给出泛化界，形式大致为

$$R(f) \le \hat R(f) + O\left(\sqrt{\frac{\mathrm{VC}}{N}}\right).$$

但深度网络的参数量远超样本量，VC 界给出的上界往往大于 1，完全失去解释力。这说明**容量理论不是故事的全部**：隐式正则、数据分布、优化轨迹都在起作用（第 7、8 章）。

**没有免费的午餐（No Free Lunch）**：在所有可能的目标函数上平均，任何学习算法的期望性能相同。因此，脱离任务分布谈“最强模型”没有意义；**归纳偏置**（卷积的局部性、注意力的置换等变、树的轴对齐分裂）才是性能来源。

**正则化的两种视角**：

- **工程视角**：限制模型复杂度，防止记住噪声；
- **贝叶斯视角**：加入先验 $p(\theta)$，MAP 估计等价于正则化。

高斯先验 → $L_2$ 正则；拉普拉斯先验 → $L_1$ 正则。这将在第 7 章展开。

**数据集大小**：经验风险与真实风险的差距随 $N$ 增大而缩小（大致 $O(1/\sqrt N)$）。当数据不足时，增加容量只会加剧过拟合；此时应优先增加数据、使用迁移学习或更强的先验。

## 5.3 超参数与验证集

**参数 vs 超参数**：

- **参数**：由训练数据直接优化，如权重、偏置；
- **超参数**：由人/搜索算法设定，如学习率、层数、正则系数、batch size。

**数据划分**：

```
训练集（拟合参数） → 验证集（选超参数/早停） → 测试集（最终评估，只用一次）
```

**为什么必须有验证集**：若用测试集选模型，测试集的信息会泄漏到模型选择中，最终指标会乐观偏置。测试集应视为“期末考试”，不能反复偷看。

**交叉验证**：

| 方法 | 做法 | 适用 |
| --- | --- | --- |
| 留出法 | 固定比例划分 | 数据多、训练成本高 |
| $k$ 折 | 分 $k$ 份，轮流验证 | 数据中等，最常用 |
| 留一法 | 每次留一个样本 | 数据极少，成本高 |
| 分层 $k$ 折 | 保持类别比例 | 类别不平衡 |
| 时间序列切分 | 用过去预测未来 | 时序数据，不能随机打乱 |
| 分组切分 | 同一实体不跨集合 | 用户/患者/设备泄漏 |

**数据泄漏的常见来源**：

- 先对全量数据做标准化/PCA/特征选择，再切分；
- 同一用户的多条记录分到训练与测试；
- 用未来信息预测过去；
- 目标编码（target encoding）未在折内计算；
- 重复样本跨集合。

**超参数搜索**（详见第 11.6 节）：网格搜索、随机搜索、贝叶斯优化、Hyperband/ASHA。高维空间中随机搜索通常优于网格搜索，因为并非所有超参数都同等重要。

## 5.4 估计量、偏差与方差

**点估计**：用数据估计参数，$\hat\theta = g(x_1,\dots,x_N)$。评价估计量的标准：

- **无偏性**：$\mathbb{E}[\hat\theta] = \theta$；
- **方差**：$\operatorname{Var}(\hat\theta)$，越小越稳定；
- **一致性**：$N\to\infty$ 时 $\hat\theta \to \theta$（依概率）；
- **均方误差**：$\mathrm{MSE} = \operatorname{Bias}^2 + \operatorname{Var}$。

**偏差-方差分解**（对平方损失）：

$$\mathbb{E}\big[(y - \hat f(x))^2\big] = \underbrace{\big(\mathbb{E}[\hat f(x)] - f(x)\big)^2}_{\text{偏差}^2} + \underbrace{\operatorname{Var}(\hat f(x))}_{\text{方差}} + \underbrace{\sigma^2}_{\text{不可约噪声}}.$$

| 模型 | 偏差 | 方差 | 表现 |
| --- | --- | --- | --- |
| 线性模型 | 高 | 低 | 欠拟合风险 |
| 深层网络 | 低 | 高 | 过拟合风险 |
| 集成/平均 | 略高 | 低 | 稳定 |

**标准误**：$\mathrm{SE}(\hat\mu) = \sigma/\sqrt N$。它衡量“换一批数据，估计值会变多少”，是置信区间与显著性检验的基础。

** bootstrap**：从训练集有放回重采样，重复计算统计量，得到经验分布。它可用于估计泛化误差、置信区间与模型稳定性，是小样本下最实用的重采样方法。

**偏差-方差与深度学习**：经典 U 形曲线预测“容量超过某点后测试误差上升”；但现代过参数化网络常出现**双下降**：在插值阈值附近测试误差先升后降。这提示“容量”不是单一标量，优化算法与数据几何同样重要（第 5.4 节）。

## 5.5 最大似然估计

**最大似然**：

$$\hat\theta_\text{ML} = \arg\max_\theta \prod_{i=1}^{N} p_\text{model}(x_i;\theta) = \arg\max_\theta \sum_{i=1}^{N}\log p_\text{model}(x_i;\theta).$$

**条件最大似然**（监督学习）：

$$\hat\theta_\text{ML} = \arg\max_\theta \sum_{i=1}^{N}\log p_\text{model}(y_i\mid x_i;\theta).$$

**与常见损失的关系**：

| 模型假设 | 负对数似然 | 等价损失 |
| --- | --- | --- |
| 高斯噪声 $y\sim\mathcal{N}(f(x),\sigma^2)$ | $\frac{1}{2\sigma^2}(y-f(x))^2 + \text{const}$ | 均方误差 |
| 伯努利 $y\sim\mathrm{Bern}(\sigma(f(x)))$ | $-y\log\hat y - (1-y)\log(1-\hat y)$ | 二元交叉熵 |
| 类别 $y\sim\mathrm{Cat}(\operatorname{softmax}(f(x)))$ | $-\log\hat y_y$ | 多元交叉熵 |
| 拉普拉斯噪声 | $\lvert y-f(x)\rvert$ | 平均绝对误差 |

因此，**选损失函数本质上是在选噪声模型**。MSE 假设高斯噪声，交叉熵假设伯努利/类别分布，Huber 损失介于两者之间（对离群点更鲁棒）。

**MLE 的性质**：在正则条件下，MLE 是一致的、渐近正态的、渐近有效的。但小样本时可能过拟合（如伯努利 $p=0$ 或 $1$），需要平滑或先验。

**贝叶斯估计**：把参数视为随机变量，

$$p(\theta\mid D) \propto p(D\mid\theta)p(\theta),$$

预测时对后验积分：

$$p(x_\text{new}\mid D) = \int p(x_\text{new}\mid\theta)p(\theta\mid D)\,d\theta.$$

**MAP 估计**取后验众数，等价于带正则的 MLE：

$$\hat\theta_\text{MAP} = \arg\max_\theta \big[\log p(D\mid\theta) + \log p(\theta)\big].$$

## 5.6 监督学习、无监督学习与强化学习

| 范式 | 数据 | 目标 | 例子 |
| --- | --- | --- | --- |
| 监督学习 | $(x,y)$ | 学 $f:x\mapsto y$ | 分类、回归、分割 |
| 无监督学习 | $x$ | 发现结构 | 聚类、降维、密度估计 |
| 半监督学习 | 少量 $(x,y)$ + 大量 $x$ | 利用未标注数据 | 自训练、一致性正则 |
| 自监督学习 | 自动构造的 $(x,\tilde y)$ | 表示学习 | 掩码预测、对比学习 |
| 强化学习 | 交互轨迹 $(s,a,r,s')$ | 最大化累积奖励 | 游戏、机器人、推荐 |

**监督学习的任务类型**：

- **分类**：输出离散类别；
- **回归**：输出连续值；
- **结构化预测**：输出序列、树、图、分割掩码；
- **排序**：输出候选的顺序。

**无监督学习**不只是“没有标签”：它要发现数据的低维结构、聚类、密度或生成过程。第 13–20 章的大部分内容都属于这个范畴。

**强化学习**与监督学习的关键差别：没有“正确答案”，只有延迟的奖励；数据分布由策略决定（探索与利用的权衡）；奖励可能稀疏、有噪声。详见第 12.5 节与相关文献。

## 5.7 随机梯度下降

**批量梯度下降**用全部 $N$ 个样本计算梯度：

$$\theta \leftarrow \theta - \eta \frac{1}{N}\sum_{i=1}^{N}\nabla_\theta L(f(x_i), y_i).$$

**随机梯度下降（SGD）** 每次用一个或一小批样本：

$$\theta \leftarrow \theta - \eta \frac{1}{B}\sum_{i\in\mathcal{B}}\nabla_\theta L(f(x_i), y_i).$$

**为什么 SGD 适合深度学习**：

1. 单步成本从 $O(N)$ 降到 $O(B)$，可处理大规模数据；
2. 梯度噪声可以帮助逃离鞍点与尖锐极小；
3. 噪声带来的隐式正则常改善泛化；
4. 天然适配在线/流式数据。

**梯度噪声**：小批量梯度是真实梯度的无偏估计，但方差随 $B$ 减小而增大。增大 batch 会降低噪声、允许更大学习率，但边际收益递减，且可能损害泛化。

**学习率与 batch size 的经验关系**：线性缩放规则 $\eta \propto B$ 在较小范围内成立；更大 batch 需要 warmup 与更精细的调参。第 8 章会详细讨论优化器与调度。

**收敛性**：对凸且平滑的目标，SGD 在适当递减学习率下收敛到最优；对非凸目标，只能保证收敛到临界点附近。深度学习的实践依赖于“好损失 landscape + 好初始化 + 好调度”。

## 5.8 构建机器学习系统与主要挑战

**标准流程**：

1. **定义问题与指标**：预测什么？错误的代价是什么？离线指标能否代表线上目标？
2. **收集与清洗数据**：覆盖真实分布，处理缺失、重复、噪声、偏差；
3. **建立基线**：先跑通简单模型（线性/树/最近邻），再上深度模型；
4. **划分数据**：训练/验证/测试，防止泄漏；
5. **选择模型与损失**：匹配任务与噪声假设；
6. **训练与调参**：监控训练/验证曲线，早停；
7. **评估与误差分析**：看混淆矩阵、分片指标、失败案例；
8. **部署与监控**：延迟、吞吐、漂移、回滚。

**主要挑战**：

| 挑战 | 说明 | 对策 |
| --- | --- | --- |
| 维度灾难 | 高维空间中样本稀疏，距离失去意义 | 低维表示、局部性先验、更多数据 |
| 局部不变性 | 分类器在训练点附近才可靠 | 数据增强、平滑正则、对抗训练 |
| 流形假设 | 真实数据集中在低维流形上 | 流形学习、自编码器、生成模型 |
| 分布偏移 | 训练与部署分布不同 | 领域自适应、重要性加权、持续学习 |
| 标签噪声 | 标注错误、主观歧义 | 鲁棒损失、噪声建模、清洗 |
| 类别不平衡 | 少数类被淹没 | 重采样、代价敏感、Focal Loss |
| 评估偏差 | 指标与业务目标不一致 | 多指标、分片评估、离线/在线一致性 |

**一句话总结**：机器学习 = **在假设空间中以数据为证据、以正则/先验控制复杂度、以验证集选择模型**；深度学习把这个框架中的假设空间换成了深层网络，但评估与泛化的基本原则不变。

## 本章小结

**核心要点**

1. 学习 = 从经验 $E$ 改善任务 $T$ 上的性能 $P$；ERM 是训练的基本框架，泛化间隙是核心问题。
2. 容量过小欠拟合，过大过拟合；正则化、数据增强、早停与集成都在控制**有效容量**。
3. 验证集用于选模型，测试集只用于最终评估；交叉验证与防泄漏是工程底线。
4. 偏差-方差分解诊断模型；深度学习常出现过参数化下的**双下降**，经典 U 形曲线不是全部。
5. 最大似然统一了 MSE、交叉熵与许多损失；MAP 等价于正则化，贝叶斯预测提供不确定度。
6. 监督/无监督/自监督/强化学习是不同数据与目标设定；深度学习的优势在表示学习。
7. SGD 以噪声换效率与隐式正则；batch size、学习率与调度需要联合调节。
8. 系统成败往往取决于数据质量、指标定义与分布偏移，而不是模型结构本身。
