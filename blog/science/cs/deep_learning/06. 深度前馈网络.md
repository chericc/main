# 第 6 章 深度前馈网络（Deep Feedforward Networks）

**本章导读**：前馈网络（feedforward network）是多层感知机（MLP）的现代形式，也是理解 CNN、RNN、Transformer 的起点。它的目标是把输入 $x$ 映射到输出 $y$，通过多层非线性变换学习一个参数化函数 $f(x;\theta)$。本章讨论：结构与记号（6.1）、为什么需要深度（6.2）、输出单元与损失（6.3）、隐藏单元（6.4）、架构设计（6.5）、反向传播（6.6）、完整训练示例（6.7），最后给出历史与理论注记（6.8）。

**学习目标**：完成本章学习后，你应当能够：

- 写出多层前馈网络的前向公式与维度；
- 用 XOR 说明非线性隐藏层的必要性；
- 根据任务选择输出单元与损失函数；
- 比较 ReLU、sigmoid、tanh、GELU 等激活函数的优缺点；
- 推导仿射层、ReLU、softmax 交叉熵的反向传播；
- 解释计算图、反向模式自动微分与梯度检查；
- 设计并训练一个多层感知机，诊断常见失败模式。

**预备知识**：第 2 章的矩阵乘法、第 3 章的交叉熵、第 4 章的梯度与链式法则、第 5 章的 ERM 与 SGD。

## 6.1 网络结构与记号

一个 $L$ 层前馈网络：

$$h^{(0)} = x,$$

$$z^{(l)} = W^{(l)} h^{(l-1)} + b^{(l)},\qquad l=1,\dots,L,$$

$$h^{(l)} = g^{(l)}(z^{(l)}),\qquad l=1,\dots,L-1,$$

$$\hat y = h^{(L)} = g^{(L)}(z^{(L)}).$$

- $W^{(l)} \in \mathbb{R}^{n_l\times n_{l-1}}$，$b^{(l)} \in \mathbb{R}^{n_l}$；
- $g^{(l)}$ 是激活函数，最后一层通常是输出层；
- 参数量约为 $\sum_l (n_l n_{l-1} + n_l)$。

**批形式**：若一个 batch 有 $B$ 个样本，$H^{(l-1)} \in \mathbb{R}^{B\times n_{l-1}}$，则

$$Z^{(l)} = H^{(l-1)} (W^{(l)})^\top + \mathbf{1}_B (b^{(l)})^\top.$$

不同框架的权重布局可能相反（$W h$ 还是 $hW$），推导时以维度为准。

**通用近似定理（universal approximation）**：含足够多隐藏单元的单隐层网络，能以任意精度逼近紧集上的连续函数。直觉上，每个隐藏单元是一个“台阶”或“基函数”，足够多的组合可以拼出任意形状。

**定理没有说的事**：

- 需要多少单元（可能随维度指数增长）；
- 需要多少数据才能学到；
- 梯度下降能否找到这些参数；
- 学到的函数是否泛化。

因此“万能近似”只是表达力的下限保证，不是深度学习成功的解释。

## 6.2 为什么需要深度：XOR 与表示

**XOR 问题**：输入 $(x_1,x_2)\in\{0,1\}^2$，输出 $x_1 \oplus x_2$。四个点中，$(0,0),(1,1)$ 为 0，$(0,1),(1,0)$ 为 1。任何一条直线都无法分开这两类，因此**线性模型无法解决 XOR**。

**加一个隐藏层**：取

$$h_1 = \mathrm{ReLU}(x_1+x_2-0.5),\qquad h_2 = \mathrm{ReLU}(x_1+x_2-1.5),$$

则输出

$$\hat y = 2h_1 - 6h_2$$

在四个点上分别等于 $0,1,1,0$，正好是 XOR。隐藏层把原始空间映射到一个新的表示空间，在那里问题变得线性可分。

**这个例子的一般教训**：

- 深度网络的第一层不是“分类”，而是**重新表示**；
- 最后一层通常仍是线性分类器，难度被转移到表示学习；
- 手工设计 XOR 的隐藏层很容易，但真实任务的特征无法手工写出——所以需要学习。

**深度 vs 宽度**：

| 视角 | 结论 |
| --- | --- |
| 表达力 | 单隐层已能万能近似，但宽度可能指数大 |
| 表示效率 | 深层可复用低层特征，参数更省 |
| 样本效率 | 层次先验减少所需数据 |
| 优化 | 深网络更难训练，需要残差/归一化/好初始化 |

**深度分离（depth separation）**：存在一些函数，用浅层网络表示需要指数多参数，而深层网络只需多项式多参数。这为“深度有本质优势”提供了理论证据，但具体到某个任务，仍要看数据与归纳偏置。

**分布式表示**：$n$ 个隐藏单元的组合可以表示 $2^n$ 个概念。深度网络不是“一个单元记一个模式”，而是用**组合**表示概念，因此参数效率高。这也是为什么深度网络能在高维输入上工作。

## 6.3 输出单元与损失函数

输出单元的选择应与**任务类型**和**噪声假设**匹配。

| 任务 | 输出单元 | 损失 | 概率解释 |
| --- | --- | --- | --- |
| 回归（高斯噪声） | 线性 | MSE | $y\sim\mathcal{N}(\hat y,\sigma^2)$ |
| 二分类 | sigmoid | 二元交叉熵 | $y\sim\mathrm{Bern}(\hat y)$ |
| 多分类 | softmax | 多元交叉熵 | $y\sim\mathrm{Cat}(\hat y)$ |
| 多标签 | 多个 sigmoid | 逐标签 BCE | 每个标签独立伯努利 |
| 计数 | Poisson 速率（softplus） | Poisson NLL | $y\sim\mathrm{Poisson}(\lambda)$ |
| 混合密度 | 混合参数 | 混合 NLL | $y\sim\sum_k \pi_k\mathcal{N}(\mu_k,\sigma_k^2)$ |

**线性输出 + MSE**：

$$\hat y = W h + b,\qquad L = \frac{1}{2}\|\hat y - y\|^2.$$

梯度 $\partial L/\partial \hat y = \hat y - y$，简单但假设噪声方差恒定。若不同样本的噪声不同，应使用异方差回归（同时预测 $\log\sigma^2$）。

**sigmoid + 二元交叉熵**：

$$\hat y = \sigma(z),\qquad L = -y\log\hat y - (1-y)\log(1-\hat y).$$

梯度对 logits 为 $\hat y - y$，数值稳定，避免“sigmoid 饱和 + MSE”导致的梯度消失。

**softmax + 多元交叉熵**：

$$\hat y_k = \frac{e^{z_k}}{\sum_j e^{z_j}},\qquad L = -\sum_k y_k\log\hat y_k.$$

对 one-hot 标签，$L = -\log\hat y_{y}$，梯度对 logits 为 $\hat y - y$。这是分类任务的标准组合。

**为什么不用 MSE 做分类**：MSE 对 logits 的梯度在预测接近 0/1 时会消失（sigmoid 饱和），且对错误但自信的预测惩罚不足；交叉熵的梯度尺度更合理。

**损失的一致性**：输出单元、损失与评估指标应尽量一致。例如类别极不平衡时，准确率不是好指标，应看 PR-AUC、召回率或代价敏感损失。

## 6.4 隐藏单元与激活函数

**激活函数的作用**：引入非线性，使多层复合不是仿射变换。没有它，$W_2(W_1x) = (W_2W_1)x$，深度毫无意义。

| 激活 | 定义 | 优点 | 缺点 |
| --- | --- | --- | --- |
| sigmoid | $1/(1+e^{-z})$ | 输出有界、可解释 | 饱和、梯度消失、非零中心 |
| tanh | $(e^z-e^{-z})/(e^z+e^{-z})$ | 零中心、比 sigmoid 强 | 仍饱和 |
| ReLU | $\max(0,z)$ | 稀疏、梯度不衰减、计算快 | “死亡 ReLU”、非零中心 |
| Leaky ReLU | $\max(\alpha z,z)$ | 缓解死亡 | 多一个超参数 |
| PReLU | 可学习 $\alpha$ | 自适应 | 小数据易过拟合 |
| ELU | $z$ 或 $\alpha(e^z-1)$ | 负半轴平滑、接近零中心 | 计算稍贵 |
| GELU | $z\Phi(z)$ | 平滑、Transformer 常用 | 计算稍贵 |
| SiLU/Swish | $z\sigma(z)$ | 平滑、非单调 | 计算稍贵 |
| Maxout | $\max_j(w_j^\top x+b_j)$ | 表达力强 | 参数翻倍 |

**ReLU 为何成为默认**：

- 正区间梯度恒为 1，缓解梯度消失；
- 输出稀疏（约一半为 0），计算与存储高效；
- 分段线性，局部近似良好，优化景观相对简单。

**死亡 ReLU**：若某个单元的输入长期为负，梯度为 0，参数不再更新。对策：Leaky ReLU、PReLU、更小学习率、更好的初始化、BatchNorm。

**sigmoid 的现状**：隐藏层几乎不用 sigmoid，但在二分类输出、门控（LSTM）与注意力掩码中仍常见。tanh 在 RNN 与小网络中仍有使用。

**激活函数的选择原则**：

1. 默认用 ReLU 或其平滑变体；
2. 深层 Transformer 常用 GELU/SiLU；
3. 输出层按任务选线性/sigmoid/softmax；
4. 不要在同一个网络里混用太多类型，除非有明确理由。

## 6.5 架构设计

**深度与宽度**：在固定参数量下，深而窄通常比浅而宽更省参数、表达更层次化；但太深难训练。实践先从 2–4 层 MLP 开始，再根据任务加深。

**跳跃连接（skip connection）**：$y = x + F(x)$。它让梯度直接回传，缓解深层退化，是 ResNet 的核心（第 9 章）。MLP 中也可用。

**归一化**：BatchNorm、LayerNorm 稳定激活分布、允许更大学习率。MLP 常用 BatchNorm；Transformer 用 LayerNorm/RMSNorm。

**输出层设计**：

- 回归：线性输出，注意目标尺度；
- 分类：softmax + 交叉熵；
- 多任务：多个头，损失加权；
- 结构化输出：CRF、序列解码（第 16 章）。

**架构搜索（NAS）**：用强化学习、进化算法或可微搜索自动设计网络。代价高，且搜索空间的归纳偏置往往比搜索算法更重要。对多数应用，迁移一个成熟架构比从零搜索更划算。

**参数共享**：同一组权重在多个位置/任务复用。CNN 的卷积核、RNN 的时间步、多任务网络的头共享都是例子。

**容量控制**：参数量不是唯一指标；有效容量还受深度、宽度、归一化、正则、训练时长影响。

## 6.6 反向传播与自动微分

**计算图**：把 $f(x;\theta)$ 表示为有向无环图，节点是运算，边是张量。前向传播计算并缓存中间结果；反向传播从输出向输入应用链式法则。

**单层推导**：设

$$z = W h + b,\qquad h' = g(z),\qquad L = \ell(h').$$

给定上游梯度 $\partial L/\partial h'$，则

$$\frac{\partial L}{\partial z} = \frac{\partial L}{\partial h'} \odot g'(z),$$

$$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial z} h^\top,\qquad \frac{\partial L}{\partial b} = \frac{\partial L}{\partial z},\qquad \frac{\partial L}{\partial h} = W^\top \frac{\partial L}{\partial z}.$$

**批形式**：若 $Z = H W^\top + \mathbf{1}b^\top$，上游梯度 $G = \partial L/\partial Z \in \mathbb{R}^{B\times n_l}$，则

$$\frac{\partial L}{\partial W} = G^\top H,\qquad \frac{\partial L}{\partial b} = G^\top \mathbf{1},\qquad \frac{\partial L}{\partial H} = G W.$$

**softmax + 交叉熵的梯度**：对单个样本，

$$\frac{\partial L}{\partial z} = \hat y - y.$$

这是深度学习中最优雅的化简之一：**预测概率减真实标签**。它也是“logits 进损失”比“先 softmax 再算损失”更稳定的原因。

**反向传播算法**：

```
前向：
  h[0] = x
  for l in 1..L:
      z[l] = W[l] h[l-1] + b[l]
      h[l] = g(z[l])
  loss = L(h[L], y)

反向：
  delta[L] = dL/dh[L] * g'(z[L])   # 或直接由损失给出
  for l in L..1:
      dW[l] = delta[l] h[l-1]^T
      db[l] = delta[l]
      delta[l-1] = W[l]^T delta[l] * g'(z[l-1])
```

**复杂度**：一次前向约 $O(\text{参数量})$，一次反向约为前向的 2 倍。反向模式自动微分适合“参数多、输出标量”的情形，这正是深度学习。

**自动微分**：框架记录运算图，反向遍历即可。用户只需写前向，框架生成反向。**梯度检查**：用有限差分

$$\frac{\partial L}{\partial \theta_i} \approx \frac{L(\theta+\epsilon e_i) - L(\theta-\epsilon e_i)}{2\epsilon}$$

与解析梯度比较，相对误差应小于 $10^{-4}$（FP64）。这是自定义算子调试的必备步骤。

**内存换时间**：反向需要保存前向激活。**检查点（checkpointing）** 只保存部分激活，反向时重算，用计算换显存。

## 6.7 完整示例与训练循环

**任务**：MNIST 手写数字分类，$28\times28$ 灰度图 → 10 类。

**模型**：

```
输入 784
→ 全连接 256 + ReLU + Dropout(0.5)
→ 全连接 128 + ReLU + Dropout(0.5)
→ 全连接 10（logits）
→ softmax 交叉熵
```

**训练伪代码**：

```python
model = MLP([784, 256, 128, 10])
optimizer = Adam(model.parameters(), lr=1e-3, weight_decay=1e-4)
for epoch in range(num_epochs):
    for x, y in train_loader:          # x: [B, 784], y: [B]
        logits = model(x)
        loss = cross_entropy(logits, y)
        optimizer.zero_grad()
        loss.backward()
        clip_grad_norm_(model.parameters(), 1.0)
        optimizer.step()
    evaluate(model, val_loader)
```

**关键细节**：

- 输入标准化（减均值、除标准差）；
- 权重初始化用 He 初始化（配合 ReLU）；
- 训练时 Dropout 开启，推理时关闭；
- 监控训练/验证损失与准确率，早停；
- 用小批量（如 128）并打乱数据；
- 先用小数据集过拟合，确认模型与管线无误，再全量训练。

**常见失败模式**：

| 现象 | 可能原因 | 排查 |
| --- | --- | --- |
| 损失不降 | 学习率太小、初始化差、标签错、数据未归一化 | 学习率扫描、检查标签、过拟合小批 |
| 损失震荡/NaN | 学习率太大、梯度爆炸、数值 bug | 降学习率、梯度裁剪、FP64 调试 |
| 训练好验证差 | 过拟合、数据泄漏、分布不同 | 加正则/数据、检查划分 |
| 两者都差 | 欠拟合、容量不足、优化困难 | 加容量、换激活、训练更久 |

## 6.8 历史与理论注记

- **感知机（1958）** 只能做线性分类；Minsky & Papert（1969）指出其局限。
- **反向传播**在 1980 年代被系统化（Rumelhart、Hinton、Williams，1986），但当时数据与算力不足。
- **万能近似**由 Cybenko（1989）、Hornik 等（1991）证明；它解释了“为什么神经网络能表示复杂函数”，但没有解释“为什么能学得好”。
- **ReLU**（Nair & Hinton，2010）与 **Dropout**（2012）、**BatchNorm**（2015）、**ResNet**（2015）让深层网络真正可训练。
- 现代 MLP 很少单独用于图像/文本，但它是 Transformer 的前馈块、CNN 的分类头、所有深度模型的基本组件。

**一句话总结**：前馈网络 = **仿射变换 + 非线性激活的复合**；深度提供层次表示，反向传播提供学习信号，输出单元与损失把任务转化为概率建模。

## 本章小结

**核心要点**

1. 前馈网络是 $L$ 层“仿射 + 非线性”的复合；没有非线性，深度退化为线性模型。
2. XOR 说明隐藏层的本质是**重新表示**；万能近似保证表达力，但不保证样本效率与可学性。
3. 输出单元与损失应匹配任务与噪声假设：线性+MSE、sigmoid+BCE、softmax+CE。
4. ReLU 是隐藏层默认选择；深层网络需要好的初始化、归一化与残差连接。
5. **反向传播 = 链式法则 + 动态规划**；softmax+CE 的梯度化简为 $\hat y - y$。
6. 自动微分让“写前向、得反向”成为现实；梯度检查与检查点是工程必备。
7. 训练失败大多来自数据、学习率、初始化与数值问题，而不是“网络不够深”。
