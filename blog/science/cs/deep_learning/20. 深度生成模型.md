# 第 20 章 深度生成模型（Deep Generative Models）

**本章导读**：生成模型学习数据分布 $p(x)$，既能评估样本概率，也能采样新样本。深度生成模型有六大路线：能量模型（玻尔兹曼机族）、变分自编码器、生成对抗网络、自回归模型、归一化流，以及近年来主导图像/视频生成的扩散模型。本章按“分类（20.1）→ 能量模型（20.2）→ VAE（20.3）→ GAN（20.4）→ 自回归（20.5）→ 流（20.6）→ 扩散（20.7）→ 评价与风险（20.8）”展开。

**学习目标**：完成本章学习后，你应当能够：

- 按“显式/隐式似然、可解/近似”对生成模型分类；
- 写出 RBM/DBN/DBM 的能量与训练难点；
- 推导 VAE 的 ELBO、重参数化与后验坍塌；
- 写出 GAN 的极小极大目标、最优判别器与 Wasserstein 目标；
- 说明自回归模型的似然与采样；
- 用变量替换公式推导归一化流的对数似然；
- 写出扩散模型的前向/反向过程与去噪损失；
- 选择评价指标，识别生成模型的偏见、版权与滥用风险。

**预备知识**：第 3 章的概率与 KL、第 16 章的能量模型、第 17–19 章的采样与变分推断、第 14 章的自编码器；第 6–9 章的神经网络基础。

## 20.1 生成模型的分类

| 维度 | 类型 | 代表 |
| --- | --- | --- |
| 似然 | 显式（可解） | 自回归、归一化流 |
| 似然 | 显式（近似） | VAE（ELBO）、能量模型（AIS） |
| 似然 | 隐式/无似然 | GAN、扩散（可用 score/ELBO 分析） |
| 隐变量 | 有 | VAE、GAN、扩散（多步） |
| 隐变量 | 无 | 自回归、流 |
| 采样 | 单步 | GAN、VAE |
| 采样 | 多步/自回归 | 扩散、自回归、流 |

**生成模型要回答的三个问题**：

1. **密度估计**：$p(x)$ 是多少？（异常检测、压缩、似然比较）
2. **采样**：如何生成新样本？（图像、音频、文本）
3. **推断**：给定 $x$，隐变量 $z$ 是什么？（表示学习、编辑）

不同模型在三者上的强弱不同：自回归/流擅长密度，GAN 擅长快速高质量采样，VAE 擅长推断与编辑，扩散擅长质量与多样性但采样慢。

## 20.2 玻尔兹曼机族

**RBM**（第 16 章）：

$$E(v,h) = -b^\top v - c^\top h - v^\top W h,\qquad p(v,h)=\frac{e^{-E(v,h)}}{Z}.$$

- 条件分布为 sigmoid，可块 Gibbs；
- 训练用 CD/PCD 近似负相；
- 自由能 $F(v)=-b^\top v-\sum_j\log(1+e^{c_j+W_{:,j}^\top v})$。

**DBN**：顶层 RBM + 下层有向生成；逐层预训练 + 微调。它曾是深层生成模型的突破口。

**DBM**：全无向多层能量模型；表达力强，但推断与训练困难（需要预训练、持续 CD、并行回火）。

**深度能量模型（Deep Energy Model）**：用深度网络参数化 $E_\theta(x)$，不显式建模隐变量：

$$p_\theta(x) = \frac{e^{-E_\theta(x)}}{Z(\theta)}.$$

训练可用得分匹配（不需要 $Z$）或 NCE；采样用 Langevin 动力学：

$$x_{t+1} = x_t - \frac{\epsilon}{2}\nabla_x E_\theta(x_t) + \sqrt{\epsilon}\,\eta_t.$$

**能量模型的优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 极灵活，可表示任意分布 | 配分函数不可解 |
| 可结合物理/约束 | 训练不稳定、采样慢 |
| 得分匹配可绕开 $Z$ | 评估困难 |

**历史地位**：RBM/DBN 让“深层生成模型”可行，但在图像质量与训练稳定性上被 VAE/GAN/扩散超越；能量模型的思想在得分匹配、扩散、EBM 复兴中延续。

## 20.3 变分自编码器

**模型**：

$$z\sim p(z)=\mathcal{N}(0,I),\qquad x\mid z\sim p_\theta(x\mid z).$$

**推断网络**：$q_\phi(z\mid x)$ 近似后验。

**ELBO**：

$$\log p_\theta(x) \ge \mathbb{E}_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big] - \mathrm{KL}\big(q_\phi(z\mid x)\|p(z)\big).$$

- 第一项是重构（或条件似然）；
- 第二项让后验接近先验，起正则作用；
- 联合优化 $\theta,\phi$。

**重参数化**：

$$z = \mu_\phi(x) + \sigma_\phi(x)\odot\epsilon,\qquad \epsilon\sim\mathcal{N}(0,I).$$

梯度可穿过采样，方差远小于 REINFORCE。

**解码器分布**：

- 二值/灰度像素：伯努利 + BCE；
- 连续像素：高斯 + MSE（需固定方差）；
- 离散 token：类别 + 交叉熵；
- 文本：自回归解码器（VAE 语言模型）。

**后验坍塌（posterior collapse）**：若解码器太强（如自回归），它可能忽略 $z$，使 $q_\phi(z\mid x)\approx p(z)$，KL 项趋 0，隐变量失效。对策：

- **KL 退火**（warm-up）：训练初期给 KL 项小权重；
- **free bits**：允许每个维度有一定 KL 预算；
- **弱解码器/受限容量**；
- **skip connection**：让解码器直接看输入；
- **β-VAE**：调大 KL 权重以追求解耦（但重构变差）。

**β-VAE**：

$$\mathcal{L} = \mathbb{E}_q[\log p(x\mid z)] - \beta\,\mathrm{KL}(q\|p).$$

$\beta>1$ 鼓励解耦表示，但可能牺牲重构；解耦与重构存在权衡。

**层次 VAE**：多层隐变量 $z_1,\dots,z_L$，建模更抽象的结构；训练更难，需要 warm-up、跳连、谱归一化。

**VAE 的优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 有概率编码器，可推断/编辑 | 生成样本常偏模糊 |
| 训练稳定、似然下界 | 后验近似有间隙 |
| 隐空间平滑、可插值 | 先验/解码器假设敏感 |

**现代变体**：VQ-VAE（离散码本）、NVAE、Hierarchical VAE、Diffusion VAE、VAE + 对抗损失。

## 20.4 生成对抗网络

**极小极大目标**：

$$\min_G\max_D\;\mathbb{E}_{x\sim p_\text{data}}[\log D(x)] + \mathbb{E}_{z\sim p(z)}[\log(1-D(G(z)))].$$

**最优判别器**（固定 $G$）：

$$D^*(x) = \frac{p_\text{data}(x)}{p_\text{data}(x)+p_g(x)}.$$

代回目标，得到

$$\max_D V(D,G) = -\log 4 + 2\,\mathrm{JSD}(p_\text{data}\|p_g).$$

因此理想情况下，训练 $G$ 最小化的是数据分布与生成分布的 Jensen–Shannon 散度。

**训练技巧**：

- 非饱和损失：$\max_G \mathbb{E}[\log D(G(z))]$，避免早期梯度消失；
- 标签平滑/单侧标签平滑；
- 谱归一化、梯度惩罚；
- 小学习率、Adam（$\beta_1=0.5$）；
- 多判别器更新/延迟更新；
- 批归一化/实例归一化；
- 经验回放、mini-batch discrimination。

**模式坍塌（mode collapse）**：$G$ 只生成少数模式，$D$ 难以区分。对策：WGAN、unrolled GAN、minibatch discrimination、多样性正则。

**Wasserstein GAN**：

$$\min_G\max_{\|f\|_L\le1}\;\mathbb{E}_{x\sim p_\text{data}}[f(x)] - \mathbb{E}_{z}[f(G(z))].$$

- 用 Lipschitz 约束的 critic 代替判别器；
- 目标与 Wasserstein 距离相关，梯度更平滑；
- 权重裁剪（原版）或梯度惩罚（WGAN-GP）实现约束。

**f-GAN**：用 $f$-散度统一 GAN 目标；不同的 $f$ 导出不同的对抗损失。

**条件 GAN**：$G(z,c)$、$D(x,c)$，用于类别/文本/图像条件生成。

**GAN 的优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 采样快（单步） | 训练不稳定 |
| 样本锐利 | 模式坍塌 |
| 无需显式似然 | 难评估、难比较 |
| 适合感知质量 | 隐空间不如 VAE 规整 |

**评价**：FID、IS、Precision/Recall、CLIPScore、人工评估。FID 依赖特征提取器与样本量，不能完全代表质量。

## 20.5 自回归生成模型

**链式法则**：

$$p(x) = \prod_{i=1}^{d} p(x_i\mid x_{<i}).$$

**优势**：似然可精确计算，训练稳定（每步是分类/回归），采样按顺序生成。

**代表**：

| 模型 | 数据 | 结构 |
| --- | --- | --- |
| PixelCNN | 图像像素 | 掩码卷积 |
| WaveNet | 音频波形 | 空洞因果卷积 |
| GPT | 文本 token | 因果 Transformer |
| ImageGPT | 图像 token | Transformer |
| VQ-VAE + 自回归先验 | 离散码本 | 两阶段生成 |

**掩码卷积**：确保预测 $x_i$ 时只能看到 $x_{<i}$，不能看到未来像素。PixelCNN 用 A/B 掩码区分“是否包含当前像素”。

**采样慢**：生成长度 $d$ 需 $d$ 次前向；可用缓存（KV cache）、并行采样、投机解码加速。

**自回归的偏差**：暴露偏差（训练用真实前缀，推理用生成前缀）；长序列误差累积；顺序依赖限制并行。

**自回归 vs 扩散**：自回归似然精确、适合离散 token；扩散并行去噪、适合连续高维信号。两者在图像/视频生成中都有应用，且可结合（自回归先验 + 扩散解码）。

## 20.6 归一化流

**变量替换**：若 $x=f(z)$ 是可逆可微映射，则

$$p_x(x) = p_z\big(f^{-1}(x)\big)\left|\det\frac{\partial f^{-1}}{\partial x}\right|.$$

取对数：

$$\log p_x(x) = \log p_z(z) - \log\left|\det\frac{\partial f}{\partial z}\right|.$$

**要求**：$f$ 可逆、雅可比行列式易算。**流**由多个可逆层堆叠：

$$z_K = f_K\circ\cdots\circ f_1(x),\qquad \log p_x(x) = \log p_z(z_K) + \sum_{k=1}^{K}\log\left|\det J_{f_k^{-1}}\right|.$$

**常见层**：

| 层 | 思路 | 行列式 |
| --- | --- | --- |
| 耦合层（RealNVP） | 一半维度变换，另一半不变 | 对角/三角，易算 |
| 自回归流（MAF/IAF） | 每维依赖前面维度 | 三角，易算 |
| 可逆 $1\times1$ 卷积（Glow） | 通道混合 | $\lvert\det W\rvert$ |
| 连续流（CNF） | ODE 定义变换 | 迹积分（似然需 ODE 求解） |

**耦合层**：

$$y_{1:d} = x_{1:d},\qquad y_{d+1:D} = x_{d+1:D}\odot\exp(s(x_{1:d})) + t(x_{1:d}).$$

逆变换容易，雅可比是三角矩阵，行列式为 $\exp(\sum s)$。

**优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 精确对数似然 | 需要可逆架构，表达受限 |
| 精确采样与推断 | 维度必须匹配 |
| 训练稳定 | 深层流的数值/计算成本 |

**应用**：密度估计、异常检测、生成、变分推断的富化后验（normalizing flow as variational family）。

## 20.7 扩散模型与得分匹配

**核心思想**：前向过程逐步加噪，把数据变成简单分布；反向过程学习去噪，从噪声恢复数据。

**前向过程**：

$$q(x_t\mid x_{t-1}) = \mathcal{N}\big(x_t;\;\sqrt{1-\beta_t}\,x_{t-1},\;\beta_t I\big),$$

$$q(x_t\mid x_0) = \mathcal{N}\big(x_t;\;\sqrt{\bar\alpha_t}\,x_0,\;(1-\bar\alpha_t)I\big),\qquad \bar\alpha_t=\prod_{s=1}^{t}(1-\beta_s).$$

**反向过程**：

$$p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\big(x_{t-1};\;\mu_\theta(x_t,t),\;\Sigma_\theta(x_t,t)\big).$$

**训练目标**（预测噪声）：

$$\mathcal{L} = \mathbb{E}_{t,x_0,\epsilon}\left[\left\|\epsilon - \epsilon_\theta\big(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\;t\big)\right\|_2^2\right].$$

**采样**（DDPM）：

$$x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{1-\alpha_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right) + \sigma_t z,\qquad z\sim\mathcal{N}(0,I).$$

**与得分匹配的联系**：去噪网络隐式估计 score：

$$\nabla_{x_t}\log q(x_t) \approx -\frac{\epsilon_\theta(x_t,t)}{\sqrt{1-\bar\alpha_t}}.$$

因此扩散模型可看作“多尺度去噪得分匹配 + Langevin 采样”。**得分 SDE** 框架把离散步骤推广到连续时间，用概率流 ODE 做确定性采样。

**条件生成与引导**：

- **分类器引导**：$\nabla\log p(x_t\mid c)=\nabla\log p(x_t)+\nabla\log p(c\mid x_t)$；
- **无分类器引导（CFG）**：

$$\hat\epsilon = \epsilon_\theta(x_t,\varnothing) + s\big(\epsilon_\theta(x_t,c)-\epsilon_\theta(x_t,\varnothing)\big),$$

$s>1$ 增强条件一致性，但过高会降低多样性。

**加速采样**：DDIM、DPM-Solver、蒸馏（Progressive Distillation、Consistency Models）、Latent Diffusion（在 VAE 隐空间扩散，降低分辨率）。

**扩散的优缺点**：

| 优点 | 缺点 |
| --- | --- |
| 样本质量高、多样性好 | 采样多步、慢 |
| 训练稳定（回归目标） | 似然计算/评估复杂 |
| 条件生成灵活 | 计算/内存成本高 |
| 理论联系 score/SDE | 对噪声调度敏感 |

**应用**：文本到图像（Stable Diffusion、DALL·E、Midjourney）、视频（Sora 类模型）、音频、分子、蛋白质、医学影像。

## 20.8 评价、选择与风险

**评价指标**：

| 指标 | 衡量 | 局限 |
| --- | --- | --- |
| 对数似然/bpd | 密度估计 | 跨模型/预处理不可比 |
| FID | 生成分布与真实分布的特征距离 | 依赖特征网络、样本量 |
| IS | 质量与多样性 | 对模式坍塌不敏感 |
| Precision/Recall | 质量/覆盖 | 需特征空间 |
| CLIPScore | 图文一致性 | 继承 CLIP 偏见 |
| 人工评估 | 真实偏好 | 昂贵、主观 |

**选择建议**：

- 需要精确似然/异常检测 → 自回归、流；
- 需要快速高质量采样 → GAN、蒸馏扩散；
- 需要隐空间编辑/推断 → VAE、扩散；
- 需要多模态条件生成 → 扩散 + 条件编码器；
- 离散序列（文本/代码）→ 自回归。

**风险与伦理**：

- **偏见与刻板印象**：生成模型放大训练数据中的偏见；
- **版权与同意**：训练数据、风格模仿、肖像权；
- **虚假信息/深度伪造**：需要水印、检测、内容凭证；
- **隐私**：记忆训练样本、成员推断；
- **滥用**：生成有害内容、绕过安全过滤；
- **环境成本**：训练与推理的能耗。

**一句话总结**：生成模型的五条路线分别在“似然可解性、采样速度、样本质量、推断能力”上取舍；扩散模型以多步去噪换取质量与稳定，自回归以精确似然换取顺序生成，GAN 以对抗换取单步锐利，VAE 以显式隐空间换取可编辑性，能量模型以灵活性换取训练难度。

## 本章小结

**核心要点**

1. 生成模型可按显式/隐式似然、单步/多步采样、是否有隐变量分类；没有一种模型在所有维度上最优。
2. RBM/DBN/DBM 用能量与配分函数建模，训练依赖 MCMC/近似；它们奠定了深层生成模型的基础。
3. VAE 最大化 ELBO，用重参数化训练；后验坍塌与模糊样本是主要问题，β-VAE 追求解耦。
4. GAN 用对抗训练学隐式分布；最优判别器对应 JSD，WGAN 用 Wasserstein 距离改善稳定性。
5. 自回归模型用链式法则给出精确似然，采样顺序进行；GPT/PixelCNN/WaveNet 是代表。
6. 归一化流用可逆变换与变量替换给出精确似然；耦合层让雅可比易算。
7. 扩散模型通过前向加噪/反向去噪训练，损失是噪声预测；它与得分匹配、SDE 理论紧密相连。
8. 评价需结合似然、FID、Precision/Recall 与人工评估；生成模型带来偏见、版权、虚假信息与隐私风险。
