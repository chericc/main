# 第 19 章 近似推断（Approximate Inference）

**本章导读**：给定观测 $x$ 与含隐变量 $z$ 的模型，推断就是求后验 $p(z\mid x)$、边缘 $p(x)$ 或期望。精确推断通常不可行；近似推断有两大路线：**变分推断**（把推断变成优化）与**采样**（第 17 章）。本章讨论：推断即优化（19.1）、EM 再审视（19.2）、变分推断与平均场（19.3）、结构化变分（19.4）、信念传播与期望传播（19.5）、摊销/可学习推断（19.6）、离散隐变量与重参数化（19.7），最后是诊断与选择（19.8）。

**学习目标**：完成本章学习后，你应当能够：

- 写出 ELBO，并说明它与对数似然、KL 的关系；
- 把 EM 解释为“精确 E 步 + M 步”的变分推断；
- 推导平均场坐标上升更新；
- 区分结构化变分、信念传播与期望传播；
- 说明摊销推断、重参数化技巧与 VAE 的联系；
- 用 Gumbel-Softmax/直通估计处理离散隐变量；
- 用 ELBO 间隙、后验预测与 IWAE 诊断近似质量。

**预备知识**：第 3 章的 KL 与贝叶斯法则、第 16 章的图模型、第 17 章的 MCMC、第 18 章的配分函数；第 5 章的最大似然。

## 19.1 推断即优化

**问题**：模型 $p(x,z)=p(z)p(x\mid z)$，观测 $x$，隐变量 $z$。推断目标包括：

- 后验 $p(z\mid x)=p(x,z)/p(x)$；
- 边缘似然 $p(x)=\int p(x,z)\,dz$；
- 期望 $\mathbb{E}_{p(z\mid x)}[f(z)]$；
- 配分函数 $Z=p(x)$。

**为什么难**：$p(x)$ 需要对 $z$ 积分/求和；高维、非线性模型下不可解。

**变分推断的核心**：选一个易处理的分布族 $\mathcal{Q}$，找 $q\in\mathcal{Q}$ 最接近真实后验：

$$q^*(z) = \arg\min_{q\in\mathcal{Q}} \mathrm{KL}\big(q(z)\,\|\,p(z\mid x)\big).$$

**ELBO 推导**：

$$\log p(x) = \mathrm{KL}\big(q(z)\|p(z\mid x)\big) + \underbrace{\mathbb{E}_q[\log p(x,z)] - \mathbb{E}_q[\log q(z)]}_{\text{ELBO}},$$

$$\mathcal{L}(q) = \mathbb{E}_q[\log p(x,z)] + H(q) = \mathbb{E}_q[\log p(x\mid z)] - \mathrm{KL}\big(q(z)\|p(z)\big).$$

由于 $\mathrm{KL}\ge0$，$\mathcal{L}(q)\le\log p(x)$；最大化 ELBO 等价于最小化 $\mathrm{KL}(q\|p(z\mid x))$。**ELBO 间隙** $\log p(x)-\mathcal{L}(q)$ 就是后验近似误差。

**KL 的方向**：这里最小化的是 $\mathrm{KL}(q\|p)$（反向 KL），倾向让 $q$ 锁定后验的**一个模式**，而不是覆盖所有模式。这是变分推断“过度自信/欠估计方差”的根源。

## 19.2 期望最大化再审视

**EM** 是变分推断的一个特例：$\mathcal{Q}$ 取所有可能分布（不限制族）。

**E 步**：固定参数 $\theta$，令 $q(z)=p(z\mid x,\theta)$，此时 ELBO 等于 $\log p(x\mid\theta)$，间隙为 0。

**M 步**：固定 $q$，最大化

$$\mathbb{E}_q[\log p(x,z\mid\theta)]$$

对 $\theta$。由于 E 步后 ELBO 与似然相切，M 步提升 ELBO 也提升似然（单调性）。

**变分 EM**：当真实后验不可解时，E 步用受限族 $q$ 做变分优化（而不是精确后验），M 步仍最大化期望完全数据对数似然。它不再保证似然单调，但通常有效。

**MAP-EM / 硬 EM**：E 步用后验的**众数**（点估计）而不是完整分布；它优化的是联合概率的下界，收敛更快但方差估计差。K-means 可看作 GMM 的硬 EM 极限。

**EM 的局限**：局部最优、对初始化敏感、需要条件分布可解；GMM 的奇异解需要给协方差加 $\epsilon I$ 正则。

## 19.3 变分推断与平均场

**平均场（mean field）** 假设隐变量在 $q$ 下独立：

$$q(z) = \prod_{i=1}^{m} q_i(z_i).$$

**坐标上升（CAVI）**：固定其他 $q_j$，最优 $q_i$ 为

$$\log q_i^*(z_i) = \mathbb{E}_{q_{-i}}\big[\log p(z,x)\big] + \text{const}.$$

即“在其余变量的期望下，取完整条件分布”。对共轭模型，$q_i$ 与先验同族，更新是矩匹配。

**算法**：

```
初始化 q
repeat:
    for i = 1..m:
        q_i(z_i) ∝ exp(E_{q_{-i}}[log p(z,x)])
until ELBO 收敛
```

**例子：高斯混合**。$q(z_i=k)=r_{ik}$（责任度），$q(\mu_k,\Lambda_k)$ 为高斯-Wishart；CAVI 在责任度与参数后验之间交替，类似 EM 但参数有分布。

**平均场的偏差**：它忽略了后验中的相关性，通常**低估方差**；对强相关变量，近似可能很差。但它快、可扩展、易诊断（ELBO 单调）。

**ELBO 的随机优化**：当数据大时，用 mini-batch 估计 ELBO，SGD 更新变分参数；这使变分推断能扩展到大规模数据。

## 19.4 结构化变分推断

**动机**：平均场假设太强。若后验有明显结构（时序、空间、树），应让 $q$ 保留这些依赖。

**结构化变分族**：

- **链式**：$q(z)=\prod_t q(z_t\mid z_{t-1})$，类似 HMM；
- **树**：$q$ 按树分解；
- **块**：把强相关变量放在同一因子中；
- **可逆流**：$q(z)=q_0(f^{-1}(z))|\det J_f|^{-1}$，用归一化流增强表达力（第 20 章）。

**权衡**：结构越丰富，优化越难、每次更新越贵；但近似误差更小。

**变分参数**：可以是每样本的自由参数（mean field），也可以是共享的神经网络（摊销，19.6）。

**半摊销/混合**：用网络给出初始 $q$，再用几步随机变分推断精修；兼顾速度与精度。

## 19.5 信念传播与期望传播

**信念传播（BP）**：在因子图上传递消息，精确计算树上的边缘与配分函数。

变量到因子：

$$\mu_{x\to f}(x) = \prod_{g\in N(x)\setminus f}\mu_{g\to x}(x),$$

因子到变量：

$$\mu_{f\to x}(x) = \sum_{x_{N(f)\setminus x}} f(x_{N(f)})\prod_{y\in N(f)\setminus x}\mu_{y\to f}(y).$$

**边缘**：$p(x)\propto\prod_{f\in N(x)}\mu_{f\to x}(x)$。**配分函数**可由消息归一化常数累乘得到。

**环状图（loopy BP）**：在一般图上迭代消息，不保证收敛，也不保证精确；但实践中（如 LDPC 码、CRF）常表现良好。它优化的是 **Bethe 自由能**，是 ELBO 的一个近似。

**期望传播（EP）**：用高斯/指数族近似每个因子，通过**矩匹配**更新；它最小化 $\mathrm{KL}(p\|q)$ 的局部版本（与变分的 $\mathrm{KL}(q\|p)$ 方向相反），因此倾向覆盖后验的矩而不是锁定单峰。EP 在稀疏高斯过程、分类任务中常用，但可能不稳定。

**BP vs 变分**：

| 维度 | 变分推断 | 信念传播 |
| --- | --- | --- |
| 目标 | ELBO（全局） | Bethe 自由能（局部） |
| 精确性 | 有偏（族限制） | 树上精确，环上近似 |
| 速度 | 可随机/并行 | 消息传递，可能慢 |
| 适用 | 连续/大模型 | 离散/图结构/CRF |

## 19.6 摊销推断与可学习推断

**问题**：mean field 需要为每个样本单独优化 $q_i$，推理成本高。**摊销推断（amortized inference）** 用共享网络直接预测变分参数：

$$q_\phi(z\mid x) = \mathcal{N}\big(z;\;\mu_\phi(x),\operatorname{diag}(\sigma_\phi^2(x))\big).$$

编码器一次前向给出后验近似，训练时与生成模型联合优化 ELBO。

**VAE**（第 20 章）：编码器 $q_\phi(z\mid x)$ + 解码器 $p_\theta(x\mid z)$，目标

$$\mathcal{L} = \mathbb{E}_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)] - \mathrm{KL}\big(q_\phi(z\mid x)\|p(z)\big).$$

**重参数化技巧**：从 $q_\phi(z\mid x)$ 采样时，把随机性外置：

$$z = \mu_\phi(x) + \sigma_\phi(x)\odot\epsilon,\qquad \epsilon\sim\mathcal{N}(0,I).$$

这样梯度可以通过 $\mu,\sigma$ 回传，方差比 REINFORCE 小得多。

**Wake–Sleep**：交替用“醒”阶段（从数据采样，训练生成模型）与“睡”阶段（从模型采样，训练推断网络）。它是早期可学习推断的方法，现代多用 ELBO 联合训练。

**半摊销**：网络输出初始 $q$，再用少量迭代精修；适合需要高精度后验的场景。

**推断网络的风险**：

- **摊销间隙（amortization gap）**：网络容量不足时，$q_\phi$ 不能逼近每个样本的后验；
- **后验坍塌**：解码器太强时，$q$ 忽略 $z$，KL 项把 $q$ 推向先验；
- **分布偏移**：训练时 $x$ 来自数据，测试时可能不同。

## 19.7 离散隐变量与重参数化技巧

**问题**：离散 $z$ 无法直接对采样做重参数化；REINFORCE/得分函数估计方差大。

**Gumbel-Softmax（Concrete）**：对类别分布 $\alpha$，采样

$$g_i = -\log(-\log U_i),\qquad U_i\sim\mathrm{Uniform}(0,1),$$

$$y_i = \frac{\exp((\log\alpha_i+g_i)/\tau)}{\sum_j\exp((\log\alpha_j+g_j)/\tau)}.$$

- $\tau>0$ 是温度；$\tau\to0$ 时 $y$ 接近 one-hot；
- 前向可用硬采样，反向用软松弛的梯度（直通估计，straight-through）；
- 它是离散分布的连续松弛，广泛用于 VAE、离散潜变量、架构搜索。

**直通估计（STE）**：

$$y_\text{hard} = \operatorname{onehot}(\arg\max y),\qquad y = y_\text{hard} + y_\text{soft} - \operatorname{stopgrad}(y_\text{soft}).$$

前向用硬值，反向用软梯度；简单但梯度有偏。

**REINFORCE / 得分函数估计**：

$$\nabla_\phi \mathbb{E}_{q_\phi}[f(z)] = \mathbb{E}_{q_\phi}\big[f(z)\nabla_\phi\log q_\phi(z)\big].$$

无偏但方差大；可用基线（baseline）、方差缩减、局部期望估计改善。

**其他方法**：NVIL、VIMCO（多样本）、REBAR、Gumbel 直通、离散流。

## 19.8 诊断与选择

**诊断**：

| 工具 | 作用 |
| --- | --- |
| ELBO 曲线 | 是否收敛、是否震荡 |
| ELBO 间隙 | 与精确/更紧下界比较 |
| IWAE 界 | 用 $K$ 个样本得到更紧的下界 |
| 后验预测检查 | 生成数据是否像真实数据 |
| 后验方差 | 是否过度自信（mean field 常见） |
| 重构误差 | 是否欠拟合/过拟合 |

**IWAE 下界**：

$$\log p(x) \ge \mathbb{E}_{z_1,\dots,z_K\sim q}\left[\log\frac{1}{K}\sum_{k=1}^{K}\frac{p(x,z_k)}{q(z_k\mid x)}\right].$$

$K=1$ 时退化为 ELBO；$K$ 增大时界更紧，但计算更贵。它也可用于评估变分族的表达力。

**选择建议**：

- 低维、需要精确后验 → MCMC（HMC/NUTS）；
- 高维、大批量、需要快速推理 → 摊销变分/VAE；
- 有图结构、离散变量 → BP/EP 或结构化变分；
- 需要紧下界/评估 → IWAE、AIS；
- 离散隐变量 → Gumbel-Softmax/STE/REINFORCE（按方差与偏差权衡）。

**一句话总结**：近似推断把“求后验”变成“优化下界”或“采样”；变分推断快但有偏，MCMC 准但慢，摊销推断把推理成本摊到训练中。选择取决于模型结构、数据规模与精度要求。

## 本章小结

**核心要点**

1. 精确后验通常不可解；变分推断用易处理分布 $q$ 近似，最大化 ELBO。
2. $\log p(x)=\mathrm{ELBO}+\mathrm{KL}(q\|p(z\mid x))$；ELBO 间隙衡量近似误差，反向 KL 倾向锁定单峰。
3. EM 是“精确 E 步 + M 步”的变分推断；变分 EM 用受限 $q$ 替代精确后验。
4. 平均场假设隐变量独立，CAVI 坐标上升；它快但低估方差，强相关时近似差。
5. 结构化变分、BP、EP 利用图结构；BP 在树上精确，环上近似（Bethe 自由能）。
6. 摊销推断用网络直接预测 $q$ 参数；重参数化使梯度低方差，是 VAE 的核心。
7. 离散隐变量用 Gumbel-Softmax/STE/REINFORCE；各有偏差-方差权衡。
8. 诊断用 ELBO、IWAE、后验预测与后验方差；方法选择取决于精度、规模与结构。
