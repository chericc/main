# 第 2 章 线性代数（Linear Algebra）

**本章导读**：深度学习的所有运算最终都落到张量上：一次前向传播是矩阵乘与逐元素非线性，一次反向传播是雅可比矩阵的转置相乘。本章不追求线性代数的完整体系，而是围绕“读懂深度学习公式”组织：对象与记号（2.1）、矩阵运算与范数（2.2）、特征分解（2.3）、奇异值分解（2.4）、行列式、迹与特征值（2.5）、主成分分析（2.6），最后讨论计算复杂度与稀疏性（2.7）。

**学习目标**：完成本章学习后，你应当能够：

- 熟练读写标量、向量、矩阵、张量的记号与维度；
- 判断矩阵乘法、Hadamard 积、转置与逆的合法性；
- 解释 $L_1$、$L_2$、$L_\infty$ 与 Frobenius 范数的几何意义；
- 用特征分解理解二次型、正定矩阵与谱半径；
- 写出 SVD，并用它求伪逆与低秩近似；
- 用行列式与迹解释体积、可逆性与特征值关系；
- 从零推导 PCA，说明它与 SVD 的等价性。

**预备知识**：高中数学的向量与矩阵；求和记号；复数的最基本概念（只需知道共轭）。

## 2.1 标量、向量、矩阵与张量

| 对象 | 记号 | 阶 | 例子 |
| --- | --- | --- | --- |
| 标量 | $a \in \mathbb{R}$ | 0 | 学习率 $\eta = 0.001$ |
| 向量 | $\boldsymbol{x} \in \mathbb{R}^n$ | 1 | 一个词的嵌入 |
| 矩阵 | $A \in \mathbb{R}^{m\times n}$ | 2 | 一层权重 |
| 张量 | $\mathcal{T} \in \mathbb{R}^{d_1\times\cdots\times d_k}$ | $k$ | 一批彩色图像 $(B,C,H,W)$ |

**约定**：向量默认是列向量；$A_{ij}$ 表示第 $i$ 行第 $j$ 列；$A_{i,:}$ 是行，$A_{:,j}$ 是列。深度学习中常见“批”维度放在最前：$X \in \mathbb{R}^{B\times d}$ 表示 $B$ 个样本、每个 $d$ 维。

**转置**：$(A^\top)_{ij} = A_{ji}$，满足 $(AB)^\top = B^\top A^\top$。**注意顺序反转**，这是推导反向传播时最常出错的地方之一。

**广播（broadcasting）**：当形状不完全一致时，框架按规则扩展长度为 1 的维度。例如 $X \in \mathbb{R}^{B\times d}$ 加偏置 $b \in \mathbb{R}^{d}$，实际执行 $X + \mathbf{1}_B b^\top$。广播让代码简洁，但也容易掩盖维度错误；调试时应打印形状。

**单位矩阵与对角矩阵**：$I_n$ 的对角线为 1、其余为 0；$\operatorname{diag}(v)$ 把向量放到对角线上。对角矩阵的乘法等价于逐元素缩放。

## 2.2 矩阵运算与范数

**矩阵乘法**：若 $A \in \mathbb{R}^{m\times n}$，$B \in \mathbb{R}^{n\times p}$，则 $C = AB \in \mathbb{R}^{m\times p}$：

$$C_{ij} = \sum_{k=1}^{n} A_{ik} B_{kj}.$$

矩阵乘法满足结合律与分配律，但**不满足交换律**：$AB \ne BA$（甚至形状都可能不匹配）。

**Hadamard 积**：逐元素相乘，$(A \odot B)_{ij} = A_{ij}B_{ij}$，要求形状相同。深度学习中的门控、掩码、注意力权重都用它。

**逆矩阵**：若 $A$ 是方阵且存在 $A^{-1}$ 使 $AA^{-1} = A^{-1}A = I$，则称 $A$ 可逆。可逆等价于行列式非零、列线性无关、满秩。数值上很少显式求逆，通常解线性方程组 $Ax = b$。

**线性相关、张成与秩**：一组向量的线性组合构成其**张成（span）**；若没有非平凡组合为零，则线性无关。矩阵的**秩**是列空间维数，也是最大线性无关列数。低秩是压缩与推荐系统的基础。

**范数**：范数衡量向量“大小”，需满足非负、齐次与三角不等式。

| 范数 | 定义 | 特点 |
| --- | --- | --- |
| $L_1$ | $\|x\|_1 = \sum_i \lvert x_i\rvert$ | 稀疏解（Lasso） |
| $L_2$ | $\|x\|_2 = \sqrt{\sum_i x_i^2}$ | 欧氏长度，光滑 |
| $L_\infty$ | $\|x\|_\infty = \max_i \lvert x_i\rvert$ | 最大坐标，对抗扰动常用 |
| Frobenius | $\|A\|_F = \sqrt{\sum_{ij} A_{ij}^2}$ | 矩阵版 $L_2$ |
| 核范数 | $\|A\|_* = \sum_i \sigma_i$ | 奇异值之和，低秩正则 |

**正交与标准正交**：$x^\top y = 0$ 称正交；若一组向量两两正交且长度为 1，则标准正交。标准正交矩阵 $Q$ 满足 $Q^\top Q = I$，因此 $Q^{-1} = Q^\top$，乘法不改变 $L_2$ 长度。

**深度学习中的例子**：

- 全连接层 $y = Wx + b$ 是仿射变换；
- 一个 batch 的前向 $Y = XW + \mathbf{1}b^\top$；
- 卷积可以写成稀疏的 Toeplitz 矩阵乘法（见第 9 章）；
- 嵌入表 $E \in \mathbb{R}^{V\times d}$ 的查表等价于 one-hot 向量左乘 $E$。

## 2.3 特征分解与二次型

对方阵 $A \in \mathbb{R}^{n\times n}$，若存在非零向量 $v$ 与标量 $\lambda$ 使

$$Av = \lambda v,$$

则 $v$ 是**特征向量**，$\lambda$ 是**特征值**。特征值满足特征多项式 $\det(A - \lambda I) = 0$。

**对角化**：若 $A$ 有 $n$ 个线性无关的特征向量，则可写成

$$A = V \operatorname{diag}(\lambda) V^{-1}.$$

**对称矩阵**（$A = A^\top$）有更好的性质：

- 特征值全为实数；
- 存在标准正交特征向量矩阵 $Q$，使 $A = Q\Lambda Q^\top$；
- 因此 $A$ 的幂、指数、逆都可以在特征基下逐元素计算。

**正定矩阵**：对任意非零 $x$，$x^\top A x > 0$。对称矩阵正定等价于所有特征值为正；半正定则允许零特征值。协方差矩阵、Hessian 在极小点附近都常是半正定的。

**二次型**：

$$x^\top A x = \sum_{i,j} A_{ij} x_i x_j.$$

对称化后 $x^\top A x = x^\top \frac{A+A^\top}{2}x$，所以只需关心对称部分。二次型的等值面是椭球，主轴方向由特征向量给出，轴长与 $1/\sqrt{\lambda_i}$ 成正比。这解释了为什么**病态（条件数大）**的 Hessian 会让梯度下降呈“之”字形（第 4、8 章）。

**谱半径**：$\rho(A) = \max_i \lvert\lambda_i\rvert$。循环网络的梯度稳定性与 Jacobian 的谱半径密切相关；谱半径持续小于 1 会导致梯度消失，大于 1 会导致爆炸。

**例子：协方差矩阵**。中心化数据 $X \in \mathbb{R}^{N\times d}$ 的协方差为 $\Sigma = \frac{1}{N}X^\top X$。它对称半正定，特征值表示各主方向的方差。

## 2.4 奇异值分解与伪逆

**SVD**：任意矩阵 $A \in \mathbb{R}^{m\times n}$ 都可分解为

$$A = U\Sigma V^\top,$$

其中 $U \in \mathbb{R}^{m\times m}$、$V \in \mathbb{R}^{n\times n}$ 是正交矩阵，$\Sigma \in \mathbb{R}^{m\times n}$ 是对角矩阵，对角元 $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$ 是**奇异值**。

- $U$ 的列是 $AA^\top$ 的特征向量（左奇异向量）；
- $V$ 的列是 $A^\top A$ 的特征向量（右奇异向量）；
- 非零奇异值的平方是 $AA^\top$ 与 $A^\top A$ 的非零特征值。

**低秩近似（Eckart–Young）**：保留前 $k$ 个奇异值，

$$A_k = \sum_{i=1}^{k} \sigma_i u_i v_i^\top,$$

在所有秩不超过 $k$ 的矩阵中，$A_k$ 是 Frobenius 范数意义下距离 $A$ 最近的矩阵。这是 PCA、图像压缩、推荐系统矩阵分解的理论基础。

**伪逆**：对不可逆或非方阵，Moore–Penrose 伪逆定义为

$$A^+ = V\Sigma^+ U^\top,$$

其中 $\Sigma^+$ 把非零奇异值取倒数再转置。它给出最小二乘问题的最小范数解：

$$A^+ b = \arg\min_x \|Ax - b\|_2^2 \quad \text{（在最小范数解中）}.$$

**条件数**：$\kappa(A) = \sigma_{\max}/\sigma_{\min}$。条件数大意味着输入的小扰动会被放大，数值求解不稳定。截断 SVD 通过丢弃小奇异值来正则化，是常用的稳定化手段。

**深度学习中的 SVD**：

- 权重矩阵的低秩分解可压缩模型；
- LoRA 用两个低秩矩阵 $BA$ 近似权重更新（附录 A.7）；
- 对激活做 SVD 可以分析表示的有效维度；
- 谱归一化用最大奇异值控制 Lipschitz 常数（GAN 稳定训练）。

## 2.5 行列式、迹与特征值

**行列式**：$\det(A)$ 表示线性变换对体积的缩放因子。性质：

- $\det(AB) = \det(A)\det(B)$；
- $\det(A^{-1}) = 1/\det(A)$；
- $\det(A) = \prod_i \lambda_i$；
- 行列式为零 ⇔ 矩阵不可逆 ⇔ 列线性相关。

**迹**：$\operatorname{tr}(A) = \sum_i A_{ii}$。性质：

- $\operatorname{tr}(AB) = \operatorname{tr}(BA)$（循环置换）；
- $\operatorname{tr}(A) = \sum_i \lambda_i$；
- $\operatorname{tr}(A^\top A) = \|A\|_F^2$。

**特征值与矩阵函数**：对可对角化矩阵，$f(A) = V f(\Lambda) V^{-1}$。因此矩阵指数、对数、逆都可以通过特征值理解。例如 $e^A$ 的特征值是 $e^{\lambda_i}$，在连续时间动力系统中描述状态演化。

**雅可比与 Hessian**：对 $f:\mathbb{R}^n \to \mathbb{R}^m$，雅可比 $J_{ij} = \partial f_i/\partial x_j$；对 $f:\mathbb{R}^n \to \mathbb{R}$，Hessian $H_{ij} = \partial^2 f/\partial x_i\partial x_j$ 对称。Hessian 的特征值刻画局部曲率：全正 → 局部极小，全负 → 局部极大，有正有负 → 鞍点。高维深度网络的临界点大多是鞍点而非局部极小，这是第 8 章的重要背景。

## 2.6 主成分分析：一个完整的例子

**问题**：把 $N$ 个 $d$ 维样本压缩到 $k$ 维，同时尽量保留方差。

**步骤**：

1. **中心化**：$\tilde X = X - \mathbf{1}\mu^\top$，其中 $\mu = \frac{1}{N}\sum_i x_i$；
2. **协方差**：$\Sigma = \frac{1}{N}\tilde X^\top \tilde X$；
3. **特征分解**：$\Sigma = Q\Lambda Q^\top$，按特征值从大到小排序；
4. **投影**：取前 $k$ 个特征向量 $Q_k$，$Z = \tilde X Q_k$；
5. **解释方差比**：$\frac{\sum_{i=1}^k \lambda_i}{\sum_{j=1}^d \lambda_j}$。

**与 SVD 的等价性**：对 $\tilde X$ 做 SVD，$\tilde X = U\Sigma V^\top$，则 $V$ 的列就是协方差的主方向，奇异值满足 $\sigma_i^2/N = \lambda_i$。因此实践中直接对数据矩阵做 SVD 更稳定，不必显式构造协方差。

**PCA 的局限**：

- 只捕捉**线性**结构；非线性流形需要自编码器、UMAP 等（第 14、15 章）；
- 方差大不等于任务相关，可能丢掉判别性弱但重要的方向；
- 对尺度敏感，需先标准化；
- 主成分的符号与顺序在数值上可能不稳定。

**一个数值例子**：若二维数据沿 $y = x$ 分布，协方差矩阵为 $\begin{pmatrix}2&2\\2&2\end{pmatrix}$，特征值为 $4,0$，第一主方向是 $(1,1)^\top/\sqrt2$。投影到一维后，所有点近似落在一条直线上，方差保留率为 100%。

## 2.7 计算复杂性与稀疏性

| 运算 | 复杂度 | 备注 |
| --- | --- | --- |
| 矩阵乘 $m\times n$ 与 $n\times p$ | $O(mnp)$ | GPU 的核心工作负载 |
| 求逆 | $O(n^3)$ | 实际用分解而非显式求逆 |
| 特征分解 | $O(n^3)$ | 对称矩阵可用更稳定的算法 |
| SVD（完整） | $O(\min(mn^2, m^2n))$ | 截断 SVD 可更快 |
| 解 $Ax=b$ | $O(n^3)$（稠密） | 稀疏时用迭代法 |

**稀疏矩阵**：当大多数元素为零时，只存非零值与索引，可大幅节省内存与计算。自然语言中的词共现、图邻接矩阵、推荐系统的用户-物品矩阵都是稀疏的。

**结构化矩阵**：Toeplitz、循环、低秩、块对角矩阵都有快速乘法。卷积层本质上利用的就是**平移结构**与**权值共享**，把 $O(n^2)$ 的全连接变成 $O(kn)$ 的局部运算。

**给深度学习实践者的三条建议**：

1. 先写清维度，再写公式；维度不匹配通常意味着概念错误；
2. 能用分解就不用显式求逆；能用 log-sum-exp 就不要直接算概率；
3. 看到“大矩阵”先问它是否低秩、稀疏或具有平移结构——这往往决定了模型能否落地。

## 本章小结

**核心要点**

1. 深度学习的基本对象是张量；矩阵乘法不交换，转置要反序，广播要检查形状。
2. 范数不仅是“长度”，也是正则化与鲁棒性的语言：$L_1$ 促稀疏，$L_2$ 促平滑，核范数促低秩。
3. 对称矩阵可正交对角化；特征值刻画二次型的曲率，Hessian 的谱决定优化难度。
4. **SVD** 适用于任意矩阵，给出低秩近似与伪逆；PCA 是它在中心化数据上的特例。
5. 行列式是体积缩放，迹是特征值之和；两者把矩阵的整体性质与局部谱联系起来。
6. 计算复杂度与矩阵结构决定了工程可行性；卷积、低秩、稀疏都是利用结构的例子。
