# 3.3 Keras和TensorFlow简史

Keras的出现比TensorFlow早8个月。Keras发布于2015年3月，而TensorFlow发布于2015年11月。

Keras和TensorFlow多年来一直保持共生关系。到2017年底，大多数TensorFlow用户通过Keras来使用TensorFlow或将二者结合使用。到2018年，TensorFlow领导层选择Keras作为官方的TensorFlow上层API。
