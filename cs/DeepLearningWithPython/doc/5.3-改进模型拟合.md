# 5.3 改进模型拟合

为了实现完美的拟合，你必须实现过拟合。由于事先不知道界线在那里，因此你必须穿过界线才能找到它。在开始处理一个问题时，你的初始目标是构建一个具有一定泛化能力并且能够过拟合的模型。得到这样一个模型之后，你的重点将是通过降低过拟合来提高泛化能力。

在这一阶段，你会遇到以下3种常见问题。

- 训练不开始：训练损失不随着时间的推移而减小。
- 训练开始的很好，但模型没有真正泛化：模型无法超越基于常识的基准。
- 训练损失和验证损失都随着时间的推移而减小，模型可以超越基准，但似乎无法过拟合，这表示模型仍处于欠拟合状态。

我们来看以下如何解决这些问题，从而抵达机器学习的第一个重要里程碑：得到一个具有一定泛化能力并且能够过拟合的模型。

## 5.3.1 调节关键的梯度下降参数

有时训练不开始，或者过早停止。损失保持不变。这个问题总是可以解决的：请记住，对随机数据也可以拟合一个模型。即使你的问题毫无意义，也应该可以训练出一个模型，不过这个模型只是记住了训练数据。

出现这种问题时，问题总是出在梯度下降过程的配置：优化器、模型权重初始值的分布、学习率或批量大小。所有这些参数都是相互依赖的，因此保持其他参数不变，调节学习率和批量大小通常就足够了。
