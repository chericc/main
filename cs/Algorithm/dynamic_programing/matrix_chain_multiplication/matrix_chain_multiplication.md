# matrix chain multiplication

## 问题描述

给定 n 个矩阵的链 <$A_1$, $A_2$, ... ,$A_n$> ，矩阵 $A_i$ 的规模为 $p_{i-1} \times p_i $ ，求一组运算顺序，使得乘积 $A_1A_2...A_n$ 所需的乘法次数最少。

注：矩阵的规模为 $p \times q$ ，是指矩阵有 $p$ 行 $q$ 列。

## 问题分析

$p \times q$ 和 $q \times r$ 的两个矩阵相乘，一共需要乘法的次数为 $qpr$ 次；两个矩阵相乘之后，规模为 $p\times r$。

比如 $1\times 2$, $2\times 3$, $3\times 4$ 的矩阵链乘，顺序相乘，则乘法次数为 $1\times 2\times 3 + 1 \times 3 \times 4=18$，如果后面两个矩阵先相乘，则乘法次数为 $2\times 3\times 4 + 1\times 2\times 4=32$。

n 个矩阵链乘，加括号的方式共有第 n-1 个卡特兰数 $C_{n-1} = \frac{1}{n}\binom{2n-2}{n-1}$ 种，随 n 指数增长，直接枚举不可行。

一个简单的思路是，对每种加括号方式，计算对应的乘法次数，找出最少的那种即可。

对链乘的次序进行分析。无论哪种运算顺序，最后一步一定是把链 $A_iA_{i+1}...A_j$ 分成左右两部分 $A_i...A_k$ 和 $A_{k+1}...A_j$（$i \le k < j$），先把两部分各自算好再相乘。左、右两部分又各自是更短的矩阵链乘问题，即形成子问题。

设 $m[i][j]$ 表示计算 $A_iA_{i+1}...A_j$ 所需的最少乘法次数，则：

$m[i][j] = 0$（$i = j$）

$m[i][j] = min_{i \le k < j} ( m[i][k] + m[k+1][j] + p_{i-1}p_kp_j )$（$i < j$）

其中，$p_{i-1}p_kp_j$ 是左右两部分结果相乘所需的乘法次数（左部结果规模 $p_{i-1} \times p_k$，右部结果规模 $p_k \times p_j$），$m[i][k]$ 和 $m[k+1][j]$ 是子问题的最优解。即原问题的最优解包含子问题的最优解（最优子结构）。
