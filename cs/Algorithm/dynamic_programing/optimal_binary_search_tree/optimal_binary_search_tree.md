# optimal binary search tree

最优二叉搜索树

## 问题描述

给定一个 n 个不同关键字的已排序序列 $K=<k_1, k_2, ..., k_n>$ ，我们希望用这些关键字构建一棵二叉搜索树。对每个关键字 $k_i$ ，都有一个概率 $p_i$ 表示其搜索频率。有些要搜索的值可能不在 $K$ 中，，因此我们还有 $n+1$ 个伪关键字 $d_0,d_1,...,d_n$ 表示不在 $K$ 中的值。其中 $d_0$ 表示所有小于 $k_1$ 的值，$d_n$ 表示所有大于 $k_n$ 的值，依此类推。对每个伪关键字，也有一个概率 $q_i$ 表示对应的搜索频率。

有 

$$\sum_{i=1}^{n}p_i + \sum_{i=0}^n q_i = 1$$

使用关键字和伪关键字构造的二叉搜索树，每个关键字都是内部节点，而每个伪关键字是内部节点。
