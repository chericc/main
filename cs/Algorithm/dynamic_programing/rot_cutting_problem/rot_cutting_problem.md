# rot cutting problem

## 问题描述

钢条长度和价格关系如下：

| 长度 | 价格 |
| --- | --- |
| 1 | 1 |
| 2 | 5 |
| 3 | 8 |
| 4 | 9 |
| 5 | 10 |
| 6 | 17 |
| 7 | 17 |
| 8 | 20 |
| 9 | 24 |
| 10 | 30 |

给定一段长度为 n 的钢条，求切割方案，使得销售收益最大。

## 问题分析

长度为 n 的钢条，最多可以切割为 n 个钢条（每个钢条长度为 1）。即，最多有 (n-1) 个切割点，也即切割的总可能性为 $2^{n-1}$ 。

一个简单的思路是，对各个可能性，计算其对应的收益，找出收益最大的对应的方案即可。

对切割之后的情况分析，对于任意一种切割方案，从左往右看，最左侧一定有一截（不切割对应的最左侧长度为 n），右侧有 0 到 n-1 截。把右侧的钢条合并为一个整体，我们只需要求出所有左侧钢条和右侧钢条的价值的最大值即可。左侧钢条是一个整体，右侧钢条又是一个钢条切割问题，即形成子问题。

$p(n) = max(p_i + p(n-i))$

其中，p(n) 表示对长度为 n 的钢条的最大收益，$p_i$ 表示左侧切割长度为 i 的方案对应的左侧钢条的收益。
